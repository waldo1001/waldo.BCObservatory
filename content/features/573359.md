# Translate objects with the same name in different namespaces

> Development: Translate objects with the same name in different namespaces. Generally available, GA 2026-10 (Microsoft 365 roadmap). "Generate namespace-aware translation identifiers so identically named AL objects can be translated independently while existing non-namespaced translations remain valid. Business value: Extension developers can translate objects independently when those objects have the same name but belong to different namespaces. This avoids translation identifier collisions and supports broader adoption of namespaces in existing apps."

[Microsoft 365 roadmap 573359](https://www.microsoft.com/microsoft-365/roadmap?id=573359) · Development · generally available · roadmap status "Launched", phase General Availability

## What Microsoft says

This avoids translation identifier collisions and supports broader adoption of namespaces in existing apps."
