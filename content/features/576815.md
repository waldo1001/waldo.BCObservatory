# Upload, install, and manage PTEs in the admin center

> Governance and administration: Upload, install, and manage PTEs in the admin center. Generally available, GA 2026-07 (Microsoft 365 roadmap). Business Central offers full management of per-tenant extensions (PTEs) in the admin center and through admin center API endpoints. In addition to viewing and uninstalling extensions, administrators can upload PTE packages, install them immediately or schedule installations, and view upcoming extension versions. The API accepts extension package uploads directly, making it easier to integrate with build pipelines and deployment automation.

[Microsoft 365 roadmap 576815](https://www.microsoft.com/microsoft-365/roadmap?id=576815) · Governance and administration · generally available · roadmap status "Launched", phase General Availability

## What Microsoft says

Business Central offers full management of per-tenant extensions (PTEs) in the admin center and through admin center API endpoints. In addition to viewing and uninstalling extensions, administrators can upload PTE packages, install them immediately or schedule installations, and view upcoming extension versions. The API accepts extension package uploads directly, making it easier to integrate with build pipelines and deployment automation. This removes previous limitations that required using the Automation API, which involved more complex configuration and constraints. All new endpoints are also exposed as tools through the admin center API MCP server, enabling developers to manage environments and extensions programmatically and through AI-assisted workflows in tools like VS Code. This provides a consistent, modern surface for extension lifecycle management across manual, automated, and AI-driven scenarios. Business Value: This feature gives administrators full lifecycle control over per-tenant extensions directly from the Business Central admin center and its APIs. It simplifies deployment workflows, enables reliable automation, and reduces operational overhead. Partners and customers can integrate extension management into CI/CD pipelines, improving governance, predictability, and release velocity.
