# Log the expense in a case of lost receipt

> Expense Agent: Log the expense in a case of lost receipt. Announced, GA 2027-02 (Microsoft 365 roadmap). Expense Agent helps employees keep expense submissions moving when an original receipt is unavailable. It guides employees through providing the information needed to support the expense, generates supporting documentation from those details, and enables them to continue the reimbursement process without manually creating replacement documentation. Benefits • Provides a guided process for documenting expenses when receipts are lost or unavailable.

[Microsoft 365 roadmap 573603](https://www.microsoft.com/microsoft-365/roadmap?id=573603) · Expense Agent · announced · roadmap status "In development", phase General Availability

## What Microsoft says

Expense Agent helps employees keep expense submissions moving when an original receipt is unavailable. It guides employees through providing the information needed to support the expense, generates supporting documentation from those details, and enables them to continue the reimbursement process without manually creating replacement documentation. Benefits • Provides a guided process for documenting expenses when receipts are lost or unavailable. • Reduces manual effort by automatically generating supporting documentation from employee-provided information. • Creates a more consistent lost-receipt process for employees and finance teams.
