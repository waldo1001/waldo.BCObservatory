# Create expense reports per trip automatically

> Expense Agent: Create expense reports per trip automatically. Announced, GA 2026-11 (Microsoft 365 roadmap). Expense Agent can automatically create expense reports based on identified business trips. You just need to configure the feature on the Expense Agent Setup page. Instead of manually collecting and organizing individual expense entries, you can use the agent to group relevant expenses and generate a dedicated expense report for each trip. Key capabilities include: Administrators can specify whether the company wants to group expenses by trip and not only by period.

[Microsoft 365 roadmap 573257](https://www.microsoft.com/microsoft-365/roadmap?id=573257) · Expense Agent · announced · roadmap status "In development", phase General Availability

## What Microsoft says

Expense Agent can automatically create expense reports based on identified business trips. You just need to configure the feature on the Expense Agent Setup page. Instead of manually collecting and organizing individual expense entries, you can use the agent to group relevant expenses and generate a dedicated expense report for each trip. Key capabilities include: Administrators can specify whether the company wants to group expenses by trip and not only by period. Automated expense report creation without requiring you to manually start and organize reports after a travel requisition is approved. Automatic trip-based expense grouping associates eligible expenses with the correct business trip based on information in the travel requisition. The agent automatically groups not only expenses based on the location, but uses intelligence to group all expenses based on the context. Non-trip related expenses keep existing period-based grouping in expense reports.
