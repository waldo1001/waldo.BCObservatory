# Install French localization as an extension to the base app

> France: Install French localization as an extension to the base app. In preview, GA 2027-02 (Microsoft 365 roadmap). The localized version for France is now available as a set of extensions on the W1 base app. This version includes a data upgrade feature to simplify the transition from the previous localization. This release moves the product closer to full delocalization, so ISVs can reach a wider market. Some features move to the base app or become global apps, while others stay specific to the French market.
