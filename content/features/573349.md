# Diagnose AL MCP server activity with file logging

> Development: Diagnose AL MCP server activity with file logging. Generally available, GA 2026-10 (Microsoft 365 roadmap). "Write AL MCP server diagnostics to a configurable file, select the appropriate detail level for troubleshooting, or turn file logging off when it isn't required. Business value: Developers and administrators can retain AL MCP server diagnostics for troubleshooting intermittent failures and reviewing agent activity. Configurable verbosity helps capture detailed information during investigation without permanently producing excessive logs."
