# Check records for uncommitted changes

> Development: Check records for uncommitted changes. Generally available, GA 2026-10 (Microsoft 365 roadmap). "Use the Record API IsDirty property to determine whether a record instance contains unsaved changes before deciding to validate, save, or otherwise process it. Business value: AL developers can determine whether a record instance has been changed before deciding to save it, validate it, or prompt the user. This can simplify conditional persistence and reduce unnecessary database operations."
