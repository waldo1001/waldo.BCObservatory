# Create expenses from credit card feeds

> Expense Agent: Create expenses from credit card feeds. Announced, GA 2026-12 (Microsoft 365 roadmap). Expense Agent now supports creating expenses from imported credit card transaction feeds or automatically reconcile with them if the expense was created earlier. Key capabilities include: Import credit card transaction data and review it in the web and mobile apps. Automatically create expenses from imported card transactions. Match imported transactions to existing expenses, where applicable.

[Microsoft 365 roadmap 573256](https://www.microsoft.com/microsoft-365/roadmap?id=573256) · Expense Agent · announced · roadmap status "In development", phase General Availability

## What Microsoft says

Expense Agent now supports creating expenses from imported credit card transaction feeds or automatically reconcile with them if the expense was created earlier. Key capabilities include: Import credit card transaction data and review it in the web and mobile apps. Automatically create expenses from imported card transactions. Match imported transactions to existing expenses, where applicable. Reduce duplicate data entry by leveraging transaction details already captured from credit card feeds. Credit card transactions are manually imported into the Credit Cards Feeds from the file. The system processes the imported transactions and identifies transactions eligible for expense creation. Expense Agent creates draft expenses using transaction information such as merchant, date, and amount. You can review the suggested expenses, and complete any required information before you submit. Matching capabilities help associate imported transactions with existing expenses, which helps avoid duplicates and improves reconciliation.
