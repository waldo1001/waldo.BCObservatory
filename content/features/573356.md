# Simplify AL extension setup and authentication in Visual Studio Code

> Development: Simplify AL extension setup and authentication in Visual Studio Code. Generally available, GA 2026-10 (Microsoft 365 roadmap). "Automatically acquire the required .NET runtime and use Visual Studio Code authentication by default, reducing manual setup across local and browser-hosted environments. Business value: AL developers spend less time installing runtimes and managing separate authentication prompts when setting up Visual Studio Code. The AL extension is also smaller because it no longer includes separate runtime copies for each supported operating system.

[Microsoft 365 roadmap 573356](https://www.microsoft.com/microsoft-365/roadmap?id=573356) · Development · generally available · roadmap status "Launched", phase General Availability

## What Microsoft says

"Automatically acquire the required .NET runtime and use Visual Studio Code authentication by default, reducing manual setup across local and browser-hosted environments. Business value: AL developers spend less time installing runtimes and managing separate authentication prompts when setting up Visual Studio Code. The AL extension is also smaller because it no longer includes separate runtime copies for each supported operating system. The streamlined configuration provides a more consistent setup across Windows, macOS, and Linux."
