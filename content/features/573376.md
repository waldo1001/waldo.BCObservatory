# Reverse Sustainability Ledger entries transaction

> Sustainability Management: Reverse Sustainability Ledger entries transaction. Generally available, GA 2026-10 (Microsoft 365 roadmap). Keep your sustainability data accurate by reversing sustainability ledger entries that contain mistakes. If you post sustainability transactions that contain a mistake, you can’t delete the entries. However, if you posted the entries from a sustainability journal or a general journal, what you can do is use the Reverse Transaction action on the Sustainability Ledger Entries page to reverse them.

[Microsoft 365 roadmap 573376](https://www.microsoft.com/microsoft-365/roadmap?id=573376) · Sustainability Management · generally available · roadmap status "Launched", phase General Availability

## What Microsoft says

Keep your sustainability data accurate by reversing sustainability ledger entries that contain mistakes. If you post sustainability transactions that contain a mistake, you can’t delete the entries. However, if you posted the entries from a sustainability journal or a general journal, what you can do is use the Reverse Transaction action on the Sustainability Ledger Entries page to reverse them. The reversal creates a new sustainability ledger entry that has the document number and posting date from the original entry. It also records the user who ran the reversal. The original posting date makes the values net to zero in the same period.
