# Enable SAF-T audit file format

> Austria: Enable SAF-T audit file format. In preview, GA 2027-04 (Microsoft 365 roadmap). This feature extends support for the Standard Audit File for Tax (SAF-T) format to Austria, allowing customers in this coumtry to generate audit files using the established SAF-T framework. Key capabilities include: Enable SAF-T audit file generation for companies operating in Austria. Reuse the existing SAF-T W1 implementation to support additional country-specific compliance scenarios. Provide a standardized electronic audit file format that can be shared with tax authorities and auditors when required.

[Microsoft 365 roadmap 573619](https://www.microsoft.com/microsoft-365/roadmap?id=573619) · Austria · in preview · roadmap status "In development", phase General Availability

## What Microsoft says

This feature extends support for the Standard Audit File for Tax (SAF-T) format to Austria, allowing customers in this coumtry to generate audit files using the established SAF-T framework. Key capabilities include: Enable SAF-T audit file generation for companies operating in Austria. Reuse the existing SAF-T W1 implementation to support additional country-specific compliance scenarios. Provide a standardized electronic audit file format that can be shared with tax authorities and auditors when required. Simplify multinational compliance processes by using a consistent audit reporting approach across supported countries. By extending an existing SAF-T capability to additional markets, organizations benefit from a more unified compliance experience while reducing the need for separate audit file solutions for each country.
