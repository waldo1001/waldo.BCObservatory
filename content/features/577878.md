# Agent can process vendor credit notes

> Payables Agent: Agent can process vendor credit notes. Announced, GA 2026-11 (Microsoft 365 roadmap). Payables Agent can recognize a vendor credit note and produce a purchase credit memo and applies to the original invoice, using the same draft and task experience as invoices. Note: It does not have Return Order matching functionality.

Payables Agent can recognize a vendor credit note and produce a purchase credit memo and applies to the original invoice, using the same draft and task experience as invoices. Note: It does not have Return Order matching functionality.
