# Access application links through ModuleInfo

> Development: Access application links through ModuleInfo. Generally available, GA 2026-10 (Microsoft 365 roadmap). "Read help, EULA, privacy statement, and locale-aware context-sensitive help links from an app manifest at runtime through additional ModuleInfo properties. Business value: Extensions can surface application-specific help, legal, and privacy resources dynamically instead of duplicating links in code. Context-sensitive help can also respect the current user's locale, improving support experiences for multilingual deployments."

[Microsoft 365 roadmap 573354](https://www.microsoft.com/microsoft-365/roadmap?id=573354) · Development · generally available · roadmap status "Launched", phase General Availability

## What Microsoft says

"Read help, EULA, privacy statement, and locale-aware context-sensitive help links from an app manifest at runtime through additional ModuleInfo properties. Business value: Extensions can surface application-specific help, legal, and privacy resources dynamically instead of duplicating links in code. Context-sensitive help can also respect the current user's locale, improving support experiences for multilingual deployments."
