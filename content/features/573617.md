# Export euBP with audit files export

> Germany: Export euBP with audit files export. In preview, GA 2027-01 (Microsoft 365 roadmap). Create more complete audit export packages with less manual preparation by exporting European Business Profile (euBP) information together with transactional audit data. Organizations using the German localization can include both in a single Audit Files Export process. Benefits: • Export euBP and transactional audit data together in a single process. • Include relevant business profile information in exported audit documentation.

[Microsoft 365 roadmap 573617](https://www.microsoft.com/microsoft-365/roadmap?id=573617) · Germany · in preview · roadmap status "In development", phase General Availability

## What Microsoft says

Create more complete audit export packages with less manual preparation by exporting European Business Profile (euBP) information together with transactional audit data. Organizations using the German localization can include both in a single Audit Files Export process. Benefits: • Export euBP and transactional audit data together in a single process. • Include relevant business profile information in exported audit documentation. • Reduce manual data collection and reconciliation during audit preparation. • Provide auditors and regulatory authorities with relevant audit and business profile information in a standardized format.
