# Try Payables Agent for free without setting up email

> Copilot and agents: Try Payables Agent for free without setting up email. Generally available, GA 2026-07 (Microsoft 365 roadmap). Payables Agent introduces a free trial mode that any user can start without help from an administrator or having paid credits. You can start the trial directly from the agent setup card or from the Purchase Invoices page. You don't need to have an administrator role or configure an email account. You upload invoice PDFs manually to start processing, bypassing the email-based sourcing flow entirely.

[Microsoft 365 roadmap 576776](https://www.microsoft.com/microsoft-365/roadmap?id=576776) · Copilot and agents · generally available · roadmap status "Launched", phase General Availability

## What Microsoft says

Payables Agent introduces a free trial mode that any user can start without help from an administrator or having paid credits. You can start the trial directly from the agent setup card or from the Purchase Invoices page. You don't need to have an administrator role or configure an email account. You upload invoice PDFs manually to start processing, bypassing the email-based sourcing flow entirely. The trial activates immediately the first time you upload an invoice. The trial includes 50 free invoice uploads. Each upload counts against the quota. You can track your remaining quota on the agent setup card throughout the trial. The full agent workflow is available during the trial: Extract invoice data Match vendors Suggest lines Create and finalize purchase invoice drafts You can experience the same capabilities that you would after subscribing. If you use up your quota of 50 invoices, continued use requires available credits. This feature is available from the May minor release of 2026 release wave 1. Business Value: Trying out the Payables Agent currently requires that you configure an email connection, which is a step that creates friction before a user has even seen what the agent does. Accounts payable clerks and accountants who want to explore the agent often can't do so on their own, because setting up email often requires help from an administrator. This feature lets any user start a Payables Agent free trial by uploading invoice files directly, with no email configuration required. Companies get a quota of 50 free invoices to experience the full agent workflow, including data extraction, vendor matching, line suggestion, and draft creation and finalization. By removing the technical barrier and the need to involve an administrator, more users can discover the agent's value firsthand and build the case for adoption within their organization.
