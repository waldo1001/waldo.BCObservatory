# Actions on reports and pages can now inherit tooltips

> Development: Actions on reports and pages can now inherit tooltips. Generally available, GA 2026-10 (Microsoft 365 roadmap). Tooltips on page or report objects are now inherited into actions that run those pages. This means you only need to write descriptive tooltips in one place and have it propagated out to all usage of the object.

[Microsoft 365 roadmap 573313](https://www.microsoft.com/microsoft-365/roadmap?id=573313) · Development · generally available · roadmap status "Launched", phase General Availability

## What Microsoft says

Tooltips on page or report objects are now inherited into actions that run those pages. This means you only need to write descriptive tooltips in one place and have it propagated out to all usage of the object.
