# Configure AL MCP workspaces dynamically

> Development: Configure AL MCP workspaces dynamically. Generally available, GA 2026-10 (Microsoft 365 roadmap). "Start the AL MCP server without a predefined project, add AL projects at runtime, and use configured connection details in headless scenarios without authentication prompts. Business value: AI-agent hosts can start a reusable AL MCP server before the target project is known, then load projects as work begins. This supports flexible agent sessions, shared tooling configurations, and headless automation without requiring a separate server process for every preconfigured workspace."

[Microsoft 365 roadmap 573348](https://www.microsoft.com/microsoft-365/roadmap?id=573348) · Development · generally available · roadmap status "Launched", phase General Availability
