# Use new APIs for getting the PDF of a document report

> Reporting and data analysis: Use new APIs for getting the PDF of a document report. Generally available, GA 2026-06 (Microsoft 365 roadmap). We're introducing read-only APIs in the document report system. The APIs help establish automation on document reporting outside Business Central. For example, to create agents with Microsoft Copilot Studio and MCP Server for Business Central to automate business processes that involve document PDFs.

[Microsoft 365 roadmap 576792](https://www.microsoft.com/microsoft-365/roadmap?id=576792) · Reporting and data analysis · generally available · roadmap status "Launched", phase General Availability

## What Microsoft says

We're introducing read-only APIs in the document report system. The APIs help establish automation on document reporting outside Business Central. For example, to create agents with Microsoft Copilot Studio and MCP Server for Business Central to automate business processes that involve document PDFs.
