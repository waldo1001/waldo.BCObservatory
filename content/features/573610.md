# Use tags to mark processed emails

> Expense Agent: Use tags to mark processed emails. Announced, GA 2027-04 (Microsoft 365 roadmap). Quickly see which expense-related emails have already been processed by Expense Agent, helping you distinguish processed from unprocessed messages with confidence. Expense Agent adds a **Processed by Expense Agent **tag in Outlook after a relevant email has been successfully processed. Benefits • Automatically marks successfully processed expense-related emails. • Provides a clear processing-status indicator in Outlook, reducing the need to verify status manually.

[Microsoft 365 roadmap 573610](https://www.microsoft.com/microsoft-365/roadmap?id=573610) · Expense Agent · announced · roadmap status "In development", phase Preview

## What Microsoft says

Quickly see which expense-related emails have already been processed by Expense Agent, helping you distinguish processed from unprocessed messages with confidence. Expense Agent adds a **Processed by Expense Agent **tag in Outlook after a relevant email has been successfully processed. Benefits • Automatically marks successfully processed expense-related emails. • Provides a clear processing-status indicator in Outlook, reducing the need to verify status manually. • Makes it easier to distinguish processed from unprocessed expense-related emails.
