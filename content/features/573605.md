# Enable approving limits and alternate approvers when primary is not available

> Expense Agent: Enable approving limits and alternate approvers when primary is not available. Announced, GA 2027-02 (Microsoft 365 roadmap). Keep expense approvals moving when primary approvers are unavailable or when requests exceed their approval limits. Organizations can set a maximum approval amount—or unlimited approval authority—for each approver, designate a next approver for requests above that limit, and assign alternate approvers as temporary or scheduled backups.

[Microsoft 365 roadmap 573605](https://www.microsoft.com/microsoft-365/roadmap?id=573605) · Expense Agent · announced · roadmap status "In development", phase General Availability

## What Microsoft says

Keep expense approvals moving when primary approvers are unavailable or when requests exceed their approval limits. Organizations can set a maximum approval amount—or unlimited approval authority—for each approver, designate a next approver for requests above that limit, and assign alternate approvers as temporary or scheduled backups. Approval requests can route to an alternate approver during periods of unavailability while following the same approval processes and controls. Benefits • Set approval limits for each approver and route requests that exceed those limits to a designated next approver. • Assign alternate approvers for ad hoc needs or planned periods of absence to help maintain approval continuity. • Reduce delays for employees submitting expenses by keeping approval requests moving when the primary approver is unavailable.
