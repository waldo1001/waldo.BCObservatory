# Install Norwegian localization as an extension to the base app

> Norway: Install Norwegian localization as an extension to the base app. Announced, GA 2027-03 (Microsoft 365 roadmap). The localized version for Norway is now available as a set of extensions on the W1 base app. This version includes a data upgrade feature to simplify the transition from the previous localization. This release moves the product closer to full delocalization, so ISVs can reach a wider market. Some features move to the base app or become global apps, while others stay specific to the Norwegian market.

[Microsoft 365 roadmap 573623](https://www.microsoft.com/microsoft-365/roadmap?id=573623) · Norway · announced · roadmap status "In development", phase General Availability

## What Microsoft says

The localized version for Norway is now available as a set of extensions on the W1 base app. This version includes a data upgrade feature to simplify the transition from the previous localization. This release moves the product closer to full delocalization, so ISVs can reach a wider market. Some features move to the base app or become global apps, while others stay specific to the Norwegian market. In the same time some of local features will ber migrated to global ones, such as non-deductible VAT.
