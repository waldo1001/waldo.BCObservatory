# Create expense with no attachment

> Expense Agent: Create expense with no attachment. Announced, GA 2027-04 (Microsoft 365 roadmap). Save time when recording lower-value expenses by creating them in Expense Agent without an attachment when the amount is below the limit you set on the Expense Agent Setup page. This gives you the flexibility to record qualifying expenses even when a receipt or supporting document isn’t available. Benefits • Create qualifying expenses without requiring an attachment at the time of submission. • Set the amount limit that determines when an attachment isn’t required.

[Microsoft 365 roadmap 573604](https://www.microsoft.com/microsoft-365/roadmap?id=573604) · Expense Agent · announced · roadmap status "In development", phase General Availability

## What Microsoft says

Save time when recording lower-value expenses by creating them in Expense Agent without an attachment when the amount is below the limit you set on the Expense Agent Setup page. This gives you the flexibility to record qualifying expenses even when a receipt or supporting document isn’t available. Benefits • Create qualifying expenses without requiring an attachment at the time of submission. • Set the amount limit that determines when an attachment isn’t required. • Record expenses below the configured limit even when a receipt or supporting document isn’t available.
