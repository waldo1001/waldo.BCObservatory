# Use new APIs for analyzing approval workflows for auditors and IT staff

> Reporting and data analysis: Use new APIs for analyzing approval workflows for auditors and IT staff. Generally available, GA 2026-06 (Microsoft 365 roadmap). In this release wave, we're introducing read-only APIs on the (workflow) approval system. This allows for establishing security and auditing analytics and reporting outside Business Central—for example, creating reports with Power BI or agents with Microsoft Copilot Studio and MCP Server for Business Central.

[Microsoft 365 roadmap 576864](https://www.microsoft.com/microsoft-365/roadmap?id=576864) · Reporting and data analysis · generally available · roadmap status "Launched", phase General Availability

## What Microsoft says

In this release wave, we're introducing read-only APIs on the (workflow) approval system. This allows for establishing security and auditing analytics and reporting outside Business Central—for example, creating reports with Power BI or agents with Microsoft Copilot Studio and MCP Server for Business Central. The APIs are read-only and allow querying for: Workflow Workflow and User mappings Workflow, User, and Action history We're also introducing a new permission set that allows a user to use approval APIs. This shouldn't be granted to standard users, but might be included in security-related permission sets. Business Value: This feature enhances transparency and control by enabling secure, read-only access to approval workflows and user actions. Businesses can leverage these APIs to build advanced auditing and compliance reports in tools like Power BI, ensuring stronger governance and accountability. Additionally, integration with Microsoft Copilot Studio and MCP Server opens opportunities for intelligent automation and analytics, driving efficiency and insight. By isolating permissions for API access, organizations maintain robust security while empowering authorized teams to innovate confidently. Enabled for: Enabled for end users automatically
