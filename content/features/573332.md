# Faster data loading with improved data model for table extensions

> Service and platform: Faster data loading with improved data model for table extensions. Generally available, GA 2026-10 (Microsoft 365 roadmap). With the new data model for table extensions, all fields on an AL table are stored in the same table in the database. This gives faster performance on all database operations that involve table extensions.

[Microsoft 365 roadmap 573332](https://www.microsoft.com/microsoft-365/roadmap?id=573332) · Service and platform · generally available · roadmap status "Launched", phase General Availability

## What Microsoft says

With the new data model for table extensions, all fields on an AL table are stored in the same table in the database. This gives faster performance on all database operations that involve table extensions.
