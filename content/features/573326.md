# Reuse header/footer layouts across document reports

> Reporting and data analysis: Reuse header/footer layouts across document reports. Generally available, GA 2026-10 (Microsoft 365 roadmap). With the new composable layouts feature, you can apply a header/footer on layouts to get consistent look and feel on the PDF output. It is possible to set defaults on a global level, per company, per report, or per layout, giving the administrator full flexibility of theming.

[Microsoft 365 roadmap 573326](https://www.microsoft.com/microsoft-365/roadmap?id=573326) · Reporting and data analysis · generally available · roadmap status "Launched", phase General Availability

## What Microsoft says

With the new composable layouts feature, you can apply a header/footer on layouts to get consistent look and feel on the PDF output. It is possible to set defaults on a global level, per company, per report, or per layout, giving the administrator full flexibility of theming.
