# Start using the new non-deductible VAT framework in Belgium

> Country and regional: Start using the new non-deductible VAT framework in Belgium. Announced, GA 2027-02 (Microsoft 365 roadmap). Belgian users will experience an improved non-deductible VAT process with the introduction of a new global feature. A preconfigured Non-deductible VAT Type field will be available specifically for Belgium. Previously, users selected a general ledger expense account in the Chart of Accounts and manually entered the partial deduction amount in the % Non-deductible VAT field.

[Microsoft 365 roadmap 576751](https://www.microsoft.com/microsoft-365/roadmap?id=576751) · Country and regional · announced · roadmap status "In development", phase General Availability

## What Microsoft says

Belgian users will experience an improved non-deductible VAT process with the introduction of a new global feature. A preconfigured Non-deductible VAT Type field will be available specifically for Belgium. Previously, users selected a general ledger expense account in the Chart of Accounts and manually entered the partial deduction amount in the % Non-deductible VAT field. With the new approach, users will follow the standard global method, and setup will be managed through the VAT Posting Group Setup . When you enable the new feature in the VAT Setup page, the system automatically provides a data upgrade. Business Value: Users in Belgium will receive an upgraded version of non-deductible VAT using the new global feature. Enabled for: Enabled by admins/makers/marketers for end users
