## Code changes

All twelve pull requests this week landed in microsoft/BCApps; nine change behaviour and none is breaking. #14297 makes the German ELMA XML export set the VAT report status to Exported instead of leaving it Released. #13854 stops the Set G/L Account No. function from running over all VAT entries, so the VAT Entries page and the G/L - VAT Reconciliation report respect user filters. #14225 fixes a regression so Get Return Shipment Lines works again on purchase credit memos for non-inventory items. #13904 adds unposted purchase return orders and credit memos to Find Entries on the Navigate page. In warehouse and manufacturing, #14013 stops stale pick bins from reaching item tracking on Transfer and Purchase-Return shipments, and #13206 removes the serial number error when reversing a Capacity Ledger Entry. #9193 locks the Code labels on default Transformation Rule records against translation. Two features change behaviour: #14400 gives cross-environment master data synchronization clear connection and permission errors, and #13673 exposes the active expense approver in the Expense Reports API, adds an Open Expense App action and obsoletes an unused FlowFilter. Three changes have no behaviour impact: #14405 renumbers three Expense Agent codeunits to avoid collisions with deprecated country apps, #14423 makes the FI depreciation posting buffer temporary, and #14327 exposes Payables Agent infotip sources through test fixtures only.
