## Code changes

The week's behaviour changes centre on the Expense Agent and Payables Agent. #14492 registers the Expense Agent Copilot capability as Generally Available instead of Preview, #14491 moves E-Document LLM calls under the Payables Agent capability, and #14442 offers the Payables Agent again in a company recreated with the same name. Expense Agent work also includes configurable per diem rounding (#14136), approval setup fixes (#13910, backported in #13927), and API changes that expose the active approver and obsolete an unused FlowFilter (#13673). Partners get new extension events and a public Create Expense Report codeunit (#14346). Codeunits were renumbered in #14405 to avoid collisions with deprecated country apps. Posting and warehouse fixes cover item charges on purchase invoice cancellation (#13112), partial inventory picks with strict expiration (#14240), FEFO pick splitting (#13331), stale pick bins (#14013) and serial numbers when reversing capacity entries (#13206). Finance and localization fixes include #13676, #14184, #14139, #13613, #14297, #13854 and #14225. Other changes: Report Filename defaults (#13732), clearer Master Data Management errors (#14400, #14077), EAP cockpit details (#14480), demo data excluding the WorkIQ feature key (#13905), Navigate (#13904), and locked Transformation Rule codes (#9193). Type and buffer fixes are #14471 and #14423, and #14327 is test fixtures only.
