## Code changes

The one breaking change this week is #13759, which removes CLEAN27 obsolete code from the W1 and regional apps, including 140 deleted AL files, so extensions still using those objects need to move to the replacements. Posting and VAT fixes changed behaviour: #13805 and #13482 keep the document's allocated non-deductible VAT amounts on purchase posting, #13344 stops a credit memo copied from a posted invoice from reverting quantities on the original purchase order, #12770 carries modified invoice discounts into project ledger entries, #13628 fills drop shipment reference fields on posted receipt lines, and #13861 completes the dispute status fix on customer ledger entries. #9587 adds concurrent posting for G/L entries. Manufacturing and planning changes include #13778 on component dimensions from Order Planning, #13724 on warehouse picks for make-to-order subassemblies and #13618 on serial numbers lost during regenerative planning. #9522 adds the OnAfterIncreaseQty event. Expense Agent work covers #13760, #13672, #13730, #13499, #12670 and #13792. E-Document changes are #13822 for full XRechnung item names and #13766 and #13765 for an output token limit. Other fixes: #13572, #13641, #13447, #13855, #13739, #13616, #13607, #13225 and #13315. #13554 extends the Fabric API, and #12084 adds Subcontracting telemetry.
