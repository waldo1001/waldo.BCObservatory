# How to Install Business Central 29 On-Premises | Full Setup

> Step-by-step on-premises installation of Business Central 29 (2026 release wave 2): setup wizard, component selection, service ports, SQL Server and IIS setup, plus software and hardware requirements. Useful as evidence for install options, port settings and SQL troubleshooting.

[Watch on YouTube](https://www.youtube.com/watch?v=KA1vHd1hITY) · Saurav Dhyani · 2026-10-09 · 34:40 · tier community · reviewed (checked by Opus)

## Overview

The video walks through a full on-premises installation of Business Central 29 from the product DVD. It covers the install demo and advanced options, the developer option, multi-tier deployment, service tier and port settings (including a separate reporting services port that is new in this version), authentication choices, SQL instance and demo database restore, and the web client published under IIS.

It also covers SQL Server troubleshooting, such as enabling TCP/IP, and the DVD contents: prerequisites, 83 default Microsoft apps, the system application and the AL VSIX file. The last part lists software and hardware requirements for servers, developer machines, the mobile app, Outlook and Office. The presenter says the install is not complex, but missed requirements cause errors.

## Key points

- Run the installer as administrator and place the DVD content near the root drive to avoid long path name errors.
- Install demo puts all components on one machine; choosing an installation option lets you pick components for production multi-tier deployments. The developer option installs the AL extension, service tier, web server and SQL database, but not VS Code itself.
- Business Central 29 has a new separate service port for reporting services. If the developer service port is changed from the default 7049, specify it explicitly in the VS Code configuration. Snapshot debugging needs a separate port (the presenter uses 8083 and adds a client firewall rule).
- SQL instance name can be left empty for a default instance and must be given for a named instance. TCP/IP must be enabled on SQL Server (restart the service) if it is off.
- SQL requirements: SQL Server 2022 Express or higher with compatibility level 160 or 170, and full-text and semantic extractions enabled at SQL install.
- OS and hardware: Windows 11 Enterprise, Education or Pro, or Windows Server 2022/2025 Standard or Data Center; IIS 10 or higher; 4-core CPU; 16-64 GB RAM depending on extension size; about 100 GB disk for a server.
- Change configuration through PowerShell commands rather than editing custom settings config directly. The NAV settings JSON file links the web client to the service tier.
