# What's New: Page Scripting Enhancements (2025 release wave 2)

> Page scripting enhancements in Business Central 2025 release wave 2 (version 27): editing recorded steps, parameters and test suites in the UI, for-each loops, expression-based conditions, and server-side headless replay, which is in preview and limited to on-premise or containers.

[Watch on YouTube](https://www.youtube.com/watch?v=KnyS6ZKI_2c) · Microsoft Dynamics 365 Business Central (YouTube) · 2025-10-01 · 15:49 · tier official · **unreviewed** (machine-generated)

## Overview

The video covers what changed in the page scripting tool for version 27, based on user feedback about recording and editing scripts. It demos inserting steps at a chosen point, drag-and-drop reordering, deleting any step, and creating parameters and test suites in the UI instead of editing YAML.

It then shows iterating over repeater entries with "for each row", conditional steps using "expression is true", and running scripts headless on the server during pipeline execution with BC Replay. Server-side replay is in preview. The presenters also say the page scripting feature is still in preview but production quality.

## Key points

- Recording now supports defining an insertion point, rearranging steps by drag and drop, and deleting any step, not only the last. Changing steps out of order can affect later steps.
- From version 27, parameters can be created, edited and viewed in the UI instead of in YAML files.
- Test suites can be created in the UI by composing scripts with an 'include a script' step that passes parameters between scripts.
- Included scripts cannot be edited in the suite and must be persisted first. Scripts in other directories need a manually specified relative path.
- Right-click a repeater and choose 'for each row' to run steps for every list entry. A conditional step using 'expression is true' evaluates a custom expression.
- Server-side headless replay uses the 'use server replay' parameter with BC Replay in pipelines. It is in preview, works on-premise or in containers only, and produces no video recordings.
- Creating documentation or training material with screenshots is not in the immediate backlog.
