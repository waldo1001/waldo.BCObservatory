# What's New: VAT Date in Business Central (2023 release wave 2)

> VAT Date in Business Central (2023 release wave 2): a separate VAT date field alongside posting date, with setup options on General Ledger Setup, posting consistency checks, VAT return period controls, reports that filter on VAT date, and editing after posting from VAT entries.

[Watch on YouTube](https://www.youtube.com/watch?v=MWXwtRr6-Wk) · Microsoft Dynamics 365 Business Central (YouTube) · 2023-12-11 · 16:51 · tier official · **unreviewed** (machine-generated)

## Overview

The video explains the VAT Date feature, which lets users report VAT on a date other than the posting date, for example a document date. It covers how the field was introduced starting with 2022 release wave 2 (version 21), how existing entries are populated with the posting date through upgrade code, and where it applies. It is a W1 feature available in most countries except Italy, which already had a similar feature. In localizations without a VAT system the field is called tax date.

The presenter walks through the General Ledger Setup options (VAT Date Usage, Default VAT Date, Control VAT Period), the consistency checks in the posting procedure, and how VAT-based reports use the VAT date. It also shows changing the VAT date after posting from VAT entries. A planned redesign in a later minor version of version 23 will move the allowed VAT date range into separate fields in VAT setup.

## Key points

- VAT Date separates VAT reporting from posting date. It is a W1 feature in most countries except Italy, which already had a similar feature. Where there is no VAT system, the field is called tax date.
- VAT Date Usage on General Ledger Setup has three options: Enable, Prevent Modification (default in countries where VAT date cannot be changed after posting) and Disabled (field hidden, but the system still uses posting date automatically).
- Default VAT Date on General Ledger Setup chooses posting date or document date as the default. It can be changed only on non-posted documents and affects some postings.
- Control VAT Period can block posting, warn only, or be turned off when VAT periods are not used. Posting checks cover a default VAT date if empty, the allowed VAT posting date range, and non-closed VAT return periods.
- A blank VAT date can still be posted through APIs even though the UI prevents it.
- With the default setup, VAT reports such as VAT statement, Calculate and Post VAT Settlement and VAT Declaration give the same output as before, because VAT date equals posting date. Output differs only if VAT dates are edited or setup is changed.
- A VAT date can be modified after posting from VAT entries if setup allows. The change propagates to posted documents and related GL entries.
