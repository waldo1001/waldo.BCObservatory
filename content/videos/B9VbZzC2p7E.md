## Overview

Erik Hougaard shows how an agent inside the Advanced Spreadsheets and Reporting app for Business Central can query data with SQL. The agent is opened from the facts box area on the right. In the demo it builds a join of posted sales invoices (sales invoice header) with customer and ledger entries and puts the result into the spreadsheet.

The video then shows how to create a SQL region manually, for example selecting name from the customer table. It notes that the agent has tools to manipulate the spreadsheet and to look at fields and tables, and that the app is free to use in the cloud sandbox.

## Key points

- The agent is reached only through the facts box area on the right side of the spreadsheet.
- The agent has tools to manipulate spreadsheet content and to look up tables and fields.
- Demo: the agent joins sales invoice header, customer and ledger entries and returns the data in the spreadsheet.
- Manual alternative: create a SQL region yourself, for example selecting name from the customer table.
- Manual SQL needs basic SQL knowledge; yellow validation warnings may appear while typing.
- Knowing the table and field structure helps the agent work effectively.
- The app is stated to be free to use in the cloud sandbox.
