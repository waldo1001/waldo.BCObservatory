# What's New: Financial Management - G/L Account Revaluations (2024 release wave 1)

> G/L account revaluation in Business Central (2024 release wave 1): a batch job that adjusts G/L balances per currency, plus controls for which currencies can post to an account. Shows single and multiple currency demos and compares it with the standard currency exchange rate adjustment batch job.

[Watch on YouTube](https://www.youtube.com/watch?v=u1oO9MEg9kc) · Microsoft Dynamics 365 Business Central (YouTube) · 2024-04-04 · 13:16 · tier official · **unreviewed** (machine-generated)

## Overview

The video covers the 2024 release wave 1 changes for multi-currency G/L accounts. The original currency code can now be stored on G/L entries, which the presenter says was a top request for over 5 years with more than 500 votes. Accounts can also be set to allow a single currency, multiple currencies, or any currency.

The demos turn on the feature in feature management, set up a revaluation account, and run the revaluation for a euro loan and then a Canadian dollar scenario with multiple currencies configured on the account. The video then compares G/L revaluation with the standard currency exchange rate adjustment batch job and gives recommendations on when to use each.

## Key points

- Turn the feature on in feature management with the setting 'Enable use of GL currency revaluation'.
- G/L revaluation adjusts the balance per currency, not each entry.
- Allowed currencies are set per G/L account: blank, a single currency, or multiple currencies through the related Source currencies table.
- The presenter recommends one currency per account; multiple currencies were shown for demo purposes.
- Do not use G/L revaluation for bank, customer or vendor accounts, which have their own adjustment mechanisms.
- The standard currency exchange rate adjustment batch job is separate. It handles customers, vendors, employees and bank accounts, and can now adjust per entry.
- Check that per-balance revaluation meets your reporting requirements before adopting it.
