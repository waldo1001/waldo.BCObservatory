# What's New: Run Page Scripts in CICD Pipelines (2024 release wave 2)

> Page script replayer for CI/CD pipelines in Business Central (2024 release wave 2): a standalone replayer distributed as an NPM package that runs recorded page scripts in pipelines for regression testing. AL-Go for GitHub support is announced for the near future; ALOps and Alpaca support are also planned.

[Watch on YouTube](https://www.youtube.com/watch?v=5GoAzII20L0) · Microsoft Dynamics 365 Business Central (YouTube) · 2024-10-08 · 5:31 · tier official · **unreviewed** (machine-generated)

## Overview

The video builds on the page scripting tool, which lets customers and consultants record and replay user actions in the web client to create user acceptance tests. Partners asked for a way to run these scripts without replaying them manually in the client, since the earlier preview worked only that way.
The release adds a standalone page script replayer, distributed as an NPM package, so recorded scripts can run in CI/CD pipelines as automated regression tests. The video demos installing and using the BC Replayer package. It also says support in managed DevOps solutions, mainly AL-Go for GitHub, is coming soon, with ALOps and Alpaca also planned.

## Key points

- Page scripting records and replays user actions in the web client to build user acceptance tests.
- Before this release, replay was client-only, which partners flagged as a limitation.
- The standalone replayer is an NPM package; install the latest version and use it in pipelines. It is available today.
- It needs Node.js, Playwright and additional dependencies installed; Windows authentication is the default.
- AL-Go for GitHub support for the replayer is announced for the near future; ALOps and Alpaca support are also planned.
- The video describes the page scripting tool as having launched in the previous release as a preview.
