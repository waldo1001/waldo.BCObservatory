# Comparing Subaccounts Segments and Dimensions Transaction and Reporting Dynamics SL and Dynamics

> Dynamics SL subaccount segments compared with Business Central dimensions: segments migrate as dimensions via the cloud migration tool. The video demos default dimensions on vendors, automatic defaulting on purchase invoices, posting preview, and the Trial Balance Dimension Report.

## Overview

The video, a 4-minute walkthrough published 2024-07-26, compares how Dynamics SL posts transactions using subaccount segments with how Business Central uses dimensions. In SL, the batch control report shows debit and credit accounts with their sub account segments.

It then shows the Business Central side: segments defined in SL migrate as dimensions, default dimensions are set on a vendor, and those values populate on purchase invoices. It finishes with previewing a posting before the journal is posted and analyzing results in the trial balance report by dimension.

## Key points

- Segments defined in Dynamics SL migrate to Business Central as dimensions using the cloud migration tool.
- Default dimensions can be assigned on vendor records and populate automatically on transactions for that vendor.
- Setting the value posting to code mandatory enforces that a dimension value exists on transactions; this is optional based on business needs.
- On a purchase invoice, defaulted dimension values show in the fact box without manual entry.
- Posting preview in Business Central lets you check the accounts before posting a journal, similar to the distributions button in SL.
- The Trial Balance Dimension Report shows amounts posted to main accounts and can be filtered by dimensions such as reporting unit and company segment.
