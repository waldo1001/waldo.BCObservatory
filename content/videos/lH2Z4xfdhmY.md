# What’s New: Data Search Improvements (For Developers) (2024 release wave 2)

> Modern search in Business Central (2024 release wave 2) for developers: searches for all words instead of substrings, is enabled per field with the optimized for text search property, and applies to page search, lookup and company-wide search. Covers the new double and filter operator in SetFilter and full-text index generation.

[Watch on YouTube](https://www.youtube.com/watch?v=lH2Z4xfdhmY) · Microsoft Dynamics 365 Business Central (YouTube) · 2024-10-08 · 11:10 · tier official · **unreviewed** (machine-generated)

## Overview

The video explains modern search, which matches all words rather than any substring in a word and is significantly faster than the legacy search. It is demonstrated in item lists, page search, lookup and company-wide search, with a performance comparison against legacy search.

For developers, it shows how to enable modern search by setting the optimized for text search property on table and table extension fields. It also covers how the synchronization engine generates the full-text index, how the new double and filter operator works in the SetFilter method of the record API, and how the page inspector helps check generated filters, since the syntax can be hard to grasp.

## Key points

- Set optimized for text search = true on table fields or table extension fields to enable modern search on them.
- Apply the property to primary key, descriptive text and identifying fields users search on; avoid fields with thousands of rows or grouping use.
- Modern search matches all words, word order does not matter, and it is faster than legacy substring search.
- Prefix a query with a double star to force legacy substring search in page search, lookup and company-wide search.
- The SetFilter method has a new double and filter operator for full-text matching; on fields without the property it falls back to a case-insensitive contains search.
- The synchronization engine creates and regenerates one full-text index per table with indexed fields, using language-neutral word breakers such as space and dash.
- Company-wide search uses modern search only for fields with the property; other fields keep legacy behavior.
