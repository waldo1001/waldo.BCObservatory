# Business Central Under the Hood episode 10: Hackers Are at the Gate! Business Central & Security.

> Business Central security discussion (Under the Hood episode 10, Aug 2025): current cyber threats, secure by default, cloud threat intelligence sharing, security development lifecycle, bounty program, red team testing, and guidance for partners and customers on MFA, threat modeling and incident response.

## Overview

The episode covers the current threat landscape, including credential stuffing, ransomware and the exposure of small businesses, and how Microsoft secures Business Central. Topics include the secure by default approach, threat intelligence that is cascaded across cloud customers, and code review through the security development lifecycle with static analysis and code scanning.

It also describes secure admin workstations, auditing and security logs sent to Microsoft Purview, the Dynamics 365 bounty program, and a 2019 red team exercise. The closing sections cover threat modeling, CISO workshops, fishing resistant MFA, phishing and social engineering, AI in security and incident response, and recommendations for partners and customers.

## Key points

- Business Central ships auditing and security logs to Microsoft Purview, so customers can build their own alerts and detect anomalies. This is part of a joint responsibility model.
- Cloud customers benefit from threat intelligence sharing: when an attack is detected on one customer, such as malicious IP addresses, it can be cascaded to all customers immediately.
- All Business Central code goes through professional security team review, including threat modeling, risk assessment and mitigation tracking, plus static analysis and code scanning before release.
- Production access uses secure admin workstations that are separate from corporate systems and need a physical security dongle, a second factor and a specialist VPN.
- Do not use SMS as multifactor authentication. Microsoft uses fishing resistant MFA such as passkeys.
- Partners and developers are pointed to the security development lifecycle guidance, a threat modeling video, and CISO workshop videos with decks.
- Microsoft pays researchers through the Dynamics 365 bounty program to report vulnerabilities responsibly, and now reports cloud bugs even without a CVE.
