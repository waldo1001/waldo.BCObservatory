# Using the Spotlight Tour Element in Onboarding

> Spotlight tour element in Business Central onboarding: a two-step pattern that introduces a page and points to an action, so users can try Teams and Excel features. Developers choose which pages use it. Clip from the 2023 release wave 2 launch event.

[Watch on YouTube](https://www.youtube.com/watch?v=5GD8S3XzQmA) · Microsoft Dynamics 365 Business Central (YouTube) · 2024-04-18 · 1:37 · tier official · reviewed (checked by Opus)

## Overview

The video explains the spotlight tour element as a way to show key selling points of Business Central, currently Teams and Excel. It lets users discover a feature and try it in two steps.

The first step is introduction text that explains the value of the page, helping users who are new to it. The second step points to an action where the user can try the feature. Developers decide which pages get a tour. The clip comes from a launch event video for 2023 release wave 2 and the presenter says it is equally relevant today.

## Key points

- Spotlight tours currently focus on Teams and Excel features.
- The pattern has two steps: an introduction text explaining the value of the page, then a pointer to an action the user can try.
- Developers decide which of their pages should call out a spotlight tour.
- Use a spotlight tour on a page where the Teams or Excel feature is relevant.
- It is meant to help users who are new to a page know where they are.
- The source is a clip from the 2023 release wave 2 launch event, described as still relevant.
- More information: aka.ms/BConboarding.
