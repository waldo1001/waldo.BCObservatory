## Overview

This one-minute video from the Business Central channel (published 2024-03-21) covers updates to the action bar in 2024 release wave one. The changes aim to make the action bar simpler to use and free up space.

The analysis mode icon is new and takes less space, but stays in the same place and still turns analysis mode on and off. Search and analysis mode captions are removed. Copilot is now on the action bar, so Copilot actions are easier to reach on any list page. The updated action bar is standard, the process tab is now called home and holds the most popular actions, and split buttons on the home tab group those actions for faster access.

- Captions for search and analysis mode are removed from the action bar to create more space.
- Copilot is on the action bar, so Copilot actions are easier to reach on any list page.
- The updated action bar is standard for all users.
- The process tab is renamed home, where the most popular actions are.
- Split buttons on the home tab group popular actions for faster access to frequently used functions.
