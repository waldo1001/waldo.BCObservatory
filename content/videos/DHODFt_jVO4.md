# What's New in Manufacturing: Costing (2025 release wave 1)

> Manufacturing costing changes in Business Central 2025 release wave 1: production BOM and routing can be defined on stock keeping units, and standard cost can be calculated per SKU after activation in manufacturing setup. Non-inventory costs can also be included in the production cost calculation, with new columns on the cost shares page and production order statistics. Both capabilities are shown in short demos.

[Watch on YouTube](https://www.youtube.com/watch?v=DHODFt_jVO4) · Microsoft Dynamics 365 Business Central (YouTube) · 2025-04-01 · 3:48 · tier official · reviewed (checked by Opus)

## Overview

The video covers two costing areas in manufacturing. First, a production bill of material or routing can be defined on a stock keeping unit, which helps when a SKU represents a product variant or a location-specific way of producing an item. Standard cost for items produced for that variant or location is then taken from the SKU instead of the item card, using a new function that calculates production standard cost at SKU level.

Second, non-inventory costs can be included in the production cost calculation. The demo shows new columns for rolled up material non-inventory cost and single level material non-inventory cost on the cost shares page and in production order statistics. Both features need to be activated in manufacturing setup.

## Key points

- A production bill of material or routing can be defined on the stock keeping unit, for example when the SKU represents a different variant or a location with different production equipment.
- Standard cost per stock keeping unit is activated in manufacturing setup; standard cost for items produced for a specific variant or location is then copied from the SKU.
- A new function calculates production standard cost, so the SKU can have a different cost than the item card.
- In the demo, a released production order has two lines for the same item at different locations; the cost uses the item card or the SKU if available.
- After output posting, item ledger entries show two output transactions with actual costs; value entries split cost into variance, material and capacity. Material cost is identical because both share the same BOM, but for the SKU subcontracting costs replace internal capacity costs.
- Non-inventory costs can be included in the production cost calculation after enabling the capability in manufacturing setup.
- The cost shares page shows new columns for rolled up material non-inventory cost and single level material non-inventory cost; non-inventory cost is also visible on the production order statistics page.
