# What's New: Dataverse & Dynamics 365 App Integration (2023 release wave 2) Part 2

> Dataverse integration in Business Central 2023 release wave 2, part 2: virtual tables reaching general availability in November, Power Pages access to BC data through virtual tables (in preview), data change event capacity, and business events versioning, troubleshooting and telemetry.

[Watch on YouTube](https://www.youtube.com/watch?v=YTA8c2XyTX4) · Microsoft Dynamics 365 Business Central (YouTube) · 2023-11-20 · 33:07 · tier official · **unreviewed** (machine-generated)

## Overview

The session covers the mission for Dataverse and Dynamics 365 app integration and the four interaction types: data sync, virtual tables, data change events and business events. It then covers improvements to virtual tables, data change events and business events.

A long demo shows Power Pages using virtual tables for anonymous external access, authenticated external access with sales order creation, and internal licensed users. It covers the Microsoft Entra app users, permission sets, Power Pages table permissions, synthetic relations and a Power Automate flow that creates BC customers. The session ends with business events versioning, system tables for troubleshooting and Application Insights telemetry.

## Key points

- Virtual tables reach general availability in November. They let Dataverse reach Business Central through the native API without replicating data.
- Power Pages support for virtual tables is in preview. It has three scenarios: anonymous external, authenticated external, and authenticated internal users. Internal users still need BC licensing.
- Data change events capacity rises from 100 to 1000 events per 30 seconds delay. It is controlled by the server settings API subscription max number of notification and API subscription delay time.
- Entra app users have no permission sets by default. An admin must assign them. The demo used wide scopes, but production should use narrow read and write access.
- Synthetic relations link native contacts to virtual tables such as sales orders and invoices. They need a BC customer column on contact, a separate relation per virtual table, and a Power Automate flow that fills the data.
- Business events now support versioning (1.0 adds a web client URL over 0.0) and filtering. Business events are still in preview, with GA targeted for the release after this one.
- The system tables external event subscription and external event activity log help troubleshoot business events. UI pages are due in November 2023. Telemetry goes to Application Insights.
