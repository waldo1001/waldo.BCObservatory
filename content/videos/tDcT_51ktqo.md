# What's New: Server and Database - A Faster Runtime (2023 release wave 2)

> Server and database changes in Business Central 2023 release wave 2: ErrorInfo add action tooltip and permission checks, a SecretText type, security groups in effective permissions, queries as run objects with a data analysis UI, exclusive time telemetry, and faster session creation and tenant startup.

[Watch on YouTube](https://www.youtube.com/watch?v=tDcT_51ktqo) · Microsoft Dynamics 365 Business Central (YouTube) · 2023-11-28 · 9:34 · tier official · reviewed (checked by Opus)

## Overview

This 10-minute What's New session covers runtime-focused changes on the server and database side. It begins with error handling, secret text and permissions, then covers queries, telemetry, and performance.

Queries get a new UI for data analysis and can be used as run objects, for example opened from page actions or placed in the reporting section. Partner telemetry separates total time from exclusive time for AL calls. Session creation is 2 to 4 ms faster because the companies a user can access are cached, and tenant startup is faster through optimized event subscriber hooking.

## Key points

- The ErrorInfo AddAction method accepts a tooltip as its fourth parameter, so users can get more information about an action from the error dialogue.
- AddAction now checks if you try to call an on-premises function. In that case the action is not shown because the user does not have permission to interact with it. The presenters recommend that you stop using the old error method that takes plain parameters and move to ErrorInfo.
- A new SecretText type handles passwords and other sensitive data. Use it where data must never appear in memory dumps or be debuggable. The What's New in AL session covers it in more detail.
- The effective permissions page now includes permissions gained through security group membership.
- Queries have a new data analysis UI and can be used as run objects, opened from page actions or placed in the reporting section. More query capabilities are expected later.
- Exclusive time telemetry is total time minus suspended time from other threads or sessions. It is available as exclusive time and as exclusive time in milliseconds. The Telemetry app shows both total and exclusive time.
- Caching the companies a user can access makes session creation 2 to 4 ms faster. For small, fast web services this is a 20-25 percent throughput gain.
