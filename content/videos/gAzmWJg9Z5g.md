# What's New: Key Updates in Learning Content (docs) for Systems Architects and Integration Developers

> Walkthrough of the new Business Central integration documentation and its landing page (aka.ms/bc-integration). It covers Microsoft 365 apps, Power Platform, Dynamics products and Dataverse, Azure services, Microsoft Entra, infrastructure services and web services, with REST APIs as the recommended web service method.

[Watch on YouTube](https://www.youtube.com/watch?v=gAzmWJg9Z5g) · Microsoft Dynamics 365 Business Central (YouTube) · 2024-04-04 · 11:15 · tier official · reviewed (checked by Opus)

## Overview

The video shows new guidance in Business Central docs on integrations to and from Business Central. The material is meant to explain how integrations work, what is possible, and how to troubleshoot problems. A new landing page at aka.ms/bc-integration gives an overview and links to detailed articles for each integration class.

The walkthrough goes through Microsoft 365 and Office apps, Power Platform, Dynamics products and Dataverse, Azure services, Microsoft Entra and infrastructure services, and web services. It ends with advice to start learning in docs and to submit a pull request when you know something that is missing.

## Key points

- The integration landing page is at aka.ms/bc-integration and links to articles for each integration class.
- The docs aim to explain how integrations work and how to troubleshoot them, not why to choose them.
- Power Platform integration relies mainly on REST APIs through the Power Platform connector.
- Dynamics products and Dataverse docs cover connectors, data synchronization, virtualization, change events and new business events.
- Azure integrations include Application Insights telemetry, Blob and File services and Azure Functions, supported by the HTTP client data type in AL and system modules that wrap Azure APIs.
- Web services offer three methods: REST APIs (recommended), and OData and SOAP as legacy methods.
- Microsoft Entra, Universal Print and network restriction with security service tags are covered; Microsoft Purview for audit is described as upcoming.
