# Introducing: Multiple VAT Numbers for Customers (2024 release wave 2)

> Multiple VAT numbers for customers in Business Central (2024 release wave 2), in public preview and expected in version 25.0. Covers setup of alternative VAT registrations per country, use in sales documents, VAT entries, VAT return and settlement filters, and extensibility interfaces.

[Watch on YouTube](https://www.youtube.com/watch?v=fdzTWZyT6mI) · Microsoft Dynamics 365 Business Central (YouTube) · 2024-10-08 · 17:46 · tier official · reviewed

## Overview

The video explains why companies operating in several European Union countries need more than one VAT registration number per customer, described as a legal requirement. It shows how to define alternative VAT registrations per country, with optional VAT and general business posting groups, either from the customer card or in a dedicated table and page.

The demos show a notification when a ship-to address with a different country is created, sales orders picking up the VAT number for the ship-to country with a confirmation dialog, custom addresses, and the new country region filter in VAT return and VAT settlement. The video also covers three interfaces developers can use to customize the behavior. The feature currently applies to customers only, not vendors or the company.

## Key points

- Status: public preview, stated to be available in version 25.0.
- Each customer can have one alternative VAT number per country, with optional VAT and general business posting groups.
- Creating a ship-to address with a different country code triggers a notification to create an alternative VAT registration if none exists.
- Sales documents use the alternative VAT number based on the ship-to country; a confirmation dialog shows the change and the user can disable it.
- A new VAT country region code field in sales documents is posted to VAT entries so they can be filtered by country.
- VAT return suggest lines and the calculate and post VAT settlement batch job get a country region filter; the VAT return filter supports multiple countries and exclusion.
- Limited to customers for now; vendors and company are not yet covered. Three interfaces allow custom logic for ship-to country changes, consistency checks and sales document behavior.
