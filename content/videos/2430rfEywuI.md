# GP Assessment Tool - Optimize Your Migration to Dynamics 365 Business Central (2024)

> The GP Assessment Tool is a free, downloadable tool. It only reads data from the Dynamics GP SQL Server and gives guidance for planning a move to Business Central. The roughly 3-minute video covers signup, downloading the tool and using a token, connecting to GP SQL Server, choosing companies, running the assessment, reviewing and sending results, and reading the report. The report shows modules used, lets you drill into installed ISV solutions, lists migration risks with recommendations, and can be shared with your partner.

[Watch on YouTube](https://www.youtube.com/watch?v=2430rfEywuI) · Microsoft Dynamics 365 Business Central (YouTube) · 2024-08-26 · 2:44 · tier official · reviewed (checked by Opus)

## Overview

The video, published in August 2024, introduces a free assessment tool for current GP users who want to know what a move to Business Central in the cloud might look like. The tool was designed to be easy to use, fast, non-intrusive and available to everyone. It only reads data from the GP SQL Server and never writes or changes anything in GP.

It walks through signing up, downloading the tool, running the assessment, reviewing the captured information before sending it, and analyzing the resulting report. The report lists modules and features used in GP, lets you drill into installed ISV solutions, and flags potential migration risks with details and recommendations. The video closes with next steps and additional resources.

## Key points

- The tool is free and does not require a Business Central license to be purchased already.
- It only reads data from the GP SQL Server; nothing is written or changed in the GP system.
- It can be run during business hours while users work in GP, with no need to wait for nights or weekends.
- Running it requires a user with GP SQL Server access.
- Excluding test or sample companies from the assessment is recommended.
- You can review the captured information before sending it.
- The report shows modules and features used in GP, allows drill-down into installed ISV solutions, and lists migration risks with details and recommendations.
