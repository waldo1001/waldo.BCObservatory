## Overview

The video shows how to keep agents running after the evaluation capacity is used up. Agent consumption is charged to an Azure subscription through a billing plan set up in Power Platform admin center.

It walks through the setup in order: Azure resource group, billing plan, new Dataverse environment, and the link to Business Central. It then shows how to verify the setup, monitor message consumption, and track costs and set budgets in Azure. Consumption data can take up to 24 hours to appear on the monitoring pages.
