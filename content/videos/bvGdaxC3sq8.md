# Introducing: Contoso Demo Tool (2023 release wave 2)

> Contoso Demo Tool is a tool announced for 2023 release wave 2 (available from version 23.0) that orchestrates modular demo data for Business Central. The video covers the limits of rapid start packages, the Contoso Coffee modules, and how developers build their own demo data modules with dependencies and helper code units.

[Watch on YouTube](https://www.youtube.com/watch?v=bvGdaxC3sq8) · Microsoft Dynamics 365 Business Central (YouTube) · 2023-12-21 · 12:01 · tier official · **unreviewed** (machine-generated)

## Overview

The video explains why rapid start packages are a limited way to create demo data, and introduces the Contoso Demo Tool as an alternative. Demo data is split into scenario-based modules that can work together or separately. Contoso Coffee, a fictitious company that makes coffee and coffee machines, provides modules such as common, warehousing, manufacturing, and service.

The presenter then shows how to build your own demo data module. This covers implementing the module interface, declaring dependencies on other modules, creating data layer by layer, and using helper code units to populate tables. The video ends with future plans, including on-demand demo data creation and an enhanced company creation wizard, and notes that the code is open source.

## Key points

- The Contoso Demo Tool is announced for wave 2 and is available from version 23.0.
- Demo data modules are described as LEGO bricks that build on top of each other, and they can be used together or separately.
- Contoso Coffee modules named in the video are common, warehousing, manufacturing, and service.
- A custom module implements a standard interface with procedures for customization pages, dependency specification, and creating demo data layer by layer.
- Modules can declare dependencies on other modules, such as common, so you can reuse their data, for example posting groups, instead of duplicating code.
- Helper code units populate tables and specify fields, so a general posting setup line can be created in one line of code.
- Planned: on-demand demo data creation that will eventually replace the evaluation and extended packages, and a company creation wizard that lets you select multiple modules. Both need more modules to be developed first.
