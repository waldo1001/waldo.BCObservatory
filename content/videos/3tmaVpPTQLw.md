# What's New: Shopify Connector B2B Functionality (2024 release wave 1)

> Shopify Connector for Business Central in 2024 release wave 1: B2B company and catalog synchronization, B2B checkout, B2B vs D2C order handling, and order editing with refunds and credit memos. Also covers smaller connector changes such as automatic Shopify URL setup, inventory minus reservation, and shipment confirmation control.

[Watch on YouTube](https://www.youtube.com/watch?v=3tmaVpPTQLw) · Microsoft Dynamics 365 Business Central (YouTube) · 2024-04-04 · 30:34 · tier official · **unreviewed** (machine-generated)

## Overview

The video, published 2024-04-04 (31 minutes), starts with updates to the core connector. These include automatic Shopify admin URL configuration, an inventory calculation that subtracts reservations, dynamic guidance notifications on the product list, a setting to turn off shipment confirmation to Shopify, and refunds and returns imported by default. It then gives an overview of B2B on Shopify.

The main part is a demo of B2B with Business Central. It covers D2C customer and B2B company synchronization, catalog setup, the Get Catalogs action, price synchronization, and B2B checkout. It ends with order handling: cancelling orders, editing orders in Shopify, creating credit memos from refunds, and the Synchronize Order and Unlink Process Documents actions for orders that were already processed.

## Key points

- The connector now builds and updates the Shopify admin URL automatically, so it no longer has to be entered by hand.
- The export customers to Shopify Boolean was removed. You now pick specific D2C customers to export, in line with how item synchronization works.
- Company synchronization has settings for default permissions of the main contact (none, ordering only, or location admin). Automatic catalog creation for new companies can be turned off so catalogs are managed manually.
- The new Get Catalogs action retrieves catalogs from Shopify, but only for companies already synchronized with Business Central.
- B2B orders are assigned to the company and D2C orders to the individual person. B2B checkout shows the company, multiple addresses and a PO number field.
- Business Central creates credit memos only from refunds with an actual amount. Zero-value refunds from Shopify order edits are filtered out.
- For orders already processed, Synchronize Order from Shopify and Unlink Process Documents are the two actions. Error detection only notifies the user and cannot change existing documents automatically. Shopify has little warehouse handling information.
