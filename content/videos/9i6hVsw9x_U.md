# AppSource App Previews

> Installing preview versions of AppSource apps in Business Central: how publishers set a preview key in Partner Center and share an install URL, and how administrators install, update and monitor previews. Covers sandbox-only installation, the highest-version rule, breaking changes between previews, and telemetry.

[Watch on YouTube](https://www.youtube.com/watch?v=9i6hVsw9x_U) · Microsoft Dynamics 365 Business Central (YouTube) · 2024-02-02 · 4:12 · tier official · reviewed (checked by Opus)

## Overview

The video explains how AppSource publishers can make preview versions of their extensions available to selected customers before public release. Publishers specify a preview (hide) key in Partner Center, or get one generated automatically if they do not set one during submission. They then build an installation URL that contains the tenant ID, app ID and preview key.

It also covers the administrator side. Previews can only be installed on sandbox environments and can be updated to higher previews or to public versions. Operations on extensions are logged to telemetry, including whether an installed app is a preview or public version.

## Key points

- Publishers set a preview (hide) key in Partner Center; if none is given at marketplace submission, one is generated automatically and the publisher is opted in.
- The install URL contains the tenant ID, app ID and preview key, and customers use it to install a preview.
- Only a preview that is the highest version of the extension can be installed. If a public version is higher, the public version is installed even when the link has a preview key.
- Previews install only on sandbox environments, not production. Sandboxes with preview versions cannot be copied or restored to production.
- Publishers can run simultaneous previews for different offers with different preview keys, even when the offers contain the same apps.
- Breaking changes are allowed between preview versions, but must not be introduced to the latest public version.
- A preview submission must include all required dependencies, otherwise the Partner Center submission might fail.
