# Less Searching More Selling with Sales Order Agent (2025)

> Sales order agent in Business Central: processes customer emails, identifies direct and similar item matches, checks availability, and prepares a ready-to-send reply in the agent pane. Explains which item data it searches (descriptions, GTN, item category, attributes, variants, identifiers, references, extended text, translations) using natural language understanding.

## Overview

A 3-minute demo from the Microsoft Dynamics 365 Business Central channel (published 2025-09-01). It starts with the problem of working out which items a customer means in an email, then shows the sales order agent reading the email and presenting a suggested result in the agent pane.

The video lists the data the agent uses to match requested items: description fields, GTN number, item category, item attributes, variants, identifiers, item references, extended text and translations. It closes on how natural language understanding lets the agent recognize items when customers use their own codes or other names.

## Key points

- The sales order agent processes a customer email and presents a suggested result in the agent pane inside Business Central.
- It identifies both direct matches and other items with matching characteristics, checks their availability, and prepares a ready-to-send reply.
- Item search uses several parameters: description, additional description, GTN number, and item category code and description.
- Item attributes such as material, size, color, weight or dimensions are searched, which helps when customers give specific details.
- Item variants (for example stationary or mobile models, or size, color and style differences) are searched.
- Item identifiers (vendor numbers, barcodes, customer-specific codes) and item references (customer or vendor item numbers) are used for matching.
- Extended text and translations are included, so detailed descriptions and requests in different languages can be matched.
