# How to Set Up Locations in Business Central (2025)

> How to set up multiple inventory locations in Business Central: location cards (found under reference data in the warehouse manager role), intransit locations, an inventory posting group per location, location codes on purchase documents, and a default ship-from location on customer cards. It also covers transfer orders (including direct transfer), transfer routes, and checking item availability by location.

[Watch on YouTube](https://www.youtube.com/watch?v=X3xygXmgRqU) · Microsoft Dynamics 365 Business Central (YouTube) · 2025-05-22 · 2:35 · tier official · reviewed (checked by Opus)

## Overview

The video shows how to set up as many locations as needed for inventory and how to move items between them. It starts with the location card, where location information is entered, intransit locations are specified, and an inventory posting group is set up for each location.

It then covers buying and selling from specific locations by entering a location code on purchase and sales documents, and setting a default location on the customer card. The remaining sections cover transfer orders, direct transfer, transfer routes, and checking item availability and out-of-stock situations across locations.

## Key points

- In the warehouse manager role, go to reference data to find the location setup; you can set up as many locations as you need on the location card.
- Intransit locations can be specified on the location card, and each location needs an inventory posting group.
- Enter a location code on a purchase document to buy items for that location; the item card shows availability in each location.
- When selling, you can choose which location items ship from, and the customer card can hold a default ship-from location for each customer.
- Transfer orders document item movement between locations and can be shipped and received in one go, line by line, or partially.
- Select the direct transfer check box to move items all at once; otherwise use the intransit code to track items during the transfer.
- Transfer routes pre-select the intransit location and can specify a shipping agent.
