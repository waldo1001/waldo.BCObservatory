# How to Set Up Locations in Business Central (2025)

> Setting up multiple inventory locations in Business Central: location cards, inventory posting groups, location codes on purchase and sales documents, default customer locations, transfer orders (including direct transfer), intransit locations and transfer routes. A 3-minute video published 2025-05-22.

[Watch on YouTube](https://www.youtube.com/watch?v=X3xygXmgRqU) · Microsoft Dynamics 365 Business Central (YouTube) · 2025-05-22 · 2:35 · tier official · **unreviewed** (machine-generated)

## Overview

The video shows how to set up as many locations as needed for inventory and how to move items between them. It starts with the location card, where location information is entered, intransit locations are specified, and an inventory posting group is set up for each location.

It then covers buying and selling from specific locations by entering a location code on purchase and sales documents, and setting a default location on the customer card. The remaining sections cover transfer orders, direct transfer, transfer routes, and checking item availability and out-of-stock situations across locations.

## Key points

- Locations are set up on the location card, in the warehouse manager role; there is no limit stated on the number of locations.
- Each location needs an inventory posting group so inventory transactions can post.
- Specify a location code on purchase documents to buy for a specific location, and on sales documents to choose where items ship from.
- A default location on the customer card makes items ship from that location automatically for that customer.
- Transfer orders document item movement between locations and can be shipped and received in full, line by line, or in partial quantities.
- Select the direct transfer checkbox on a transfer order to move items all at once without an intransit location.
- Set up transfer routes to pre-select the intransit location (and optionally a shipping agent) so it need not be chosen on each transfer order.
