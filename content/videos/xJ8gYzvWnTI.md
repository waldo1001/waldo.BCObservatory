# What's New: Business Central User Experience and Productivity (2026 release wave 1)

> Business Central 2026 release wave 1 user experience changes, focused on working with agents: a dedicated agent task pane, created/updated by system columns, a review bar for agent changes, a cancel all agent tasks action, an updated icon and a new feedback button.

[Watch on YouTube](https://www.youtube.com/watch?v=xJ8gYzvWnTI) · Microsoft Dynamics 365 Business Central (YouTube) · 2026-04-01 · 6:40 · tier official · **unreviewed** (machine-generated)

## Overview

This 7-minute What's New video covers user experience changes in Business Central 2026 release wave 1. Most changes concern how users work with agents in the product, including the built-in sales order and payables agents and custom agents built by partners or users.

The video demos the agent task pane, the system columns, the review bar and the payables agent. It also covers the updated Business Central icon, a cancel all agent tasks action, and a feedback button that accepts comments, screenshots and documents. The presenter says more actions are being worked on for the task pane.

## Key points

- A new agent task pane is separate from the main experience. It is used to manage activities of the built-in sales order and payables agents and of custom agents.
- Lists get Created by and Updated by system columns. They help identify documents created or modified by agents.
- A review bar appears when a document needs human review or was changed by an agent. It shows what was changed and when.
- A cancel all agent tasks action in the task pane stops all tasks at once. It is useful when an agent is misconfigured or stuck with many tasks.
- The presenter says more task pane actions are being worked on for future updates.
- The Business Central icon is updated to match Microsoft design changes. It shows in the browser, mobile app and Teams app.
- A feedback button in some product areas lets users send detailed comments with screenshots and documents.
