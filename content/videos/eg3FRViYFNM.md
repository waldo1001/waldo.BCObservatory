# What's new: Productivity features in the web client (2023 release wave 2)

> Productivity features in the Business Central web client in 2023 release wave 2: lookup show details and Control Alt Down, company data search in Tell Me (Alt Q), readable shared links, tab naming, actionable errors, page inspection additions, rich content fields, and analysis tabs (generally available).

[Watch on YouTube](https://www.youtube.com/watch?v=eg3FRViYFNM) · Microsoft Dynamics 365 Business Central (YouTube) · 2023-12-22 · 30:56 · tier official · **unreviewed** (machine-generated)

## Overview

The session covers navigation and search changes in the web client. Lookup dialogues get a show details action and a Control Alt Down shortcut that opens the related card. Tell Me can search company data with Alt Q, with a smarter results page and an explore reports link.

It also covers shared link readability, browser tab naming with a company switcher that opens a page in another company in a new tab, and actionable error and inline validation dialogues. For developers, it covers native rich content fields in AL and page inspection additions. Analysis tabs are now generally available. Two changes are tied to Update 24, approximately April 2024.

## Key points

- Control Alt Down in a lookup opens the related card page; if no card exists it opens the list filtered to the selected record. Show details in simple lookups needs no partner uptake.
- Alt Q opens Tell Me for company data search; the focused value on an editable page is copied into the search. Results are tailored to permissions and user role.
- Legacy list views are to be removed from the web client in Update 24 (approximately April 2024), previously Update 23, so they need migrating.
- Automatic saving of field values when leaving a field will be enabled for everyone in Update 24 (approximately April 2024).
- Actionable errors include dimension posting fixes (dimension must be the same or blank) in the first iteration, plus an interface for AL developers to add fixes for custom errors.
- Rich content fields can be implemented natively in AL without control add-ins, with a toolbar of over 25 functions.
- Page inspection can scroll to a field, link to Visual Studio Code, and, with Update 23, add read-only source table fields to a page or make editable fields read-only.
