# Dynamics GP Cloud Migration - Moving to Business Central

> Dynamics GP to Business Central cloud migration enhancements: recent additions (excluding inactive checkbooks, migrating unreconciled bank transactions, fiscal periods, classes as posting groups, and GL year limits) plus the Wave 2 2022 GP configuration page. That page opens from Cloud Migration Management and lets you choose modules, master data only, and exclusion of inactive or discontinued items. It also covers global dimensions, per-company overrides, and unique GL summary document numbers.

[Watch on YouTube](https://www.youtube.com/watch?v=Ry9QvV6D7lg) · Microsoft Dynamics 365 Business Central (YouTube) · 2024-03-21 · 14:21 · tier official · reviewed (checked by Opus)

## Overview

The video shows how the GP migration tool changed compared with the older setup wizard, which offered only a few options. A new GP configuration page, reached through the Cloud Migration Management page with the Configure GP migration option, gives more control over what moves from GP into Business Central. It is described as part of wave 2 2022.

The demo covers module selection, limiting GL years, master data only per module, filtering inactive checkbooks, bank accounts and discontinued items, converting GP classes to posting groups, and setting up global dimensions. It also shows company-level tweaks, the migration run into staging tables, viewing migrated data, and fiscal period migration. The speaker says that picking whether to exclude inactive or discontinued items is coming very soon.

## Key points

- Open the tool by searching for Cloud Migration Management, then select Configure GP migration to reach the new GP configuration page.
- The configuration page replaces the all-or-nothing wizard: you can pick modules such as GL, AP, AR or Bank, and choose master data only per module.
- GL year limit: the default of zero brings everything over; setting a starting year limits the years migrated and beginning balances are created automatically.
- Global dimensions: the main account segment becomes the natural account, two segments become global dimensions, and further segments become shortcut dimensions. This can be configured per company.
- Optional conversion of GP classes for customers, items and vendors into posting groups with assignments; fiscal periods migrate to accounting periods; unreconciled bank transactions can be migrated.
- GL summary records get incremented document numbers, so specific transactions can be reconciled or reversed instead of all sharing one number.
- Company-level tweaks can override global settings; correlated options unmark automatically when a related option is deselected. The migration first moves GP data into staging tables.
