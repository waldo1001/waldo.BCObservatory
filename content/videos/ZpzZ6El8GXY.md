# What's new: Data Analysis (2026 release wave 2)

> Data analysis changes in the 2026 release wave 2: system fields (created by/on, modified by/on) become available in analysis mode, list views can be bookmarked to the role center, and profiles get system fields and bookmarks. Bookmarking analysis tabs is announced for version 29.x, not the major release.

[Watch on YouTube](https://www.youtube.com/watch?v=ZpzZ6El8GXY) · Microsoft Dynamics 365 Business Central (YouTube) · 2026-10-01 · 5:31 · tier official · reviewed (checked by Opus)

## Overview

The video covers what is new in data analysis for the 2026 release wave 2. In analysis mode, the system fields created by, created on, modified by and modified on can now be used in analysis tabs and views. They exist on all tables but were not visible in analysis mode before. The demos use the sales orders list (modified by and modified at, to see who last touched an order) and the customer list (created by, modified by).

The second part covers bookmarking. List views and saved filters can be bookmarked to the role center. Bookmarking an analysis tab or analysis view is announced for a future minor version (29.x). The video also shows system audit fields added to pages in the page designer for profiles, and bookmarked views added to a role center at profile level. The presenter points to aka.ms/bc-analytics, section ad hoc data analysis, for resources.

## Key points

- System fields (created by, created on, modified by, modified on) are now always available in the columns menu in analysis mode, even if the list page does not show them.
- Example: add modified by and modified at to the sales orders list in analysis mode to see which salesperson last touched an order.
- Example: on the customer list, add created by or modified by to get history on customers.
- List views and saved filters can be bookmarked so users navigate to them directly from the role center.
- Bookmarking an analysis tab or analysis view is announced for version 29.x, hopefully one of the first minor versions, and is not in the major release.
- In the page designer for profiles, system audit fields can be added to pages such as cards and lists.
- Bookmarked analysis views and list views can be added to a role center at profile level, so all users of that profile see them.
