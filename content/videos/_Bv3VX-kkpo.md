# What's New: User Experience Enhancements (2025 release wave 2)

> Business Central 2025 release wave 2 user experience changes: factbox resizing, Advanced Tellme semantic search (preview), extra instructions for the sales order agent, week numbers in date pickers, and a data masking property for sensitive fields (preview).

[Watch on YouTube](https://www.youtube.com/watch?v=_Bv3VX-kkpo) · Microsoft Dynamics 365 Business Central (YouTube) · 2025-10-01 · 5:13 · tier official · reviewed (checked by Opus)

## Overview

A five-minute What's New video covering user interface changes in Business Central 2025 release wave 2. It demonstrates how the page adjusts when the factbox opens and closes, and how side panes can be resized by hand.

It also shows Advanced Tellme, which uses semantic search to find pages and reports, and new options for giving the sales order agent extra instructions. Two smaller items follow: week numbers in date pickers, and a property that hides sensitive field values until the user reveals them. Advanced Tellme and data masking are both in preview and need to be enabled in feature management.

## Key points

- The UI now adjusts automatically when the factbox is opened or closed, as the default behavior. Users can also resize the factbox, copilot pane, help pane and page scripting pane manually.
- Advanced Tellme is in preview and must be enabled in feature management. It uses semantic search to match the meaning of the search term to pages and reports.
- Agents such as the sales order agent accept additional instructions, either by choosing a predefined option or by entering free text.
- Date pickers can show week numbers on the side. Shift+Home toggles the view, and the display follows regional settings.
- A new data masking property hides sensitive values, for example a company bank account number, until the user reveals them. AL developers apply it to fields that hold sensitive data.
- Data masking is in preview and must be enabled in feature management. It is expected to appear in more areas of Business Central in coming releases.
