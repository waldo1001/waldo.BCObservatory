# Historical Snapshot (2024)

> GP Historical Snapshot in Business Central: configuring and running a migration of GP transactional data into extension tables, then viewing it in list pages for GL, customers, vendors and items. Covers the GP Company Migration Configuration page, module and date range selection, and monitoring progress.

[Watch on YouTube](https://www.youtube.com/watch?v=mZNfMPpxovE) · Microsoft Dynamics 365 Business Central (YouTube) · 2024-10-18 · 5:55 · tier official · reviewed (checked by Opus)

## Overview

The video demonstrates the GP Snapshot, which brings transactional information from Dynamics GP into Business Central extension tables so that historical data can be viewed in list pages. Configuration is done through the cloud migration wizard or the cloud migration management page, where you pick the module transactions to migrate and how far back to go.

After the cloud migration completes, the snapshot runs automatically and its progress can be followed in tiles on the cloud migration management page. The demo then walks through the GP Detail Snapshot views for GL accounts, customers, vendors and items, including export to Excel, filtering and drill-through.

## Key points

- The snapshot stores GP transactional data in extension tables and shows it in list pages in Business Central.
- Configure it before migration starts, through the cloud migration wizard or the cloud migration management page (GP Company Migration Configuration page).
- You select which module transactions to migrate and the date range. The default year follows the GL summary setting, but you can use a different range, for example 3 years of GL summary and 7 years of transactions.
- The snapshot runs automatically once the cloud migration is complete. Progress is shown in tiles on the cloud migration management page.
- GL detail is under the chart of accounts as GP Detail Snapshot. It comes from the GP 20,000 and 30,000 tables (open and history), and can be exported to Excel, filtered, and searched by journal entry number, with drill-through to subledger transactions.
- Customer and vendor lists have a GP Detail Snapshot option (receivables and sales order processing for customers, payables and purchase receiving for vendors), filterable by a specific record.
- Item snapshot data for inventory transactions is available under items, but there are no tiles for the item list navigation.
