# Change Dataset Properties for a Power BI Telemetry App in Power BI

> Changing dataset properties for a Business Central Power BI Telemetry app in the Power BI service: finding the workspace, opening the dataset settings, editing data source credentials, and setting the refresh rate and error notifications. Demonstrated in a 2-minute video.

[Watch on YouTube](https://www.youtube.com/watch?v=sZ7wMU1Uxio) · Microsoft Dynamics 365 Business Central (YouTube) · 2023-12-05 · 1:49 · tier official · reviewed (checked by Opus)

## Overview

The video shows how to change anything related to data loading for a Power BI app built on Business Central telemetry. You start in the Power BI workspaces menu, search for the report, and find the underlying workspace that holds the report and dataset artifacts.

From the dataset you open its settings. Under data source credentials you can edit the credentials and change who refreshes the dataset. In the refresh section you set how often the report refreshes and configure notifications for refresh errors.

## Key points

- To change data loading for a Business Central Telemetry Power BI app, go to the Power BI workspaces menu and search for the report to find its underlying workspace.
- The workspace holds the report and the dataset, which is the data foundation for the reports.
- Open the dataset settings to change dataset properties.
- Under data source credentials, choose edit credentials to change who refreshes the dataset.
- Use the refresh menu to change how often the report refreshes.
- Notifications for refresh errors can be configured in the same refresh settings.
