# What's New: Opening Visual Studio Code from the Web Client (2025 release wave 1)

> Opening Visual Studio Code from the Business Central web client gets three additions in 2025 release wave 1: generating launch configurations, formatting and downloading extension dependencies, and symbol search in VS Code, including use with Copilot. All are demoed.

[Watch on YouTube](https://www.youtube.com/watch?v=LDzOda1IOnE) · Microsoft Dynamics 365 Business Central (YouTube) · 2025-04-01 · 11:26 · tier official · reviewed (checked by Opus)

## Overview

The session recaps the existing ability to open Visual Studio Code from the web client, and the attach option added to Help and Support in 2023 release wave 2 for debugging sandboxes. It then presents three new capabilities that came from feedback.

Demos cover generating launch configurations from Help and Support and Extension Management, selecting extensions and copying or downloading them as dependencies, and searching symbols with Control+T. The last demo shows how symbol search gives Copilot context, for example about the customer table.

## Key points

- Launch configurations matching the environment can be generated from Help and Support and from Extension Management. The VS Code project's configuration is created or updated without manual parameter editing.
- Publish and attach debugger are only available for sandbox environments. Download symbols and snapshot debug work for both sandbox and production.
- In Extension Management you can select extensions and format them as dependencies. Show and Copy lets you share them across projects.
- Selected dependencies can be downloaded to a VS Code project with one click, so symbols are available right away.
- Control+T (Go to Symbol) in VS Code lists tables, pages and other objects from apps and Microsoft dependencies. It works only where source code is available.
- A special keyword in Copilot chat searches symbols and adds them to context. Copilot can then answer questions about table structures and fields, such as the customer table.
