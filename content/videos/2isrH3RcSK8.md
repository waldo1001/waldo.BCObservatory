# Business Central Launch Event 2024 Release Wave 2 - Recording of Live Opening

> Opening session of the Business Central 2024 release wave 2 launch event. It gives an overview of the release: Copilot (default on, chat in 20 more languages, item substitutions, number series), subscription billing, Power BI and financial reports, sustainability, Shopify, Field Service, modern search (preview), and flexible update management (preview). It also covers admin features (partner environment access, audit logging), AL-Go and AL improvements, AI toolkit and testing, managed AI resources (private preview), performance and page scripting.

[Watch on YouTube](https://www.youtube.com/watch?v=2isrH3RcSK8) · Microsoft Dynamics 365 Business Central (YouTube) · 2024-10-09 · 39:15 · tier official · reviewed (checked by Opus)

## Overview

The recording of the live opening of the 2024 release wave 2 launch event walks through the release in 16 chapters. It starts with Copilot (default on, Copilot Chat for analysis views in 20 additional languages, Copilot for Finance, item substitution and number series generation) and moves to subscription billing, Power BI reports, sustainability, projects, service, Shopify and Field Service.

It then covers Power Automate, modern search in preview, column resizing and access keys, Word reporting, and 156 community contributions. The later chapters cover administrators (flexible update management, partner access per environment, audit logging to Microsoft 365), developers (AL-Go for GitHub, AL improvements, code navigation, AI toolkit, AI testing, managed AI resources) and performance work (profiler scheduling, job queue order, warehouse ledger posting, page scripting in pipelines).

## Key points

- Copilot is default on without setup; an admin page controls which Copilot capabilities are enabled in the company.
- Copilot Chat builds analysis views from questions and is available in 20 additional languages.
- Modern search is in preview and is expected to leave preview the following month. It uses full-text search in partner-marked columns, and legacy search stays available for comprehensive searching.
- Flexible update management, coming in preview, extends the update postponement window from 60 days to 5 months.
- Partners (delegated admins) can be assigned to specific environments, and administrative actions are logged to the Microsoft 365 unified audit log.
- AL-Go for GitHub adds security hardening, ISV app compatibility testing and performance baseline testing.
- An AI testing toolkit is in preview and works with Azure AI Studio. Managed AI resources for ISVs are in private preview, with expansion to public preview planned.
