# What’s New: Enhanced Document Reporting Features (For Developers) (2024 release wave 2)

> Word layout enhancements for document reports in Business Central 2024 release wave 2, aimed at developers: a new Word add-in with layout controls (developer comments, hide empty table, row, column, hide field if zero), Word sections with merge data item, themeable layouts, and font and alignment fixes.

[Watch on YouTube](https://www.youtube.com/watch?v=V8CSor5qBRE) · Microsoft Dynamics 365 Business Central (YouTube) · 2024-10-08 · 25:04 · tier official · **unreviewed** (machine-generated)

## Overview

The video covers what is new for developers who build Word layouts for document reports in the 2024 release wave 2. It starts with installing the Word add-in from the Office App Store, then demonstrates the new layout controls: developer comments, hide empty table, hide empty table row, hide empty table column and hide field if zero.

It then shows Word sections working in layouts that use the merge data item property, and themeable reports where Office themes change fonts and colors. It closes with smaller changes: a fix for alignment in repeaters, Planet, PostNet and IMB barcode fonts in the service, and the Aptos font, which the presenter says will be available by October. The presenter notes the add-in is labeled preview in his version but will appear as the normal published version when the recording is watched.

## Key points

- The Word add-in is installed from the Office App Store and adds layout controls for document reports.
- Developer comments are added with the insert layout comment action and are hidden from end users in the generated document.
- Hide if empty table removes the whole table when the repeater has no data; mark the full table and apply the control.
- Hide table row if empty depends on a chosen field in the repeater; hide empty table column is applied to the header cell, for example for discount columns.
- Hide field if zero works on any field in the layout, not only repeater fields, and can be combined with hide column to remove all-zero columns.
- Word sections can now be used in layouts that use the merge data item property, to control margins, orientation, columns, watermarks, headers and footers. The documentation warning about this limit is described as no longer valid.
- Themeable reports let users apply Office themes in Word and upload the layout again, only for layouts marked as themeable.
