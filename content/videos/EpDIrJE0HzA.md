# Build an Agent in Microsoft Copilot Studio for Business Central (2025)

> Building an agent in Microsoft Copilot Studio that reads Business Central data through an MCP server, using the MCP Configurations page in Business Central. It covers publishing the agent to Teams and Microsoft 365 Copilot, and the credit-based Copilot Studio licensing.

[Watch on YouTube](https://www.youtube.com/watch?v=EpDIrJE0HzA) · Microsoft Dynamics 365 Business Central (YouTube) · 2025-12-03 · 6:05 · tier official · reviewed (checked by Opus)

## Overview

The video, published 2025-12-03 and about 6 minutes long, explains that Copilot Studio is part of Power Platform and is used to build conversational experiences and agents connected to data. It describes the Model Context Protocol (MCP) as an open protocol for AI systems to talk to business applications, and as an alternative to Power Platform connectors for reaching Business Central APIs.

The demo sets up data, configures MCP in Business Central, publishes the agent, and tests it in Microsoft 365 Copilot. It ends with licensing: Copilot Studio is bought separately from Business Central, through credit packs or pay-as-you-go.

## Key points

- Copilot Studio is part of Power Platform and builds agents connected to data, including Business Central data via Power Platform connectors and APIs.
- An MCP server is an alternative to Power Platform connectors for giving an agent access to Business Central APIs.
- Business Central has an MCP Configurations page where you define a configuration that exposes an API (for example items) in read-only mode.
- The demo publishes the agent to channels including Teams and Microsoft 365 Copilot, and tests it in Microsoft 365 Copilot.
- Copilot Studio needs credit packs or a pay-as-you-go subscription, purchased separately and not included in Business Central licensing.
- Users the agent is shared with consume the credits and do not need additional paid user licenses.
