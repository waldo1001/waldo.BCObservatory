# AL Language extension 18.1

> AL Language extension 18.1 for Business Central 2026 release wave 2 (BC29): released 2026-10-10; 2 changelog entries.

[Changelog on the Visual Studio Marketplace](https://marketplace.visualstudio.com/items/ms-dynamics-smb.al/changelog) · Business Central 2026 release wave 2 · BC29

## Snapshot debugging AL tests

- Added `run_tests` to the Snapshot Debugging MCP proxy so agents can execute selected AL tests in an isolated session attached to the armed snapshot, then collect the test capture through `stop_snapshot_debugging`.
- Added optional `snapshotVerbosity` to Snapshot Debugging MCP initialization. `SnapPoint` remains the default; `Full` captures every method context and encountered non-IP-protected AL source object for any attached session and should be used only for short, targeted reproductions.

## Bug fixes

- Fixed Word layouts created with the Word add-in missing data bindings when the compiler compiles the layout against the current report design.
