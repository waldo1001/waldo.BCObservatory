# AL Language extension 16.4

> AL Language extension 16.4 for Business Central 2025 release wave 2 (BC27): released 2026-10-19; 3 changelog entries.

[Changelog on the Visual Studio Marketplace](https://marketplace.visualstudio.com/items/ms-dynamics-smb.al/changelog) · Business Central 2025 release wave 2 · BC27

## What changed on this page

- 2026-10-20: changed "Bug fixes"

## Bug fixes

- Fixed an issue where the generated AL table proxies for CDS/Dataverse integration referenced base tables by their bare short name. When two referenced apps defined a table with the same name (for example `FS Customer Asset` in both the Base Application and Field Service Integration), the reference was ambiguous and the compile failed with AL0275. Generated `extends`, `TableRelation`, and `CalcFormula` references are now fully namespace-qualified.
- Fixed an issue where the cancellation dialog was not shown when publishing an extension.
- Fixed an issue where publishing could be triggered twice when the first publish attempt failed.

## AppSourceCop

- [AS0116](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/analyzers/appsourcecop-as0116), [AS0122](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/analyzers/appsourcecop-as0122): The analyzer rules for moving fields and tables are now relaxed, so that if the source app is missing or the source field/table does not exist, it is now a warning.
- [AS0041](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/analyzers/appsourcecop-as0041), [AS0036](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/analyzers/appsourcecop-as0036), [AS0039](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/analyzers/appsourcecop-as0039), [AS0034](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/analyzers/appsourcecop-as0034): Removal or change of the `MovedFrom`/`MovedTo` properties are now correctly reported as a breaking change.
- [AS0119](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/analyzers/appsourcecop-as0119): When the value of the app in the `MovedFrom` property of a field/table does not match the one on the source, the correct diagnostic is now reported, instead of reporting that there is no source field/table that is being moved.

## Support for new `ExtendedDataType` value: `Task`

The [ExtendedDataType property](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/properties/devenv-extendeddatatype-property) for `BigInteger` field now also supports the `Task` value.
Setting this value on the field allows the client to correctly render elements in a list formatted as tasks.
