# AL Language extension 16.3

> AL Language extension 16.3 for Business Central 2025 release wave 2 (BC27): released 2026-01-22; 2 changelog entries, 2 GitHub issues linked.

[Changelog on the Visual Studio Marketplace](https://marketplace.visualstudio.com/items/ms-dynamics-smb.al/changelog) · Business Central 2025 release wave 2 · BC27

## Miscellaneous

- Added a workaround to an issue caused by VSCode 1.106.3 which caused launch.json files to not be created in new projects.
- Fixed crashes in `aldoc` for projects without namespaces or with external business events (methods marked with the ´ExternalBusinessEvent` attribute).
- Fixed an issue where the `CaptionClass` property of a field would not be correctly resolved when a locked `Caption` was also specified on the field.
