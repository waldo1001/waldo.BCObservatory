## Actions

| Group | Action | ToolTip | Runs |
|---|---|---|---|
| Processing | Check for duplicates | Recalculate how many emails are affected and how many redundant copies would be deleted. |  |
|  | View affected emails | Open the list of affected emails with the number of stored copies of each. |  |
|  | Activate scheduled cleanup | Queue the background cleanup using the configuration above. It keeps the oldest copy of each email and deletes the rest. This cannot be undone. |  |
|  | Clean up now | Queue a one-off cleanup to start immediately, independent of the recurring schedule. It keeps the oldest copy of each email and deletes the rest. This cannot be undone. |  |
|  | Cancel scheduled cleanup | Remove the scheduled background cleanup job. Rows already deleted stay deleted. |  |
|  | Open background job | Open the Job Queue Entry of the background cleanup for diagnostics. |  |
