- `ShowVATRates()`: Displays VAT rates configuration view for VAT product posting groups selection and rate assignment. Shows VAT product posting groups with editable VAT percentage fields for rate configuration.

- `ShowVATClauses()`: Displays VAT clauses configuration view for VAT clause assignment to VAT product posting groups. Shows selected VAT product posting groups with VAT clause assignment fields for document text handling.
