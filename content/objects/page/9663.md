## Actions

| Group | Action | ToolTip | Runs |
|---|---|---|---|
| Processing | Add global default | Add the row that applies to every report and every layout, the fallback used when nothing more specific is set. Goes to that row when it already exists. |  |
|  | Set for one report | Pick a report and add the row that covers all of its layouts, creating it if it does not exist yet. |  |
|  | Apply to all layouts | Widen this row so it applies to every layout of the report instead of the one named. Available when the row names a layout. |  |
|  | Set for one layout | Pick a single report layout and add the row that covers only that layout, creating it if it does not exist yet. |  |
