## Procedures

- `RunModalWithGenerationRule(var QltyInspectionGenRule: Record "Qlty. Inspection Gen. Rule"): Action` (internal): Runs the setup guide using the supplied generation rule as its initial state. Start the setup guide using this generation rule as a pre-requisite. Use this to edit an existing rule. You can also use it to start a new rule with a default template by supplying a template filter.
