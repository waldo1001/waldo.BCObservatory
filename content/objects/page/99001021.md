- `SetItem(Item: Record Item)` (internal): Sets the item record that the wizard operates on.
- `SetBOMRoutingDisplay(DisplayType: Enum "Prod. Definition Display")` (internal): Sets the display mode for the BOM and routing section of the wizard.
- `SetProdCompDisplay(DisplayType: Enum "Prod. Definition Display")` (internal): Sets the display mode for the production order components section of the wizard.
- `SetTempData(var NewTempData: Codeunit "Prod. Definition Temp Data")` (internal): Injects the temporary data codeunit that the wizard uses for BOM, routing, and production order data.
- `SetWizardMode(Mode: Enum "Prod. Definition Mode")` (internal): Sets the operating mode of the wizard (e.g., define item structure or create production order).
- `GetBOMRtngSaveTarget(): Enum "Prod. Definition Save Target"` (internal): Returns the user's choice for where to apply the BOM and routing changes.
- `GetFinished(): Boolean` (internal): Returns whether the wizard has been completed by the user.
