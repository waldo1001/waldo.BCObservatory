## Procedures

- `GetDimensionIDs(var DimSetID: Integer; var NewDimSetId: Integer)`: Retrieves both original and new dimension set IDs from the reclassification buffer. Returns dimension set IDs representing the before and after states of dimension reclassification.
- `SetDimensionIDs(DimSetID: Integer; NewDimSetId: Integer)`: Sets up dimension reclassification buffer with original and new dimension set entries. Populates the buffer with dimension mappings based on provided dimension set IDs.
- `SetFormCaption(NewFormCaption: Text[250])`: Sets a custom caption for the dimension reclassification form. Allows contextual form titles to indicate the source or purpose of dimension reclassification.
