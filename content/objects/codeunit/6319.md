- `GetWritableWorkspaces(var TempPowerBISelectionElement: Record "Power BI Selection Element" temporary)`: Populates the buffer with the workspaces that deployable reports can be deployed to: the "My Workspace" option (represented by a null ID) plus every shared workspace the user can write to
- `LookupTargetWorkspace(var WorkspaceId: Guid; var WorkspaceName: Text[200]): Boolean`: Opens a lookup for the writable Power BI workspaces and returns the selected one. An empty (null) WorkspaceId means "My Workspace".
- `WorkspaceExists(WorkspaceId: Guid): Boolean`: Returns true if the given workspace still exists and the user can write to it. An empty (null) WorkspaceId ("My Workspace") is always considered valid.
