## Procedures

- `ConvertPostedHeaderToSalesHeader(var PostedRecRef: RecordRef; var SalesHeader: Record "Sales Header")`: Converts a posted document header RecordRef to a Sales Header buffer. Supports Sales Invoice Header, Sales Cr.Memo Header, Service Invoice Header, and Service Cr.Memo Header.
- `ConvertPostedLineToSalesLine(var PostedLineRecRef: RecordRef; var SalesLine: Record "Sales Line")`: Converts a posted document line RecordRef to a Sales Line buffer. Supports Sales Invoice Line, Sales Cr.Memo Line, Service Invoice Line, and Service Cr.Memo Line.
- `GetTotals(var PostedDocHeaderRecRef: RecordRef; var PostedDocLineRecRef: RecordRef; var TempVATAmtLine: Record "VAT Amount Line" temporary; var TempVATProductPostingGroup: Record "VAT Product Posting Group" temporary; PEPPOLFormat: Enum "PEPPOL 3.0 Format")`: Calculates and retrieves VAT totals for a posted document. Supports Sales Invoice, Sales Credit Memo, Service Invoice, and Service Credit Memo.
- `GetTotals(var PurchaseHeaderRecRef: RecordRef; var PurchaseLineRecRef: RecordRef; var TempVATAmtLine: Record "VAT Amount Line" temporary; var TempVATProductPostingGroup: Record "VAT Product Posting Group" temporary; PEPPOLPurchaseFormat: Enum "PEPPOL 3.0 Purchase")`: Calculates and retrieves VAT totals for a purchase order.
- `SetDocumentAttachmentFilters(var PostedDocHeaderRecRef: RecordRef; var DocumentAttachments: Record "Document Attachment")`: Sets document attachment filters based on the posted document header.
- `GetInvoiceRoundingLine(PostedDocHeaderRecRef: RecordRef; var TempSalesLineRounding: Record "Sales Line" temporary; PEPPOLFormat: Enum "PEPPOL 3.0 Format")`: Gets the invoice rounding line from the posted document lines.
- `GetInvoiceRoundingLine(PurchaseHeaderRecRef: RecordRef; var TempPurchaseLineRounding: Record "Purchase Line" temporary; PEPPOLPurchaseFormat: Enum "PEPPOL 3.0 Purchase")`: Gets the invoice rounding line from purchase order lines using a RecordRef header.
- `SetFilters(var PostedDocHeaderRecRef: RecordRef; var PostedDocLineRecRef: RecordRef; TempSalesLineRounding: Record "Sales Line" temporary)`: Sets filters on posted document lines, excluding the rounding line if present.
- `SetFilters(var PurchaseHeaderRecRef: RecordRef; var PurchaseLineRecRef: RecordRef; TempPurchaseLineRounding: Record "Purchase Line" temporary)`: Sets filters on purchase order lines using RecordRefs, excluding the rounding line if present.
