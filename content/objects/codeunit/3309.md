## Procedures

- `DemoExperienceAvailable(): Boolean`: Returns true if the demo experience is available for the current company.
- `OpenGuidePage(PASetupConfiguration: Codeunit "PA Setup Configuration")`: Opens the demo guide page.
- `CreateDemoFilesForEmail()` (obsolete 28.0: Demo files are created during the evaluation company creation): Creates demo files to use for the demo email when the agent is enabled.
- `SendDemoInvoicesByEmail(PASetupConfiguration: Codeunit "PA Setup Configuration"): Boolean`: Sends the sample invoices by email if the agent is active, otherwise flags them to be sent at activation.
- `SendDemoEmail(PASetupConfiguration: Codeunit "PA Setup Configuration"): Boolean`: Sends a demo email using the provided PA setup configuration.
- `IsEmailConfiguredForDemoEmail(PASetupConfiguration: Codeunit "PA Setup Configuration"): Boolean`: Returns True if an email account is configured so that demo invoices can be sent by email.
- `GetDemoFilesToDownloadCount(): Integer`: Gets the count of the demo files to download.
- `ShowDemoFilesToDownload()`: Shows the page with the demo files available for download.
- `DownloadDemoFile(PADemoFile: Record "PA Demo File")` (obsolete 28.0: Sample files are now downloaded from E-Doc Sample Purch. Inv. Files page): Downloads the selected demo file.
