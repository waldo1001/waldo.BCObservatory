## Procedures

- `Release(var SpendRequest: Record "Spend Request")`: Sets the status of the spend request to Released.
- `Reopen(var SpendRequest: Record "Spend Request")`: Sets the status of the spend request back to Open so it can be edited again.
- `Close(var SpendRequest: Record "Spend Request")`: Sets the status of the spend request to Closed so it cannot be used anymore.
- `PerformManualRelease(var SpendRequest: Record "Spend Request")`: Performs a manual release of the spend request triggered from the UI.
- `PerformManualReopen(var SpendRequest: Record "Spend Request")`: Performs a manual reopen of the spend request triggered from the UI.
- `PerformManualClose(var SpendRequest: Record "Spend Request")`: Performs a manual close of the spend request triggered from the UI.
