## Procedures

- `RefreshSubTotalMismatch(EDocumentPurchaseHeader: Record "E-Document Purchase Header"): Boolean`: Re-evaluates the Sub Total mismatch from the persisted lines and updates the persisted notification. A previously dismissed notification stays dismissed.
- `RefreshSubTotalMismatchAfterHeaderEdit(EDocumentPurchaseHeader: Record "E-Document Purchase Header"): Boolean`: Re-evaluates the Sub Total mismatch after the user changed an amount on the header, re-arming a previously dismissed notification.
- `RefreshSubTotalMismatchAfterLineEdit(EDocumentPurchaseLine: Record "E-Document Purchase Line"): Boolean`: Re-evaluates the Sub Total mismatch after the user changed an amount on a draft line, re-arming a previously dismissed notification. The supplied line is used instead of its persisted version, because page field validation runs before the record is written.
- `RefreshSubTotalMismatchAfterLineDeletion(EDocumentPurchaseLine: Record "E-Document Purchase Line"): Boolean`: Re-evaluates the Sub Total mismatch while a draft line is being deleted, re-arming a previously dismissed notification. The line is still persisted when this runs, so it is excluded explicitly.
- `AddVendorMatchedByNameNotAddress(EDocumentEntryNo: Integer)`: Persists the Vendor Matched By Name Not Address notification for the current user. Gating on My Notifications is the caller's responsibility.
- `AddSubTotalMismatch(EDocumentEntryNo: Integer)`: Persists the Sub Total Mismatch notification for the current user. Gating on My Notifications is the caller's responsibility.
- `RemoveSubTotalMismatch(EDocumentEntryNo: Integer)`: Removes the persisted Sub Total Mismatch notification for the current user, e.g. when the totals re-converge.
- `ReArmSubTotalMismatch(EDocumentEntryNo: Integer)`: Removes a previously dismissed Sub Total Mismatch row so the mismatch can be shown again after an amount edit.
- `MarkDismissed(EDocumentEntryNo: Integer; NotificationId: Guid)`: Marks a persisted notification as dismissed, keeping the row so it is not re-shown to this user.
- `DeleteAllOfType(NotificationType: Enum "E-Document Notification Type")`: Deletes every persisted notification of a type for the current user.
- `GetNotification(EDocumentEntryNo: Integer; NotificationId: Guid; var EDocumentNotification: Record "E-Document Notification"): Boolean`: Reads one persisted notification for the current user.
- `FindPendingDraftNotifications(EDocumentEntryNo: Integer; var EDocumentNotification: Record "E-Document Notification"): Boolean`: Finds the Purchase Document Draft notifications that are pending display for the current user.
- `SubTotalMismatchExists(EDocumentEntryNo: Integer): Boolean`: Returns whether a Sub Total Mismatch row exists for the current user and e-document.
- `IsSubTotalMismatchDismissed(EDocumentEntryNo: Integer): Boolean`: Returns whether the current user has dismissed the Sub Total Mismatch notification for the e-document.
- `VendorMatchedByNameNotAddressNotificationId(): Guid`
- `SubTotalMismatchNotificationId(): Guid`
