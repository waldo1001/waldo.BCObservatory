## Procedures

- `GetGPT35TokenCount(Input: SecretText): Integer`: Gets the token count for the input according to GPT3.5 models.
- `GetGPT4TokenCount(Input: SecretText): Integer`: Gets the token count for the input according to GPT4 models.
- `GetAdaTokenCount(Input: SecretText): Integer`: Gets the token count for the input according to embedding Ada models.

- `GetTotalServerSessionTokensConsumed(): Integer`: Gets the total tokens used till now for the server session. The total tokens used is aggregated for all the models. Note: this method is expected to change in future.
