- `RecordExcelExport(FinancialReportName: Code[10]; ColumnLayoutName: Code[10]; FollowsColumns: Boolean; DateFilterText: Text)` (internal): The overview's Open in Excel is about to run report 29. - `ClearExcelExport()` (internal): Open in Excel has returned. Forgets the subject whether or not it was used, so it cannot name a later workbook.
- `TryNameExcelDownload(var FileName: Text): Boolean` (internal): Takes, not peeks, the subject: one export downloads one workbook. Called from Report Filename Excel Sub. until Base Application raises a file name event (ask 4).
