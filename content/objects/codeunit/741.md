## Events published

- `OnBeforeValidate(var VATReportHeader: Record "VAT Report Header"; var IsValidated: Boolean)` (integration): Integration event raised before VAT report validation during release process. Allows custom validation logic to be added before standard validation.

## Procedures

- `Release(var VATReportHeader: Record "VAT Report Header")`: Releases VAT report from open to released status with validation. Runs configured validation codeunit before changing status.
- `Reopen(var VATReportHeader: Record "VAT Report Header")`: Reopens released VAT report back to open status for modifications. Validates report can be reopened before changing status.
- `Submit(var VATReportHeader: Record "VAT Report Header")`: Submits released VAT report to submitted status for tax authority processing. Validates report can be submitted before changing status.
