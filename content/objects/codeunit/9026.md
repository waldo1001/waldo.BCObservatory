- `UserLoggedInSinceDateTime(FromDateTime: DateTime): Boolean`: Returns true if the current user logged in to the current company at or after the specified DateTime.
- `UserLoggedInEnvironment(UserSecurityID: Guid): Boolean`: Checks whether a user has logged in to the current environment (to any of the companies) in the past.

- `CreateOrUpdateLoginInfo()`: Updates or creates the last login information of the current user (first, last and penultimate login date) for the current company.
