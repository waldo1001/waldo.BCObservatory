- `GetPeriod(TenantLicenseState: Enum "Tenant License State"): Integer`: Returns the default number of days that the tenant license can be in the current state, passed as a parameter.
- `GetStartDate(): DateTime`: Gets the start date for the current license state.
- `GetEndDate(): DateTime`: Gets the end date for the current license state.
- `IsEvaluationMode(): Boolean`: Checks whether the current license state is evaluation.
- `IsTrialMode(): Boolean`: Checks whether the current license state is trial.
- `IsTrialSuspendedMode(): Boolean`: Checks whether the trial license is suspended.
- `IsTrialExtendedMode(): Boolean`: Checks whether the trial license has been extended.
- `IsTrialExtendedSuspendedMode(): Boolean`: Checks whether the trial license has been extended and is currently suspended.
- `IsPaidMode(): Boolean`: Checks whether the current license state is paid.
- `IsPaidWarningMode(): Boolean`: Checks whether the paid license is in warning mode.
- `IsPaidSuspendedMode(): Boolean`: Checks whether the paid license is suspended.
- `GetLicenseState(): Enum "Tenant License State"`: Gets the the current license state.
- `ExtendTrialLicense()`: Extends the trial license.
