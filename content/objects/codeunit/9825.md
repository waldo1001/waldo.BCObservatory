## Procedures

- `IsCustomized(PlanId: Guid): Boolean`: Checks if a plan configuration was customized.
- `AddCustomPermissionSetToPlan(PlanId: Guid; RoleId: Code[20]; AppId: Guid; Scope: Option; Company: Text[30])`: Adds a permission set to a plan.
- `RemoveCustomPermissionSetFromPlan(PlanId: Guid; RoleId: Code[20]; AppId: Guid; Scope: Option; Company: Text)`: Removes a permissions set from a plan.
- `AssignCustomPermissionsToUser(PlanId: Guid; UserSecurityId: Guid)`: Assigns all custom permission sets for a plan to a user.
- `RemoveCustomPermissionsFromUser(PlanId: Guid; UserSecurityId: Guid)`: Removes custom permission sets for a plan from a user. If the permission set is also associated with another plan, it is not deleted.
- `GetCustomPermissions(var PermissionSetInPlanBuffer: Record "Permission Set In Plan Buffer")`: Gets the list of all custom permission sets for a plan.
- `AddDefaultPermissionSetToPlan(PlanId: Guid; RoleId: Code[20]; AppId: Guid; Scope: Option)`: Adds a permission set to a plan.
- `RemoveDefaultPermissionSetFromPlan(PlanId: Guid; RoleId: Code[20]; AppId: Guid; Scope: Option)`: Removes a permissions set from a plan.
- `AssignDefaultPermissionsToUser(PlanId: Guid; UserSecurityId: Guid; Company: Text[30])`: Assigns all default permission sets for a plan to a user.
- `RemoveDefaultPermissionsFromUser(PlanId: Guid; UserSecurityId: Guid)`: Removes default permission sets for a plan from a user. If the permission set is also associated with another plan, it is not deleted.
- `GetDefaultPermissions(var PermissionSetInPlanBuffer: Record "Permission Set In Plan Buffer")`: Gets the list of all default permission sets for a plan.
- `VerifyUserHasRequiredPermissionSet(RoleId: Code[20]; AppId: Guid; Scope: Option; Company: Text)`: Checks whether the current user has enough permissions to assign or de-assign a permission set from plan.
