## Procedures

- `GetSetupRecord(var AgentSetupBuffer: Record "Agent Setup Buffer"; UserSecurityID: Guid; AgentMetadataProvider: Enum "Agent Metadata Provider"; DefaultUserName: Code[50]; DefaultDisplayName: Text[80]; AgentSummary: Text)`: Gets the setup record for existing agents or initializes a new setup record for new agents.
- `CopySetupRecord(var Target: Record "Agent Setup Buffer"; var Source: Record "Agent Setup Buffer")`: Copies the setup record from the source buffer to the target buffer.
- `SaveChanges(var AgentSetupBuffer: Record "Agent Setup Buffer"): Guid`: Saves changes done. If the agent does not exist we will create a new agent otherwise we will update the agent.
- `GetChangesMade(var AgentSetupBuffer: Record "Agent Setup Buffer"): Boolean`: Checks if there are any changes made in the setup buffer that need to be saved.
- `OpenLanguageAndRegionPage(var AgentSetupBuffer: Record "Agent Setup Buffer"): Boolean`: Opens a page where the language and region settings for the agent can be updated.
- `GetAgentSummary(var AgentSetupBuffer: Record "Agent Setup Buffer"): Text`: Retrieves the summary information about the agent.
- `OpenAgentAccessControlPage(var AgentSetupBuffer: Record "Agent Setup Buffer"): Boolean`: Opens a page where the user access control settings for the agent can be updated.
- `OpenProfileLookup(var UserSettingsRec: Record "User Settings"): Boolean`: Allows the user to select a profile out of the list of available profiles. The user settings record will be updated with the selected profile.
- `OpenAgentLookup(var AgentUserSecurityId: Guid): Boolean`: Allows the user to select an agent out of the list of enabled agents.
- `FindAgentByUserName(AgentUserName: Text; var AgentUserSecurityId: Guid): Boolean`: Finds the agent user security ID based on the provided user name.
- `OpenAgentLookup(AgentType: Enum "Agent Metadata Provider"; var AgentUserSecurityId: Guid): Boolean`: Allows the user to select an agent out of the list of enabled agents.
- `OpenSetupPage(var AgentSetupBuffer: Record "Agent Setup Buffer")`: Opens the setup page for the agent.
- `OpenSetupPage(AgentUserSecurityId: Guid)`: Opens the setup page for the agent.
- `UpdateUserAccessControl(var AgentSetupBuffer: Record "Agent Setup Buffer"): Boolean`: Opens the page where the user access control settings for the agent can be updated.
