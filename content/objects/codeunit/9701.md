- `OnConvertStyleToStyleText(CueStyle: Enum "Cues And KPIs Style"; var Result: Text; var Resolved: Boolean)` (integration): Event that is called to convert from the style enum to a text value in case of extended enum values. Subscribe to this event if you want to introduce new cue styles.

## Procedures

- `OpenCustomizePageForCurrentUser(TableId: Integer)`: Opens the cue setup user page with an implicit filter on table id. The page shows previously added entries in the Cue Setup Administration page that have the UserId being either the current user or blank. The page also displays all other fields the that the passed table might have of type decimal or...
- `ChangeUserForSetupEntry(var RecordRef: RecordRef; Company: Text[30]; UserName: Text[50])`: Changes the user of a cue setup entry. A Recref pointing to the newly modified record is returned by var.
- `SetCueStyle(TableID: Integer; FieldID: Integer; Amount: Decimal; var FinalStyle: Enum "Cues And KPIs Style")`: Retrieves a Cues And KPIs Style enum based on the cue setup of the provided TableId, FieldID and Amount. The computed cue style is returned by var.
- `PersonalizedCueSetupExistsForCurrentUser(TableID: Integer; FieldID: Integer): Boolean`: Checks if a personalized Cue Setup record exists for the current user. The ID of the table containing the field for which the style is wanted. The ID of the field for which the style is wanted.
- `ConvertStyleToStyleText(CueStyle: Enum "Cues And KPIs Style"): Text`: Converts a Cues And KPIs Style enum to a style text. Enum values 0,7,8,9,10 are defined by default, if custom values are needed take a look at OnConvertStyleToStyleText event.
- `InsertData(TableID: Integer; FieldNo: Integer; LowRangeStyle: Enum "Cues And KPIs Style"; Threshold1: Decimal; MiddleRangeStyle: Enum "Cues And KPIs Style"; Threshold2: Decimal; HighRangeStyle: Enum "Cues And KPIs Style"): Boolean`: Inserts cue setup data. The entries inserted via this method will have no value for the userid field.
