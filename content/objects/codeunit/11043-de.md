## Procedures

- `GetPaymentMeansCode(PaymentMethodCode: Code[10]): Code[3]`: Returns the UNCL4461 payment means code for the given Payment Method Code. Falls back to '58' (SEPA Credit Transfer) if no code is configured.
- `IsDirectDebit(PaymentMeansCode: Code[3]): Boolean`: Returns true when the given UNCL4461 payment means code is a SEPA direct debit code (49 or 59). Direct debit requires the BG-19 mandate data (BT-89, BT-90, BT-91) in the exported document.
- `IsCreditTransfer(PaymentMeansCode: Code[3]): Boolean`: Returns true when the given UNCL4461 payment means code is a credit transfer code (30 or 58). Credit transfer only requires the payee account (BT-84) in the exported document.
- `GetCreditorNo(CompanyBankAccountCode: Code[20]): Code[35]`: Returns the SEPA Creditor Identifier from the company bank account. Used for SEPA Direct Debit payment means (49/59) in the SellerTradeParty/AccountingSupplierParty.
- `CheckPaymentDataAvailable(SourceDocumentHeader: RecordRef)`: Validates that all required payment data is available for the given document before export. Called from XRechnungFormat.Check() and ZUGFeRDFormat.Check().
