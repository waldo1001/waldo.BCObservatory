- `GetLanguageId(LanguageCode: Code[10]): Integer`: Gets the language ID based on its code.

- `SetOverrideFormatRegion(FormatRegion: Text[80]; ResetOverride: Boolean)`: Overrides the format region returned by the GetFormatRegionOrDefault function.
- `GetLanguageCode(LanguageId: Integer): Code[10]`: Gets the code for a language based on its ID.
- `GetWindowsLanguageName(LanguageCode: Code[10]): Text`: Gets the name of a language based on the language code.
- `GetWindowsLanguageName(LanguageId: Integer): Text`: Gets the name of a windows language based on its ID.
- `GetApplicationLanguages(var TempLanguage: Record "Windows Language" temporary)`: Gets all available languages in the application.
- `GetDefaultApplicationLanguageId(): Integer`: Gets the default application language ID.
- `ToDefaultLanguage(ValueVariant: Variant): Text`: Formats the provided value in default language.
- `ValidateApplicationLanguageId(LanguageId: Integer)`: Checks whether the provided language is a valid application language. If it isn't, the function displays an error.
- `ValidateWindowsLanguageId(LanguageId: Integer)`: Checks whether the provided language exists. If it doesn't, the function displays an error.
- `LookupApplicationLanguageId(var LanguageId: Integer)`: Opens a list of the languages that are available for the application so that the user can choose a language.
- `LookupWindowsLanguageId(var LanguageId: Integer)`: Opens a list of languages that are available for the Windows version.
- `LookupLanguageCode(var LanguageCode: Code[10])`: Opens a list of the languages that are available for the application so that the user can choose a language.
- `GetParentLanguageId(LanguageId: Integer): Integer`: Gets the parent language ID based on Windows Culture Info.
- `SetPreferredLanguageID(UserSecID: Guid; NewLanguageID: Integer)`: Sets the preferred language for the provided user.
- `GetTwoLetterISOLanguageName(LanguageID: Integer): Text[2]`: Retrieves the two-letter ISO language name for the specified language ID.
- `GetLanguageIdFromCultureName(CultureName: Text): Integer`: Retrieves the language ID for the specified culture name.
