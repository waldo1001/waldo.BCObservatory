## Procedures

- `GetConfigurationIdByName(Name: Text[100]): Guid`: Retrieves the SystemId (GUID) of a configuration by its name.
- `CreateConfiguration(Name: Text[100]; Description: Text[250]): Guid`: Creates a new MCP configuration with the specified name and description.
- `ActivateConfiguration(ConfigId: Guid; Active: Boolean)`: Activates the specified MCP configuration.
- `AllowCreateUpdateDeleteTools(ConfigId: Guid; Allow: Boolean)`: Allows create, update and delete tools for the specified MCP configuration. Disallowing this will make the tools read-only.
- `DeleteConfiguration(ConfigId: Guid)`: Deletes the specified MCP configuration.
- `CopyConfiguration(SourceConfigId: Guid; NewName: Text[100]; NewDescription: Text[250]): Guid`: Copies an existing configuration to a new configuration, including its tools and permissions.
- `SetAsDefaultConfiguration(ConfigId: Guid)`: Sets the specified MCP configuration as the default configuration. When no configuration is specified by a connection, the default configuration will be used. Only active configurations can be set as default.
- `ClearDefaultConfiguration()`: Clears the current default configuration designation and restores the system default.
- `EnableDynamicToolMode(ConfigId: Guid; Enable: Boolean)`: Enables dynamic tool mode for the specified configuration.
- `EnableDiscoverReadOnlyObjects(ConfigId: Guid; Enable: Boolean)`: Enables discovery of accessible read-only objects for the specified configuration.
- `EnableDataQueryTools(ConfigId: Guid; Enable: Boolean)`: Enables or disables the Data Query Tools feature for the specified configuration.
- `EnableAPITools(ConfigId: Guid; Enable: Boolean)`: Enables or disables the API Tools feature for the specified configuration.
- `FindWarningsForConfiguration(ConfigId: Guid; var MCPConfigWarning: Record "MCP Config Warning"): Boolean`: Finds warnings for the specified MCP configuration, such as missing objects or missing parent objects.
- `ApplyRecommendedAction(var MCPConfigWarning: Record "MCP Config Warning")`: Applies the recommended action for the specified warning.
- `CreateAPITool(ConfigId: Guid; APIPageId: Integer): Guid`: Creates a new API tool for the specified configuration and API page.
- `CreateAPITool(ConfigId: Guid; APIPageId: Integer; ValidateAPIPublisher: Boolean): Guid`: Creates a new API tool for the specified configuration and API page.
- `CreateQueryAPITool(ConfigId: Guid; QueryId: Integer): Guid`: Creates a new API tool for the specified configuration and query.
- `CreateCodeunitAPITool(ConfigId: Guid; CodeunitId: Integer): Guid`: Creates a new API tool for the specified configuration and codeunit.
- `GetAPIToolId(ConfigId: Guid; ObjectId: Integer; ObjectType: Option Page,Query,Codeunit): Guid`: Retrieves the SystemId (GUID) of a tool by its configuration ID, object ID and object type.
- `GetAPIToolId(ConfigId: Guid; APIPageId: Integer): Guid` (obsolete 29.0: Use GetAPIToolId with ObjectType parameter instead.): Retrieves the SystemId (GUID) of a tool by its configuration ID and API page.
- `DeleteTool(ToolSystemId: Guid)`: Deletes the specified tool from the configuration.
- `AllowRead(ToolSystemId: Guid; Allow: Boolean)`: Sets the read permission for the specified tool.
- `AllowCreate(ToolSystemId: Guid; Allow: Boolean)`: Sets the create permission for the specified tool.
- `AllowModify(ToolSystemId: Guid; Allow: Boolean)`: Sets the modify permission for the specified tool.
- `AllowDelete(ToolSystemId: Guid; Allow: Boolean)`: Sets the delete permission for the specified tool.
- `AllowActions(ToolSystemId: Guid; Allow: Boolean)`: Sets the actions permission for the specified tool. For API pages this controls bound actions; for codeunit tools this controls whether the codeunit action can be invoked.
- `AllowBoundActions(ToolSystemId: Guid; Allow: Boolean)` (obsolete 29.0: Renamed to AllowActions.): Sets the bound actions permission for the specified tool.
- `CreateEntraApplication(Name: Text[100]; Description: Text[250]; ClientId: Guid)`: Creates a new MCP Entra Application with the specified name, description, and client ID.
- `DeleteEntraApplication(Name: Text[100])`: Deletes the specified MCP Entra Application.
- `ExportConfiguration(ConfigId: Guid; var OutStream: OutStream)`: Exports the specified MCP configuration and its tools to a JSON stream.
- `ImportConfiguration(var InStream: InStream; NewName: Text[100]; NewDescription: Text[250]): Guid`: Imports an MCP configuration and its tools from a JSON stream.
