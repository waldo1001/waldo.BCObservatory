## Procedures

- `IsEligibleToStart(): Boolean`: Checks whether the current company is eligible to start a trial. Returns true only when no trial has been started and no agent exists in this company.
- `StartTrial()`: Initializes the trial mode by marking trial as started and setting the invoice count to zero.
- `ResetTrial()` (internal)
- `IsActive(): Boolean`: Checks whether the current company is in trial mode and has not exceeded the invoice limit.
- `IncrementTrialInvoiceCount()`: Increments the count of invoices processed during the trial period.
- `GetTrialInvoiceCount(): Integer`: Gets the current count of invoices processed during the trial period.
- `GetTrialInvoiceLimit(): Integer`: Gets the maximum number of invoices allowed during the trial period.
- `MarkTrialEnded()` (internal): Marks the trial as ended at the module (tenant) scope, preventing any company from starting a trial.
