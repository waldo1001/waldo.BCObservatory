## Procedures

- `Apply(CustLedgEntry: Record "Cust. Ledger Entry"; ApplyUnapplyParameters: Record "Apply Unapply Parameters"): Boolean`: Applies the customer ledger entry based on the specified application parameters.
- `GetApplicationDate(CustLedgEntry: Record "Cust. Ledger Entry"): Date`: Gets the latest posting date among all customer ledger entries with the same Applies-to ID.
- `FindLastApplEntry(CustLedgEntryNo: Integer): Integer`: Finds the last application entry number for the specified customer ledger entry.
- `UnApplyDtldCustLedgEntry(DtldCustLedgEntry: Record "Detailed Cust. Ledg. Entry")`: Unapplies the specified detailed customer ledger entry if it is the last application entry.
- `CheckCustLedgEntryToUnapply(CustLedgEntryNo: Integer; var DetailedCustLedgEntry: Record "Detailed Cust. Ledg. Entry")`: Validates that the customer ledger entry can be unapplied and retrieves the last application entry.
- `UnApplyCustLedgEntry(CustLedgEntryNo: Integer)`: Unapplies the customer ledger entry by its entry number.
- `PostUnApplyCustomer(DtldCustLedgEntry2: Record "Detailed Cust. Ledg. Entry"; ApplyUnapplyParameters: Record "Apply Unapply Parameters")`: Posts the unapplication of a customer ledger entry with automatic commit.
- `PostUnApplyCustomerCommit(DtldCustLedgEntry2: Record "Detailed Cust. Ledg. Entry"; ApplyUnapplyParameters: Record "Apply Unapply Parameters"; CommitChanges: Boolean)`: Posts the unapplication of a customer ledger entry with optional commit control.
- `CheckReversal(CustLedgEntryNo: Integer)`: Checks whether the customer ledger entry is part of a reversal and raises an error if it is.
- `ApplyCustEntryFormEntry(var ApplyingCustLedgEntry: Record "Cust. Ledger Entry")`: Opens the Apply Customer Entries page to allow the user to select entries for application.
- `PreviewApply(CustLedgEntry: Record "Cust. Ledger Entry"; ApplyUnapplyParameters: Record "Apply Unapply Parameters")`: Previews the application of a customer ledger entry without posting.
- `PreviewUnapply(DetailedCustLedgEntry: Record "Detailed Cust. Ledg. Entry"; ApplyUnapplyParameters: Record "Apply Unapply Parameters")`: Previews the unapplication of a detailed customer ledger entry without posting.
- `SetApplyContext(ApplyUnapplyParameters: Record "Apply Unapply Parameters")`: Sets the context for an application preview operation.
- `SetUnapplyContext(var DetailedCustLedgEntry: Record "Detailed Cust. Ledg. Entry"; ApplyUnapplyParameters: Record "Apply Unapply Parameters")`: Sets the context for an unapplication preview operation.
- `GetAppliedCustLedgerEntries(var TempAppliedCustLedgerEntry: Record "Cust. Ledger Entry" temporary; CustLedgerEntryNo: Integer)`: Retrieves all customer ledger entries that have been applied to the specified entry.
