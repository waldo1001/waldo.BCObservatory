## Procedures

- `Start()`: Binds this codeunit instance as the active DE PEPPOL context for the current call stack and resets any captured state. - `Stop()`: Unbinds this instance from the current session's subscriber chain and clears its captured state. Must be called after the PEPPOL export through the W1 bridge has returned so that later operations in the same session do not see stale DE context values.
- `SetBuyerReference(NewBuyerReference: Text)`: Publishes the resolved DE buyer-reference value to the active bound context instance. The DE Document Info Provider returns this value from GetBuyerReference , which the W1 Sales Invoice / Sales Cr.Memo PEPPOL30 XmlPort renders into the cbc:BuyerReference element on the exported document.
- `SetSkipCustomerVATRegNoCheck(NewValue: Boolean)`: Publishes whether the W1 Customer GLN/VAT identifier check should be skipped for the active document. - `HasContext(): Boolean`: Returns whether a DE PEPPOL context is currently bound on the active session and call stack. - `GetBuyerReference(): Text`: Returns the buyer-reference value pushed by the EDocumentDE bridge via on the active bound instance.
- `GetSkipCustomerVATRegNoCheck(): Boolean`: Returns the skip-customer-VAT/GLN-check flag pushed by the EDocumentDE bridge via on the active bound instance.
