## Procedures

- `SalesLineVerifyChange(var NewSalesLine: Record "Sales Line"; var OldSalesLine: Record "Sales Line")`: Verifies that changes to a sales line do not conflict with existing warehouse lines.
- `SalesLineDelete(var SalesLine: Record "Sales Line")`: Validates that a sales line can be deleted when warehouse lines exist.
- `SalesHeaderVerifyChange(var NewSalesHeader: Record "Sales Header"; var OldSalesHeader: Record "Sales Header")`: Verifies that changes to a sales header's shipping advice are propagated to warehouse lines.
- `FromSalesLine2ShptLine(WarehouseShipmentHeader: Record "Warehouse Shipment Header"; SalesLine: Record "Sales Line"): Boolean`: Creates warehouse shipment lines from a sales line, including assembly-to-order lines if applicable.
- `SalesLine2ReceiptLine(WarehouseReceiptHeader: Record "Warehouse Receipt Header"; SalesLine: Record "Sales Line"): Boolean`: Creates a warehouse receipt line from a sales line for returns.
- `CheckIfFromSalesLine2ShptLine(SalesLine: Record "Sales Line"): Boolean`: Checks if a warehouse shipment line can be created from a sales line.
- `CheckIfFromSalesLine2ShptLine(SalesLine: Record "Sales Line"; ReservedFromStock: Enum "Reservation From Stock"): Boolean`: Checks if a warehouse shipment line can be created from a sales line with a specific reservation filter.
- `CheckIfSalesLine2ReceiptLine(SalesLine: Record "Sales Line"): Boolean`: Checks if a warehouse receipt line can be created from a sales line.

Plus 2 local procedures.
