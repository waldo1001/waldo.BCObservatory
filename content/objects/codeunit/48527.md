## Procedures

- `LogEvent(EventId: Text; Message: Text)`: Emits a diagnostic trace to Application Insights (publisher telemetry).
- `LogEvent(EventId: Text; Message: Text; Dimensions: Dictionary of [Text, Text])`: Emits a diagnostic trace with custom dimensions to Application Insights.
- `LogFailureEvent(EventId: Text; Message: Text; Dimensions: Dictionary of [Text, Text])`: Emits a customer-actionable operational failure, visible in tenant-level telemetry.
- `LogAudit(EventId: Text; Message: Text)`: Emits an audit event describing a configuration change made by the current user. Session.LogAuditMessage is OnPrem-only, so on the Cloud target these events are recorded as publisher telemetry tagged with an AuditEvent dimension.
