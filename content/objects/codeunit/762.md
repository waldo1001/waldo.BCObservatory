- `GetSetupRecordset(var AccountSchedulesChartSetup: Record "Account Schedules Chart Setup"; ChartName: Text[60]; Move: Integer)`: Retrieves and positions the account schedules chart setup record based on chart name and navigation direction. - `DrillDown(var BusChartBuf: Record "Business Chart Buffer"; AccountSchedulesChartSetup: Record "Account Schedules Chart Setup")`: Performs drill-down operation from chart data point to underlying financial data and analysis. Opens appropriate pages based on account schedule line totaling type and column layout configuration.
- `UpdateData(var BusChartBuf: Record "Business Chart Buffer"; Period: Option " ",Next,Previous; AccountSchedulesChartSetup: Record "Account Schedules Chart Setup")`: Updates chart data with account schedule calculations for the specified period and chart setup. Populates business chart buffer with financial data based on account schedule and column layout definitions.
- `GetCorrectedDate(BusChartBuf: Record "Business Chart Buffer"; InputDate: Date; PeriodNo: Integer): Date`: Calculates corrected date based on period length and period number for chart axis positioning. Adjusts dates for period-based chart display and handles different period length types.
- `CheckDuplicateAccScheduleLineDescription(AccScheduleName: Code[10])`: Validates account schedule line descriptions for duplicates within the specified account schedule. Raises error if duplicate descriptions are found to prevent chart display ambiguity.
- `CheckDuplicateColumnLayoutColumnHeader(ColumnLayoutName: Code[10])`: Validates column layout headers for duplicates within the specified column layout definition. Raises error if duplicate column headers are found to prevent chart display ambiguity.
- `SelectAll(AccSchedChartSetupLine: Record "Acc. Sched. Chart Setup Line"; IsMeasure: Boolean)`: Selects all chart setup lines and applies default chart types for measures or dimensions. Enables all available data series in the chart with appropriate visualization settings.
- `DeselectAll(AccSchedChartSetupLine: Record "Acc. Sched. Chart Setup Line"; IsMeasure: Boolean)`: Deselects all chart setup lines and removes chart type assignments for measures or dimensions. Hides all data series from the chart display by clearing visualization settings.
- `GetAccSchedMgtRef(var RefAccSchedManagement: Codeunit AccSchedManagement)`: Provides reference to the internal account schedule management codeunit for external access. Enables external code to access account schedule calculation and management functionality.
