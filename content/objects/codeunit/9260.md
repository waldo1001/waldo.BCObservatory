## Procedures

- `RegisterEvent(EventName: Text): Boolean`: Pushes a new event entry to the CES back-end for the current user.
- `GetEligibility(SurveyName: Text; var FormsProId: Text; var FormsProEligibilityId: Text; var IsEligible: Boolean): Boolean`: Gets the eligibility of the current user for the indicated survey. Making this API call resets the eligibility flag (this avoids double prompting).
- `RegisterEventAndGetEligibility(EventName: Text; SurveyName: Text; var FormsProId: Text; var FormsProEligibilityId: Text; var IsEligible: Boolean): Boolean`: Push a new event entry to the CES back-end, and get the eligibility of a given user for the indicated survey. This endpoint combines the functionality of the above 2 endpoints (adding an event and checking user eligibility).
- `GetSurvey(SurveyName: Text; var CustomerExperienceSurvey: Record "Customer Experience Survey"): Boolean`: Returns the details for a single survey
- `RenderSurvey(SurveyName: Text; FormsProId: Text; FormsProEligibilityId: Text)`: Renders a given survey
