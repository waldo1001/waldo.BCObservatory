## Procedures

- `Open(var SelectedUser: Record User): Boolean`: Opens the user lookup page with external and system users (application, agent, etc.) filtered out and assigns the selected users on the parameter.
- `OpenWithSystemUsers(var SelectedUser: Record User): Boolean`: Opens the user lookup page with only external users filtered out and assigns the selected users on the parameter.
- `ValidateUserName(UserName: Code[50])`: Displays an error if there is no user with the given username and the user table is not empty.
- `HideExternalUsers(var User: Record User)`: Sets Filter on the given User Record to exclude external and system (application, agent, etc.) users.
- `FilterSystemUserAndAADGroupUsers(var User: Record User)`: Sets Filter on the given User Record to exclude the system user and Microsoft Entra group users.
- `FilterSystemUserAndGroupUsers(var User: Record User)`: Sets Filter on the given User Record to exclude the system user, Microsoft Entra group users and Windows Group users.
