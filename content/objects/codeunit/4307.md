## Procedures

- `GetText(TaskID: BigInteger; MessageID: Guid): Text`: Get the message text for the given agent task message.
- `GetText(var AgentTaskMessage: Record "Agent Task Message"): Text`: Get the message text for the given agent task message. The record is not retrieved again; the caller must ensure the record is up to date.
- `UpdateText(TaskID: BigInteger; MessageID: Guid; NewMessageText: Text)`: Updates the message text.
- `UpdateText(var AgentTaskMessage: Record "Agent Task Message"; NewMessageText: Text)` (obsolete 29.0: Use the overload that takes TaskID and MessageID instead.): Updates the message text.
- `IsEditable(TaskID: BigInteger; MessageID: Guid): Boolean`: Check if it is possible to edit the message.
- `IsEditable(var AgentTaskMessage: Record "Agent Task Message"): Boolean`: Check if it is possible to edit the message. The record is not retrieved again; the caller must ensure the record is up to date.
- `SetStatusToSent(TaskID: BigInteger; MessageID: Guid)`: Sets the message status to sent.
- `SetStatusToSent(var AgentTaskMessage: Record "Agent Task Message")` (obsolete 29.0: Use the overload that takes TaskID and MessageID instead.): Sets the message status to sent.
- `SetStatusToFailed(TaskID: BigInteger; MessageID: Guid; StatusReason: Text[250])`: Sets the message status to failed, to indicate that delivery of the output message failed terminally. Only a reviewed output message, or one that already failed, can be set to failed.
- `SetStatusToReviewed(TaskID: BigInteger; MessageID: Guid)`: Sets the message status back to reviewed, so that delivery of a failed output message can be attempted again. The status reason of the previous failure is cleared.
- `AddAttachment(var AgentTaskMessage: Record "Agent Task Message"; FileName: Text[250]; FileMIMEType: Text[100]; Attachment: InStream)`: Add an attachment to the task message.
- `SetIgnoreAttachment(IgnoreAttachment: Boolean)`: Set whether to ignore attachments for the message. When set to true, attachments will be marked as ignored and will not be processed by the agent. The default value is false.
- `DownloadAttachments(var AgentTaskMessage: Record "Agent Task Message")`: Downloads the attachments for a specific message.
- `ShowAttachment(TaskID: BigInteger; FileID: BigInteger)`: Shows the attachments for a specific message. If file is not supported to be shown, it will be downloaded.
- `ShowAttachment(var AgentTaskFile: Record "Agent Task File")`: Shows the attachments for a specific message. If file is not supported to be shown, it will be downloaded.
- `GetAttachments(TaskID: BigInteger; MessageID: Guid; var TempAgentTaskFile: Record "Agent Task File" temporary)`: Loads the attachments for a specific message to the temporary buffer.
- `GetFileSizeDisplayText(SizeInBytes: Decimal): Text`: Get the display text for the file size.
