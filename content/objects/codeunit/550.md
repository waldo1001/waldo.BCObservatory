## Procedures

- `ConvertVATProdPostGrp(UpdateOption: Option): Boolean`: Determines whether VAT product posting groups should be converted based on the update option.
- `ConvertGenProdPostGrp(UpdateOption: Option): Boolean`: Determines whether general product posting groups should be converted based on the update option.
- `UpdateTable(TableID: Integer; ConvertVATProdPostingGroup: Boolean; ConvertGenProdPostingGroup: Boolean)`: Updates all records in a specified table with new VAT or general product posting groups.
- `UpdateRec(var RecRef: RecordRef; ConvertVATProdPostingGroup: Boolean; ConvertGenProdPostingGroup: Boolean)`: Updates posting group fields in a specific record and creates log entries for the changes.
- `WriteLogEntry(VATRateChangeLogEntry: Record "VAT Rate Change Log Entry")`: Inserts a log entry for VAT rate change conversion tracking.
- `AddNewSalesLine(SalesLine: Record "Sales Line"; VATProdPostingGroup: Code[20]; GenProdPostingGroup: Code[20])`: Creates a new sales line with updated posting groups when document lines need to be split during conversion. Handles complex scenarios with reservations, item charges, and blanket orders.
- `UpdatePurchase()`: Updates purchase documents with new VAT and general product posting groups during conversion. Handles document status changes, line splitting, and complex validation scenarios.
- `GetNextPurchaseLineNo(PurchaseLine: Record "Purchase Line"; var NextLineNo: Integer): Boolean`: Calculates the next available line number for a new purchase line.
- `UpdateUnitPriceInclVAT(Type: Enum "Sales Line Type"): Boolean`: Determines whether unit price including VAT should be updated for the specified sales line type. Uses setup configuration to control which line types require price updates during VAT rate changes.
- `LineInScope(GenProdPostingGroup: Code[20]; VATProdPostingGroup: Code[20]; ConvertGenProdPostingGroup: Boolean; ConvertVATProdPostingGroup: Boolean): Boolean`: Determines whether a record is in scope for conversion based on its posting group values.
- `GetNextSalesLineNo(SalesLine: Record "Sales Line"; var NextLineNo: Integer): Boolean`: Calculates the next available line number for inserting a new sales line in the same document. Uses spacing logic to insert between existing lines when possible, or appends with standard increment.
- `GetRoundingPrecision(CurrencyCode: Code[10]): Decimal`: Retrieves the unit amount rounding precision for the specified currency. Handles both local currency (empty code) and foreign currency scenarios with proper precision lookup.
- `IncludeSalesLine(Type: Enum "Sales Line Type"; No: Code[20]): Boolean`: Determines whether a sales line with the specified type and number should be included in VAT rate change processing. Validates line inclusion based on setup configuration and posting group assignments.
- `IncludePurchLine(Type: Enum "Purchase Line Type"; No: Code[20]): Boolean`: Determines whether a purchase line with the specified type and number should be included in VAT rate change processing. Validates line inclusion based on setup configuration and posting group assignments.
- `InitVATRateChangeLogEntry(var VATRateChangeLogEntry: Record "VAT Rate Change Log Entry"; RecRef: RecordRef; OutstandingQuantity: Decimal; LineNo: Integer)`: Initializes a VAT rate change log entry with standard tracking information for a record conversion. Sets up logging data including record identification, table reference, and status description.
