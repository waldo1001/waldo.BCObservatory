## Procedures

- `CheckReminder(ReminderHeader: Record "Reminder Header")`: Validates if a reminder meets PEPPOL requirements.
- `CheckFinChargeMemo(FinChargeMemoHeader: Record "Finance Charge Memo Header")`: Validates if a finance charge memo meets PEPPOL requirements.
- `CheckPurchaseOrder(PurchaseHeader: Record "Purchase Header"; EDocumentProcessingPhase: Enum "E-Document Processing Phase")`: Validates if a purchase order meets PEPPOL requirements before the outbound e-document is created.
- `CheckRemittanceAdvice(GenJournalLine: Record "Gen. Journal Line")`: Validates if a remittance advice built from an unposted vendor payment journal line meets PEPPOL requirements.
