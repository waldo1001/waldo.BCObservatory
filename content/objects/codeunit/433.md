## Procedures

- `GetAadTenantId(): Text`: Gets the Microsoft Entra tenant ID.
- `GetAadTenantDomainName(): Text`: Gets the Microsoft Entra tenant domain name. If the Microsoft Graph API cannot be reached, the error is displayed.
- `GetCountryLetterCode(): Code[2]`: Gets the current Microsoft Entra tenant registered country letter code. Visit Microsoft Admin Cententer to view or edit Organizational Information. If the Microsoft Graph API cannot be reached, the error is displayed.
- `GetPreferredLanguage(): Code[2]`: Gets the current Microsoft Entra tenant registered preferred language. Visit Microsoft Admin Cententer to view or edit Organizational Information. If the Microsoft Graph API cannot be reached, the error is displayed.
- `IsVerifiedDomain(Domain: Text): Boolean`: Checks whether a domain is registered as verified on the current Microsoft Entra tenant. If the Microsoft Graph API cannot be reached, the error is displayed.
- `GetPowerPlatformTenantURL(): Text`: Gets the Power Platform tenant URL.
