## Procedures

- `ValidateZUGFeRDXML(var XmlStream: InStream)`: Validates a ZUGFeRD document against the UN/CEFACT Cross Industry Invoice (CII) D22B schemas bundled with this app. Raises an error describing the first schema violation found.
- `ValidateXRechnungInvoiceXML(var XmlStream: InStream)`: Validates an XRechnung invoice against the OASIS UBL 2.1 Invoice schemas bundled with this app. Raises an error describing the first schema violation found.
- `ValidateXRechnungCreditNoteXML(var XmlStream: InStream)`: Validates an XRechnung credit note against the OASIS UBL 2.1 CreditNote schemas bundled with this app. Raises an error describing the first schema violation found.
