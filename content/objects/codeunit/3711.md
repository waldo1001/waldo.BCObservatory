## Procedures

- `Any(): Boolean`: Checks if there any translations present at all.
- `Get(RecVariant: Variant; FieldId: Integer): Text`: Gets the value of a field in the global language for the record.

- `ShowForAllRecords(TableId: Integer; FieldId: Integer)`: Shows all language translations available for a given field for all the records in that table in a new page.
- `GetTranslations(RecVariant: Variant; FieldId: Integer; var TranslationBuffer: Record "Translation Buffer"): Boolean`: Gets all available translations for a record into a temporary buffer. If FieldId is 0, it retrieves translations for all fields.
