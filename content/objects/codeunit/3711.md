## Procedures

- `Any(): Boolean`: Checks if there any translations present at all.
- `Get(RecVariant: Variant; FieldId: Integer): Text`: Gets the value of a field in the global language for the record.
- `Get(RecVariant: Variant; FieldId: Integer; LanguageId: Integer): Text`: Gets the value of a field in the language that is specified for the record.
- `Set(RecVariant: Variant; FieldId: Integer; Value: Text[2048])`: Sets the value of a field to the global language for the record.
- `Set(RecVariant: Variant; FieldId: Integer; LanguageId: Integer; Value: Text[2048])`: Sets the value of a field to the language specified for the record.
- `Delete(RecVariant: Variant)`: Deletes all translations for a persisted (non temporary) record.
- `Delete(RecVariant: Variant; FieldId: Integer)`: Deletes the translation for a field on a persisted (non temporary) record.
- `Delete(TableID: Integer)`: Deletes all the translation for a table ID.
- `Copy(FromRecVariant: Variant; ToRecVariant: Variant)`: Copies the translation for a field from one record to another record on a persisted (non-temporary) record.
- `Copy(FromRecVariant: Variant; ToRecVariant: Variant; FieldId: Integer)`: Copies the translation for a field from one record to another record on a persisted (non-temporary) record.
- `Copy(FromRecVariant: Variant; FromFieldId: Integer; ToRecVariant: Variant; ToFieldId: Integer)`: Copies the translation from one record's field to another record's field on a persisted (non-temporary) record.
- `Show(RecVariant: Variant; FieldId: Integer)`: Shows all language translations that are available for a field in a new page.
- `Show(RecVariant: Variant; FieldId: Integer; CheckFieldLength: Boolean)`: Shows all language translations that are available for a field in a new page.
- `ShowForAllRecords(TableId: Integer; FieldId: Integer)`: Shows all language translations available for a given field for all the records in that table in a new page.
- `GetTranslations(RecVariant: Variant; FieldId: Integer; var TranslationBuffer: Record "Translation Buffer"): Boolean`: Gets all available translations for a record into a temporary buffer. If FieldId is 0, it retrieves translations for all fields.
