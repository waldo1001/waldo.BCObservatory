## Procedures

- `OpenExtensionSourceInVSCode(var PublishedApplication: Record "Published Application")`: Opens an URL that sends a request to VS Code to retrieve and open the source code of the provided extension from Git.
- `UpdateConfigurationsInVSCode()`: Opens an URL that sends a request to VS Code to update the launch configurations to match the current environment to publish and debug.
- `UpdateDependenciesInVSCode(var PublishedApplication: Record "Published Application")`: Opens an URL that sends a request to VS Code to add and download the selected extensions as dependencies.
- `GetDependenciesAsJson(var PublishedApplication: Record "Published Application"): Text`: Returns the selected extensions as a JSON array of dependencies.
- `NavigateToPageDefinitionInVSCode(var PageInfoAndFields: Record "Page Info And Fields"; var NavAppInstalledApp: Record "NAV App Installed App")`: Opens an URL that sends a request to VS Code to navigate to the source definition of the given page and to download the dependent symbols.
