## Procedures

- `GetGraphUser(UserSecurityId: Guid; var User: DotNet UserInfo)`: Gets the Microsoft Entra user with the given security ID.
- `GetGraphUser(UserSecurityId: Guid; ForceFetchFromGraph: Boolean; var User: DotNet UserInfo)`: Gets the Microsoft Entra user with the given security ID.
- `GetObjectId(UserSecurityId: Guid): Text`: Retrieves the user’s unique identifier, which is its object ID, from Microsoft Entra.
- `GetUserAuthenticationObjectId(UserSecurityId: Guid): Text`: Gets the user's authentication object ID.
- `TryGetUserAuthenticationObjectId(UserSecurityId: Guid; var AuthenticationObjectId: Text): Boolean`: Tries to get the user's authentication object ID.
- `GetUser(AuthenticationObjectID: Text; var User: Record User): Boolean`: Gets the user from a given Authentication object ID.
- `IsUserDelegatedAdmin(): Boolean`: Returns whether the current user is Delegated Admin.
- `IsUserDelegatedHelpdesk(): Boolean`: Returns whether the current user is Delegated Helpdesk.
- `IsUserDelegated(): Boolean`: Returns whether the current user is delegated.
- `UpdateUserFromAzureGraph(var User: Record User; var AzureADUser: DotNet UserInfo): Boolean`: Updates the user record with information from Microsoft Entra.
- `GetAuthenticationEmail(GraphUserInfo: DotNet UserInfo): Text[250]`: Gets the authentication email of the provided Graph user.
- `GetDisplayName(GraphUserInfo: DotNet UserInfo): Text[50]`: Gets the display name of the provided Graph user.
- `GetContactEmail(GraphUserInfo: DotNet UserInfo): Text[250]`: Gets the contact email of the provided Graph user.
- `GetFullName(GraphUserInfo: DotNet UserInfo): Text[80]`: Gets the full name of the provided Graph user.
- `GetPreferredLanguageID(GraphUserInfo: DotNet UserInfo): Integer`: Gets the preferred language ID of the provided Graph user.
- `EnsureAuthenticationEmailIsNotInUse(AuthenticationEmail: Text)`: Ensures that an email address specified for authorization is not already in use by another database user. If it is, all the database users with this authentication email address are updated and their email addresses are updated the ones that are specified in Microsoft Entra.
