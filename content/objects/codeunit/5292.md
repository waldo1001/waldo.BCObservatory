## Procedures

- `Initialize()`: Initializes the dummy root node to which all other nodes are added. The list of child nodes of the dummy root node is returned by the GetXmlNodes function.
- `InitNamespace(NewNamespaceUri: Text)`: Sets the NamespaceUri that is later used in the functions which create XML nodes.
- `AddNewXmlNode(NodeName: Text; NodeText: Text)`: Adds the child node to the current node and sets that child node as a parent for the next nodes.
- `AppendXmlNode(NodeName: Text; NodeText: Text)`: Adds the child node to the current node. Node is not added if the content is empty.
- `AppendXmlNodeEmptyContentAllowed(NodeName: Text; NodeText: Text)`: Adds the child node to the current node. Node content can be empty.
- `FinalizeXmlNode()`: Selects the parent node of the current node, i.e. "closes" the current XML node.
- `GetXmlNodes(): XmlNodeList`: Returns the list of child nodes of the dummy root node.
