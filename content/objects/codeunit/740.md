## Procedures

- `GetLines(VATReportHeader: Record "VAT Report Header")`: Generates VAT statement lines for the report using configured suggest lines codeunit. Validates report is open and routes to appropriate line generation logic.
- `Generate(VATReportHeader: Record "VAT Report Header")`: Generates VAT report content using configured content codeunit. Creates formatted output for printing or electronic submission.
- `ShowGenerate(VATReportHeader: Record "VAT Report Header"): Boolean`: Determines if Generate action should be visible for the VAT report. Checks configuration for content codeunit without submission codeunit.
- `Export(VATReportHeader: Record "VAT Report Header")`: Exports VAT report using configured content and submission codeunits. Handles both content generation and electronic submission processes.
- `ShowExport(VATReportHeader: Record "VAT Report Header"): Boolean`: Determines if Export action should be visible for the VAT report. Checks configuration for submission codeunit availability.
- `ReceiveResponse(VATReportHeader: Record "VAT Report Header")`: Receives and processes responses from tax authority using configured response handler codeunit. Updates VAT report status based on submission response.
- `ShowReceiveResponse(VATReportHeader: Record "VAT Report Header"): Boolean`: Determines if Receive Response action should be visible for the VAT report. Checks report status and response handler configuration.
- `Release(VATReportHeader: Record "VAT Report Header")`: Releases VAT report from open to released status with validation. Delegates to VAT Report Release/Reopen codeunit for processing.
- `Reopen(VATReportHeader: Record "VAT Report Header")`: Reopens released VAT report back to open status for modifications. Delegates to VAT Report Release/Reopen codeunit for processing.
- `Print(VATReportHeader: Record "VAT Report Header")`: Prints VAT report based on current status with automatic release if needed. Routes to appropriate print method based on report status.
- `Submit(VATReportHeader: Record "VAT Report Header")`: Submits released VAT report to submitted status for tax authority processing. Delegates to VAT Report Release/Reopen codeunit for status management.
- `ShowSubmissionMessage(VATReportHeader: Record "VAT Report Header"): Boolean`: Determines if submission message should be displayed based on report status and attachments. Checks for existing submission attachments and configuration settings.
- `GetVATReportConfiguration(var VATReportsConfiguration: Record "VAT Reports Configuration"; VATReportHeader: Record "VAT Report Header")`: Retrieves VAT report configuration based on report type and version. Applies filters and finds matching configuration record for report processing.
