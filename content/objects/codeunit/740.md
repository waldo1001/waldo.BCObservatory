- `Release(VATReportHeader: Record "VAT Report Header")`: Releases VAT report from open to released status with validation. Delegates to VAT Report Release/Reopen codeunit for processing.
- `Reopen(VATReportHeader: Record "VAT Report Header")`: Reopens released VAT report back to open status for modifications. Delegates to VAT Report Release/Reopen codeunit for processing.
- `Print(VATReportHeader: Record "VAT Report Header")`: Prints VAT report based on current status with automatic release if needed. Routes to appropriate print method based on report status.
- `Submit(VATReportHeader: Record "VAT Report Header")`: Submits released VAT report to submitted status for tax authority processing. Delegates to VAT Report Release/Reopen codeunit for status management.
- `ShowSubmissionMessage(VATReportHeader: Record "VAT Report Header"): Boolean`: Determines if submission message should be displayed based on report status and attachments. Checks for existing submission attachments and configuration settings.
- `GetVATReportConfiguration(var VATReportsConfiguration: Record "VAT Reports Configuration"; VATReportHeader: Record "VAT Report Header")`: Retrieves VAT report configuration based on report type and version. Applies filters and finds matching configuration record for report processing.
