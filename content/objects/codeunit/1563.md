## Events published

- `OnBeforeShowPrivacyNotice(PrivacyNotice: Record "Privacy Notice"; var Handled: Boolean)` (integration): This event is called when we are confirming approval to the privacy notice but no decision has been made. Just before calling any UI to show a dialog to the user. This allows overriding of individual privacy notices in case of custom wizards.
  - subscribers: [Codeunit 1568 "Power Automate Privacy Notice"](../codeunit/1568.md) ShowPrivacyNoticePowerAutomate, [Codeunit 1569 "Microsoft Learn Privacy Notice"](../codeunit/1569.md) ShowPrivacyNoticeMicrosoftLearn

This will happen during demotool, upgrade and using the action on the Privacy Notices list. If a Privacy Notice with the same Id already exist, the entry is ignored.
