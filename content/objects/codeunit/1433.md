## Procedures

- `TryShowSurvey(): Boolean`: Tries to show the satisfaction survey dialog to the current user. The survey is only shown if the user is chosen for the survey. The method sends the request to the server and checks the response to check if the user is chosen for the survey.
- `TryShowSurvey(Status: Integer; Response: Text): Boolean`: Tries to show the satisfaction survey dialog to the current user. Decision to show the survey or not is based on the response from the server on the check request.
- `TryGetCheckUrl(var Url: Text): Boolean`: Gets the URL of the request to the server for checking if the dialog has to be presented to the current user.
- `GetRequestTimeoutAsync(): Integer`: Gets the asynchronous request timeout.
- `ResetState(): Boolean`: Deletes the survey state and deactivates the survey for all users.
- `ResetCache(): Boolean`: Resets the the cached survey parameters.
- `ActivateSurvey(): Boolean`: Activates a try to show the survey for the current user.
- `DeactivateSurvey(): Boolean`: Deactivates a try to show the survey for the current user.
