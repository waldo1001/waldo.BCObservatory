## Procedures

- `GetRecord(): RecordRef`: Get the record that we are currently merging into the word document.
- `AddFieldValue(CustomFieldName: Text; CustomFieldValue: Text[2048])`: Set the value of a specific field. The field must already have been added in the Word Template Custom Fields codeunit.
- `Initialize(var NewTempWordTemplateCustomField: Record "Word Template Custom Field" temporary)` (internal): Set the valid fields users can add values for. This table includes fields for all related tables as well, with appropriate RelatedTableCode.
- `SetCurrentRecord(RecordRef: RecordRef; RelatedTableCode: Code[5])` (internal): Sets the record that users can add field values for (the valid fields themselves are defined in Initialize). Also clears out all current values for the record.
- `GetCurrentCustomValues(var CurrentTempWordTemplateCustomField: Record "Word Template Custom Field" temporary)` (internal): Get the table containing all custom field names and values that has been added above.
