## Procedures

- `SetHeader(NewResponseId: Text; NewSalesOrderId: Text; NewOrderReferenceId: Text; NewResponseCode: Code[10]; NewDocumentCurrencyCode: Code[10]; NewIssueDate: Date)`: Sets the document level data of the Order Response.
- `SetSellerParty(EndpointId: Text; EndpointSchemeId: Text; Name: Text)`: Sets the seller party (cac:SellerSupplierParty) of the Order Response.
- `SetBuyerParty(EndpointId: Text; EndpointSchemeId: Text; Name: Text)`: Sets the buyer party (cac:BuyerCustomerParty) of the Order Response.
- `SetPromisedDeliveryDate(PromisedDeliveryDate: Date)`: Sets the delivery date promised by the seller for the whole order (cac:Delivery/cac:PromisedDeliveryPeriod).
- `SetNote(Note: Text)`: Sets the clarification of the seller's decision (cbc:Note), for example changes that cannot be expressed as response lines. Omitted when empty.
- `AddLine(OrderLineId: Text; LineStatusCode: Code[10]; ItemName: Text)`: Adds a response line (cac:OrderLine). The SetLine* procedures apply to the line added last.
- `AddLine(ResponseLineId: Text; OrderLineId: Text; LineStatusCode: Code[10]; ItemName: Text)`: Adds a response line (cac:OrderLine) whose identifier differs from the order line it refers to, for example a line the seller added (status 1) for part of an order line. The SetLine* procedures apply to the line added last.
- `SetLineQuantity(Quantity: Decimal; UnitCode: Text)`: Sets the quantity the seller will deliver (cbc:Quantity) on the line added last.
- `SetLineMaximumBackorderQuantity(MaximumBackorderQuantity: Decimal)`: Sets the quantity the seller will deliver at a later time (cbc:MaximumBackorderQuantity) on the line added last. Use 0 when the remaining ordered quantity will not be delivered. Written only together with the line quantity.
- `SetLinePromisedDeliveryDate(PromisedDeliveryDate: Date)`: Sets the delivery date promised by the seller (cac:Delivery/cac:PromisedDeliveryPeriod) on the line added last.
- `SetLinePrice(PriceAmount: Decimal)`: Sets the net unit price confirmed by the seller (cac:Price/cbc:PriceAmount) on the line added last, in the document currency.
- `SetLineItemIdentification(BuyersItemId: Text; SellersItemId: Text)`: Sets the buyer's and seller's item identifiers (cac:Item) on the line added last. Empty identifiers are omitted.
- `Build(var TempBlob: Codeunit "Temp Blob")`: Serializes the Order Response populated through the setter procedures into TempBlob, then resets the builder so that no lines or header data carry over into the next response built with the same instance.
- `Build(EDocEntryNo: Integer; BuyerOrderNo: Code[20]; SellerName: Text[100]; BuyerName: Text[100]; ResponseCode: Code[10]; var TempBlob: Codeunit "Temp Blob")`: Generates an Order Response without currency, endpoint or line information using primitive parameters. Writes the result into TempBlob. Use the setter procedures and Build(TempBlob) to produce a complete response.
