## Procedures

- `GetEntries(TableNo: Integer; var RecRef: RecordRef)`: Retrieves captured preview entries for the specified table type. Returns temporary records containing all entries captured during preview processing.
- `IsTransactionConsistent(): Boolean`: Determines whether the posting preview transaction maintained consistency. Validates that all preview operations completed without transaction errors or rollbacks.
- `ShowEntries(TableNo: Integer)`: Displays detailed entries for the specified table type in appropriate preview pages. Opens specialized preview pages showing captured entries for comprehensive analysis.
- `FillDocumentEntry(var TempDocumentEntry: Record "Document Entry" temporary)`: Fills the temporary Document Entry table with all posted entries from the preview transaction.
- `InsertDocumentEntry(RecVar: Variant; var TempDocumentEntry: Record "Document Entry" temporary)`: Inserts a single preview entry into the temporary Document Entry table.
- `PreventCommit()`: Prevents database commits during preview operations to maintain preview-only transaction state.
- `SetShowDocumentNo(NewShowDocNo: Boolean)`: Controls whether document numbers are displayed in preview results.
