## Procedures

- `GetUser(UserPrincipalName: Text; var UserInfo: DotNet UserInfo)`: Gets the user with the specified user principal name from Microsoft Entra.
- `GetCurrentUser(var UserInfo: DotNet UserInfo)`: Gets the current user from Microsoft Entra.
- `GetUserByAuthorizationEmail(AuthorizationEmail: Text; var UserInfo: DotNet UserInfo)`: Gets the user with the specified authorization email from Microsoft Entra.
- `GetUserByObjectId(ObjectId: Text; var UserInfo: DotNet UserInfo)`: Gets the user with the specified object ID from Microsoft Entra.
- `TryGetUserByObjectId(ObjectId: Text; var UserInfo: DotNet UserInfo): Boolean`: Tries to return the user with the specified object ID from Microsoft Entra.
- `GetUserAssignedPlans(UserInfo: DotNet UserInfo; var UserAssignedPlans: DotNet GenericList1)`: Gets the assigned plans for the specified user from Microsoft Entra.
- `GetUserRoles(UserInfo: DotNet UserInfo; var UserRoles: DotNet GenericIEnumerable1)`: Gets the roles assigned to the user from Microsoft Entra.
- `GetDirectorySubscribedSkus(var DirectorySubscribedSkus: DotNet GenericIEnumerable1)`: Gets the list of subscriptions owned by the tenant.
- `GetDirectoryRoles(var DirectoryRoles: DotNet GenericIEnumerable1)`: Gets the directory roles from Microsoft Entra.
- `GetTenantDetail(var TenantInfo: DotNet TenantInfo)`: Gets details about the tenant from Microsoft Entra.
- `IsM365CollaborationEnabled(): Boolean`: Gets the value of whether M365 collaboration is enabled.
- `GetEnvironmentSecurityGroupId(): Text`: Gets the name of the Microsoft Entra security group defined in tenant admin center. For more info, see https://learn.microsoft.com/en-us/dynamics365/business-central/dev-itpro/administration/tenant-admin-center-environments#manage-access-using-azure-active-directory-groups
- `IsEnvironmentSecurityGroupDefined(): Boolean`: Returns if the Microsoft Entra security group is defined in tenant admin center.
- `GetUsersPage(NumberOfUsers: Integer; var UserInfoPage: DotNet UserInfoPage)`: Gets a list of users.
- `GetLicensedUsersPage(AssignedPlans: DotNet StringArray; NumberOfUsers: Integer; var UserInfoPage: DotNet UserInfoPage)`: Gets a list of licensed users.
- `GetGroupMembers(GroupDisplayName: Text; var GroupMembers: DotNet IEnumerable)`: Gets a list of users who are members of the specified Microsoft Entra group.
- `GetMembersPageForGroupId(GroupId: Text; NumberOfUsers: Integer; var UserInfoPage: DotNet UserInfoPage)`: Gets a list of users who are members of the specified Microsoft Entra group.
- `GetMemberIdsPageForGroupId(GroupId: Text; NumberOfUsers: Integer; var UserIdsPage: DotNet UserIdsPage)`: Gets a list of user IDs of users who are members of the specified Microsoft Entra group.
- `IsGroupMember(GroupDisplayName: Text; GraphUserInfo: DotNet UserInfo): Boolean`: Checks if a given user is a member of a Microsoft Entra security group.
- `IsMemberOfGroupWithId(GroupId: Text; GraphUserInfo: DotNet UserInfo): Boolean`: Checks if a given user is a member of a Microsoft Entra security group.
- `GetGroupName(GroupId: Text): Text`: Gets the group's display name
- `GetFirstGroupIdWithName(GroupName: Text): Text`: Gets the first Microsoft Entra group object ID that matches the provided display name.
- `GetGroups(): Dictionary of [Text, Text]`: Gets all of the Microsoft Entra security groups.
- `IsGraphUserAccountEnabled(UserPrincipalName: Text; var IsEnabled: Boolean)`: Checks if the Microsoft 365 user account for the specified principal name is enabled. Note: Even if the graph user is enabled, the account may be disabled in Business Central.
