## Procedures

- `GetGlobalDimensions(DimSetID: Integer; var ShortcutDimCode: array[8] of Code[20])`: Retrieves global dimension values (dimensions 1-2) from a dimension set. Extracts dimension value codes for global dimensions configured in General Ledger Setup.
- `GetShortcutDimensions(DimSetID: Integer; var ShortcutDimCode: array[8] of Code[20])`: Retrieves all shortcut dimension values (dimensions 1-8) from a dimension set. Extracts dimension value codes for all shortcut dimensions configured in General Ledger Setup.
