## Procedures

- `ShowPurchaseOrder(RecRelatedVariant: Variant)`: Opens the Purchase Order page for the subcontracting purchase order linked to the given variant record.
- `CalcNoOfTransferOrders(RecRelatedVariant: Variant): Integer`: Returns the number of subcontracting transfer order lines linked to the given variant record.
- `GetTransferOrderNo(RecRelatedVariant: Variant): Code[20]`: Returns the transfer order document number linked to the given variant record, or 'Multiple' if more than one exists.
- `GetReturnTransferOrderNo(RecRelatedVariant: Variant): Code[20]`: Returns the return transfer order document number linked to the given variant record.
- `GetNoOfTransferOrders(RecRelatedVariant: Variant): Integer`: Returns the number of distinct transfer orders (by document number) linked to the subcontracting purchase order for the given variant record.
- `GetTransferOrderNoByVariant(RecRelatedVariant: Variant; var TransferOrderNo: Code[20]): Boolean`: Finds the transfer order number linked to the purchase or receipt document in the given variant record.
- `ShowTransferOrdersAndReturnOrder(RecRelatedVariant: Variant; LookUpPage: Boolean; IsReturn: Boolean): Integer`: Shows the transfer order(s) or return transfer order linked to the given variant record.
- `ShowTransferOrdersFromProductionOrder(ProductionOrder: Record "Production Order")`: Opens the subcontracting transfer order(s) linked to the given production order.
- `ShowTransferOrdersFromPurchaseOrder(PurchaseHeader: Record "Purchase Header"; IsReturn: Boolean)`: Opens the subcontracting transfer order(s) linked to the given purchase order.
- `CalcNoOfPurchasePrices(var PurchaseLine: Record "Purchase Line"): Integer`: Returns the number of subcontractor prices matching the given purchase line.
- `ShowSubcontractorPrices(PurchaseLine: Record "Purchase Line")`: Opens the Subcontractor Prices page filtered to the subcontractor prices matching the given purchase line.
