## Procedures

- `GetOAuth2Credentials(var UserName: Text; var AccessToken: SecretText)` (internal): Provide the credentials to authenticate using OAuth 2.0 for Exchange Online mailboxes.
- `AuthenticateWithOAuth2()` (internal): Authenticate the current user. Disregard the token cache and show the authentication dialog.
- `AuthenticateWithOAuth2CustomAppReg(var SMTPAccount: Record "SMTP Account")` (internal)
- `CheckOAuth2Authentication()` (internal): Verify if the current user is successfully authenticated. If there is token cache, it will be used. Otherwise, the authentication dialog will be shown.
- `GetUserName(AccessToken: SecretText; var UserName: Text)` (internal): Get user's email address by the access token.
