## Procedures

- `Create(GroupCode: Code[20]; GroupId: Text)`: Creates a new security group.
- `Delete(GroupCode: Code[20])`: Deletes a security group.
- `Copy(SourceGroupCode: Code[20]; DestinationGroupCode: Code[20]; DestinationGroupId: Text)`: Copies a security group.
- `CopyPermissions(SourceGroupCode: Code[20]; DestinationGroupCode: Code[20])`: Copies permission sets from the source security group to the destination security group.
- `AddPermissionSet(GroupCode: Code[20]; RoleId: Code[20]; Company: Text[30]; Scope: Option System,Tenant; AppId: Guid)`: Adds a permission set to a security group.
- `RemovePermissionSet(GroupCode: Code[20]; RoleId: Code[20]; Company: Text[30]; Scope: Option System,Tenant; AppId: Guid): Boolean`: Removes a permission set from a security group.
- `GetGroups(var SecurityGroupBuffer: Record "Security Group Buffer")`: Gets all the defined security groups.
- `GetGroups(var SecurityGroupBuffer: Record "Security Group Buffer"; FetchGroupNames: Boolean)`: Gets all the defined security groups.
- `GetMembers(var SecurityGroupMemberBuffer: Record "Security Group Member Buffer"): List of [Code[20]]`: Gets all the security group memberships.
- `ValidateGroupId(GroupId: Text)`: Validates the group ID that can be used for a security group.
- `GetGroupUserSecurityId(GroupCode: Code[20]): Guid`: Gets the user security ID of a special user record that corresponds to a Microsoft Entra security group or Windows group.
- `GetName(GroupCode: Code[20]; var GroupName: Text[250]): Boolean`: Gets the name of the security group.
- `GetId(GroupCode: Code[20]): Text[250]`: Gets the SID of a Windows group or an object ID of a Microsoft Entra security group by group code.
- `GetCode(GroupId: Text[250]; var GroupCode: Code[20]): Boolean`: Gets the code of the security group by its ID.
- `GetIdByName(GroupName: Text): Text` (internal): Gets the SID of a Windows group or an object ID of a Microsoft Entra security group by group name.
- `SendNotificationForDeletedGroups(var SecurityGroupBuffer: Record "Security Group Buffer")` (internal): Shows the notification listing deleted Windows / Microsoft Entra groups.
- `IsWindowsAuthentication(): Boolean`: Checks whether the current authentication type is Windows, meaning that Windows groups will be used for defining security groups.
- `Export(SecurityGroupCodes: List of [Code[20]]; Destination: OutStream)`: Exports the provided list of security groups.
- `Import(Source: InStream)`: Imports a list of security groups.
