# Codeunit 4321 "Agent"

> Codeunit 4321 "Agent" in System Application (System.Agents). 30 public procedures. Introduced in BC25, still in BC30, changed in BC27-29.

## Procedures

- `Create(AgentMetadataProvider: Enum "Agent Metadata Provider"; var UserName: Code[50]; UserDisplayName: Text[80]; var TempAgentAccessControl: Record "Agent Access Control" temporary): Guid`: Creates a new agent. The agent will be in the disabled state, with the users that can interact with the agent setup.
- `Activate(AgentUserSecurityID: Guid)`: Activates the agent
- `Deactivate(AgentUserSecurityID: Guid)`: Deactivates the agent
- `Archive(AgentUserSecurityID: Guid)`: Archives the agent. Archiving removes the agent from active use and cannot be undone. The agent must be inactive (deactivated) before it can be archived.
- `IsArchivingSupported(AgentUserSecurityID: Guid): Boolean`: Checks if the agent type supports archiving.
- `IsArchived(AgentUserSecurityID: Guid): Boolean`: Checks if the agent is archived.
- `GetDisplayName(AgentUserSecurityID: Guid): Text[80]`: Get the display name of the agent.
- `GetUserName(AgentUserSecurityID: Guid): Code[50]`: Get the user name of the agent.
- `SetDisplayName(AgentUserSecurityID: Guid; DisplayName: Text[80])`: Sets the display name of the agent.
- `GetModelId(AgentUserSecurityID: Guid): Code[30]`: Gets the model ID of the agent.
- `GetModelName(AgentUserSecurityID: Guid): Text[70]`: Gets the model name of the agent.
- `SetModelId(AgentUserSecurityID: Guid; ModelId: Code[30])`: Sets the model ID of the agent.
- `SetModelIdToAuto(AgentUserSecurityID: Guid)`: Sets the agent model to auto mode, meaning the agent will use the default agent model.
- `SetInstructions(AgentUserSecurityID: Guid; Instructions: SecretText)`: Set the instructions which agent will use to complete the tasks.
- `IsActive(AgentUserSecurityID: Guid): Boolean`: Checks if the agent is active.
- `PopulateDefaultProfile(ProfileID: Text[30]; ProfileAppID: Guid; var TempAllProfile: Record "All Profile" temporary)`: Populates the temporary profile record with the specified information.
- `SetProfile(AgentUserSecurityID: Guid; ProfileID: Text; ProfileAppID: Guid)`: Assigns the profile to the agent.
- `UpdateLocalizationSettings(AgentUserSecurityID: Guid; LanguageID: Integer; LocaleID: Integer; TimeZone: Text[180])`: Updates the Language, Regional Settings and Time Zone for the agent.
- `GetUserSettings(AgentUserSecurityID: Guid; var UserSettingsRec: Record "User Settings")`: Gets the user settings for the agent. Few properties are retrieved, like: Profile, Language, Regional Settings and Time Zone.
- `UpdateAccessControl(AgentUserSecurityID: Guid; var TempAccessControlBuffer: Record "Access Control Buffer" temporary)`: Assigns one or multiple permission sets to the agent. The assignment overrides any existing permission sets.
- `GetAccessControl(AgentUserSecurityID: Guid; var TempAccessControlBuffer: Record "Access Control Buffer" temporary)`: Gets the permission sets assigned to the agent.
- `GetAgentAccessControl(AgentUserSecurityID: Guid; var TempAgentAccessControl: Record "Agent Access Control" temporary)`: Gets the users that can manage or give tasks to the agent.
- `UpdateAgentAccessControl(AgentUserSecurityID: Guid; var TempAgentAccessControl: Record "Agent Access Control" temporary)`: Sets the users that can manage or give tasks to the agent. Existing set of users will be replaced with a new set.
- `SetProfile(AgentUserSecurityID: Guid; var AllProfile: Record "All Profile")`: Assigns the profile to the agent.
- `ProfileLookup(var UserSettingsRec: Record "User Settings"): Boolean`: Allows the user to select the new profile for given User Settings for an agent.
- `UpdateLocalizationSettings(AgentUserSecurityID: Guid; var NewUserSettings: Record "User Settings")`: Updates the Language, Regional Settings and Time Zone for the agent.
- `GetUserAccess(AgentUserSecurityID: Guid; var TempAgentAccessControl: Record "Agent Access Control" temporary)`: Gets the users that can manage or give tasks to the agent.
- `AssignPermissionSet(AgentUserSecurityID: Guid; var TempAccessControlBuffer: Record "Access Control Buffer" temporary)`: Assigns the permission set to the agent.
- `UpdateAccess(AgentUserSecurityID: Guid; var TempAgentAccessControl: Record "Agent Access Control" temporary)`: Sets the users that can manage or give tasks to the agent. Existing set of users will be replaced with a new set.
- `OpenSetupPageId(AgentMetadataProvider: Enum "Agent Metadata Provider"; AgentUserSecurityID: Guid)`: Opens the setup page for the specified agent.
