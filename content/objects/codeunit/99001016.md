## Procedures

- `InitializeFromItem(Item: Record Item)` (internal): Initializes the temporary data from an item record, setting item details and clearing production tables.
- `InitializeFromSalesLine(SalesLine: Record "Sales Line")` (internal): Initializes the temporary data from a sales line, creating a temporary production order and clearing production tables.
- `InitializeFromSKU(SKU: Record "Stockkeeping Unit")` (internal): Initializes the temporary data from a stockkeeping unit. The parent item's description and base unit of measure are resolved and stored alongside the SKU's location and variant codes for downstream BOM/routing resolution.
- `CreateTemporaryProdOrderLine()` (internal): Creates and inserts a temporary production order line from the current internal temporary production order. Call SetNewProdOrder first to ensure the production order context is set correctly.
- `ClearTemporaryProductionTables()` (internal): Clears the temporary production order component and routing line tables. Call this after SetNewProdOrder and CreateTemporaryProdOrderLine to reset the component/routing state.
- `InitializeNewTemporaryBOMInformation(ItemNo: Code[20]; ItemDescription: Text[100]; BaseUOMCode: Code[10])` (internal): Creates a new blank temporary BOM header and an optional default component line for editing in the wizard.
- `InitializeNewTemporaryRoutingInformation(ItemNo: Code[20]; ItemDescription: Text[100])` (internal): Creates a new blank temporary routing header for editing in the wizard, and adds a default operation 10 if a common work center is configured.
- `BuildTemporaryStructureFromBOMRouting()` (internal): Builds the temporary production order component and routing line structures from the current temporary BOM and routing data.
- `LoadBOMLines(BOMNo: Code[20]; VersionCode: Code[20])` (internal): Loads production BOM lines from the database into the internal temporary BOM line table.
- `LoadRoutingLines(RoutingNo: Code[20]; VersionCode: Code[20])` (internal): Loads routing lines from the database into the internal temporary routing line table.
- `UpdateRoutingVersionCode(NewVersionCode: Code[20])` (internal): Updates the version code on all temporary routing lines to the specified new version code.
- `UpdateBOMVersionCode(NewVersionCode: Code[20])` (internal): Updates the version code on all temporary BOM lines to the specified new version code.
- `SetNewBOMInformation(var TempBOMHeader2: Record "Production BOM Header" temporary; var TempBOMLines2: Record "Production BOM Line" temporary)` (internal): Replaces the internal temporary BOM data with the provided BOM header and lines.
- `SetNewRoutingInformation(var TempRoutingHeader2: Record "Routing Header" temporary; var TempRoutingLines2: Record "Routing Line" temporary)` (internal): Replaces the internal temporary routing data with the provided routing header and lines.
- `SetNewProdOrderComponent(var TempProdOrderComponent2: Record "Prod. Order Component" temporary)` (internal): Replaces the internal temporary production order components with the provided records.
- `SetNewProdOrderRoutingLine(var TempProdOrderRoutingLine2: Record "Prod. Order Routing Line" temporary)` (internal): Replaces the internal temporary production order routing lines with the provided records.
- `SetNewProdOrder(var TempProdOrder2: Record "Production Order" temporary)` (internal): Replaces the internal temporary production order with the provided record.
- `SetGlobalItemInfo(ItemNo: Code[20]; ItemDescription: Text[100])` (internal): Sets the global item context (item number and description) used throughout the wizard. This is normally set automatically by InitializeFromItem or InitializeFromSalesLine. Call this before SetNewProdOrder and CreateTemporaryProdOrderLine when initializing from a custom source type.
- `SetNewPurchLine(PurchLine: Record "Purchase Line")` (internal): Stores a copy of the given purchase line as the internal purchase line context. This is used by downstream logic (e.g. BOM/routing source resolution) that reads back the stored purchase line.
- `SetRtngBOMSourceType(SourceType: Enum "Prod. Definition Source")` (internal): Sets the source type indicating whether the BOM/routing originates from an existing record or is newly defined.
- `GetGlobalBOMLines(var TempBOMLines: Record "Production BOM Line" temporary)` (internal): Returns the internal temporary BOM lines by copying them into the provided variable.
- `GetGlobalRoutingLines(var TempRoutingLines: Record "Routing Line" temporary)` (internal): Returns the internal temporary routing lines by copying them into the provided variable.
- `GetGlobalBOMHeader(var TempBOMHeaderOut: Record "Production BOM Header" temporary)` (internal): Returns the internal temporary BOM header by copying it into the provided variable.
- `GetGlobalRoutingHeader(var TempRoutingHeaderOut: Record "Routing Header" temporary)` (internal): Returns the internal temporary routing header by copying it into the provided variable.
- `GetGlobalProdOrderComponent(var TempProdOrderComponentOut: Record "Prod. Order Component" temporary)` (internal): Returns the internal temporary production order components by copying them into the provided variable.
- `GetGlobalProdOrderRoutingLine(var TempProdOrderRoutingLineOut: Record "Prod. Order Routing Line" temporary)` (internal): Returns the internal temporary production order routing lines by copying them into the provided variable.
- `GetGlobalProdOrder(var TempProductionOrder: Record "Production Order" temporary)` (internal): Returns the internal temporary production order by copying it into the provided variable.
- `GetGlobalProdOrderLine(var TempProductionOrderLine: Record "Prod. Order Line" temporary)` (internal): Returns the internal temporary production order line by copying it into the provided variable.
- `UpdateProdOrderRoutingInfo(RoutingNo: Code[20]; VersionCode: Code[20])` (internal): Sets the Routing No. on the temporary production order line. If the Prod. Order Routing Line already has a routing assigned, this will overwrite the existing routing reference with the new one.
- `UpdateProdOrderBOMInfo(BOMNo: Code[20]; VersionCode: Code[20])` (internal): Sets the Production BOM No. and Version Code on the temporary production order line.
- `GetRtngBOMSourceType(): Enum "Prod. Definition Source"` (internal): Returns the currently stored BOM/routing source type.
- `GetGlobalPurchLine(var TempPurchaseLine: Record "Purchase Line" temporary)` (internal): Returns the stored global purchase line by copying it into the provided variable.
- `GetGlobalSalesLine(var TempSalesLineOut: Record "Sales Line" temporary)` (internal): Returns the stored global sales line by copying it into the provided variable.

- `GetGlobalSourceType(): Enum "Prod. Definition Source"` (internal): Returns the source record type that was used to initialize this temporary data instance, e.g. Item, StockkeepingUnit, SalesLine, or PurchaseLine.
