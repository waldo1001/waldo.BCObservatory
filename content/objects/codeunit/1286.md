## Procedures

- `VerifyCertificate(var CertBase64Value: Text; Password: SecretText; X509ContentType: Enum "X509 Content Type"): Boolean`: Verifes that a certificate is initialized and can be exported.
- `GetCertificateFriendlyName(CertBase64Value: Text; Password: SecretText; var FriendlyName: Text)`: Specifies the friendly name of the certificate based on it's Base64 value.
- `GetCertificateSubject(CertBase64Value: Text; Password: SecretText; var Subject: Text)`: Specifies the subject of the certificate based on it's Base64 value.
- `GetCertificateThumbprint(CertBase64Value: Text; Password: SecretText; var Thumbprint: Text)`: Specifies the thumbprint of the certificate based on it's Base64 value.
- `GetCertificateIssuer(CertBase64Value: Text; Password: SecretText; var Issuer: Text)`: Specifies the issuer of the certificate based on it's Base64 value.
- `GetCertificateExpiration(CertBase64Value: Text; Password: SecretText; var Expiration: DateTime)`: Specifies the expiration date of the certificate based on it's Base64 value.
- `GetCertificateNotBefore(CertBase64Value: Text; Password: SecretText; var NotBefore: DateTime)`: Specifies the NotBefore date of the certificate based on it's Base64 value.
- `HasPrivateKey(CertBase64Value: Text; Password: SecretText): Boolean`: Checks whether the certificate has a private key based on it's Base64 value.
- `GetCertificatePropertiesAsJson(CertBase64Value: Text; Password: SecretText; var CertPropertyJson: Text)`: Specifies the certificate details in Json object
- `GetCertificatePublicKey(CertBase64Value: Text; Password: SecretText): Text`: Gets Certificate public key
- `GetCertificatePrivateKey(CertBase64Value: Text; Password: SecretText): SecretText`: Gets Certificate private key
- `GetCertificateSerialNumber(CertBase64Value: Text; Password: SecretText; var SerialNumber: Text)`: Gets Certificate serial number
- `GetCertificateSerialNumberAsASCII(CertBase64Value: Text; Password: SecretText; var SerialNumberASCII: Text)`: Gets Certificate serial number as ASCII
- `GetCertificatePublicKeyAsBase64String(CertBase64Value: Text; Password: SecretText): Text`: Gets certificate public key as Base64 string
- `GetRawCertDataAsBase64String(CertBase64Value: Text; Password: SecretText): Text`: Returns the raw data for the certificate as a Base64 string.
- `CreateFromPemAndExportAsBase64(CertificateBase64: Text; PrivateKeyXmlString: SecretText; Password: SecretText): Text`: Creates a new instance of X509Certificate2 from the specified Base64 encoded certificate value. The certificate is exported as Base64 encoded string.
