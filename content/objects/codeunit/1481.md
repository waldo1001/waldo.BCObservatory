## Events published

- `OnEditInExcelWithStructuredFilter(ServiceName: Text[240]; Filter: JsonObject; Payload: JsonObject; SearchFilter: Text; var Handled: Boolean)` (integration): This event is called when Edit in Excel is invoked, handling JSON structured filters. It also allows overriding the Edit in Excel functionality. It is however recommended to use OnEditInExcelWithFilters below if possible to avoid taking dependency on a given structure.
- `OnEditInExcelWithFilters(ServiceName: Text[240]; var EditinExcelFilters: Codeunit "Edit in Excel Filters"; SearchFilter: Text; var Handled: Boolean)` (integration): This event is called when the Edit in Excel system action is invoked or EditInExcel is called in this codeunit. It allows modifying filters or overriding the Edit in Excel functionality completely.
- `OnBeforePageControlFieldFindSet(var PageControlField: Record "Page Control Field"; PageId: Integer)` (integration): This event is raised before iterating the Page Control Field record set used to build the Edit in Excel workbook column bindings. Subscribers can add further filters or change the sort order to control which page fields are exported to Excel (for example, to honor user personalization).

## Procedures

- `EditPageInExcel(PageCaption: Text[240]; PageId: Integer)`: Creates web service for the specified page, and uses the web service to prepare and download an Excel file for the Edit in Excel functionality.
- `EditPageInExcel(PageCaption: Text[240]; PageId: Integer; EditinExcelFilters: Codeunit "Edit in Excel Filters")`: Creates web service for the specified page, and uses the web service to prepare and download an Excel file for the Edit in Excel functionality.
- `EditPageInExcel(PageCaption: Text[240]; PageId: Integer; EditinExcelFilters: Codeunit "Edit in Excel Filters"; FileName: Text)`: Creates web service for the specified page, and uses the web service to prepare and download an Excel file for the Edit in Excel functionality.
- `GenerateExcelWorkBook(TenantWebService: Record "Tenant Web Service"; SearchFilter: Text)`: Prepares an Excel file for the Edit in Excel functionality by using the specified web service, and downloads the file.
- `GenerateExcelWorkBook(TenantWebService: Record "Tenant Web Service"; EditinExcelFilters: Codeunit "Edit in Excel Filters")`: Prepares an Excel file for the Edit in Excel functionality by using the specified web service, and downloads the file.
- `ExternalizeODataObjectName(Name: Text): Text`: Converts a name (e.g. a field name or service name) to its OData externalized form. Mimics the conversion the Edit in Excel runtime applies to field and service names when generating the workbook payload, so that other apps can derive the same external names without duplicating the conversion logic.
