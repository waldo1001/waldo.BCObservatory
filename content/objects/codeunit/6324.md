## Procedures

- `GetPowerBIResourceUrl(): Text`: Returns the AAD resource URL for Power BI.
- `GetPowerBIApiUrl(): Text`: Returns the URL to be used for Power BI report upload.
- `GetPowerBIReportsUrl(): Text`: Returns the URL to retrieve the Power BI reports in the user's personal workspace.
- `GetPowerBISharedReportsUrl(WorkspaceID: Guid): Text`: Returns the URL to retrieve the Power BI reports in one of the user's shared workspaces.
- `GetPowerBIWorkspacesUrl(): Text`: Returns the URL to retrieve the Power BI workspaces shared with the user.
- `GetLicenseUrl(): Text`: Returns the URL where the user can get a Power BI license.
- `GetPowerBIReportUrl(ReportId: Guid): Text`: Returns the web URL to open a report in the Power BI portal (My Workspace).
- `GetPowerBIEmbedReportsUrl(): Text`: Returns the base URL to embed a Power BI report in Business Central.
- `SetBaseApiUrl(NewBaseApiUrl: Text)` (internal)
