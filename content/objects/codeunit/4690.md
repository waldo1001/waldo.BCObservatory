## Procedures

- `SetMinDateTime(DateTime: DateTime)`: Sets the earliest date to be returned from CalculateNextOccurrence. The default MinDateTime is today at the start time set in recurrence.
- `CalculateNextOccurrence(RecurrenceID: Guid; LastOccurrence: DateTime): DateTime`: Calculates the time and date for the next occurrence.
- `CreateDaily(StartTime: Time; StartDate: Date; EndDate: Date; DaysBetween: Integer): Guid`: Creates a daily recurrence.

- `CreateYearlyByDay(StartTime: Time; StartDate: Date; EndDate: Date; YearsBetween: Integer; DayOfMonth: Integer; Month: Enum "Recurrence - Month"): Guid`: Creates a yearly recurrence by day.

- `OpenRecurrenceSchedule(var RecurrenceID: Guid)`: Opens the card for the recurrence.
- `RecurrenceDisplayText(RecurrenceID: Guid): Text`: Returns a short text description of the recurrence.
