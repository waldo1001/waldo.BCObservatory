## Procedures

- `HasUpgradeTag(Tag: Code[250]): Boolean`: Verifies if the upgrade tag exists.
- `HasUpgradeTag(Tag: Code[250]; TagCompanyName: Code[30]): Boolean`: Verifies if the upgrade tag exists.
- `HasDatabaseUpgradeTag(Tag: Code[250]): Boolean`: Verifies if the database upgrade tag exists.
- `SetDatabaseUpgradeTag(NewTag: Code[250])`: Sets the upgrade tag for database upgrades.
- `SetUpgradeTag(NewTag: Code[250])`: Sets the upgrade tag.
- `SetSkippedUpgrade(ExistingTag: Code[250]; SkipUpgrade: Boolean)`: Sets the upgrade tag to skipped.
- `SetSkippedUpgrade(ExistingTag: Code[250]; TagCompanyName: Code[30]; SkipUpgrade: Boolean)`: Sets the upgrade tag to skipped.
- `HasUpgradeTagSkipped(ExistingTag: Code[250]; TagCompanyName: Code[30]): Boolean`: Check if the upgrade tag is skipped.
- `SetAllUpgradeTags()`: This method should be used to set all upgrade tags in a new company. The method is called from codeunit 2 - Company Initialize.
- `SetAllUpgradeTags(NewCompanyName: Code[30])`: This method should be used to set all upgrade tags in a new company.
- `CopyUpgradeTags(FromCompanyName: Code[30]; ToCompanyName: Code[30])`: This method should be used to copy all upgrade tags from a company to another company.
- `GetPerCompanyUpgradeTags(var PerCompanyUpgradeTags: List of [Code[250]])`: With this method you get all the upgrade tags by company in a list.
- `GetPerDatabaseUpgradeTags(var PerDatabaseUpgradeTags: List of [Code[250]])`: With this method you get all the upgrade tags by database in a list.
- `BackupUpgradeTags(): Integer`: This function is used for cloud migration to backup upgrade tags before cloud migration is triggered. Using the function if cloud migration is not enabled will throw an error.
- `RestoreUpgradeTagsFromBackup(BackupId: Integer; RestoreMissingTagsOnly: Boolean)`: This function is used to restore Upgrade tags after cloud migration. Using the function if cloud migration is not enabled will throw an error.
