## Procedures

- `CopyLinks(FromRecord: Variant; ToRecord: Variant)`: Copies all the links from one record to the other and sets Notify to FALSE for them.
- `WriteNote(var RecordLink: Record "Record Link"; Note: Text)`: Writes the Note BLOB into the format the client code expects.
- `ReadNote(RecordLink: Record "Record Link"): Text`: Read the Note BLOB
- `RemoveLinks(RecVariant: Variant)`: Removes all record links from all records in the RecVariant within current filters
- `RemoveOrphanedLinks()`: Iterates over the record link table and removes those with obsolete record ids.
