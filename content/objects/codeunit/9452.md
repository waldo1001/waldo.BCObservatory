## Procedures

- `GetDefaultFileAccount(var TempFileAccount: Record "File Account" temporary): Boolean`
- `GetFileAccount(Scenario: Enum "File Scenario"; var TempFileAccount: Record "File Account" temporary): Boolean`: Gets the file account used by the given file scenario. If the no account is defined for the provided scenario, the default account (if defined) will be returned.
- `GetSpecificFileAccount(Scenario: Enum "File Scenario"; var TempFileAccount: Record "File Account" temporary): Boolean`: Gets the file account used by the given file scenario.
- `SetDefaultFileAccount(TempFileAccount: Record "File Account" temporary)`: Sets a default file account.
- `SetFileAccount(Scenario: Enum "File Scenario"; TempFileAccount: Record "File Account" temporary)`: Sets a file account to be used by the given file scenario.
- `UnassignScenario(Scenario: Enum "File Scenario")`: Unassign an file scenario. The scenario will then use the default file account.
