## Procedures

- `GetDetachedTenantMedia(var TempTenantMedia: Record "Tenant Media" temporary; LoadMediaContent: Boolean): Boolean`: Returns a list of detached tenant media. This media may be detached by itself or have an detached Media Set pointing to them.
- `GetDetachedTenantMedia(var TempTenantMedia: Record "Tenant Media" temporary; LoadMediaContent: Boolean; RecordLimit: Integer): Boolean`: Returns a list of detached tenant media. This media may be detached by itself or have an detached Media Set pointing to them.
- `GetTenantMediaFromDetachedMediaSet(var TempTenantMedia: Record "Tenant Media" temporary; LoadMediaContent: Boolean): Boolean`: Returns a list of detached tenant media. This media may be detached by itself or have an detached Media Set pointing to them.
- `GetTenantMediaFromDetachedMediaSet(var TempTenantMedia: Record "Tenant Media" temporary; LoadMediaContent: Boolean; RecordLimit: Integer): Boolean`: Returns a list of detached tenant media. This media may be detached by itself or have an detached Media Set pointing to them.
- `DownloadTenantMedia(MediaId: Guid): Boolean`: Downloads the content of the specified tenant media id.
- `DeleteDetachedTenantMedia(var TempTenantMedia: Record "Tenant Media" temporary)`: Deletes the specified Tenant Media records specified in the temporary record if it is detached.
- `DeleteDetachedTenantMediaSet()`: Deletes all detached tenant media sets. Note: This function will delete detached media set in batches of 10 and commit in between each batch. This is to ensure we don't get stuck always trying to delete the same media and time out.
- `DeleteDetachedTenantMedia()`: Deletes all detached tenant media. Note: This function will delete detached media in batches of 100 and commit in between each batch. This is to ensure we don't get stuck always trying to delete the same media and time out.
- `ScheduleCleanupDetachedMedia()`: Schedules a background task which will remove both detached Tenant Media and detached Tenant Media Set. If user cannot schedule tasks, will suggest running the task in the foreground.
