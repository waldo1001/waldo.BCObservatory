## Procedures

- `Init(UriString: Text)`: Initializes a new instance of the Uri class with the specified URI.
- `GetAbsoluteUri(): Text`: Gets the absolute URI.
- `GetScheme(): Text`: Gets the scheme name for the URI.
- `GetHost(): Text`: Gets the host name of the URI.
- `GetAuthority(): Text`: Gets the authority of the URI.
- `GetPort(): Integer`: Gets the port number of the URI.
- `GetAbsolutePath(): Text`: Gets the absolute path of the URI.
- `GetQuery(): Text`: Gets any query information included in the specified URI.
- `GetFragment(): Text`: Gets the escaped URI fragment.
- `GetSegments(var Segments: List of [Text])`: Gets a list containing the path segments that make up the specified URI.
- `EscapeDataString(TextToEscape: Text): Text`: Converts a string to its escaped representation.
- `UnescapeDataString(TextToUnescape: Text): Text`: Converts a string to its unescaped representation.
- `IsValidUri(UriString: Text)`: Checks if the provded string is a valid URI.
- `IsWellFormedUriString(UriString: Text; UriKind: Enum UriKind): Boolean`: Indicates whether the string is well-formed by attempting to construct a URI with the string and ensures that the string does not require further escaping.
- `IsBaseOf(var UriToTest: Codeunit Uri): Boolean`: Determines whether the current Uri instance is a base of the specified Uri instance.
- `ValidateIntegrationURL(FieldValueURL: Text; HardcodedIntegrationURL: Text): Text`: Validates integration URI host from setup table field is the same as the hardcoded integration URI host, returns the hardcoded integration URI if validation fails.
- `AreURIsHaveSameHost(UriString1: Text; UriString2: Text): Boolean`: Verifies whether two URIs have the same host (e.g., both subdomain.example.com\test1 and subdomain.example.com\test2 have the same host subdomain.example.com).
- `IsValidURIPattern(UriString: Text; Pattern: Text): Boolean`: Verifies whether the URI is in a valid pattern.
- `GetUri(var OutUri: DotNet Uri)`: Gets the underlying .Net Uri variable.
- `SetUri(NewUri: DotNet Uri)`: Sets the underlying .Net Uri variable.
