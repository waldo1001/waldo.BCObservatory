## Procedures

- `InstallExtension(PackageId: Guid; lcid: Integer; IsUIEnabled: Boolean): Boolean`: Installs an extension, based on its PackageId and Locale Identifier.
- `UninstallExtension(PackageId: Guid; IsUIEnabled: Boolean): Boolean`: Uninstalls an extension, based on its PackageId.
- `UninstallExtensionAndDeleteExtensionData(PackageId: Guid; IsUIEnabled: Boolean): Boolean`: Uninstalls an extension, based on its PackageId and permanently deletes the tables that contain data for the extension.
- `UploadExtension(FileStream: InStream; lcid: Integer)`: Uploads an extension, using a File Stream and based on the Locale Identifier. This method is only applicable in SaaS environment.
- `DeployExtension(AppId: Guid; lcid: Integer; IsUIEnabled: Boolean)`: Deploys an extension, based on its ID and Locale Identifier. This method is only applicable in SaaS environment.
- `UnpublishExtension(PackageId: Guid): Boolean`: Unpublishes an extension, based on its PackageId. An extension can only be unpublished, if it is a per-tenant one and it has been uninstalled first.
- `DownloadExtensionSource(PackageId: Guid): Boolean`: Downloads the source of an extension, based on its PackageId.
- `GetExtensionSource(PackageId: Guid; var ExtensionSourceTempBlob: Codeunit "Temp Blob"): Boolean`: Retrives the source of an extension, based on its PackageId.
- `IsInstalledByPackageId(PackageId: Guid): Boolean`: Checks whether an extension is installed, based on its PackageId.
- `IsInstalledByAppId(AppId: Guid): Boolean`: Checks whether an extension is installed, based on its AppId.
- `GetAllExtensionDeploymentStatusEntries(var TempExtensionDeploymentStatus: Record "Extension Deployment Status" temporary)`: Retrieves a list of all the Deployment Status Entries
- `GetDeployOperationInfo(OperationId: Guid; var Version: Text; var Schedule: Text; var Publisher: Text; var AppName: Text; Description: Text)`: Retrieves the AppName,Version,Schedule,Publisher by the NAVApp Tenant OperationId.
- `RefreshStatus(OperationId: Guid)`: Refreshes the status of the Operation.
- `ConfigureExtensionHttpClientRequestsAllowance(PackageId: Text; AreHttpClientRqstsAllowed: Boolean): Boolean`: Allows or disallows Http Client requests against the specified extension.
- `GetLatestVersionPackageIdByAppId(AppId: Guid): Guid`: Gets the PackageId of the latest Extension Version by the Extension AppId.
- `GetCurrentlyInstalledVersionPackageIdByAppId(AppId: Guid): Guid`: Gets the PackageId of the latest version of the extension by the extension's AppId.
- `GetSpecificVersionPackageIdByAppId(AppId: Guid; Name: Text; VersionMajor: Integer; VersionMinor: Integer; VersionBuild: Integer; VersionRevision: Integer): Guid`: Gets the package ID of the version of the extension by the extension's AppId, Name, Version Major, Version Minor, Version Build, Version Revision.
- `GetExtensionLogo(AppId: Guid; var LogoTempBlob: Codeunit "Temp Blob")`: Gets the logo of an extension.
- `UploadExtensionToVersion(FileInStream: InStream; lcid: Integer; DeployTo: Enum "Extension Deploy To")`: Uploads an extension to current version, next minor or next major, using a File Stream and based on the Locale Identifier. This method is only applicable in SaaS environment.
- `UploadExtensionToVersion(FileInStream: InStream; lcid: Integer; DeployTo: Enum "Extension Deploy To"; SyncMode: Enum "Extension Sync Mode")`: Uploads an extension to current version, next minor or next major, using a File Stream and based on the Locale Identifier. This method is only applicable in SaaS environment.
- `InstallMarketplaceExtension(AppId: Guid)`: Installs an extension, based on its extension id.
- `GetAppName(AppId: Guid): Text`: Returns the Name of the app given the App Id.
- `GetDeploymentDetailedStatusMessage(OperationId: Guid): Text`: Returns the detailed message from a deployment operation.
- `GetDeploymentDetailedStatusMessageAsStream(OperationId: Guid; OutStream: OutStream)`: Writes the detailed message from a deployment operation to a stream.
