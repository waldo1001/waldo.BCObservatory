## Procedures

- `InsertDimensions(var DimBuf: Record "Dimension Buffer"): Integer`: Inserts dimension entries into the buffer and returns a new entry number. Creates a new entry set in the dimension buffer with sequential entry numbering.
- `InsertDimensionsUsingEntryNo(var DimBuf: Record "Dimension Buffer"; EntryNo: Integer)`: Inserts dimension entries into the buffer using a specific entry number. Assigns the provided entry number to all dimensions in the buffer set.
- `FindDimensions(var DimBuf: Record "Dimension Buffer"): Integer`: Finds existing dimension set in the buffer and returns its entry number. Searches for a matching set of dimensions and returns the entry number if found.
- `FindDimensionsKnownDimBufCount(var DimBuf: Record "Dimension Buffer"; DimBufCount: Integer): Integer`: Finds existing dimension set with known dimension count and returns its entry number. Optimized search method when the number of dimensions in the set is already known.
- `GetDimensions(EntryNo: Integer; var DimBuf: Record "Dimension Buffer"): Boolean`: Retrieves all dimensions for a specific entry number into the dimension buffer. Populates the provided dimension buffer with all dimensions associated with the entry number.
- `DeleteAllDimensions()`: Clears all dimension entries from the temporary dimension buffer. Removes all stored dimension data to prepare for new operations.
- `CollectDimEntryNo(var SelectedDim: Record "Selected Dimension"; DimSetID: Integer; EntryNo: Integer; ForgetDimEntryNo: Integer; DoCollect: Boolean; var DimEntryNo: Integer)`: Collects dimension entry numbers for selected dimensions in analysis scenarios. Manages dimension entry collection for analysis views and reporting with optional collection control.
- `FindFirstDimEntryNo(var DimEntryNo: Integer; var EntryNo: Integer): Boolean`: Finds the first dimension entry number and corresponding entry number in the collection. Initializes iteration through collected dimension entries for analysis processing.
- `NextDimEntryNo(var DimEntryNo: Integer; var EntryNo: Integer): Boolean`: Advances to the next dimension entry number and corresponding entry number in the collection. Continues iteration through collected dimension entries for analysis processing.
- `DeleteAllDimEntryNo()`: Clears all collected dimension entry numbers from the collection. Removes all entries from the dimension entry buffer to prepare for new collection.
- `GetDimensionId(var Dimbuf: Record "Dimension Buffer"): Integer`: Gets or creates a unique dimension ID for a dimension combination. Returns an existing ID if the dimension combination already exists, or creates a new one.
- `RetrieveDimensions(DimId: Integer; var DimBuf: Record "Dimension Buffer")`: Retrieves all dimensions for a specific dimension ID into a dimension buffer. Reconstructs the dimension combination from the dimension ID buffer into the provided buffer.
