## Procedures

- `GetConsumptionQtyFromProdOrderComponent(ProdOrderComponent: Record "Prod. Order Component"): Decimal`: Returns the total consumption quantity posted for the given production order component via its linked routing operation.
- `ShowConsumptionQtyFromProdOrderComponent(ProdOrderComponent: Record "Prod. Order Component")`: Opens the Item Ledger Entries page filtered to consumption entries for the given production order component.
- `GetPurchOrderOutstandingQtyBaseFromProdOrderComp(ProdOrderComponent: Record "Prod. Order Component"): Decimal`: Returns the total outstanding base quantity on subcontracting purchase lines for the given production order component.
- `ShowPurchOrderOutstandingQtyBaseFromProdOrderComp(ProdOrderComponent: Record "Prod. Order Component")`: Opens the Purchase Lines page filtered to outstanding subcontracting purchase lines for the given production order component.
- `GetPurchOrderQtyReceivedBaseFromProdOrderComp(ProdOrderComponent: Record "Prod. Order Component"): Decimal`: Returns the total received base quantity on subcontracting purchase lines for the given production order component.
- `ShowPurchOrderQtyReceivedBaseFromProdOrderComp(ProdOrderComponent: Record "Prod. Order Component")`: Opens the Purchase Lines page filtered to subcontracting purchase lines for the given production order component to show received quantities.
