## Procedures

- `TemplateSelection(PageID: Integer; var VATStmtLine: Record "VAT Statement Line"; var StmtSelected: Boolean)`: Handles VAT statement template selection for a specific page and applies filtering. Creates default template if none exists or shows template selection if multiple templates available.
- `TemplateSelectionFromBatch(var VATStmtName: Record "VAT Statement Name")`: Opens VAT statement page from batch selection with template-specific page configuration. Applies template and statement name filters before launching the statement page.
- `OpenStmt(var CurrentStmtName: Code[10]; var VATStmtLine: Record "VAT Statement Line")`: Opens VAT statement with specified name and applies proper filtering. Validates template name and sets statement name filter for VAT statement lines.
- `OpenStmtBatch(var VATStmtName: Record "VAT Statement Name")`: Opens VAT statement batch with template selection and proper filtering setup. Handles template selection when multiple templates exist and creates default statement names.
- `CheckName(CurrentStmtName: Code[10]; var VATStmtLine: Record "VAT Statement Line")`: Validates that the specified statement name exists for the current template. Ensures statement name is valid for the current VAT statement line context.
- `SetName(CurrentStmtName: Code[10]; var VATStmtLine: Record "VAT Statement Line")`: Sets the statement name filter on VAT statement lines and positions to first record. Applies statement name filtering and navigates to the first matching line.
- `LookupName(CurrentStmtTemplateName: Code[10]; CurrentStmtName: Code[10]; var EntrdStmtName: Text[10]): Boolean`: Opens lookup page for VAT statement names within the specified template. Allows user selection of VAT statement name and returns the selected name.
