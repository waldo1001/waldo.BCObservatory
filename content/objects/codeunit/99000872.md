- `ShowItemAvailabilityFromSalesLine(var SalesLine: Record "Sales Line"; AvailabilityType: Enum "Item Availability Type")`: Shows item availability information from a sales line for the specified availability type.
- `ShowSalesLines(var Item: Record Item)`: Shows sales order lines for the specified item.
- `TransferFromSales(var InventoryEventBuffer: Record "Inventory Event Buffer"; SalesLine: Record "Sales Line")`: Transfers sales line data to an inventory event buffer for availability calculation.
- `TransferFromSalesBlanketOrder(var InventoryEventBuffer: Record "Inventory Event Buffer"; SalesLine: Record "Sales Line"; UnconsumedQtyBase: Decimal)`: Transfers blanket sales order line data to an inventory event buffer.
- `TransferFromSalesReturn(var InventoryEventBuffer: Record "Inventory Event Buffer"; SalesLine: Record "Sales Line")`: Transfers sales return order line data to an inventory event buffer.
