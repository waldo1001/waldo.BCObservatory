## Procedures

- `IsSuper(UserSecurityId: Guid): Boolean`: Checks whether the user has the SUPER permissions set.
- `RemoveSuperPermissions(UserSecurityId: Guid): Boolean`: Removes the SUPER permissions set from a user.
- `CanManageUsersOnTenant(UserSecurityId: Guid): Boolean`: Checks whether the user has permission to manage users in the tenant.
- `HasUserPermissionSetAssigned(UserSecurityId: Guid; Company: Text; RoleId: Code[20]; Scope: Option; AppId: Guid): Boolean`: Checks whether a user has a specific permission set assigned.
- `AssignPermissionSets(var UserSecurityId: Guid; CompanyName: Text; var AggregatePermissionSet: Record "Aggregate Permission Set")`: Assign a permission set to a given user
- `GetEffectivePermission(PermissionObjectType: Option "Table Data","Table",,"Report",,"Codeunit","XMLport",MenuSuite,"Page","Query","System",,,,,,,,,; ObjectId: Integer): Record "Expanded Permission" temporary`: Gets the effective permissions for the current user in the current company.
