## Procedures

- `AddVendorMatchedByNameNotAddressNotification(EDocumentEntryNo: Integer)`: Persists a notification that informs a user of Purchase Document Draft that a vendor is matched by name but not by address. Does not display anything.
- `AddSubTotalMismatchNotification(EDocumentEntryNo: Integer)`: Persists a notification that informs a user of Purchase Document Draft that the header Sub Total no longer matches the sum of the lines. Does not display anything.
- `RemoveSubTotalMismatchNotification(EDocumentEntryNo: Integer)`: Removes the persisted Sub Total Mismatch notification for the current user and e-document, e.g. when the totals re-converge.
- `RefreshSubTotalMismatch(EDocumentPurchaseHeader: Record "E-Document Purchase Header")`: Re-evaluates the Sub Total mismatch and updates the persisted notification. Does not display anything.
- `RefreshAndShowPendingDraftNotifications(EDocumentEntryNo: Integer)`: Refreshes the Sub Total mismatch state and then shows every pending Purchase Document Draft notification once.
- `SendPurchaseDocumentDraftNotifications(EDocumentEntryNo: Integer)`: Shows every pending Purchase Document Draft notification for the current user.
- `RefreshAndShowSubTotalMismatchAfterHeaderEdit(EDocumentPurchaseHeader: Record "E-Document Purchase Header")`: Re-evaluates the Sub Total mismatch after a header amount edit, re-arming a dismissal, and shows the notification if it applies.
- `RefreshAndShowSubTotalMismatchAfterLineEdit(EDocumentPurchaseLine: Record "E-Document Purchase Line")`: Re-evaluates the Sub Total mismatch after a line amount edit, re-arming a dismissal, and shows the notification if it applies.
- `RefreshAndShowSubTotalMismatchAfterLineDeletion(EDocumentPurchaseLine: Record "E-Document Purchase Line")`: Re-evaluates the Sub Total mismatch while a line is being deleted, re-arming a dismissal, and shows the notification if it applies.
- `ShowSubTotalMismatchNotification(EDocumentEntryNo: Integer)`: Shows the Sub Total Mismatch notification for the e-document, if it is persisted and not dismissed.
- `IsSubTotalMismatchNotificationEnabled(): Boolean`: Returns whether the current user has the Sub Total Mismatch notification enabled.
- `IsSubTotalMismatchDismissed(EDocumentEntryNo: Integer): Boolean`: Returns whether the current user has dismissed the Sub Total Mismatch notification for the e-document.
- `DismissVendorMatchedByNameNotAddressNotification(Notification: Notification)`: Dismisses the notification of the certain Purchase Document Draft that informs a user about a vendor that is matched by name but not by address. The persisted notification row is kept and marked as dismissed so it is not re-shown to this user.
- `DisableVendorMatchedByNameNotAddressNotification(Notification: Notification)`: Disables the notification that informs a user of Purchase Document Draft that a vendor is matched by name but not by address.
- `DismissSubTotalMismatchNotification(Notification: Notification)`: Dismisses the Sub Total Mismatch notification for the current Purchase Document Draft. The persisted notification row is kept and marked as dismissed so the mismatch is not re-shown to this user until an amount edit re-arms it.
- `DisableSubTotalMismatchNotification(Notification: Notification)`: Disables the Sub Total Mismatch notification for the current user.

Plus 3 local procedures.
