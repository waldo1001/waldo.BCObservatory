## Procedures

- `CreateWebService(ObjectType: Option; ObjectId: Integer; ObjectName: Text; Published: Boolean)`: Creates a web service for a given object. If the web service already exists, it modifies the web service accordingly. This method should be used for On-Prem scenarios only. Calling this method in SaaS will throw a runtime error.
- `CreateTenantWebService(ObjectType: Option; ObjectId: Integer; ObjectName: Text; Published: Boolean)`: Creates a tenant web service for a given object. If the tenant web service already exists, it modifies the tenant web service accordingly.
- `GetWebServiceUrl(WebServiceAggregate: Record "Web Service Aggregate"; ClientType: Enum "Client Type"): Text`: Gets the web service URL for a given Web Service Aggregate record and client type.
- `CreateTenantWebServiceColumnsFromTemp(var TenantWebServiceColumns: Record "Tenant Web Service Columns"; var TempTenantWebServiceColumns: Record "Tenant Web Service Columns" temporary; TenantWebServiceRecordId: RecordId)`: Creates tenant web service columns from temporary records.
- `CreateTenantWebServiceFilterFromRecordRef(var TenantWebServiceFilter: Record "Tenant Web Service Filter"; var RecordRef: RecordRef; TenantWebServiceRecordId: RecordId)`: Creates a tenant web service filter from a record reference.
- `GetTenantWebServiceFilter(TenantWebServiceFilter: Record "Tenant Web Service Filter"): Text`: Returns the tenant web service filter for a given record.
- `RetrieveTenantWebServiceFilter(var TenantWebServiceFilter: Record "Tenant Web Service Filter"): Text`: Returns the tenant web service filter for a given record.
- `SetTenantWebServiceFilter(var TenantWebServiceFilter: Record "Tenant Web Service Filter"; FilterText: Text)`: Sets the tenant web service filter for a given record.
- `GetODataSelectClause(TenantWebServiceOData: Record "Tenant Web Service OData"): Text`: Returns the OData select clause for a given record.
- `SetODataSelectClause(var TenantWebServiceOData: Record "Tenant Web Service OData"; ODataText: Text)`: Sets the OData select clause for a given record.
- `GetODataFilterClause(TenantWebServiceOData: Record "Tenant Web Service OData"): Text`: Returns the OData filter clause for a given record.
- `SetODataFilterClause(var TenantWebServiceOData: Record "Tenant Web Service OData"; ODataText: Text)`: Sets the OData filter clause for a given record.
- `GetODataV4FilterClause(TenantWebServiceOData: Record "Tenant Web Service OData"): Text`: Returns the OData V4 filter clause for a given record.
- `SetODataV4FilterClause(var TenantWebServiceOData: Record "Tenant Web Service OData"; ODataText: Text)`: Sets the OData V4 filter clause for a given record.
- `GetObjectCaption(WebServiceAggregate: Record "Web Service Aggregate"): Text[80]`: Gets the name of the object that will be exposed to the web service for a given record.
- `LoadRecords(var WebServiceAggregate: Record "Web Service Aggregate")`: Loads records from Web Service and Tenant Web Service table into given Web Service Aggregate record.
- `LoadRecordsFromTenantWebServiceColumns(var TenantWebService: Record "Tenant Web Service")`: Loads records from Tenant Web Service table if there is a corresponding Tenant Web Service Column.
- `CreateTenantWebServiceColumnForPage(TenantWebServiceRecordId: RecordId; FieldNumber: Integer; DataItem: Integer)`: Creates a tenant web service for a given page.
- `CreateTenantWebServiceColumnForQuery(TenantWebServiceRecordId: RecordId; FieldNumber: Integer; DataItem: Integer; MetaData: DotNet QueryMetadataReader)`: Creates a tenant web service for a given query.
- `InsertSelectedColumns(var TenantWebService: Record "Tenant Web Service"; var ColumnDictionary: DotNet GenericDictionary2; var TargetTenantWebServiceColumns: Record "Tenant Web Service Columns"; DataItem: Integer)`: Inserts selected columns in a given dictionary to the tenant web service columns table.
- `RemoveUnselectedColumnsFromFilter(var TenantWebService: Record "Tenant Web Service"; DataItem: Integer; DataItemView: Text): Text`: Removes filters that are not in the selected columns for the given service.
- `IsServiceNameValid(Value: Text): Boolean`: Checks if given service name is valid.
- `DeleteWebService(var WebServiceAggregate: Record "Web Service Aggregate")`: Deletes a webservice.
