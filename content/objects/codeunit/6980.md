## Procedures

- `Reopen(var ExpenseRecord: Record Expense)` (internal)
- `PerformManualRelease(var ExpenseRecord: Record Expense)`: Releases the expense as the current user after checking that the required fields are filled in. The expense rules are re-evaluated and any violations are recorded, but violations do not block the release.
- `PerformManualCheckAndRelease(var ExpenseRecord: Record Expense)`: Checks and releases the expense as the current user. An error is raised if the expense does not meet the release requirements.
- `PerformManualReopen(var ExpenseRecord: Record Expense)`: Reopens the released expense as the current user so that it can be edited again. The expense must not be included in an expense report.
