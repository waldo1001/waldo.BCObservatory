- `GetNoOfTransferLinesFromRouting(ProdOrderRoutingLine: Record "Prod. Order Routing Line"): Decimal`: Returns the number of outbound subcontracting transfer lines linked to the given production order routing line.
- `GetNoOfReturnTransferLinesFromRouting(ProdOrderRoutingLine: Record "Prod. Order Routing Line"): Decimal`: Returns the number of return subcontracting transfer lines linked to the given production order routing line.
- `ShowTransferLinesFromRouting(ProdOrderRoutingLine: Record "Prod. Order Routing Line")`: Opens the Transfer Lines page filtered to outbound subcontracting transfer lines for the given production order routing line.
- `ShowReturnTransferLinesFromRouting(ProdOrderRoutingLine: Record "Prod. Order Routing Line")`: Opens the Transfer Lines page filtered to return subcontracting transfer lines for the given production order routing line.
- `GetNoOfLinkedComponentsFromRouting(ProdOrderRoutingLine: Record "Prod. Order Routing Line"): Integer`: Returns the number of production order components linked via routing link code to the given production order routing line.
- `ShowProdOrderComponents(ProdOrderRoutingLine: Record "Prod. Order Routing Line")`: Opens the Subc. Prod. Order Components page filtered to components linked to the given production order routing line.
