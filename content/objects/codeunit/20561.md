## Procedures

- `GetSubcontractorNo(ProdOrderRoutingLine: Record "Prod. Order Routing Line"): Code[20]`: Returns the subcontractor vendor number for the work center on the given production order routing line.
- `ShowSubcontractor(ProdOrderRoutingLine: Record "Prod. Order Routing Line")`: Opens the Vendor Card for the subcontractor assigned to the work center on the given production order routing line.
- `GetPurchOrderQtyFromRoutingLine(ProdOrderRoutingLine: Record "Prod. Order Routing Line"): Decimal`: Returns the total quantity on open purchase order lines linked to the given production order routing line.
- `ShowPurchaseOrderLinesFromRouting(ProdOrderRoutingLine: Record "Prod. Order Routing Line")`: Opens the Purchase Lines page filtered to open purchase lines linked to the given production order routing line.
- `GetPurchReceiptQtyFromRoutingLine(ProdOrderRoutingLine: Record "Prod. Order Routing Line"): Decimal`: Returns the total received quantity on purchase receipt lines linked to the given production order routing line.
- `ShowPurchaseReceiptLinesFromRouting(ProdOrderRoutingLine: Record "Prod. Order Routing Line")`: Opens the Purch. Receipt Lines page filtered to receipt lines linked to the given production order routing line.
- `GetPurchInvoicedQtyFromRoutingLine(ProdOrderRoutingLine: Record "Prod. Order Routing Line"): Decimal`: Returns the total invoiced quantity on purchase invoice lines linked to the given production order routing line.
- `ShowPurchaseInvoiceLinesFromRouting(ProdOrderRoutingLine: Record "Prod. Order Routing Line")`: Opens the Posted Purchase Invoice Lines page filtered to invoice lines linked to the given production order routing line.
- `GetNoOfTransferLinesFromRouting(ProdOrderRoutingLine: Record "Prod. Order Routing Line"): Decimal`: Returns the number of outbound subcontracting transfer lines linked to the given production order routing line.
- `GetNoOfReturnTransferLinesFromRouting(ProdOrderRoutingLine: Record "Prod. Order Routing Line"): Decimal`: Returns the number of return subcontracting transfer lines linked to the given production order routing line.
- `ShowTransferLinesFromRouting(ProdOrderRoutingLine: Record "Prod. Order Routing Line")`: Opens the Transfer Lines page filtered to outbound subcontracting transfer lines for the given production order routing line.
- `ShowReturnTransferLinesFromRouting(ProdOrderRoutingLine: Record "Prod. Order Routing Line")`: Opens the Transfer Lines page filtered to return subcontracting transfer lines for the given production order routing line.
- `GetNoOfLinkedComponentsFromRouting(ProdOrderRoutingLine: Record "Prod. Order Routing Line"): Integer`: Returns the number of production order components linked via routing link code to the given production order routing line.
- `ShowProdOrderComponents(ProdOrderRoutingLine: Record "Prod. Order Routing Line")`: Opens the Subc. Prod. Order Components page filtered to components linked to the given production order routing line.
