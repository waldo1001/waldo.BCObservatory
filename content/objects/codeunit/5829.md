## Procedures

- `AddMatch(NewMatch: Record "Matched Order Line")`: Adds an edge to the group if it's valid in the current context, merging in any already-persisted allocations that share a line with the edge so validations account for them.
- `SaveMatchingGroups()`: Revalidates the fully merged group against the current documents and persists it.
- `GetInvoiceOrderEdges(): Boolean` (internal): Snapshots the invoice-order (blank-receipt) edges and positions at the first one.
- `NextInvoiceOrderEdge(): Boolean` (internal): Advances to the next invoice-order edge in the snapshot.
- `GetInvoiceLine(): Guid` (internal): The invoice line SystemId of the current invoice-order edge.
- `GetOrderLine(): Guid` (internal): The order line SystemId of the current invoice-order edge.
- `AllocatedInInvoiceOrderEdge(): Decimal` (internal): The quantity budgeted by the current invoice-order edge.
- `SumAllocatedInOrderReceiptEdges(): Decimal` (internal): The live sum of receipt edges already pinned to the current invoice-order pair.
- `GetReceiptEdgeQuantity(InvoiceLineSystemId: Guid; OrderLineSystemId: Guid; ReceiptLineSystemId: Guid): Decimal` (internal): The live quantity of the receipt edge for the given (invoice, order, receipt), 0 if none.
- `GetReceiptConsumedQuantity(ReceiptLineSystemId: Guid): Decimal` (internal): The live total quantity pinned to a receipt line across all invoices in the group.

Plus 25 local procedures.
