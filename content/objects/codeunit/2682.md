## Events published

- `OnGetFieldNoForTableType(TableNo: Integer; var FieldNo: Integer)` (integration): Specifies the Field No. for the table type field. For example "Sales Header" would specify 1 = "Document Type"
- `OnGetParentTable(SubTableNo: Integer; var ParentTableNo: Integer)` (integration): Specifies the parent table if a table is a sub-table in a header/lines construct, such as Sales Line
- `OnGetSubTable(ParentTableNo: Integer; var SubTableNo: Integer)` (integration): Specifies the sub table if a table is a parent table in a header/lines construct, such as Sales Line / Sales Header
- `OnGetListPageNo(TableNo: Integer; TableType: Integer; var PageNo: Integer)` (integration): Specifies the list page no. to be used for displaying the record. Only needed if the page is not the standard list/card page for the table
- `OnGetCardPageNo(TableNo: Integer; TableType: Integer; var PageNo: Integer)` (integration): Specifies the card page no. to be used for displaying the record. If no card exists, then specify the list page no. Only needed if the page is not the standard list/card page for the table

- `OnGetExcludedRelatedTableField(RelatedTableNo: Integer; var IsExcluded: Boolean)` (integration): Specifies whether a field is excluded from the default fields in a table, based on its table relation. - `OnBeforeSearchTable(var RecordRef: RecordRef)` (integration): Allows the addition of additional filters for the specified during the search.
- `OnBeforeSearchTableProcedure(TableNo: Integer; TableType: Integer; var FieldList: List of [Integer]; var SearchStrings: List of [Text]; var Results: Dictionary of [Text, Text]; var IsHandled: Boolean)` (integration): Allows the different implementation of the SerachTable procedure.
