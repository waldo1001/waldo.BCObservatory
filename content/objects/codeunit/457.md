## Procedures

- `IsProduction(): Boolean`: Checks if environment type of tenant is Production.
- `GetEnvironmentName(): Text`: Gets the name of the environment.
- `IsSandbox(): Boolean`: Checks if environment type of tenant is Sandbox.
- `IsSaaS(): Boolean`: Checks if the deployment type is SaaS (Software as a Service).
- `IsOnPrem(): Boolean`: Checks the deployment type is OnPremises.
- `IsFinancials(): Boolean`: Checks the application family is Financials.
- `IsSaaSInfrastructure(): Boolean`: Checks if the deployment infrastucture is SaaS (Software as a Service). Note: This function will return false in a Docker container.
- `IsPreview(): Boolean`: Checks if the ring is preview.
- `IsEarlyPreview(): Boolean`: Checks if the ring is early preview.
- `ShowEarlyPreviewNotification()`: Shows a notification if the ring is early preview.
- `GetApplicationFamily(): Text`: Gets the application family.
- `VersionInstalled(AppID: Guid): Integer`: Gets the version which a given app was installed in.
- `CanStartSession(): Boolean`: Checks if a new session can be started via the Session.StartSession call.
- `EnableM365Collaboration()`: Sets M365 Collaboration to enabled in the tenant admin center
- `GetLinkedPowerPlatformEnvironmentId(): Text`: Gets the linked Power Platform environment id.
- `GetEnvironmentSetting(SettingName: Text): Text`: Gets the value of the specified environment setting. This is only callable from Microsoft published apps.
