## Procedures

- `SetResultCondition(Result: Text; Condition: Text; AllowError: Boolean): Boolean`: Set a specific result for the test. If AllowError is set to true it will error when a problem occurs. If AllowError is set to false it will just return false when a problem occurs.
- `AssistEditDefaultValue()`: Starts the appropriate 'assist edit' dialog for the given data type and conditions.
- `AssistEditFreeText()` (internal): Opens the large-text editor and stores the accepted default value.
- `AssistEditLookupTable()`: Looks up and validates the table used by a table lookup test.
- `AssistEditLookupField()`: Looks up and validates the field used by a table lookup test.
- `AssistEditLookupTableFilter()`: Edits the lookup table filter and refreshes the display summary of allowed values.
- `UpdateAllowedValuesFromTableLookup()`: This is basically to make a summary for the human to see more easily when configuring templates and tests. This data isn't actually used during execution.
- `CheckDeleteConstraints(AskQuestion: Boolean)`: Prevents deletion of tests used by inspections and confirms deletion of template lines that use the test.
- `SuggestUnusedTestCodeFromDescription(InputDescription: Text; var SuggestionCode: Code[20])` (internal): Generates an unused test code from a description.
- `SuggestUnusedTestCodeFromDescriptionAndList(InputDescription: Text; IgnoredListOptionalAdditionalUsed: List of [Text]; var SuggestionCode: Code[20])` (internal): Generates a test code unused by both stored tests and a supplied list.
- `GenerateShortTestCodeFromLongerText(Input: Text; var SuggestionCode: Code[20])` (internal): Removes punctuation and, when needed, vowels to form a test code within the target length.
- `ValidateAllowableValuesOnDefault()`: Validates that the default value is allowable.
- `ValidateAllowableValuesFormat()`: Validates that the allowable values expression is a valid filter for the test value type.
- `CollectAllowableValues(var TempBufferQltyTestLookupValue: Record "Qlty. Test Lookup Value" temporary; OptionalSetToValue: Text)`: Code = the unique code Description = raw description. Custom 1 = original value Custom 2 = lowercase value Custom 3 = uppercase value.
- `CollectAllowableValues(var OptionalContextQltyInspectionHeader: Record "Qlty. Inspection Header"; var OptionalContextQltyInspectionLine: Record "Qlty. Inspection Line"; var TempBufferQltyTestLookupValue: Record "Qlty. Test Lookup Value" temporary; OptionalSetToValue: Text)`: Collects table lookup or option values with optional inspection context and positions the buffer near a requested value.
- `AssistEditExpressionFormula()`: Edits and persists the expression formula for a text-expression test.
- `AssistEditAllowableValues()`: Edits custom lookup values or the allowable-values expression according to the test type.
- `IsNumericFieldType(): Boolean`: Returns true if the field type is numeric in nature.
