## Procedures

- `OpenSetupCard()`: Opens the setup card page for this payment service configuration. Allows users to modify provider-specific settings and parameters.
- `CreateReportingArgs(var PaymentReportingArgument: Record "Payment Reporting Argument"; DocumentRecordVariant: Variant)`: Creates payment reporting arguments for a specific document and its associated payment services. Generates the data needed for payment provider integration and customer communication.
- `GetDefaultPaymentServices(var SetID: Integer): Boolean`: Retrieves payment services configured to be always included on documents. Returns a set ID for enabled payment services that are set to be included by default.
- `SelectPaymentService(var SetID: Integer): Boolean`: Presents payment service selection dialog to user and returns the selected set ID. Handles the complete workflow for selecting payment services including setup prompts.
- `SaveSet(var TempPaymentServiceSetup: Record "Payment Service Setup" temporary): Integer`: Saves a temporary payment service setup collection as a persistent set. Converts temporary payment service records into a record set that can be referenced by ID.
- `LoadSet(var TempPaymentServiceSetup: Record "Payment Service Setup" temporary; SetID: Integer)`: Loads a payment service set into temporary records based on the provided set ID. Marks payment services as available based on their inclusion in the specified set.
- `GetSelectedPaymentsText(SetID: Integer): Text`: Returns a comma-separated text string of selected payment service names. Provides user-friendly display of payment services included in a set.
- `CanChangePaymentService(DocumentVariant: Variant): Boolean`: Determines if payment service configuration can be changed for a given document. Validates document status and payment method compatibility for payment service modifications.
- `ChangePaymentServicePostedInvoice(var SalesInvoiceHeader: Record "Sales Invoice Header")`: Enables changing payment service configuration for a posted sales invoice. Updates the payment service set ID on the posted invoice and provides user feedback.
- `IsPaymentServiceVisible(): Boolean`: Checks if payment services are available for display in user interfaces. Determines visibility of payment service functionality based on registered providers.
- `NewPaymentService(): Boolean`: Initiates creation of a new payment service through the setup workflow. Handles provider selection and setup dialog presentation to the user.
- `AssignPrimaryKey(var PaymentServiceSetup: Record "Payment Service Setup")`: Assigns the primary key for a payment service setup record based on its setup record ID. Ensures unique identification of payment service configurations.
- `DeletePaymentServiceSetup(RunTrigger: Boolean)`: Deletes the underlying payment service setup record referenced by the Setup Record ID. Performs cleanup of related configuration data when removing payment services.
- `TermsOfServiceDrillDown()`: Opens the Terms of Service URL in the default browser or application. Enables users to review payment service provider terms and conditions.
