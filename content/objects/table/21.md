## Procedures

- `GetLastEntryNo(): Integer`: Gets the entry number of the last customer ledger entry in the table.
- `ShowDoc(): Boolean`: Opens the appropriate posted document page based on the document type.
- `ShowPostedDocAttachment()`: Opens the document attachment details page for the posted document associated with this entry.
- `HasPostedDocAttachment(): Boolean`: Checks whether the posted document associated with this entry has any attachments.
- `DrillDownOnEntries(var DtldCustLedgEntry: Record "Detailed Cust. Ledg. Entry")`: Opens the Customer Ledger Entries page filtered by the specified detailed customer ledger entry filters.
- `DrillDownOnOverdueEntries(var DtldCustLedgEntry: Record "Detailed Cust. Ledg. Entry")`: Opens the Customer Ledger Entries page filtered to show only overdue entries.
- `GetOriginalCurrencyFactor(): Decimal`: Gets the original currency factor, returning 1 if not set.
- `GetAdjustedCurrencyFactor(): Decimal`: Gets the adjusted currency factor, returning 1 if not set.
- `ShowDimensions()`: Opens the Dimension Set Entries page showing the dimensions for this entry.
- `SetStyle(): Text`: Determines the visual style for displaying this entry based on its payment status.
- `SetApplyToFilters(CustomerNo: Code[20]; ApplyDocType: Option; ApplyDocNo: Code[20]; ApplyAmount: Decimal)`: Sets filters on the record to show entries that can be applied based on the specified criteria.
- `SetAmountToApply(AppliesToDocNo: Code[20]; CustomerNo: Code[20])`: Toggles the Amount to Apply field between the remaining amount and zero for the specified document.
- `CopyFromGenJnlLine(GenJnlLine: Record "Gen. Journal Line")`: Copies field values from a general journal line to this customer ledger entry.
- `CopyFromCVLedgEntryBuffer(var CVLedgerEntryBuffer: Record "CV Ledger Entry Buffer")`: Copies field values from a CV ledger entry buffer to this customer ledger entry.
- `RecalculateAmounts(FromCurrencyCode: Code[10]; ToCurrencyCode: Code[10]; PostingDate: Date)`: Recalculates amount fields from one currency to another using exchange rates at the specified posting date.
- `UpdateAmountsForApplication(ApplnDate: Date; ApplnCurrencyCode: Code[10]; RoundAmounts: Boolean; UpdateMaxPaymentTolerance: Boolean)`: Updates amount fields for application by converting to the application currency.
- `GetRemainingPmtDiscPossible(ReferenceDate: Date): Decimal`: Gets the remaining payment discount possible, allowing for customization through events.
