## Procedures

- `GetOrInsert()`: Retrieves existing settings record or creates a new one with default values. Ensures settings are always available for payment application processes by using singleton pattern with default configuration for new installations.
- `GetCandidateLookbackStartDate(ReferenceDate: Date): Date`: Calculates the earliest posting date to include when searching for candidate ledger entries. Returns 0D (no lower bound) when the lookback is not configured or no reference date is available.
