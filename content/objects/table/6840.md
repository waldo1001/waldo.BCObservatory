## Procedures

- `GetRemainingAmountLCY(): Decimal`: Returns the difference between estimated amount and actually spent amount
- `GetDocumentTypeDescription(): Text`
- `AssistEditNo(): Boolean`: Allows the user to select a number from another no. series.
- `TestStatusOpen()`: Ensures the spend request is still in the Open status, which is required before any field can be modified.
- `TestStatus(ExpectedStatus: Enum "Spend Request Status")`: Verifies the request has the expected status, using the document type in the error message.
- `ShowDocDim()`: Opens a page for editing dimensions for the sales header. If dimensions are changed, they're updated on the sales lines as well.
- `Approve()` (internal): Sets status to Approved and updates when and who approved.
- `Reject()` (internal): Sets status to Rejected and updates when and who rejected.
- `ValidateShortcutDimCode(FieldNumber: Integer; var ShortcutDimCode: Code[20])`: Verifies whether the provided shortcut dimension code and value are valid. If valid, assigns it to the sales document.
- `CreateDimFromDefaultDim(FieldNo: Integer)`: Initializes the dimensions for the document from default dimensions for the related entry specified in the field.
- `CreateDim(DefaultDimSource: List of [Dictionary of [Integer, Code[20]]])`: Creates and assigns dimensions for the sales header based on the provided default dimension sources.
- `AddToTotalExpectedAmount(DeltaLCY: Decimal)` (internal): Applies an incremental change to the Total Expected Amount and refreshes the LCY total using the document currency factor. Called by detail tables (generic or layer-specific) when their amounts change.
- `ChangeCurrency(xCurrencyCode: Code[10])` (internal)
- `UpdateCurrencyExchangeRate()` (internal)
- `ValidateSpendRequest(SpendRequestNo: Code[20]; var SpendRequestclose: Boolean; NewAmountLCY: Decimal)`: Validates that the spendrequest is approved, asks if should be closed and checks if there's room for the new amount
- `ValidateSpendRequest(SpendRequestNo: Code[20]; var SpendRequestclose: Boolean)`: Validates that the spendrequest is approved and asks if should be closed
- `SetSkipSpendRequestClose(NewSkipSpendRequestClose: Boolean)`: Sets whether the confirmation to close the spend request should be skipped during validation. When set to true, ValidateSpendRequest does not prompt to close the spend request.
- `CheckSpendRequestAmount(SpendRequestNo: Code[20]; NewAmountLCY: Decimal)`: Checks if there's room for the new amount (absolute value)
