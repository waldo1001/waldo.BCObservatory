## Procedures

- `GetCaptionClass(FieldNumber: Integer): Text[80]`: Returns the caption class string for the specified field number based on whether prices include VAT.
- `IsExtendedText(): Boolean`: Determines whether this line is an extended text line attached to another document line.
- `ShowDimensions()`: Opens the Dimension Set Entries page to display the dimensions associated with this archived sales line.
- `ShowLineComments()`: Opens the Sales Archive Comment Sheet page to display comments associated with this archived sales line.
- `ShowDeferrals()`: Opens the Deferral Schedule Archive page to display the deferral schedule for this archived sales line.
- `CopyTempLines(SalesHeaderArchive: Record "Sales Header Archive"; var TempSalesLine: Record "Sales Line" temporary)`: Copies archived sales lines to a temporary sales line record set for use in document restoration.
