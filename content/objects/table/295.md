- `PrintRecords()`: Prints the reminder test report for the current record.
- `ConfirmDeletion(): Boolean`: Prompts the user to confirm deletion of the reminder and warns about number series gaps.
- `CreateDim(DefaultDimSource: List of [Dictionary of [Integer, Code[20]]])`: Creates dimensions for the reminder header based on the provided dimension sources.
- `ValidateShortcutDimCode(FieldNumber: Integer; var ShortcutDimCode: Code[20])`: Validates and updates a shortcut dimension code on the reminder header.
- `GetInvoiceRoundingAmount(): Decimal`: Calculates the invoice rounding amount for the reminder based on currency settings.
- `UpdateReminderRounding(ReminderHeader: Record "Reminder Header")`: Updates the invoice rounding line for the reminder by recalculating the rounding amount.
- `ShowDocDim()`: Opens a dialog to view and edit the document dimensions for the reminder.
- `CalculateLineFeeVATAmount(): Decimal`: Calculates the total VAT amount for line fee type reminder lines.
- `SetAllowSelectNoSeries()`: Enables the option to select from related number series when creating a reminder.
- `SetCustomerFromFilter()`: Sets the customer number from the current filter if a single customer is filtered.
- `SetReminderNo()`: Assigns the next reminder number from the number series if no number is set.
- `CreateDimFromDefaultDim()`: Creates dimensions for the reminder header using the default dimension sources.
