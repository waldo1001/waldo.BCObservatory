## Procedures

- `PrepareSales(SalesLine: Record "Sales Line"; DocumentNo: Code[20])`: Prepares the deferral posting buffer for sales line posting. Initializes buffer fields with sales line dimensions and tax information.
- `ReverseAmounts()`: Reverses the signs of all amount fields in the posting buffer. Used for credit transactions and corrections.
- `PreparePurch(PurchLine: Record "Purchase Line"; DocumentNo: Code[20])`: Prepares the deferral posting buffer for purchase line posting. Initializes buffer fields with purchase line dimensions and tax information.
- `PrepareRemainderSales(SalesLine: Record "Sales Line"; NewAmountLCY: Decimal; NewAmount: Decimal; GLAccount: Code[20]; DeferralAccount: Code[20]; DeferralLineNo: Integer)`: Prepares the deferral posting buffer for remainder sales amounts. Handles partial deferrals where only part of the line amount is deferred.
- `PrepareRemainderPurchase(PurchaseLine: Record "Purchase Line"; NewAmountLCY: Decimal; NewAmount: Decimal; GLAccount: Code[20]; DeferralAccount: Code[20]; DeferralLineNo: Integer)`: Prepares the deferral posting buffer for remainder purchase amounts. Handles partial deferrals where only part of the line amount is deferred.
- `PrepareInitialAmounts(AmountLCY: Decimal; AmountACY: decimal; RemainAmtToDefer: Decimal; RemainAmtToDeferACY: Decimal; GLAccount: Code[20]; DeferralAccount: Code[20])`: Prepares initial amounts for deferral posting buffer. Overload method without discount parameters.
- `PrepareInitialAmounts(AmountLCY: Decimal; AmountACY: decimal; RemainAmtToDefer: Decimal; RemainAmtToDeferACY: Decimal; GLAccount: Code[20]; DeferralAccount: Code[20]; DiscountAmount: Decimal; DiscountAmountACY: Decimal)`: Prepares initial amounts for deferral posting buffer including discount handling. Extended version with discount amount parameters.
- `InitFromDeferralLine(DeferralLine: Record "Deferral Line")`: Initializes the posting buffer from a deferral line record. Copies amounts, dates, and description from the deferral line.
- `Update(DeferralPostBuffer: Record "Deferral Posting Buffer")`: Updates an existing deferral posting buffer record with values from another buffer. Accumulates amounts if a matching record exists, otherwise creates a new record.
- `GetLastEntryNo(): Integer`: Gets the last entry number used in the deferral posting buffer table. Used for assigning sequential entry numbers to new buffer records.

Plus 2 local procedures.
