## Procedures

- `CreateSalesInvoice(OrderDate: Date; PostingDate: Date)`: Creates a sales invoice using the standard sales code for the customer.
- `InsertSalesLines(var SalesHeader: Record "Sales Header")`: Opens a page to select standard customer sales codes and inserts the selected lines into the sales header.
- `ApplyStdCodesToSalesLines(var SalesHeader: Record "Sales Header"; StdCustSalesCode: Record "Standard Customer Sales Code")`: Applies the standard sales code lines to the sales document.
- `InsertExtendedText(SalesLine: Record "Sales Line")`: Inserts extended text for a sales line if applicable.
- `InsertExtendedText(SalesLine: Record "Sales Line"; SalesHeader: Record "Sales Header")`: Inserts extended text for a sales line using the sales header context.
- `GetNextLineNo(SalesLine: Record "Sales Line"): Integer`: Gets the next available line number for a sales document.
- `SetFilterByAutomaticAndAlwaysAskCodes(SalesHeader: Record "Sales Header")`: Sets filters on the record to find standard sales codes that should be automatically or always-ask inserted.
- `IsInsertRecurringLinesOnDocumentAutomatic(SalesHeader: Record "Sales Header"): Boolean`: Checks if recurring lines should be automatically inserted for the document type.
- `ShouldAutoInsertRecurringLinesOnDocument(SalesHeader: Record "Sales Header"): Boolean`: Checks if recurring lines should be auto-inserted (automatic or always-ask) for the document type.
