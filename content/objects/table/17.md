## Procedures

- `GetAdditionalReportingCurrencyCode(): Code[10]`
- `GetNextEntryNo(): Integer`
- `GetLastEntryNo(): Integer`: Gets the highest entry number from the G/L Entry table.
- `GetLastEntry(var LastEntryNo: Integer; var LastTransactionNo: Integer)`: Gets the last entry number and transaction number from the G/L Entry table.
- `GetCurrencyCode(): Code[10]` (obsolete 27.0: use GetAdditionalReportingCurrencyCode instead): Gets the additional reporting currency code from General Ledger Setup.
- `ShowValueEntries()`: Opens the Value Entries page showing item ledger entries related to this G/L entry.
- `ShowDimensions()`: Opens the Dimension Set Entries page showing dimensions for this G/L entry.
- `UpdateDebitCredit(Correction: Boolean)`: Updates debit and credit amounts based on the amount and correction flag.
- `CopyFromGenJnlLine(GenJnlLine: Record "Gen. Journal Line")`: Copies values from General Journal Line to G/L Entry fields.
- `CopyPostingGroupsFromGLEntry(GLEntry: Record "G/L Entry")`: Copies posting groups from another G/L Entry record.
- `CopyPostingGroupsFromVATEntry(VATEntry: Record "VAT Entry")`: Copies posting groups from VAT Entry record.
- `CopyPostingGroupsFromGenJnlLine(GenJnlLine: Record "Gen. Journal Line")`: Copies posting groups from General Journal Line record.
- `CopyPostingGroupsFromDtldCVBuf(DtldCVLedgEntryBuf: Record "Detailed CV Ledg. Entry Buffer"; GenPostingType: Option " ",Purchase,Sale,Settlement)`: Copies posting groups from Detailed CV Ledger Entry Buffer record.
- `CopyFromDeferralPostBuffer(DeferralPostBuffer: Record "Deferral Posting Buffer")`: Copies values from Deferral Posting Buffer to G/L Entry fields.
- `UpdateAccountID()`: Updates the Account ID field based on the G/L Account No.
