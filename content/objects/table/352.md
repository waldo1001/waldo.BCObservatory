## Procedures

- `GetCaption(): Text[250]`: Generates a descriptive caption for the default dimension record. Returns a formatted text showing the table name and record number for user identification.
- `UpdateGlobalDimCode(GlobalDimCodeNo: Integer; TableID: Integer; AccNo: Code[20]; NewDimValue: Code[20])`: Updates global dimension codes in master data records when default dimension values change. Synchronizes global dimension values across tables when dimension posting requirements change.
- `ClearAllowedValuesFilter(var DimValuePerAccount: Record "Dim. Value per Account")`: Clears the allowed values filter and related dimension value per account records. Called when changing from Code Mandatory posting type to allow unrestricted dimension value selection.
- `CreateDimValuePerAccountFromDimValue(DimValue: Record "Dimension Value"; ShouldUpdateAllowed: Boolean)`: Creates or updates a dimension value per account record from a dimension value. Sets the Allowed flag to the value of ShouldUpdateAllowed.
- `AddDimensionValueToAllowedFilter(DimValueCode: Code[20])`: Adds a dimension value to the allowed values filter without rebuilding from Dim. Value per Account records. Appends the value code to the filter text if not already covered by the existing filter.
- `IncludedInAllowedValuesFilter(DimValuePerAccount: Record "Dim. Value per Account"): Boolean`: Checks whether a dimension value per account record is included in the allowed values filter. Returns true if the dimension value matches the current allowed values filter criteria.
- `UpdateDimValuesPerAccountFromAllowedValuesFilter(var DimValuePerAccount: Record "Dim. Value per Account")`: Updates dimension values per account records based on the allowed values filter. Synchronizes the allowed dimension values list with the current filter criteria.
- `CheckDisallowedDimensionValue(DimValuePerAccount: Record "Dim. Value per Account")`: Validates that a dimension value is not disallowed for use with this default dimension. Prevents assignment of dimension values that are restricted by the allowed values filter.
- `UpdateDefaultDimensionAllowedValuesFilter()`: Updates the allowed values filter field based on currently allowed dimension values. Rebuilds the filter string from dimension value per account records marked as allowed.
- `GetAllowedValuesFilter(): Text[250]`: Returns the allowed values filter as a text string truncated to field length. Provides the current filter that restricts dimension value selection for this default dimension.
- `GetFullAllowedValuesFilter(var DimValuePerAccount: Record "Dim. Value per Account"): Text`: Returns the complete allowed values filter without length restrictions. Generates a filter string from all allowed dimension values for this default dimension.
- `UpdateParentType(): Boolean`: Updates the parent type field based on the current table ID. Maps specific table IDs to their corresponding parent type enum values.
- `UpdateParentId(): Boolean`: Updates the parent ID field based on the current table ID and record number. Links the default dimension to the correct master data record using system IDs.
- `UpdateReferencedIds()`: Updates all referenced ID fields and modifies the record if any changes occurred. Ensures system IDs are synchronized with the current dimension and parent record references.
- `UpdateReferencedIdFields(): Boolean`: Updates all referenced ID fields and returns whether any changes were made. Coordinates updates to parent ID, parent type, dimension ID, and dimension value ID fields.
