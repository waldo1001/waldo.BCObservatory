## Procedures

- `ShowDimensions()`: Opens the dimension management page to display dimensions associated with this entry.
- `CopyFromGenJnlLine(GenJnlLine: Record "Gen. Journal Line")`: Copies field values from a general journal line to populate this bank account ledger entry. Transfers standard fields and dimensions, then raises integration event for customization.
- `UpdateDebitCredit(Correction: Boolean)`: Updates the debit and credit amount fields based on the transaction amount and correction flag. Positive amounts become debits, negative amounts become credits, with correction logic applied.
- `GetAppliedStatementNo(): Code[20]`: Retrieves the statement number associated with this entry if it has been applied to a bank statement. Checks for applied check entries or direct bank account entry application status.
- `IsApplied(): Boolean`: Determines whether this bank account ledger entry has been applied to a bank statement.
- `SetStyle(): Text`: Determines the visual style to apply to this entry in list displays. Applied entries receive favorable styling to indicate their reconciled status.
- `SetFilterBankAccNoOpen(BankAccNo: Code[20])`: Applies filters to show only open entries for a specific bank account. Resets all existing filters and sets up optimized key and filtering for open entry retrieval.
- `CopyFromBankAccLedgerEntry(BankAccountLedgerEntry: Record "Bank Account Ledger Entry"; StatementNo: Code[20])`: Creates a new bank account ledger entry by copying key fields from an existing entry. Used for creating related entries with specific statement association during reconciliation processes.
- `SetBankReconciliationCandidatesFilter(BankAccReconciliation: Record "Bank Acc. Reconciliation")`: Sets filters on the record to find potential candidates for bank reconciliation matching. Filters for open, non-reversed entries with remaining amounts within the reconciliation date range.
