## Procedures

- `GetLatestStateRecord(var PowerBIDeploymentState: Record "Power BI Deployment State"): Boolean`: Retrieves the latest deployment state record. Returns false if none exists.
- `GetLatestCompletedState(): Record "Power BI Deployment State"`: Retrieves the latest completed deployment state record. Returns an empty record if there's none
- `GetUploadStatus(): Enum "Power BI Upload Status"`: Derives the current upload status from the latest Power BI Deployment State record. This is the single source of truth for deployment status.
- `FailCurrentStep(FailedReason: Text; FailedCallstack: Text)`: Marks the latest state record as failed with the given reason. If no state record exists yet (e.g. the very first step failed before any transition), creates one with Status Reached = NotStarted so the failure is never silently lost.
- `ResetDeployment()`: Resets a deployment by deleting all state records. After this, GetUploadStatus() returns NotStarted and the aggregator will include the report as pending work for re-deployment. Used both for retrying failed deployments and for applying version updates.
- `GetDeploymentStatus(): Enum "Power BI Deployment Status"`
- `GetDeploymentOutcome(DeploymentStatus: Enum "Power BI Deployment Status"): Enum "Power BI Deployment Outcome"`
- `QueueForDeployment(ReportId: Enum "Power BI Deployable Report")` (internal)
- `DeleteAllRecords()`: Wipes all local deployment tracking data for the current company across every deployable report. Reports already uploaded to the Power BI workspace are not touched.
- `DeleteAllRecords(InCompany: Text[30])`: Wipes all local deployment tracking data in the specified company. Used by subscribers that need to clear records in a different company than the caller's (e.g. after Copy Company, where the subscriber runs in the source company but must wipe the target).
- `RecordStep(NewStatus: Enum "Power BI Upload Status")`: Creates a new state record for the given status.
