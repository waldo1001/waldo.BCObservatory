## Procedures

- `GetTargetURL(): Text`: Retrieves the target URL from the BLOB field as a text string. Extracts the payment service URL for use in web requests and redirects.
- `SetTargetURL(ServiceURL: Text)`: Sets the target URL by storing it in the BLOB field after validation. Validates that the URL is properly formatted and uses HTTP/HTTPS protocol.
- `TrySetTargetURL(ServiceURL: Text)`: Attempts to set the target URL with error handling. Returns success/failure status without throwing exceptions.
- `GetCurrencyCode(CurrencyCode: Code[10]): Code[10]`: Returns the currency code, defaulting to local currency if not specified. Ensures a valid currency code is always available for payment processing.
- `GetPayPalServiceID(): Integer`: Returns the service identifier for PayPal payment processing. Used to identify PayPal as the selected payment service provider.
- `GetMSWalletServiceID(): Integer`: Returns the service identifier for Microsoft Wallet payment processing. Used to identify Microsoft Wallet as the selected payment service provider.
- `GetWorldPayServiceID(): Integer`: Returns the service identifier for WorldPay payment processing. Used to identify WorldPay as the selected payment service provider.
- `GetPayPalLogoFile(): Text`: Returns the filename for the PayPal logo image resource. Used for displaying PayPal branding in payment interfaces.
- `GetMSWalletLogoFile(): Text`: Returns the filename for the Microsoft Wallet logo image resource. Used for displaying Microsoft branding in payment interfaces.
- `GetWorldPayLogoFile(): Text`: Returns the filename for the WorldPay logo image resource. Used for displaying WorldPay branding in payment interfaces.
