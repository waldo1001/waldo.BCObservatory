## Procedures

- `InitRoundingPrecision()`: Initializes currency rounding precision fields with values from General Ledger Setup. Sets default values for Amount Rounding Precision, Unit-Amount Rounding Precision, Invoice Rounding settings, VAT settings, and raises the OnAfterInitRoundingPrecision event.
- `GetExchangeRate(ConversionDate: Date): Decimal`: Retrieves the most recent exchange rate for the actual currency, based on 1FCY. If no exchange rate is specified, it returns 1
- `VATRoundingDirection(): Text[1]`: Returns the directional symbol for VAT rounding based on the VAT Rounding Type setting. Used in rounding calculations to determine rounding behavior.
- `InvoiceRoundingDirection(): Text[1]`: Returns the directional symbol for invoice rounding based on the Invoice Rounding Type setting. Used in invoice rounding calculations to determine rounding behavior.
- `CheckAmountRoundingPrecision()`: Validates that required rounding precision fields are properly set. Ensures both Unit-Amount Rounding Precision and Amount Rounding Precision have values.
- `GetGainLossAccount(DtldCVLedgEntryBuf: Record "Detailed CV Ledg. Entry Buffer"): Code[20]`: Determines the appropriate G/L account for posting currency gain/loss based on entry type. Routes to specific account getter methods based on the type of gain/loss being processed. Raises OnBeforeGetGainLossAccount event for customization opportunities.
- `GetRealizedGainsAccount(): Code[20]`: Returns the G/L account for posting realized currency gains. Validates that the account is specified before returning it.
- `GetRealizedLossesAccount(): Code[20]`: Returns the G/L account for posting realized currency losses. Validates that the account is specified before returning it.
- `GetRealizedGLGainsAccount(): Code[20]`: Returns the G/L account for posting realized currency gains on G/L transactions. Validates that the account is specified before returning it.
- `GetRealizedGLLossesAccount(): Code[20]`: Returns the G/L account for posting realized currency losses on G/L transactions. Validates that the account is specified before returning it.
- `GetResidualGainsAccount(): Code[20]`: Returns the G/L account for posting residual currency gains. Validates that the account is specified before returning it.
- `GetResidualLossesAccount(): Code[20]`: Returns the G/L account for posting residual currency losses. Validates that the account is specified before returning it.
- `GetUnrealizedGainsAccount(): Code[20]`: Returns the G/L account for posting unrealized currency gains. Validates that the account is specified before returning it.
- `GetUnrealizedLossesAccount(): Code[20]`: Returns the G/L account for posting unrealized currency losses. Validates that the account is specified before returning it.
- `GetConvLCYRoundingDebitAccount(): Code[20]`: Returns the G/L account for posting debit rounding differences during LCY conversion. Validates that the account is specified before returning it.
- `GetConvLCYRoundingCreditAccount(): Code[20]`: Returns the G/L account for posting credit rounding differences during LCY conversion. Validates that the account is specified before returning it.
- `GetCurrencySymbol(): Text[10]`: Gets the display symbol for this currency, falling back to the currency code if no symbol is defined.
- `ResolveCurrencySymbol(CurrencyCode: Code[10]): Text[10]`: Resolves an appropriate display symbol for a given currency code. First checks if the currency record has a custom symbol, then falls back to built-in symbol mappings for common currencies. Raises OnBeforeResolveCurrencySymbol event for customization.
- `ResolveCurrencyDescription(CurrencyCode: Code[10]): Text`: Resolves a descriptive name for a given currency code. First checks if the currency record has a custom description, then falls back to built-in description mappings for common currencies.
- `ResolveGLCurrencySymbol(CurrencyCode: Code[10]): Text[10]`: Resolves the currency symbol for use in General Ledger contexts. If a currency code is provided, resolves its symbol. If empty, returns the LCY symbol from GL Setup.
- `Initialize(CurrencyCode: Code[10])`: Initializes the currency record by loading it if a currency code is provided. If no currency code is provided, initializes rounding precision from GL Setup. This is an overload that calls the full Initialize method with CheckAmountRoundingPrecision set to false.
- `Initialize(CurrencyCode: Code[10]; CheckAmountRoundingPrecision: Boolean)`: Initializes the currency record by loading it if a currency code is provided. If no currency code is provided, initializes rounding precision from GL Setup. Optionally validates that Amount Rounding Precision is properly set.
- `SuggestSetupAccounts()`: Suggests appropriate G/L accounts for currency posting based on existing currency setups. Analyzes other currency records to suggest commonly used accounts for gain/loss posting. Shows a message if no suggestions can be made.
- `CheckDuplicateCurrencySymbol(CurrencySymbol: Text[10])`
