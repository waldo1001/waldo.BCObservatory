## Procedures

- `UpdatePresentationOrder()`: Updates the hierarchical presentation order and indentation level based on the category's position in the tree structure. Calculates the sort order for proper display sequence in financial reports and user interfaces.
- `InitializeDataSet()`: Initializes the account category dataset with standard financial statement structure. Creates default categories for Assets, Liabilities, Equity, Income, Cost of Goods Sold, and Expenses.
- `InsertRow(): Integer`: Creates a new account category as a sibling of the current category with default settings. Returns the entry number of the newly created category for further processing.
- `MoveUp()`: Moves the current account category up one position in the sibling sequence within the same parent level. Updates presentation order and descendant categories accordingly.
- `MoveDown()`: Moves the current account category down one position in the sibling sequence within the same parent level. Updates presentation order and descendant categories accordingly.
- `MakeChildOfPreviousSibling()`: Changes the current category to become a child of its previous sibling category. Restructures the hierarchy by moving the category down one level in the tree.
- `MakeSiblingOfParent()`: Changes the current category to become a sibling of its parent category. Restructures the hierarchy by moving the category up one level in the tree.
- `DeleteRow()`: Deletes the current category and all its child categories from the hierarchy. Removes associated account assignments and updates related financial reports.
- `MapAccounts()`: Maps general ledger accounts to this category (placeholder for future implementation). Provides extension point for custom account mapping logic.
- `ValidateTotaling(NewTotaling: Text)`: Validates and assigns a new totaling filter for general ledger accounts in this category. Updates account assignments and clears previous totaling assignments as needed.
- `LookupTotaling()`: Opens a lookup page to select G/L accounts for the Totaling field. Provides a filtered view based on the category's Income/Balance setting.
- `PositiveNormalBalance(): Boolean`: Determines if the account category has a positive normal balance. Returns true for Expense, Assets, and Cost of Goods Sold categories.
- `GetBalance(): Decimal`: Calculates the total balance for this account category including all child categories. Processes both totaling accounts and hierarchical child categories.
- `GetTotaling(): Text[250]`: Gets the totaling filter string for this account category. Returns the account filter used for calculating category totals.
- `ShowNotificationAccSchedUpdateNeeded()`: Shows a notification that account schedules need to be updated when categories change. Helps maintain consistency between account categories and financial reporting.
- `GetAccSchedUpdateNeededNotificationId(): Guid`: Returns the unique identifier for the account schedule update needed notification. Used for notification management and user preferences.
- `DontNotifyCurrentUserAgain(NotificationID: Guid)`: Disables the account schedule update notification for the current user. Allows users to opt out of future notifications about category updates.
