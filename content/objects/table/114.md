## Procedures

- `SendRecords()`: Sends the credit memo records using the customer's document sending profile.
- `SendProfile(var DocumentSendingProfile: Record "Document Sending Profile")`: Sends the credit memo using a specific document sending profile.
- `StartTrackingSite()`: Opens the shipping agent's tracking website for this return shipment.
- `PrintRecords(ShowRequestPage: Boolean)`: Prints the selected credit memo records.
- `CheckNoPrinted()`: Validates that the credit memo has been printed at least once.
- `EmailRecords(ShowRequestPage: Boolean)`: Sends the credit memo records by email.
- `PrintToDocumentAttachment(var SalesCrMemoHeader: Record "Sales Cr.Memo Header")`: Prints the credit memos and saves them as document attachments.
- `Navigate()`: Opens the Navigate page to show related entries for this credit memo.
- `LookupAdjmtValueEntries()`: Opens a page showing value entries with adjustments for this credit memo.
- `GetCustomerVATRegistrationNumber(): Text`: Gets the customer's VAT registration number.
- `GetCustomerVATRegistrationNumberLbl(): Text`: Gets the label for the VAT registration number field.
- `GetLegalStatement(): Text`: Gets the legal statement from sales setup for printing on credit memos.
- `ShowDimensions()`: Shows the dimension set entries for this credit memo.
- `SetSecurityFilterOnRespCenter()`: Sets a security filter based on the user's responsibility center.
- `GetDocExchStatusStyle(): Text`: Gets the style class for displaying the document exchange status.
- `ShowActivityLog()`: Shows the activity log entries for this credit memo.
- `DocExchangeStatusIsSent(): Boolean`: Checks if the credit memo has been sent via document exchange.
- `ShowCanceledOrCorrInvoice()`: Shows the invoice that was canceled or corrected by this credit memo.
- `ShowCorrectiveInvoice()`: Opens the invoice that corrected this cancelled credit memo.
- `ShowCancelledInvoice()`: Opens the invoice that was cancelled by this corrective credit memo.
- `GetWorkDescription(): Text`: Retrieves the work description text from the BLOB field.
