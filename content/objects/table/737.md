- `CopyToVATReturn(var VATReportHeader: Record "VAT Report Header")`: Copies VAT return period information to a VAT report header. Sets period dates, year, and number for VAT return creation.
- `FindVATPeriodByDate(VATReportingDate: Date): Boolean` (internal): Finds VAT period containing the specified reporting date. Filters by start and end date range.
- `FindVATReturnPeriod(var VATReturnPeriod: Record "VAT Return Period"; StartDate: Date; EndDate: Date): Boolean`: Finds VAT return period matching the specified start and end dates. Used to locate existing periods for validation and processing.
- `DiffersFromVATReturnPeriod(var VATReturnPeriod: Record "VAT Return Period"): Boolean`: Compares current period with another VAT return period for differences. Checks due date, status, received date, and period key for changes.
- `DrillDownVATReturn()`: Opens VAT return card for the current period. Creates new VAT return if none exists for open periods.
- `CheckOpenOrOverdue(): Text`: Calculates and returns status text for open or overdue VAT periods. Provides due date warnings and overdue notifications based on setup.
