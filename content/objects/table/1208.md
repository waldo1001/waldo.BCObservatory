## Procedures

- `CreateNew(DirectDebitCollectionNo: Integer; CustLedgerEntry: Record "Cust. Ledger Entry")`: Creates a new direct debit collection entry based on a customer ledger entry.
- `DeletePaymentFileErrors()`: Removes payment file errors associated with this collection entry.
- `HasPaymentFileErrors(): Boolean`: Checks if any payment file errors exist for this collection entry.
- `ExportSEPA()`: Initiates SEPA direct debit export process for this collection entry.
- `InsertPaymentFileError(Text: Text)`: Creates a payment file error entry with specified text.
- `InsertPaymentFileErrorWithDetails(ErrorText: Text; AddnlInfo: Text)`: Creates a payment file error entry with additional details.
- `Reject()`: Rejects the collection entry and rolls back the mandate sequence type if applicable.
- `GetAmountInActiveCollections(): Decimal`: Calculates the total amount already allocated to other active collections for the same customer ledger entry.
- `SetTodayAsTransferDateForOverdueEnries()`: Updates transfer dates to today for all overdue entries in the same collection.
