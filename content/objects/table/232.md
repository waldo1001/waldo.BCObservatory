## Procedures

- `SetupNewBatch()`: Sets up a new journal batch with default values from the journal template. Copies configuration settings like balancing account, number series, and reason codes from the template.
- `LinesExist(): Boolean`: Checks whether any journal lines exist for this journal batch. Used for validation before allowing batch deletion or modification.
- `GetBalance(): Decimal`: Calculates the total balance of all journal lines in this batch. Returns the sum of Balance (LCY) field for all lines in the batch.
- `CheckBalance(): Decimal`: Checks the balance of the journal batch and triggers appropriate events. Calls OnGeneralJournalBatchBalanced if balanced, OnGeneralJournalBatchNotBalanced if not.
- `UpdateBalAccountId()`: Updates the Bal. Account Id field based on the current balancing account number and type. Synchronizes the system ID field with the referenced G/L Account record.
