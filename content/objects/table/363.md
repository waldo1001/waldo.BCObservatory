## Procedures

- `AnalysisViewReset()`: Resets the analysis view by clearing all analysis view entries and resetting tracking fields.
- `CheckDimensionIsTracked(DimensionCode: Code[20]): Boolean`: Checks if a specified dimension code is tracked by any of the four dimension code fields in the analysis view.
- `CheckDimensionsAreRetained(ObjectType: Integer; ObjectID: Integer; OnlyIfIncludeBudgets: Boolean)`: Validates that required dimensions are retained for specified objects in analysis views.
- `CheckViewsAreUpdated()`: Checks if all analysis views are updated with the latest transaction data and prompts for update if needed.
- `UpdateAllAnalysisViews(ShowWindow: Boolean)`: Updates all analysis views in the system, optionally showing a progress window.
- `UpdateLastEntryNo()`: Updates the last entry number for all non-blocked analysis views to the latest G/L entry number.
- `ValidateDelete(FieldName: Text)`: Validates that the user confirms deletion of analysis view data when modifying configuration fields.
- `AnalysisViewBudgetReset()`: Resets the analysis view budget entries by deleting all budget entries and resetting the last budget entry number.
- `ValidateModify(FieldName: Text)`: Validates that the user confirms modification of analysis view data when changing configuration fields.
- `CopyAnalysisViewFilters(ObjectType: Integer; ObjectID: Integer; AnalysisViewCode: Code[10])`: Copies analysis view dimension filters to selected dimensions for a specified object.
- `CheckIfLastEntryOrDateIsSet(): Boolean`: Checks if the analysis view has been configured with last entry tracking or last date updated.
- `SetUpdateOnPosting(NewUpdateOnPosting: Boolean)`: Sets the Update on Posting field for all analysis views to the specified value.
- `SetSkipConfirmationDialogue()`: Sets a flag to skip confirmation dialogues during analysis view operations.
- `RunAnalysisByDimensionPage()`: Opens the Analysis by Dimensions page for the current analysis view.
- `ShowResetNeededNotification()`: Shows a notification to the user indicating that the analysis view needs to be reset.
