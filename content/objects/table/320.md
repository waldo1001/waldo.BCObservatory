## Procedures

- `GetSalesAccount(Unrealized: Boolean): Code[20]`: Returns the appropriate sales tax G/L account based on realization status.
- `GetPurchAccount(Unrealized: Boolean): Code[20]`: Returns the appropriate purchase tax G/L account based on realization status.
- `GetRevChargeAccount(Unrealized: Boolean): Code[20]`: Returns the appropriate reverse charge G/L account based on realization status.
- `CreateTaxJurisdiction(NewJurisdictionCode: Code[10])`: Creates a new tax jurisdiction with the specified code and default account setup.
- `GetDescriptionInCurrentLanguageFullLength(): Text[100]`: Returns the tax jurisdiction description in the user's current language. Falls back to the default description if no translation is available.
- `GetName(): Text[30]`: Returns the jurisdiction name, defaulting to the code if name is empty.
