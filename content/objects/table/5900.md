## Procedures

- `AssistEdit(OldServHeader: Record "Service Header"): Boolean`: Lists all related number series for service header when creating new record.
- `CreateDim(DefaultDimSource: List of [Dictionary of [Integer, Code[20]]])`: Generates new dimension set id from provided default dimensions for the current service header.
- `UpdateAllLineDim(NewParentDimSetID: Integer; OldParentDimSetID: Integer)`
- `ValidateShortcutDimCode(FieldNumber: Integer; var ShortcutDimCode: Code[20])`: Triggers validation of shortcut dimension values.
- `UpdateCurrencyFactor()`: Updates value of the field 'Currency Factor' for the current service header.
- `RecreateServLines(ChangedFieldName: Text[100])`: Recalculates existing service lines related to current service header based on new values from hader.
- `ConfirmCurrencyFactorUpdate()`
- `UpdateServLinesByFieldNo(ChangedFieldNo: Integer; AskQuestion: Boolean)`: Propagates changes for specific fields provided by 'ChangedFieldNo' to service lines related to current service header.
- `TestMandatoryFields(var PassedServLine: Record "Service Line")`: Verify if all necessary fields are populated for provided service lines based on service management setup.
- `UpdateResponseDateTime()`: Updates values of 'Response Date' and 'Response Time' based on related service item line.
- `ServItemLineExists(): Boolean`: Checks if service item line exists for current service header record.
- `ServLineExists(): Boolean`: Checks if service line exists for current service header record.
