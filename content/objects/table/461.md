## Procedures

- `IncrAmounts(PrepmtInvLineBuf: Record "Prepayment Inv. Line Buffer")`: Increments amounts in the current record with amounts from another prepayment invoice line buffer. Adds all financial amounts including VAT, base amounts, and discount amounts.
- `ReverseAmounts()`: Reverses all amounts in the current record by changing signs. Used for creating credit memo entries or reversing prepayment entries.
- `SetAmounts(AmountLCY: Decimal; AmountInclVAT: Decimal; VATBaseAmount: Decimal; AmountACY: Decimal; VATBaseAmountACY: Decimal; VATDifference: Decimal)`: Sets the financial amounts for the prepayment invoice line buffer. Updates amount, VAT amounts, and base amounts in both LCY and ACY.
- `InsertInvLineBuffer(PrepmtInvLineBuf2: Record "Prepayment Inv. Line Buffer")`: Inserts or updates a prepayment invoice line buffer record. If record exists, increments amounts; otherwise inserts new record.
- `CopyWithLineNo(PrepmtInvLineBuf: Record "Prepayment Inv. Line Buffer"; LineNo: Integer)`: Copies a prepayment invoice line buffer record with a new line number. Creates a new record with the specified line number.
- `CopyFromPurchLine(PurchLine: Record "Purchase Line")`: Copies posting group information from a purchase line to the prepayment buffer. Transfers VAT and posting group settings for prepayment processing.
- `CopyFromSalesLine(SalesLine: Record "Sales Line")`: Copies posting group information from a sales line to the prepayment buffer. Transfers VAT and posting group settings for prepayment processing.
- `SetFilterOnPKey(PrepmtInvLineBuf: Record "Prepayment Inv. Line Buffer")`: Sets filters on the primary key fields of the prepayment invoice line buffer. Used for finding existing records with matching key values.
- `FillAdjInvLineBuffer(PrepmtInvLineBuf: Record "Prepayment Inv. Line Buffer"; GLAccountNo: Code[20]; CorrAmount: Decimal; CorrAmountACY: Decimal)`: Fills the buffer with adjustment invoice line data for amount corrections. Creates adjustment entries for prepayment amount differences.
- `FillFromGLAcc(CompressPrepayment: Boolean)`: Fills the buffer with G/L account information for prepayment processing. Copies posting group information from the specified G/L account.
- `AdjustVATBase(VATAdjustment: array[2] of Decimal)`: Adjusts VAT base amount and VAT amount based on provided adjustment values. Recalculates amount including VAT after adjustments.
- `AmountsToArray(var VATAmount: array[2] of Decimal)`: Converts buffer amounts to an array format for processing. Returns base amount and VAT amount in array elements.
- `CompressBuffer()`: Compresses multiple buffer lines with same key into consolidated entries. Combines amounts for lines with identical posting group and dimension combinations.
- `UpdateVATAmounts()`: Updates VAT amounts based on VAT posting setup and calculated percentages. Recalculates VAT amount in both local and additional reporting currency.
- `GetVATPct(): Decimal` (internal)
