## Procedures

- `ValidateVATRates(): Boolean`: Validates that at least one non-default VAT setup posting group is selected for configuration. Used by VAT setup process to ensure user has made meaningful selections.
- `PopulateVATProdGroups()`: Populates working VAT product posting group records from default templates for setup configuration. Creates non-default copies of default templates for user modification during VAT setup process.
- `AddOrUpdateProdPostingGrp(ProdGrpCode: Code[20]; GrpDesc: Text[100]; VatRate: Decimal; SalesAccount: Code[20]; PurchAccount: Code[20]; IsService: Boolean; IsDefault: Boolean): Boolean`: Adds or updates a VAT product posting group template with specified configuration parameters. Creates new template or modifies existing one with VAT rate, account assignments, and classification.
- `CheckExistingItemAndServiceWithVAT(VATProdPostingGroupCode: Code[20]; IsService: Boolean): Boolean`: Checks whether existing items or services are already configured with the specified VAT product posting group. Validates impact of VAT configuration changes on existing master data.
- `ValidateGLAccountsExist(var ErrorMessage: Text): Boolean`: Validates that all selected VAT posting group templates have valid G/L account assignments. Ensures VAT setup completion by checking required account configurations for posting.
- `GetLabelTok(LabelName: Text): Code[20]`: Retrieves predefined label token codes used for standard VAT product posting group setup. Provides consistent codes for creating standardized VAT configurations across implementations.
- `GetLabelTxt(LabelName: Text): Text[100]`: Retrieves predefined label text descriptions used for standard VAT product posting group setup. Provides consistent descriptions for creating standardized VAT configurations across implementations.
