## Procedures

- `ValidateTestValue()` (protected): Validates and evaluates the current test value against its inspection and result configuration.
- `AssistEditTestValue()`: Opens the assist-edit interaction appropriate for the current test value type.
- `AssistEditFreeText()` (internal): Opens the large-text editor and stores an accepted value on the inspection line.
- `GetLargeText(): Text` (internal): Reads the full test value from the text BLOB, falling back to the Test Value field.
- `SetLargeText(LargeText: Text; ValidateValue: Boolean; OnlySetBlob: Boolean)` (internal): Stores a large test value in the field and, for text tests, in the text BLOB.
- `CollectAllowableValues(var TempBufferQltyTestLookupValue: Record "Qlty. Test Lookup Value" temporary)` (internal): Collects the allowable lookup values for the current test and inspection context. Code = the unique code Description = raw description. Custom 1 = original value Custom 2 = lowercase value Custom 3 = uppercase value.
- `IsNumericFieldType(): Boolean` (internal): Determines whether the current test uses a numeric value type.
- `GetFailedSampleCount(): Integer` (internal): Gets the failed sample count, which is currently always zero.
- `GetResultStyle(): Text`: Gets the display style configured for the current result.
- `UpdateExpressionsInOtherInspectionLinesInSameInspection()` (internal): Reevaluates expression and condition-dependent lines in the same inspection after this line changes.
- `EvaluateTextExpression(var EvaluateAgainstQltyInspectionHeader: Record "Qlty. Inspection Header")` (internal): Evaluates the current line's text expression against the supplied inspection header.
- `GetMeasurementNote(): Text`: Reads the most recent note linked to the inspection line.
- `SetMeasurementNote(Note: Text)`: Updates the latest note linked to the inspection line or creates one when none exists.
- `RunModalEditMeasurementNote()` (internal): Opens an editable note dialog and stores the accepted measurement note.
- `RunModalReadOnlyComment()` (internal): Opens the current measurement note in a read-only dialog.
