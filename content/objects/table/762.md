## Procedures

- `SetAccScheduleName(AccSchedName: Code[10])`: Sets the account schedule name and updates the record. Validates and modifies the chart setup with new account schedule configuration.
- `SetColumnLayoutName(ColumnLayoutName: Code[10])`: Sets the column layout name and updates the record. Validates and modifies the chart setup with new column layout configuration.
- `SetShowPer(ShowPer: Option)`: Sets the chart axis display option and updates the record. Configures what the X-axis represents in the chart visualization.
- `SetPeriodLength(PeriodLength: Option)`: Sets the period length for chart analysis and updates the record. Defines the time span for each period in the chart visualization.
- `SetLastViewed()`: Marks this chart setup as the last viewed configuration. Updates the record and clears last viewed flag from other setups.
- `SetLinkToLines(var AccSchedChartSetupLine: Record "Acc. Sched. Chart Setup Line")`: Sets filters on chart setup lines based on current chart configuration. Links chart setup lines to this configuration for data retrieval.
- `SetLinkToMeasureLines(var AccSchedChartSetupLine: Record "Acc. Sched. Chart Setup Line")`: Sets filters on chart setup lines for measure-based chart display. Configures line filtering based on X-axis configuration for measure presentation.
- `SetLinkToDimensionLines(var AccSchedChartSetupLine: Record "Acc. Sched. Chart Setup Line")`: Sets filters on chart setup lines for dimension-based chart display. Configures line filtering based on X-axis configuration for dimension presentation.
- `RefreshLines(Force: Boolean)`: Refreshes chart setup lines based on current account schedule and column layout configuration. Updates line data when configuration changes or when forced refresh is requested.
- `FilterAccSchedLines(var AccScheduleLine: Record "Acc. Schedule Line")`: Applies filters to account schedule lines based on current chart setup configuration. Filters lines to match the assigned account schedule name and exclude empty descriptions.
- `FilterColumnLayout(var ColumnLayout: Record "Column Layout")`: Applies filters to column layout records based on current chart setup configuration. Filters columns to match the assigned column layout name and exclude empty headers.
- `SetMeasureChartTypesToDefault(var AccSchedChartSetupLine: Record "Acc. Sched. Chart Setup Line")`: Sets default chart types for measure lines in chart setup configuration. Assigns column chart types to unset measure lines up to maximum supported measures.
- `SetDimensionChartTypesToDefault(var AccSchedChartSetupLine: Record "Acc. Sched. Chart Setup Line")`: Sets default chart types for dimension lines in chart setup configuration. Assigns default chart types to unset dimension lines for visualization.
