- `InsertDtldCVLedgEntry(var DtldCVLedgEntryBuf: Record "Detailed CV Ledg. Entry Buffer"; var CVLedgEntryBuf: Record "CV Ledger Entry Buffer"; InsertZeroAmout: Boolean)`: Inserts or updates a detailed CV ledger entry buffer record with consolidation logic. Combines entries with matching key fields to avoid duplicate buffer records.
- `CopyPostingGroupsFromVATEntry(VATEntry: Record "VAT Entry")`: Copies posting group fields from a VAT entry to the detailed CV ledger entry buffer. Used for VAT-related detailed entries to maintain proper posting setup references.
- `CopyFromGenJnlLine(GenJnlLine: Record "Gen. Journal Line")`: Copies relevant fields from a general journal line to create an initial detailed CV ledger entry. Sets up the buffer with transaction amounts, dimensions, and basic posting information.
- `InitFromGenJnlLine(GenJnlLine: Record "Gen. Journal Line")`: Initializes the detailed CV ledger entry buffer with basic posting information from a general journal line. Sets up document and user identification fields without amounts or detailed data.
- `CopyFromCVLedgEntryBuf(CVLedgEntryBuf: Record "CV Ledger Entry Buffer")`: Copies key reference fields from a CV ledger entry buffer to establish parent-child relationship. Links the detailed entry to its parent ledger entry with currency and dimension information.
- `InitDetailedCVLedgEntryBuf(GenJnlLine: Record "Gen. Journal Line"; var CVLedgEntryBuf: Record "CV Ledger Entry Buffer"; var DtldCVLedgEntryBuf: Record "Detailed CV Ledg. Creates fully populated detailed entry for payment applications, discounts, and tolerance scenarios.
