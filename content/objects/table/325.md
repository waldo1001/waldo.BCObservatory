- `OnBeforeCheckSetupUsage(var VATPostingSetup: Record "VAT Posting Setup"; var IsHandled: Boolean; VATBusPostingGroup: Code[20]; VATProdPostingGroup: Code[20])` (integration): Integration event raised before checking VAT posting setup usage to allow custom validation logic. Enables extensions to perform additional validation or override standard setup usage checks.

## Procedures

- `CheckGLAcc(AccNo: Code[20])`: Validates that the specified G/L account exists and is properly configured for VAT posting.
- `TestNotSalesTax(FromFieldName: Text[100])`: Validates that the specified field is not used when VAT Calculation Type is Sales Tax. Prevents configuration of VAT fields that are incompatible with Sales Tax calculation method.
- `GetSalesAccount(Unrealized: Boolean): Code[20]`: Returns the appropriate sales VAT G/L account based on whether unrealized VAT is being processed. Retrieves either realized or unrealized sales VAT account with validation for required account setup.
- `GetPurchAccount(Unrealized: Boolean): Code[20]`: Returns the appropriate purchase VAT G/L account based on whether unrealized VAT is being processed. Retrieves either realized or unrealized purchase VAT account with validation for required account setup.
- `GetRevChargeAccount(Unrealized: Boolean): Code[20]`: Returns the appropriate reverse charge VAT G/L account based on whether unrealized VAT is being processed. Retrieves either realized or unrealized reverse charge VAT account for EU and domestic reverse charge transactions.
- `SetAccountsVisibility(var UnrealizedVATVisible: Boolean; var AdjustForPmtDiscVisible: Boolean)`: Sets visibility flags for unrealized VAT and payment discount adjustment based on General Ledger Setup configuration. Controls UI field visibility for VAT posting setup pages based on system-wide VAT settings.
- `SuggestSetupAccounts()`: Suggests G/L account assignments for VAT posting setup based on existing similar setups and account patterns. Provides automated account suggestion functionality to streamline VAT posting setup configuration.
