## Procedures

- `SendProfile(var DocumentSendingProfile: Record "Document Sending Profile")`: Sends the shipment document using the specified document sending profile.
- `SendRecords()`: Sends the selected shipment records using the customer's document sending profile.
- `PrintRecords(ShowRequestForm: Boolean)`: Prints the sales shipment records using the configured report selection.
- `CheckNoPrinted()`: Validates that the shipment has been printed at least once.
- `EmailRecords(ShowDialog: Boolean)`: Sends the sales shipment records via email using the configured document sending profile.
- `Navigate()`: Opens the Navigate page to show related entries for this sales shipment.
- `StartTrackingSite()`: Opens the shipping agent's tracking website for the package.
- `ShowDimensions()`: Opens a page showing the dimension set for this sales shipment.
- `IsCompletlyInvoiced(): Boolean`: Checks if all lines in the shipment have been fully invoiced.
- `SetSecurityFilterOnRespCenter()`: Sets a security filter based on the user's responsibility center.
- `GetCustomerVATRegistrationNumber(): Text`: Gets the customer's VAT registration number.
- `GetCustomerVATRegistrationNumberLbl(): Text`: Gets the label for the VAT registration number field.
- `GetCustomerGlobalLocationNumber(): Text`: Gets the customer's global location number (GLN).
- `GetCustomerGlobalLocationNumberLbl(): Text`: Gets the label for the GLN field.
- `GetLegalStatement(): Text`: Gets the legal statement from sales setup for printing on shipments.
- `GetWorkDescription(): Text`: Gets the work description text from the blob field.
