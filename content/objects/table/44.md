- `SetUpNewLine()`: Initializes default values for a new sales comment line, setting the date to work date if no other comment exists for the current date.
- `CopyComments(FromDocumentType: Integer; ToDocumentType: Integer; FromNumber: Code[20]; ToNumber: Code[20])`: Copies all comment lines from one sales document to another.
- `CopyLineComments(FromDocumentType: Integer; ToDocumentType: Integer; FromNumber: Code[20]; ToNumber: Code[20]; FromDocumentLineNo: Integer; ToDocumentLineNo: Integer)`: Copies comment lines associated with a specific document line to another document line.
- `CopyLineCommentsFromSalesLines(FromDocumentType: Integer; ToDocumentType: Integer; FromNumber: Code[20]; ToNumber: Code[20]; var TempSalesLineSource: Record "Sales Line" temporary)`: Copies line-level comments from multiple sales lines to header-level comments on the target document.
- `CopyHeaderComments(FromDocumentType: Integer; ToDocumentType: Integer; FromNumber: Code[20]; ToNumber: Code[20])`: Copies header-level comments from one sales document to another.
- `DeleteComments(DocType: Option; DocNo: Code[20])`: Deletes all comment lines associated with the specified sales document.
- `ShowComments(DocType: Option; DocNo: Code[20]; DocLineNo: Integer)`: Opens the Sales Comment Sheet page to display comments for the specified document or document line.
