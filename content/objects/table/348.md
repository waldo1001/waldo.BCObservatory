## Procedures

- `CheckIfDimUsed(DimChecked: Code[20]; DimTypeChecked: Enum "Dim Type Checked"; BudgetNameChecked: Code[10]; AnalysisViewChecked: Code[10]; AnalysisAreaChecked: Integer): Boolean`: Checks if a dimension is being used in various system setups, posted entries, or budgets. This comprehensive check prevents deletion of dimensions that would cause data integrity issues.
- `GetCheckDimErr(): Text[250]`: Returns the formatted error message indicating where the dimension is being used. Used in conjunction with CheckIfDimUsed to provide detailed error information.
- `GetMLName(LanguageID: Integer): Text[30]`: Retrieves the multilanguage name for the dimension in the specified language. Falls back to the default name if no translation exists.
- `GetMLCodeCaption(LanguageID: Integer): Text[80]`: Retrieves the multilanguage code caption for the dimension in the specified language. Falls back to the default code caption if no translation exists.
- `GetMLFilterCaption(LanguageID: Integer): Text[80]`: Retrieves the multilanguage filter caption for the dimension in the specified language. Falls back to the default filter caption if no translation exists.
- `SetMLName(NewMLName: Text[30]; LanguageID: Integer)`: Sets the multilanguage name for the dimension in the specified language. Updates either the main record or creates/updates a translation record.
- `SetMLCodeCaption(NewMLCodeCaption: Text[80]; LanguageID: Integer)`: Sets the multilanguage code caption for the dimension in the specified language. Updates either the main record or creates/updates a translation record.
- `SetMLFilterCaption(NewMLFilterCaption: Text[80]; LanguageID: Integer)`: Sets the multilanguage filter caption for the dimension in the specified language. Updates either the main record or creates/updates a translation record.
- `SetMLDescription(NewMLDescription: Text[100]; LanguageID: Integer)`: Sets the multilanguage description for the dimension in the specified language. Currently only creates the translation record structure without storing the description value.
