## Procedures

- `EmptyLine(): Boolean`: Checks if the line is empty (no item number and zero quantity).
- `InsertLine(): Boolean`: Determines if the line should be inserted into a sales document.
- `ShowDimensions()`: Opens the dimension set editing page for this standard sales line.
- `ValidateShortcutDimCode(FieldNumber: Integer; var ShortcutDimCode: Code[20])`: Validates a shortcut dimension code for this standard sales line.
- `LookupShortcutDimCode(FieldNumber: Integer; var ShortcutDimCode: Code[20])`: Opens a lookup for a shortcut dimension code and validates the selection.
- `ShowShortcutDimCode(var ShortcutDimCode: array[8] of Code[20])`: Retrieves all eight shortcut dimension codes for this standard sales line.
- `FormatType(): Text[20]` (obsolete 29.0: Use FormatTypeAsText() instead.): Formats the line type for display, returning 'Comment' for blank types.
- `FormatTypeAsText(): Text[30]`: Formats the line type for display, returning 'Comment' for blank types.
