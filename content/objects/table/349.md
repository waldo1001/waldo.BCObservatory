## Procedures

- `CheckIfDimValueUsed(): Boolean`: Checks whether this dimension value is being used in posted entries or dimension sets. Prevents deletion or modification of dimension values that would cause data integrity issues.
- `LookUpDimFilter(Dim: Code[20]; var Text: Text): Boolean`: Opens a lookup page for dimension values and returns a filter string of selected values. Used in filter fields to allow multi-selection of dimension values.
- `LookupDimValue(DimCode: Code[20]; var DimValueCode: Code[20])`: Opens a lookup page for selecting a single dimension value. Used for dimension value selection in forms and fields.
