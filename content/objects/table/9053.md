## Procedures

- `SetRespCenterFilter()`: Sets a responsibility center filter on the sales cue based on the current user's assigned responsibility center.
- `CalculateAverageDaysDelayed(): Decimal`: Calculates the average number of days that delayed sales orders are overdue for shipment.
- `CountOrders(FieldNumber: Integer): Integer`: Counts the number of sales orders matching the criteria associated with the specified field.
- `ShowOrders(FieldNumber: Integer)`: Opens the Sales Order List page filtered to show orders matching the criteria associated with the specified field.
- `CalcNoOfReservedFromStockSalesOrders(): Integer`: Calculates the number of sales orders that have all required quantities fully reserved from available inventory stock.
- `DrillDownNoOfReservedFromStockSalesOrders()`: Opens the Sales Order List page showing only sales orders that are fully reserved from available inventory stock.

Plus 3 local procedures.
