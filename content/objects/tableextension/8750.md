## Procedures

- `MarkAsNotUploadedToExternal()` (internal): Marks the document attachment as not uploaded to external storage. Clears all external storage related fields.
- `MarkAsDeletedInternally()` (internal): Marks the document attachment as deleted from internal storage. Clears the Document Reference ID and sets the stored internally flag to false.
