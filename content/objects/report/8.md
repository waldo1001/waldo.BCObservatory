## Procedures

- `GetPeriodLength(): DateFormula`: Retrieves the configured period length formula for the budget report. Returns the DateFormula used to calculate period intervals for budget analysis.
- `GetPeriodStartDate(): Date`: Retrieves the starting date configured for the budget report period analysis. Returns the first period's starting date used in budget calculations.
