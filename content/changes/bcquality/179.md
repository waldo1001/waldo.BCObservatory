# #179 Add bounded knowledge retrieval

> Added deterministic, lossless bounded knowledge retrieval for review skills that caps context at 16,000 UTF-8 bytes per page, returns all applicable catalog rows without filtering or ranking, and validates retrieval through GUID-scoped scratch paths to improve efficiency and validation reliability.

[Pull request](https://github.com/microsoft/BCQuality/pull/179) · merged into `main` on 2026-09-11 by JesperSchulz · 26 files (+1892 -56), 19 AL · refactor · tier official · **unreviewed** (machine-generated)

## What changed

- Implemented capped pagination (16,000 bytes per page) for knowledge-index retrieval with strict UTF-8 and path-safety checks
- Returns complete applicable catalog rows without top-k filtering, ranking, or query-based omission to ensure deterministic behavior
- Added exact article and sample body retrieval in batches up to eight paths with SHA-256 validation and byte counting
- Applied bounded Source workflow to all 16 canonical review skills while preserving existing Relevance, Worklist, Action, and Output rules
- Comprehensive validation covers all 282 articles and 457 samples with explicit failure handling for invalid metadata, stale continuations, and oversized batches
