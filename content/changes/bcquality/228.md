# #228 Knowledge: isolated events, FilterGroup scope, BLOB CalcFields and stream text encoding

> Six knowledge articles added to guide developers on isolated events, FilterGroup scope, BLOB CalcFields, and text encoding in streams, with paired good and bad code examples.

[Pull request](https://github.com/microsoft/BCQuality/pull/228) · merged into `main` on 2026-10-20 by demiliani · 24 files (+725 -10), 22 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Isolated events are only isolated outside a write transaction; after uncommitted writes they run as normal events
- Rollback of a failing isolated subscriber does not undo var parameters, so IsHandled can stay true and skip default logic
- Page scope filters must not sit in filter group 0, and the filter group must be restored after setting hidden filters
- Call CalcFields on a BLOB before reading its stream, and set a text encoding on streams exchanged externally
- Four review skills and the evaluation fixtures are wired to the new articles
