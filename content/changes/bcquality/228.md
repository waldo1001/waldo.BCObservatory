# #228 Knowledge: isolated events, FilterGroup scope, BLOB CalcFields and stream text encoding

> Six knowledge articles added to guide developers on isolated events, FilterGroup scope, BLOB CalcFields, and text encoding in streams, with paired good and bad code examples.

[Pull request](https://github.com/microsoft/BCQuality/pull/228) · merged into `main` on 2026-10-20 by demiliani · 24 files (+725 -10), 22 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- Isolated events isolation guarantees only hold outside write transactions; runs as normal event after uncommitted writes
- FilterGroup scope filters must not use group 0 to avoid removal from filter pane; hidden filters need restoration to prevent replacement
- BLOB streams must call CalcFields before reading to avoid empty stream returns; text encoding must be set for external exchange to prevent character corruption
- Variant rollback behavior: isolated events don't undo var parameters; subscribers can set IsHandled to skip default logic despite rollback
- Review skills updated with new articles and evaluation fixtures populated for deterministic article selection
