# #253 knowledge(performance): add trigger-only fields to API pages with AddLoadFields

> New knowledge article documents how to use AddLoadFields on API pages to prevent JIT loading failures when accessing unbound fields in OnAfterGetRecord.

[Pull request](https://github.com/microsoft/BCQuality/pull/253) · merged into `main` on 2026-11-02 by pri-kise · 4 files (+128 -0), 3 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Explains that unbound Rec fields read in OnAfterGetRecord on API pages cause per-row JIT loads
- Recommends Rec.AddLoadFields in OnOpenPage to avoid 'Inconsistent read' and JIT loading failures
- Warns against Rec.SetLoadFields in OnOpenPage because it replaces the platform's layout-based field selection
- Adds bad and good AL examples for the pattern
- Registers the new article in the evaluation review fixtures
