# #229 Knowledge: Community Copilot domain (System.AI features) and review skill

> Added community knowledge domain for Copilot development covering System.AI module best practices like capability registration, Azure OpenAI calls, response validation, and prompt injection prevention, with a new peer review skill.

[Pull request](https://github.com/microsoft/BCQuality/pull/229) · merged into `main` on 2026-10-20 by demiliani · 19 files (+650 -2), 16 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Five new Community Copilot articles with good and bad samples: capability registration on install and upgrade, calling Azure OpenAI through the AI module, checking the operation response, saving PromptDialog proposals only when kept, and keeping user input out of system messages
- New community review skill al-copilot-review that runs as a top-level peer and is not composed by al-code-review
- Targets mistakes the compiler and analyzers do not catch
- Articles include false-positive carve-outs and Microsoft Learn references
- Registered in review fixtures and documented in the user and troubleshooting guides
