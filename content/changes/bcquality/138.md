# #138 knowledge(style): event subscribers bind by parameter name, so a shorter list is not a mismatch

> The style guide for event subscribers is clarified to document the actual behavior that AL binds subscribers by parameter name rather than position, allowing subscribers to omit parameters and reorder them without it being a mismatch.

[Pull request](https://github.com/microsoft/BCQuality/pull/138) · merged into `main` on 2026-08-28 by gggdttt · 1 file (+8 -4), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- AL binds event subscribers to publishers by parameter name, not by position
- Subscribers can omit any parameters they don't use from any position
- Subscriber parameters can be declared in a different order than the publisher
- The style guide is updated to prevent false positives from flagging valid shorter parameter lists
- Evidence from real BCApps code shows 11 subscribers with reordering or non-prefix subsets that currently ship
