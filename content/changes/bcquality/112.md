# #112 Add precision guards for systematic agent false-positive patterns

> Adds six knowledge articles that act as precision guards against recurring agent false positives. They cover tooltips on bound page fields, Boolean page triggers that default to true, filters defined outside the diff, CalcFields in both GetRecord triggers, and unreleased symbol or schema changes that need no breaking-change or upgrade handling.

[Pull request](https://github.com/microsoft/BCQuality/pull/112) · merged into `main` on 2026-07-17 by gggdttt · 6 files (+140 -0), 6 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Six new knowledge articles across breaking-changes, error-handling, performance, ui and upgrade
- Bound page fields inherit the source table field's ToolTip, so they should not be flagged
- Boolean page triggers return true by default; only an explicit exit(false) cancels
- CalcFields in both OnAfterGetRecord and OnAfterGetCurrRecord is not redundant, and the effective filter may be defined outside the diff
- Changes to symbols or schema that never shipped in a release are not breaking and need no upgrade path
- Behaviour changes for users or extensions.
