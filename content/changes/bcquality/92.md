> Security and privacy knowledge articles were corrected to align with current Business Central APIs and behavior, including fixes for SecretText HTTP guidance, error telemetry semantics, field data classification, and consent handling.

## What changed

- SecretText HTTP guidance updated to use HttpRequestMessage.SetSecretRequestUri with HttpClient.Send instead of non-existent API
- Error telemetry cluster realigned with AA0231 and current RT0030 behavior for Label/TextConst versus dynamic first arguments
- Field data classification, Privacy Notice registration, and consent handling corrected to match System Application behavior
- SecretText.Unwrap documentation clarified as on-premises-only, and ValidateTableRelation false handling improved
- All samples now use current Microsoft Learn patterns and are compilable
