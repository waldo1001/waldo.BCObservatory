# #119 Add batch-2 FP guards: sentence-case action captions + PK Get is transaction-cached

> Two knowledge articles were added to guide developers about correct use of sentence-case action captions and transaction-cached primary key lookups, helping suppress false positive quality warnings.

## What changed

- Action captions that express imperative commands should use sentence case (capitalize only the first word and proper nouns), not title case
- Primary key Get calls within a transaction are already cached by the system and do not require manual dictionary caching when used per-row
- Knowledge articles with example code help developers understand when and why certain coding patterns are correct
- These articles address feedback from Business Central app maintainers about false positive quality rule flagging
- Knowledge index was updated to include the two new articles
