## What changed

- Item Ledger Entry carries the shipment's document number, not the invoice number, after combined Ship and Invoice posting of sales orders
- Use TestPage field .Visible()/.Enabled() to verify UI rendering state and .Editable() via OpenEdit() for editability verification
- Generate test fixture values with GenerateGUID() for full-length fields or GenerateRandomCodeWithLength/GenerateRandomCode20 when uniqueness must be verified
- Four atomic AL-specific patterns documented with good/bad code examples from CURABIS internal training material
- Patterns cover data modeling and testing domains with best practices and anti-patterns
