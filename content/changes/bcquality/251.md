# #251 Clarify 20-character limit for assignable permission set names

> Documentation clarifies that assignable permission sets must not exceed 20 characters in name, a stricter limit than the general 30-character object naming rule, with compiler error AL0305 enforcing this at build time.

[Pull request](https://github.com/microsoft/BCQuality/pull/251) · merged into `main` on 2026-10-30 by iti-maciej-filipowicz · 1 file (+9 -4), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Assignable permission sets have a 20-character name limit, not the general 30-character limit
- Non-assignable permission sets still follow the 30-character limit
- The 20-character limit is a build-time compiler error (AL0305), not just a publish-time finding
- Includes best practice showing full names with prefix/affix must fit 20 characters
- Anti-pattern added showing 21-30-character assignable permission set names
