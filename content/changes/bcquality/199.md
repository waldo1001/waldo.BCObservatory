# #199 Fix indirect permission letters: `ri` is indirect read plus insert

> A security best practice article now correctly explains that permission letters r, i, m, d each represent one permission (read, insert, modify, delete), and corrects its examples to avoid over-granting indirect permissions.

[Pull request](https://github.com/microsoft/BCQuality/pull/199) · merged into `main` on 2026-09-29 by Nikolaj1407 · 2 files (+7 -3), 2 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Permission tokens consist of individual letters: r (read), i (insert), m (modify), d (delete), with lowercase meaning indirect
- The read-only 'Report Runner' example now correctly uses 'r' instead of 'ri', which would have also granted indirect insert
- Best practice guidance and keywords updated to reflect the correct interpretation of permission letters
- Added references to official Microsoft Learn documentation on permissions
