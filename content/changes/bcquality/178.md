# #178 Separate deterministic analyzer rules from BCQuality

> Deterministic analyzer rules and their documentation are removed from BCQuality, leaving only knowledge that adds BC-specific context beyond what the compiler already enforces.

[Pull request](https://github.com/microsoft/BCQuality/pull/178) · merged into `main` on 2026-09-11 by JesperSchulz · 60 files (+45 -1095), 55 AL · refactor · tier official · **unreviewed** (model text not yet checked)

## What changed

- 18 deterministic rules removed including CodeCop formatting rules and compiler-enforced checks like AS0062, AS0011, AS0007
- Knowledge samples and markdown files for style, AppSource, and breaking changes rules deleted
- Review skills updated to remove detection logic for retired rules
- BCQuality focuses on BC-specific reasoning rather than mechanical facts already enforced by tooling
- Division of responsibility established between compiler/analyzer and BCQuality knowledge base
