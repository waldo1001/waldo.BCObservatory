# #147 ShowMandatory + OnQueryClosePage Check

> Two new UI community knowledge articles with code examples demonstrate best practices for marking required fields and validating request page input to prevent common defects like fields appearing optional or losing user input on validation errors.

[Pull request](https://github.com/microsoft/BCQuality/pull/147) · merged into `main` on 2026-09-02 by pri-kise · 6 files (+342 -0), 6 AL · feature · tier official · **unreviewed** (machine-generated)

## What changed

- ShowMandatory property draws an asterisk but doesn't enforce requirements; use TestField or NotBlank to enforce and show the field is required
- OnPreReport runs after the request page closes, so validation errors there lose user input; validate in OnQueryClosePage instead
- Guard OnQueryClosePage validation with CloseAction to avoid errors when users cancel
- Keep OnPreReport validation for reports with no request page
- Articles include bad and good AL code examples to illustrate the defects and correct approaches
