# #225 Performance and style knowledge: compute Role Center headlines in the background; build client links with GetUrl

> Two new development guidelines added: computing Role Center headlines in background tasks via the RC Headlines Executor, and building client links using GetUrl instead of hardcoded URLs.

[Pull request](https://github.com/microsoft/BCQuality/pull/225) · merged into `main` on 2026-10-19 by MichaelDieringer · 9 files (+271 -4), 8 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- New performance article: loop-based Base App headlines should compute in an OnComputeHeadlines subscriber on codeunit 1441, with results stored per user
- Own HeadlinePart pages have no executor event and should use a page background task
- New style article: links into the running environment's client should come from GetUrl, not a hardcoded host, tenant or environment
- Edge cases follow Learn: unpublished SOAP/OData objects raise a runtime error, and UseFilters can return an empty string
- Both articles ship compiling good and bad samples and are wired into the performance and style review skills
