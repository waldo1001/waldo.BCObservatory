- Field relocation to table extension is not a deletion and requires no obsoletion
- Event parameter addition does not break subscribers that bind by subset matching
- Both guards use negative-clarification format to suppress false positives
- Scope limited to contract axis; data migration findings remain unmasked
- Complements existing event parameter validation rules
