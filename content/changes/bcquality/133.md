# #133 Add TransferFields SkipFieldsNotMatchingType guidance

> Added guidance in BCQuality to warn developers against using TransferFields with SkipFieldsNotMatchingType as a blanket solution, as it can silently drop fields when type mismatches occur within the same extension.

[Pull request](https://github.com/microsoft/BCQuality/pull/133) · merged into `main` on 2026-08-24 by yahyatouil-dev · 3 files (+140 -0), 3 AL · other · tier official · reviewed (checked by Opus)

## What changed

- New knowledge rule explains that TransferFields only errors on type mismatches within the same extension, not cross-extension
- Using SkipFieldsNotMatchingType to suppress errors can mask silent field drops
- Good pattern: use explicit field-by-field mapping with Evaluate for type conversions to fail loudly
- Bad pattern: relying on SkipFieldsNotMatchingType when destination needs all source fields copied
- Rule includes code examples and verification against Microsoft Learn documentation
