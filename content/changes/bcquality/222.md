## What changed

- Introduces al-knowledge skill entry point for agents to ask development questions and receive cited guidance
- Skill reads relevant BCQuality articles and returns knowledge-response JSON with answer, outcome, references and suppression details
- Implements knowledge-query input and knowledge-response output contracts following BCQuality Entry, READ and DO patterns
- Adds response schema validation and discovery metadata for applicable articles using READ's applicability and precedence rules
- Separates knowledge guidance from code review verdicts; no-knowledge and failed responses contain no citations
