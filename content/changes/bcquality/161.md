# #161 AL methods limited during write transactions (RunModal, Codeunit.Run)

> New performance guidance documents platform restrictions on calling RunModal and Codeunit.Run methods during write transactions, explaining when each method is blocked and how to structure code to avoid triggering the runtime error.

## What changed

- Page.RunModal, Report.RunModal, and XmlPort.RunModal are blocked during write transactions with specific exceptions (Report/XmlPort only when request page is suppressed)
- Codeunit.Run is restricted during write transactions when the return value is used
- Article clarifies that modal pages hold locks and must be called before write operations begin
- Guidance aligns with existing Microsoft Base Application patterns using Commit() before modal calls
