# #150 Simplify standalone AL code review skill

> The standalone AL code review skill is renamed from bcquality-al-review to al-code-review, with its SKILL.md simplified to a thin adapter that delegates to internal Entry and coordinator components. Plugin manifests and version are updated accordingly.

[Pull request](https://github.com/microsoft/BCQuality/pull/150) · merged into `main` on 2026-09-03 by JesperSchulz · 9 files (+203 -109), 4 AL · refactor · tier official · reviewed (checked by Opus)

## What changed

- Skill renamed from bcquality-al-review to al-code-review to avoid collision with BC-ALAgents al-review skill
- Host-facing SKILL.md reduced to a thin adapter translating caller goals to Entry's task context
- Plugin manifests point to canonical skills/ directory with version bumped to 0.2.0
- New documentation clarifies the distinction between host adapter, Entry, internal coordinator, and domain leaves
- Validator extended to enforce host-skill naming and required frontmatter
- Breaking: existing extensions can stop compiling or working.
