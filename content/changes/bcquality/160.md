# #160 Clarify page field caption and tooltip inheritance

> Knowledge articles now state that bound page fields inherit Caption and, from BC24 runtime 13.0, ToolTip from their source table fields. Agents should inspect source fields before flagging missing properties, which avoids redundant page-level captions and tooltips.

## What changed

- Recognizes caption inheritance from table fields to bound page fields
- Documents tooltip inheritance from BC24 runtime 13.0 onwards
- Removes redundant recommendations for caption and tooltip on inherited bound fields
- Updates good and bad AL examples with accurate scenarios
- Requires source field inspection before reporting missing properties
- Behaviour changes for users or extensions.
