# #98 Add P0 event and interface compatibility knowledge

> Guidance added for event and interface compatibility patterns, covering enum unknown value handling, published interface evolution, subscriber contracts for local and internal events, and shipped event attribute immutability.

[Pull request](https://github.com/microsoft/BCQuality/pull/98) · merged into `main` on 2026-07-14 by JesperSchulz · 19 files (+331 -32), 19 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- New samples and documentation for handling unknown enum ordinals using UnknownValueImplementation (BC18+)
- Guidelines for extending published interfaces with versioned siblings and BC25+ extends syntax
- Event parameter compatibility rules clarified: local/internal subscribers bind by name and can omit new parameters; public procedures cannot gain required parameters
- Shipped event attribute flags must not be modified to maintain compatibility
- Targeted review skill cues added for events and interfaces topics
