# #54 Emit human-readable domain label on review findings

> Review findings now include a human-readable domain label owned by BCQuality, eliminating the need for consumer taxonomy maps and allowing new review domains to render correctly without engine changes.

[Pull request](https://github.com/microsoft/BCQuality/pull/54) · merged into `main` on 2026-07-15 by JesperSchulz · 19 files (+91 -56), 18 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- Adds optional `findings[].domain` field to review output schema with display labels like 'Breaking Changes', 'Performance', 'Security'
- Each AL review leaf skill sets domain on every finding it emits; cross-cutting findings use 'Agent' as domain
- Domain is display text that consumers must preserve exactly without modification or lossy transformation
- Backward compatible: absent domain field triggers legacy fallback behavior in consumers
- Decouples review domain taxonomy from consumer engine, shifting ownership to BCQuality producers
