# #230 Knowledge: report layouts and dataset contract, query join and grouping defaults

> Five knowledge articles were added to cover report layout declaration, report dataset column contracts, and query defaults for joins and grouping that differ from SQL conventions.

[Pull request](https://github.com/microsoft/BCQuality/pull/230) · merged into `main` on 2026-10-20 by demiliani · 18 files (+529 -3), 17 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- Report layouts should be declared in the rendering section, not using deprecated DefaultLayout/RDLCLayout properties
- Report dataset column names form a contract with Excel sheets, Word XML, and external layouts, so renames and removals break layouts
- Report extensions require explicit layout selection via DefaultRenderingLayout since layouts are not selected automatically
- Query dataitems default to left outer joins when SqlJoinType is omitted, affecting how unmatched upper rows appear
- Non-aggregated columns in queries implicitly become group keys, which can silently change grouping and affect calculations like integer division in Average
