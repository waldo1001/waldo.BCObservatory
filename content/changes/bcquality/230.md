# #230 Knowledge: report layouts and dataset contract, query join and grouping defaults

> Five knowledge articles were added to cover report layout declaration, report dataset column contracts, and query defaults for joins and grouping that differ from SQL conventions.

[Pull request](https://github.com/microsoft/BCQuality/pull/230) · merged into `main` on 2026-10-20 by demiliani · 18 files (+529 -3), 17 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- New reports should declare layouts in the rendering section instead of the legacy DefaultLayout, RDLCLayout, WordLayout and ExcelLayout properties, which are set to be deprecated
- Report dataset column names are a contract with Excel Data sheets, Word XML parts and user-defined layouts, so renaming or removing them breaks those layouts
- A layout added in a reportextension does not replace the base layout automatically; DefaultRenderingLayout cannot be set there and the layout must be selected
- Query dataitems default to LeftOuterJoin when SqlJoinType is omitted, and every non-aggregated column becomes a group key
- The al-reporting-review and al-query-review skills and the review fixtures were updated to use the new articles
