# #277 knowledge: translations, assisted setup, API queries, and a new xmlport domain

> BCQuality adds 18 knowledge articles. Fourteen go into existing domains (translations, assisted setup, API queries, MaskType, dependency versions). Four go into a new xmlport domain, together with an al-xmlport-review leaf that al-code-review now uses.

[Pull request](https://github.com/microsoft/BCQuality/pull/277) · merged into `main` on 2026-11-19 by demiliani · 45 files (+1485 -13), 42 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- 14 articles extend the style, ui, web-services, security and upgrade domains
- New xmlport domain with 4 articles: MS-DOS default TextEncoding, Xmlport.Run Import argument versus Direction, Import/Export return values, passing the filtered record
- New al-xmlport-review leaf, added as the 20th sub-skill of al-code-review, returns not-applicable when there is no XMLport object or Xmlport call
- Eight articles have no good/bad sample pair because they cover XLIFF or app.json content or lack a verified method signature
- Platform claims link to the Microsoft Learn pages they come from
