# #192 Add SCM functional knowledge domain

> SCM (supply chain management) functional knowledge domain added with nine scoped rules and self-contained AL code samples covering item posting, reservations, warehouse adjustments, and requisition workflows.

[Pull request](https://github.com/microsoft/BCQuality/pull/192) · merged into `main` on 2026-09-21 by JesperSchulz · 34 files (+1030 -10), 29 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Nine SCM rules covering item-ledger posting, revaluation, item application, reservations and item tracking
- Rules also cover warehouse adjustments, transfer posting, available-to-promise and requisition action messages
- Each rule has self-contained bad and good AL samples
- New al-scm-review skill registered in the AL code review; item, value and warehouse records are SCM-owned while pure G/L and VAT mutations stay with Finance
- All samples compile with CodeCop against Base Application 28.5
