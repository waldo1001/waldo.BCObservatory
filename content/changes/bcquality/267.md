# #267 Evaluation: keep standalone BDD tag lines in prepared testing samples

> Quality rules for BDD-style test samples now preserve standalone tag lines (FEATURE, SCENARIO, GIVEN, WHEN, THEN) during text preparation while stripping other comments. Ten selected testing articles have been updated with complete, neutral BDD tags to guide evaluation of test code structure.

[Pull request](https://github.com/microsoft/BCQuality/pull/267) · merged into `main` on 2026-11-06 by Nikolaj1407 · 22 files (+352 -31), 18 AL · refactor · tier official · **unreviewed** (model text not yet checked)

## What changed

- Text preparation regex modified to keep only standalone BDD tag lines, stripping all other comments
- Validation now rejects retained tag lines containing 'Good', 'Bad', or 'anti-pattern' in selected samples
- Ten selected testing articles updated with complete BDD tag coverage (FEATURE, SCENARIO, GIVEN, WHEN, THEN)
- BDD tag placement preserved in bad/good sample pairs when code performs identical operations
- Preparation logic moved to dedicated Review-FixtureText.ps1 script used by harness and regression checks
