# #117 tooltip: PR review flags genuinely-missing tooltips instead of deferring to AA0218

> PR review now independently flags genuinely missing tooltips on page fields instead of deferring to compiler analyzer AA0218, which can be disabled or downgraded in team rulesets.

[Pull request](https://github.com/microsoft/BCQuality/pull/117) · merged into `main` on 2026-07-20 by gggdttt · 2 files (+6 -4), 2 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Bound fields whose source field also lacks a ToolTip are now flagged as medium
- Unbound controls without a ToolTip are now flagged as medium
- Bound fields inheriting a ToolTip from the source field are still not flagged
- Notes that AA0218 severity is set per app and is often downgraded or disabled
- Anti-pattern now covers both over-flagging inherited fields and staying silent on real gaps
- Behaviour changes for users or extensions.
