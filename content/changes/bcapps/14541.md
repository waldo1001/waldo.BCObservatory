# #14541 [Expense Agent] Send company scope header on company-bound requests

> Expense Agent now sends an X-ERP-Scope header on company-bound requests to route them to the correct company registration, computed from tenant ID, environment name, and company ID using UUIDv5.

[Pull request](https://github.com/microsoft/BCApps/pull/14541) · merged into `main` (BC30) on 2026-11-27 by icipriand (community contribution) · 2 files (+403 -0), 1 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Scope header added only to company-bound requests (expense submission, open report reminders, reimbursement notifications, welcome emails)
- Scope ID calculated on-the-fly from AAD tenant ID, environment name, and company ID without persistence
- Scope value computed as UUIDv5 hash of normalized name with fixed namespace
- Company ID canonicalized to accept prefixes and various GUID formats, producing lowercase hyphenated GUID
- Requests fail with error if tenant, environment, or company is missing instead of being sent without scope
- Behaviour changes for users or extensions.
