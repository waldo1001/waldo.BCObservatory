# #13673 Expose active expense approver and expense app navigation

> The Expense Reports API now exposes activeApproverExpenseUserNo and filters by active approver with Pending Approval and Interim Approved statuses instead of expanding submitter lists, and advertises an ActiveApproverRouting capability. Report card and list pages gain an Open Expense App action, and the unused Pending Approval By FlowFilter is obsoleted.

[Pull request](https://github.com/microsoft/BCApps/pull/13673) · merged into `main` (BC30) on 2026-11-23 by encimita · 16 files (+985 -157), 9 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- activeApproverExpenseUserNo field exposed in Expense Reports API for direct approver linking
- Submitter-list expansion replaced with filtering by active approver and approval statuses
- Open Expense App actions added to report card and list pages under Navigate section
- Secondary key on Approver Expense User No. and Status enables efficient approver collection queries
- PendingApprovalBy FlowFilter marked obsolete for version 30.0
- Behaviour changes for users or extensions.
