# #12816 [29.x]- Project Planning Lines are created in reverse order when purchase line descriptions are copied

> Fixed project planning lines being created in reverse order when posting purchase invoices with multiple G/L account lines assigned to the same project, by sorting invoice posting buffer entries in ascending order by source line number.

## What changed

- Project planning lines now maintain the original purchase line sequence when 'Copy Line Descr. to G/L Entry' is enabled
- Buffer processing loop in PurchPostInvoice codeunit modified to iterate groups in ascending order by source line number
- G/L Entry, VAT Entry, and Job Ledger Entry posting behavior remains unaffected
- Bug reproduced in job consumption purchase tests with multiple lines assigned to same project task
- Behaviour changes for users or extensions.
