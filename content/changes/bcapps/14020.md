# #14020 Bug 650215: Direct Transfer route does not populate configured In-Transit Code on transfer order

> Transfer orders using routes now correctly apply the configured In-Transit Code for Shipment and Receipt transfers, while clearing it for Direct Transfer posting mode.

[Pull request](https://github.com/microsoft/BCApps/pull/14020) · merged into `main` (BC30) on 2026-11-18 by ChethanT · 9 files (+570 -20), 8 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- In-Transit Code is applied from routes for non-direct transfers and cleared for Direct Transfer posting
- Synchronizes existing transfer lines with header values when either location changes on direct transfers
- Direct transfer receipt quantities align with shipment quantities even with non-blank route transit codes
- Receipt validation receives the in-memory header with updated Direct Transfer flag to prevent stale route mode
- Thirteen regression tests added covering location-entry sequences, in-transit code replacement, and quantity defaults with inherited transit
- Behaviour changes for users or extensions.
