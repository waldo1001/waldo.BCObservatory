# #10407 Shopify connector: persist order Tax Area Code, Tax Liable, and Tax Exempt (stack 1/3)

> Shopify connector now captures and persists tax area code, tax liable, and tax exempt fields from Shopify orders, propagates them to sales documents during order and refund creation, and adds integration events for downstream extensions.

[Pull request](https://github.com/microsoft/BCApps/pull/10407) · merged into `main` (BC30) on 2026-08-20 by onbuyuka · 14 files (+380 -11), 11 AL · feature · tier official · **unreviewed** (machine-generated)

## What changed

- Tax Area Code, Tax Liable, and Tax Exempt fields added to Shopify Order Header table
- Shopify GraphQL queries updated to retrieve tax data
- Tax values propagated to Sales Header on both order and refund creation
- Fallback to Order Management tax area lookup when stored code is blank
- Integration events and CommitBehavior added for extensibility
- Behaviour changes for users or extensions.
