# #12051 [Peppol] Fix Remittance Advice XML line count, Note order and invoice reference

> The Peppol remittance advice XML export now correctly reports the actual line count, orders note elements according to XSD requirements, and uses the vendor invoice number for invoice references.

[Pull request](https://github.com/microsoft/BCApps/pull/12051) · merged into `main` (BC30) on 2026-10-01 by GediminasGaubys (community contribution) · 2 files (+85 -9), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- LineCountNumeric element now reflects the actual number of lines instead of always showing zero
- Line-level Note elements are positioned immediately after ID elements to match XSD schema requirements
- Invoice references now prioritize the vendor's external document number, falling back to the system document number
- InvoicingPartyReference element is no longer emitted from the export
- New test validates all three corrections
- Behaviour changes for users or extensions.
