# #13724 Bug 651757: Allow warehouse pick for MTO subassembly after registered put-away

> Warehouse pick selection for make-to-order subassemblies now allows higher-level supplied components after production output put-away is registered, completing a fix that enables proper warehouse workflows for MTO items.

[Pull request](https://github.com/microsoft/BCApps/pull/13724) · merged into `main` (BC30) on 2026-11-10 by ChethanT · 7 files (+386 -8), 5 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Extended warehouse-picking eligibility to include Planning Level 1 components when output put-away has been registered
- Maintained consistent eligibility rules across production-order action, warehouse source reports, and worksheet source selection
- Removed incorrect comparison between supplying-line output put-away and component picks that was blocking valid pick scenarios
- Added comprehensive test cases covering full output, staged output, worksheet picking, and mixed stock scenarios
- Propagated changes to Italian localization layer through Miapp
- Behaviour changes for users or extensions.
