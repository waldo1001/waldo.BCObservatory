# #12554 [Main] - User encounters a "record is not open" error when attaching a document to a posted sales shipment in Dynamics 365 (Base Application v28)

> Document attachment uploads now work correctly for posted sales shipments and return receipts by adding missing table references and hardening error handling.

[Pull request](https://github.com/microsoft/BCApps/pull/12554) · merged into `main` (BC30) on 2026-10-13 by DhavalMore88 (community contribution) · 9 files (+732 -151), 7 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Added Sales Shipment Header and Return Receipt Header cases to GetRefTable in Document Attachment Mgmt
- Uploading files from the Documents FactBox on posted sales shipments and return receipts no longer fails with 'The record is not open'
- Upload files, Show details and Attach from email in the FactBox now raise a clear error if the source record still cannot be resolved after OnAfterGetRecRefFail
- Follows the existing pattern used for Sales Invoice Header and Sales Cr.Memo Header
- Regression tests added in W1 and ES test layers
- Behaviour changes for users or extensions.
