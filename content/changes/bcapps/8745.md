# #8745 Bug 640098: Make Table Information Cache refresh resilient to duplicate table numbers

> The Table Information Cache refresh now aggregates metrics when duplicate table numbers are encountered instead of failing with a duplicate-key error. This makes the Data Administrator page's refresh action resilient to orphaned or renamed SQL tables.

[Pull request](https://github.com/microsoft/BCApps/pull/8745) · merged into `main` (BC30) on 2026-07-17 by Groenbech96 · 1 file (+17 -1), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Fixes the Data Administrator Refresh action failing with a duplicate-key error
- The platform's Table Information table can return several rows with the same Table No. but different table names
- Instead of inserting a duplicate, the refresh now adds No. of Records, Size, Data Size and Index Size into the existing cache row
- The full refresh no longer aborts with NavCSideDuplicateKeyException
- Behaviour changes for users or extensions.
