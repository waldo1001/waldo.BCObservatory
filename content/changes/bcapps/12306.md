# #12306 Warn before releasing a purchase order that was already sent electronically

> A warning now appears when releasing a purchase order that was already electronically sent, preventing silent re-export of the same e-document with the same identifier that would later cause conflicts.

## What changed

- Adds a confirmation prompt when releasing a purchase order that has a previously sent e-document
- First release and failed export retries remain unaffected
- Prevents accidental re-export with same cbc:ID that causes duplicate order errors on receiving side
- Supports Peppol integration by warning before unsupported OrderChange scenario
- Internal changes only with no breaking changes to public APIs
- Behaviour changes for users or extensions.
