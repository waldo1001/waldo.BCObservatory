# #13429 [Quality Management] Receiving setup guide: don't offer the warehouse receipt Create trigger

> The Receiving setup guide now prevents creating Quality Management rules with unsupported warehouse receipt triggers that would never fire, limiting trigger options to Never and When Warehouse Receipt is posted.

[Pull request](https://github.com/microsoft/BCApps/pull/13429) · merged into `main` (BC30) on 2026-11-06 by alexei-dobriansky · 2 files (+51 -1), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- The warehouse receipt trigger field now restricts to Never and When Warehouse Receipt is posted options only
- Setup defaults of created trigger are not carried into the guide to prevent invalid rules
- Finish action rejects unsupported trigger combinations with guidance to the Generation Rules page
- Tooltip explains how to manually set up Warehouse Receipt Line rules for the created trigger
- Existing rules and the Generation Rules page remain unchanged for manual rule creation
- Behaviour changes for users or extensions.
