# #10665 [SOA] Skip content extraction for image attachments

> The Sales Order Agent now skips content extraction for image attachments and uses their stored text content instead, improving processing reliability while maintaining relevance filtering for all attachments.

[Pull request](https://github.com/microsoft/BCApps/pull/10665) · merged into `main` (BC30) on 2026-08-27 by qasimikram · 3 files (+35 -0), 2 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Image attachments bypass the extraction model (which rejects them) and use pre-stored text content
- New IsImageAttachmentContentType function identifies standard and non-standard image MIME types
- Non-image attachments continue through the existing extraction and system-ID marker check path
- Relevance evaluation still applies to all attachments regardless of extraction bypass
- Change is marked temporary pending future extraction model support for images
- Behaviour changes for users or extensions.
