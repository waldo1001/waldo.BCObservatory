# #10124 [Extensibility Request] issue 30400: add credit memo line filter event

> A new integration event allows extensions to filter purchase credit memo lines before they are selected during prepayment document updates, enabling customization without replacing standard posting logic.

[Pull request](https://github.com/microsoft/BCApps/pull/10124) · merged into `main` (BC30) on 2026-08-12 by AleksandricMarko · 6 files (+36 -0), 6 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- New event OnUpdatePurchaseDocumentOnBeforeFindSetCrMemoPurchLine fires before credit memo lines are retrieved
- Subscribers can apply additional filters to refine the purchase line selection
- Event provides access to purchase header and mutable purchase line parameters
- Change propagated across all localization layers (APAC, ES, IT, NA, NL, W1)
- Addresses extensibility gap in purchase prepayment posting process
