# #9291 Add [NonDebuggable] to Cryptography Management encrypt/decrypt procedures

> The Cryptography Management system application now marks all encryption and decryption procedures with the NonDebuggable attribute to prevent AL debugger access to sensitive cleartext data.

## What changed

- Four procedures in Cryptography Management codeunits receive the NonDebuggable attribute
- EncryptText, Encrypt, and Decrypt procedures are now protected from debugger inspection
- Prevents extraction of cleartext input and return values when procedures return Text instead of SecretText
- Maintains confidentiality of encrypted and decrypted data
