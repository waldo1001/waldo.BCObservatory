# #13207 Skip missing and removed tables when loading record sets

> Record Set Management now gracefully skips table references that have been removed or don't exist when loading record sets, preventing metadata exceptions and allowing sales documents and Edit in Excel to function when legacy payment-service sets are present.

[Pull request](https://github.com/microsoft/BCApps/pull/13207) · merged into `main` (BC30) on 2026-11-12 by haoranpb · 2 files (+104 -9), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Guards GetSet method against membership entries for deleted or ObsoleteState=Removed tables
- Continues loading records from available tables, including those marked Pending
- Resolves issue where retired payment-provider table references caused metadata exceptions
- Prevents sales document pages and Edit in Excel from failing due to stale record set memberships
- Adds four regression tests covering removed and absent tables in various set configurations
- Behaviour changes for users or extensions.
