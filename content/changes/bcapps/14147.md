# #14147 Fix reactivated direct transfer and BEANS issues

> Fixed direct transfer orders to create inbound warehouse requests when their route overrides the Inventory Setup posting mode, and corrected Quality Management demo data to seed Coffee Defect and Uniformity tests with proper conditions.

[Pull request](https://github.com/microsoft/BCApps/pull/14147) · merged into `main` (BC30) on 2026-11-19 by alexei-dobriansky · 4 files (+63 -8), 2 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- On release, direct transfer orders now use the posting mode from their transfer route instead of only the Inventory Setup default
- When the route sets Direct Transfer, an inbound warehouse request is created, so an Inventory Put-away can be made at the destination
- Quality Management BEANS demo data now gives the Coffee Defect and Coffee Uniformity tests their own conditions
- New regression test covers route-specific direct transfer posting with an inbound Inventory Put-away
- The transfer fix only matters when the route posting mode differs from Inventory Setup; the demo data change does not migrate existing Quality Test records
- Behaviour changes for users or extensions.
