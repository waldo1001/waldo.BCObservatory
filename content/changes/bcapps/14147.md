# #14147 Fix reactivated direct transfer and BEANS issues

> Fixed direct transfer orders to create inbound warehouse requests when their route overrides the Inventory Setup posting mode, and corrected Quality Management demo data to seed Coffee Defect and Uniformity tests with proper conditions.

## What changed

- Direct transfer orders now respect their route-derived posting mode instead of only using Inventory Setup default for warehouse request creation
- Inbound Inventory Put-away will now be created when transfer route specifies direct transfer mode
- Quality Management demo data updated to include semantic conditions on Coffee Defect and Coffee Uniformity tests in BEANS template
- New regression test added to verify route-specific direct transfer posting with inbound Inventory Put-away
- Changes only affect scenario where transfer route posting mode differs from Inventory Setup default
- Behaviour changes for users or extensions.
