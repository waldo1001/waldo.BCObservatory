# #10526 Use BaseApp's new PO Matching module in E-Documents

> E-Documents now leverages BaseApp's new PO Matching module to support one-to-many matching and receiving at invoice for two-way matches, with additional warnings for amount mismatches and expanded matching fields.

## What changed

- Integrates BaseApp's new PO Matching API surface into E-Document creation workflow
- Enables one-to-many purchase order line matching against invoices
- Supports receiving at invoice time for two-way matches
- Adds warning notifications when invoice amounts don't match purchase orders
- Expands page fields to show more matching information for Payables Agent decisions
- Behaviour changes for users or extensions.
