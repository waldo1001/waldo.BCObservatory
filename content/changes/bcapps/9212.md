# #9212 Bug 629779: [Inventory] Show a single Export/Import item data action pair on Cost Adjustment and Item Card

> The Cost Adjustment and Item Card pages now show a single Export/Import action pair that automatically switches between standard inventory and manufacturing data formats based on whether the Manufacturing module is enabled, eliminating duplicate and confusing action options.

[Pull request](https://github.com/microsoft/BCApps/pull/9212) · merged into `main` (BC30) on 2026-08-05 by alexei-dobriansky · 9 files (+42 -15), 9 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- Pages detect Manufacturing enablement at runtime and display only the relevant Export/Import pair
- Captions simplified to show only 'Export item data' and 'Import item data' regardless of module
- Manufacturing-enabled installations route to production data XMLPorts while standard installations use standard XMLPorts
- Change applied across Cost Adjustment Overview, Manufacturing Cost Adjustment Overview extension, Item Card, and Manufacturing Item Card extension
- No schema or public API changes, purely UI-level caption and visibility adjustments
- Behaviour changes for users or extensions.
