# #12308 Don't block approval workflow when foreground notification email fails

> Prevent approval workflow blocking when foreground notification email delivery fails by logging errors instead of raising exceptions mid-transaction.

[Pull request](https://github.com/microsoft/BCApps/pull/12308) · merged into `main` (BC30) on 2026-10-08 by darjoo · 3 files (+110 -4), 2 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Foreground instant notifications for delegated users no longer raise errors when email delivery fails
- Failed notifications are logged to telemetry and shown to users as notifications with Details action instead of blocking workflows
- Failed Notification Entries retain error details and remain available for later dispatch
- New internal flag SetRunInForeground distinguishes foreground dispatch path from job queue path
- Workflow response steps can now complete successfully despite email delivery failures
- Behaviour changes for users or extensions.
