# #9779 [Extensibility Request] issue 30361: add OnAutoArchiveJobOnCaseElse event to Job Archive Management

> A new integration event OnAutoArchiveJobOnCaseElse is added to Job Archive Management so extensions can handle custom archive modes beyond the standard options.

[Pull request](https://github.com/microsoft/BCApps/pull/9779) · merged into `main` (BC30) on 2026-07-30 by AleksandricMarko · 1 file (+7 -0), 1 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Event fires in the else branch of the archive jobs case when a non-standard archive mode is set
- Extensions receive the Job and Jobs Setup records as parameters
- Allows custom archive handling logic to be plugged in without modifying core code
- Addresses gap where unhandled archive modes silently did nothing
