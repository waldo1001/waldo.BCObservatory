# #9966 Harden Contact Sync delta URL and ownership checks

> Contact Sync now validates delta URLs against the approved Microsoft Graph endpoint and enforces record ownership checks to prevent malicious URL manipulation or cross-user record access.

[Pull request](https://github.com/microsoft/BCApps/pull/9966) · merged into `main` (BC30) on 2026-08-27 by Naveen26423 · 8 files (+460 -34), 4 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- Delta URLs are validated before persisting to ensure they match the https://graph.microsoft.com/v1.0/ prefix
- Invalid delta URLs trigger fallback to full sync instead of failing
- Record ownership enforcement prevents users from inserting or modifying other users' sync records
- User ID field changes on existing records are blocked
- Install and upgrade contexts bypass ownership checks to avoid regressions
- Behaviour changes for users or extensions.
