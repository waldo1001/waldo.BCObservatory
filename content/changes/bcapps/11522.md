# #11522 [main] [Order Planning] Production copy allows Req. worksheet templates that cannot create production orders

> Production order copying in Order Planning now restricts the destination to nonrecurring Planning-type worksheets only, preventing invalid selections that would silently lose production demand when carrying out actions.

[Pull request](https://github.com/microsoft/BCApps/pull/11522) · merged into `main` (BC30) on 2026-09-29 by Shikhverma · 6 files (+288 -27), 3 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- The production worksheet template lookup is filtered to Template Type = Planning
- The batch lookup is filtered to Recurring = false
- The option caption changed from Copy to Req. Wksh. to Copy to Planning Wksh.
- Prevents production demand being lost silently when inert production lines are deleted during nonrecurring batch cleanup
- Behaviour changes for users or extensions.
