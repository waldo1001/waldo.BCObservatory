# #10840 Bugs/625412 Wrong posted G/L Entries and VAT Entries using Cash Basis Unrealized VAT from a partial Credit Memo if we mix VAT types and use only part of the amount in the Mexican version.

> Cash-basis VAT calculations for partial credit memo applications now correctly determine settled amounts per VAT posting group, preventing incorrect G/L entries between realized and unrealized VAT accounts.

[Pull request](https://github.com/microsoft/BCApps/pull/10840) · merged into `main` (BC30) on 2026-09-14 by v-mjofre · 7 files (+582 -86), 2 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Fixed VAT realization to use settled amount per VAT group instead of total settled amount
- Added dedicated calculation for credit memo portion associated with each VAT posting group
- Currency factor is applied before VAT amount calculation
- Added condition to prevent G/L entries when credit memo application does not represent actual VAT realization
- Comprehensive test coverage added for cash-basis VAT credit memo scenarios
- Behaviour changes for users or extensions.
