# #13599 [SOA] Setup can be saved while the agent remains inactive without warning

> The Sales Order Agent setup page now shows a confirmation when saving an inactive agent with configuration changes, asking whether to activate it. The first-time setup path was also fixed to actually activate the agent when the user confirms.

[Pull request](https://github.com/microsoft/BCApps/pull/13599) · merged into `main` (BC30) on 2026-11-04 by VolodySyn · 1 file (+30 -2), 1 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- Confirmation appears only when the agent is inactive, setup changed, and the user didn't manually toggle Active
- Confirmation is never shown for Try it out flow, manual Active toggle off, or when nothing changed
- New ActivateAgent() helper ensures activation works correctly in both first-time setup and update flows
- Previously, saying Yes to activate in first-time setup didn't work because FlowField overwrites were not handled
- Only UI flow change, no schema or public API modifications
- Behaviour changes for users or extensions.
