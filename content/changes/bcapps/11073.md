# #11073 Validate image content before sending to Computer Vision

> Image Analysis Management now validates image content before sending to Computer Vision endpoints, rejecting non-image blobs and unsupported formats while supporting JPEG, PNG, GIF and BMP.

[Pull request](https://github.com/microsoft/BCApps/pull/11073) · merged into `main` (BC30) on 2026-10-09 by gggdttt · 2 files (+459 -12), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Validates that uploaded content is a supported image format before HTTP request
- Accepts JPEG, PNG, GIF and BMP formats matching documented Computer Vision and Custom Vision requirements
- Loads and decodes image files using System Application Image codeunit
- Rejects non-image content and unsupported formats through existing error notification path
- No universal size limits or minimum dimensions imposed; API-specific checks remain with configured service
- Behaviour changes for users or extensions.
