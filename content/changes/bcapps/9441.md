# #9441 [Extensibility Request] issue 30337: add OnCreateProdOrderLineOnBeforeCreateProdOrderLineFromItem event

> A new integration event OnCreateProdOrderLineOnBeforeCreateProdOrderLineFromItem allows extensions to completely replace the standard item source type processing when creating production order lines, with control over the error outcome.

- New IsHandled-based integration event lets extensions take full ownership of item-line creation
- Extensions can bypass standard flow and set the ErrorOccured flag
- Existing events and standard behavior preserved when the extension doesn't handle the operation
- Event exposes Production Order record and variant code for custom processing
- Extracted item creation logic into separate local procedure
