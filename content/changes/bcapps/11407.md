# #11407 [Shopify] Keep exchange shipments eligible for synchronization

> Exchange-refund Shopify orders now sync their shipments correctly. A bug where the refund ID was incorrectly copied to the fulfillment ID field during shipment posting has been fixed.

[Pull request](https://github.com/microsoft/BCApps/pull/11407) · merged into `main` (BC30) on 2026-09-18 by onbuyuka · 1 file (+4 -2), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Refund ID was unintentionally copied to the fulfillment ID during shipment posting via TransferFields
- This caused shipments to be treated as already synchronized, preventing proper sync to Shopify
- The fix clears the fulfillment value when it matches a transferred refund ID
- Exchange-refund orders can now synchronize their shipments with Shopify
- Low risk change with no schema modifications
- Behaviour changes for users or extensions.
