# #8750 [Bug Fix] #638688: Suppress availability warning for Transfer WIP Item lines

> Transfer order lines flagged as WIP items now skip the standard item-availability warning check since WIP items are intermediate goods managed by subcontracting, not subject to regular inventory constraints.

[Pull request](https://github.com/microsoft/BCApps/pull/8750) · merged into `main` (BC30) on 2026-08-04 by ventselartur · 3 files (+227 -0), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- New subscriber to Transfer Line OnBeforeCheckItemAvailable sets IsHandled when Transfer WIP Item is true
- Changing Quantity on a WIP transfer line no longer raises the item-availability warning
- Non-WIP transfer lines still run the availability check
- Subscriber only runs when subcontracting is enabled and skips temporary records
- New test codeunit plus a spy codeunit check whether the availability check ran
- Behaviour changes for users or extensions.
