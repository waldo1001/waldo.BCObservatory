# #9220 Backport SL Migration - Snapshot Project Transactions

> Support for snapshotting and migrating historical Dynamics SL project transactions is added to the SL historical data app, including new tables, viewing pages, and configuration options.

[Pull request](https://github.com/microsoft/BCApps/pull/9220) · merged into `main` (BC30) on 2026-07-09 by nikolakukrika · 25 files (+2937 -16), 25 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- New tables store migrated SL project transaction data (PJTran, PJTranEx, PJProj, PJEmploy) in both source and historical formats
- Pages added for viewing batch entries and project transaction details with project card and list extensions
- Configuration field and migration logic introduced but not yet connected to wizard pages or orchestration
- Permission sets updated to allow access to the new objects across all SL migration role sets
- Backports functionality from NAV PR with follow-up wiring deferred
- Behaviour changes for users or extensions.
