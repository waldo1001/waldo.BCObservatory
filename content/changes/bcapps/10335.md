# #10335 Unblock bc login due to pp failures

> Business Central sign-in no longer blocks when Power Platform environment lookup fails. The change handles lookup failures gracefully by logging telemetry for diagnosis while allowing sign-in to proceed.

[Pull request](https://github.com/microsoft/BCApps/pull/10335) · merged into `main` (BC30) on 2026-09-07 by rupeshdan · 2 files (+150 -8), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Prevents sign-in blocking when linked Power Platform environment lookup fails
- Lookup failures are logged to telemetry instead of being surfaced to the caller
- Null GUIDs and empty environment responses are ignored
- Returns a clear error when no Power Platform tenant is configured
- Adds integration tests for failed, null, valid and empty-response scenarios
- Behaviour changes for users or extensions.
