## What changed

- Prevents sign-in blocking when linked Power Platform environment lookup fails
- Logs telemetry for diagnosis without surfacing errors to users
- Handles null GUIDs and empty environment responses
- Returns clear error only when no Power Platform tenant is configured
- Includes integration tests for failed, null, valid, and empty-response scenarios
