# #10877 [MAIN]-Bug 648518 Source Currency VAT Amount is zero on G/L Entry when posting sales invoice with Line Discount Deferral Code and Discount Posting is No Discounts

> Fixed an issue where Source Currency VAT Amount was incorrectly set to zero on G/L entries when posting sales invoices with line discounts, deferral codes, and discount posting set to No Discounts. The VAT amount is now calculated correctly across all scenarios.

[Pull request](https://github.com/microsoft/BCApps/pull/10877) · merged into `main` (BC30) on 2026-09-07 by v-praghav · 13 files (+735 -40), 8 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- Source Currency VAT Amount now calculates correctly when deferrals, line discounts, and No Discounts posting setting are combined
- The fix ensures VAT calculation uses the formula (Unit Price - Discount) × VAT% in all cases
- All Source Currency amounts now balance correctly across G/L entries
- Test cases added to validate the fix across multiple localization layers
- The posting routine in Sales Post Invoice codeunit was corrected to handle this edge case
- Behaviour changes for users or extensions.
