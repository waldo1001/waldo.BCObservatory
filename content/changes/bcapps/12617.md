# #12617 [Security] Move URL checks from Web Request Helper to System Application Uri module

> URL validation moved from Web Request Helper using DotNet System.Uri to native System Application Uri module across multiple apps, with obsolete markers for deprecated procedures.

[Pull request](https://github.com/microsoft/BCApps/pull/12617) · merged into `main` (BC30) on 2026-10-13 by darjoo · 22 files (+281 -113), 21 AL · refactor · tier official · reviewed (checked by Opus)

## What changed

- Migrated URL validation away from DotNet with IsValidUri, IsValidUriWithoutProtocol, IsSecureHttpUrl, IsHttpUrl, and GetHostNameFromUrl
- System Application Uri module now used directly by all callers in Base App, CZ, NA, NO, and specialty apps
- Five helper procedures reimplemented on top of Uri codeunit and marked obsolete for CLEAN30
- Removed unused System.Integration directives across multiple files
- Semantics preserved: absolute URI validation, scheme checking, same error messages
