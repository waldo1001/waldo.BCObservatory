## What changed

- Posting step in demo data generation is guarded by a new SkipPostingExpenseReport() function
- Expense reports are still created; only the posting step is skipped when translations are missing
- Temporary workaround that should be removed once Expense GL Account Names translations are generated
- Affects two historical demo data codeunits: Create Posted Expense Report and Create Posted Expense Reports
- Demo data will not contain posted expense reports until the skip function is removed
- Behaviour changes for users or extensions.
