# #9140 Remap object IDs during Payment Management FR data

## What changed

- Added RemapPaymentStepObjectIDs() method to remap legacy report and xmlport IDs in Payment Step FR records during upgrade
- Built-in mapping covers standard Microsoft FR payment reports and xmlport, with zero values and unmapped IDs left untouched
- New OnAfterRemapPaymentStepObjectIDs integration event allows partners to remap custom reports and xmlports
