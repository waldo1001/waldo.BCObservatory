# #9482 Make service-invoked System Application facades callable by any user (Privacy Notice + Page Summary Provider)

> Two System Application facade codeunits now declare inherent entitlements and permissions so any authenticated user can call them in low-permission sessions like web services, OData, Copilot, and agents, instead of requiring explicit Execute permission.

[Pull request](https://github.com/microsoft/BCApps/pull/9482) · merged into `main` (BC30) on 2026-07-21 by onbuyuka · 2 files (+4 -0), 2 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- Privacy Notice and Page Summary Provider facades previously blocked non-SUPER users with NavPermissionException
- Root cause was facades missing InherentEntitlements and InherentPermissions declarations that their implementation codeunits had
- Adding inherent grants aligns facades with their delegate implementations and allows Copilot capabilities and agent tasks to function for all users
- Actual table access remains controlled by implementation codeunits' declared tabledata permissions
- Fixes permission denial for Entra tenant admins and other low-permission session users
- Behaviour changes for users or extensions.
