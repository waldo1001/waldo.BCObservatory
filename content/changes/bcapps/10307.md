# #10307 [Shopify] Fix Order Totals factbox opening an unrelated sales order for a linked posted invoice

> The Shopify Order Totals factbox now correctly resolves and displays totals for open sales orders, open sales invoices, and posted sales invoices by using the document link table, and navigates to the correct document type instead of always opening a sales order.

[Pull request](https://github.com/microsoft/BCApps/pull/10307) · merged into `main` (BC30) on 2026-08-19 by onbuyuka · 2 files (+627 -28), 1 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- Factbox resolves the linked sales document through the Shpfy Doc. Link To Doc. table with fallback to header fields for legacy orders
- Totals are computed per document type using appropriate calculation methods for open or posted documents
- Sales Document No. drill-down dispatches to the correct document type via the Shpfy IOpenBCDocument interface
- Number of Lines drill-down opens the appropriate page based on document type (Sales Lines or Posted Sales Invoice Lines)
- Stale values are cleared when the linked document can no longer be resolved
- Behaviour changes for users or extensions.
