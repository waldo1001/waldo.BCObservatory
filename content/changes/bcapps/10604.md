# #10604 [Main]-export/import of a report definition fails if the statuses in the originating company do not exist in the destination company

> Financial report and row definitions now import successfully between companies even when the status codes do not exist in the destination company. The import process clears missing status references before applying the package, allowing the definitions to be imported with empty status fields.

## What changed

- Added ClearNonExistingStatusInPackage procedure to handle missing status codes during import
- Prevents RapidStart package validation errors when status values don't exist in destination company
- Clears non-matching status references while keeping row definitions and their lines intact
- Users can manually set status after import completes
- Added test coverage for missing statuses in multiple localizations (W1, APAC, CZ, ES, RU, SE)
- Behaviour changes for users or extensions.
