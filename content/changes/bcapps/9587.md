# #9587 Concurrent posting for General Ledger entries

> The posting process for General Ledger entries now supports concurrent processing, improving performance when posting multiple journal entries simultaneously across finance, purchasing, and sales modules.

[Pull request](https://github.com/microsoft/BCApps/pull/9587) · merged into `main` (BC30) on 2026-11-09 by Alexander-Ya · 210 files (+7356 -740), 162 AL · performance · tier official · **unreviewed** (model text not yet checked)

## What changed

- Concurrent posting enabled for G/L Entry operations across multiple ledger types
- Posting codeunits (Gen. Jnl.-Post Line, Gen. Jnl.-Post Batch) restructured to handle parallel execution
- Register tables and detailed ledger entries updated to support concurrent inserts
- Changes applied consistently across localization layers (APAC, BE, CH, DACH, ES, FI, FR)
- Reports and utility codeunits adjusted to work with concurrent posting logic
- Behaviour changes for users or extensions.
