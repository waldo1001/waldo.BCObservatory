# #9445 [Extensibility Request] issue 30173: add integration events to Sales Line Discounts page

> Two integration events are added to the Sales Line Discounts page to allow extensions to customize record filtering and resolve filter descriptions for item type values without modifying base code.

[Pull request](https://github.com/microsoft/BCApps/pull/9445) · merged into `main` (BC30) on 2026-07-15 by AleksandricMarko · 1 file (+25 -0), 1 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- OnSetRecFiltersOnBeforeCurrPageUpdate is raised in SetRecFilters before CurrPage.Update so subscribers can add filters
- That event uses IncludeSender = true, matching existing events on the page
- OnGetFilterDescriptionCaseElse is raised from a new else branch in GetFilterDescription for item type values other than Item and Item Discount Group
- Event parameters use the page's ItemTypeFilter option type; the requested enum does not exist yet
