# #8947 [Permissions] Add Where-Used and Permissions Overview navigation actions

> Navigation actions have been added to Permission Sets, Permission Set cards, Table Information, and Page Inspection pages to open the Permissions Overview page with optional filters for viewing related permissions.

[Pull request](https://github.com/microsoft/BCApps/pull/8947) · merged into `main` (BC30) on 2026-07-20 by Groenbech96 · 9 files (+258 -0), 8 AL · feature · tier official · **unreviewed** (machine-generated)

## What changed

- New integration events in System Application Permissions Overview codeunit enable cross-app navigation
- Permission Sets list and card pages gain Where-Used and Permissions Overview actions
- Table Information and Page Inspection pages now support drilling down to permissions
- Integration events allow BaseApp to handle page navigation while Permissions Overview remains in BaseApp
- New PermissionsOverviewHandler codeunit bridges System Application events to BaseApp
- Behaviour changes for users or extensions.
