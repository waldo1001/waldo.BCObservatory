# #14507 [29.x]-All VAT Entries are gone through without filters with "Set G/L Account No." function.

> The Set G/L Account No. action on the VAT Entries page now correctly processes only selected or filtered entries instead of updating all entries in the database. The G/L - VAT Reconciliation report also now applies filters appropriately when processing VAT statement lines.

[Pull request](https://github.com/microsoft/BCApps/pull/14507) · merged into `releases/29.x` (BC29) on 2026-11-26 by DhavalMore88 (community contribution) · 11 files (+184 -55), 9 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- SetGLAccountNo action now uses SetSelectionFilter to process only selected or filtered VAT entries
- Buckets process from first to last selected entry number without overlapping
- Bucket range uses separate filter group to preserve selection filters
- G/L - VAT Reconciliation report only adjusts G/L Account No. for VAT Entry Totaling lines
- Fixes performance issue where large companies with millions of entries experienced long processing times
- Behaviour changes for users or extensions.
