# #9777 [Extensibility Request] issue 30377: add OnBeforePrintOnlyIfSalesCheck event in Item Sales Statistics report

> Item Sales Statistics report now exposes an integration event that allows extensions to override the skip decision for items based on sales quantity before printing, enabling custom logic for alternate UOM scenarios.

[Pull request](https://github.com/microsoft/BCApps/pull/9777) · merged into `main` (BC30) on 2026-07-30 by AleksandricMarko · 1 file (+10 -1), 1 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- New integration event OnAfterGetRecordItemOnBeforePrintOnlyIfSalesCheck allows subscribers to override the skip record decision
- Event fires after CalcFields calculates sales quantity but before CurrReport.Skip() executes
- Extensions can now influence whether items appear in the report output based on alternate-UOM sales figures
- Behavior remains unchanged when no subscribers are present
- Skip logic refactored from inline check into SkipRecord boolean variable
