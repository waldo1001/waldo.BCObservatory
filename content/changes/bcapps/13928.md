# #13928 Bug 658681: [Master Data Management] Support certificate secret for cross-environment synchronization

> Cross-environment master data synchronization now supports certificate authentication as an alternative to client secrets, with certificate storage in isolated storage and automatic validation of expiration and private keys.

[Pull request](https://github.com/microsoft/BCApps/pull/13928) · merged into `main` (BC30) on 2026-11-13 by dcenic · 7 files (+925 -48), 5 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Adds Authentication Type field to connection wizard, defaulting to Client Secret with Certificate option
- Certificate stored securely in isolated storage with thumbprint and expiration date metadata
- Validates certificate has private key, opens with password, and is not expired
- Token acquisition uses OAuth2.AcquireTokensWithCertificate when certificate is stored
- Cleanup on environment copy and setup deletion removes all stored credentials from isolated storage
- Behaviour changes for users or extensions.
