# #10480 [Bug Fix] #250: Honor ImportFSSolution TryFunction result in FS setup wizard

> The Field Service connection setup wizard now properly checks the result of the ImportFSSolution function and stops the setup process if the import fails, instead of silently continuing with an incomplete connection.

[Pull request](https://github.com/microsoft/BCApps/pull/10480) · merged into `main` (BC30) on 2026-10-14 by ventselartur · 1 file (+2 -1), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- ImportFSSolution is a TryFunction that was being called without checking its success/failure result
- Failed imports were silently ignored, allowing the wizard to proceed to update and enable the connection
- The fix wraps the call in a failure guard that stops finalization and shows the error to the user
- Follows standard BC TryFunction pattern with error surfacing instead of silent failures
- Behaviour changes for users or extensions.
