# #11961 Cache security group resolution in Effective Permissions

> Security group membership resolution is now cached by user in Effective Permissions, reducing backend calls from ~196K to nearly zero when exporting permissions to Excel by reusing the same codeunit instance across page rows.

[Pull request](https://github.com/microsoft/BCApps/pull/11961) · merged into `main` (BC30) on 2026-09-29 by darjoo · 2 files (+6 -1), 2 AL · performance · tier official · **unreviewed** (machine-generated)

## What changed

- Caches security group membership resolution in a Dictionary keyed by user security ID
- Reuses page-level EffectivePermissionsMgt instance instead of creating local instances per row
- Reduces backend calls from approximately 196K (~4 minutes) to negligible for a tenant with 36 security groups
- Cache lasts while the page is open and clears on page refresh
- Group membership changes while the page is open will not be reflected until page reopens
- Behaviour changes for users or extensions.
