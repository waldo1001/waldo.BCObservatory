# #11989 [Bug 500351] Allow Effective Permissions for delegated admins and helpdesk

> The Effective Permissions page now works for delegated admins and helpdesk users in SaaS instead of blocking them, since the underlying platform crash that prompted the original guard has been fixed.

## What changed

- Removes a check that prevented delegated admins and helpdesk users from opening the Effective Permissions page
- Allows the page to work when Authentication Object ID is empty for delegated users
- Platform has resolved the crash that originally required the guard, allowing safe removal for delegated users
- Still blocks non-delegated users without an Entra ID account
- Includes tests covering delegated admin, delegated helpdesk, and non-delegated user scenarios
