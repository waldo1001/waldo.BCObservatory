# #11989 [Bug 500351] Allow Effective Permissions for delegated admins and helpdesk

> The Effective Permissions page now works for delegated admins and helpdesk users in SaaS instead of blocking them, since the underlying platform crash that prompted the original guard has been fixed.

[Pull request](https://github.com/microsoft/BCApps/pull/11989) · merged into `main` (BC30) on 2026-09-30 by darjoo · 2 files (+111 -2), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Skips the Entra ID check in the Effective Permissions page for users with the Delegated Admin or Helpdesk plan
- Delegated users have an empty Authentication Object ID, so before this fix the page always blocked them
- The platform crash that originally required the guard has been fixed
- Non-delegated users without an Entra ID account still get the error
- Adds tests for delegated admin, delegated helpdesk and non-delegated user cases
- Behaviour changes for users or extensions.
