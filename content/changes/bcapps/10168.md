# #10168 [APAC] Keep vendor ACY on purchase invoice payables entry

> The posting engine in APAC regions now correctly preserves the vendor-calculated additional reporting currency on payables entries, preventing unbalanced ACY amounts and spurious residual entries when posting purchase invoices with blank currencies and non-zero vendor exchange rates.

[Pull request](https://github.com/microsoft/BCApps/pull/10168) · merged into `main` (BC30) on 2026-08-17 by Jose-agg · 2 files (+112 -3), 1 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- Vendor-calculated additional currency amount (ACY) is now retained in the balancing payables entry instead of being replaced with zero
- Source currency amount is calculated independently from LCY rather than reusing the ACY value
- Fixes unbalanced ACY amounts that previously created residual entries in APAC preview posting scenarios
- Change is isolated to APAC layer and does not affect W1 behavior or existing data structures
- New test validates correct ACY handling for purchase invoices with vendor exchange rates
- Behaviour changes for users or extensions.
