# #13225 Fix Bug 656636 CompAuxNum and CompAuxLib columns should be informed for Payment Discount lines on Unapplied Entries in the French Audit File

> The FEC audit file export now correctly populates CompAuxNum and CompAuxLib columns for payment discount lines on unapplied entries by using a fallback lookup based on G/L entry source type and source number.

## What changed

- Fixed missing auxiliary account information (CompAuxNum and CompAuxLib) in FEC exports for unapplied payment entries
- Added fallback logic using G/L entry source type and source number when transaction-based lookup fails
- Unapplication transactions now properly match to customer and vendor information
- Added automated tests to validate correct handling of unapplied customer and vendor entries
- Behaviour changes for users or extensions.
