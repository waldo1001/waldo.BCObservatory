# #8634 [MCP] Register MCP server as a Copilot capability

> The MCP server is now registered as a Copilot capability on the Copilot & agent capabilities page, allowing administrators to activate or deactivate it. Deactivating the capability updates the Copilot Settings status, which the platform reads to control MCP availability.

[Pull request](https://github.com/microsoft/BCApps/pull/8634) · merged into `main` (BC30) on 2026-07-21 by onbuyuka · 9 files (+187 -0), 6 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- MCP server registered as a Generally Available Copilot capability with standard Activate/Deactivate flow
- Registered automatically on install, on upgrade, and via the Copilot capabilities page subscriber
- Notifications appear on MCP Config pages when the capability is deactivated, with a link to the capabilities page
- Existing MCP configurations remain unchanged when re-activating
- Platform enforces MCP requests based on the Copilot Settings status for the MCP Server capability
- Behaviour changes for users or extensions.
