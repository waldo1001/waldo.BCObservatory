# #12326 Migrate Doc. Exchange and OCR service callers off Http Web Request Mgt.

> Document Exchange and OCR service codeunits migrate from DotNet Http Web Request Mgt to native HttpClient, removing DotNet dependencies while maintaining backward-compatible public signatures.

[Pull request](https://github.com/microsoft/BCApps/pull/12326) · merged into `main` (BC30) on 2026-10-09 by darjoo · 6 files (+922 -351), 3 AL · refactor · tier official · reviewed (checked by Opus)

## What changed

- Doc. Exch. Service Mgt. and OCR Service Mgt. now use native HttpClient, HttpRequestMessage and HttpResponseMessage instead of Http Web Request Mgt.
- Credentials, form bodies and auth headers are handled as SecretText with NonDebuggable
- DotNet XML parsing replaced by native XmlDocument and XML DOM Management overloads
- Embedded attachments are decoded with Base64 Convert into a Temp Blob instead of DotNet File/Convert and a server temp file
- OCR session cookie uses the native Cookie type with explicit re-authentication when missing or expired
