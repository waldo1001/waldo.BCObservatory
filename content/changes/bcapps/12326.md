# #12326 Migrate Doc. Exchange and OCR service callers off Http Web Request Mgt.

> Document Exchange and OCR service codeunits migrate from DotNet Http Web Request Mgt to native HttpClient, removing DotNet dependencies while maintaining backward-compatible public signatures.

[Pull request](https://github.com/microsoft/BCApps/pull/12326) · merged into `main` (BC30) on 2026-10-09 by darjoo · 6 files (+922 -351), 3 AL · refactor · tier official · **unreviewed** (model text not yet checked)

## What changed

- Native HttpClient replaces DotNet HttpWebRequest in token requests, service requests, and XML parsing
- SecretText and [NonDebuggable] attributes protect credentials and authorization headers
- DotNet XmlDocument replaced with native XmlDocument and XML DOM Management overloads
- Session cookie handling converted from DotNet Cookie to native Cookie type with explicit re-authentication logic
- Base64 encoding for embedded attachments replaces DotNet File and Convert classes
