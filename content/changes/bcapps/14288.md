# #14288 Grant report layout override permissions for non-SUPER users

> The Reporting - Edit permission set now grants necessary permissions for non-SUPER users to override extension-installed report layouts without encountering permission errors.

[Pull request](https://github.com/microsoft/BCApps/pull/14288) · merged into `main` (BC30) on 2026-11-19 by jehelles · 1 file (+1 -0), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Adds RIMD permissions for Tenant Report Layout Override table to Reporting - Edit permission set
- Resolves IndirectInsert permission errors when non-SUPER users attempt to change extension-installed layouts
- Aligns the standard user-permission set with existing report-layout table permissions
- Platform entitlement already supported the override table; this fills the user-permission gap
- No schema or data changes required
- Behaviour changes for users or extensions.
