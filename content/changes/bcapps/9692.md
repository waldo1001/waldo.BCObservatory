# #9692 Fix effective permission filtering

> The Effective Permissions page now displays specific object permissions correctly instead of showing wildcard permissions when filtering by object, ensuring the UI accurately reflects the configured authorization.

## What changed

- Permission buffer population prioritizes exact object IDs over wildcard object ID 0
- Blank permissions on exact records are treated as explicit exclusions that take precedence over wildcard grants
- UI consistency improved while effective authorization calculation remains unchanged
- New tests verify exact grants display instead of wildcard grants and exact exclusions override wildcard grants
- Low-risk change affecting only the permission UI buffer
