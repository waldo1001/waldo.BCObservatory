# #12133 Block file scheme in Web Request Helper

> Web Request Helper now rejects file:// URLs before creating HTTP requests to prevent unauthorized local file access through crafted URLs.

[Pull request](https://github.com/microsoft/BCApps/pull/12133) · merged into `main` (BC30) on 2026-09-30 by darjoo · 1 file (+7 -0), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Added validation to block file URI scheme in GetResponseTextInternal
- File URLs are rejected with a false return instead of unhandled error
- No behavior change for http/https URLs
- Reuses existing IsValidUri and IsSecureHttpUrl scheme checks
- Security fix preventing server-side file read attacks
- Behaviour changes for users or extensions.
