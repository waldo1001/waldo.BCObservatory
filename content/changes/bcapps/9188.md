# #9188 [Shopify] Create BC customer on order import when Shopify customer has no default address

> The Shopify connector now handles customer sync when no default address is set by falling back to the first available address instead of silently mapping to the default customer or erroring, ensuring orders are properly linked to newly created BC customers.

[Pull request](https://github.com/microsoft/BCApps/pull/9188) · merged into `main` (BC30) on 2026-07-09 by onbuyuka · 3 files (+87 -10), 2 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Shopify customers with no default address now fall back to the first available address
- Cust. By Email/Phone mapping (CU 30113) now creates and links a BC customer instead of returning blank, and re-reads the Shopify customer so the mapping returns the new customer number
- Update Customer (CU 30124) uses an available address instead of erroring, and errors only when the customer has no address at all
- Error label renamed from NoDefaltAddressErr to NoAddressErr with text 'No address found'
- Regression tests added for both paths
- Behaviour changes for users or extensions.
