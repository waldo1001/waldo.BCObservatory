# #9188 [Shopify] Create BC customer on order import when Shopify customer has no default address

> The Shopify connector now handles customer sync when no default address is set by falling back to the first available address instead of silently mapping to the default customer or erroring, ensuring orders are properly linked to newly created BC customers.

[Pull request](https://github.com/microsoft/BCApps/pull/9188) · merged into `main` (BC30) on 2026-07-09 by onbuyuka · 3 files (+87 -10), 2 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- Shopify customer with no default address (`defaultAddress = null`) now falls back to the first available address instead of failing silently or with an error
- Customer import (CU 30113) now creates and links a BC customer; the customer record is re-read so the mapping returns the correct customer number instead of blank
- Customer update (CU 30124) now uses an available address instead of erroring; only errors when no address exists at all
- Renamed error label from `NoDefaltAddressErr` to `NoAddressErr` to reflect corrected behavior and improve clarity
- Added regression tests confirming the fix works and guards against future breakage
- Behaviour changes for users or extensions.
