# #13813 [main] feature 624914 - Refactor depreciation calculation logic to use GetDepreciationCalculationBase for improved clarity and maintainability

> Czech Fixed Asset Localization adds an optional checkbox to deduct ending book value from the depreciation base, supporting residual-value treatment under new accounting requirements while preserving existing behavior by default.

[Pull request](https://github.com/microsoft/BCApps/pull/13813) · merged into `main` (BC30) on 2026-11-23 by DavidHolusa · 11 files (+1283 -252), 8 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Adds an 'Include Ending Book Value in Depreciation Base' checkbox to Czech Fixed Asset Setup, cleared by default
- When enabled, the ending book value is deducted from the depreciation base, but it still acts as the final floor
- Respects individual and default ending book values and Ignore Def. Ending Book Value; assets in a tax depreciation group ignore ending book value entirely
- Calculate Normal Depreciation in the Base Application gets a new integration event and a shared calculation-base helper
- Affects only later calculations; asks for confirmation when the setting is changed interactively
- Behaviour changes for users or extensions.
