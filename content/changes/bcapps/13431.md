# #13431 Extend sales document edit permissions with subscrition billing edit

> A permission set extension enables the Sales Order Agent to add items with subscription billing to sales documents by granting necessary Subscription Billing table access to users who can edit sales documents.

## What changed

- Creates new permission set extension Sub. Billing D365 S. Doc Edit that extends D365 SALES DOC, EDIT
- Grants access to Subscription Billing tables needed for items with Service Commitment Option = Sales with Subscription
- Fixes Sales Order Agent failing to add subscription items due to permission errors on Item Subscription Package and Billing Line tables
- Follows existing pattern of permission set extensions for other D365 roles in the same folder
- No schema or data changes, applies only when Subscription Billing app is installed
- Behaviour changes for users or extensions.
