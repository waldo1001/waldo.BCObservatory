# #13431 Extend sales document edit permissions with subscrition billing edit

> A permission set extension enables the Sales Order Agent to add items with subscription billing to sales documents by granting necessary Subscription Billing table access to users who can edit sales documents.

[Pull request](https://github.com/microsoft/BCApps/pull/13431) · merged into `main` (BC30) on 2026-10-30 by VolodySyn · 1 file (+8 -0), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Adds permission set extension Sub. Billing D365 S. Doc Edit (ID 8002), which extends D365 SALES DOC, EDIT
- The extension includes Sub. Billing User, so sales document editors also get Subscription Billing table permissions, including indirect insert, modify and delete
- Fixes the Sales Order Agent permission errors on Item Subscription Package and Billing Line when it adds items sold with a subscription
- Follows the existing extensions for D365 BASIC, D365 TEAM MEMBER and D365 SETUP
- No schema or data changes; takes effect only when Subscription Billing is installed
- Behaviour changes for users or extensions.
