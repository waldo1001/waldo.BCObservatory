# #9572 Obsolete E-Document Purchase Order Matching Copilot

> The E-Document Purchase Order Matching Copilot feature is marked as obsolete pending removal in version 29.0, with its core objects moved to a deprecation warning state while the replacement E-Document Purchase Draft experience handles order matching through a different code path.

[Pull request](https://github.com/microsoft/BCApps/pull/9572) · merged into `main` (BC30) on 2026-07-22 by Groenbech96 (community contribution) · 20 files (+116 -98), 16 AL · obsoletion · tier official · **unreviewed** (model text not yet checked)

## What changed

- Five Copilot-specific objects in the order matching module are marked ObsoleteState = Pending with ObsoleteTag 29.0
- The shared 'E-Document Matching Assistance' Copilot capability remains active for the E-Document AI Tool Processor import flow
- Purchase order line matching now handled by the E-Document Purchase Draft experience using codeunit 6196
- AI-assisted matching moved to import time via the E-Document AI Tool Processor
- No persisted data migration needed as the buffer table is temporary
- Breaking: existing extensions can stop compiling or working.
