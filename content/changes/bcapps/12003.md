# #12003 [Main]- Project Planning Lines are created in reverse order when purchase line descriptions are copied

> Fix project planning lines being created in reverse order when posting purchase invoices with copy line descriptions enabled.

[Pull request](https://github.com/microsoft/BCApps/pull/12003) · merged into `main` (BC30) on 2026-10-09 by DhavalMore88 (community contribution) · 10 files (+583 -60), 8 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Project Planning Lines now follow the original purchase line order instead of reverse order
- Occurs when Copy Line Descr. to G/L Entry is enabled and several G/L Account lines share a project and task
- Cause: Invoice Posting Buffer groups were processed in descending order of a key that includes the source line number
- Purch. Post Invoice now processes buffer groups in ascending source line order across all layers
- Intended not to change G/L, VAT or Job Ledger Entry posting; job consumption tests updated
- Behaviour changes for users or extensions.
