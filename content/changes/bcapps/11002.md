# #11002 [Master] - Slice 626305: [Excise Tax][VENDOR] Improving Excise Duty Calculation

> Excise duty calculation now supports rate-based models (specific-per-unit, ad valorem, hybrid) alongside the legacy item and fixed-asset rates, with a new rate table and calculation type enum to resolve duties before calculating taxable amounts.

[Pull request](https://github.com/microsoft/BCApps/pull/11002) · merged into `main` (BC30) on 2026-09-15 by v-rohangarg20 · 21 files (+1142 -82), 18 AL · feature · tier official · **unreviewed** (machine-generated)

## What changed

- Added Excise Tax Rate table and list page for flexible duty models
- Introduced Excise Calculation Type enum with specific-per-unit, ad valorem, and hybrid options
- Fixed taxable amount calculation timing by resolving final rate and calculation type first for item ledger entries
- Included migration from existing item/fixed-asset rate table to new model
- Updated permissions, pages, journal lines, and transaction logs
- Behaviour changes for users or extensions.
