# #10828 Avoid remote attachment checks during FactBox refresh

> Attachment FactBox navigation performance improved by deferring external file existence checks until explicitly requested via export or preview, preventing repeated synchronous SharePoint calls during list browsing.

[Pull request](https://github.com/microsoft/BCApps/pull/10828) · merged into `main` (BC30) on 2026-09-15 by JesperSchulz · 8 files (+301 -36), 3 AL · performance · tier official · reviewed (checked by Opus)

## What changed

- External-only attachments now rely on persisted metadata for HasContent() checks instead of making synchronous FileExists calls
- Removed automatic external provider calls from FactBox refreshes and metadata validation scenarios
- Export and preview operations now fail explicitly when external files are missing or account mappings are unconfigured
- Expense Agent content-hash updates made best-effort to avoid blocking writes on transient retrieval failures
- Added comprehensive test coverage for configured/unconfigured external storage, internal attachments, and retrieval failure scenarios
- Behaviour changes for users or extensions.
