# #10165 [Extensibility Request] issue 29901: expose item application entry before find

> Adds an event in Undo Sales Shipment Line before the filtered Item Application Entry is retrieved when undoing a drop shipment, so subscribers can adjust loaded fields and avoid JIT load-field errors on extension fields.

- New event fires before the item application entry is found in UnApplyDropShipment
- Subscribers can adjust which fields are loaded on the Item Application Entry record
- Standard load-field optimization is kept
- Added in both W1 and RU layers
- Lets extensions that add fields to Item Application Entry avoid JIT load-field errors
