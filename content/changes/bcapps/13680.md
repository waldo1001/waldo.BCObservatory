# #13680 [Excel Reports] Handle an apostrophe in the No. on the Vendor and Customer Top List

> Excel reports for top vendor and customer lists now handle apostrophes in account numbers correctly by properly escaping quotes in filter expressions.

[Pull request](https://github.com/microsoft/BCApps/pull/13680) · merged into `main` (BC30) on 2026-11-20 by Franco111000 (community contribution) · 3 files (+123 -8), 2 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Fixed NavInvalidFilterExpressionException when vendor or customer numbers contain apostrophes
- Escape helper now doubles internal quotes and uses Text parameter type instead of Code
- Single-value buffer lookups converted to SetRange for exact comparison instead of filter parsing
- Added tests verifying exports with apostrophes at start, middle, and end of account numbers
- No breaking changes; local helper modification affects only these reports
- Behaviour changes for users or extensions.
