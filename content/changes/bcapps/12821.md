# #12821 [SOA] Copy manual task attachments to sales quotes

> Sales Order Agent now copies manual task attachments to sales quotes by tracking transfers in a new internal table instead of relying on email rows.

[Pull request](https://github.com/microsoft/BCApps/pull/12821) · merged into `main` (BC30) on 2026-10-28 by qasimikram · 4 files (+143 -29), 4 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Adds internal table 4590 SOA Attachment Transfer to track which attachments have been copied from task messages to quotes
- Copies attachments from task input messages (mailbox, manual, Try it out) not just from email rows
- Prevents duplicate attachments by checking transfers and verifying destination attachments still exist
- Excludes output messages and ignored attachments from copying
- Uses SaveAttachmentFromStream with LockTable to ensure thread-safe, transactional copying
- Behaviour changes for users or extensions.
