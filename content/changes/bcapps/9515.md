## What changed

- Fixed incorrect withholding tax calculations when using rules other than 'Less than'
- Created a reusable ShouldCreateWithholdingTax procedure that respects the configured calculation rule
- Updated threshold checks across multiple codeunits to use the new rule-aware logic instead of hard-coded comparisons
- Withholding tax is now created or suppressed based on the actual configured rule, not always the 'Less than' rule
- Added comprehensive tests to verify correct behavior for all calculation rule options
