# #11483 [E-Documents Core] - Linkage & Traceability

> The E-Documents module now provides linkage and traceability by adding lookup functions to navigate from posted and ledger documents back to their associated E-Documents, with status and message FactBoxes displayed across all relevant sales, purchase, and service document pages.

[Pull request](https://github.com/microsoft/BCApps/pull/11483) · merged into `main` (BC30) on 2026-09-24 by GediminasGaubys (community contribution) · 34 files (+2137 -58), 33 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- New table methods enable finding E-Documents by document identity (number, posting date, partner, direction, type) with fallback logic for related document types
- Status FactBox displays linked E-Document status and aggregated service delivery status across all transmission channels
- Messages FactBox shows E-Document message history with ability to download raw XML payloads
- Open E-Document action wired into 30+ document list and card pages across sales, purchase, service, and other modules
- Comprehensive test coverage added for the new lookup and linkage procedures
- Behaviour changes for users or extensions.
