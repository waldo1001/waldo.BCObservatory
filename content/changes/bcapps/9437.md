# #9437 [Extensibility Request] issue 30339: add OnAfterCalcAvailableQtyBase event to Whse. Worksheet Line

> An integration event was added to the warehouse worksheet line calculation to allow extensions to adjust the available quantity after the standard calculation completes.

[Pull request](https://github.com/microsoft/BCApps/pull/9437) · merged into `main` (BC30) on 2026-07-15 by AleksandricMarko · 1 file (+7 -0), 1 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- New OnAfterCalcAvailableQtyBase event enables extensions to modify calculated available quantity
- Eliminates the need for extensions to reimplement entire CalcAvailableQtyBase logic
- Supports scenarios like stock ring-fencing that require tweaking results based on standard calculation
- Event is raised at the end of CalcAvailableQtyBase procedure with calculated AvailableQty parameter
- Complements the existing OnBeforeCalcAvailableQtyBase event with post-calculation flexibility
