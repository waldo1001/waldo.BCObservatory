# #9838 Grant indirect read on Privacy Notice tables in Privacy Notice Impl.

> The Privacy Notice Impl. codeunit now grants indirect read permission on Privacy Notice and Privacy Notice Approval tables to allow non-SUPER users to check privacy notice approval state in Copilot and service sessions without NavPermissionException.

- Added indirect read permission (`rim`) to Privacy Notice table in the codeunit's Permissions property
- Added indirect read permission (`r`) to Privacy Notice Approval table
- Enables capability checks to succeed before a company is opened when role permissions resolve to None
- Paired with platform change that adds inherent indirect read (`rX`) to these system tables
- Maintains least-privilege principle by requiring explicit indirect read declaration
