- Replaced FindFirst() with FindSet() in the dimension-set rebuild loop on APIV2DimensionSetLines.Page.al
- FindSet() is the correct retrieval pattern for iterating an entire filtered result set
- Reduces database round trips and improves APIV2 performance with larger dimension line counts
- Functional behavior unchanged; loop logic and exit conditions remain identical
