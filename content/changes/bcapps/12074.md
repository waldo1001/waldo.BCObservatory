# #12074 Expense Agent: travel request expense location, per-traveler reports, activity log and submitter comment

> The Expense Agent travel request feature now supports expense location selection using per diem rules, creates per-traveler expense reports on approval, logs the full request lifecycle, enables rejection with automatic reopen, and allows submitter comments for resubmissions.

[Pull request](https://github.com/microsoft/BCApps/pull/12074) · merged into `main` (BC30) on 2026-10-02 by claudiuciumedean · 19 files (+2196 -365), 15 AL · feature · tier official · **unreviewed** (machine-generated)

## What changed

- Expense location field replaces three obsolete country/region fields and enforces location+date validation when per diem is enabled
- Approving a travel request creates separate expense reports for each additional traveler, with employee validation and removal restrictions
- Activity log tracks travel request lifecycle (created, submitted, resubmitted, approved, rejected) with separate entries for generated expense reports
- Reject action reopens the request immediately so submitters can resubmit without a separate call
- New submitTravelRequestWithComment action allows comments during resubmission, stored in read-only field
- Behaviour changes for users or extensions.
