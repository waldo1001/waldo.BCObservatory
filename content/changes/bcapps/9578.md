# #9578 [E-Documents Core] - Enabling remittance advice export via E-Documents (payment journal + posted payments)

> E-Documents now supports exporting remittance advice from payment journals and posted vendor payments as PEPPOL BIS 3.0 UBL 2.1 XML documents. The existing UK remittance advice email functionality moves into the base application, while legacy page extensions are marked obsolete.

[Pull request](https://github.com/microsoft/BCApps/pull/9578) · merged into `main` (BC30) on 2026-08-11 by AndriusAndrulevicius (community contribution) · 71 files (+3905 -15), 66 AL · feature · tier official · **unreviewed** (machine-generated)

## What changed

- New 'Remittance Advice' E-Document type with data assembly, validation, and PEPPOL 3.0 export
- Opt-in checkbox on remittance advice reports creates E-Documents for each payment
- Shared math codeunit ensures E-Document data matches printed reports
- UK remittance advice email actions moved from extension into base application pages
- Old UKSendRemittanceAdvice page extensions marked obsolete
- Breaking: existing extensions can stop compiling or working.
