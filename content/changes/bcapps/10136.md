# #10136 [CH][SEPA CT] Export requires both IBAN and Clearing No. for domestic payments and refunds

> Swiss SEPA CT export now automatically extracts the clearing number from the IBAN when not explicitly provided, ensuring both values are populated for domestic payments and refunds.

[Pull request](https://github.com/microsoft/BCApps/pull/10136) · merged into `main` (BC30) on 2026-08-17 by dcenic · 5 files (+224 -2), 3 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Clearing No. is now extracted from the IBAN when it is blank
- Payment type determination uses the extracted clearing number
- MmbId in the Swiss SEPA CT file is populated with the clearing number instead of an invalid value
- Vendor payments that already have a clearing number produce identical output
- Tests added in both Swiss SEPA CT export test codeunits
- Behaviour changes for users or extensions.
