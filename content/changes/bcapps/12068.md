> The Completely Picked calculation for production orders now includes components supplied by other production-order lines, ensuring warehouse picks are generated for make-to-order subassemblies after put-away registration.

## What changed

- Fixed FlowField calculation to include supplied-by components when determining if a production order is completely picked
- Prevents premature completion of warehouse pick requests when subassemblies remain unpicked
- Enables follow-up warehouse picks to be generated for supplied components
- Added regression tests for fully picked and mixed picked/unpicked components
