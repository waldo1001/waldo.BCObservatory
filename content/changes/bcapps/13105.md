# #13105 [MCP] Warn when configurations have no tools

> The MCP configuration validation framework now warns when a configuration has no tools or agents enabled, including an 'Empty Configuration' rule that checks for enabled API/agent features and read-only discovery or Data Query Tools.

[Pull request](https://github.com/microsoft/BCApps/pull/13105) · merged into `main` (BC30) on 2026-10-27 by onbuyuka · 4 files (+297 -1), 3 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- New 'Empty Configuration' warning rule added to detect configurations with no configured APIs, agents, or discovery tools
- Warning uses configuration-filtered IsEmpty() checks for API and agent features
- Read-only discovery and Data Query Tools are considered when determining if configuration is non-empty
- Warning is overridable and opens configuration for review without automatically enabling features
- No schema, permission, or public API signature changes
- Behaviour changes for users or extensions.
