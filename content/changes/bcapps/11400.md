# #11400 [Shopify] Handle missing variant mapping in product action

> The Show product in Shopify action on the Item Card and Item List is now enabled only when the item has a Shopify Variant linked through an enabled shop. If the variant mapping disappears before the action runs, users get clear guidance instead of a raw database filter error.

[Pull request](https://github.com/microsoft/BCApps/pull/11400) · merged into `main` (BC30) on 2026-09-18 by onbuyuka · 4 files (+86 -40), 3 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Action enabled only when item has a valid Shopify Variant linked through an enabled shop
- Clear error guidance provided if variant mapping disappears between page rendering and action invocation
- Same validation behavior applied to both Item Card and Item List pages
- No schema or data changes; existing valid mappings unaffected
- Regression tests added for the new validation logic
- Behaviour changes for users or extensions.
