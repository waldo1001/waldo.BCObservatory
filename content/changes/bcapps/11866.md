# #11866 [Shopify] Disable Sync Shipments To Shopify when no Shopify orders exist

> The Sync Shipments To Shopify action on the Shopify Orders page is now disabled when no applicable Shopify orders exist. The check honors the Shop Code filter from the Shop Card and ignores other page filters, so a visually empty page does not wrongly disable the action.

[Pull request](https://github.com/microsoft/BCApps/pull/11866) · merged into `main` (BC30) on 2026-10-01 by onbuyuka · 1 file (+11 -0), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Sync Shipments To Shopify is disabled when no applicable Shopify order headers exist
- The Shop Code filter is honored when the page is opened from a Shopify Shop Card
- Customer, company, status, view and user filters are ignored for this check
- Only the action's enabled state changes; there are no data model, API or permission changes
- Behaviour changes for users or extensions.
