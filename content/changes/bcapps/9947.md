# #9947 Allow long localized sales and purchase line type captions

> Line type captions in sales and purchase documents can now display up to 30 characters instead of 20, supporting longer localized text like French allocation account names without formatting failures.

[Pull request](https://github.com/microsoft/BCApps/pull/9947) · merged into `main` (BC30) on 2026-08-13 by djukicmilica · 120 files (+1944 -329), 94 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- Added FormatTypeAsText() method returning Text[30] to sales, purchase, and standard line tables
- Updated UI and lookup paths to use the new 30-character formatting method
- Preserved existing FormatType(): Text[20] and OnBeforeFormatType() as obsolete compatibility layers
- Introduced new Text[30] events for subscribers needing wider output capacity
- Added regression tests covering long localized captions and legacy event precedence
- Breaking: existing extensions can stop compiling or working.
