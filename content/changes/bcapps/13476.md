# #13476 [Fabric] Separate workspace read and write scopes

> Fabric mirroring now uses read-only workspace scopes for browsing operations and requests write permission only for workspace role assignments, with manual setup instructions as fallback.

[Pull request](https://github.com/microsoft/BCApps/pull/13476) · merged into `main` (BC30) on 2026-11-04 by onbuyuka · 2 files (+36 -12), 2 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Workspace browsing and Open Mirroring database operations now use Workspace.Read.All for read-only access
- Add to workspace feature exclusively requests Workspace.ReadWrite.All permission
- If token acquisition for write permission fails, users see manual instructions to grant Contributor access in Fabric
- Underlying authentication errors are preserved in error details
- Custom-app default authentication flow remains unchanged
- Behaviour changes for users or extensions.
