# #10209 Promote AA0471, AA0472 and AA0474 to Error in the base ruleset

> Three analyzer rules (AA0471, AA0472, AA0474) are promoted from None to Error in the base ruleset, with violations in the Withholding Tax app fixed by adding missing AutoFormatExpression attributes to amount fields.

[Pull request](https://github.com/microsoft/BCApps/pull/10209) · merged into `main` (BC30) on 2026-08-14 by JesperSchulz · 4 files (+8 -25), 3 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- AA0472 had no violations and its override was removed
- AA0471 and AA0474 had one and five violations respectively, all fixed by adding AutoFormatExpression currency specifications
- Amount fields in Withholding Tax Entry and WHT Empl. Ledger Entry Ext now reference the Currency Code field for formatting
- WHT Threshold Accumulator uses an empty AutoFormatExpression to indicate local currency only amounts
- Ruleset hardening improves code quality enforcement across the base configuration
