# #10717 Enable amount formatting with currency symbols

> Amount formatting now supports displaying currency symbols or ISO codes before or after values using AL format-string tokens, with a new Default position option that defers to General Ledger Setup settings.

## What changed

- Currency Symbol Position enum gains Default value with IDs re-mapped
- Amount formatting uses AL `<S,...>` tokens to embed currency text as part of formatting
- Foreign currencies can now inherit position settings from General Ledger Setup when their position is Default
- Upgrade code preserves existing configuration across all country layers
- Tests split into session-isolated codeunits covering symbol/code combinations and positions
- Breaking: existing extensions can stop compiling or working.
