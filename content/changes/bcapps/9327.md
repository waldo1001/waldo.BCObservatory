# #9327 [Shopify] Migrate Shopify Connector to Expiring Offline Access Tokens

> The Shopify Connector now supports Shopify's expiring offline access tokens with automatic refresh-token rotation. The connector transparently migrates legacy non-expiring tokens to expiring tokens during API calls and refreshes tokens before expiry, with a user notification when the refresh token expires.

[Pull request](https://github.com/microsoft/BCApps/pull/9327) · merged into `main` (BC30) on 2026-08-05 by onbuyuka · 10 files (+638 -21), 4 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- New token fields and expiry tracking added to the Shopify Registered Store table
- Automatic token migration from non-expiring to expiring tokens during first API call
- Refresh token orchestrator integrated into every API call via the Communication Manager
- Reactive 401 error handling with single retry on token refresh failure
- User notification on Shop Card when refresh token expires
- Behaviour changes for users or extensions.
