# #14331 Fix trailing periods in generated document attachment folders

> Document attachment external storage now removes trailing periods from generated table folder names, so uploads for tables like Purch. Cr. Memo Hdr. are no longer rejected by SharePoint. An empty result falls back to Table_<TableID>.

[Pull request](https://github.com/microsoft/BCApps/pull/14331) · merged into `main` (BC30) on 2026-11-20 by JesperSchulz · 5 files (+194 -1), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Removes trailing periods from generated table folder names after reserved-character removal and truncation
- Falls back to Table_<TableID> format when normalization results in an empty name
- Applies normalization consistently across directory lookup, creation, and upload operations
- Extends connector mock to capture directory paths for regression testing
- Only affects newly generated folder names; existing folders and historical files remain unchanged
- Behaviour changes for users or extensions.
