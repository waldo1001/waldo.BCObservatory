# #12291 [Quality Management] Pass the single tracking record and clear the right filter in the purchase receipt subscriber

> Fixed two defects in purchase receipt handling where the tracking buffer filter cleanup targeted the wrong field and the wrong buffer was passed to inspection creation, with comprehensive test coverage added.

## What changed

- Filter cleanup now clears correct field 'Quantity Handled (Base)' instead of 'Qty. to Invoice (Base)'
- Single-record buffer now passed to inspection creation instead of full posting buffer
- Downstream subscribers now receive filtered buffer only for intended tracking records
- Post-event subscribers receive correct buffer state for their processing
- Added two new tests covering multi-lot tracking and filter cleanup validation
