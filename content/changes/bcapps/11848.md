# #11848 [main] Report 11564, Foreign Currency Layout: foreign currency opening balance is not included

> Report 11564 now correctly includes foreign currency opening balances for G/L accounts with multiple registered source currencies, fixing previously understated running FCY balances.

[Pull request](https://github.com/microsoft/BCApps/pull/11848) · merged into `main` (BC30) on 2026-10-06 by Shikhverma · 2 files (+231 -7), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Opening balance for accounts with multiple registered source currencies was incorrectly set to 0 instead of summing balances across all currencies
- New helper method CalcSourceCurrencyOpeningBalance() calculates opening balance by summing across all registered currencies when source currency code is blank
- Single-currency account behavior remains unchanged
- Test coverage added for accounts with multiple registered source currencies
- Behaviour changes for users or extensions.
