# #11611 [Shopify] Add GraphQL type to request telemetry

> Shopify request telemetry now includes a GraphQL Type custom dimension that captures the query type name for typed requests while preserving privacy by not exposing query contents or variables.

[Pull request](https://github.com/microsoft/BCApps/pull/11611) · merged into `main` (BC30) on 2026-09-22 by onbuyuka · 2 files (+28 -12), 2 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- New GraphQL Type dimension added to telemetry event 0000K8W
- Typed requests emit the enum value name; untyped requests emit empty value
- Dimension value persists through HTTP and GraphQL retry paths
- Enables grouping telemetry by query type without exposing sensitive data
- Change is additive with no impact on existing request behavior
- Behaviour changes for users or extensions.
