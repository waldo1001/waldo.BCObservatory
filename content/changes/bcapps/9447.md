# #9447 [Extensibility Request] issue 30239: add OnBeforeOnRunOnCheckWarehouse event in Mfg. Item Jnl. Check Line

> A new OnBeforeOnRunOnCheckWarehouse integration event enables extensions to conditionally bypass manufacturing warehouse validation for specific item journal transactions without affecting standard behavior.

## What changed

- New IntegrationEvent publisher added to Mfg. Item Jnl. Check Line codeunit
- Extensions can set IsHandled to skip manufacturing checks for their own transactions
- Allows Consumption/Output transactions to bypass validation when intentionally needed
- Preserves existing validation for all other scenarios
- Event provides access to ItemJournalLine, CalledFromAdjustment, and CalledFromInvtPutawayPick parameters
