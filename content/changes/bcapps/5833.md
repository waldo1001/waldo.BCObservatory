# #5833 Add Microsoft Graph API Support to SharePoint Connector

> The SharePoint Connector now supports Microsoft Graph API as an alternative to REST API, enabling downloads of files larger than 150 MB through chunked transfers while maintaining backward compatibility.

[Pull request](https://github.com/microsoft/BCApps/pull/5833) · merged into `main` (BC30) on 2026-07-16 by tinestaric (community contribution) · 13 files (+2463 -239), 7 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Added a toggle to choose between Graph API and legacy REST API implementations
- New helper codeunits encapsulate Graph and REST operations separately
- Graph API enables chunked downloads to bypass the 150 MB response size limit
- Existing accounts default to REST API on upgrade to prevent breaking changes
- Comprehensive test coverage for both API paths, account storage, and routing logic
- Behaviour changes for users or extensions.
