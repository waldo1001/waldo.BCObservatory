# #12322 [QM] Destination bin code is now visible and usable for the user

> Quality Management now allows users to select and use destination bin codes when creating manual transfer orders, with bin selection validated for bin-mandatory locations.

[Pull request](https://github.com/microsoft/BCApps/pull/12322) · merged into `main` (BC30) on 2026-10-15 by 6CRIPT · 6 files (+348 -9), 3 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Manual Create Transfer Order in Quality Management gets a destination bin selection
- Bin can only be selected for bin-mandatory, non-directed destination locations
- The chosen bin is validated against the selected destination location
- The selected bin is stored in Transfer-To Bin Code on the transfer line
- A new permission set, QltyMgmt - Bin View, was added
- Behaviour changes for users or extensions.
