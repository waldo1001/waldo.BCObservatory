# #12322 [QM] Destination bin code is now visible and usable for the user

> Quality Management now allows users to select and use destination bin codes when creating manual transfer orders, with bin selection validated for bin-mandatory locations.

[Pull request](https://github.com/microsoft/BCApps/pull/12322) · merged into `main` (BC30) on 2026-10-15 by 6CRIPT · 6 files (+348 -9), 3 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- Destination bin code field added to manual Create Transfer Order action in Quality Management
- Bin selection enabled only for bin-mandatory, non-directed locations
- Selected bin code is validated against the destination location
- Destination bin code propagates to the transfer order line
- New permission set QltyMgmtBinView controls access to bin code visibility
- Behaviour changes for users or extensions.
