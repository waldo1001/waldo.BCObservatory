# #13641 Bug 647022: [Subcontracting] Use alternative worksheet names and migrate the legacy page

> Subcontracting initialization now preserves existing customer templates and uses alternative worksheet names when the default SUBCONTR name is unavailable, while migrating the legacy page ID only from the old Subcontracting Worksheet.

[Pull request](https://github.com/microsoft/BCApps/pull/13641) · merged into `main` (BC30) on 2026-11-11 by ChethanT · 6 files (+684 -7), 3 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Prevents silent replacement of non-Subcontracting templates named SUBCONTR by preserving customer templates
- Generates alternative names (SUBCONTR1, SUBCONTR2, etc.) within 10-character limit when default name is unavailable
- Migrates Page ID only from the legacy Subcontracting Worksheet (99000886) to the new worksheet
- Reuses existing Subcontracting-type templates before creating new ones, preventing duplicates on repeated initialization
- Maintains existing template identity, descriptions, recurring settings, and batch configurations except for explicit legacy page migration
- Behaviour changes for users or extensions.
