# #9857 [main] bug 644746 - Add configurable EPO Service Setup for gov.cz domain migration

> A configurable EPO Service Setup table and page allow Czech administrators to manage the Electronic Filing Office endpoint URL when migrating from adisspr.mfcr.cz to mojedane.gov.cz, replacing hardcoded values with admin-configurable settings and registering the service in Service Connections.

## What changed

- New EPO Service Setup table and page enable administrators to configure the EPO endpoint URL instead of hardcoding it
- Default URL updated to https://mojedane.gov.cz/dpr/ for the Czech Financial Administration migration
- EPO service registered as a Service Connection for discoverability and status management
- GetHttpResonse() method renamed to GetHttpResponse() fixing a typo in the internal codeunit
- Auto-initialization on first access ensures seamless upgrade without requiring separate migration logic
- Behaviour changes for users or extensions.
