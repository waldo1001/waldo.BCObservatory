# #13999 Intrastat export XML performance improvement

> Codeunit 1283 now buffers Data Exch. Field rows in memory and reads from the temporary table instead of querying the database for each XML line and column, eliminating tens of thousands of round trips during large Intrastat exports. Progress dialogs were added to show export status.

[Pull request](https://github.com/microsoft/BCApps/pull/13999) · merged into `main` (BC30) on 2026-11-18 by VolodySyn · 1 file (+77 -8), 1 AL · performance · tier official · reviewed (checked by Opus)

## What changed

- Data Exch. Field rows are loaded once into a temporary record using FindSet, reducing database round trips from thousands to one
- New GetDataExchFieldValue overload reads from the in-memory buffer instead of the database
- Progress dialogs display during read and write phases, with update frequency scaling (1, 10, or 100 lines) based on total line count
- Dialogs only appear when GuiAllowed() is true, so background sessions see no UI changes
- Generated XML output remains identical; existing events and the original GetDataExchFieldValue overload are preserved
- Behaviour changes for users or extensions.
