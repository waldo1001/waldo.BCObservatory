# #11511 [29.x]Bug 647991 Assembly-to-Order Item Incorrectly Blocks Shipment of Unrelated Sales Order Line

> Fixed an issue where posting an inventory pick for a non-ATO sales line could fail when an unrelated ATO line on the same order had outstanding warehouse activity. The fix prevents unnecessary updates to the assembly order when warehouse activity is still pending.

[Pull request](https://github.com/microsoft/BCApps/pull/11511) · merged into `releases/29.x` (BC29) on 2026-09-17 by MSNehaNawal · 14 files (+205 -12), 13 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Non-ATO sales lines can now post independently without being blocked by unrelated ATO items
- Added logic to skip assembly order quantity updates when warehouse activities are still outstanding
- Event subscriber on warehouse activity post prevents errors from unrelated assembly-to-order lines
- Fixes posting failures that occurred when mixed ATO and non-ATO items shared a sales order
- Behaviour changes for users or extensions.
