# #13801 [29.x][ALL-E] Report 713 "Inventory Custmer Sales" – Excel (data only) export generates one row per Item Ledger Entry with NULL values instead of one aggregated row per Item/Customer combination - Copy

> Report 713 Inventory - Customer Sales no longer emits intermediate rows with only item data and NULL customer values in Excel (data only) export. CurrReport.Skip() is called when the aggregate buffer is empty, so the output has one aggregated row per Item/Customer combination.

[Pull request](https://github.com/microsoft/BCApps/pull/13801) · merged into `releases/29.x` (BC29) on 2026-11-12 by sanjmaurya · 2 files (+68 -0), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Rows are skipped when the temporary aggregate buffer is empty
- Excel (data only) export now gives one aggregated row per Item/Customer combination
- Customer aggregates, subtotals, grand totals and the Word layout are preserved
- A regression test was added in SCM Inventory Reports tests
- Behaviour changes for users or extensions.
