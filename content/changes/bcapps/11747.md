# #11747 [master][Subscription Billing] Sales-Explode BOM fails for foreign-currency customers

> Fixed a 'Sales Line does not exist' error when exploding an Assembly BOM on a sales order for a foreign-currency customer. GetDate() in the Sales Subscription Line table now reuses the cached in-memory Sales Line via GetSalesLine before falling back to a database lookup.

[Pull request](https://github.com/microsoft/BCApps/pull/11747) · merged into `main` (BC30) on 2026-09-24 by neeleshsinghal · 2 files (+47 -1), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Exploding BOMs on foreign-currency sales orders raised 'Sales Line does not exist' error
- Root cause was direct database lookup of Sales Line during BOM explosion when the line only existed in memory
- Changed GetDate() to use GetSalesLine() method to leverage cached Sales Line before fallback database lookup
- Added test coverage for the foreign-currency BOM explosion scenario
- Affects Subscription Billing feature in sales order processing
- Behaviour changes for users or extensions.
