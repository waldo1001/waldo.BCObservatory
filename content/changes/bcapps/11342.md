# #11342 [29.x][ALL-E] Document Type is Quote in Document Attachment table (1173) after posting a Sales Invoice with attachmentsIntial Commit

> Document attachments transferred after posting a sales invoice or credit memo now correctly retain the posted document type instead of being incorrectly set to Quote.

[Pull request](https://github.com/microsoft/BCApps/pull/11342) · merged into `releases/29.x` (BC29) on 2026-09-29 by sanjmaurya · 4 files (+409 -2), 2 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Attachment transfers during document posting were clearing the document type field, defaulting to Quote enum value 0
- Logic updated to explicitly set document type based on the posted document table
- Posted invoice attachments now have Invoice type, posted credit memos have Credit Memo type
- Regression tests added to verify correct document type assignment for both header and line attachments
- Behaviour changes for users or extensions.
