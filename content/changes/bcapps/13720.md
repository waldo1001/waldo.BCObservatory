# #13720 Split the MS-STD configuration package into functional-area packages

> The MS-STD configuration package is split into nine functional-area packages (Finance, Inventory, Inventory Valuation, Manufacturing, Projects, Purchase, Sales, Subscription Billing, and Sustainability). New installations register these packages as inactive, while upgrades activate the new packages and remove the legacy MS-STD package.
