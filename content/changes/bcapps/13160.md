# #13160 [Main][all-e]Changing Negative Amount Format to Parentheses modifies displayed decimal precision despite unchanged rounding settings in the Financial Reports

> Fixed an issue where selecting parentheses for negative amounts in Financial Reports incorrectly changed the displayed decimal precision instead of respecting the configured rounding settings.

## What changed

- Negative amount formatting was using a hardcoded two-decimal pattern instead of the configured precision
- The fix applies rounding first, then wraps negative values in parentheses
- Preserves existing rounding behavior when changing negative number display format
- Updates impact the Matrix Management codeunit and Account Schedule Overview page
- Test cases updated across multiple localization layers to reflect corrected behavior
