# #10036 [SOA]: Bugbash for releases 28.x - Contact unable to find due to Qasim map to Megan, different names

> Sales Order Agent now correctly maps unknown senders to alternative contacts and routes replies to the mapped contact's email address while preserving thread context and original recipients.

[Pull request](https://github.com/microsoft/BCApps/pull/10036) · merged into `main` (BC30) on 2026-08-13 by tomasevicst · 19 files (+542 -56), 18 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- Contact lookup resolves sender mappings stored in SOA Task Contact Override
- E-Mail 2 field on Contact table stores alternate email addresses for persistent mappings
- Reply routing respects contact mappings and addresses replies to the mapped contact's primary email
- Contact List exposes OnBeforeFindRecord event handled only during SOA sessions
- Agent instructions updated to accept mapped contacts without requiring user confirmation
- Behaviour changes for users or extensions.
