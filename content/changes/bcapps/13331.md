# #13331 [Main]-Warehouse Picks Creating Incorrect Line Splitting final pick.

> Create Pick now correctly assigns lot quantities when breakbulk is disabled and FEFO is enabled, preventing shipments from being underpicked by ensuring only inventory in the requested unit of measure counts toward lot availability.

[Pull request](https://github.com/microsoft/BCApps/pull/13331) · merged into `main` (BC30) on 2026-11-24 by DhavalMore88 (community contribution) · 2 files (+208 -0), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Fixed lot quantity calculation in FEFO picking to respect unit of measure constraints when breakbulk is not allowed
- New CalcQtyAvailToPickInUnitOfMeasure procedure calculates how much of a lot can be picked from bins holding the requested unit only
- Prevents scenarios where the first-expiring lot could be assigned more quantity than physically available in the requested unit of measure
- Ensures subsequent lots receive the remaining quantity needed to fulfill shipments completely
- Added regression tests for single and multiple shipment scenarios
- Behaviour changes for users or extensions.
