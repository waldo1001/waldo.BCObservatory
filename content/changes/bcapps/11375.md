# #11375 Obsolete GPT-5.5 chat and add GPT-5.6 Ceres deployments

> GPT-5.5 chat deployment getters in AOAI Deployments are marked obsolete because those deployments retire on 11 September 2026. New GPT-5.6 Ceres latest and preview getters are added, and Sales Order Agent attachment extraction and item search now use them.

[Pull request](https://github.com/microsoft/BCApps/pull/11375) · merged into `main` (BC30) on 2026-09-23 by darjoo · 8 files (+162 -8), 6 AL · obsoletion · tier official · reviewed (checked by Opus)

## What changed

- GetGPT55ChatLatest() and GetGPT55ChatPreview() methods marked obsolete in version 30.0 with retirement telemetry
- New GetGPT56CeresLatest() and GetGPT56CeresPreview() methods added returning gpt-56-ceres deployment models
- Sales Order Agent attachment extraction and item search callers migrated to GPT-5.6 Ceres deployments
- GPT-5.5 preview retained for file-content compatibility until cleanup, GPT-5.6 preview enabled for file-content messages
- Five AL tests added covering deployment names, obsolete method retention, file-content preview support, and unsupported model rejection
- Behaviour changes for users or extensions.
