# #10775 [Shopify] Optimize unmapped cue counts

> Shopify cue counts for unmapped items now use stored SystemId fields and a new key to enable efficient SQL queries instead of materializing tables row by row during Role Center refresh.

[Pull request](https://github.com/microsoft/BCApps/pull/10775) · merged into `main` (BC30) on 2026-09-02 by onbuyuka · 2 files (+6 -3), 2 AL · performance · tier official · **unreviewed** (machine-generated)

## What changed

- Changed cue calculations to count empty Customer and Item SystemId fields instead of using lookup FlowFields
- SQL can now execute direct COUNT(*) queries instead of materializing source tables
- Added a new key led by Item SystemId for efficient global unmapped-product seeking
- Records with deleted Customer or Item references are no longer included in counts
- Behaviour changes for users or extensions.
