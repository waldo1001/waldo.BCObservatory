# #13469 [SOA] Do not show duplicate-contact notification on outgoing email

> The Sales Order Agent no longer displays the duplicate-contact notification on outgoing email review pages, preventing users from making conflicting customer information changes after content generation.

[Pull request](https://github.com/microsoft/BCApps/pull/13469) · merged into `main` (BC30) on 2026-11-02 by VolodySyn · 1 file (+2 -2), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Duplicate-contact notification is now shown only on incoming messages where it matters for customer selection
- Outgoing messages no longer show the notification, avoiding confusion when recipient and content are already finalized
- Change adds a type check requiring Rec.Type::Input before displaying the notification
- Contact and customer information remains consistent with the generated email body and quote
- No schema, data, permission or API changes, only UI refinement
- Behaviour changes for users or extensions.
