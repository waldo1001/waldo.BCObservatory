# #13294 [29.x]-Exporting vendor remittance gets stuck when a payment jour nal is sorted by Document No.

> Fixed an issue where exporting vendor remittance advice from a payment journal sorted by Document No. would hang indefinitely by ensuring lines are processed in primary key order instead of the current sort order.

[Pull request](https://github.com/microsoft/BCApps/pull/13294) · merged into `releases/29.x` (BC29) on 2026-10-30 by DhavalMore88 (community contribution) · 2 files (+52 -0), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Vendor remittance export now completes successfully when payment journal is sorted by Document No.
- Solution uses SetCurrentKey to force processing by primary key (Journal Template Name, Journal Batch Name, Line No.) which doesn't change during export.
- Prevents infinite loop caused by Document No. changes moving already-processed lines ahead in sort order.
- Added regression test ExportPaymentJournalSortedByDocumentNo to prevent recurrence.
- Behaviour changes for users or extensions.
