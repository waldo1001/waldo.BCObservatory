# #12214 [Shopify] Store currency handling for auto-created orders

> The Shopify connector now persists the currency handling mode used during order processing to the Shopify order record, ensuring the stored value reflects the actual mode applied to the created sales document even if the shop configuration changes during synchronization.

[Pull request](https://github.com/microsoft/BCApps/pull/12214) · merged into `main` (BC30) on 2026-10-06 by onbuyuka · 3 files (+111 -3), 2 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Currency handling mode is now stored in the Shopify order processor from the same shop snapshot that creates the sales document
- Both automatic and manual order processing wrappers preserve the currency handling value
- Prevents stale or incorrect Processed Currency Handling values if shop settings change during synchronization
- Regression test enhanced to verify the stored mode matches the resulting document
- Behaviour changes for users or extensions.
