# #10901 [Extensibility Request] issue 30428: add sales order line update event

> A new event OnBeforeUpdateSalesOrderLineIfExist allows extensions to intercept and override the default sales order line update logic during sales return order posting, enabling custom handling of prepayment amounts.

[Pull request](https://github.com/microsoft/BCApps/pull/10901) · merged into `main` (BC30) on 2026-09-02 by AleksandricMarko · 12 files (+192 -0), 12 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- New OnBeforeUpdateSalesOrderLineIfExist event added to Sales-Post codeunit
- Event includes an initialized IsHandled parameter for overriding standard behavior
- Enables extensions to prevent automatic prepayment amount restoration to open orders
- Added across all localization layers (W1, APAC, BE, CH, ES, FI, FR, GB, IT, NA, NO, RU)
- Allows subscribers to implement custom update logic that fits their business requirements
