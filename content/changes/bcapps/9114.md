- Removes TestDataSensitivities from the disabled-test list so it runs in CI again
- Adds GetAppsPendingDataClassification as a temporary allow-list of app ids with unclassified fields
- Tables from apps not on the list still fail the test, which catches new regressions
- AL-Go settings now trigger a full build when the disabled-test lists change
