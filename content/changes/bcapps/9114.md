# #9114 Re-enable Data Classification test (CU 135153 TestDataSensitivities) in CI

> Re-enables the Data Sensitivity classification test in CI by introducing an app-level exclusion mechanism to grandfathered apps still shipping unclassified fields, allowing new regressions to be caught while existing classification debt is addressed per-app.

## What changed

- Re-enables disabled test CU 135153 TestDataSensitivities that validates all shipped fields have Data Sensitivity classifications
- Introduces temporary allow-list mechanism for apps with unclassified fields via GetAppsPendingDataClassification
- Test still fails for unclassified tables in apps not on the allow-list, ensuring new regressions are caught
- CI configuration updated to trigger full test runs when disabled-test lists change
- No public code changes; test refinement and CI automation only
