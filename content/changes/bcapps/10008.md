# #10008 [MCP] Add codeunit APIs as MCP tools in MCP configuration

> Codeunit APIs are now integrated into MCP configuration as a new object type alongside API pages and queries, with unified selection UI and metadata sourced from the Api Web Service table.

[Pull request](https://github.com/microsoft/BCApps/pull/10008) · merged into `main` (BC30) on 2026-08-20 by onbuyuka · 13 files (+615 -269), 10 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- Codeunits added as an object type in MCP configuration with parity to API pages and queries
- All API metadata now unified in Api Web Service table instead of separate lookups
- API Overview page redesigned to list pages, queries, and codeunits from single source
- Permission model changed from 'Allow Bound Actions' to 'Allow Actions' for codeunit tool invocation
- V1 APIs and Base Application beta queries excluded from MCP selection
- Breaking: existing extensions can stop compiling or working.
