# #8747 [Subcontracting] Disable "WIP Item Transfer" for Machine Center

> The "Transfer WIP Item" field on routing lines is now restricted to Work Center types with subcontracting enabled, with validation failing and the field disabled for Machine Center types. Comprehensive UI and validation tests were added to ensure correct behavior.

[Pull request](https://github.com/microsoft/BCApps/pull/8747) · merged into `main` (BC30) on 2026-08-18 by SPinkow (community contribution) · 11 files (+328 -9), 6 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- Restrict "Transfer WIP Item" field to Work Center routing lines only, disabling it for Machine Center types
- Add validation logic that prevents the field from being enabled for Machine Center routing lines
- Make the field non-editable and invisible in the Subc. PO Subform page extension
- Add comprehensive UI and validation tests to verify field behavior for both Work Center and Machine Center types
- Introduce CreateRoutingLineForMachineCenter helper method to improve test setup and maintainability
- Behaviour changes for users or extensions.
