# #11741 [MCP] Add company and environment descriptions

> Company and environment descriptions are now stored and exposed via APIs to provide richer context for MCP and other consumers. Company descriptions are stored as BLOBs in Company Information, environment descriptions once per database in System Application, and both are made available as read-only fields in API v2.0.

[Pull request](https://github.com/microsoft/BCApps/pull/11741) · merged into `main` (BC30) on 2026-09-30 by nikolakukrika · 47 files (+2326 -41), 40 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Company Description field added to Company Information table as a BLOB across all country layers
- Environment Description stored once per database in System Application
- Multiline text editors added to Company Information page UI
- Read-only fields exposed in API v2.0 companyInformation endpoint
- API change is additive and backward compatible; existing APIs unchanged
- Behaviour changes for users or extensions.
