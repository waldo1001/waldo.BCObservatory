# #8752 [Bug Fix] #638531: Disable Open TO from PO actions on non-subcontracting lines

> The Open TO from PO actions on subcontracting purchase order lines are now properly disabled for non-subcontracting lines instead of appearing enabled but doing nothing.

[Pull request](https://github.com/microsoft/BCApps/pull/8752) · merged into `main` (BC30) on 2026-08-17 by ventselartur · 2 files (+75 -1), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Transfer Order and Return Transfer Order actions disabled on purchase lines without production order numbers
- Action enablement now depends on line-level subcontracting status via OnAfterGetCurrRecord trigger
- Prevents confusing UI behavior where actions appear available but execute no operation
- Regression test added to verify correct action state for both subcontracting and non-subcontracting lines
- Behaviour changes for users or extensions.
