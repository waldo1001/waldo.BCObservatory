# #9094 Add shared CompanyMetadata data source for report layouts

> A shared CompanyMetadata data source is now available for report layouts to bind company information, eliminating the need for each report to manually code Company Information fields.

[Pull request](https://github.com/microsoft/BCApps/pull/9094) · merged into `main` (BC30) on 2026-08-03 by v-mortenr (community contribution) · 4 files (+561 -0), 2 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- ReportManagement subscribes to the GetCompanyMetadata business event and populates a shared company block with name, address, contact details, bank information, and identifiers
- New Company Metadata Builder codeunit provides typed setters to centralize wire keys and avoid hand-written key strings
- Company display name uses CompanyProperty.DisplayName() to align with how ReportRequest is built
- Empty Company Information fields produce present-but-empty values in the data source
- Tests-Report coverage validates values, captions, display-name logic, empty-safe behavior, and address repeater functionality
- Behaviour changes for users or extensions.
