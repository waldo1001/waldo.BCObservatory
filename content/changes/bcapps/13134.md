# #13134 [main] Bug 656172 Payment Slips Summarized by Due Date are not aggregating correlative in the French version.

> Fixed aggregation of payment slips in the French payment management reports when credit memos and invoices are not consecutive, by correcting the lookup logic in the summarization process to group records by customer, currency, and due date instead of using the full primary key.

[Pull request](https://github.com/microsoft/BCApps/pull/13134) · merged into `main` (BC30) on 2026-10-30 by MSNehaNawal · 3 files (+174 -2), 2 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Payment slip summarization now groups by customer, currency, and due date instead of the full primary key that included generated fields
- Replaced full-key Find() calls with explicit grouping logic using a separate temporary record variable
- Previously retained values from processed groups in generated fields no longer interfere with new groupings
- Amount and Amount (LCY) are correctly accumulated for each group while preserving existing line and document numbers
- Behaviour changes for users or extensions.
