# #11561 [Permissions] Fix read-only error in obsolete permission cleanup

> The Remove Obsolete Permissions action now deletes only from the Tenant Permission table instead of the read-only system Permission table, ensuring cleanup works correctly on SaaS infrastructure.

- Cleanup is now tenant-only, affecting both user-defined and extension-owned permission sets
- System permissions remain untouched on all environments
- Action no longer attempts to modify the read-only Permission table on SaaS
- Tooltip and result messages updated to reflect tenant scope
