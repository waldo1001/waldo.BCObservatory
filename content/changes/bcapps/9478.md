# #9478 feat(Sustainability): Add Reverse Transaction for Sustainability Ledger Entries

> Users can now reverse posted Sustainability Ledger Entries manually from the page or automatically when their originating G/L transaction is reversed, with all emission fields negated and the reversal posted on the original entry's date.

[Pull request](https://github.com/microsoft/BCApps/pull/9478) · merged into `main` (BC30) on 2026-08-19 by KseniaOreshkina · 5 files (+675 -3), 4 AL · feature · tier official · **unreviewed** (machine-generated)

## What changed

- Manual reversal action added to Sustainability Ledger Entries page with confirmation
- Automatic reversal triggered when a G/L transaction that produced sustainability entries is reversed
- New fields track reversal status: Reversed, Reversed by Entry No., Reversed Entry No.
- All emission fields (CO2, CH4, N2O, CO2e, Carbon Fee, Water, Waste, Energy) are negated in the reversal entry
- Reversal entry posted on original entry's date to ensure emissions net to zero within same period
- Behaviour changes for users or extensions.
