# #12532 [Master]-Dispute Status code is not retained in some scenarios within the Vendor/Purchase Side, but works well in Customer/Sales side

> Fixes cases where the Dispute Status code was not kept on the vendor/purchase side, while the customer/sales side already worked. The changes touch Vend. Entry-Edit, Purch. Inv. Header - Edit and the Vendor Ledger Entries page across W1 and several country layers.

## What changed

- Dispute Status is now retained in scenarios on the vendor side where it was lost
- Vend. Entry-Edit updated in W1 and several country layers
- Purch. Inv. Header - Edit adjusted in W1 and ES, with a one-line change to the Vendor Ledger Entries page
- Brings vendor behaviour in line with the customer/sales side
- Edit Posted Documents tests added across multiple layers
- Behaviour changes for users or extensions.
