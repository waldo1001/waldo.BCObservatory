# #11938 Bug 650344: [Subcontracting] Prevent cancellation of vendor-supplied component lines

> Subcontracting planning no longer proposes cancellation actions for vendor-supplied component purchase lines, preventing unintended line removals during regenerative planning.

## What changed

- Vendor-supplied component lines are excluded from planning supply calculations
- Regenerative planning no longer generates Cancel requisition lines for these components
- Regression test added to ensure the fix prevents future cancellation proposals
- Change affects only subcontracting planning behavior
