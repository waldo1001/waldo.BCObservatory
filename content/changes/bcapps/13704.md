# #13704 [Subcontracting] Add quantity-ready-to-start tracking for production routing operations

> Production order routing operations now track quantity ready to start, showing how much output from preceding operations is available for the next step. The calculation respects send-ahead quantities and thresholds, and can optionally filter subcontracting worksheet proposals to exclude operations not yet ready.

[Pull request](https://github.com/microsoft/BCApps/pull/13704) · merged into `main` (BC30) on 2026-11-13 by stevengrossGOB (community contribution) · 22 files (+2524 -0), 18 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- New read-only Quantity Ready to Start field on production routing lines
- Calculation respects send-ahead quantities, thresholds, parallel routings and production families
- Readiness maintained during routing calculation, planning, output posting and order reopening
- Optional filter added to Calculate Subcontracts report to exclude unready operations
- New columns hidden by default; subcontracting filter is optional to preserve backward compatibility
- Behaviour changes for users or extensions.
