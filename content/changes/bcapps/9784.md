# #9784 [E-Document Formats] Fix defects in V2 draft migration for XRechnung, PINT A-NZ and Factura-E

> Fixed defects in V2 draft migration for XRechnung, PINT A-NZ, and Factura-E e-document formats, including incorrect reset logic, dead fallback code, and missing field mappings for purchase line matching.

[Pull request](https://github.com/microsoft/BCApps/pull/9784) · merged into `main` (BC30) on 2026-07-29 by Groenbech96 · 5 files (+90 -4), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- XRechnung: ResetDraft was not called from ReadIntoDraft, causing duplicate lines on re-runs; added root element validation to reject unsupported documents
- PINT A-NZ: VendorParticipantId and vendor address fields were passed by value instead of by reference, making vendor-matching fallbacks unreachable; credit notes missing billing reference mapping
- Factura-E: Corrective invoice number incorrectly mapped to Purchase Order No instead of Applies-to Ext. Invoice No, preventing credit memo matching
- Added three regression tests for XRechnung mirroring OIOUBL test patterns
- Aligns migration defects with DK OIOUBL reference implementation standards
- Behaviour changes for users or extensions.
