# #10213 Bug 8845 Old Prices Calculated in Req. Worksheet

> When other fields on a Requisition Line are validated, Order Date is no longer set to a date before the work date, so prices are calculated correctly. Starting Date is now only updated through validation, so validating Order Date from code no longer sets it directly.

## What changed

- Validating other Requisition Line fields no longer sets Order Date earlier than the work date
- Fixes outdated prices calculated in the requisition worksheet
- Starting Date is only set through validation, keeping Starting Date-Time in sync
- New test in SCMPlanReqWksht and existing tests adjusted that relied on past order dates
- Behaviour changes for users or extensions.
