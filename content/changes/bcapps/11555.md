## What changed

- UpdateListItem keeps ContentType, WebUrl, CreatedDateTime and LastModifiedDateTime when the record already holds the item
- ParseListItemFieldValueSet returns Boolean; UpdateListItem logs a parse error under new event ID 0000UKW
- Drive item update and rename operations log an OperationName telemetry dimension
- GetListItem still appends the default $expand=fields to the endpoint so the caller's optional parameters are not mutated
- New tests cover field preservation, empty field values and expand handling
- Behaviour changes for users or extensions.
