# #9613 [Master] - Sustainability: Specific Carbon Tracking, Item Charge emissions & setup fixes (Bugs 641051, 641486, 641487, 641049, 641222, 641055, 641289, 641224, 641309)

> Sustainability module fixes for carbon tracking with item charges, value chain posting, and setup validations. Corrects proportional CO2e distribution across split item ledger entries, adds missing value entries for undo operations, and improves field visibility and defaults.

[Pull request](https://github.com/microsoft/BCApps/pull/9613) · merged into `main` (BC30) on 2026-07-29 by v-rohangarg20 · 15 files (+3073 -32), 11 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Item charge CO2e now distributed proportionally across split item ledger entries and tracking specifications
- Undo purchase receipt and service documents now properly reverse and recreate sustainability value entries
- Added validation warning when specific carbon tracking method is enabled without corresponding item tracking setup
- CO2e per Unit field added to Item Journal page for better visibility and editability
- Installation Multiplier default value set to 1 for distance-based Scope 3 emissions in purchase documents
- Behaviour changes for users or extensions.
