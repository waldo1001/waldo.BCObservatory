# #8698 [E-Documents Core] [Peppol] - Enabling EDI capabilities with E-Documents. PEPPOL Order Response Message Handling

> E-documents now track order responses and acknowledgements as lifecycle events with a message model, enabling outgoing response generation and inbound order rejection with UI visibility.

[Pull request](https://github.com/microsoft/BCApps/pull/8698) · merged into `main` (BC30) on 2026-07-27 by jzaksauskas (community contribution) · 35 files (+979 -11), 28 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- New message model for e-documents to track order responses and acknowledgements as lifecycle events
- Automatic generation of outgoing acknowledgements and accept/reject responses for supported formats
- Manual reject action added for inbound orders
- Message visibility in UI with payload viewing and related message data cleanup
- New integration tests for message response handling
- Behaviour changes for users or extensions.
