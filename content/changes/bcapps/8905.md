# #8905 [Master] Different source reference on reservation entries created directly from Job Planning Line and via a warehouse pick.

> Reservation entries for project (job) planning lines now get the same source reference whether they are created directly or through a warehouse or inventory pick. The change touches project warehouse handling, pick creation and posting, and adds upgrade code with upgrade tags for existing data.

## What changed

- Fixes different source references on reservation entries created from Job Planning Line and via warehouse pick
- Updates Job Warehouse Mgt., Job Planning Line, pick creation, and warehouse activity posting and registering
- Adds upgrade code and upgrade tags across W1 and several local layers
- Adds tests for inventory picks, warehouse picks and upgrade on project planning lines
- Behaviour changes for users or extensions.
