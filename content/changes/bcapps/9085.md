- Added CheckDirectTransferAllowed method to validate direct transfer feasibility before setting the field
- Raises a guided error suggesting either setting up an in-transit route or using Direct Transfer posting
- Handles the case where source location requires pick or shipment but direct transfer is not configured
- Includes a negative test case to verify the error handling
