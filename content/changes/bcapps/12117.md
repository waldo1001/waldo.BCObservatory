# #12117 [Job Queue] Clearer message and attempt number for runs interrupted by the platform

> Job Queue displays a clearer message when the platform interrupts a run, including the attempt number, and adds telemetry tracking for interruptions.

## What changed

- Replaces confusing 'job has stopped' error message with 'run was interrupted' message that includes the attempt number
- Derives attempt number from log entries sharing the same System Task Id
- Adds JobQueueInterruptedAttempt dimension to the 0000PCR telemetry signal
- Helps distinguish platform interruptions from actual job failures
- User-facing label text changes require retranslation and updates to any monitoring rules
- Behaviour changes for users or extensions.
