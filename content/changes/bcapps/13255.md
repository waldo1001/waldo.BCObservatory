# #13255 [Main]-Exporting vendor remittance gets stuck when a payment jour nal is sorted by Document No.

> Fixed vendor remittance export hanging when a payment journal is sorted by Document No. The export now uses primary key order instead of the current sort order to prevent lines from being processed repeatedly.

[Pull request](https://github.com/microsoft/BCApps/pull/13255) · merged into `main` (BC30) on 2026-10-26 by DhavalMore88 (community contribution) · 2 files (+52 -0), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Export loop now uses primary key order (Journal Template Name, Journal Batch Name, Line No.) instead of the journal's current sort order
- Prevents lines from resorting during processing when Document No. is updated
- Each line is now exported exactly once instead of repeatedly
- Added regression test ExportPaymentJournalSortedByDocumentNo
- Behaviour changes for users or extensions.
