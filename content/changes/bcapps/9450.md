# #9450 [Extensibility Request] issue 30290: Add OnBeforeUpdateSetupOnBillToCustomerChangeInSalesHeader event

> A new integration event OnBeforeUpdateSetupOnBillToCustomerChangeInSalesHeader is added to the Sales Header table to allow extensions to override or skip the standard VAT registration update logic when the bill-to customer changes.

[Pull request](https://github.com/microsoft/BCApps/pull/9450) · merged into `main` (BC30) on 2026-07-24 by AleksandricMarko · 15 files (+225 -15), 15 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- New IntegrationEvent added before AltCustVATRegFacade.UpdateSetupOnBillToCustomerChangeInSalesHeader call
- Event has IsHandled parameter that allows subscribers to prevent standard logic execution
- Change applied consistently across all localization layers (W1, NA, BE, CH, CZ, ES, FI, FR, GB, IT, NL, NO, RU, SE, APAC)
- Enables extensions to implement custom VAT registration and posting group assignment without conflicts
- Maintains backward compatibility as event is optional
