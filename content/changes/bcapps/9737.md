# #9737 [E-Document] Move Data Exchange definitions from labels to app resource files

> E-Document installation moved eight PEPPOL Data Exchange Definition XMLs from translatable AL labels into app resource files, eliminating unnecessary translation pipeline overhead and fixing partner translation issues.

[Pull request](https://github.com/microsoft/BCApps/pull/9737) · merged into `main` (BC30) on 2026-07-28 by Groenbech96 · 9 files (+41 -86), 1 AL · refactor · tier official · **unreviewed** (model text not yet checked)

## What changed

- Relocated ~470 KB of XML payloads from embedded AL labels to .resources/DataExchange files
- Removed eight labels (DataExchangeInvXML1Txt, DataExchangeCrMXML1Txt, and six others) that were mistakenly included in translations
- Renamed resource files to match naming convention (e.g., 'e-Doc PEPPOL Invoice Import.xml' to 'eDocPEPPOLInvoiceImport.xml')
- Consolidated import logic into a single ImportDataExchDefinition procedure used by both V1 and V2 definitions
- Regenerated eDocPEPPOLInvoiceImport.xml to include missing DataExchColumnDef entry and updated attachment column names
