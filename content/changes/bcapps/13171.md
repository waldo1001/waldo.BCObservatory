# #13171 [Fixed Assets] Prevent change of FA Posting group after acquisition and FA journal cancellation line with empty Document No.

> Two Fixed Assets bugs are fixed: FA Posting Group field is now protected after acquisition posting, and FA journal cancellation creates a valid document number when the batch is not empty.

[Pull request](https://github.com/microsoft/BCApps/pull/13171) · merged into `main` (BC30) on 2026-10-27 by dcenic · 12 files (+863 -0), 8 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- FA Posting Group validation now blocks changes after acquisition cost is posted, preventing G/L account mismatch
- New CheckFAPostingGroupChangeAfterAcquisition validation prevents unguarded posting group modification
- Cancel FA Ledger Entries now uses the last batch line's document number when creating cancellation entries in non-empty batches
- Fixes applied across W1 and localized versions (DACH, FR, GB, RU)
- Comprehensive test cases added to verify both correction scenarios
- Behaviour changes for users or extensions.
