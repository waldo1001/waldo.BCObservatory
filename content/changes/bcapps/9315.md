# #9315 [Projects] Add Assigned Resources to projects and project tasks

> Projects now support assigning resources at the project level or to specific posting-type tasks, with multiple resources per project or task managed through a new Assigned Resources table and UI actions.

[Pull request](https://github.com/microsoft/BCApps/pull/9315) · merged into `main` (BC30) on 2026-07-14 by t-prda · 41 files (+1062 -0), 36 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- New Job Assigned Resource table stores resource assignments linked to projects and optional posting-type tasks
- Assigned Resources actions added to project cards, lists, and task pages for managing assignments
- Task-level assignments restricted to posting-type tasks; changing a task type away from posting is blocked if assignments exist
- Assigned resources cascade-delete with projects or tasks; assignments archived and restored alongside job archives
- Copy Project Tasks includes optional toggle to copy assigned resources without overwriting existing entries
- Behaviour changes for users or extensions.
