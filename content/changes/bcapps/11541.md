# #11541 Clarify Expense Agent and expense management setup

> Page 6996 is now shown as Expense Management Setup, hiding redundant agent controls marked pending removal under CLEAN30. Wizard 6991 gains reminder frequency details, the Only Shortest Route setting and staged stale-account repair. Missing setup no longer defaults HTTP requests to production.

[Pull request](https://github.com/microsoft/BCApps/pull/11541) · merged into `main` (BC30) on 2026-09-17 by t-prda · 5 files (+214 -87), 5 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Page 6996 is searchable as Expense Management Setup; redundant agent, communication, AI policy and project controls are hidden and pending cleanup under CLEAN30
- Wizard 6991 adds weekly, monthly and custom reminder details and moves Only Shortest Route into its mileage section
- Stale-account repair is staged in the wizard and only persisted on explicit Update; Cancel discards it
- Page 7076 becomes Expense Agent Communication Status, reachable via a new View communication status action
- Canary flag is passed explicitly for endpoint selection, and missing setup clears the URL and returns false instead of using production
- Behaviour changes for users or extensions.
