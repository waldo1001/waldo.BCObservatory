# #11541 Clarify Expense Agent and expense management setup

> Expense Agent setup UI is reorganized to separate agent configuration from general expense management, with controls for communication status, reminders, and mileage settings consolidated into their relevant groups and the wizard enhanced with better defaults and validation handling.

## What changed

- Expense Management Setup page hides redundant agent/communication controls marked as pending cleanup in version 30.0
- Setup wizard gains reminder configuration with weekly/monthly/custom frequency options and improved date-formula guidance
- Agent configuration fields and mileage settings consolidated into logical groups on both setup surfaces
- Expense Agent Status page renamed to Expense Agent Communication Status with improved navigation
- Staging of account repair tasks in wizard with explicit update/cancel handling without live validation
- Behaviour changes for users or extensions.
