# #10565 Add default manufacturing version number series

> Manufacturing Setup now supports optional default number series for production BOM and routing versions, with new headers inheriting these defaults when their own series is blank.

[Pull request](https://github.com/microsoft/BCApps/pull/10565) · merged into `main` (BC30) on 2026-10-08 by attilatoury · 14 files (+609 -2), 8 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Optional default number series fields added to Manufacturing Setup for production BOM versions and routing versions
- New headers inherit setup defaults only when their Version Nos. field is blank
- Existing headers and explicit values remain unchanged; blank setup preserves prior behavior
- Contoso dataset creates PRODBOM-V and ROUTING-V series and assigns them only when setup is blank
- Schema change mirrored in Italian localization layer with focused test coverage
- Behaviour changes for users or extensions.
