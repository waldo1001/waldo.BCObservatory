# #11242 [main] bug 640925 - Enhance draft and proforma invoice report layouts and upgrade tag definitions

> The Czech localization's Draft and Pro Forma Invoice report layouts are enhanced with improved alignment and new fields, and an upgrade procedure automatically sets the CZ-specific layouts as default during upgrades while preserving existing customizations.

## What changed

- Pro Forma Invoice report layout updated with new columns (TotalLbl, VATIdentifier) and improved alignment
- VAT calculation logic fixed to use SalesPost.GetSalesLines with temporary records, filtering out non-Item line types for correct VAT amounts
- Automatic upgrade procedure added to set CZ-specific RDL layouts as default during upgrade, only when no custom layout has been selected
- New tabledata permissions added for Report Layout Selection and Tenant Report Layout tables
- Existing custom layout selections are preserved during upgrade
- Behaviour changes for users or extensions.
