# #11242 [main] bug 640925 - Enhance draft and proforma invoice report layouts and upgrade tag definitions

> Czech localization Draft and Pro Forma Invoice layouts are updated, and an upgrade sets the CZ RDL layouts as default unless a custom layout is selected. Pro Forma Invoice VAT is now calculated from temporary sales lines via SalesPost.GetSalesLines, with non-Item lines filtered out, for correct VAT amounts.

[Pull request](https://github.com/microsoft/BCApps/pull/11242) · merged into `main` (BC30) on 2026-09-14 by DavidHolusa · 5 files (+569 -142), 4 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Pro Forma Invoice RDL layout gains new columns such as TotalLbl and VATIdentifier, with improved alignment
- VAT amounts now come from SalesPost.GetSalesLines temporary records with non-Item lines filtered out, which changes the VAT breakdown
- Upgrade procedure sets the CZ-specific layouts as default only when no custom selection exists
- Upgrade codeunit gets tabledata permissions for Report Layout Selection and Tenant Report Layout Selection
- Behaviour changes for users or extensions.
