# #14022 [Expense Agent] Travel request fixes: deletion after cancel, linked reports, approver audit user, closure history

> Four travel request improvements: deletion after report cancellation, linked reports visibility, approver user tracking in audit fields, and activity logging for request closure.

[Pull request](https://github.com/microsoft/BCApps/pull/14022) · merged into `main` (BC30) on 2026-11-17 by claudiuciumedean · 12 files (+991 -24), 11 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Travel requests can now be deleted after linked posted reports are canceled
- New actions show all expense and posted expense reports linked to a travel request
- Approve/reject audit fields now record the approver's BC user instead of session user
- New Closed activity event logs when travel requests are closed
- Permission sets updated for new functionality
- Behaviour changes for users or extensions.
