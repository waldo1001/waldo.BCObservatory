> Fixed default bin assignment for drop shipments when creating purchase orders from sales orders. The requisition line no longer incorrectly receives a default bin during item validation when the drop-shipment flag is set.

- Prevent default-bin assignment for drop shipments during validation

- Added four regression tests covering drop-shipment and ordinary orders with and without item variants
