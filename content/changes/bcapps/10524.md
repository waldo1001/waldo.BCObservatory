# #10524 Add a purchase order matching API

> New public APIs enable external applications to programmatically create purchase order matches with receipts, including a convenience feature to suggest unmatched receipts based on remaining invoice amounts.

[Pull request](https://github.com/microsoft/BCApps/pull/10524) · merged into `main` (BC30) on 2026-08-28 by mynjj · 4 files (+2107 -0), 3 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- Three new public codeunits provide a facade for inserting matched order line records
- A receipt suggestion algorithm discovers unmatched receipts that could cover remaining invoice amounts
- Match group buffers validate all matches quantity-wise before database insertion
- Iterators allow consumers to traverse matches and invoiceable receipts
- All changes are additive with no impact on existing BaseApp matching logic
- Behaviour changes for users or extensions.
