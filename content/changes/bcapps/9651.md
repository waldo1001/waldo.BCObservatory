# #9651 [Extensibility Request] issue 30352: add SkipNewExpirationDateCheck to OnCheckExpirationDateOnAfterCalcSumLot

> A new parameter SkipNewExpirationDateCheck was added to the OnCheckExpirationDateOnAfterCalcSumLot event, allowing subscribers to bypass the mandatory New Expiration Date validation during item journal posting without affecting other logic.

[Pull request](https://github.com/microsoft/BCApps/pull/9651) · merged into `main` (BC30) on 2026-07-27 by AleksandricMarko · 6 files (+30 -18), 6 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Adds var SkipNewExpirationDateCheck parameter to the OnCheckExpirationDateOnAfterCalcSumLot integration event in codeunit 22
- Subscribers can set it to true to skip only the New Expiration Date TestField check
- Avoids using OnBeforeCheckExpirationDate IsHandled, which would require replicating the procedure and skip downstream events
- Parameter defaults to false; adding it is non-breaking for existing subscribers
- Mirrored in W1 and the ES, APAC, CH, RU and IT layers
