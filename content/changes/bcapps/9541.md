# #9541 [SOA] Bound outbound reply retries

> Outbound replies in the Sales Order Agent now limit retry attempts to five per message, provide a manual retry action, and isolate failures to prevent blocking other messages.

[Pull request](https://github.com/microsoft/BCApps/pull/9541) · merged into `main` (BC30) on 2026-07-23 by qasimikram · 6 files (+355 -60), 6 AL · feature · tier official · **unreviewed** (machine-generated)

## What changed

- Capped failed outbound reply attempts at five per message to prevent infinite retries
- Suppresses exhausted replies without recurring telemetry when retry limit is reached
- Added a Retry sending action that resets the attempt count for manual retry
- Isolated individual reply failures so remaining messages continue processing
- Added new Reply Attempt table to track retry history
- Behaviour changes for users or extensions.
