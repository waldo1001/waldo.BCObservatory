# #9430 Fix untrappable JSON error in E-Document ADI import (Bug 640122)

> E-Document matching assistance import now handles malformed Azure Document Intelligence responses gracefully by checking JSON property existence and adding telemetry for diagnostic purposes instead of crashing with an untrappable error.

[Pull request](https://github.com/microsoft/BCApps/pull/9430) · merged into `main` (BC30) on 2026-07-15 by ventselartur · 1 file (+22 -6), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Every JSON property read in E-Document matching assistance now validates the Get call return value
- Missing or malformed ADI response properties no longer cause untrappable runtime errors
- Telemetry warnings added to diagnose which property is missing from ADI responses
- Import degrades gracefully when Azure response structure is incomplete
- Helper functions return empty objects instead of dereferencing uninitialized tokens
- Behaviour changes for users or extensions.
