# #9702 Default new E-Document services to import v2 and let users select the draft format

> New E-Document services now default to the v2 import pipeline, and the Import Process selector is visible on the service card. A Draft Format field (Read into Draft Impl.) is shown for Version 2.0 so users can choose how structured documents are read into drafts. The ForNAV connector service is pinned to Version 1.0.

[Pull request](https://github.com/microsoft/BCApps/pull/9702) · merged into `main` (BC30) on 2026-07-24 by Groenbech96 · 8 files (+68 -4), 2 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- New services default to Import Process Version 2.0 and the selector is now visible
- Added draft format field to the service card (only for v2) letting users pick how to read structured data
- ForNAV connector automatically pins to Version 1.0 since its inbound is not yet v2-compatible
- Selectable draft format prevents v2 import failures when structured formats return Unspecified
- Tests verify v2 defaults and draft format persistence
- Behaviour changes for users or extensions.
