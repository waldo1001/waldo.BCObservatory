# #13674 Add expense interim approval controls, approval outcomes, and approver lookup

> Expense Agent now supports interim approval controls with explicit approval outcomes, an interim approver capability flag, and an API to discover available approvers for assignment.

[Pull request](https://github.com/microsoft/BCApps/pull/13674) · merged into `main` (BC30) on 2026-11-27 by encimita · 18 files (+1262 -4), 13 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- Added SubmitAndAssignInterimApprover action to release, assign, and submit expense reports in one transaction
- New approval outcome endpoints return approval status, completion state, and next approver information as JSON
- InterimApprover capability reflects Allow Interim Approvers setting; ApprovalsWithOutcome capability always enabled
- New availableApprovers API collection and per-user endpoint expose eligible approvers for interim assignment
- Interim assignments clear on resubmission when feature is disabled; active approvals are preserved
- Behaviour changes for users or extensions.
