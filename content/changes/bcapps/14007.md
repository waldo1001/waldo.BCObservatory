# #14007 Obsolete Create Product Information with Copilot

> The Create Product Information with Copilot app is discontinued and its functionality is obsoleted. The upgrade codeunit unregisters the Copilot capability once per database, a notification directs users to modern search instead, and most objects are wrapped in obsolescence guards with Pending state for 30.0 and Removed state for 33.0.

[Pull request](https://github.com/microsoft/BCApps/pull/14007) · merged into `main` (BC30) on 2026-11-16 by VolodySyn · 20 files (+220 -44), 19 AL · obsoletion · tier official · **unreviewed** (model text not yet checked)

## What changed

- Copilot capability for item substitution suggestions is unregistered via upgrade codeunit, guarded by upgrade tag MS-659006-UnregisterCreateProductInfoCapability-20261112
- Subscriber to OnRegisterCopilotCapability removed to prevent re-registration when capabilities page is opened
- New notification in Item Substitution Entry page directs users to use modern search instead, with don't show again option
- Most app objects (codeunits, pages, table extension, enums) marked obsolete with Pending state for version 30.0, transitioning to Removed in 33.0
- App removed from build configuration so it no longer installs on new environments
- Behaviour changes for users or extensions.
