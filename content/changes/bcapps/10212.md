# #10212 Add SetReferenceType method to SignedXml and SignedXmlImpl (#10139)

> A SetReferenceType method is added to the SignedXml codeunit to allow callers to set the Type property on XMLDSIG Reference elements, enabling creation of XML signatures with typed references such as references to XAdES SignedProperties.

[Pull request](https://github.com/microsoft/BCApps/pull/10212) · merged into `main` (BC30) on 2026-10-07 by marcus905 (community contribution) · 3 files (+51 -0), 2 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- New SetReferenceType(Type: Text) method added to SignedXml and SignedXmlImpl codeunits
- Exposes the underlying .NET Reference.Type property that was previously inaccessible
- Enables XML signatures requiring typed references like XAdES SignedProperties
- Unit test added to verify the Type attribute is correctly emitted in generated Reference elements
- No breaking changes or compatibility impacts
- Behaviour changes for users or extensions.
