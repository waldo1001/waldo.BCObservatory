# #9200 Cloud Migration bug fixes (BC14 reimplementation, custom mapping, OnPrem dev companies)

> Cloud migration tooling improvements include skipping the table mapping step in BC14 setup, preventing upgrade errors when no data is replicated, making the custom mapping page closable without valid entries, and adding an action to register existing on-premise companies for cloud migration development.

[Pull request](https://github.com/microsoft/BCApps/pull/9200) · merged into `main` (BC30) on 2026-07-23 by nikolakukrika · 19 files (+560 -147), 15 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- BC14 migration wizard no longer shows custom migration table mapping configuration step
- One-step upgrade guard prevents errors during setup when no companies are selected
- Custom mapping page now uses lookup mode and card layout allowing closure with invalid data
- New action on cloud migration pages registers on-premise companies as hybrid companies for development
- Mapping validation moved from page close to save operation
- Behaviour changes for users or extensions.
