# #11665 Bug 649580: [Subcontracting] Transfer Shipment report is missing subcontractor and manufacturing references

> The Subcontracting app now adds a report extension and selectable layout for standard Transfer Shipment report 5704 that prints the posted subcontractor, subcontract purchase order and production order references. Italian report 12154 stays for ordinary transfer shipments without subcontracting dependencies, keeping its old dataset columns as blank values.

## What changed

- Report 12154 simplified to show ordinary transfer shipments without subcontracting fields
- New report extension for standard report 5704 with subcontractor, purchase order, and production order details
- Legacy report dataset columns preserved as blank compatibility values for existing consumers
- Subcontracting reporting logic moved into the app to respect app boundaries
- New and refactored tests added for both standard and subcontracting transfer shipment scenarios
- Behaviour changes for users or extensions.
