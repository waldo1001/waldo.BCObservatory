# #9264 [master] Bin Capacity Policy "Prohibit More Than Max. Cap." fails and allows more than the maximum Capacity, when you split lines on Inventory Movement

> Fixed bin capacity enforcement in non-directed warehouses so that registering partial inventory movements now correctly prevents bins from exceeding maximum capacity limits.

[Pull request](https://github.com/microsoft/BCApps/pull/9264) · merged into `main` (BC30) on 2026-07-13 by neeleshsinghal (community contribution) · 2 files (+138 -0), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Bin Capacity Policy 'Prohibit More Than Max. Cap.' was incorrectly allowing overflow when splitting inventory movement lines in basic warehouses
- Root cause: cubage and weight calculations were only performed for directed locations, leaving zero values in basic warehouse entries
- Solution adds cubage/weight calculation via WMSMgt.CalcCubageAndWeight for non-directed warehouse movements
- Warehouse entries now properly carry cubage data so capacity checks can validate against maximum limits
- Includes test coverage for the scenario
- Behaviour changes for users or extensions.
