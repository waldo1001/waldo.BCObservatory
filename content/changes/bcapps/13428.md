# #13428 [Quality Management] Keep Sample Size and Pass/Fail Quantity within Quantity (Base)

> Quality Management inspections now enforce that Sample Size and Pass/Fail Quantity cannot exceed Quantity (Base), preventing data inconsistencies when Quantity (Base) is reduced after inspection creation or when it is zero.

[Pull request](https://github.com/microsoft/BCApps/pull/13428) · merged into `main` (BC30) on 2026-11-06 by alexei-dobriansky · 4 files (+106 -6), 2 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Sample Size and template Sample Fixed Amount fields now have MinValue of 0 to prevent negative values
- Validating Quantity (Base) recaps any Sample Size that exceeds the new quantity value
- Finish operation applies the lesser of Sample Size or Quantity (Base), capped at Quantity (Base), fixing cases where Pass/Fail were incorrectly set to 0 or equal to Sample Size on zero-quantity inspections
- Pass/Fail Quantity tooltips now indicate the capping behavior
- Negative Sample Size values already stored are treated as 0 during posting without blocking inspection creation
- Behaviour changes for users or extensions.
