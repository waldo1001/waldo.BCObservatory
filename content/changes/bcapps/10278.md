# #10278 Subcontracting Operation Notes 

> Subcontracting operations now support dedicated comments at the standard task, routing line, and production order routing line levels, which flow to subcontracting purchase orders as attached blank lines while production-order attachments flow to related purchase lines.

[Pull request](https://github.com/microsoft/BCApps/pull/10278) · merged into `main` (BC30) on 2026-08-21 by stevengrossGOB (community contribution) · 32 files (+4410 -220), 23 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- New comment tables and pages for standard tasks, routing lines, and production order routing lines
- Comments and attachments flow to subcontracting purchase orders as blank lines
- Comments are restricted to subcontracting operations only
- Production-order comments are scoped by output line to prevent mixing vendor instructions in Family orders
- Document Attachment Details integration event updated with PurchaseDocumentFlow parameter
- Breaking: existing extensions can stop compiling or working.
