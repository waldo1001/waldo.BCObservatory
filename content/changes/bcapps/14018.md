# #14018 [29.X]-ZUGFeRD: Custom Ship-to Address is not transferred to XML Delivery Address in the German version.

> Custom ship-to address fields are now correctly transferred to the XML delivery address in ZUGFeRD and XRechnung documents for German localization, and similar address handling is extended to PEPPOL invoices across W1 and NO localizations.

[Pull request](https://github.com/microsoft/BCApps/pull/14018) · merged into `releases/29.x` (BC29) on 2026-11-16 by neeleshsinghal · 13 files (+2017 -60), 9 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Ship-to address details are properly mapped to XML delivery address fields in ZUGFeRD export
- XRechnung export updated to handle custom ship-to address transfer
- PEPPOL30 sales validation and XML exports enhanced to include address handling in W1 and NO versions
- Comprehensive test coverage added for ZUGFeRD, XRechnung and PEPPOL address mapping scenarios
- Addresses bug where custom ship-to addresses were not appearing in generated e-documents
- Behaviour changes for users or extensions.
