# #12609 Confirm before deleting attachments from an unfiltered Doc. Attachment List Factbox

> A confirmation dialog now prevents accidental bulk deletion of attachments when the Doc. Attachment List Factbox loads without its filters due to a platform defect, protecting attachments from other documents.

[Pull request](https://github.com/microsoft/BCApps/pull/12609) · merged into `main` (BC30) on 2026-10-14 by darjoo · 4 files (+453 -2), 2 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Adds OnDeleteRecord confirmation that triggers only when the factbox is completely unfiltered
- Stores selected record SystemIds in a list to confirm only on the first record of a bulk delete operation
- Unfiltered state is detected by checking all filter groups (0-255) for absence of filters
- Confirmation defaults to No, requiring explicit user approval to delete from an unfiltered list
- Normal filtered delete behavior and GuiAllowed false scenarios remain unchanged
- Behaviour changes for users or extensions.
