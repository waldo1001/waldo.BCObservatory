# #8577 [Shopify] Fix #7724: Resolve Option 1 Name from existing Shopify Variant records

> Fixed a regression where the Option 1 Name for Shopify product variants was being incorrectly reset to 'Variant' instead of preserving existing names like 'Color' or 'Size'. The fix ensures Option 1 Value is always set when the name is resolved from existing Shopify records.

[Pull request](https://github.com/microsoft/BCApps/pull/8577) · merged into `main` (BC30) on 2026-11-06 by Debs-TVT (community contribution) · 2 files (+485 -6), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Regression in product export where Option 1 Name was reset to 'Variant' for Shopify-origin products with existing variants
- Root cause was missing guard condition to set Option 1 Value when resolved name differed from 'Variant'
- Added JustResolvedOption1Name flag to handle all cases consistently
- Five new test scenarios cover Shopify-origin, BC-origin, and ambiguous variant cases
- All tests pass with no regressions to existing product export functionality
- Behaviour changes for users or extensions.
