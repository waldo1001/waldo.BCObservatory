# #10481 [Bug Fix] #251: Handle GetUserName TryFunction failure during OAuth validation

> Fixed OAuth2 SMTP authentication to properly handle token parsing failures by consuming the TryFunction return value, preventing raw errors from being shown to users instead of the authentication-failed message.

[Pull request](https://github.com/microsoft/BCApps/pull/10481) · merged into `main` (BC30) on 2026-10-14 by ventselartur · 2 files (+37 -3), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- CheckOAuth2Authentication now uses the GetUserName TryFunction result and shows AuthenticationFailedMsg when token parsing fails
- GetOAuth2Credentials now raises CouldNotAuthenticateErr when parsing fails, instead of continuing with an empty user name
- Raw runtime parse errors are no longer shown to users
- Adds a regression test for an unparseable token in SMTP Account Auth Tests
- Behaviour changes for users or extensions.
