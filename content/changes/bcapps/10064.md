# #10064 Add support for “External Document No.” in Subscription Contracts Fixes #8818

> Subscription Contracts now support an External Document No. field that is automatically transferred to generated sales documents and posted invoices, improving support for EAN invoicing scenarios.

[Pull request](https://github.com/microsoft/BCApps/pull/10064) · merged into `main` (BC30) on 2026-09-22 by dksander (community contribution) · 4 files (+39 -0), 3 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Added External Document No. field to Subscription Contracts
- Field value is automatically propagated to sales invoices during billing document creation
- Propagation continues through to posted sales invoices
- New test validates the end-to-end transfer of the field value
- Low-risk change that only extends functionality when the field is populated
- Behaviour changes for users or extensions.
