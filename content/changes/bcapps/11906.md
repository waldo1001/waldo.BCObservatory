# #11906 [Main]-Incident 51000001968459: Issue while creating any import purchase invoice

> Fixed cost-loading logic for import purchase invoices with Nil-Rated GST and Non-Availment setting to properly include Custom Duty in inventory and direct cost entries.

[Pull request](https://github.com/microsoft/BCApps/pull/11906) · merged into `main` (BC30) on 2026-09-26 by v-ajaztabrez · 1 file (+6 -4), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Custom Duty is now included in inventory cost for import invoices with Nil-Rated GST and Non-Availment
- Logic no longer exits prematurely when GST amount is zero if Custom Duty is present
- Non-Availment cost-loading is restricted to prevent duplicate Custom Duty capitalization in Availment scenarios
- Resolves issue where Custom Duty was missing from Inventory and Direct Cost Applied entries
- Behaviour changes for users or extensions.
