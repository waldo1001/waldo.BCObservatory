> Manufacturing enum fallback logic in item journals now correctly returns false when Manufacturing subscribers are absent, preventing ordinary records from being misclassified as manufacturing records.

## What changed

- Adds Boolean predicate events for manufacturing classification instead of relying on enum getters that return ordinal zero when subscribers are absent
- Applies fixes across salesperson dimensions, journal line setup, item tracking validation, recurring journal selection, and the Inventory Posting - Test report
- Preserves existing getter APIs while introducing new predicate events for classification
- Propagates changes to all eight country-specific layers
- Includes new regression tests for production and non-production scenarios
- Behaviour changes for users or extensions.
