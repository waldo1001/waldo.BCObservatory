# #14281 Fix manufacturing enum fallback in item journals

> Item journal code no longer treats ordinary lines and templates as manufacturing records when Manufacturing subscribers are absent. New Boolean predicate events that default to false replace the enum getters at the standard call sites, and the change is applied to all country layers.

[Pull request](https://github.com/microsoft/BCApps/pull/14281) · merged into `main` (BC30) on 2026-11-20 by Alexander-Ya · 15 files (+381 -59), 14 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Adds false-default Boolean predicate events, with Manufacturing subscribers, to classify production and consumption records
- Used for salesperson dimensions, journal line setup, item tracking validation, recurring journal selection and the Inventory Posting - Test report
- Existing enum getter procedures and events remain available
- Extensions that customize classification through the old getter events should move to the new predicate events
- Adds regression tests in SCM Item Journal
- Breaking: existing extensions can stop compiling or working.
