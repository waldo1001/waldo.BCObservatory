- CurrencyAmount and ExchangeRate now use SAFlongmonetaryType
- NOK amount structure updated with DebitTaxAmount and CreditTaxAmount for foreign-currency tax scenarios
- New GenerateSAFT14File codeunit added to handle 1.40 format generation
- Tests added for new SAF-T 1.40 XML structure
