# #9104 Delocalize Export G/L Entries to XML into Audit File Export framework

> Export of G/L entries to XML is rebuilt on the shared Audit File Export framework as a new XML Audit File app (FR), with tests. A new page visibility interface on the Audit File Export Format enum lets each format control which fields and actions show on the Audit File Export Doc. Card.

[Pull request](https://github.com/microsoft/BCApps/pull/9104) · merged into `main` (BC30) on 2026-10-20 by ventselartur · 43 files (+1429 -112), 29 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Created Audit File Export Page Visibility interface for formats to control field/action visibility
- Refactored FEC page extension to use visibility interface instead of hard-coded toggles
- Added new XML Audit File app that exports G/L entries to XML through the shared framework
- Included XmlPort, data handling, permission sets, setup pages, and test coverage
- Registered new app and test projects in build configuration files
- Behaviour changes for users or extensions.
