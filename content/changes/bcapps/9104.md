# #9104 Delocalize Export G/L Entries to XML into Audit File Export framework

> The Export G/L Entries to XML feature was moved from French localization into a reusable Audit File Export framework, with a new generic visibility interface letting each export format control UI elements on the export document card.

[Pull request](https://github.com/microsoft/BCApps/pull/9104) · merged into `main` (BC30) on 2026-10-20 by ventselartur · 43 files (+1429 -112), 29 AL · refactor · tier official · **unreviewed** (model text not yet checked)

## What changed

- Created Audit File Export Page Visibility interface for formats to control field/action visibility
- Refactored FEC page extension to use visibility interface instead of hard-coded toggles
- Added new XML Audit File app that exports G/L entries to XML through the shared framework
- Included XmlPort, data handling, permission sets, setup pages, and test coverage
- Registered new app and test projects in build configuration files
