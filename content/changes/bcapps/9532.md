# #9532 [Master]Error when creating a Pick "Nothing to handle. The quantity to be picked is in bin W-09-0002, which is not set up for picking."

> Fixes warehouse pick creation by checking all ship-type bins for picked-not-shipped quantities instead of only the default shipment bin, preventing false 'nothing to handle' errors.

[Pull request](https://github.com/microsoft/BCApps/pull/9532) · merged into `main` (BC30) on 2026-08-11 by sanjmaurya (community contribution) · 3 files (+287 -1), 2 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- Added CalcQtyOnShipmentBins helper function to sum item quantities across all ship-type bins
- Original code only checked the default shipment bin, causing incorrect quantity calculations when shipment bin was changed
- Fix ensures picked quantities in any ship-type bin are recognized for availability calculations
- Bin Mandatory guard preserved to maintain existing behavior for locations without default shipment bin
- Includes test coverage for the scenario
- Behaviour changes for users or extensions.
