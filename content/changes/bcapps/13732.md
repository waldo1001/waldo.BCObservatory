# #13732 Initialize report filename defaults for new and existing companies

> Report Filename Manager now initializes default filename patterns for 69 standard reports during company initialization, installation, and upgrade, ensuring consistent report naming without requiring manual setup.

[Pull request](https://github.com/microsoft/BCApps/pull/13732) · merged into `main` (BC30) on 2026-11-25 by gggdttt · 16 files (+1302 -66), 9 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- New companies receive enabled filename setup with 65 report-specific defaults and 4 generic document defaults during Company-Initialize
- Existing companies get missing configuration added during installation and upgrade without changing their feature switch or filename-length settings
- Customized, filtered, or enabled patterns are preserved and not overwritten
- Three reports with no document context (5085, 6520, 6521) use report name and date instead of document identifiers
- Caller-owned server output paths are preserved for legacy API PDF generation while patterns apply to client display and attachment names
- Behaviour changes for users or extensions.
