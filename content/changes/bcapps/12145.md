# #12145 [Main]-Item charge assignment update Error on sales order when there is no Price.  "Sorry, we just updated this page. Reopen it and try again." when running in SaaS

> Fixed an error on sales orders when assigning item charges by amount when some item lines have no price. The assignment record set is now refreshed after bulk updates to prevent stale data issues.

## What changed

- Item charge assignment by amount failed with a page refresh error in SaaS when an item line had zero price
- The assignment fields were cleared with ModifyAll but the record set was not refreshed before the allocation logic ran
- Added FindSet() call after bulk updates to refresh the record set
- Regression test added covering zero-price and priced item line scenarios
- Fixes issue AB#581982
