# #11290 [Bug 640454] Scope Expense Agent Entra permissions by company

> The Expense Agent now manages Microsoft Entra permissions scoped to individual companies, adding company-specific grants on activation and removing them on deactivation while preserving other permissions and disabling the shared application only when no active companies remain.

[Pull request](https://github.com/microsoft/BCApps/pull/11290) · merged into `main` (BC30) on 2026-09-18 by t-prda · 7 files (+897 -94), 4 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Entra permissions are now company-scoped rather than global, with exactly one grant per active company
- Existing global grants are preserved when adding company-specific grants during activation
- Company grants are cleanly removed during deactivation without affecting global or other-company permissions
- The shared Entra application is disabled only when no non-empty company grants exist
- Non-SUPER users need Agent - Admin, Expense Mgmt. Admin, SECURITY, and Expense Agent permission sets to manage registrations
- Behaviour changes for users or extensions.
