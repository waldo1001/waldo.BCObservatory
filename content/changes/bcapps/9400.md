# #9400 Route early preview feedback to the correct OCV area

> Early Access Preview feedback now routes to the correct OCV feedback area instead of appearing in the general feedback category.

## What changed

- Feedback from the Early Access Preview Features page was sent without OCV area metadata and landed in the general feedback area
- Feedback at release level and at feature level now goes to the EarlyAccessPreview area
- Feedback prompts and feature names stay the same
- Only routing metadata passed to the platform feedback API is added
- Behaviour changes for users or extensions.
