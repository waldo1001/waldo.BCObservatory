# #9550 [Main]-[BC-IN] Purchase invoice with a deferral schedule and Non-availment GST is not functioning correctly

> Purchase invoices with non-availment GST and deferral templates now post correctly in the India localization by handling deferral validation in the tax engine.

[Pull request](https://github.com/microsoft/BCApps/pull/9550) · merged into `main` (BC30) on 2026-07-17 by v-ajaztabrez (community contribution) · 1 file (+23 -1), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Purchase invoices with non-availment GST failed to post when a default deferral template was configured on a G/L account
- The base application's deferral validation was too strict for the tax engine scenario
- A subscription to the OnBeforeCheckDeferralConditionForGenJournal event now provides localization-specific handling
- The fix also resolves related journal voucher posting issues
- Changes only affect the India tax base application
- Behaviour changes for users or extensions.
