## What changed

- Page-level Boolean RecordActionsEnabled is set in OnAfterGetCurrRecord based on whether records exist
- Disables navigation and processing action groups plus the Print Label action when no records are present
- Individual action conditions still apply for stricter control, while group-level enablement handles nested and extension-added actions consistently
- Transition from populated to empty list after initial load is not addressed as a known platform limitation
- Test coverage includes initial empty and non-empty page states plus subcontracting extension actions
