# #13811 Enable custom agent task creation from the timeline

> Custom agents now support creating tasks directly from the timeline through an interface implementation, offering options to create a simple task or open the full test agent UI with draft preservation.

## What changed

- Implements IAgentManualTaskCreation interface for custom agents following the Sales Order Agent pattern
- Adds option dialog defaulting to 'Create in Test Agent page' with alternative 'Create task' choice
- Simple task dialog includes 'Open test agent' action visible only for custom agents
- Maintains security checks for configuration permissions, inactive agents, and archived agents
- Timeline file-upload task creation remains disabled
- Behaviour changes for users or extensions.
