# #9609 Bug 642555: [master] [NL] SEPA Direct Debit Export (Report 11000015 – pain.008.001.08) exports unstructured address instead of structured

> The SEPA Direct Debit export now formats debtor, creditor, and related addresses as structured XML elements with street, postal code, town, and country instead of a single unstructured text line, as required by banks.

[Pull request](https://github.com/microsoft/BCApps/pull/9609) · merged into `main` (BC30) on 2026-07-29 by AleksanderGladkov · 4 files (+273 -127), 3 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Address elements now exported as structured XML fields (<StrtNm>, <PstCd>, <TwnNm>, <Ctry>) instead of unstructured <AdrLine>
- Applies to debtor, creditor, ultimate creditor, and ultimate debtor addresses
- Each address element is only written when it contains a value
- Aligns Dutch SEPA Direct Debit export with bank requirements
- Behaviour changes for users or extensions.
