# #11435 Validate unauthenticated public API responses before use

> Unauthenticated external API responses are now validated for size, schema, and integrity before being used in tax and financial processing. The hardening covers VIES VAT validation, currency exchange rates, Nemhandel company status, and MTD fraud prevention endpoints.

[Pull request](https://github.com/microsoft/BCApps/pull/11435) · merged into `main` (BC30) on 2026-09-18 by dcenic · 13 files (+1195 -55), 5 AL · feature · tier official · **unreviewed** (machine-generated)

## What changed

- Size caps added to prevent oversized responses from external endpoints (64 KB for VIES/Nemhandel, 10 MB for currency rates, 4 KB for MTD)
- Integrity checks ensure VAT responses echo the requested country code and VAT number to prevent response spoofing
- Schema validation for JSON responses from Nemhandel and MTD endpoints
- Telemetry and Security Audit logging on rejection with PII minimization
- Comprehensive test coverage added for all size, schema, and integrity validation scenarios
- Behaviour changes for users or extensions.
