# #12007 [Main]-TDS Amount incorrectly calculated under Tax Information Factbox if you use Applies-to ID in the Indian version.

> Fixed incorrect TDS amount calculation when applying payments to purchase invoices via Applies-to ID in the Indian version. The system was deducting the gross payment amount instead of the TDS base, resulting in over-deducted TDS.

[Pull request](https://github.com/microsoft/BCApps/pull/12007) · merged into `main` (BC30) on 2026-09-30 by v-maheshsharma · 2 files (+6596 -6625), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Corrected calculation logic in the Applies-to ID TDS use case to properly sum applied TDS base amounts
- Removed an erroneous expression that was overwriting the calculated applied amount with the gross payment amount
- Bumped use-case version from 5 to 6 to ensure the corrected configuration is re-imported
- TDS now calculates correctly for single and multiple applied payments
- Behaviour changes for users or extensions.
