# #9914 [APIV2] Return unapplied lines from the Vendor Payments API

> The Vendor Payments API now returns all payment lines in a batch, including unapplied payments and those with non-invoice applications, matching the behavior of the Customer Payments API.

[Pull request](https://github.com/microsoft/BCApps/pull/9914) · merged into `main` (BC30) on 2026-08-07 by onbuyuka · 4 files (+336 -35), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Removed record-filtering logic that hid unapplied payment lines from the Vendor Payments API
- The appliesToInvoiceNumber field is now empty for non-invoice applications instead of showing credit memo numbers
- All payment lines are now visible regardless of application status or type
- Added comprehensive test coverage for unapplied payments and non-invoice applications
- Journal-batch scoping and POST/PATCH logic remain unchanged
- Behaviour changes for users or extensions.
