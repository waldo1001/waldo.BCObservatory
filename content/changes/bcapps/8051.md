# #8051 [Edit in Excel] Expose ExternalizeODataObjectName and add Page Control Field publisher

> The Edit in Excel codeunit now exposes a public procedure for OData object name conversion and adds an event for filtering page control fields before generating workbooks, enabling other apps to integrate with Edit in Excel without duplicating logic.

[Pull request](https://github.com/microsoft/BCApps/pull/8051) · merged into `main` (BC30) on 2026-07-09 by Franco111000 (community contribution) · 3 files (+114 -1), 2 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Exposes ExternalizeODataObjectName as public procedure for external apps to convert field and service names to OData format
- Adds OnPageControlFieldFilterBeforeFindSetInSetupFieldColumnBindings event to allow subscribers to filter or reorder fields in workbooks
- Enables integration with Edit in Excel without forking internal conversion logic
- Allows callers to honor user personalization when determining which fields appear in the workbook
- Tests added to verify public wrapper round-trip and event invocation
