# #13764 List the SIFT of a key that is disabled in metadata on the Indexes part

> The Indexes part on the Table Information page now lists disabled SIFTs for keys that are disabled in metadata and define SumIndexFields, allowing administrators to enable them.

[Pull request](https://github.com/microsoft/BCApps/pull/13764) · merged into `main` (BC30) on 2026-11-12 by ehenriksen9 (community contribution) · 1 file (+1 -1), 1 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Indexes List Part now lists a disabled SIFT row for keys that are disabled in metadata and define SumIndexFields
- Mirrors the existing condition used for regular indexes
- Administrators can select and enable such SIFTs, relying on the platform counterpart change
- The Key table is unchanged, so AL code reading MaintainSIFTIndex is unaffected
- Enabling a row for a key with MaintainSIFTIndex false is still rejected by the platform
- Behaviour changes for users or extensions.
