# #9005 (Bug 641089) Guard Item Ledger/Value Entry No. allocation in Item Jnl.-Post Line with CommitBehavior::Ignore

> Item journal posting now prevents duplicate-key errors in concurrent scenarios by wrapping split posting in a commit-behavior guard frame, with an event for callers that need commits honored.

## What changed

- Entry number allocation for Item Ledger and Value Entries is protected by CommitBehavior::Ignore guard
- OnSetCommitBehavior event allows subscribers to opt out and restore legacy commit behavior if needed
- Pattern mirrors existing guard in General Journal posting
- Applied across all regional layers (W1, APAC, CH, ES, IT, RU)
- Two tests verify commit suppression and opt-out behavior
- Behaviour changes for users or extensions.
