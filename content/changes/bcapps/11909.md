# #11909 Block guest users from managing Expense Agent

> Guest users and external administrators can no longer enable or disable Expense Agent or schedule or stop its tasks. External users are detected from the Business Central authentication email, with the access token identity-provider claim as a fallback.

[Pull request](https://github.com/microsoft/BCApps/pull/11909) · merged into `main` (BC30) on 2026-10-16 by encimita · 4 files (+57 -1), 4 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Guest and external administrator access is blocked from Expense Agent configuration changes
- Detection of external users uses Business Central authentication email or identity-provider claim as fallback
- Task scheduling and state changes trigger access validation before any state modification
- Limited task-scheduling warning removed as users are now blocked at configuration stage
- Behaviour changes for users or extensions.
