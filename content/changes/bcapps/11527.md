# #11527 E-document payment improvements

> E-Document payment processing now supports durable, retryable occurrences with bounded automatic retries, dispatcher job management, and enhanced French E-Reporting UI for lifecycle messages.

[Pull request](https://github.com/microsoft/BCApps/pull/11527) · merged into `main` (BC30) on 2026-10-13 by djukicmilica · 20 files (+972 -46), 8 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- Captures payment applications and reversals for outgoing sales-invoice E-Documents
- Installs recurring dispatcher processing occurrences in batches with 30-minute processing lease protection
- Implements bounded retries with delays of 5 minutes, 30 minutes, 2 hours, and 8 hours; Action Required status after five failures
- Adds UI for lifecycle messages, VAT breakdowns, payment occurrences, and retry details in French E-Reporting
- Migrates existing error occurrences to Retry Pending during install and upgrade
- Behaviour changes for users or extensions.
