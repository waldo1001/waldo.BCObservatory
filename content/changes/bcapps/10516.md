# #10516 Ruleset hardening: promote AL0468, AL0520, AL0589, AL0611, AL0749, AW0004 to Error

> Six AL compiler rules are promoted from Warning to Error severity in the base ruleset, with all existing accepted violations marked by pragmas at their source locations to enforce the rules going forward.

[Pull request](https://github.com/microsoft/BCApps/pull/10516) · merged into `main` (BC30) on 2026-08-27 by JesperSchulz · 36 files (+96 -31), 34 AL · refactor · tier official · **unreviewed** (model text not yet checked)

## What changed

- AL0468, AL0520, AL0589, AL0611, AL0749, and AW0004 rules moved from ruleset overrides to Error level
- 45 deliberate violations suppressed with scoped pragmas at call sites instead of remaining invisible as repo-wide warnings
- New violations of these rules now fail the build; known violations stay documented in the code
- Ruleset simplification reduces override count from 94 to 88
- Changes include table extensions, pages, codeunits and reports across localization and base application modules
