# #13054 [FR] Delocalize delayed VAT and SEPA payment-slip integration

> Moved French delayed VAT and SEPA direct debit payment-slip features from base layers to the Payment Management FR app, while maintaining reusable posting and calculation engines in the base application.

[Pull request](https://github.com/microsoft/BCApps/pull/13054) · merged into `main` (BC30) on 2026-10-23 by ventselartur · 76 files (+3453 -275), 60 AL · refactor · tier official · reviewed (checked by Opus)

## What changed

- Moved journal-context fields and the unrealized application buffer into Payment Management FR, with data migration
- Delayed VAT recognition and percentage validation now run through app subscribers using standard VAT calculation
- Moved source-document export-error linking into the app and corrected the error FactBox reference
- SEPA direct debit export now supports filtered and temporary entries while keeping ordinary collections working
- Updated permissions, data classification and cloud-migration lists without adding dependencies
- Behaviour changes for users or extensions.
