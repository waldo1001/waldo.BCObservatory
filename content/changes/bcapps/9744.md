# #9744 [Email - Outlook REST API] Skip attachments without contentBytes in RetrieveEmails

> The Email - Outlook REST API connector now skips attachments without contentBytes instead of failing the entire batch, allowing emails with non-file attachments to be imported successfully.

## What changed

- Attachments without contentBytes (item and reference attachments) are now skipped instead of causing batch failure
- File attachments with contentBytes continue to work unchanged
- Unhandled JSON parsing errors that rolled back entire email batches are eliminated
- Regression test added with test payload for non-file attachments
- Behaviour changes for users or extensions.
