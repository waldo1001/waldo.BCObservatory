# #11171 [Security][Hardening] Validate integration URLs stored in setup tables

> Integration endpoint URLs stored in setup tables are now validated against their expected host and scheme before use to prevent credential redirection to malicious endpoints. The validation applies to Pagero, SignUp, Logiq, Shopify, Document Exchange, and Dataverse connectors, falling back to hardcoded values on mismatch.

[Pull request](https://github.com/microsoft/BCApps/pull/11171) · merged into `main` (BC30) on 2026-09-22 by onbuyuka · 21 files (+573 -33), 7 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- URLs must match both host and scheme; https-to-http downgrades are rejected
- Malformed stored URLs fall back to hardcoded endpoints instead of throwing errors
- Online (SaaS) Document Exchange connections are pinned to Tradeshift; on-premises uses stored URLs unchanged
- Dataverse environments must match the configured cloud's trusted host suffix
- Shopify validates shop hostname before OAuth authorize and token endpoints
- Behaviour changes for users or extensions.
