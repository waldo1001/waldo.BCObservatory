# #12160 Deliverable 617319: Move French accelerated depreciation to W1 base application

> French accelerated depreciation functionality is now part of the standard W1 base application, with migration support for existing French setups through feature management.

## What changed

- Derogatory depreciation moved from French-specific localization to the core application
- New depreciation book setup fields, posting accounts, and calculation logic added to all installations
- Links created between regular and derogatory entries to maintain consistency during posting and reversals
- Feature management controls migration of existing French depreciation books and historical data
- Reports and layouts updated to display derogatory depreciation information
- Behaviour changes for users or extensions.
