# #10051 Bug 642053: [master] [Sustainability] Preview Posting Creates Gaps in Sustainability Ledger Entry Numbers

> Preview posting in sustainability journals no longer creates gaps in Sustainability Ledger Entry numbers by intercepting inserts before database persistence and using temporary in-memory rows instead of consuming AutoIncrement identities.

[Pull request](https://github.com/microsoft/BCApps/pull/10051) · merged into `main` (BC30) on 2026-08-19 by AleksanderGladkov · 7 files (+639 -6), 3 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- Preview posting collects sustainability ledger entries in memory instead of physically inserting them to avoid consuming AutoIncrement identity numbers
- Adds interception logic to shared insert operation to redirect preview rows to temporary storage
- Normal posting behavior remains unchanged and maintains sequential numbering
- Comprehensive regression tests verify entry number continuity across journal types including general journal, purchase credit memo, recurring journals, and fixed asset journals
- Multiple preview operations no longer burn entry numbers
- Behaviour changes for users or extensions.
