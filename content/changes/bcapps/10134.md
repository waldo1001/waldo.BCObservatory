# #10134 [Bug 646487] Composite layout: focus fix, body-layout gating, and setup UI

> Multiple bugs in composite layout management are fixed, including focus handling, multi-select deletion, configuration key conflicts, and layout subtype restrictions. UI labels are clarified and a Details FactBox replaces the Theme and Header/Footer Box.

[Pull request](https://github.com/microsoft/BCApps/pull/10134) · merged into `main` (BC30) on 2026-08-21 by v-mortenr · 10 files (+1484 -159), 9 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Focus now moves to newly created theme or header/footer parts
- Multi-select delete and configuration row creation no longer cause data loss or invalid states
- Theme and header/footer can only be assigned to body layouts, enforced at UI and save level
- Details FactBox replaces Theme and Header/Footer Box with better layout of information
- Configuration row scopes are displayed as human-readable text instead of wildcard conventions
- Behaviour changes for users or extensions.
