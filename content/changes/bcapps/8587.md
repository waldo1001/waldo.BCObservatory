# #8587 [Shopify] Make codeunit 30272 "Shpfy Update Price Source" public

> Codeunit 30272 "Shpfy Update Price Source" is now public, allowing partners to reference it for custom Shopify price calculation logic through explicit bind/unbind subscriptions.

[Pull request](https://github.com/microsoft/BCApps/pull/8587) · merged into `main` (BC30) on 2026-07-07 by onbuyuka · 1 file (+1 -1), 1 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Access on codeunit 30272 changes from Internal to Public
- Partners handling OnBeforeCalculateUnitPrice can bind this codeunit so the pricing engine uses the Shop's currency, VAT and discount settings
- The codeunit only reads non-sensitive Shop configuration
- EventSubscriberInstance is Manual, so subscriptions stay inactive until a partner binds them
- Getters on codeunit 30182 remain internal
