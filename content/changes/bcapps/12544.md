# #12544 Slice 626931: [Expense Agent] Lost receipt workflow and document creation (November '26)

> The Expense Agent now allows users to submit expenses without a receipt by selecting a 'No Receipt' option, which generates a standardized document, attaches it automatically, and applies enhanced compliance controls through policy-based settings.

[Pull request](https://github.com/microsoft/BCApps/pull/12544) · merged into `main` (BC30) on 2026-11-20 by BardurKnudsen · 40 files (+1699 -299), 34 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- No Receipt workflow enables expense submission when original receipt is missing
- System auto-generates a standardized Lost Receipt document and attaches it as proof
- Policy-based controls: administrators can allow/disallow, set maximum amounts and frequency limits
- Marked expenses are assigned Non-Compliant status and require approver review
- New enums and codeunits handle No Receipt declaration, management, and validation
- Behaviour changes for users or extensions.
