# #10567 SOA : Create Task from TaskPane respects review configuration for known senders

> Tasks created manually in the SOA Create Task pane now respect the review configuration for known senders, and typing a sender email automatically resolves the matching contact or customer.

[Pull request](https://github.com/microsoft/BCApps/pull/10567) · merged into `main` (BC30) on 2026-08-30 by VolodySyn · 4 files (+35 -11), 4 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- Manual task creation now honors the configured review setting (No review, First message, All messages)
- SOATaskMessage.MessageRequiresReview refactored to accept sender address instead of Email Inbox record for code reuse
- SOA Create Task page resolves and initializes contact/customer when a sender email is typed in, matching the lookup behavior
- Sample message personalization, location, and language are now populated for manually created tasks
- Prior selections are cleared and lookup is skipped on empty input to prevent stale matches
- Behaviour changes for users or extensions.
