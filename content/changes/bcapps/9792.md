# #9792 Migrate ZUGFeRD, PEPPOL BIS 3.0 DE, Factur-X FR and Peppol BIS 3.0 FR to the V2 draft import pipeline

> German ZUGFeRD and PEPPOL BIS 3.0 DE formats and French Factur-X and PEPPOL BIS 3.0 FR formats are now migrated to the V2 draft import pipeline, enabling the draft-based workflow and Copilot-assisted matching previously unavailable for these localized e-document formats.

[Pull request](https://github.com/microsoft/BCApps/pull/9792) · merged into `main` (BC30) on 2026-07-29 by Groenbech96 · 24 files (+2380 -1), 9 AL · feature · tier official · **unreviewed** (machine-generated)

## What changed

- ZUGFeRD and Factur-X handlers implement both CII XML parsing and PDF/A-3 container extraction
- PEPPOL BIS 3.0 handlers for both countries reuse existing UBL readers adapted for their regional specifications
- French SIRET identifiers and German Leitweg-ID values are preserved during round-trip import-export cycles
- New enum extension values added for Read into Draft and Structure Received workflows
- German table extension field stores buyer reference data on E-Document Purchase Header
- Behaviour changes for users or extensions.
