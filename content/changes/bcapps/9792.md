# #9792 Migrate ZUGFeRD, PEPPOL BIS 3.0 DE, Factur-X FR and Peppol BIS 3.0 FR to the V2 draft import pipeline

> German ZUGFeRD and PEPPOL BIS 3.0 DE formats and French Factur-X and PEPPOL BIS 3.0 FR formats are now migrated to the V2 draft import pipeline, enabling the draft-based workflow and Copilot-assisted matching previously unavailable for these localized e-document formats.

[Pull request](https://github.com/microsoft/BCApps/pull/9792) · merged into `main` (BC30) on 2026-07-29 by Groenbech96 · 24 files (+2380 -1), 9 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- ZUGFeRD and Factur-X handlers parse CII XML and can extract it from a PDF/A-3 container
- PEPPOL BIS 3.0 DE reuses the existing XRechnung UBL reader; Peppol BIS 3.0 FR gets a new UBL reader
- French SIRET party identifiers written on export are mapped back on import
- New Buyer Reference DE field on E-Document Purchase Header stores the Leitweg-ID but is not shown in the UI yet
- New Read into Draft and Structure Received enum values; selecting these formats on a service defaults the read into draft implementation
- Behaviour changes for users or extensions.
