# #13330 Bug 656921: [master] Recurring Frequency missing from Edit in Excel

> The Recurring Frequency field is now editable in Edit in Excel for recurring general journals by restoring a direct column binding while maintaining localized display in the user interface.

## What changed

- Recurring Frequency was missing from Edit in Excel because the localized display uses a text variable that cannot bind to the field
- One editable Recurring Frequency column is restored for Edit in Excel
- Localized display and Open in Excel values stay the same, with no duplicate columns
- Recurring General Journal page changed in W1, APAC, ES, IT and RU; tests updated in more layers
- Validation showed OData updates were saved in the journal
