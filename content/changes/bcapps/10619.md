# #10619 [Shopify] Index Has Order State Error to fix slow Shopify Activities cue

> A database index is added to the Shopify Order Header table on the "Has Order State Error" field to improve the performance of the Activities cue, which was consuming significant server resources during slow counts.

[Pull request](https://github.com/microsoft/BCApps/pull/10619) · merged into `main` (BC30) on 2026-08-28 by onbuyuka · 1 file (+3 -0), 1 AL · performance · tier official · reviewed (checked by Opus)

## What changed

- New key added to Shpfy Order Header table to support filtering on Has Order State Error field
- Addresses performance bottleneck in Shopify Activities cue that was running full table scans
- Index enables SQL to seek narrow index instead of scanning the wide ~100-column table
- Expected to reduce CPU time from ~16.5s to near-instant for the Unprocessed Order Updates count
