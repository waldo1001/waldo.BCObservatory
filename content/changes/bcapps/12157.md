## What changed

- Page extensions providing address lookup integration have been removed
- Test code for the GetAddress.io functionality has been deleted
- Core objects marked with obsolete attribute and deprecation messages
- Configuration and permission sets updated to reflect obsolescence
- App was already uninstalled from existing tenants as of 28.3
- Breaking: existing extensions can stop compiling or working.
