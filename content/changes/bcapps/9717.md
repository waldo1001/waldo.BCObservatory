# #9717 Fix internal admin losing SUPER during customized plan provisioning

- Added IsUserInternalAdmin helper to check Global Admin, Dynamics 365 Admin, and BC Admin plans
- Applied internal-admin exemption to customized plan branch where it was previously bypassed
- Delegated admins intentionally excluded from exemption as their SUPER is governed separately
- Added six comprehensive tests covering various admin and user scenarios with customized plans
- Default plan behavior and existing users remain unaffected
- Behaviour changes for users or extensions.
