# #11211 [Bug 649379] Composite layout stress-test fixes, part resolution source and status action captions

> Report layout creation and management now prevents duplicate names from overwriting existing layouts, blocks unapproved layouts from becoming defaults, validates default layout status changes, handles empty uploads properly, and allows blank header/footer parts to be created.

[Pull request](https://github.com/microsoft/BCApps/pull/11211) · merged into `main` (BC30) on 2026-09-10 by v-mortenr · 6 files (+520 -18), 5 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Duplicate layout names are rejected before file upload instead of silently overwriting
- Moving a layout out of Approved status is blocked if it's the current report default
- Only approved layouts can be set as default
- Empty file uploads are validated and rejected with a clear error message
- Blank header/footer parts can now be created with the report's WordXmlPart injected
- Behaviour changes for users or extensions.
