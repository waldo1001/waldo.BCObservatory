# #11211 [Bug 649379] Composite layout stress-test fixes, part resolution source and status action captions

> Fixes composite report layout defects: a new layout can no longer overwrite one with the same name, default layouts must stay Approved, and empty uploads are rejected. Blank header/footer parts can be created. Show layout parts now resolves the effective layout correctly, and status actions read Set as ....

[Pull request](https://github.com/microsoft/BCApps/pull/11211) · merged into `main` (BC30) on 2026-09-10 by v-mortenr · 6 files (+520 -18), 5 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- New layouts with a taken name are rejected; only Replace deletes the old layout, after a successful upload
- An Approved layout explicitly selected as default cannot change status, and only approved layouts can become default
- Empty uploads are rejected with a dedicated error
- Blank header/footer parts can be created with the report's WordXmlPart
- Show layout parts uses the report's effective layout; status captions changed to Set as ...
- Behaviour changes for users or extensions.
