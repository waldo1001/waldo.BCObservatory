# #13824 Implement namespace normalization for Fabric Data and Logging in setup pages and platform management

> Fabric table and schema names are now normalized to lowercase in setup pages to ensure consistent handling across case-sensitive file systems and data platforms. New setup records use lowercase defaults (businesscentral and businesscentral_log) while existing values remain unchanged.

[Pull request](https://github.com/microsoft/BCApps/pull/13824) · merged into `main` (BC30) on 2026-11-12 by Bertverbeek4PS (community contribution) · 4 files (+111 -12), 3 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- Namespace fields normalize user input to lowercase when saved through the UI or API
- New setup records automatically use lowercase defaults to avoid casing mismatches in Fabric landing zones
- Existing stored namespace values are not migrated, preventing disruption to already-exported tables and models
- Added comprehensive tests validating lowercase normalization behavior
- Direct AL writes bypassing page validation may still store uppercase values
- Behaviour changes for users or extensions.
