# #9839 [main] feature 623913 - EET 2.0

> Implements EET 2.0 message format and security model for Czech electronic sales registration with new taxpayer identity and authorization fields, corrected production endpoint, response security verification, and updated UI documentation.

[Pull request](https://github.com/microsoft/BCApps/pull/9839) · merged into `main` (BC30) on 2026-10-28 by DavidHolusa · 56 files (+1827 -1161), 49 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Adds Taxpayer ID and Authorizing Taxpayer ID fields for own sale, direct and indirect representation, and authorization scenarios
- Introduces Unit ID field to replace the old Identification field in EET messages
- Verifies response certificate validity and subject against specification requirements
- Updates production endpoint and adds SOAPAction header for EET 2.0 compliance
- Reorganizes UI with new field groups for Taxpayer and Authorization on EET Service Setup and Entry Card
- Behaviour changes for users or extensions.
