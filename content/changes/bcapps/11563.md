# #11563 [E-Documents Core] [Peppol] - Add PEPPOL Requested Delivery Period support (header + line)

> Added support for PEPPOL Requested Delivery Period at both header and line level in purchase order export, and fixed import to properly copy line-level requested delivery dates instead of silently dropping them.

[Pull request](https://github.com/microsoft/BCApps/pull/11563) · merged into `main` (BC30) on 2026-09-24 by GediminasGaubys (community contribution) · 9 files (+360 -0), 7 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- New interfaces expose purchase header and line requested receipt dates for PEPPOL export
- Export writes requested delivery period as XML elements at header and line level only when dates are set
- Import now correctly validates and copies requested delivery date from staged sales line data
- Fixed issue where line-level delivery dates from PEPPOL orders were being silently dropped
- Changes covered by new test validating header and line dates are preserved independently
- Behaviour changes for users or extensions.
