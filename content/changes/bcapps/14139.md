# #14139 [main] bug - Fix incorrect source entry lookup event in Czech compensations

> Czech compensations now expose separate customer and vendor source entry lookup events with modifiable record parameters, replacing the previous event that passed the customer ledger entry by value and incorrectly used the customer event for vendor lookups.

[Pull request](https://github.com/microsoft/BCApps/pull/14139) · merged into `main` (BC30) on 2026-11-24 by v-janpopr · 3 files (+272 -25), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- New separate customer and vendor lookup events use var record parameters so subscribers can modify filters
- Original event marked obsolete in version 30.0 and retained under conditional compilation for compatibility
- Vendor lookup now correctly invokes vendor-specific event instead of customer event
- Regression tests verify subscriber-defined filters restrict lookups and selected entries are saved
- Existing release and posting tests updated to use their own posted documents instead of relying on existing ledger entries
- Behaviour changes for users or extensions.
