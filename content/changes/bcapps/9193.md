# #9193 Lock Code labels on default Transformation Rule records

> Transformation Rule record codes are now locked to prevent translation, ensuring configuration portability across differently-localized environments while keeping descriptions translatable.

[Pull request](https://github.com/microsoft/BCApps/pull/9193) · merged into `main` (BC30) on 2026-11-23 by yematsmartit (community contribution) · 1 file (+13 -13), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Added Locked = true to 12 Code-producing labels in Transformation Rule default records to prevent translation of primary keys
- Description labels remain translatable since only descriptions should be localized, not the code identifiers
- Fixes portability issues when configurations reference transformation rules across environments with different languages or translation extensions
- Prevents logical rule codes like 'Uppercase' from having different values depending on installation language
- Existing translated code values in pre-upgrade environments will not be renamed; new English locked codes will be inserted as separate records
