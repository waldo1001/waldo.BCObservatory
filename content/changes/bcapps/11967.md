# #11967 Block Edit in Excel for pages based on the User table

> Edit in Excel now blocks page-based editing for tables that are the User table to prevent authentication corruption when users are edited via Excel and published back. A new check in the Edit in Excel implementation logs telemetry and raises an error before workbook generation.

## What changed

- Adds CheckPageIsSupported validation in codeunit 1482 to block User table pages
- Check runs at all entry points before workbook creation and web service setup
- Uses source table identification to cover all User-based pages including renamed or localized ones
- Logs telemetry event 0000U9E when block occurs
- New tests verify the blocking behavior for pages with User as source table
- Behaviour changes for users or extensions.
