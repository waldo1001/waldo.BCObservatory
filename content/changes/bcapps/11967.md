# #11967 Block Edit in Excel for pages based on the User table

> Edit in Excel now blocks page-based editing for tables that are the User table to prevent authentication corruption when users are edited via Excel and published back. A new check in the Edit in Excel implementation logs telemetry and raises an error before workbook generation.

[Pull request](https://github.com/microsoft/BCApps/pull/11967) · merged into `main` (BC30) on 2026-09-29 by darjoo · 4 files (+70 -0), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Adds CheckPageIsSupported to codeunit 1482 (Edit in Excel Impl.), which blocks pages whose source table is User
- The check runs in all three entry points, and in EditPageInExcel it runs before the web service is created and before OnEditInExcelWithFilters is raised
- The check uses the source table, so it covers every page over User and renamed or localized *_Excel web services can't bypass it
- When the check blocks a page, it logs telemetry 0000U9E and shows an error
- This is a mitigation only: workbooks already downloaded and existing Users_Excel web services can still publish changes
- Behaviour changes for users or extensions.
