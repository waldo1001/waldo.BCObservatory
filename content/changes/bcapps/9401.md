# #9401 Fix Incoming Documents default processed filter

> The Incoming Documents page now defaults to showing only unprocessed records when opened without a filter, while preserving explicit filter choices. This restores the expected behavior after a regression.

[Pull request](https://github.com/microsoft/BCApps/pull/9401) · merged into `main` (BC30) on 2026-08-17 by JesperSchulz · 2 files (+55 -4), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Opening the page without a filter again defaults to unprocessed documents (Processed = false)
- An explicit Processed = true filter is no longer cleared, and explicit true or false filters are kept
- Regression tests cover the unfiltered, true and false filter scenarios
- Show All and Show Unprocessed actions keep their existing behavior
- Behaviour changes for users or extensions.
