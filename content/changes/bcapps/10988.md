# #10988 [Event Request] Codeunit 730 "Copy Item": Add price-specific before event

> A new before event OnBeforeCopyItemPriceListLines2 is added to the Copy Item codeunit to allow subscribers to intercept price list line copying operations with access to price and amount type parameters.

[Pull request](https://github.com/microsoft/BCApps/pull/10988) · merged into `main` (BC30) on 2026-09-08 by AleksandricMarko · 1 file (+11 -0), 1 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- New event OnBeforeCopyItemPriceListLines2 fires before copying price list lines in the price-specific overload
- Event exposes PriceType and AmountType parameters for subscriber customization
- The 2 suffix distinguishes this event from the existing OnBeforeCopyItemPriceListLines for the dispatcher method
- Enables extensions to control individual copy operations before filters and inserts
