# #14070 [29.x][All-e]"Specify the VAT registration number that you want to verify" error when entering a VAT Registration No. in the Sales Order if the Customer Card has no VAT Registration No.

> Sales Header VAT Registration No. validation now checks the number entered on the document instead of the customer card number, allowing verification of different numbers.

[Pull request](https://github.com/microsoft/BCApps/pull/14070) · merged into `releases/29.x` (BC29) on 2026-11-18 by sanjmaurya · 19 files (+524 -36), 15 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Passes a copy of the customer record with the entered VAT number to validation instead of the original customer card
- Preserves the existing rule that only fills a blank customer VAT number automatically
- Allows verification of VAT numbers different from those on the customer card
- Fixes error when customer card has no VAT number but document entry requires validation
- Includes regression test ValidateHeaderVATRegistrationNoChecksEnteredNumberWhenCustomerHasNone
- Behaviour changes for users or extensions.
