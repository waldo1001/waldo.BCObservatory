# #9716 Expose AppService location and EUDB membership on Environment Information for internal consumption

> Environment Information now exposes App Service location and EU Data Boundary membership status for internal use, restricted to Microsoft-published callers and returning defaults outside SaaS.

## What changed

- Two new procedures added to expose AppService location and EUDB membership
- Both procedures restricted to Microsoft-published callers only
- Returns empty location and false EUDB status when outside SaaS infrastructure
- Includes partner and standard test coverage for the new functionality
- IsApplicationServiceInEUDB() returns false when outside EUDB or information unavailable
