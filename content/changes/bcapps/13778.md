# #13778 []Main[ALL-E] Dimensions of components are incorrectly populated when creating Production Order through Order Planning

> Order Planning now calculates component dimensions using the same inheritance and priority rules as Production Order Refresh, ensuring consistent dimension assignment for production order components regardless of creation method.

[Pull request](https://github.com/microsoft/BCApps/pull/13778) · merged into `main` (BC30) on 2026-11-10 by sanjmaurya · 5 files (+425 -2), 3 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Component dimensions in Order Planning now follow Production Order source code and dimension-priority rules
- Parent requisition line dimensions are inherited as Production Order Line dimensions
- Non-conflicting component defaults are preserved while conflicting defaults no longer override parent dimensions
- Planning Worksheet behavior remains unchanged
- Added regression tests for no priorities, item priority, and parent priority scenarios
- Behaviour changes for users or extensions.
