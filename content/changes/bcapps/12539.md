# #12539 Add Expense Agent consumption V2 and trial support

> Expense Agent adds a V2 consumption API and a 50-expense feature trial, with trial status in the billing overview and remaining free expenses in setup. Quota checks go through an internal interface so tests can inject a mock, and telemetry now logs a static message with selected metadata dimensions instead of the raw request.

[Pull request](https://github.com/microsoft/BCApps/pull/12539) · merged into `main` (BC30) on 2026-10-26 by encimita · 13 files (+1045 -42), 9 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- V2 consumption API validates nested v1 fields and required identifiers and rejects null usage values
- 50-expense trial; policy-evaluation operations do not count toward trial usage
- Trial status shown in billing overview and remaining free expenses in setup wizard
- Saved trial classification is preserved on retries, and consumption is allowed when trial quota is available
- Internal quota interface with a default production implementation and test injection
- Behaviour changes for users or extensions.
