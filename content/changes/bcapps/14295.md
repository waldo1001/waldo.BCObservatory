# #14295 [Main] Expense Management: make core expense business objects public

> Expense Management core business objects are now publicly accessible for extensions to read, extend, release and post expenses, while keeping agent-specific and policy-related functionality internal.

[Pull request](https://github.com/microsoft/BCApps/pull/14295) · merged into `main` (BC30) on 2026-11-20 by t-prda · 59 files (+514 -112), 59 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- 33 tables, 3 release and posting codeunits and 9 non-extensible enums in Expense Agent made public
- Corporate card, AI extraction, policy evaluation, alternate approver and Entra fields stay internal at field level
- On-behalf approval, raw Reopen, rule bypass and similar procedures made internal; local helpers made local
- Current-user release, check-and-release and reopen operations and posting via Codeunit.Run remain public
- XML documentation added to public procedures; BaseApp Spend Request objects get docs only
