# #11007 Add Travel Request API lifecycle to Expense Agent

> Travel Request API lifecycle management is integrated into the Expense Agent, enabling creation, approval, and rejection of travel requests through scoped OData endpoints with proper authorization and linked expense report generation.

[Pull request](https://github.com/microsoft/BCApps/pull/11007) · merged into `main` (BC30) on 2026-09-09 by claudiuciumedean · 30 files (+2653 -30), 23 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- Advertises travelRequest capability and adds owner/approver-scoped navigation for travel requests in API endpoints
- Implements bound submit, approve, and reject actions with authorization checks, status guards, and audit fields
- Automatically creates linked expense reports on travel request approval with cascade delete protection
- Normalizes currency handling on reads and writes while preventing PATCH requests from changing status or ownership
- Emits distinct submit, approve, and reject usage events without sensitive identifiers; excludes HTTP integration tests from CI
- Behaviour changes for users or extensions.
