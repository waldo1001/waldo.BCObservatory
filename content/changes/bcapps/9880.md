# #9880 [Bug Fix] #620132: Prevent IRS 1099 data on vendor ledger entries of non-1099 vendors

> Added validation to prevent IRS 1099 data from being entered on vendor ledger entries for vendors not set up for 1099 reporting. The validation checks that a vendor has an IRS 1099 Vendor Form Box Setup record for the selected reporting period before allowing IRS 1099 fields to be populated.

[Pull request](https://github.com/microsoft/BCApps/pull/9880) · merged into `main` (BC30) on 2026-10-23 by ventselartur · 4 files (+189 -2), 2 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Validates that vendors have 1099 setup before accepting 1099 reporting period, form number, or form box assignments
- Clearing 1099 fields remains unconditionally allowed
- Added CheckVendorSubjectFor1099Reporting method to verify vendor-period setup exists
- Prevents data inconsistency where non-1099 vendors could receive 1099 information
- Includes three new test cases covering validation and clearing scenarios
- Behaviour changes for users or extensions.
