# #10308 Uptake agent archiving in Sales Order Agent (AB#644549)

> The Sales Order Agent app now supports agent archiving, a soft delete capability that marks deactivated agents as read-only while preserving their data. Archived agents no longer consume instance slots, their identities and mailboxes can be reused by administrators, and the setup experience becomes read-only for archived agents.

[Pull request](https://github.com/microsoft/BCApps/pull/10308) · merged into `main` (BC30) on 2026-08-19 by qasimikram · 9 files (+359 -36), 9 AL · feature · tier official · **unreviewed** (machine-generated)

## What changed

- Archived agents no longer count toward the 20-agent instance limit, freeing slots
- Archived agent identities and mailboxes can be deliberately reused by administrators but are not auto-suggested
- Setup pages become read-only for archived agents with explanatory notifications
- Scheduled tasks are canceled when agents are deactivated to prevent orphaned execution
- Upgrade processes skip archived agents to avoid repeated failures on write operations
- Behaviour changes for users or extensions.
