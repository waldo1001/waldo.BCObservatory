# #9360 Harden SFTP Client module (security review phase 1)

> The SFTP Client module hardens security by removing MD5 fingerprint support, adding a 25 MB file-size limit, disabling debugging, and applying NonDebuggable attributes to sensitive code paths. The SFTP Connector now only accepts SHA256 fingerprints.

[Pull request](https://github.com/microsoft/BCApps/pull/9360) · merged into `main` (BC30) on 2026-08-12 by JesperSchulz · 10 files (+153 -38), 7 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- MD5 host-key fingerprints are no longer supported; only SHA256 prefixes accepted
- File upload and download operations are capped at 25 MB with a typed File Too Large exception
- Debugging is disabled and sensitive code paths marked NonDebuggable to protect customer data
- Generic exception branch no longer exposes raw server or .NET exception text
- Telemetry event SFTP-0001 added to track file transfer sizes
- Breaking: existing extensions can stop compiling or working.
