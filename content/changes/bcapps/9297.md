# #9297 [Main]- Error The Bin Content does not exist.Not able to post an Inventory Pick for Assemble to Order

> Fixed a bug preventing posting of inventory picks for assemble-to-order items by skipping bin content validation for ATO pick lines, which don't have bin content until assembly posting occurs.

## What changed

- ATO pick lines were incorrectly validated against bin content that doesn't exist yet
- Validation only happens during assembly posting, not before the pick
- Solution skips bin content checks for ATO lines in the validation loop
- Test case added to prevent regression
