# #9122 Bug 641488: Add "Calendar Entries Available Until" FlowField to Work/Machine Center

> A new FlowField called Calendar Entries Available Until has been added to Work Center and Machine Center tables to show the latest date for which calendar entries have been generated, helping users avoid stale calendar errors during scheduling.

## What changed

- New FlowField (field 7304) calculates the maximum date from Calendar Entry records for each center
- The field is displayed on Work Center and Machine Center cards and lists
- Visual styling marks the field as Unfavorable when the date is in the past
- IT layer Work Center pages are updated to propagate the new field
- Tests added to verify FlowField calculations for both Work Center and Machine Center
- Behaviour changes for users or extensions.
