# #12538 Remove CLEAN27 for Create Item from Item No. setup fields

> Removes the CLEAN27-guarded code for the Create Item from Item No. fields in the Sales & Receivables Setup and Purchases & Payables Setup tables and pages, across the W1 and localization layers. The related helper code in the LibrarySales and LibraryPurchase test libraries is also removed.

[Pull request](https://github.com/microsoft/BCApps/pull/12538) · merged into `main` (BC30) on 2026-10-08 by Alexander-Ya · 64 files (+48 -596), 44 AL · obsoletion · tier official · reviewed (checked by Opus)

## What changed

- Removes CLEAN27 code for the Create Item from Item No. fields in tables 311 and 312
- Removes the matching controls from the Sales & Receivables Setup and Purchases & Payables Setup pages
- Removes the related helpers from the LibrarySales and LibraryPurchase test codeunits
- Applied in W1 and many country layers
- Breaking: existing extensions can stop compiling or working.
