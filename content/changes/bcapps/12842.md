- CalcQtyOnShipmentBins fallback logic added to find picked stock in non-default shipment bins
- Addresses issue where picked quantities were incorrectly reset to zero, blocking subsequent picks
- Uses existing CalcQtyOnBin helper to check non-default shipment bins while preserving item-tracking filters
- Fix applies to basic warehouse locations where shipment bins lack explicit Ship bin type
