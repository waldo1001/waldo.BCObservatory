# #13012 [Subcontracting] Assign worksheet suggestions to existing purchase orders

> Subcontracting worksheet users can now assign suggestions to existing open purchase orders instead of always creating new orders, with filtering and validation for purchase order compatibility.

[Pull request](https://github.com/microsoft/BCApps/pull/13012) · merged into `main` (BC30) on 2026-11-18 by stevengrossGOB (community contribution) · 32 files (+3730 -552), 21 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- Adds purchase order targeting to requisition lines with compatibility checks for vendor, customer, shipping, currency and purchasing code
- Worksheet gains actions for assigning purchase orders, clearing targets, and showing assigned orders
- Reference semantics changed: Ref. Order Type now indicates Purchase with empty Ref. Order No., while Prod. Order No. tracks the production order
- Requisition Line Management codeunit removes target if action message changes from New
- Comprehensive test coverage with 27 new tests for assignment, validation, and edge cases
- Behaviour changes for users or extensions.
