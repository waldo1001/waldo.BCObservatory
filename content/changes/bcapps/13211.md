# #13211 Copy time sheet skips deleted work types and absence reasons

> Time sheet copying now handles deleted work types and absence reasons gracefully by leaving them blank instead of failing, with a notification alerting users to review affected lines before submission.

[Pull request](https://github.com/microsoft/BCApps/pull/13211) · merged into `main` (BC30) on 2026-10-29 by VolodySyn · 4 files (+323 -23), 3 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Copy time sheet operations no longer error when work types or absence reasons have been deleted
- Deleted references are left blank on copied lines, requiring users to select valid ones before submitting absence lines
- Time Sheet Details FactBox hides description when the work type or absence reason no longer exists instead of raising an error
- Users receive a single notification after copying showing how many lines have blank work types or absence reasons requiring review
- All other line data (type, description, chargeable status, time details, comments) copies normally
- Behaviour changes for users or extensions.
