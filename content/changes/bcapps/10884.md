# #10884 [Bug Fix] Fix recurring journal background posting for IRS 1099 invoice lines (US)

> IRS 1099 subscriber no longer persists journal lines directly, preventing errors when background posting re-validates scheduled lines and allowing the line owner to control persistence.

## What changed

- Removed SaveChangesInGenJnlLine calls from IRS 1099 subscribers to prevent double-persistence during OnModify re-entry
- Subscribers still derive IRS fields onto records but leave persistence to the owning caller
- OnModify guard remains to protect user edits while allowing background posting to succeed
- Added three test cases to verify scheduled posting syncs IRS data without errors and direct modify guards still work
- No schema, permission, or upgrade impacts
