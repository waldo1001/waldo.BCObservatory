# #11604 fix: capture Shopify fulfillment deliveredAt timestamp

> The Shopify connector now captures and displays the fulfillment delivery timestamp from Shopify, enabling users to see when shipments were actually delivered. A new field stores the deliveredAt value, the GraphQL query requests it, and the import logic parses it across both order fetches and shipment exports.

[Pull request](https://github.com/microsoft/BCApps/pull/11604) · merged into `main` (BC30) on 2026-10-05 by abame (community contribution) · 6 files (+86 -5), 4 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Added deliveredAt field to Shpfy Order Fulfillment table
- Updated GraphQL query to request deliveredAt timestamp from Shopify
- Import logic now parses and stores the delivered timestamp
- Delivered At value displayed on Order Fulfillment pages
- Handles both null values and re-import scenarios with timestamp updates
- Behaviour changes for users or extensions.
