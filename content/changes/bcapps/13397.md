# #13397 [main] Incorrect depreciation calculation for assets used less than 180 days under Income Tax Act rules

> Fixed depreciation calculation for Indian fixed assets used less than 180 days, which previously applied a 50% reduction twice under Income Tax Act rules. The calculation now counts only days the asset is in use and avoids duplicate reductions.

[Pull request](https://github.com/microsoft/BCApps/pull/13397) · merged into `main` (BC30) on 2026-11-06 by Shikhverma · 2 files (+17 -11), 2 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Removed duplicate 50% reduction that was applied both from setup and hardcoded logic
- 180-day reduction now counts actual days asset was in use in fiscal year, not calculation run duration
- Depreciation calculated against opening fiscal year book value minus already-posted amounts
- Prevents over-reduction to 25% when 50% reduction should apply
- Later calculation runs in same year only top up to annual depreciation amount
- Behaviour changes for users or extensions.
