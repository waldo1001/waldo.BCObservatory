# #10513 [Extensibility Request] issue 30270: expose JobPostLine before calculating totals

> Sales invoice posting exposes a new event that provides access to the Job Post-Line instance before calculating totals, enabling extensions to interact with job data during the posting process.

## What changed

- New event OnPostLinesOnBeforeCalcSums in Sales Post Invoice Events codeunit
- Event fires before TempInvoicePostingBuffer.CalcSums in the PostLines method
- Provides subscribers with posting context and active Job Post-Line instance
- Implemented across all localization layers (W1, APAC, BE, ES, FI, IT, NA, RU)
- Allows extensions to access job data without changing existing procedure signatures
