# #13910 [Main] - Bug 657627: [Expense Agent] Expense User Card rejects manual approval setup with duplicate error

> The Expense User Card now reuses an existing unassigned approval setup instead of rejecting it with a duplicate error, and allows replacing an assigned approver after confirmation.

[Pull request](https://github.com/microsoft/BCApps/pull/13910) · merged into `main` (BC30) on 2026-11-24 by v-rohangarg20 · 2 files (+151 -9), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- An unassigned existing setup is automatically assigned to the card owner
- Replacing a different approver requires confirmation showing both approvers
- Adding a user already assigned to the same approver preserves the original validation error
- Noninteractive execution does not authorize approver replacement
- Regression tests added for unassigned setup, confirmed replacement, and duplicate assignment scenarios
- Behaviour changes for users or extensions.
