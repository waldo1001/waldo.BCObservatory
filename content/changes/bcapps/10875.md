# #10875 [Master] Partial Warehouse Shipment with Lot-Tracked Item Fails on Second Shipment Due to Auto-Populated Bin Code and Item Tracking Quantity Validation Error ("You cannot select more than 0 units")Initial commit

> Fixed a bug where partial warehouse shipments of lot-tracked items failed on subsequent shipments because the item tracking incorrectly inherited the sales line's bin code, restricting availability to that bin instead of allowing selection from the correct warehouse bin.

[Pull request](https://github.com/microsoft/BCApps/pull/10875) · merged into `main` (BC30) on 2026-09-15 by sanjmaurya · 2 files (+181 -0), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Clears the bin code in tracking specification when handling warehouse shipment lines as the second source
- Prevents inherited bin codes from restricting item availability incorrectly
- Allows remaining lot-tracked quantities to be selected from the appropriate warehouse bin
- Fixes validation error when selecting more than available units in a restricted bin
- Added comprehensive test coverage for partial shipments with lot-tracked items
- Behaviour changes for users or extensions.
