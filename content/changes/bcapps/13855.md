# #13855 [Main][ALL-E] Item Attributes (Decimal): Unable to Enter 0 After Clearing the Attribute Value to blank 

> Fixed decimal item attribute lookup to correctly distinguish between blank and zero values, allowing users to save 0 as an attribute value after clearing it.

[Pull request](https://github.com/microsoft/BCApps/pull/13855) · merged into `main` (BC30) on 2026-11-10 by sanjmaurya · 2 files (+77 -2), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Decimal item attribute lookup was incorrectly selecting blank records when searching for numeric 0
- Blank attribute records have a default numeric value of 0, causing the collision
- Lookup now excludes blank attribute values when searching for nonblank decimal values
- Regression tests added to verify blank-versus-zero lookup and zero persistence across page reopens
- Behaviour changes for users or extensions.
