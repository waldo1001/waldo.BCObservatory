# #10092 [Shopify] Add cues for Skipped Records and API Errors on Activities page

> Two new cues on the Shopify Activities page display counts of skipped sync records and API errors, making background job issues visible without manually opening logs.

[Pull request](https://github.com/microsoft/BCApps/pull/10092) · merged into `main` (BC30) on 2026-08-19 by onbuyuka · 2 files (+50 -0), 2 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Added a Skipped Records cue that counts all Shpfy Skipped Record entries, turns amber when above zero and drills down to the Skipped Records page
- Added an API Errors cue that counts log entries with errors, turns red when above zero and drills down to error-filtered Log Entries
- Two new FlowFields (10, 11) on the Shpfy Cue table back the cues
- Makes skipped records and errors from background Job Queue syncs visible, since the skipped-record notification needs GuiAllowed
- Additive only and follows the existing cue pattern; no breaking changes
- Behaviour changes for users or extensions.
