# #9949 [Bug 645022] UI improvements for report themes and header/footers (composite layout)

> Composite layout administration pages get UI improvements: page 9663 shows decoded part names, and page 9666 gains a Description column plus Replace, Edit description and Show info actions. Page 9668 adds a Description field, and page 9660 enables composite actions only for Word layouts.

[Pull request](https://github.com/microsoft/BCApps/pull/9949) · merged into `main` (BC30) on 2026-08-10 by v-mortenr · 6 files (+311 -6), 5 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Tenant Report Layout Cfg shows decoded part names instead of the raw guid::name value, display only
- Report Theme and Header/Footer adds Description column, Replace, Edit description and Show info actions, with Replace and Part Status scoped to lines
- New Report Theme Header/Footer page adds a Description field and is reused as the Edit Description dialog
- Report Layouts enables Manage all themes/header-footers and Layout configuration only for Word layouts
- Telemetry no longer includes the raw user-entered layout description
- Behaviour changes for users or extensions.
