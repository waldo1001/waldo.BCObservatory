# #10346 Fix activity log indirect permissions

> The Expense Agent and Expense Management permission sets now grant indirect permissions on Expense Activity Log Entry to prevent SaaS entitlement failures when users create lifecycle activity entries, while keeping all writes code-mediated through the activity log manager.

[Pull request](https://github.com/microsoft/BCApps/pull/10346) · merged into `main` (BC30) on 2026-08-20 by t-prda · 4 files (+50 -5), 2 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Expense Mgmt. Edit receives indirect insert/modify/delete permission on Expense Activity Log Entry
- Expense Agent - Data receives direct read plus indirect insert/modify/delete permissions
- All activity writes remain code-mediated through Expense Activity Log Mgt., never direct
- Permission hierarchy automatically extends the fix to admin users and those with Expense Management roles
- Added regression tests verifying that both basic users and agents lack direct activity-log insert permission
