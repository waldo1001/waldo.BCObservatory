# #9127 Add Dataverse Cloud endpoints override for sovereign clouds

> A new interface and enum enable partners to override Dataverse endpoints for sovereign cloud environments without forking BaseApp. The setup table stores the cloud selection and endpoints are routed through the interface at all call sites.

[Pull request](https://github.com/microsoft/BCApps/pull/9127) · merged into `main` (BC30) on 2026-07-09 by onbuyuka · 10 files (+326 -22), 7 AL · feature · tier official · **unreviewed** (machine-generated)

## What changed

- New extensible enum and interface allow partners to provide sovereign cloud endpoints like GCC High, US-DoD, and China
- Setup table gains a field to store the selected Dataverse cloud, defaulting to Commercial with no UI changes
- All hardcoded OAuth and Discovery URLs now route through the interface implementation
- Existing commercial tenants are unaffected; no upgrade code needed
- Partners can extend the enum and implement their own endpoint codeunit
- Behaviour changes for users or extensions.
