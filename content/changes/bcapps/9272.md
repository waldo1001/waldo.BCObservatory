# #9272 Fix duplicate in-transit location in localized Contoso demo data

> The Contoso demo data now uses a single source for the in-transit location code across inventory and warehousing modules, eliminating duplicate location records in non-English locales.

[Pull request](https://github.com/microsoft/BCApps/pull/9272) · merged into `main` (BC30) on 2026-08-14 by attilatoury · 2 files (+17 -2), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Replaced the warehousing module's independent in-transit location definition with a call to the existing inventory module procedure
- Removed the redundant translatable label that could cause different abbreviations in non-English languages
- The duplicate-guard check now works correctly because both modules reference the same location code
- The fix only applies to new demo data; existing databases with duplicates are not cleaned up
- Safe to apply regardless of module initialization order since the function returns a constant
- Behaviour changes for users or extensions.
