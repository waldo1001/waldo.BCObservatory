# #10437 [FR E-Reporting] Add payment and invoice lifecycle messages

> E-Document message lifecycle infrastructure and French electronic invoicing support added to enable payment and invoice lifecycle communication with message queuing, response handling, VAT allocation, and buyer acceptance or refusal workflows.

[Pull request](https://github.com/microsoft/BCApps/pull/10437) · merged into `main` (BC30) on 2026-09-15 by djukicmilica · 61 files (+6347 -51), 29 AL · feature · tier official · **unreviewed** (machine-generated)

## What changed

- Public E-Document message API with IMessageSender and IMessageResponseHandler contracts for extensible lifecycle messaging
- Payment occurrence tracking with applied and reversed payment messages for approved invoices with retry and deduplication support
- French Collected and Negative Collected messages for payment applications and unapplications with proportional VAT allocation
- Buyer acceptance and refusal workflow for incoming purchase invoices with optional refusal reasons and single-response validation
- Background message delivery and response polling with queuing, external reference correlation, and status normalization
- Behaviour changes for users or extensions.
