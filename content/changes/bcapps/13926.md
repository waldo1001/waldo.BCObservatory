# #13926 Bug 648938: Transfer Routes matrix does not indicate configured direct routes

> In the In-Transit Code view of the Transfer Routes matrix, a configured off-diagonal direct-transfer route now shows a localizable Direct label instead of '...', even when an in-transit code is also set, so it can be told apart from an undefined route.

## What changed

- Configured off-diagonal direct routes show Direct in the In-Transit Code view
- Direct takes precedence even when an in-transit code is populated
- Non-direct routes, undefined routes, diagonal cells, shipping-agent views and AssistEdit are unchanged
- Three new tests cover direct display, precedence and compatibility; existing matrix baselines still pass
- Behaviour changes for users or extensions.
