# #13926 Bug 648938: Transfer Routes matrix does not indicate configured direct routes

> The Transfer Routes matrix now displays 'Direct' for configured direct-transfer routes without in-transit locations, instead of showing ellipsis that made them indistinguishable from undefined routes.

[Pull request](https://github.com/microsoft/BCApps/pull/13926) · merged into `main` (BC30) on 2026-11-12 by ChethanT · 2 files (+161 -1), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Direct-transfer routes in the In-Transit Code view display 'Direct' when configured without an in-transit location
- Empty off-diagonal cells no longer obscure the presence of a configured direct route
- Non-direct routes, undefined routes, diagonal cells, and shipping-agent views remain unchanged
- Three new test procedures verify direct route display, precedence, and compatibility
- Existing matrix baselines for in-transit code and shipping views still pass
- Behaviour changes for users or extensions.
