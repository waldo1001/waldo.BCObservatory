# #9912 Restore the IRS Forms assisted setup registration removed by the CLEAN25 sweep

> The IRS Forms setup wizard registration that was accidentally removed during a code cleanup sweep has been restored, allowing US users to access the 1099 setup guide from the Assisted Setup list again.

## What changed

- Re-registers the IRS Forms Guide wizard in Assisted Setup from codeunit 10030 with an unconditional OnRegisterAssistedSetup subscriber
- Setup is marked complete when an IRS Reporting Period record already exists
- The IRS Reporting Period read is guarded by ReadPermission so the Assisted Setup page still opens for users without access
- Adds test codeunit 148025 IRS Forms Assisted Setup Tests (6 tests) covering registration, completion logic and title, description and help link
- Behaviour changes for users or extensions.
