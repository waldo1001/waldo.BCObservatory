# #13439 Validate negative Reorder Quantity for Fixed Reorder Qty. planning

> Item, Item Template, and Stockkeeping Unit now reject negative Reorder Quantities with a clear validation error, and planning failures for Fixed Reorder Qty. policy are replaced with actionable error messages.

[Pull request](https://github.com/microsoft/BCApps/pull/13439) · merged into `main` (BC30) on 2026-11-06 by alexei-dobriansky · 18 files (+184 -4), 17 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Reorder Quantity on Item, Item Templ. and Stockkeeping Unit now has MinValue = 0; Item and Item Templ. changes are propagated to country layers
- CalcReorderQty in Inventory Profile Offsetting raises a clear field error for negative values under Fixed Reorder Qty. instead of the internal 'Inventory Profile does not exist' error
- With planning resiliency, the error is written to the Planning Error Log with the actual value instead of a hard-coded 0
- Existing negative values are not migrated; zero quantities behave as before
- New SCM planning test covers the negative quantity error
- Behaviour changes for users or extensions.
