# #9687 [main] bug 642230 - Enhance FA General Report logic and add tests for Tax Deprec. Group and FA Posting Group handling

> Fixed a bug where the FA General Report procedures could clear the FA Posting Group or Tax Depreciation Group fields with blank values from depreciation book records instead of only updating with non-blank values. Added comprehensive unit tests for both scenarios.

[Pull request](https://github.com/microsoft/BCApps/pull/9687) · merged into `main` (BC30) on 2026-07-23 by DavidHolusa · 9 files (+281 -5), 5 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- SetFAPostingGroup and SetFATaxDeprGroup now check that source values are non-blank before updating the fixed asset fields
- Prevents silent data loss where running reports with Group Totals filters could erase posting group assignments
- Guard condition added for blank value validation in both W1 and CZ localizations
- New unit tests cover both the protective case (blank source) and the update case (different non-blank source)
- No breaking changes or data migration required
- Behaviour changes for users or extensions.
