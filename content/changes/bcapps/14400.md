# #14400 [Master Data Management] User-friendly errors for cross-environment connection and permission failures

> Cross-environment master data synchronization now provides clear error messages when connections fail or permissions are insufficient, helping administrators diagnose and fix setup issues quickly instead of seeing bare HTTP status codes.

[Pull request](https://github.com/microsoft/BCApps/pull/14400) · merged into `main` (BC30) on 2026-11-23 by dcenic · 11 files (+624 -32), 6 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- HTTP errors are mapped to actionable guidance about source environment names, company names, app registration, and permissions
- Unreadable tables now generate explicit permission errors instead of silently stopping synchronization
- Connection wizard validates the setup and shows the failure reason before saving
- Telemetry captures OData error codes and classified failure reasons for better diagnostics
- GetCapabilities reports when source hasn't approved cross-environment privacy notice
- Behaviour changes for users or extensions.
