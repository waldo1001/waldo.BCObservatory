# #9464 [Extensibility Request] issue 30349: add OnBeforeCheckTrackingIfRequired event to Item Journal Line

> An integration event is added to the CheckTrackingIfRequired procedure in the Item Journal Line table, allowing extensions to perform custom item tracking validation and raise more meaningful error messages before standard checks run.

## What changed

- New OnBeforeCheckTrackingIfRequired event fires at the start of CheckTrackingIfRequired
- Subscribers can run their own item tracking validation before the standard TestField checks
- Extensions can raise clearer errors that point to the affected document line or item
- Applied in W1 and the APAC, CH, ES, FR, GB, IT and RU layers
