# #10216 Fix Purchase Journal document amount decimal formatting

> The Purchase Journal page now refreshes its Document Amount field formatting when a vendor is validated, so it immediately reflects the correct decimal-place settings from the vendor's currency instead of retaining the previous format.

[Pull request](https://github.com/microsoft/BCApps/pull/10216) · merged into `main` (BC30) on 2026-08-13 by PredragMaricic · 8 files (+8 -0), 8 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- Validating a vendor updates the journal line's currency but the page did not refresh the field format
- Document Amount field uses Currency Code as its auto-format expression
- Page now refreshes without saving after account validation so the field immediately applies the vendor currency's decimal-place settings
- Change applied to W1 and all localized versions
- Existing test verifies three-decimal values are preserved correctly
- Behaviour changes for users or extensions.
