# #13672 Expense Agent: expose VAT setup in configuration wizard

> The Expense Agent Setup Wizard now exposes VAT configuration controls (Default VAT Business Posting Group, Allow VAT Reclaim, and a link to VAT Posting Setup) within the wizard interface instead of requiring administrators to leave the wizard to access these settings.

## What changed

- VAT configuration fields added to the accounting defaults section of the setup wizard
- Controls use the existing temporary setup record and call ConfigUpdated() to mark changes without early persistence
- Default VAT Business Posting Group field is positioned first to satisfy table validation requirements
- Navigation to standard VAT Posting Setup page uses the same modal pattern as other wizard links
- Update and Cancel operations flow through existing save/discard logic
- Behaviour changes for users or extensions.
