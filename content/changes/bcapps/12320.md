# #12320 Fix 409 conflict in APIV2 Company Info E2E description test

> Fixed 409 conflict errors in APIV2 Company Info E2E tests by disabling test isolation to allow commits to take effect, and changed Environment Information reads to no longer write the singleton record.

[Pull request](https://github.com/microsoft/BCApps/pull/12320) · merged into `main` (BC30) on 2026-10-06 by darjoo · 2 files (+15 -1), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Disabled test isolation on APIV2 Company Info E2E test codeunit so Commit() succeeds and web-service calls can access records
- Modified GetEnvironmentDescription to use direct Get() instead of GetEnvironmentInformationSafe, preventing unintended writes on read operations
- Added test cleanup to restore original company and environment descriptions after E2E tests run
- Environment Information singleton record is now created only on first write rather than first read
- Resolves 409 'record in table being updated' conflicts that prevented both test methods from running
