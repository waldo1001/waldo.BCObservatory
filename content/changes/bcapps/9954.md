# #9954 Restoring undefined action. (Purchase Orders page can't be open in latest `main`)

> An earlier change emptied the body of an E-Document action. Because it was then not emitted, actionrefs pointing to it stopped the Purchase Orders page from opening. This change restores the action body so the pages open again.

[Pull request](https://github.com/microsoft/BCApps/pull/9954) · merged into `main` (BC30) on 2026-08-06 by mynjj · 5 files (+40 -2), 5 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- An earlier change emptied an action's body, leaving it with no OnAction code and no RunObject, so it was not emitted
- Actionrefs to the missing action stopped the purchase order pages from opening
- The action code is restored in the E-Document page, the purchase order page extensions and the line matching objects
- The change was merged because the analyzer was disabled on the BCApps gate
- Behaviour changes for users or extensions.
