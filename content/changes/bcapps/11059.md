# #11059 Hardening subscription billing + drop shipment scenarios

> Subscription Billing now creates subscriptions at sales order release from the existing quantity per serial number, using Qty. to Ship only as a fallback, so a blank Default Quantity to Ship works. It also fake-invoices sales orders released through drop shipment purchase receipts.

## What changed

- Subscription creation uses QtyPerSerialNo and falls back to Qty. to Ship only when it is zero
- Handles Sales & Receivables Setup with Default Quantity to Ship set to Blank
- Subscribes to sales orders closed by a drop shipment purchase order and sets the same values as the normal path
- Tests added for both scenarios
- Behaviour changes for users or extensions.
