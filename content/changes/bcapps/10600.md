## What changed

- New Reclassify CO2e % field added to FA Reclassification Journal Line table extension
- Field validation requires Sust. Account No. or New Sust. Account No. to be set
- Journal subscriber updated to use the new CO2e percentage field instead of acquisition cost percentage for emission reclassification
- New field exposed on the FA Reclassification Journal page
- Test cases added to verify the functionality with different and zero CO2e percentages
