# #9906 [Bug Fix] #641100: Export Acc. Sched. to Excel - log report usage in OnPostReport to avoid modal page in write transaction

> Report 29 now logs financial report usage after processing instead of before, preventing a write transaction that blocked modal pages when exporting account schedules with multiple worksheets.

## What changed

- Moved LogReportUsage call from OnPreReport to OnPostReport to avoid open write transactions
- Fixes PAGE.RunModal error when users updated Excel files with multiple sheets
- OnPreReport still resolves CompanyDisplayName for report execution
- Affected both W1 and NA layers which had identical defects
- Added regression test to verify audit logs don't block modal pages
- Behaviour changes for users or extensions.
