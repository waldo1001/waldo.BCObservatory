# #10336 [Main]- Incorrect calculation of single-level capacity and material cost for Stockkeeping Units (SKU) when running cost changes in the Standard Cost Worksheet and implementing the Standard Cost change

> The Implement Standard Cost Change report no longer copies an item's updated cost shares to its stockkeeping units in the Load SKU Cost on Manufacturing mode, where it used to ignore that setting. Users are told to recalculate SKU costs with Calc. Standard Cost on the Stockkeeping Unit Card.

[Pull request](https://github.com/microsoft/BCApps/pull/10336) · merged into `main` (BC30) on 2026-08-24 by DeepsShukla (community contribution) · 2 files (+192 -1), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- The Implement Standard Cost Change report was incorrectly copying item cost shares to SKUs regardless of the Load SKU Cost on Manufacturing setting
- Report now skips SKU cost updates in this scenario
- Users are directed to recalculate SKU costs using the Calc. Standard Cost action on the Stockkeeping Unit Card
- Fixes discrepancies in cost calculations for SKU-specific costing
- Behaviour changes for users or extensions.
