# #13692 Fix SharePoint REST upload 404 caused by trailing slash in parent folder

> The SharePoint REST connector now correctly handles trailing slashes in folder paths, fixing 404 errors that prevented uploads and file operations through the legacy REST API.

[Pull request](https://github.com/microsoft/BCApps/pull/13692) · merged into `main` (BC30) on 2026-11-05 by darjoo · 2 files (+195 -6), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Removed trailing separators from parent folder paths that caused API rejections
- Fixed SplitPath and GetParentPath logic to work with the newer GetFolderByServerRelativePath method
- Added path normalization in InitPath to handle directory paths from Storage Browser navigation
- Integrated fixes for doubled separators and root folder handling
- Resolves widespread upload failures affecting approximately 70k operations across 66 tenants
- Behaviour changes for users or extensions.
