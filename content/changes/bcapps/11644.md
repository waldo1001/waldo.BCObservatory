# #11644 [Subcontracting] Bug 648937: Transfer WIP Item is lost when production orders are created from Planning Worksheet

> Transfers of WIP items configured on production routings are now preserved when production orders are created from the Planning Worksheet, maintaining the connection between planning and production orders.

## What changed

- Transfer WIP Item and transfer descriptions are now stored on planning routing lines
- Values are propagated from routing lines through Planning Worksheet carry-out to production order routing lines
- Support includes both certified routing versions and base routings
- Integration tests added to verify the behavior
- Fixes data loss issue when creating production orders from planning worksheet
- Behaviour changes for users or extensions.
