# #9362 [FI] Delocalize FI VAT-VIES Declaration report into FI Core

> The Finnish VAT-VIES Declaration report is moved from a localized FI BaseApp override into FI Core as a report extension, with shared dataset columns added to the base report and Finnish-specific rendering handled through FI Core's extension layer.

[Pull request](https://github.com/microsoft/BCApps/pull/9362) · merged into `main` (BC30) on 2026-08-20 by djukicmilica · 17 files (+1224 -1804), 8 AL · refactor · tier official · **unreviewed** (machine-generated)

## What changed

- Report 19 VAT-VIES Declaration is delocalised: the FI BaseApp override is removed and functionality is reimplemented via FI Core extension
- Shared W1/BE base report gains dataset columns for Business Identity Code, Registered Home City, and localized captions to support Finnish requirements
- FI Core adds a report extension with Finnish RDLC layout and a feature key FIVATVIESDeclaration to gate Finnish-specific fields and captions
- VAT Entry table's FI-specific EU Service key is moved from FI BaseApp override to FI Core table extension
- Tests verify both enabled and disabled feature states and ensure standard report behavior is preserved
