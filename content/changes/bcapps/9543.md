# #9543 Support VAT return reporting frequencies in Denmark

> The Danish electronic VAT declaration system now supports multiple reporting frequencies - monthly, quarterly, and semi-annual periods - parsed from SKAT VAT return data, with a legacy quarterly fallback feature flag and enhanced validation.

[Pull request](https://github.com/microsoft/BCApps/pull/9543) · merged into `main` (BC30) on 2026-08-02 by djukicmilica (community contribution) · 7 files (+548 -12), 4 AL · feature · tier official · **unreviewed** (machine-generated)

## What changed

- Added ElecVATDeclRepFrequency enum to represent reporting frequency types
- Extended VAT period calculation logic to handle monthly, quarterly, and semi-annual frequencies
- Implemented validation to prevent overlapping VAT return periods and reject invalid due dates
- Retained legacy quarterly fallback behind feature flag DKElecVAT-ReportingFrequencyEnabled
- Expanded test coverage with focused scenarios for various frequency calculations
- Behaviour changes for users or extensions.
