# #10445 [Bug][Subscription Billing] Contract Renewal Quote total ignores the Billing Base Period and shows the base-period amount instead of the renewal-term amount

> Fix contract renewal quote totals to correctly apply billing rhythm conversions alongside base period conversions when calculating subscription line amounts.

[Pull request](https://github.com/microsoft/BCApps/pull/10445) · merged into `main` (BC30) on 2026-10-09 by miljance (community contribution) · 2 files (+157 -16), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Contract renewal quotes now show correct renewal-term amounts instead of base-period amounts
- Bug occurred when Billing Base Period differed from Billing Rhythm; with 1M base and 12M rhythm, totals showed 100 instead of 1200
- Root cause: contract-renewal branch omitted the base-period-to-rhythm conversion factor
- Period count variables changed from threaded var parameters to local variables to prevent value leakage between lines
- Added tests covering various billing period and rhythm combinations
- Behaviour changes for users or extensions.
