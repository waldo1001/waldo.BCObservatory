# #14123 [Shopify] Keep gift cards from unverified POS returns on the sales invoice

> Modified Shopify gift card handling on POS unverified returns so they remain on sales invoices rather than being treated as exchange items, preventing empty invoice generation with auto-release enabled.

[Pull request](https://github.com/microsoft/BCApps/pull/14123) · merged into `main` (BC30) on 2026-11-17 by onbuyuka · 13 files (+385 -37), 3 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- A gift card on a return with unverified return lines is treated as a regular order line again and invoiced
- Fixes empty sales invoices that failed to release when Auto Release was on
- Is Exchange Item is now set for every line as it is written, replacing MarkExchangeItemOrderLines, so re-importing fixes orders that were flagged by mistake
- Refund import creates no synthetic exchange refund line for these gift cards and removes one left by an earlier import
- Verified returns with exchanges behave as before; 7 tests added
- Behaviour changes for users or extensions.
