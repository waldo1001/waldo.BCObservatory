# #13582 [main] Price Groups of Subscription Packages are not considered.

> On the Assign Subscription Lines page, offered subscription packages are now always filtered to the customer's price group plus packages without a price group. Customers without a price group no longer see price-group-restricted packages, and the fallback that offered every package is removed.

[Pull request](https://github.com/microsoft/BCApps/pull/13582) · merged into `main` (BC30) on 2026-11-13 by Shikhverma · 2 files (+36 -4), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Filter now always applied to offered packages based on customer's price group plus unrestricted packages
- Customers without a price group now only see packages without a price group restriction
- Removed fallback filter clearing that previously allowed all packages when no match found
- Page does not open if no qualifying packages exist for the customer
- Automatic selection behavior unchanged; new test added for customer-without-price-group scenario
- Behaviour changes for users or extensions.
