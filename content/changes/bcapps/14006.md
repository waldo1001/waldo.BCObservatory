# #14006 GP - Better item transaction duplicate handling

> Fixes duplicate records during GP migration when inventory transactions contain multiple lot number receipt lines. A new GP item transactions buffer table is added and the GP Populate Combined Tables logic is updated, with permission set updates and new tests.

[Pull request](https://github.com/microsoft/BCApps/pull/14006) · merged into `main` (BC30) on 2026-11-17 by jaymckinney-enavate (community contribution) · 10 files (+298 -27), 9 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- New GP Item Transactions Buffer table added to the HybridGP app
- GP Populate Combined Tables codeunit updated to avoid duplicate item transactions
- Duplicates happened when a transaction had several lot number receipt lines
- HybridGP permission sets and permission set extensions updated for the new table
- New tests added in GP Item Transaction Tests
- Behaviour changes for users or extensions.
