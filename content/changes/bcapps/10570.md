# #10570 Expense Agent: add approval conversation to expense reports

> The Expense Agent now supports approval conversations by storing submitter comments, exposing them through the API, adding a pending-approval action with optional comments, and recording comments in activity events.

[Pull request](https://github.com/microsoft/BCApps/pull/10570) · merged into `main` (BC30) on 2026-09-02 by t-prda · 12 files (+288 -39), 8 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- The latest submitter comment is stored on the Expense Report Header
- The Expense Reports API exposes both latest comments
- New capability-backed pending-approval action that takes an optional comment
- Comments are recorded on the existing Submitted/Resubmitted and Rejected activity events
- Historical comments are shortened with an ellipsis, and the existing Expense Report page extension point is kept
- Behaviour changes for users or extensions.
