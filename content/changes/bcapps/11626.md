- Media and watermark cache lifetime now resets only at batch boundaries instead of during ancillary fetches
- Privacy consent failures show actionable messages instead of bare 403 errors
- Contact synchronization fixed for scenarios where auto-created contacts conflict with existing entries
- Blank date and datetime values now synchronize correctly
- Permission issues resolved for non-SUPER users accessing Master Data Management features
