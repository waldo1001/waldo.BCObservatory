# #13721 [Expense Agent] Create per diem line when approving travel requests with Per Diem Included

> When approving travel requests with Per Diem Included, the system now automatically creates a per diem expense line for each traveler based on matching expense rules, with blocking validation if no appropriate rule is found.

[Pull request](https://github.com/microsoft/BCApps/pull/13721) · merged into `main` (BC30) on 2026-11-06 by claudiuciumedean · 11 files (+1179 -30), 7 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Approving a Per Diem Included travel request adds a per diem line to each traveler's newly created expense report; existing reports are untouched
- The category is the first active Per Diem category whose rule matches the expense location and is effective on the trip start date
- Approval fails with an error, leaving the request Released, if no rule matches or the rule has no Daily Rate condition
- A per diem calculation of None still creates a zero-amount line
- Per diem lines are exempt from receipt and merchant requirements like Mileage, via ExpenseRuleValidation.IsMerchantReceiptRequirementApplicable
- Behaviour changes for users or extensions.
