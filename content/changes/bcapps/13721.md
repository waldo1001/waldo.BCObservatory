# #13721 [Expense Agent] Create per diem line when approving travel requests with Per Diem Included

> When approving travel requests with Per Diem Included, the system now automatically creates a per diem expense line for each traveler based on matching expense rules, with blocking validation if no appropriate rule is found.

[Pull request](https://github.com/microsoft/BCApps/pull/13721) · merged into `main` (BC30) on 2026-11-06 by claudiuciumedean · 11 files (+1179 -30), 7 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- Per diem lines are automatically created during travel request approval when Per Diem Included is enabled
- Category resolution matches rules by location and trip start date, selecting the first active category
- Approval fails with a clear error if no matching rule exists or the rule lacks a Daily Rate condition
- Per diem lines are exempted from merchant and receipt requirements, consistent with mileage handling
- Centralized validation logic in ExpenseRuleValidation.IsMerchantReceiptRequirementApplicable improves maintainability
- Behaviour changes for users or extensions.
