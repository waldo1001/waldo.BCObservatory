# #8183 Handle failure to manually create E-Document from posted doc with no …

> E-Document creation now correctly reports failure when a posted document cannot be converted to an e-document instead of incorrectly showing a success message.

[Pull request](https://github.com/microsoft/BCApps/pull/8183) · merged into `main` (BC30) on 2026-07-14 by georgepomazkov (community contribution) · 11 files (+89 -23), 11 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- The result of e-document creation is now propagated back through the call chain
- Users see 'The e-document could not be created.' when creation fails
- Fixes cases where no explicit error prevented the false success message
- Multiple page extensions updated to handle the creation result
- Resolves false positive feedback when document type is unsupported
- Behaviour changes for users or extensions.
