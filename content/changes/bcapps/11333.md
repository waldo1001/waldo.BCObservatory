# #11333 Align travel request APIs with employee travelers and expense report lifecycle

> Expense Agent APIs now align travel request and expense report workflows by adding employee filtering, creating expense reports during travel request approval, and supporting owner-scoped report recreation after draft deletion.

[Pull request](https://github.com/microsoft/BCApps/pull/11333) · merged into `main` (BC30) on 2026-09-17 by claudiuciumedean · 18 files (+1384 -40), 13 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Employees API gains filterable isExpenseUser field to distinguish expense-enabled employees
- Travel request approval automatically creates Expense Reports for the Requested For user and prevents duplicate creation
- Travel requests expose employees as a read-only navigation property filtered by SystemId
- Owner-scoped report recreation allowed after draft deletion if no existing posted history exists
- Added indirect permissions and nonunique lookup keys to support these operations
- Behaviour changes for users or extensions.
