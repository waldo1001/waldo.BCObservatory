# #10156 [Bug][SubscriptionBilling] Assign Subscription Lines dialog does not identify the sales line it was opened for

> The Assign Subscription Lines dialog now clearly identifies which sales line it is opened for by displaying the line number and description in its caption, and consolidates subscription package assignment logic to prevent duplicate dialogs when exploding bill-of-materials.

[Pull request](https://github.com/microsoft/BCApps/pull/10156) · merged into `main` (BC30) on 2026-09-28 by miljance (community contribution) · 4 files (+318 -0), 3 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- Dialog caption now shows sales line number and description instead of subscription package code
- Subscription package assignment logic consolidated from two separate paths to one post-insert subscriber
- Prevents duplicate dialogs when exploding BOM with multiple components
- New extension event OnAfterGetAssignSubscriptionLinesCaption allows customization
- Fixes a latent defect where lines were committed before their parent sales line was inserted
- Behaviour changes for users or extensions.
