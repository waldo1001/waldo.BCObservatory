# #11023 BE's PEPPOL "escompte" compensation

> Belgian PEPPOL invoices and credit memos keep the payment discount AllowanceCharge so VAT uses the discounted base. They add a compensating AllowanceCharge, an extra TaxSubtotal and ChargeTotalAmount so totals show the full amount as BE practice requires. Analogous changes were made in BaseApp and a test app was added.

[Pull request](https://github.com/microsoft/BCApps/pull/11023) · merged into `main` (BC30) on 2026-09-10 by mynjj · 13 files (+663 -32), 11 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- New PeppolBE codeunits for escompte, monetary info and payment info
- Discount AllowanceCharge kept; an additional compensating charge restores the displayed totals
- PEPPOL Tax Info Provider interface and PEPPOL30 xmlports extended to support the compensation
- Analogous changes in the deprecated BaseApp PEPPOL Management code
- Test app.json added for PeppolBE tests, which were expanded
- Behaviour changes for users or extensions.
