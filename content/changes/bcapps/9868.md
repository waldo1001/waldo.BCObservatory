# #9868 [MAIN]-Bug 644801-IRS Reporting Period - Copy Setup process will copy the 1099 Adjustments as part of the process of copying from one IRS Reporting Period to a new Period setup.

> The copy setup process for IRS Reporting Periods now correctly resets 1099 adjustment amounts to zero when copying from one period to another, preventing incorrect carryover of adjustment values.

[Pull request](https://github.com/microsoft/BCApps/pull/9868) · merged into `main` (BC30) on 2026-08-05 by v-praghav · 3 files (+69 -0), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Copy logic was duplicating full adjustment records instead of resetting amounts
- Amount field is now explicitly set to 0 before inserting records in the target period
- Automated test added to validate the copy behavior
- Fixes an issue where 1099 adjustment amounts were incorrectly carried over between periods
- Behaviour changes for users or extensions.
