# #9077 [Quality Management] Bug 620326: Reset IsChangingStatus on handled Reopen/Finish early-exit

> Quality Management's Reopen/Finish procedures now properly reset the IsChangingStatus flag when a subscriber handles the OnBefore events, preventing improper modifications to completed inspections.

[Pull request](https://github.com/microsoft/BCApps/pull/9077) · merged into `main` (BC30) on 2026-08-19 by alexei-dobriansky · 3 files (+130 -2), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- IsChangingStatus flag was stuck true when OnBefore event handlers set IsHandled=true
- This caused TestStatusOpen validation to be skipped on later modifications
- Flag is now reset before early exit when event is handled
- Adds manual subscriber test to verify the fix
- Prevents unwanted state changes to finished inspections
- Behaviour changes for users or extensions.
