# #14008 [MAIN] Fix customer GST application posting sequence (Bug 659070)

> Fixed a posting sequence error when applying GST advance payments against sales invoices with different customer posting groups by deferring GST journal posting until after customer application posting completes.

[Pull request](https://github.com/microsoft/BCApps/pull/14008) · merged into `main` (BC30) on 2026-11-19 by v-ajaztabrez · 2 files (+22 -7), 2 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Resolves 'G/L Entry already exists' error when applying GST advance payments with different customer posting groups
- Root cause was premature GST entry posting using separate posting instance during active customer application posting
- Solution defers offline customer GST posting until customer application posting finishes
- Uses shared Gen. Jnl.-Post Line instance from OnAfterPostApplyCustLedgEntry event
- Fixes both invoice posting and preview functionality
- Behaviour changes for users or extensions.
