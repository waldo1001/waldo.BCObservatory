# #7546 [Payables Agent] Agent-driven line matching

> Adds agent-driven line matching to the Payables Agent, allowing agents to resolve purchase lines by navigating BC pages instead of using the AL PrepareDraft pipeline when the PAAgentDrivenLineMatching feature flag is enabled.

[Pull request](https://github.com/microsoft/BCApps/pull/7546) · merged into `main` (BC30) on 2026-08-18 by dayland · 17 files (+1249 -6), 15 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- Feature flag PAAgentDrivenLineMatching gates all new behavior, leaving default behavior unchanged
- New historical line data loader retrieves up to 5000 posted purchase invoice lines prioritized by vendor and relevance
- Six new lookup actions added to draft purchase lines for Text-to-Account Mappings, Historical Lines, Chart of Accounts, Items, and Deferral Templates
- New agent-driven instructions prompt implements a collect-then-synthesize matching strategy across six data sources
- New page customizations provide read-only, locked-down views for agent navigation
- Behaviour changes for users or extensions.
