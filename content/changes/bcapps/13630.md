# #13630 [NL] Fix CBG applies-to ID length handling

> The NL CBG Statement Line now handles applies-to IDs consistently as Code[50] across all related declarations and APIs, fixing failures when longer valid IDs are processed during payment tolerance management.

[Pull request](https://github.com/microsoft/BCApps/pull/13630) · merged into `main` (BC30) on 2026-11-05 by JesperSchulz · 4 files (+222 -6), 2 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Aligns Code[20] declarations in Payment Tolerance Management and New Applies-to ID to the existing Code[50] field
- Enables the first bank ID to retain the full 20-character statement document number plus numeric suffix without truncation
- Adds five new tests covering 10-, 20-, 21-, and 50-character applies-to IDs, numeric carry, persistence, and payment tolerance workflows
- Updates existing 10,000-line counter test to use Code[50] receiving variable
- Preserves existing counter increment, suffix, cash-journal selection and payment tolerance logic
- Behaviour changes for users or extensions.
