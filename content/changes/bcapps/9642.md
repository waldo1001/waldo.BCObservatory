# #9642 [Bug]: E-Documents for Germany - FindEDocumentService always selects last matching service, ignoring which service triggered the export

> E-Document exports for Germany now use the service that triggered the export instead of always selecting the last matching service, ensuring correct settings like PDF embedding are applied.

[Pull request](https://github.com/microsoft/BCApps/pull/9642) · merged into `main` (BC30) on 2026-09-29 by miljance (community contribution) · 12 files (+847 -1), 9 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- XRechnung format passes the triggering service to Export XRechnung Document through SetEDocumentService
- ZUGFeRD uses a new ZUGFeRD Export Context codeunit to carry the service from format into report extensions
- FindEDocumentService and OnAfterFindEDocumentService are deprecated but kept working until CLEAN29 for backward compatibility
- Tests verify both the new path and legacy fallback work correctly
- Context codeunit is public so partners can use it in customized report extensions
- Behaviour changes for users or extensions.
