# #10020 [Master] - Bug 641894: [Expense Agent] [Rules] Mileage expense should not validate require receipt number rule

> Mileage expenses in Expense Agent no longer incorrectly trigger the receipt number mandatory validation rule, since mileage never has receipts.

## What changed

- Mileage expenses are now excluded from the require receipt number validation
- The fix applies to both initial expense and expense report line validation
- Validation logic now checks expense type before applying the rule
- Tests added to verify mileage expenses bypass receipt number checks
- Non-mileage expenses continue to enforce receipt number requirements when enabled
- Behaviour changes for users or extensions.
