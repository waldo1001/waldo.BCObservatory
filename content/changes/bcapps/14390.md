# #14390 [main] [E-Documents][PEPPOL] V1 import fails for UBL invoices using alternate cac/cbc namespace prefixes

> PEPPOL import for UBL invoices now handles alternate XML namespace prefixes correctly by matching elements through namespace URI instead of lexical prefix matching.

[Pull request](https://github.com/microsoft/BCApps/pull/14390) · merged into `main` (BC30) on 2026-11-25 by Shikhverma · 3 files (+324 -15), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Fixed V1 PEPPOL import failures when UBL elements use alternate namespace prefixes like cac1 and cbc1
- Changed namespace matching from lexical prefix-based to URI-aware namespace resolution
- Added URI awareness with multiple aliases and namespace-scope validation to codeunit 6166
- Added regression test coverage for complete V1 parsing including invoices, credit notes, attributes, attachments, lines, and document charges
- Behaviour changes for users or extensions.
