# #9121 [Subcontracting] Bug 641405: Production Order actions in ILE page not clickable for transfer lines

> Production Order, Routing and Components actions on the Item Ledger Entries page are now enabled for subcontracting transfer-type entries. When the base Order fields do not point to a production order, the production order is read from the Subc. Prod. Order fields.

## What changed

- Actions are now enabled when Subc. Prod. Order No. is set, not just when base Order No. is a production order
- SetProdOrderInformationByVariant resolves production order from Subc. Prod. Order fields as a fallback
- Fixes greyed-out actions for transfer-type subcontracting Item Ledger Entries
- Test coverage added for the fix
