# #9208 [Enforced Digital Vouchers] - Attaching EDocuments when using Digital Vouchers

> Digital Vouchers now automatically attach generated E-Documents to posted sales and purchase documents when configured to do so. The Digital Voucher Entry Setup table adds an E-Document check type option that streamlines compliance document management and reduces manual attachment effort.

[Pull request](https://github.com/microsoft/BCApps/pull/9208) · merged into `main` (BC30) on 2026-08-11 by jzaksauskas (community contribution) · 13 files (+730 -10), 9 AL · feature · tier official · **unreviewed** (machine-generated)

## What changed

- New E-Document check type added to Digital Voucher Entry Setup for automating E-Document attachment
- Automatic attachment of E-Document files to Incoming Document Files when posting sales or purchase documents
- E-Document check type only available when Generate Automatically is enabled
- E-Document option restricted to Sales Document or Purchase Document entry types
- Enhanced automation reduces manual effort and ensures consistent document linking
- Behaviour changes for users or extensions.
