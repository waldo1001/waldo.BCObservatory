# #14492 [Main] Expense Agent: register the Copilot capability as generally available

> The Expense Agent Copilot capability is now registered as Generally Available instead of Preview, applying the same pattern used by the Sales Order and Payables agents.

[Pull request](https://github.com/microsoft/BCApps/pull/14492) · merged into `main` (BC30) on 2026-11-25 by t-prda · 2 files (+11 -9), 2 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Install process now registers the capability as Generally Available from the start
- If already registered as Preview, the capability is modified to Generally Available status
- Upgrade process automatically moves existing tenants from Preview to GA status
- Deactivated capabilities are re-activated once during the upgrade to GA
- Pattern matches the existing implementation for Sales Order and Payables agents
- Behaviour changes for users or extensions.
