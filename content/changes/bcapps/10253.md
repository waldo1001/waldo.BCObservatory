# #10253 Avoid starting a write transaction under `ShowCanCreateAgent`

> Payables Agent Setup no longer starts a write transaction when computing ShowCanCreateAgent. This avoids problems when third-party code commits, asks for confirmation and then opens a page, while a separate platform bug remains open.

- Interim fix while platform bug 646707 is handled separately
