# #12561 [Shopify] Preserve tax match after rate conflict

> Shopify order processing now preserves tax mappings and holds document creation when a tax rate conflict occurs, rather than rolling back changes on error, allowing merchants to review and resolve the conflict.

[Pull request](https://github.com/microsoft/BCApps/pull/12561) · merged into `main` (BC30) on 2026-10-20 by onbuyuka · 6 files (+165 -18), 5 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Tax rate conflicts are treated as intentional processing holds instead of exceptions
- Successful tax area and jurisdiction mappings persist when conflicts occur
- Orders remain unprocessed without creating a Sales Document, keeping the Review Tax Match recovery action available
- The internal OnBeforeCreateSalesHeader event can now return an intentional hold message
- Behavior applies consistently to both manual and automatic order processing
- Behaviour changes for users or extensions.
