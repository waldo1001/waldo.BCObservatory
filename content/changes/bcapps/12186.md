# #12186 Set several fields in one ModifyAll call

> Consecutive ModifyAll calls on the same filtered record are merged into a single call that sets several fields, cutting SQL round trips. Where RunTrigger was passed, OnModify now runs once per row with all fields already set instead of once per field.

[Pull request](https://github.com/microsoft/BCApps/pull/12186) · merged into `main` (BC30) on 2026-10-19 by jehelles · 309 files (+430 -942), 131 AL · performance · tier official · reviewed (checked by Opus)

## What changed

- Back-to-back ModifyAll calls on the same record are merged into one call
- Field and value expressions are unchanged and keep their order
- With RunTrigger, OnModify runs once per row instead of once per field; three such cases are outside test code
- One run is left unmerged because its calls disagreed on RunTrigger
- Touches about 300 files across W1 apps, localization layers and demo data
- Behaviour changes for users or extensions.
