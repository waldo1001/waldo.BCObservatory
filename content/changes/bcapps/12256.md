# #12256 [Payables Agent] Exclude agent accounts from eligible users

> Automatic user selection in Payables Agent Setup now skips users with the Agent license type. Before this, saving the setup or activating the agent could fail when an agent account had created a posted purchase invoice in the last 30 days, because the platform rejects an agent configuring another agent.

- Preserves existing non-agent user eligibility criteria
