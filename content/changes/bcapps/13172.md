# #13172 Export structured AI eval run data

> AI Eval run data can now be exported in a structured form from the AI Test Toolkit command-line page, with optional authorized Agent Task details. Agent Task gains public GetTaskLogEntryDetails overloads, and the old record-based GetLogEntryDetails public method is removed.

[Pull request](https://github.com/microsoft/BCApps/pull/13172) · merged into `main` (BC30) on 2026-11-03 by nikolakukrika · 17 files (+1009 -58), 8 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- The AI Eval command-line page streams results.json, the evaluation result files and then the Agent Task detail files, keeping the suite/version/dataset hierarchy
- New public Agent Task methods: GetTaskLogEntryDetails(AgentTaskID) returns the full task export and GetTaskLogEntryDetails(AgentTaskID, StepNumber) returns a single log entry
- The AI Test Toolkit now uses the public API, and its internalsVisibleTo grants and the unused stream/BLOB adapter are removed
- The old record-based GetLogEntryDetails public method is removed
- Multiline messages and call stacks are now read to the end of the stream, with separators only between lines
- Breaking: existing extensions can stop compiling or working.
