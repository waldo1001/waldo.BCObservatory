# #8999 Migrate Recommended Apps & Connectivity Apps to Official Marketplace Catalog API

> Recommended Apps and Connectivity Apps now use the official Marketplace Catalog API with Azure Key Vault integration instead of the deprecated undocumented endpoint that was blocked by WAF.

## What changed

- Migrated from blocked undocumented endpoint to official catalogapi.azure.com API
- Integrated Azure Key Vault for secure API key management using SecretText
- Updated JSON response parsing to read largeIconUri from top-level response
- Removed User-Agent spoofing no longer needed with official API
- Updated test assertions for new API error response format
- Behaviour changes for users or extensions.
