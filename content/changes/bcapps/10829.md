# #10829 [29.x][Expense Agent] Backport approval conversation from #10570

> The Expense Agent now supports approval conversations, allowing submitters to add comments when resubmitting reports and exposing the latest approver and submitter comments through the API and report page.

## What changed

- Submitters can add comments when resubmitting expense reports
- Latest approver and submitter comments are exposed via the API and Expense Report page
- Comment snapshots are recorded in activity history as immutable records
- New approvalConversation capability is advertised
- The releaseAndMarkPendingApprovalExpenseReport action is marked obsolete
- Behaviour changes for users or extensions.
