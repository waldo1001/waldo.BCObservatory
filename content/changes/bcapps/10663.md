# #10663 [Main]-Stock card report shows incorrect received quantity

> Stock Card report now correctly shows received quantities and costs when purchase receipts are split into multiple partial invoices, fixing understated balances that cascaded through the report.

[Pull request](https://github.com/microsoft/BCApps/pull/10663) · merged into `main` (BC30) on 2026-08-31 by DhavalMore88 (community contribution) · 2 files (+147 -8), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Report used FindFirst() to read Value Entries, retrieving only the earliest entry when multiple partial invoices existed against one Item Ledger Entry
- Replaced FindFirst() with CalcSums() to aggregate all Value Entries for each Item Ledger Entry regardless of partial invoice count
- Added ValueEntry.Reset() to prevent filter leakage between records
- Received quantity, amount, and cost columns now reflect complete partial invoice totals
- Running balance calculations throughout the report are now accurate
- Behaviour changes for users or extensions.
