# #14009 [MAIN] Avoid empty GST component lookup on customer reapplication (Bug 659069)

> Fixed a bug where reapplying customer payments after unapplication would fail with an empty GST component lookup error by skipping GST account resolution when no GST entries are involved.

[Pull request](https://github.com/microsoft/BCApps/pull/14009) · merged into `main` (BC30) on 2026-11-19 by v-ajaztabrez · 1 file (+3 -0), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Reapplying customer payments against invoices after unapplication now works without errors
- GST application routine exits early when the GST posting buffer is empty
- Prevents blank GST component code from triggering a failed lookup
- Avoids unnecessary account resolution and posting when no GST entries exist
- Behaviour changes for users or extensions.
