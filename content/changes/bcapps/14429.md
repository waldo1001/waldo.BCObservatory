# #14429 [29.x]-Purchase Credit Memo – "Get Return Shipment Lines" fails for Non-Inventory items with "corrective credit memo can only reverse the original posted invoice" error (regression from Bug 636861)

> Using 'Get Return Shipment Lines' on a purchase credit memo no longer fails for non-inventory items with the error that a corrective credit memo can only reverse the original posted invoice. This fixes a regression introduced by Bug 636861.

## What changed

- 'Get Return Shipment Lines' on purchase credit memos works again for non-inventory items
- Removes the wrongly raised 'corrective credit memo can only reverse the original posted invoice' error
- Fixes a regression introduced by the fix for Bug 636861
- The Purchase Line table is changed in W1 and all country layers
- Tests added to O365 Correct Purchase Invoice in several layers
- Behaviour changes for users or extensions.
