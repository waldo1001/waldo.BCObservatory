# #10129 [Extensibility Request] issue 30342: allow skipping blocked item checks

> ServContractManagement gets two separate IsHandled events so extensions can skip the blocked service item check or the blocked item and variant check. This lets them keep invoicing contracts whose references were later blocked or deleted.

## What changed

- IsHandled event added before the service item check in CheckServiceItemBlockedForAll
- Separate IsHandled event added before the item and variant check in CheckItemServiceBlocked
- Each check can be skipped independently by subscribers
- Default behavior is unchanged; checks still stop invoicing unless handled
