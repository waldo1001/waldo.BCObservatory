# #10129 [Extensibility Request] issue 30342: allow skipping blocked item checks

> Service contract invoicing now allows extensions to skip blocked item and service item validation checks independently, enabling contracts to be invoiced when appropriate despite blocked or deleted references.

- Added IsHandled event to CheckServiceItemBlockedForAll for skipping service item validation
- Added IsHandled event to CheckItemServiceBlocked for skipping item and variant validation
- Enables extensions to bypass blocked-item checks independently
- Allows active contracts to continue invoicing when business logic permits
- Service contract invoicing no longer stops due to blocked referenced items
