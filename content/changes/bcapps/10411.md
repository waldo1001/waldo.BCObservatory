# #10411 [SOA] Allow changing or clearing manually selected contacts

> Users can now select, change, or clear manually chosen contacts in the Sales Order Agent through a dedicated lookup interface and assist-edit, with changes isolated to one-time overrides that don't modify underlying contact fields.

[Pull request](https://github.com/microsoft/BCApps/pull/10411) · merged into `main` (BC30) on 2026-08-20 by tomasevicst · 5 files (+238 -41), 5 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- New contact lookup page allows matching both E-Mail and E-Mail 2 fields without standard restrictions
- Users can change a previously selected one-time contact or clear the mapping to return to email-based matching
- Changes are isolated to task-message overrides; existing contact email fields remain unmodified
- Authorization checks continue to restrict mapping changes to configured owner or agent
- Backward compatible - existing contact matching unchanged until user explicitly selects a contact
- Behaviour changes for users or extensions.
