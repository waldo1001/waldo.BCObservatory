# #12213 [Financial Reports] Add row and column definition preview

> Financial report row and column definitions now include preview capability. Users can set a counterpart definition on each report definition and quickly preview how the row or column layout renders.

[Pull request](https://github.com/microsoft/BCApps/pull/12213) · merged into `main` (BC30) on 2026-10-05 by dcenic · 14 files (+919 -0), 11 AL · feature · tier official · **unreviewed** (machine-generated)

## What changed

- Added per-definition fields to store the preview counterpart (Column Definition on Account Schedule, Row Definition on Column Layout)
- Preview action opens a temporary, view-only financial report using the current definition paired with the preview counterpart
- Error messaging guides users to set the required preview counterpart field when attempting preview without one
- Expanded automated tests verify preview functionality across row and column definitions
- No company-wide defaults added to General Ledger Setup per architectural consistency
- Behaviour changes for users or extensions.
