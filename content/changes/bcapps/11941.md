# #11941 Bug 651577 CompAuxNum and CompAuxLib columns should be informed for Payment Discount lines on Unapplied Entries in the French Audit File.

> The FEC audit file export now populates CompAuxNum and CompAuxLib columns for payment discount lines on unapplied entries by using G/L entry source type and number as a fallback when customer/vendor ledger entries are unavailable.

[Pull request](https://github.com/microsoft/BCApps/pull/11941) · merged into `main` (BC30) on 2026-10-01 by v-praghav · 2 files (+153 -23), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Unapplication creates G/L entries without corresponding customer/vendor ledger entries, causing missing auxiliary account information
- Added fallback logic using G/L entry source type and source number to identify the party for receivables/payables accounts
- Improved FEC export completeness for unapplied payment scenarios
- Added automated tests for both customer and vendor unapplication cases
- Behaviour changes for users or extensions.
