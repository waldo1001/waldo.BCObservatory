# #12947 [MCP] Provide environment and company descriptions to the platform

> Environment Information Impl. and Company Information Mgt. now subscribe to two new platform events, GetEnvironmentDescription and GetCompanyDescription, to supply the environment and company descriptions. The MCP server's list_companies tool can then return company descriptions. This requires the platform change that adds the events.

[Pull request](https://github.com/microsoft/BCApps/pull/12947) · merged into `main` (BC30) on 2026-11-12 by onbuyuka · 10 files (+584 -0), 4 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Subscribes to the platform events GetEnvironmentDescription and GetCompanyDescription on System Action Triggers; the events come from a separate platform change
- Environment Information Impl. returns the environment description
- Company Information Mgt. (W1, NA, ES) reads the requested company's description using ChangeCompany, so the session's company stays the same
- An empty description is returned when the company is missing, not accessible or has no Company Information record
- The MCP list_companies tool uses the company description so agents can tell companies apart
- Behaviour changes for users or extensions.
