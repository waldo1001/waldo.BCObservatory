# #8875 [master] SOA: Bugbash for releases 28.x - Select an existing contact, or create a new one - Use another contact always

> Fixed an error when selecting an existing contact in the Sales Order Agent by adding a commit before opening the contact selection dialog, preventing a write transaction conflict.

[Pull request](https://github.com/microsoft/BCApps/pull/8875) · merged into `main` (BC30) on 2026-07-08 by tomasevicst · 1 file (+1 -0), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- The 'Use another contact always' option failed with a form.RunModal write transaction error
- Root cause was an active write transaction when ContactList.RunModal() was called
- Solution adds Commit() before ContactList.RunModal() in SelectContactAndUpdateEmail, matching the pattern used in CreateContact
- The commit is safe because there are no pending writes at this point
- Resolves the conflict between the modal dialog and the Contact table's locking chain
- Behaviour changes for users or extensions.
