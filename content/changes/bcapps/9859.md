[Pull request](https://github.com/microsoft/BCApps/pull/9859) · merged into `main` (BC30) on 2026-08-04 by v-rohangarg20 (community contribution) · 564 files (+116408 -1791), 337 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- Adds expense management module with AI agent capabilities for automating expense workflows and approvals
- Provides 50+ API pages for expense data access and management including reports, itemizations, and participants
- Introduces role-based permission sets for agents and admins alongside core business entity tables
- Includes localized event subscribers for multiple regions (AT, AU, CA, DE, DK, ES, FR, GB, NZ, US)
- Supports agent consumption tracking, KPI monitoring, and email-based task scheduling features
- Behaviour changes for users or extensions.
