# #10489 MSlenejennum/647452/new header and footer layouts and report themes

> New composite report parts management codeunit seeds 11 header/footer designs and 3 themes into the shared Tenant Report Defaults pool on install and upgrade, overwriting tenant edits to shipped content.

[Pull request](https://github.com/microsoft/BCApps/pull/10489) · merged into `main` (BC30) on 2026-09-07 by MSlenejennum · 22 files (+869 -0), 7 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Introduces codeunit 9667 'Composite Report Parts Mgt.' to manage predefined report layout parts
- Adds 14 docx and dotx resources for header/footer designs and report themes
- Seeding process runs on every upgrade to ensure shipped parts always reflect app content
- Unshipped parts are removed and their assignments cleared automatically
- Resource read failures are logged to telemetry without aborting install or upgrade
- Behaviour changes for users or extensions.
