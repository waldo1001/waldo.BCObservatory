# #10072 [main] - Serial and Lot number mismatch when item is produced via Production Order and moved to inventory through an Internal Put-away

> Registering a warehouse put-away now checks each line that has a Serial No. against the open Item Ledger Entry for that item, variant, location and serial number. If that entry has a Lot No., the line's Lot No. must match it, so a blank or wrong lot can no longer be registered, for example after an internal put-away of produced items.

## What changed

- New CheckItemTrackingRequiredForPutAway check added to CheckLines in Whse.-Activity-Register
- The check uses the posted Item Ledger Entry instead of item tracking configuration flags
- For put-away lines with a Serial No., the open ledger entry is found by Item, Variant, Location and Serial No.
- If that entry has a Lot No., the put-away line's Lot No. must match it
- Fixes blank lots getting through when a production output is put away with an internal put-away; a test is added
- Behaviour changes for users or extensions.
