# #10072 [main] - Serial and Lot number mismatch when item is produced via Production Order and moved to inventory through an Internal Put-away

> A data-driven validation check was added to the warehouse activity registration to ensure that lot numbers match the posted item ledger entries when internal put-aways process items from production orders.

[Pull request](https://github.com/microsoft/BCApps/pull/10072) · merged into `main` (BC30) on 2026-08-11 by MSNehaNawal · 2 files (+86 -0), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Warehouse activity registration now validates lot and serial number tracking before registration completes
- The fix compares put-away lines against actual posted Item Ledger Entries instead of relying only on configuration flags
- For put-away lines with serial numbers, the system resolves the corresponding open item ledger entry and verifies lot number consistency
- Prevents lot number mismatches when items move from production orders to inventory via internal put-aways
- Adds enforcement of lot requirements at registration time rather than skipping validation
- Behaviour changes for users or extensions.
