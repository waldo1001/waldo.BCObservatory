# #9426 [E-Document Formats] Migrate NAV PRs 247170 and 247176 into BCApps

> PINT A-NZ and Factura-E e-document formats are migrated to the structured import pipeline with new IStructuredFormatReader implementations that parse XML directly into purchase draft staging tables.

[Pull request](https://github.com/microsoft/BCApps/pull/9426) · merged into `main` (BC30) on 2026-07-23 by Groenbech96 · 16 files (+1902 -3), 2 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- New EDocumentPINTANZHandler and EDocumentFacturaEHandler codeunits implement IStructuredFormatReader.ReadIntoDraft to parse UBL invoice/credit-memo and Factura-E 3.2.2 XML formats
- E-Document PEPPOL Utility codeunit provides shared reusable logic for extracting PEPPOL BIS 3.0 UBL data (namespaces, parties, amounts, lines, attachments, currency)
- SetBuffer method on E-Doc. Readable Purchase Doc. page promoted from internal to public to allow format readers to present extracted data without persisting drafts
- Enum extensions register new handlers on E-Doc. Read into Draft enumeration for both formats
- Comprehensive structured integration tests added covering content extraction, purchase invoice creation with auto-matched item references, and draft line updates
- Breaking: existing extensions can stop compiling or working.
