# #11722 [Shopify] Rename tax matching and add configurable processing limit

> Customer-facing references to Shopify Tax Matching Agent now read Shopify Tax Matching, and AL object names stay unchanged. A new fail-closed, per-company rolling order limit is configured through the ShopifyTaxMatchingProcessingLimit Azure Key Vault value, and new telemetry covers configuration problems and limit exhaustion.

[Pull request](https://github.com/microsoft/BCApps/pull/11722) · merged into `main` (BC30) on 2026-09-29 by onbuyuka · 27 files (+478 -93), 19 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Renamed customer-facing references from 'Shopify Tax Matching Agent' to 'Shopify Tax Matching' while keeping internal AL object names unchanged
- Implemented a fail-closed, per-company rolling order limit configurable via Azure Key Vault setting ShopifyTaxMatchingProcessingLimit
- Extended operational telemetry to track configuration issues, limit exhaustion, request volume, and matching results
- Added deterministic AL tests covering configuration parsing, fail-closed behavior, limit enforcement, and rolling-period expiry
- Updated Learn More action to point to the Microsoft Learn article for the feature
- Behaviour changes for users or extensions.
