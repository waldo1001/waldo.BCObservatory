# #9391 [Master] - Slice 616928: [Expense Management] [App part] Expense Managements Travel Requisitions 💸

> Expense Management adds travel requisition support: new API pages for spend requests, spend request details and travelers, a Traveler table and page, and extensions of the spend request card and list. Base Application gains a Release Spend Request codeunit and a G/L link preview page, and the SpendRequestType enum is removed.

## What changed

- New API pages for Spend Requests, Spend Request Details and Travelers
- New Traveler table and Travelers page in the Expense Agent app
- Spend Request table, card and list extended by Expense Management
- New Release Spend Request codeunit and Spend Req. To G/L Link Preview page in Base Application
- SpendRequestType enum removed; reversal and posting preview codeunits updated across localizations
- Breaking: existing extensions can stop compiling or working.
