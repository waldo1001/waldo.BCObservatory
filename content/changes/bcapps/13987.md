# #13987 [Main][All-e]"Specify the VAT registration number that you want to verify" error when entering a VAT Registration No. in the Sales Order if the Customer Card has no VAT Registration No

> Fixed a VAT registration number validation error in Sales Orders where the system incorrectly validated the customer's stored VAT number instead of the number entered on the document when the customer card had no VAT number and the VIES validation service was enabled.

[Pull request](https://github.com/microsoft/BCApps/pull/13987) · merged into `main` (BC30) on 2026-11-17 by sanjmaurya · 19 files (+524 -35), 15 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Sales Header VAT Registration No. field now passes a copy of the customer record with the entered number instead of the actual customer record for VIES validation
- Preserves the existing behavior of only filling a blank customer VAT number, preventing unintended overwrites
- Added comprehensive test cases to verify the validation checks the entered number when the customer has no VAT number
- Fix applied across all localization layers (W1, NA, GB, FR, ES, IT, etc.)
- Resolves error 'Specify the VAT registration number that you want to verify' when entering valid VAT numbers on sales documents
- Behaviour changes for users or extensions.
