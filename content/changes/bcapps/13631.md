# #13631 [main] bug 646068 - Add support for disabling incremental exchange gain/loss posting in General Ledger Setup

> Czech localization now allows disabling incremental exchange gain/loss posting in General Ledger Setup, letting companies choose between incremental posting and standard W1 exchange gain/loss calculations.

[Pull request](https://github.com/microsoft/BCApps/pull/13631) · merged into `main` (BC30) on 2026-11-18 by DavidHolusa · 5 files (+304 -6), 4 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- New setting on Currency FastTab of General Ledger Setup to toggle between incremental and W1-style exchange gain/loss posting
- Defaults to disabled, preserving existing Czech incremental posting behavior without requiring data migration
- When enabled, allows reversal of previously posted unrealized exchange gains and losses per W1 approach
- Extended General Ledger Setup table, page, and permissions for Czech localization
- Test coverage added for foreign currency scenarios
- Behaviour changes for users or extensions.
