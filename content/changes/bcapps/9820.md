# #9820 Use ReadCommitted isolation for CalcFields in Job Queue Entry GetXmlContent

> Job Queue Entry GetXmlContent method now uses ReadCommitted isolation when reading the XML parameter BLOB to prevent unnecessary locking and blocking in concurrent scenarios.

[Pull request](https://github.com/microsoft/BCApps/pull/9820) · merged into `main` (BC30) on 2026-07-30 by darjoo · 1 file (+1 -0), 1 AL · performance · tier official · reviewed (checked by Opus)

## What changed

- Adds explicit ReadIsolation(IsolationLevel::ReadCommitted) to CalcFields(XML) call in GetXmlContent
- Prevents locking on job queue entry records during XML parameter reads
- Removes implicit isolation escalation when caller is in an updating transaction
- No signature or behavior changes to the procedure or related events
- Low risk change with same effective isolation as default read behavior
