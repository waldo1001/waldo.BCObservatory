## What changed

- Added 'Released' and 'Released & Print' options to the planning worksheet's carry out action message enum
- Users can now create released production orders directly instead of creating firm planned orders and manually changing status
- Forward flushing for released orders is preserved during creation
- New integration event added while maintaining backward compatibility with existing event signatures
- Comprehensive test coverage added for the new functionality including forward-flushing validation
- Behaviour changes for users or extensions.
