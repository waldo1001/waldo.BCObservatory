# #9905 [Bug][SubscriptionBilling] Contract lines of type G/L Account never post to the selected G/L account

> Contract lines of type G/L Account now post to the G/L account specified on the line instead of the default account from General Posting Setup, both for immediate posting and deferral release scenarios.

[Pull request](https://github.com/microsoft/BCApps/pull/9905) · merged into `main` (BC30) on 2026-09-04 by miljance (community contribution) · 10 files (+308 -31), 7 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- G/L Account contract lines bypass the General Posting Setup account lookup and post to the line's selected account
- A new G/L Account No. field on deferral tables stores the account reference from sales/purchase lines
- Deferral release logic posts to the stored account, with fallback to General Posting Setup when not specified
- Added comprehensive tests for both immediate-posting and deferral-release paths
- Schema change is additive only; no breaking changes or upgrade code needed
- Behaviour changes for users or extensions.
