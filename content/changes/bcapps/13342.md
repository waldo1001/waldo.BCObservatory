# #13342 [Main] Incorrect Buyer/Seller Registration No. Written to Detailed GST Ledger Entry When Posting Purchase Invoice Without Order Address

> Fixed incorrect registration numbers appearing in GST ledger entries when purchase invoices are posted without order addresses by resetting cached values between postings.

[Pull request](https://github.com/microsoft/BCApps/pull/13342) · merged into `main` (BC30) on 2026-10-29 by v-ajaztabrez · 1 file (+5 -0), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Detailed GST Ledger Entries showed previous invoice's registration number when subsequent invoice had no Order Address
- Root cause was single-instance codeunit retaining values between postings in the same session
- Solution resets cached Pay-to Vendor No., Buyer/Seller Registration No., and State Code before each document posting
- Affects Indian GST purchase posting workflow
- Behaviour changes for users or extensions.
