# #9700 Rename TempCustomMigrationTableBuffer back to CustomMigrationTableBuffer

> A variable name in custom migration mapping is restored from TempCustomMigrationTableBuffer to CustomMigrationTableBuffer to prevent misleading naming and rule violations.

[Pull request](https://github.com/microsoft/BCApps/pull/9700) · merged into `main` (BC30) on 2026-07-27 by gggdttt · 1 file (+3 -3), 1 AL · refactor · tier official · reviewed (checked by Opus)

## What changed

- Variable in the Add Custom Migration Mapping page renamed back to CustomMigrationTableBuffer
- The variable is only a handle for calling SaveMigrationTableMapping, not a data buffer
- Removes the Temp prefix that violated AA0237 on a non-temporary variable, an error in the NAV build
- Restores the pre-#9200 name, consistent with the NAV 28.x backport and PR #9663
- Naming-only change with no behavior impact
