# #10255 Add expense activity history foundation

> Expense activity history foundation adds tracking of lifecycle events for expense reports with an append-only activity log table, read-only APIs scoped by report and user role, factbox UI components, and comprehensive test coverage.

[Pull request](https://github.com/microsoft/BCApps/pull/10255) · merged into `main` (BC30) on 2026-08-17 by t-prda · 33 files (+2546 -37), 24 AL · feature · tier official · **unreviewed** (machine-generated)

## What changed

- New append-only activity log table records expense report lifecycle events (Created, Submitted, Approved, Rejected, Posted, etc.)
- Activity log captures actor, role, comments, financial snapshots, categories, and receipt counts for each event
- Read-only APIs expose activity history filtered by report scope or limited to Expense User role with actor role requirements
- Factbox components display activity history in active/posted reports and manager views
- ActivityLog capability registered with comprehensive unit, API, and posting tests
- Behaviour changes for users or extensions.
