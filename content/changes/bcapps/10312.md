# #10312 Update expense VAT specification source

> Expense Agent now sets the Source of VAT specification records to Agent when created through the API and Manual when created in the UI, blocks changes and deletions of agent-created records, and gives more specific errors when posting expense reports with pending VAT reclaim status.

[Pull request](https://github.com/microsoft/BCApps/pull/10312) · merged into `main` (BC30) on 2026-08-31 by Alexander-Ya · 26 files (+2192 -217), 18 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Source is set to Agent for API-created VAT specifications and Manual for UI-created ones; the Source field is now non-editable
- Agent-created VAT specification records cannot be modified or deleted, and UpdateVATSpecification no longer overwrites them
- Certain validations and category/subcategory handling apply only to manual entries
- Posting errors for pending VAT reclaim status are more specific and offer navigation actions
- Adds an upgrade codeunit and expanded test coverage
- Behaviour changes for users or extensions.
