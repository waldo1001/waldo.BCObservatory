# #12194 Harden web request helpers: opt-in default credentials

> Http Web Request Mgt. and SOAP Web Service Request Mgt. now disable default credentials by default and require callers to opt in with SetUseDefaultCredentials(true) for on-premises installations, preventing unintended transmission of Business Central service account credentials to external hosts.

[Pull request](https://github.com/microsoft/BCApps/pull/12194) · merged into `main` (BC30) on 2026-10-02 by darjoo · 6 files (+51 -5), 3 AL · breaking · tier official · reviewed (checked by Opus)

## What changed

- Http Web Request Mgt. and SOAP Web Service Request Mgt. no longer use default credentials unless the caller opts in
- New OnPrem SetUseDefaultCredentials(Boolean) lets callers turn default credentials back on
- Fault-response trace logging in Http Web Request Mgt. is now off by default; use SetTraceLogEnabled(true)
- Extension Marketplace never sends default credentials for its AppSource telemetry callback
- Library - Graph Mgt test library opts in because API tests call the local BC server
- Breaking: existing extensions can stop compiling or working.
