# #9663 Migrate customer, vendor and item transactions for BC14 cloud migration

> Extends BC14 cloud migration to stage customer, vendor, and item subledger transactions alongside G/L entries, enabling migration of open receivables, payables, and inventory for both current and historical data.

[Pull request](https://github.com/microsoft/BCApps/pull/9663) · merged into `main` (BC30) on 2026-08-04 by gggdttt · 33 files (+4145 -6), 29 AL · feature · tier official · **unreviewed** (machine-generated)

## What changed

- Adds buffer tables for customer, vendor, and item ledger entries with detailed posting setup
- Implements current migrators that post open entries through general and item journals to cloud company
- Provides historical migrators to copy archived source entries into HybridBC14HistoricalData app for reference
- Each migrator is gated by module flags to run only when relevant modules are selected
- Includes comprehensive test coverage for all current and historical migrators
- Behaviour changes for users or extensions.
