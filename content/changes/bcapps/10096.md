# #10096 Fix Close Income Statement grouping when no dimensions are selected

> Fixed the Close Income Statement report to properly group G/L entries by account, business unit, and source currency when no dimensions are selected, and ensured closing lines retain source currency codes even when amounts net to zero.

[Pull request](https://github.com/microsoft/BCApps/pull/10096) · merged into `main` (BC30) on 2026-08-17 by ventselartur · 8 files (+1179 -36), 3 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- Entry grouping now works correctly regardless of dimension selection by keying the buffer on business unit, dimension combination, and source currency
- Added dimension buffer ID mapping to handle cases where dimension combinations are reused across source currencies
- Source currency codes are preserved on closing lines even when the source currency amount nets to zero
- Entry grouping state is properly cleared between account batches using the new ResetEntryNoGrouping method
- Added comprehensive tests covering both scenarios with and without Additional Reporting Currency
- Behaviour changes for users or extensions.
