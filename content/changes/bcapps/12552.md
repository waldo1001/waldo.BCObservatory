# #12552 [29.x]-Validation of the "No." field on the sales order additionally re-validates the Unit of Measure Code

> Fixed a bug where validating the "No." field on a sales order with a linked released production order caused repeated production order status warnings and potential modal dialog errors in write transactions.

[Pull request](https://github.com/microsoft/BCApps/pull/12552) · merged into `releases/29.x` (BC29) on 2026-10-19 by DhavalMore88 (community contribution) · 14 files (+520 -24), 13 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Validate("Unit of Measure Code") inside ValidateUnitOfMeasureCodeFromNo is now wrapped with StatusCheckSuspended to stop nested status checks
- Quantity and Shipment Date validations check StatusCheckSuspended before calling CheckReceiptOrderStatus
- Check Prod. Order Status also respects the suspended flag, so the warning shows only once when "No." validation starts
- Prevents the 'Form.RunModal is not allowed in write transactions' error
- Sales Line changed in the W1 layer and several country layers, with new tests in SCM Planning and Manufacturing
- Behaviour changes for users or extensions.
