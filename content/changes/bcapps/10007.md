# #10007 [SOA] Ignore item availability when disabled

> The Sales Order Agent now ignores item availability signals when availability checking is disabled in settings, while still requesting assistance when no item is found.

[Pull request](https://github.com/microsoft/BCApps/pull/10007) · merged into `main` (BC30) on 2026-08-10 by qasimikram · 3 files (+25 -8), 2 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- Adds prompt instruction to skip availability checks when feature is disabled
- Excludes availability and capable-to-promise instructions from generated prompts when disabled
- Hides and neutralizes availability values on the item search page for agent sessions when setting is off
- Failed item searches still escalate to request assistance regardless of availability setting
- Behaviour changes for users or extensions.
