# #9371 Bug 642180: DE report 11015 Export Business Data fails when scheduled via Job Queue: Client callbacks are not supported

> Report 11015 Export Business Data now stores generated ZIP files in the Report Inbox when scheduled via Job Queue instead of attempting a client callback that fails in background sessions.

[Pull request](https://github.com/microsoft/BCApps/pull/9371) · merged into `main` (BC30) on 2026-07-14 by AleksanderGladkov · 1 file (+23 -0), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Scheduled Job Queue runs failed because the report pushed the ZIP to the client, which background sessions cannot do
- In background sessions with no GUI, the ZIP is now stored in the Report Inbox
- Users download scheduled exports from the Report Inbox
- Running the report interactively still downloads the ZIP directly
- Matches how scheduled layout reports already behave
- Behaviour changes for users or extensions.
