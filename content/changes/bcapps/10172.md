# #10172 [Extensibility Request] issue 30111: add purchase prepayment update events

> Three integration events are added to the purchase prepayment line update procedure, allowing extensions to adjust line selection, handle missing-lines errors, and modify custom fields before each line update.

## What changed

- Event fired after filters are set on prepayment lines
- Event fired before the standard no-lines-found error is raised
- Event fired before each line modification occurs
- Extensions can override standard behavior when subscribing
- Changes applied across all regional layers (W1, NA, APAC, ES, IT, NL)
