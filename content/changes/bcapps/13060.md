# #13060 [Extensibility Request][Subscription Billing] Extension points for a partner billing extension: Billing Proposal visibility, purchase-side event parity, usage-based billing period, document line creation

> Subscription Billing adds extension points including public methods, purchase-side events for parity with sales, usage-based billing events, and document line creation events to enable partner extensions without maintaining private code copies.

[Pull request](https://github.com/microsoft/BCApps/pull/13060) · merged into `main` (BC30) on 2026-11-13 by miljance (community contribution) · 5 files (+374 -15), 3 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Makes four Billing Proposal procedures public so partners can call them instead of keeping private copies
- Adds an event after the usage-based subscription billing period is calculated
- Adds purchase-side events for contract description lines and purchase header creation, matching the sales side
- Adds IsHandled events before sales and purchase line creation from billing lines
- Makes Usage Data Billing SaveDocumentValues public so handlers can keep usage billing links consistent
