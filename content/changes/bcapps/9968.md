# #9968 [BC-IN] TDS Amount Not Calculated on Initial TDS Section Selection in Bank Payment Voucher

> TDS/GST/TCS taxes are now calculated on first entry of tax fields in Indian journal and voucher pages. The fix restores record saving before tax calculation and adds an event for advanced customization.

[Pull request](https://github.com/microsoft/BCApps/pull/9968) · merged into `main` (BC30) on 2026-08-12 by v-maheshsharma (community contribution) · 32 files (+197 -0), 32 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- TDS/GST/TCS amount now calculates correctly when tax section code or related fields are entered initially
- Restored CurrPage.SaveRecord() call in tax calculation flow across 31 India journal and voucher page extensions
- Added integration event OnBeforeUpdateTaxAmountOnGenJnlLine to codeunit Calculate Tax for extensibility
- Event allows subscribers to override save and tax calculation logic, useful for environments with complex approval workflows
- Fixes regression from earlier commit that removed the save call, which caused zero tax on first pass
- Behaviour changes for users or extensions.
