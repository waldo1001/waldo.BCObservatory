# #9452 [Extensibility Request] issue 30329: override confirmation text in CancelPostedInvoiceAndOpenSalesOrder

> An integration event allows extensions to override the confirmation text when canceling a posted sales invoice, enabling accurate messaging when custom logic changes the behavior applied to the originating sales order.

## What changed

- New integration event `OnCancelPostedInvoiceAndOpenSalesOrderOnBeforeConfirm` added to codeunit 1322
- Extensions can now override confirmation question text instead of duplicating the procedure logic
- Confirmation text is stored in a variable before being shown to users
- Event exposes sales invoice header, sales header, and the confirmation text parameter
- Addresses inconsistency when extensions customize how posted invoice corrections affect originating order quantities
- Behaviour changes for users or extensions.
