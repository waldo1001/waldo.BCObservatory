# #9089 Merge-ES-Excluded-from-Calculation-to-W1

> Spain's excluded-from-calculation functionality is merged into the worldwide base application, consolidating region-specific ledger entry and general ledger setup logic across multiple localization layers.

[Pull request](https://github.com/microsoft/BCApps/pull/9089) · merged into `main` (BC30) on 2026-07-20 by Alexander-Ya · 90 files (+560 -1919), 90 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- Excluded from Calculation field logic moved from Spain-specific implementation to W1 base
- General Ledger Setup, Customer/Vendor Ledger Entry, and Currency tables updated across multiple regions
- Spain-specific MyCustomer and StandardStatement Report removed from ES layer
- Consistent excluded-from-calculation handling now applies across APAC, BE, CH, DACH, ES, FI, FR, GB, IS, IT, NA, NL regions
- Customer and vendor ledger entry calculations align with the new exclusion framework
- Behaviour changes for users or extensions.
