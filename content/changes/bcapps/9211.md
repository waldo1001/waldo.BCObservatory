# #9211 [Shopify] Surface skipped records and sent JSONL for bulk price sync

> When a bulk price sync reverts variants that Shopify rejected, the Shopify connector now logs a Shopify Skipped Record with the Shopify error message for each one. When Logging Mode is All, it also stores the sent JSONL on the bulk operation, and a new action lets you download it.

[Pull request](https://github.com/microsoft/BCApps/pull/9211) · merged into `main` (BC30) on 2026-07-09 by onbuyuka · 5 files (+309 -9), 4 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Failed variants in bulk price sync now generate Shopify Skipped Records with Shopify error messages instead of silently reverting
- Skipped records reference the linked BC Item Variant or Item to show users exactly which product failed and why
- Sent JSONL payload is stored on bulk operation records when Logging Mode is set to All for troubleshooting
- Download Sent Data action added to Shopify Bulk Operations page to retrieve the stored request JSONL
- New Sent JSONL field with helper methods added to Shopify Bulk Operation table
- Behaviour changes for users or extensions.
