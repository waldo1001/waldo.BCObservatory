# #12149 [main] Bug 652332 Issuing multiple Reminders or Finance Charge Memos with Print, produces a PDF only for the last one

> Fixed an issue where issuing multiple reminders or finance charge memos with the print option would only generate a PDF for the last document. The fix batches all issued documents into a single print invocation so the PDF includes all selected documents.

[Pull request](https://github.com/microsoft/BCApps/pull/12149) · merged into `main` (BC30) on 2026-10-21 by MSNehaNawal · 8 files (+397 -37), 5 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Printing multiple reminders or finance charge memos now produces a single PDF containing all documents instead of only the last one
- Documents are batched into one print call rather than printed individually
- Email processing for these documents remains unchanged
- Changes applied to both base application and localization layers
- Test coverage added for the fix
- Behaviour changes for users or extensions.
