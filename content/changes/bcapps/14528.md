# #14528 Deliverable 660629: [29.x] BCApps part of No Receipt expenses

> The Expense Agent now allows users to submit expenses with missing original receipts by selecting a Lost Receipt option, with the system generating a standardized declaration document and enforcing mandatory approver review.

[Pull request](https://github.com/microsoft/BCApps/pull/14528) · merged into `releases/29.x` (BC29) on 2026-11-26 by BardurKnudsen · 40 files (+1697 -299), 34 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- New Lost Receipt functionality lets users mark expenses without original receipts
- System automatically generates a standardized Lost Receipt declaration document based on expense data
- Enhanced compliance controls require mandatory approver review for no-receipt expenses
- New enums for Expense Compliance Status and Expense No Receipt Type added
- New management codeunit and report created to handle no-receipt declarations
- Behaviour changes for users or extensions.
