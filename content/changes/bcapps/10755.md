# #10755 Migrate Http Web Request Mgt. callers to native HttpClient

> Five codeunits now use native AL HTTP types (HttpClient, HttpRequestMessage) instead of the legacy Http Web Request Mgt. codeunit for internal HTTP operations, reducing dependency on deprecated patterns while maintaining backward compatibility where needed.

[Pull request](https://github.com/microsoft/BCApps/pull/10755) · merged into `main` (BC30) on 2026-10-02 by darjoo · 6 files (+259 -148), 5 AL · refactor · tier official · **unreviewed** (model text not yet checked)

## What changed

- Migrated currency exchange rates, external accountant invitations, JSON structure retrieval, and OData metadata calls from legacy to native HTTP types
- Preserved public API compatibility in ODataUtility by keeping the old CreateMetadataWebRequest procedure while adding new CreateMetadataRequest with native types
- Simplified error handling in UpdateCurrencyExchangeRates by using direct error text instead of XML/WebException parsing
- Consolidated duplicate telemetry logging in InviteExternalAccountant into a single helper
- Changed internal InitializeWebRequest in GraphClient to take HttpRequestMessage instead of Http Web Request Mgt.
