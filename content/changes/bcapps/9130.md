# #9130 [Subcontracting] Refactor event subscriber for planning components and add test for Vendor-supplied components

> The subcontracting planning logic was refactored to use a new event subscriber that prevents vendor-supplied components from generating separate planning demand while keeping them visible in the planning worksheet. A test was added to verify this behavior.

[Pull request](https://github.com/microsoft/BCApps/pull/9130) · merged into `main` (BC30) on 2026-08-20 by SPinkow (community contribution) · 2 files (+138 -6), 1 AL · refactor · tier official · **unreviewed** (model text not yet checked)

## What changed

- Event subscriber changed from OnTransferBOMOnBeforeUpdatePlanningComp to OnAfterFilterLinesWithItemToPlan
- Vendor-supplied components are filtered out during planning to prevent duplicate demand generation
- Vendor-supplied components remain in the planning worksheet for consumption tracking
- New test verifies that vendor-supplied components are not planned separately but can be replanned if supply method changes
- Refactoring improves code organization by moving logic to a more appropriate event hook
- Behaviour changes for users or extensions.
