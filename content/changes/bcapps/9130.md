# #9130 [Subcontracting] Refactor event subscriber for planning components and add test for Vendor-supplied components

> Vendor-supplied components in subcontracting no longer generate separate planning demand but still appear in the planning worksheet for consumption registration. The subscriber now hooks OnAfterFilterLinesWithItemToPlan on Planning Component instead of OnTransferBOMOnBeforeUpdatePlanningComp, and a test covers the behaviour.

[Pull request](https://github.com/microsoft/BCApps/pull/9130) · merged into `main` (BC30) on 2026-08-20 by SPinkow (community contribution) · 2 files (+138 -6), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Subscriber moved from OnTransferBOMOnBeforeUpdatePlanningComp to OnAfterFilterLinesWithItemToPlan on Planning Component
- Components with supply method Vendor-Supplied are filtered out so they create no separate requisition lines
- Vendor-supplied components remain in the planning worksheet and production order for consumption tracking
- New test confirms the component is planned again when its supply method changes
- Behaviour changes for users or extensions.
