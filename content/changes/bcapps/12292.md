# #12292 Fix #10964: Use VAT registration number fallback in FatturaPA file name

> FatturaPA file names now use VAT Registration Number as a fallback when Fiscal Code is blank, matching the transmitter identifier already used in the XML document.

[Pull request](https://github.com/microsoft/BCApps/pull/12292) · merged into `main` (BC30) on 2026-10-30 by marcus905 (community contribution) · 3 files (+41 -5), 2 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Fiscal Code is checked first; if empty, VAT Registration No. is used for the transmitter identifier
- File naming now aligns with the XML's IdTrasmittente/IdCodice field behavior
- Helper method centralized to avoid duplicated fallback logic in GetFileName()
- Existing files generated with Fiscal Code remain unchanged
- Added unit tests for the fallback scenario
- Behaviour changes for users or extensions.
