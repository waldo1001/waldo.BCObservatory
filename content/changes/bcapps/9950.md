# #9950 [Master] - Bug 645038 Withholding Tax entries from a previous posting preview appear on unrelated documents (e.g. expense report)

> Withholding Tax entries from a previous posting preview no longer leak into unrelated document previews. The fix clears temporary WHT entries at the start of each preview instead of only during actual posting.

[Pull request](https://github.com/microsoft/BCApps/pull/9950) · merged into `main` (BC30) on 2026-08-11 by v-rohangarg20 · 1 file (+2 -18), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Fixed bug where stale Withholding Tax entries from one preview appeared when previewing an unrelated document
- Root cause was that temporary entries were only cleared on actual posting, not on preview operations
- Solution clears the temporary Withholding Tax buffer at the start of every preview operation
- Removed subscribers from OnBeforePostPurchaseDoc and OnBeforeGenJnlDoc events
- Cleaned up unused imports after refactoring
- Behaviour changes for users or extensions.
