# #10034 [Shopify] Don't block Shops page when user lacks extension permissions

> The Shopify Shops page no longer fails to open on Belgian environments when users lack extension installation permissions. A permission error during the installation status check now skips the notification instead of blocking the page.

## What changed

- Wrapped installation status check in a try function to gracefully handle permission errors
- Users without extension install permissions can now open the Shopify Shops page
- The notification is skipped when its underlying check fails, avoiding blocker errors
- Change is specific to Belgian localization and the extension notification feature
- Behaviour changes for users or extensions.
