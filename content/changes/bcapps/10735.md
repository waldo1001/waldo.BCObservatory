# #10735 [Slice-631381] Add Mark as Accepted in posted documents for Spanish SII

> Spanish SII posted documents now include a Mark as Accepted action to resolve stuck Incorrect or Pending statuses directly from the document page, matching the behavior available on the SII History page.

[Pull request](https://github.com/microsoft/BCApps/pull/10735) · merged into `main` (BC30) on 2026-08-28 by Explorer986 · 8 files (+711 -9), 7 AL · feature · tier official · **unreviewed** (machine-generated)

## What changed

- New Mark as Accepted action added to posted sales, purchase, and service invoice and credit memo pages for Spanish localization
- Resolves SII document status by source, type, and number without requiring the SII posting date to match
- Action gated behind SII enabled check and Show Advanced Actions setting
- Returns success status to the page which handles user messaging
- Nine new tests added covering happy path scenarios and edge cases
- Behaviour changes for users or extensions.
