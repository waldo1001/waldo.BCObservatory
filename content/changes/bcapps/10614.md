# #10614 Expense Agent: Improve expense activity history captions

> Expense report activity logs now display user-friendly captions (Activity, Date and Time, Performed By, Details) instead of technical field names, and the FactBox is renamed from Activity Log to History.

[Pull request](https://github.com/microsoft/BCApps/pull/10614) · merged into `main` (BC30) on 2026-08-31 by t-prda · 5 files (+12 -16), 5 AL · feature · tier official · **unreviewed** (machine-generated)

## What changed

- Renamed the FactBox from Activity Log to History for clearer user communication
- Replaced technical column headers with descriptive labels (Activity, Date and Time, Performed By, Details)
- Field tooltips are now inherited from the activity log table rather than duplicated on the FactBox
- Applies to expense reports, posted expense reports, and manager expense report pages
- Behaviour changes for users or extensions.
