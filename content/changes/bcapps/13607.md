# #13607  [Main][ALL-E] Report 713 "Inventory Custmer Sales" – Excel (data only) export generates one row per Item Ledger Entry with NULL values instead of one aggregated row per Item/Customer combinationInitial commit

> Report 713 now correctly exports aggregated rows per Item/Customer combination in Excel (data only) format instead of generating intermediate rows with NULL customer values.

[Pull request](https://github.com/microsoft/BCApps/pull/13607) · merged into `main` (BC30) on 2026-11-09 by sanjmaurya · 2 files (+68 -0), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- The report was emitting dataset rows even when the temporary aggregate buffer was empty
- Null customer values appeared in intermediate rows during Excel export
- Solution adds CurrReport.Skip() to suppress intermediate rows while preserving aggregates and totals
- Word layout and existing subtotals/grand totals remain unaffected
- Test coverage added for the fix
- Behaviour changes for users or extensions.
