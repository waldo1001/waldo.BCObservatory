# #13303 [Bank. Acc. Reconciliation with Copilot] Implement ability to switch LLM with a simple configuration change

> Bank Account Reconciliation with Copilot now supports switching between different LLM models through Key Vault configuration without code changes, and improves parser robustness to handle variations in model output formatting.

[Pull request](https://github.com/microsoft/BCApps/pull/13303) · merged into `main` (BC30) on 2026-10-30 by dcenic · 3 files (+181 -71), 2 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- New GetChatCompletionsDeployment() method reads Key Vault secret to select between GPT-5.6 Ceres or GPT-4.1 models
- Deployment name added as custom dimension to telemetry events for audit and incident tracking
- Parser logic strengthened to handle formatting variations like spacing differences and bracketed text across both statement matching and transfer-to-G/L-account features
- Default behavior unchanged when Key Vault secret is missing or blank
- Both matching and G/L account proposal parsers now share common helper methods for consistent handling
- Behaviour changes for users or extensions.
