# #9073 Data Exchange Definition export performance improvement

> Data Exchange Definition exports now use in-memory mapping with bulk saves and reuse FlowField calculations to significantly improve performance on large record sets, with no change to output format.

[Pull request](https://github.com/microsoft/BCApps/pull/9073) · merged into `main` (BC30) on 2026-07-13 by VolodySyn · 3 files (+251 -5), 3 AL · performance · tier official · **unreviewed** (machine-generated)

## What changed

- Eliminates per-row database writes by building field values in memory first, then transferring to the persisted table in one bulk pass
- Reuses pre-aggregated FlowField values from the grouping buffer instead of recalculating per line
- Throttles progress dialog updates based on row count to reduce UI overhead on large exports
