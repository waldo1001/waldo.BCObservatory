# #9455 Update permissions for G/L Transaction table

> Permission sets for general ledger transactions are updated across multiple localization layers to align with access requirements for posting and compression operations.

[Pull request](https://github.com/microsoft/BCApps/pull/9455) · merged into `main` (BC30) on 2026-07-25 by Alexander-Ya · 57 files (+57 -1), 57 AL · feature · tier official · **unreviewed** (machine-generated)

## What changed

- Added read permission for G/L Transaction table to multiple permission sets across W1, RU, CH, NA, ES, IT, NL, BE, and APAC layers
- Updated permission sets include payables, receivables, fixed assets, general ledger, inventory, jobs, and Dynamics 365 role-based sets
- Covers both OnPrem and cloud permission sets for consistent access controls
- Enables users with relevant roles to access general ledger transaction data when performing finance operations
- No breaking changes to existing permissions, only additions of read access
- Behaviour changes for users or extensions.
