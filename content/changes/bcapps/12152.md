# #12152 [MCP] Clear environment description after environment copy

> Environment descriptions are now cleared when an environment is copied, preventing the destination from retaining information about the source environment.

## What changed

- Subscribes to the database-level environment cleanup event triggered during environment copy
- Clears the environment description BLOB for every environment-copy scenario
- Adds a regression test to verify description is cleared after environment copy
- Operates at database scope, consistent with the environment description's `DataPerCompany = false` setting
- Existing descriptions remain unchanged unless the platform triggers an environment-copy cleanup event
- Behaviour changes for users or extensions.
