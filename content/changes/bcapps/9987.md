# #9987 Fix Payment Management FR data update paths and per-company feature status

> Fixed French payment management data migration path by centralizing migration logic, adding separate upgrade tags for object ID remapping, and removing cross-company feature status duplication that incorrectly marked migrations as complete in unmigrated companies.

[Pull request](https://github.com/microsoft/BCApps/pull/9987) · merged into `main` (BC30) on 2026-08-18 by ventselartur · 7 files (+332 -389), 7 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- Created new codeunit to consolidate payment data migration, ensuring Feature Management path also remaps object IDs
- Added separate upgrade tag for remapping to repair companies that migrated before remapping was added
- Removed cross-company ModifyAll pattern from feature codeunits that incorrectly copied completion status across all companies
- Fixed bank account field direction so RIB data migrates correctly to base application fields
- Improved data update requirement check to count all migrated tables and avoid skipping migrations in companies without bank accounts
- Behaviour changes for users or extensions.
