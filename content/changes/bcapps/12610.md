# #12610 [Report Filename Manager] New app for configurable report output file names - Slice 651696 [vendor work]

> A new Report Filename Manager app enables administrators to configure dynamic file names for report output across all distribution routes using customizable patterns and placeholders.

[Pull request](https://github.com/microsoft/BCApps/pull/12610) · merged into `main` (BC30) on 2026-10-27 by anordmann · 127 files (+26530 -0), 49 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- New W1 app with 26 codeunits managing report file naming patterns and context
- Supports multiple output routes: print, preview, save, download, email, PDF attachment, and scheduled reports
- Extensible placeholder system with implementation-specific handlers for document types and metadata fields
- Uses platform and Base Application events; includes temporary stand-ins for four missing events
- Configuration applies consistently across all companies since it uses compiled metadata only
- Behaviour changes for users or extensions.
