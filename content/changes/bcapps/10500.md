# #10500 [Bug Fix] #190: Additional-Currency Total Cost incorrect on Project Ledger Entries

> Project ledger entries now correctly record additional-currency total cost when a manual source currency exchange rate override is applied, matching G/L entry behavior.

[Pull request](https://github.com/microsoft/BCApps/pull/10500) · merged into `main` (BC30) on 2026-10-12 by ventselartur · 6 files (+139 -11), 5 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Carry source currency code and source currency amount from Gen. Journal Line to Job Journal Line during transfer
- Skip currency re-conversion when source currency equals additional reporting currency, preserving overridden rates
- Ensures project and G/L ledger entries remain consistent for manually overridden exchange rates
- Added regression test demonstrating the fix
- Behaviour changes for users or extensions.
