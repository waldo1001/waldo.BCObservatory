# #14346 [Main] Expense Management: add partner extension events and make Create Expense Report public

> Expense management adds integration events for partners to customize expense report lines and posting without friend access, and makes the Create Expense Report codeunit public with a focused API surface.

[Pull request](https://github.com/microsoft/BCApps/pull/14346) · merged into `main` (BC30) on 2026-11-23 by t-prda · 6 files (+627 -7), 4 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Seven new integration events cover copying expense fields to report lines, posting operations, per diem calculations, and post-posting follow-up actions
- Create Expense Report codeunit changed from internal to public, exposing only the AddSingleExpenseToExpenseReport procedure while keeping UI methods internal
- Integration events added to Expense Report-Post, Expense Ledger Entry, and Expense Per Diem Calculation objects to support localization and partner customizations
- Existing events like OnAfterReleaseExpense and OnCheckExpenseReportPostRestrictions are reused for consistency
- Per diem calculation refactored to delegate to a local procedure for event raising without changing behavior for non-subscribers
