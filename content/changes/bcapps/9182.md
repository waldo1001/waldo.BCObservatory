# #9182 Align Pay-to Name 2 editability with the other pay-to address fields on purchase documents

> Pay-to Name 2 field on purchase documents is now editable under the same conditions as other pay-to address fields when custom address is selected or vendor differs from buy-from vendor.

[Pull request](https://github.com/microsoft/BCApps/pull/9182) · merged into `main` (BC30) on 2026-10-08 by Franco111000 (community contribution) · 33 files (+106 -61), 29 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Pay-to Name 2 editability aligned with other pay-to address fields on three purchase pages
- Field now editable when Custom Address is selected or pay-to vendor differs from buy-from vendor
- Previously editable only when Another Vendor option was selected
- Identical two-property change applied across all localization layers (APAC, BE, CH, DACH, ES, FI, IT, NA, NL, NO, RU)
- Extended test coverage verifies editability alongside sibling address fields
- Behaviour changes for users or extensions.
