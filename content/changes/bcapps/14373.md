## What changed

- Four extensibility events added to codeunits 18466 and 18467 for subcontracting receipt posting
- OnBeforePostPurchOrder and OnBeforeCreatePostedReceipt events in Subcontracting Post with IsHandled support
- OnRecieveBackCompOnBeforePostItemJnlLine event for raw material return journal line posting
- OnBeforePostPurchOrderLine event in Subcontracting Post Batch for each subcontracting line
- Posting behavior unchanged when no subscribers are present
