# #11628 Expense Agent: capture submission policy evaluation history

> Expense Agent now captures policy evaluation history at the report level, storing outcomes and flagged categories in the activity log during submission and resubmission with deduplication per submission round.

[Pull request](https://github.com/microsoft/BCApps/pull/11628) · merged into `main` (BC30) on 2026-10-01 by t-prda · 10 files (+1690 -30), 7 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- Report-level policy evaluation summaries added to expense activity history
- Activity logger captures submission/resubmission events and line evaluation confirmations
- Passed/failed counts and distinct flagged category codes are stored in activity entries
- Category overflow handled with a final '...' array entry for display
- Read-only API exposes snapshots and preserves data through posting
- Behaviour changes for users or extensions.
