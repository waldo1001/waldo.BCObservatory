# #13807 [main] Bug 657914 Total Number of Supplies has incorrect type and tooltip in the VAT Report page of the German version.

> The Total Number of Supplies field in the VAT Report page is corrected to display as a whole number instead of an amount with decimal places in the German version.

[Pull request](https://github.com/microsoft/BCApps/pull/13807) · merged into `main` (BC30) on 2026-11-16 by MSNehaNawal · 2 files (+4 -3), 2 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Field 33 Total Number of Supplies in VAT Report Header is a Decimal FlowField that was formatted as an amount, so it showed two decimal places
- It now shows as a whole number, the same way the summed line field Number of Supplies does (AutoFormatType 0, DecimalPlaces 0:0)
- The field stays Decimal, which avoids a breaking schema change to Integer
- Applies to the German (DE) layer of the VAT Report page and table
- Behaviour changes for users or extensions.
