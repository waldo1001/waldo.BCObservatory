# #13807 [main] Bug 657914 Total Number of Supplies has incorrect type and tooltip in the VAT Report page of the German version.

> The Total Number of Supplies field in the VAT Report page is corrected to display as a whole number instead of an amount with decimal places in the German version.

## What changed

- Field 33 in VATReportHeader is a Decimal FlowField that was incorrectly formatted as an amount with two decimal places
- Changed AutoFormatType and DecimalPlaces settings to display the field as a whole number, matching the source field behavior
- Avoids a breaking schema change by keeping the field as Decimal type while correcting its display format
- Fixes incorrect tooltip and type presentation in the German VAT Report page
