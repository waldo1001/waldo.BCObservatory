# #9098 Align the Vend. Entry-Edit post-modify event with its Cust. Entry-Edit counterpart

> The vendor entry-edit codeunit now raises an improved post-modify event that mirrors its customer counterpart, passing both the original and modified entry records for better context to event subscribers.

[Pull request](https://github.com/microsoft/BCApps/pull/9098) · merged into `main` (BC30) on 2026-07-09 by Franco111000 (community contribution) · 8 files (+128 -0), 8 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- New event OnRunOnAfterVendLedgEntryModify added with the same signature as OnRunOnAfterCustLedgEntryModify from the customer counterpart
- Old misspelled event OnRunOnAfterVendLedgEntryMofidy obsoleted and guarded with CLEAN29 pattern to maintain backward compatibility
- Both event parameters passed by reference to provide full context to subscribers
- Change applied uniformly across W1 and all localization layers (APAC, CH, IT, NA, NL, NO, RU)
- No behavior changes to end users; change is event-focused for extension developers
