# #9959 [Shopify] Add catalog filters to Sync Catalog Prices report

> The Sync Catalog Prices report now supports filtering by individual catalogs, allowing merchants to split large sync operations across multiple Job Queue entries to work within Business Central's 12-hour session limit.

[Pull request](https://github.com/microsoft/BCApps/pull/9959) · merged into `main` (BC30) on 2026-08-05 by onbuyuka · 2 files (+37 -32), 2 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- Report 30116 restructured with nested Shpfy Catalog dataitem to expose Id and Name filters alongside Shop Code filter
- Enables splitting catalog price syncs across multiple concurrent Job Queue entries for faster completion
- Codeunit 30295 refactored with new SetShop and SyncCatalog methods while retaining catalog deduplication and SetCatalogType
- Addresses timeout issues for merchants with 150+ large catalogs that couldn't complete within 12-hour background session limits
- Request page now displays Shop and Catalog filters for scoped sync operations
- Behaviour changes for users or extensions.
