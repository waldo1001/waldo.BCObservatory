# #13102 Create putaway template bin validation

> Put-away template bin validation now excludes receipt, shipment, and posted receipt-line bins to ensure only compliant bins are selected for put-away operations.

## What changed

- Receipt, shipment, and posted receipt-line bins are excluded from put-away template searches
- Create Put-away now selects valid eligible bins matching template criteria instead of falling back to non-compliant bins
- Regression test added to verify correct bin selection behavior
- No breaking changes or compatibility risks
