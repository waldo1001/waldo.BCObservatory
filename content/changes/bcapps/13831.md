# #13831 [Agent Design Experience] Use native Markdown for custom-agent instructions

> Custom agent instructions now use the native Markdown field instead of a WebPageViewer control, with a new per-agent checkbox to enable business skills that provide specialized guidance.

[Pull request](https://github.com/microsoft/BCApps/pull/13831) · merged into `main` (BC30) on 2026-11-26 by nikolakukrika · 15 files (+718 -86), 13 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Replace WebPageViewer textarea with native multiline Markdown field for instruction editing
- Add optional per-agent Use business skills checkbox that defaults to enabled for new agents
- Preserve instruction text as raw UTF-8 without HTML conversion, maintaining formatting and whitespace
- Share Markdown part across setup dialog, agent card, history previews, and import previews
- Load instructions explicitly and refresh after history restore instead of relying on control-add-in events
- Behaviour changes for users or extensions.
