# #10298 [main]A WIP Balance is presented incorrectly on the “Production Order – WIP” Report 5802 after Finishing Production Order Without Output Item Ledger Entry posted with new Manufacturing Setup option for no Output required.

> Report 5802 now displays a new Expensed WIP column to correctly show work-in-progress that was written off when production orders are finished without output, resolving a reconciliation issue with the general ledger.

[Pull request](https://github.com/microsoft/BCApps/pull/10298) · merged into `main` (BC30) on 2026-08-25 by Shikhverma · 5 files (+697 -33), 1 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- Added Expensed WIP column to Report 5802 to display WIP written off for production orders finished without output
- Created IsFinishedWithoutOutput helper to detect finished orders with no Output Item Ledger Entry
- WIP amounts are reclassified from ending balance to Expensed WIP column when orders lack output
- Report layout updated in RDLC, Word, and Excel formats to include the new column
- New test verifies Expensed WIP equals written-off cost and ending WIP shows zero
- Behaviour changes for users or extensions.
