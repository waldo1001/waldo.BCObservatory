# #11629 Fix Norwegian SAF-T 1.30 export issues

> Norwegian SAF-T 1.30 export now correctly reports header versions, handles credit amounts as non-negative, excludes unselected dimensions from the XML, and counts transaction groups consistently across split files.

[Pull request](https://github.com/microsoft/BCApps/pull/11629) · merged into `main` (BC30) on 2026-10-07 by AleksanderGladkov · 7 files (+1139 -69), 5 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- Header versions are now set to 1.30 and the current application version instead of hardcoded values
- Credit currency amounts are exported as non-negative values rather than retaining their sign
- Analysis data for dimensions not selected for export is omitted from the XML
- Transaction count uses exported transaction groups across journals and repeats totals in every split file
- SAF-T 1.20 exports remain unchanged; comprehensive XML regression tests added
- Behaviour changes for users or extensions.
