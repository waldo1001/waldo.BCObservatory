# #9363 GP - Updates 202607

> The Dynamics GP migration tool now handles item batches correctly by distributing transactions across multiple batches instead of creating one batch, improves validation for payment terms, purchase orders, and GL account categories, and fixes type mismatches in validation logic.

[Pull request](https://github.com/microsoft/BCApps/pull/9363) · merged into `main` (BC30) on 2026-09-11 by jaymckinney-enavate (community contribution) · 8 files (+110 -197), 8 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Item batches are now distributed properly for multiple transactions instead of consolidating into a single batch
- Validation logic corrected for type mismatches between Code and Text fields like postal codes
- Enhanced validation for payment terms, PO splits across multiple lines, and custom GL account expense categories
- Account beginning balance validation temporarily removed pending redesign
- Several fixes applied to GP migration codeunits and pages
- Behaviour changes for users or extensions.
