# #11155 Fix missing default item journal batch in Contoso Inventory setup

> Inventory's default item journal batch is now created with its template during Contoso setup, removing the dependency on Manufacturing, Service, or Jobs modules for this creation.

- Item journal batch is generated alongside its template in the item journal template creation helper
- Common and Warehouse module generation no longer requires Manufacturing, Service, or Jobs to create the default batch
- Batch settings are preserved using existing helper functionality
- Three regression tests validate batch creation, template handling, and settings preservation
- No breaking changes to numbering or dependencies
