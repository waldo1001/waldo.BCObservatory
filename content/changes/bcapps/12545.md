# #12545 [Contoso Demo Data] Refresh Common G/L mappings before Manufacturing demo setup

> Manufacturing demo data setup now runs the existing Create Common GL Account codeunit first to refresh the Common G/L account mappings. Before this, Manufacturing failed to find the Raw Materials account when Common data had been generated in an earlier session and the mappings were empty.

[Pull request](https://github.com/microsoft/BCApps/pull/12545) · merged into `main` (BC30) on 2026-10-14 by attilatoury · 2 files (+145 -0), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Calls existing Create Common GL Account codeunit at the beginning of Manufacturing setup
- Fixes issue where Manufacturing fails to find Raw Materials account when Common mappings are empty
- Adds regression test to verify Manufacturing restores localized mappings without replacing existing accounts
- Supports localizations that use blank mappings
- No schema or public contract changes
- Behaviour changes for users or extensions.
