# #9321 [Shopify] Add Unlisted product status

> The Shopify Connector's product status enum now includes the Unlisted value that Shopify added to its API, correcting the misrepresentation of unlisted products during import.

[Pull request](https://github.com/microsoft/BCApps/pull/9321) · merged into `main` (BC30) on 2026-07-16 by onbuyuka · 1 file (+4 -0), 1 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Added an Unlisted value to the Shpfy Product Status enum (30130)
- Shopify has exposed UNLISTED since API version 2025-10, and the connector uses version 2026-07
- On import, UNLISTED now maps to Unlisted instead of falling back to Active
- Export uppercases the enum name back to UNLISTED, so no mapping code had to change
- Products wrongly stored as Active are corrected on the next sync
- Behaviour changes for users or extensions.
