# #9321 [Shopify] Add Unlisted product status

> The Shopify Connector's product status enum now includes the Unlisted value that Shopify added to its API, correcting the misrepresentation of unlisted products during import.

## What changed

- Added Unlisted value to the Shpfy Product Status enum (30130)
- Shopify API version 2026-07 supports UNLISTED status starting from API version 2025-10
- Import now correctly maps UNLISTED string to Unlisted enum value instead of falling back to Active
- No code changes needed in the mapping logic as the value name matches the cleaned Shopify string
- Existing Active, Archived, and Draft product handling remains unchanged
- Behaviour changes for users or extensions.
