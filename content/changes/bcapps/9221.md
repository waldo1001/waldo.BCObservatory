# #9221 [Shopify] Uptake Admin GraphQL API to version 2026-07

> The Shopify connector now supports the Admin GraphQL API version 2026-07 and handles market-driven shipping by reading shipping option names from market delivery settings instead of the deprecated merchant delivery profile APIs.

[Pull request](https://github.com/microsoft/BCApps/pull/9221) · merged into `main` (BC30) on 2026-07-09 by onbuyuka · 12 files (+146 -5), 3 AL · feature · tier official · **unreviewed** (machine-generated)

## What changed

- Updated API version from 2026-01 to 2026-07 following Shopify's deprecation schedule
- Added detection of market-driven shipping model through ShopFeatures.marketDrivenShipping
- For market-driven shops, reads shipping option definitions from markets.delivery.shipping instead of deprecated deliveryProfiles
- Added new GraphQL resources GetMarketShippingMethods and GetNextMarketShippingMethods with corresponding enum values
- Added test coverage for the market-driven shipping path with sample responses
- Behaviour changes for users or extensions.
