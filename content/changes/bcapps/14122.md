# #14122 [Subcontracting] Refresh the transfer order lines without saving in SetIsSubcontracting

> SetIsSubcontracting on the Subc. Trans. Order Sub. page extension now calls CurrPage.Update(false), so it refreshes the transfer lines subform without saving the current line. This stops a failed line save from being raised inside the Transfer Order's record-fetch trigger and closing the page.

[Pull request](https://github.com/microsoft/BCApps/pull/14122) · merged into `main` (BC30) on 2026-11-17 by Franco111000 (community contribution) · 1 file (+1 -1), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- CurrPage.Update() replaced by CurrPage.Update(false) in SetIsSubcontracting
- Transfer Order calls it from OnOpenPage and OnAfterGetCurrRecord, so before this each header fetch saved the current line
- A save error no longer surfaces inside OnAfterGetCurrRecord and closes the page
- Edited lines are still saved by the normal page save, for example when leaving the row
- Matches how SetPerTaskBillingFieldsVisible refreshes the Job Task Lines subform from the Job Card
- Behaviour changes for users or extensions.
