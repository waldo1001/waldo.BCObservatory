# #9585 [master] Description Field value gets automatically reverted the original value after changing it.

> Fixed a bug where the Description field on sales lines would revert to its original item value after editing, when Calc. Inv. Discount was enabled and Quantity had been validated.

[Pull request](https://github.com/microsoft/BCApps/pull/9585) · merged into `main` (BC30) on 2026-07-20 by neeleshsinghal · 4 files (+44 -3), 3 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Description field was being overwritten by a database reload after Quantity validation
- The NeedRefreshSalesLine flag was incorrectly set to false after an early-exit, preventing proper cleanup
- Moved the flag reset before the early-exit to ensure RefreshSalesLine doesn't reload uncommitted edits
- Bug occurred in CalculateSalesSubPageTotals when totals were already up-to-date
- Added test coverage to document the fix
- Behaviour changes for users or extensions.
