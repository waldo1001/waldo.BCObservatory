# #9444 [Extensibility Request] issue 30223: add IsHandled events to Purchase Line (translation, price calc, WMS)

> Three new IsHandled integration events are added to the Purchase Line table, enabling extensions to intervene in item translation, location-based price calculation, and WMS location checks.

## What changed

- OnCopyFromItemOnBeforeGetItemTranslation lets subscribers skip the standard item translation call in CopyFromItem
- OnValidateLocationCodeOnBeforePlanPriceCalcByField passes Rec, xRec and CurrFieldNo so subscribers can replace price planning on Location Code validation
- OnBeforeCheckWMS lets subscribers bypass the standard WMS location check
- Changes applied in W1 and propagated to the Purchase Line table in all other BaseApp layers
