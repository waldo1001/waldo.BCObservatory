# #10417 [Shopify] Pace raw-text GraphQL calls to prevent excessive throttling

> The Shopify connector now paces GraphQL requests issued through the raw-text overload to prevent excessive throttling, by using an estimated cost value instead of zero.

[Pull request](https://github.com/microsoft/BCApps/pull/10417) · merged into `main` (BC30) on 2026-08-24 by onbuyuka · 1 file (+1 -1), 1 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- The single-argument ExecuteGraphQL(Text) overload previously hard-coded ExpectedCost to 0, causing no pacing between requests
- This resulted in rapid bucket depletion and retry loops with no back-off on shops with small GraphQL cost buckets
- The fix sets ExpectedCost to 10 (the average Shopify mutation cost) to restore pre-request and inter-retry pacing
- The retry loop now benefits from pacing without requiring changes to its logic
- Data integrity is not affected; sync throughput is improved by reducing throttling events
- Behaviour changes for users or extensions.
