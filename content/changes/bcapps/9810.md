# #9810 [master]-Edit in Excel fails with false duplicate error when creating new Item Variants

> Item Variants page no longer fails with a false duplicate key error when creating new variants through Edit in Excel by limiting the forced record update to interactive clients only.

[Pull request](https://github.com/microsoft/BCApps/pull/9810) · merged into `main` (BC30) on 2026-07-31 by MSNehaNawal (community contribution) · 1 file (+4 -1), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Removed forced immediate record persistence that triggered during Edit in Excel operations
- Scoped the OnValidate trigger's CurrPage.Update(true) call to interactive sessions only
- OData and web service sessions now bypass the early update, preventing duplicate key conflicts
- Allows Edit in Excel to handle variant creation through its normal OData insert flow
- Behaviour changes for users or extensions.
