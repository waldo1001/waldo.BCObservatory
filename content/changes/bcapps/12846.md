# #12846 [main] bug 652274 - [CZ] Add the Country/Region of Origin Code field to a document line

> Czech Intrastat reporting now supports a Country/Region of Origin Code field on document lines, initialized from the item card but changeable per transaction, with an option to retrieve values from posted entries instead.

[Pull request](https://github.com/microsoft/BCApps/pull/12846) · merged into `main` (BC30) on 2026-10-19 by v-janpopr · 79 files (+2163 -315), 72 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- New Country/Reg. of Orig. Code CZ field added to all document, journal, archive, and ledger lines
- Field auto-populated from item card but can be manually changed per transaction
- New Intrastat Report Setup option to retrieve origin from Item Card (default) or Posted Entries
- Value preserved through posting, archiving, direct transfers, and ledger creation
- Allows same item from different country sources without requiring separate item cards
- Behaviour changes for users or extensions.
