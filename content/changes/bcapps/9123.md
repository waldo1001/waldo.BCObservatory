# #9123 Bug 641489: Show Next/Previous Operation No. on routing lines when Type = Parallel

> Next Operation No. and Previous Operation No. fields on routing lines now automatically show when routing type is Parallel instead of remaining hardcoded invisible, eliminating the need for manual personalization.

[Pull request](https://github.com/microsoft/BCApps/pull/9123) · merged into `main` (BC30) on 2026-07-10 by alexei-dobriansky · 6 files (+76 -8), 6 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- Fields visibility now binds to routing type: shows for Parallel, hides for Serial
- Visibility can be controlled via SetParallelFieldsVisible setter on subform
- Parent routing cards trigger visibility updates in OnAfterGetRecord and Type field OnValidate
- Workaround no longer needed for ISV apps that previously personalized these fields manually
- UI tests added to verify automatic field visibility
- Behaviour changes for users or extensions.
