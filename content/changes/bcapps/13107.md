# #13107 CZ Registration No. verification must do integrity and schema check of the response

> The CZ Registration No. validation against the ARES Czech business register now includes schema, integrity, and size checks before marking responses as Valid, similar to other unauthenticated integrations.

[Pull request](https://github.com/microsoft/BCApps/pull/13107) · merged into `main` (BC30) on 2026-10-25 by dcenic · 3 files (+355 -3), 2 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Schema validation ensures responses contain required fields (ico, obchodniJmeno, sidlo) as non-empty strings or objects
- Integrity check confirms the response ico exactly matches the requested IČO
- Response body is capped at 64 KB and validated before JSON parsing
- Invalid responses are rejected with Security Audit and telemetry entries
- Prevents acceptance of malformed or unrelated ARES data for master data updates
- Behaviour changes for users or extensions.
