# #9168 [QM] Fix internal put-away from Quality Inspection sourcing wrong bin

> Internal put-away disposition from Quality Inspection now resolves the source bin from actual Bin Content in directed put-away locations instead of relying on field naming conventions, fixing errors when items no longer exist in their original receive bins.

[Pull request](https://github.com/microsoft/BCApps/pull/9168) · merged into `main` (BC30) on 2026-07-15 by 6CRIPT · 4 files (+204 -24), 3 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Resolves source bins from real Bin Content for bin-mandatory locations, excluding receive and adjustment bins
- Validates source bins for receive-bin issues before document creation to show actionable error messages
- Displays intended quantity instead of 0 in failed creation notifications
- Falls back to naming-convention logic only for non-bin-mandatory locations or when item has no current stock
- Extracted IsReceiveBin as a reusable helper function
- Behaviour changes for users or extensions.
