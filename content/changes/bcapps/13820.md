# #13820 [main] NO SAF-T changes imported category identifier casing and does not show full identifiers in mapping setup

> Norwegian SAF-T now preserves original category identifiers during import and displays them in the mapping setup to prevent uppercase conversion issues and improve identifier visibility.

[Pull request](https://github.com/microsoft/BCApps/pull/13820) · merged into `main` (BC30) on 2026-11-18 by AleksanderGladkov · 6 files (+145 -18), 4 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Original category identifier now stored for all imported categories, not only those over 20 characters
- New read-only Category Extended No. column on the SAF-T G/L Mapping Subpage shows the full identifier
- Value refreshes when a category is selected or cleared
- Existing category keys and mappings unchanged; reimport source files and regenerate the export to repair short categories
- Import, mapping page and XML export tests updated and extended
- Behaviour changes for users or extensions.
