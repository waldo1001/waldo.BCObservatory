# #9067 Production Definition Wizard - Implementation 

> The Production Definition Wizard is introduced as a guided multi-step interface for configuring Bill of Materials and Routing for manufactured items, with new setup fields, temporary record handling improvements, and expanded event publishers for extensibility.

[Pull request](https://github.com/microsoft/BCApps/pull/9067) · merged into `main` (BC30) on 2026-08-16 by stevengrossGOB (community contribution) · 100 files (+11954 -162), 85 AL · feature · tier official · **unreviewed** (machine-generated)

## What changed

- New wizard pages and configuration fields added to Manufacturing Setup to control wizard visibility, behavior, and default values
- Temporary record handling improved with IsTemporary checks in production order components and routing lines to prevent unintended database access
- Event publishers expanded with new parameters and integration points like OnBeforeGetProdOrderNeeds and OnBeforeGetProdOrderLine for extension flexibility
- CreateOrderFromSales page enhanced with UseProductDefinitionWizard field to allow users to opt into wizard during order creation
- Manufacturing module refactored to support the new wizard-based workflow for production definition
- Behaviour changes for users or extensions.
