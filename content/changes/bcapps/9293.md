# #9293 [Bug][SubscriptionBilling] Process Usage Data Billing uses lines marked Processing Status = Error (currency mismatch)

> Process Usage Data Billing now excludes lines marked with Processing Status Error, preventing recalculation of erroneous data and consolidating filtering logic into a single helper method. Processing Status is now properly maintained throughout the billing workflow and users can manually close or reopen usage data imports.

[Pull request](https://github.com/microsoft/BCApps/pull/9293) · merged into `main` (BC30) on 2026-09-25 by miljance (community contribution) · 9 files (+374 -61), 8 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Lines with Processing Status Error are now excluded from sums and lookups in the billing process
- Three duplicate CalcSums procedures consolidated into one CalculateSumsFromUsageDataBilling method
- Processing Status transitions now route through Validate to consistently stamp Processing Date
- Manual Close/Reopen actions added to Usage Data Imports page with multi-select support
- Six new tests added covering the corrected behavior
- Behaviour changes for users or extensions.
