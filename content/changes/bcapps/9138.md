# #9138 [Shopify] Add Belgium localization for company tax id mapping (Enterprise No.)

> A new Belgium localization app for Shopify Connector enables mapping customer tax IDs to the Enterprise No. field, which is required for Belgian B2B company sync. The W1 Shopify app notifies users if the optional Belgian app is not installed.

[Pull request](https://github.com/microsoft/BCApps/pull/9138) · merged into `main` (BC30) on 2026-07-21 by onbuyuka · 13 files (+454 -3), 4 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- New Shopify Connector BE app adds Enterprise No. as a tax ID mapping option for Belgian customers
- Enum extension and codeunit implement the mapping logic for field 11310 (Enterprise No.)
- W1 Shopify Shop Mgt. shows dismissable notification when Belgian localization is detected but the optional BE app is not installed
- App is opt-in and registered only for Belgium in build configuration
- Test project validates tax ID mapping and filtering for the Belgian implementation
- Behaviour changes for users or extensions.
