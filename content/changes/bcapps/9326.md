# #9326 [FI] Delocalize Depreciation Differences into a first-party extension

> Finland's Depreciation Differences feature moves from the base application into a first-party extension app, with legacy code marked obsolete and scheduled for removal in version 33.

[Pull request](https://github.com/microsoft/BCApps/pull/9326) · merged into `main` (BC30) on 2026-11-16 by djukicmilica · 61 files (+4739 -31), 41 AL · refactor · tier official · reviewed (checked by Opus)

## What changed

- New extension app DepreciationDifferencesFI provides depreciation differences functionality with table extensions, page extensions, reports, and codeunits
- Legacy BaseApp implementation marked obsolete (pending in 30.0, removed in 33.0) and wrapped behind CLEAN30 guards to support transitional migration
- Feature uses a feature key (DepreciationDifferencesFI) and upgrade codeunit to migrate data from legacy schema until CLEANSCHEMA33
- Helper procedures shared between migration paths avoid code duplication during transition period
- Extension integrates with Contoso Coffee demo data and hybrid cloud migration infrastructure
