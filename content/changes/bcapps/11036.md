# #11036 Ruleset hardening: promote four compatibility rules to Error

> Four AL compatibility rules (AA0052, PTE0018, AS0099, AW0009) are promoted from warnings to errors in the ruleset by removing overrides and adding targeted pragmas to existing code that preserves compatibility-sensitive patterns.

[Pull request](https://github.com/microsoft/BCApps/pull/11036) · merged into `main` (BC30) on 2026-09-07 by JesperSchulz · 64 files (+126 -19), 63 AL · other · tier official · **unreviewed** (machine-generated)

## What changed

- AA0052 and PTE0018 rules now error on cross-application permission-set inclusions, with 24 pragmas accepting existing compositions
- AS0099 promotes to error with 6 pragmas covering enum and field IDs where published IDs are preserved for backward compatibility
- AW0009 promotes to error with 33 pragmas on page fields backed by Blob/Bitmap types where Media conversion would require breaking schema changes
- Pragmas are narrowly scoped to actual violations found in analyzer diagnostics, not pattern-based scans
- Rule enforcement becomes stricter going forward, requiring contributors to avoid these patterns or justify narrowly-scoped exceptions
