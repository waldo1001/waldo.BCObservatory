# #10520 [Extensibility Request] issue 29640: use document type enum in blocked customer event

> Blocked customer check event now passes the extensible Gen. Journal Document Type enum value instead of converting to an option integer, preserving document type extensibility.

- Changed OnBeforeCheckBlockedCust event parameter from option to Gen. Journal Document Type enum
- Removed integer conversion to preserve enum extensibility for extensions
- Applied to W1 and all 10 country layers consistently
- Enables extensions to use custom document type values without reduction to integer
- Breaking: existing extensions can stop compiling or working.
