# #12142 [main] bug 652254 - Statutory Reporting Setup - new field for Official Name

> Czech statutory reporting now supports official company names up to 255 characters through a new Official Full Name field, with automatic migration from the legacy 30-character field and XML export updates.

[Pull request](https://github.com/microsoft/BCApps/pull/12142) · merged into `main` (BC30) on 2026-10-12 by v-janpopr · 8 files (+79 -23), 7 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- New Official Full Name field (255 characters) added to Statutory Reporting Setup
- Legacy Official Name field (30 characters) marked obsolete but retained for compatibility
- VAT Statement, VAT Control Report, and VIES Declaration exports now use new field
- Upgrade routine automatically copies existing Official Name values to new field
- Per-company upgrade tag ensures migration runs only once
- Behaviour changes for users or extensions.
