# #8679 [Shopify] Fix missing shop currency mapping on order transactions

> Shop currency code mapping on Shopify order transactions was accidentally removed in a previous commit and is now restored to ensure the Currency field displays correctly on the Order Transactions page.

[Pull request](https://github.com/microsoft/BCApps/pull/8679) · merged into `main` (BC30) on 2026-07-17 by nikolakukrika · 3 files (+435 -5), 2 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- The amountSet.shopMoney.currencyCode mapping to the Currency field was missing after a presentment currency support commit
- The field was being used without being populated, causing stale or empty currency values
- The fix re-adds the mapping alongside presentmentMoney to match the pattern already correctly used in amountRoundingSet
- Shopify GraphQL query already provided the data; it just needed to be read and mapped
- A test codeunit was added to verify the fix
- Behaviour changes for users or extensions.
