# #10487 Add integration event before inserting the cost allocation journal line

> Cost Allocation report now exposes an integration event that allows extensions to modify cost journal lines before they are inserted into the temporary journal.

## What changed

- New integration event OnWriteJournalLineOnBeforeInsertTempCostJournalLine added to Cost Allocation report
- Event fires before each temporary cost journal line is inserted
- Event passes the journal line by reference and the Cost Allocation Source for context
- Purely additive change with no impact on existing logic or data
- Provides extension point for customizing cost allocation data
