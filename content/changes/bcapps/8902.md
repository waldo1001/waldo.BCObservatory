# #8902 Bug 639568: Scope Subc. PO component location check to current prod order line

> Fixed a false warning when creating subcontracting purchase orders from routing lines on production orders with multiple lines sharing the same routing link code by scoping the component location check to the current line.

[Pull request](https://github.com/microsoft/BCApps/pull/8902) · merged into `main` (BC30) on 2026-07-28 by ChethanT · 2 files (+79 -0), 1 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- The warning about component locations appeared incorrectly when processing multiple routing lines with the same routing link code
- Root cause was that the component filter checked the production order and routing link code but not the specific production order line number
- Added line number filter to scope the check to only the current production order line being processed
- Test case added to verify the fix handles phantom components from earlier lines correctly
- Behaviour changes for users or extensions.
