# #9631  [Main]- "Filter by Attribute" action does not apply the filter under specific circumstances

> The 'Filter by Attribute' action on the Item List page now preserves user-applied filters instead of replacing them, fixing cases where filters were incorrectly lost during attribute filtering.

## What changed

- Attribute filtering now uses a temporary record filtering flow consistently
- User-applied filters (like Vendor No. conditions) are preserved and combined with attribute results
- Page record context is no longer reset during attribute filtering
- The fix applies across all regional versions of the Item List page
- Added test coverage for attribute filtering scenarios
