# #13893 Add index management actions to update statistics per table or index

> Administrators can now update database statistics directly from the Index Management page for either a complete table or a specific enabled index to optimize query performance.

[Pull request](https://github.com/microsoft/BCApps/pull/13893) · merged into `main` (BC30) on 2026-11-13 by mbaranovych · 2 files (+73 -0), 2 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Adds two new actions: update table statistics and update index statistics
- Requires confirmation and warns of temporary performance impact during update
- Automatically refreshes page to display updated statistics timestamp after completion
- SIFT indexes and disabled indexes are excluded from single-index updates
- Behaviour changes for users or extensions.
