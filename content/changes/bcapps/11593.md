# #11593  [29.x] - Bug 650481[Expense Agent] Closed travel requests are editable and are missing approver info.

> Travel requests can no longer be edited once closed, automatic approvals now record the approver details, and the requested-for user name is displayed on the travel request card.

## What changed

- Closed travel requests are now read-only to prevent unintended modifications
- Automatic approval process now captures and stores approver identity and timestamp
- Travel request card displays the name of the expense user the request was made for
- Fixes issues with spend request editability and missing approval metadata
- Includes test coverage for the fixed scenarios
