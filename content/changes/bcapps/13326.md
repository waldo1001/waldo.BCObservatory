# #13326 [Fabric] Clean up test events, app naming, authentication and telemetry

> The Fabric mirroring app makes five test-only IsHandled events in Fabric Platform Mgt internal, renames the app to Business Central Mirroring to Fabric (preview), removes the unused Key Vault first-party client-ID lookup, and replaces pseudo-audit telemetry events with real audit logs via Audit Log.LogAuditMessage.

[Pull request](https://github.com/microsoft/BCApps/pull/13326) · merged into `main` (BC30) on 2026-10-28 by onbuyuka · 10 files (+59 -109), 5 AL · refactor · tier official · reviewed (checked by Opus)

## What changed

- Five test-only IsHandled events in Fabric Platform Mgt are now internal; the test app keeps access via internalsVisibleTo
- App and test app renamed to Business Central Mirroring to Fabric (preview) and Business Central Mirroring to Fabric Tests, with dependency and build metadata updated
- Removed the unused Key Vault first-party client-ID lookup; custom-app auth reads GetCustomClientId() directly
- Eight pseudo-audit telemetry events replaced with Audit Log.LogAuditMessage using ApplicationManagement category; GetAuditDimensions() removed
- Diagnostic event IDs kept at direct Session.LogMessage calls
- Breaking: existing extensions can stop compiling or working.
