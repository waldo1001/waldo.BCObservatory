# #14527 Don't reuse a Payables Agent user that has no permissions in the company

> Payables Agent setup now verifies that a reused agent user has permissions in the current company before attempting to reuse it, preventing task failures when a company is deleted and recreated with the same name.

[Pull request](https://github.com/microsoft/BCApps/pull/14527) · merged into `main` (BC30) on 2026-11-26 by Explorer986 · 1 file (+18 -1), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Agent user lookup by name now includes a permissions check for the current company
- If an agent user lacks permissions in the current company, a new agent is created instead of reused
- Uses the same permissions verification the agent framework runs before accepting tasks
- Agents already linked in company setup continue to work as before
- Resolves task failures with 'agent has no access control permissions' error after company recreation
- Behaviour changes for users or extensions.
