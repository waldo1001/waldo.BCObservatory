# #12008 [29.x]-TDS Amount incorrectly calculated under Tax Information Factbox if you use Applies-to ID in the Indian version.

> Fixed TDS amount calculation in the Indian version when applying payments via Applies-to ID, which was incorrectly deducting the gross payment amount instead of the TDS base amount.

[Pull request](https://github.com/microsoft/BCApps/pull/12008) · merged into `releases/29.x` (BC29) on 2026-09-30 by v-maheshsharma · 2 files (+6596 -6625), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- The TDS use case (Applies-to ID) was overwriting the correctly summed TDS base amount with the gross payment amount
- Removed the erroneous expression to preserve AppliedAmount as the sum of posted TDS Base Amounts
- Updated use case version from 5 to 6 and registered version in TDSTaxConfiguration to ensure the corrected logic is re-imported
- TDS now calculates correctly for single and multiple applied payments
- Behaviour changes for users or extensions.
