# #9969 Add AL fast prompt interface and wrappers

> A new GetFastPrompt interface and AOAI Fast Prompt Response codeunit enable AL code to fetch blob-backed prompt templates from Edge Configuration Service with typed response handling.

[Pull request](https://github.com/microsoft/BCApps/pull/9969) · merged into `main` (BC30) on 2026-08-20 by Naveen26423 · 6 files (+231 -1), 4 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- New GetFastPrompt public procedure on Azure OpenAI codeunit for retrieving ECS-stored prompt templates
- New AOAI Fast Prompt Response codeunit (7789) provides typed response object with template, error code, and error message
- Integrates with DotNet ALCopilotFunctions layer to resolve fast prompts from ECS
- Supports error handling for invalid keys and unsupported authorization scenarios
- AI module object ID range expanded from 7788 to 7789
- Behaviour changes for users or extensions.
