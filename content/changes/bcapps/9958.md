# #9958 [Main] -Detail Trial Balance - Running Balance Incorrect When "Include Closing Entries" Is Disabled

> Fixed the Detail Trial Balance report so that excluded closing entries no longer incorrectly accumulate into the running balance column, ensuring displayed balances reconcile with visible entries.

## What changed

- Closing entries that are skipped from printing were still contributing to the running balance calculation
- Reordered the trigger to check and skip closing entries before accumulating amounts into GLBalance
- Running balance now accurately reflects only the entries actually displayed on the report
- Matches existing pattern used for reversed entries and corrections-only filters
- Added test cases across multiple localization layers to verify the fix
