# #10376 [Main] Fix unbalanced G/L when a Credit Memo is applied to a rejected/redraw…

> Fixed an issue where applying a sales credit memo to a rejected or redrawn bill in the Spanish (Cartera) version caused the Rejected Bills Account to become unbalanced due to duplicate posting.

## What changed

- Credit memos applied to rejected bills now post the Rejected Bills Account reclassification only once instead of twice
- Prevents duplicate posting by skipping application posting in PostDtldCustApplicationEntry when PostReceivableDocs already handles the rejected bill
- Ensures the Rejected Bills Account clears correctly and transactions remain balanced
- Includes test coverage for the cartera redraw scenario
- Behaviour changes for users or extensions.
