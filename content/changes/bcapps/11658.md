# #11658 [Shopify] Limit webhook subscription payload fields

> Shopify webhook subscriptions now request only the required fields (id for orders, admin_graphql_api_id and type for bulk operations) instead of receiving full webhook resources, reducing payload size and network overhead.

[Pull request](https://github.com/microsoft/BCApps/pull/11658) · merged into `main` (BC30) on 2026-09-22 by onbuyuka · 3 files (+15 -4), 2 AL · performance · tier official · **unreviewed** (model text not yet checked)

## What changed

- Added topic-specific includeFields parameters to webhook subscription GraphQL queries
- Orders/create webhooks now request only the id field
- Bulk operations finish webhooks now request admin_graphql_api_id and type fields
- Existing subscriptions are not affected; changes apply to new or recreated subscriptions
- No schema, permission, or upgrade changes required
