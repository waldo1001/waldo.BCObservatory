# #13883 [Shopify] Initialize return processing for existing shops on upgrade

> An upgrade migration initializes the Process Returns As field for existing Shopify shops to Credit Memo during upgrade, fixing incorrect refund document creation for shops that retained the default Quote value.

[Pull request](https://github.com/microsoft/BCApps/pull/13883) · merged into `main` (BC30) on 2026-11-12 by onbuyuka · 2 files (+95 -0), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Adds per-company upgrade migration to change only Quote/0 values to Credit Memo in existing shops
- Preserves valid Credit Memo and Return Order selections already configured by users
- Registers upgrade tag for new companies to prevent duplicate migrations
- Includes two regression tests for migration behavior and upgrade-tag guard logic
- Does not repair sales quotes already created before upgrade
- Behaviour changes for users or extensions.
