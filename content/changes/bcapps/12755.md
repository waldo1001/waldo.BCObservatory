# #12755 Flow Service Management: use native HttpClient instead of Web Request Helper

> Flow Service Management.GetEnvironments now calls the endpoint through native AL HttpClient instead of Web Request Helper. URL validation, the Bearer token as a secret, error handling and UTF-8 charset handling stay as before. The request is now subject to the extension's outbound HTTP policy.

[Pull request](https://github.com/microsoft/BCApps/pull/12755) · merged into `main` (BC30) on 2026-10-14 by darjoo · 1 file (+84 -4), 1 AL · refactor · tier official · reviewed (checked by Opus)

## What changed

- Replaces Web Request Helper.GetResponseTextUsingCharset with a local TryGetResponseText try function built on HttpClient
- Keeps http/https URI validation, the Bearer token sent as a secret, failure on a non-success status, and UTF-8 charset detection
- Removes the last caller of GetResponseTextUsingCharset, which is a prerequisite for obsoleting codeunit 1299 in #12615
- OnPrem-scoped code path with no public API change
