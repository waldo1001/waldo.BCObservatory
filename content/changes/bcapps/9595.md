# #9595 [main] Feature 640068 - Separate settings for automatic dimensions

> A new settings table and page enable separate management of automatic dimension creation configuration, introducing a "Do Not Create Default Dimension" option and decoupling this feature from the Default Dimension table.

[Pull request](https://github.com/microsoft/BCApps/pull/9595) · merged into `main` (BC30) on 2026-07-21 by v-janpopr · 16 files (+712 -223), 15 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- New AutoCreateDefaultDimCZA table stores automatic dimension creation settings independently
- New page provides dedicated UI for managing automatic dimension creation configuration
- Adds "Do Not Create Default Dimension" option to control when dimensions are created
- DimensionAutoCreateMgtCZA refactored to use new table and mark old methods obsolete
- Dimension auto-creation logic now conditional based on new setting
- Behaviour changes for users or extensions.
