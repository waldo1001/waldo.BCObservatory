# #11815 Improvements to E-Documents PO matching (E2E findings)

> E-Documents PO matching now correctly handles draft page warnings based on receipt status, prevents match state cleanup issues when resetting drafts, and shows finalized matches in the draft view for better visibility.

[Pull request](https://github.com/microsoft/BCApps/pull/11815) · merged into `main` (BC30) on 2026-09-24 by mynjj · 7 files (+557 -94), 6 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Draft page warnings update dynamically when draft changes through OnAfterGetCurrRecord
- Exceeded Quantity Received warning no longer appears for lines with Receipt on Invoice enabled
- DeleteAll trigger properly executes when resetting drafts to clean up PO matching state
- New finalized PO match table stores completed matches for informational display in draft without affecting matching logic
- Behaviour changes for users or extensions.
