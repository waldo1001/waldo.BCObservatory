# #13898 [29.x][ALL-E] Item Attributes (Decimal): Unable to Enter 0 After Clearing the Attribute Value to blank

> Decimal item attributes now correctly handle entering 0 after clearing a value to blank, by excluding blank records from numeric lookups.

[Pull request](https://github.com/microsoft/BCApps/pull/13898) · merged into `releases/29.x` (BC29) on 2026-11-12 by sanjmaurya · 2 files (+77 -2), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Blank decimal attribute records were incorrectly matched when searching for value 0 due to default numeric values
- Lookup logic now excludes blank attribute values when matching nonblank decimal values
- Regression tests added to verify blank versus zero behavior and zero entry after clearing and reopening
- Fixes inability to save decimal value 0 after clearing to blank on reopening the Item Attributes page
- Behaviour changes for users or extensions.
