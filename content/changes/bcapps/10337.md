# #10337 Let subscribers override the half-year new year date in SetHalfYearConventionMethod

> The OnBeforeSetHalfYearConventionMethod event now allows subscribers to override the accounting period start date used for half-year depreciation calculations by adding a trailing var parameter that subscribers can populate.

[Pull request](https://github.com/microsoft/BCApps/pull/10337) · merged into `main` (BC30) on 2026-08-19 by Explorer986 · 5 files (+35 -15), 5 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Event now includes a trailing var NewYearDateOverride parameter that subscribers can set
- When a subscriber sets the override, the base code uses that date instead of the accounting period start
- Maintains backward compatibility by keeping the existing event signature unchanged
- Applied consistently across all localization layers (W1, FR, GB, IT, RU)
- Fixes issue where subscribers could set NewYearDate but it was always overwritten
- Behaviour changes for users or extensions.
