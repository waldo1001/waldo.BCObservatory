# #13757 Fix stale report filename captions and cover language resolution

> Fixed a bug where the report filename resolver incorrectly returned true for nonexistent reports when the output value was already populated, and added language resolution coverage with regression tests.

[Pull request](https://github.com/microsoft/BCApps/pull/13757) · merged into `main` (BC30) on 2026-11-18 by gggdttt · 6 files (+274 -4), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Output is cleared before the metadata lookup, so nonexistent or zero report IDs now return false with empty output
- Existing language selection for the report name caption is unchanged; only test coverage was added for it
- Nine new AL regression tests cover explicit language, blank-code company default, caller-language restoration, translated and missing captions, and nonexistent reports
- Two test-only reports and a checked-in de-DE translation fixture avoid relying on installed Base Application translations
- Implementation comment now separates metadata resource selection from the report's effective rendering language
- Behaviour changes for users or extensions.
