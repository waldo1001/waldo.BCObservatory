# #9872 Add missing telemetry event IDs to E-Document Session.LogMessage calls

> Added missing telemetry event IDs to 21 Session.LogMessage calls in E-Document and Avalara connector apps to enable proper aggregation and monitoring in the telemetry pipeline.

[Pull request](https://github.com/microsoft/BCApps/pull/9872) · merged into `main` (BC30) on 2026-08-03 by Groenbech96 · 7 files (+21 -21), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Allocated 21 unique telemetry event IDs (0000UVW - 0000UWG) to untagged Session.LogMessage calls
- Avalara connector was previously invisible in telemetry queries by event ID despite 20 logging calls
- Core E-Document PEPPOL handler had one additional missing event tag
- Tags were centrally reserved to prevent collision risk
- Enables standard telemetry pipeline filtering and alerting by event ID
