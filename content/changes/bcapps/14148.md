# #14148 Only skip draft preparation for the Payables Agent's own e-documents with agent-driven line matching

> Draft preparation skip now applies only to the Payables Agent's own e-documents when agent-driven line matching is enabled, restoring normal preparation for other e-document services.

[Pull request](https://github.com/microsoft/BCApps/pull/14148) · merged into `main` (BC30) on 2026-11-18 by Explorer986 · 2 files (+98 -4), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- With the agent-driven line matching experiment on, draft preparation is skipped only for e-documents of the AGENT E-Document service
- E-documents from other services, such as PEPPOL XML, again get a vendor, purchase order, line matching and VAT posting group in the draft
- The experiment check and the agent service check are now separate conditions
- Nothing changes when the experiment is off
- AGENT service code duplicated as a label because Payables Agent depends on E-Document Core
- Behaviour changes for users or extensions.
