# #10386 [Agent Archiving] Prevent archived custom agents from being modified

> Archived custom agents can now be viewed for auditing but are protected from modification across all authoring surfaces, blocking direct changes and closing persistence gaps in the agent card and instruction history.

[Pull request](https://github.com/microsoft/BCApps/pull/10386) · merged into `main` (BC30) on 2026-08-21 by krupybalu · 7 files (+90 -4), 6 AL · feature · tier official · **unreviewed** (machine-generated)

## What changed

- Archived agents are now read-only in the configure agent page with Update action disabled
- Test agent page blocks archived agents with an error instead of opening, since the same information is available elsewhere
- Fixed two persistence gaps: instruction drill-down from agent card now opens read-only, and instruction history rename no longer modifies archived agents
- All modifications are conditional on archived state, so non-archived agents and failed lookups remain unaffected
- No schema, permission, or upgrade impact; changes are isolated to the Agent Design Experience app
- Behaviour changes for users or extensions.
