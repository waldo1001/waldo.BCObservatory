# #12432 [AB#647643] Retain remote files and safely retire verified local references

> Follow-up to the external storage retention fix that was already merged in #11733. Adds regression tests for quote posting, Copy/Move and retirement guards, updates the configuration guidance, shows retention status on the Document Attachment - External page, and removes unused deletion telemetry.

[Pull request](https://github.com/microsoft/BCApps/pull/12432) · merged into `main` (BC30) on 2026-10-14 by JesperSchulz · 8 files (+1300 -52), 3 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- The core logic that keeps remote files and safely retires local references was already merged in #11733
- Adds a retention-status display to the Document Attachment - External page
- Adds regression tests for quote to order posting, Copy/Move with byte checks, and retirement guards
- Removes unused deletion telemetry and updates the README configuration guidance
- Trade-off: remote files are kept even when unshared, so storage use can grow
- Behaviour changes for users or extensions.
