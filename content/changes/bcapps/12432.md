# #12432 [AB#647643] Retain remote files and safely retire verified local references

> External storage now retains remote files instead of deleting them when removing attachments, preventing data loss when attachments are shared between documents. Explicit retirement clears only local metadata after verifying the attachment and its content remain intact.

[Pull request](https://github.com/microsoft/BCApps/pull/12432) · merged into `main` (BC30) on 2026-10-14 by JesperSchulz · 8 files (+1300 -52), 3 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Remote files are retained rather than deleted to prevent losing shared attachments
- Attachment deletion cannot affect other attachments' shared files
- Explicit retirement clears only local external metadata after locking and verification
- Stronger test coverage added for quote posting, copy/move operations and retirement flows
- Unused deletion telemetry removed
- Behaviour changes for users or extensions.
