# #11673 #[MAIN]-Not enough inventory available at vendor location for this order

> India Localization subcontracting receipt now prevents duplicate component consumption that occurred when both standard manufacturing posting and the Delivery Challan process posted consumption simultaneously.

## What changed

- Component consumption was posted twice: once by standard manufacturing flow and once by India Localization Delivery Challan process
- Solution assigns Subcontracting Order No. to identify India-specific output journal lines and suppresses automatic flushing for these lines
- Preserves normal production flushing for other scenarios while preventing inventory errors from doubled consumption
- Fixes incorrect posting behavior that could cause 'not enough inventory' errors at production location
- Maintains output posting, capacity posting, vendor-location consumption, and item tracking functionality
