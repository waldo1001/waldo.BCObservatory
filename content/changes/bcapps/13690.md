# #13690 [Main] - Bug 657870: [ExpenseAgent] Allow assigning interim approvers via API before expense reports are pending approval

> Interim approvers can now be assigned via API before an expense report is submitted for approval, allowing them to be configured on Released reports without changing the active approver.

[Pull request](https://github.com/microsoft/BCApps/pull/13690) · merged into `main` (BC30) on 2026-11-06 by v-rohangarg20 · 3 files (+216 -17), 2 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Interim approver assignment enabled on Released and Pending Approval reports, not just Pending Approval
- On Released reports, interim approver is saved without changing report status or active approver until submission
- Conflicts revalidated when routing on submit, resubmit, or reopen to prevent interim approver from being final approver
- Assignment remains blocked on Open, Interim Approved, and Approved reports with updated error messages
- Added comprehensive regression tests for pre-submission assignment, two-stage approval flow, and validation scenarios
- Behaviour changes for users or extensions.
