# #10348 Adding a Power BI workspace to Company Information to be used when deploying reports

> Company Information now supports configuring a Power BI Workspace to serve as the target destination for deploying Power BI reports from Business Central.

[Pull request](https://github.com/microsoft/BCApps/pull/10348) · merged into `main` (BC30) on 2026-09-10 by mynjj · 51 files (+1342 -81), 48 AL · feature · tier official · **unreviewed** (machine-generated)

## What changed

- Added a Power BI Workspace field to Company Information's Reporting section
- Workspace configuration is used as the deployment target for Deployable reports
- New method surfaces added to Power BI service interfaces to support workspace management
- Workspace lookup page added to allow selecting from available Power BI workspaces
- Changes applied across all localization layers (W1, NA, GB, DE, FR, etc.)
- Behaviour changes for users or extensions.
