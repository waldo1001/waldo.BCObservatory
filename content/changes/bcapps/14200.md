# #14200 Refresh the purchase order match warnings of a draft line as soon as it is edited

> Purchase order match warnings now refresh immediately when a draft line is edited, eliminating stale warning messages after the user corrects values like unit cost.

## What changed

- Line is saved and warnings recalculated before page refresh when editing Quantity, Direct Unit Cost, Line Discount, Line Type, No., or Unit of Measure
- Corrected lines now show 'No warnings' status immediately instead of retaining previous warnings
- Warnings column disappears once no line has warnings
- Aligns behavior with purchase order subform which saves before recalculating totals
- Low risk change with minimal performance impact
- Behaviour changes for users or extensions.
