# #12429 Skip enabling incomplete existing retention policies on install/upgrade

> Skip enabling incomplete retention policies during install and upgrade when the existing setup would fail validation, preventing tenant upgrades from blocking on Dataverse Entity Change records with missing retention periods.

## What changed

- Guard skips enabling retention policy when record is already enabled, applies to all records without a retention period, or uses filters with no enabled lines
- Preserves customer's existing incomplete setup instead of blocking upgrade with validation error
- Added read permission on Retention Policy Setup Line to codeunit 3999
- Changed EnableRetentionPolicySetup from local to internal visibility for testing
- Covers Dataverse Entity Change, Integration Synch. Job and Integration Synch. Job Errors tables
