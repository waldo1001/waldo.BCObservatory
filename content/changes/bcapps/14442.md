# #14442 Offer the Payables Agent again in a company recreated with the same name

> The Payables Agent is now offered again in the plus menu when a company is recreated with the same name, by checking only the agent linked in the company setup instead of searching by user name.

[Pull request](https://github.com/microsoft/BCApps/pull/14442) · merged into `main` (BC30) on 2026-11-25 by Explorer986 · 2 files (+14 -11), 2 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Only the agent linked in the company's setup counts as set up for the plus menu and Purchase Invoices actions
- Deleted companies keep their agent user, which previously made a recreated company with the same name look already set up
- Setup still locates the existing agent by user name and reuses it, so no duplicate agent user is created
- Setup, intake and upgrade find the agent as before
- Behaviour changes for users or extensions.
