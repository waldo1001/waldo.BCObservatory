# #10247 [SOA] Show Cc recipients on email messages

> Sales Order Agent email cards now display Cc recipients in a read-only field, matching Business Central's Email Viewer formatting, with special handling for mapped-contact replies and calculation failures.

[Pull request](https://github.com/microsoft/BCApps/pull/10247) · merged into `main` (BC30) on 2026-09-22 by attilatoury · 4 files (+84 -0), 4 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- Added Cc field to Email Details showing semicolon-separated recipients
- Incoming messages show original inbox Cc list
- Mapped outgoing replies filter Cc against To recipients and mapped contact
- Blank Cc displayed when source data cannot be resolved instead of using unfiltered list
- Added Email Inbox read permissions to fix license-level errors when opening agent timeline cards
- Behaviour changes for users or extensions.
