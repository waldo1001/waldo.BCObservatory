# #10431 [Agent Archiving] Fix broken reference links to archived agents and their tasks

> Reference links to archived agents and their tasks now open the Agent Card and Agent Task Log Entries respectively instead of failing or showing unrelated agents, while non-archived agents follow the same navigation paths as before.

[Pull request](https://github.com/microsoft/BCApps/pull/10431) · merged into `main` (BC30) on 2026-08-24 by krupybalu · 7 files (+131 -14), 6 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- Archived agents are now reachable for auditing through proper navigation surfaces
- Agent task references on Inbound E-Documents and agent drill-downs now route to appropriate pages when agents are archived
- Two internal helper methods route navigation based on agent substate to either task pane or card/log views
- Non-archived agents experience no behavior change
- External apps can replicate the logic using existing public APIs without waiting for client-side changes
- Behaviour changes for users or extensions.
