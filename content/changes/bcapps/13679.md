# #13679 [E-Document Core] Grant Execute on the status factbox, PDF preview and Navigate handler

> The E-Document Core permission set now grants Execute permission on the status factbox page, picture preview page, and navigate handler codeunit to prevent permission errors when users access E-Document components on standard pages.

[Pull request](https://github.com/microsoft/BCApps/pull/13679) · merged into `main` (BC30) on 2026-11-18 by Franco111000 (community contribution) · 2 files (+38 -0), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Added Execute permission on Page 6187 (E-Doc. Status FactBox), Page 6111 (Inbound E-Doc. Picture), and Codeunit 6247 (E-Doc. Navigate Handler) to the E-Document Core permission set
- Resolves error messages for users with custom permission sets lacking page wildcards when opening Sales Orders with E-Document components
- These objects are embedded as parts on 25 standard pages but were missing from the permission set
- Added test to verify the permission set includes Execute on these objects
- Affects E-Document Core and inherited roles like E-Document Core - Read, User, Admin, Edit, and Basic
- Behaviour changes for users or extensions.
