# #11163 [29.x]Adjustment Amount is not accurate in the Exch. Rate Adjmt. Ledger Entries page if an Unrealized Gain gest registered and a second adjustment turns into a Loss.

> The Exchange Rate Adjustment process now correctly calculates individual adjustment amounts in ledger entries when unrealized gains reverse into losses, instead of incorrectly using cumulative amounts.

- Adjustment Amount now accurately reflects per-row values in Exchange Rate Adjustment Ledger Entries page
- Addresses scenario where unrealized gain reverses and subsequent adjustment becomes a loss
- Added comprehensive test coverage for the correction
