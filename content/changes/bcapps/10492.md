# #10492 [SOA] Restrict direct deletion of contact overrides

> The SOA Task Contact Override table restricts direct deletion by removing the inherent delete permission, while preserving legitimate deletions through validated code paths.

- Inherent delete permission removed from table to prevent unauthorized direct deletion via RecordRef or similar mechanisms
- Deletion still available through SOA Filters Impl codeunit which validates access before removing records
- Insert, modify, read and contact-routing operations unchanged
- Prevents bypassing contact-mapping authorization checks
