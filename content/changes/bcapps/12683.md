# #12683 [API tests] Return shipment PDF selection and pdfDocument test isolation

> The return shipment PDF handler now uses the P.Ret.Shpt. report selection instead of P.Return, so the API can produce a PDF for a posted return shipment. Three API pdfDocument tests are fixed by disabling test isolation and creating their own documents, and they are removed from the disabled list.

[Pull request](https://github.com/microsoft/BCApps/pull/12683) · merged into `main` (BC30) on 2026-11-04 by t-prda · 5 files (+14 -28), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Return Shpt. PDF Doc.Handler uses P.Ret.Shpt. instead of P.Return report selection usage
- Before this fix, expanding pdfDocument on purchase return shipments returned HTTP 400
- RequiredTestIsolation set to Disabled on the three API test codeunits so data is committed before the HTTP call
- Blanket order and quote tests create their own one-line document
- Three tests removed from the APIV2 disabled-tests list
- Behaviour changes for users or extensions.
