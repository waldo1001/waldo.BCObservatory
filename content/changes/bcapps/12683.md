# #12683 [API tests] Return shipment PDF selection and pdfDocument test isolation

> Return Shipment PDF generation now uses the correct report selection, and API tests for PDF document expansion are fixed by disabling transaction isolation and improving test data reuse.

[Pull request](https://github.com/microsoft/BCApps/pull/12683) · merged into `main` (BC30) on 2026-11-04 by t-prda · 5 files (+14 -28), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Return Shipment PDF handler corrected to use the P.Ret.Shpt. report selection instead of P.Return for posted return shipments
- API tests for blanket orders and purchase quotes disabled transaction isolation to prevent locking conflicts with HTTP calls
- Tests now create their own isolated documents instead of reusing existing data
- Three previously excluded tests re-enabled in the test suite
- Behaviour changes for users or extensions.
