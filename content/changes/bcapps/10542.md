- Added interim and final approver fields to expense report headers with validation rules

- UI and API support for assigning interim approvers, restricted to agent mode
- Guards prevent interim approver conflicts (not submitter, not final approver, required selection)
- Activity logging tracks interim approver assignments and interim approvals
