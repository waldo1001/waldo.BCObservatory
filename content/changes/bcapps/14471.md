# #14471 Fix incoming document attachment overview Line No. type

> The Line No. field in the Inc. Doc. Attachment Overview table is changed from Integer to BigInteger to match the corresponding field in Incoming Document Attachment after 64-bit migration.

## What changed

- Field type mismatch resolved between two related tables after 64-bit migration
- Line No. field now consistently uses BigInteger (8 bytes) instead of Integer (4 bytes)
- Prevents data narrowing when transferring fields between the tables
- Overview table is temporary, so no data migration needed
- Existing regression test TestFieldDefinitionsMatch validates the fix
