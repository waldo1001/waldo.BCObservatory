# #8085 [MCP] Server Features in MCP configuration: API Tools, Dynamic Tool Mode, Data Query Tools (Preview)

> Adds a Server Features surface to MCP configuration allowing admins to enable Data Query Tools, Dynamic Tool Mode, and API Tools through interface-based, extensible handlers. Each feature controls its own activation, settings, and system tools without requiring page modifications.

[Pull request](https://github.com/microsoft/BCApps/pull/8085) · merged into `main` (BC30) on 2026-07-27 by onbuyuka · 26 files (+1274 -276), 23 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- New interface-based feature system where enum values bind to handler codeunits for activation, settings, and system tool loading
- Dynamic Tool Mode now requires API Tools to be enabled first and is displayed indented as a sub-feature
- Available APIs list allows curated selection of both API pages and queries through a unified lookup
- System Tools list-part dynamically populates by iterating active features and calling their handlers
- Configuration list gains Set as Default / Clear Default actions and shows read-only API Tools / Data Query Tools status columns
- Behaviour changes for users or extensions.
