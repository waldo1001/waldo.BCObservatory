# #9601 Reset workflow templates no longer removes steps from active workflows

> Reset workflow templates no longer removes steps from active workflows. The fix prevents data loss by scoping step deletion to template workflows only, not derived workflows sharing the same code prefix, and adds confirmation dialog for safety.

[Pull request](https://github.com/microsoft/BCApps/pull/9601) · merged into `main` (BC30) on 2026-07-27 by darjoo · 3 files (+124 -10), 2 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- Prevents accidental deletion of steps in active workflows created from templates when resetting templates
- Root cause was overly broad filter that matched derived workflows by code prefix instead of exact template code
- Fix iterates template workflows and deletes steps only for exact template codes
- Adds confirmation dialog to Reset Microsoft Templates action for user safety
- Two regression tests added to prevent recurrence
- Behaviour changes for users or extensions.
