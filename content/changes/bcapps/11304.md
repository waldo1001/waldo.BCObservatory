# #11304 [Master]-Validation of the "No." field on the sales order additionally re-validates the Unit of Measure Code

> Validation of the item number field on sales lines now prevents duplicate production order status checks when the unit of measure code is re-validated, fixing repeated modal dialogs and write-transaction errors.

[Pull request](https://github.com/microsoft/BCApps/pull/11304) · merged into `main` (BC30) on 2026-09-17 by DhavalMore88 (community contribution) · 14 files (+358 -12), 13 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Unit of Measure Code validation during No. validation now runs with status checks suspended
- Quantity and Shipment Date validations skip the production order status check when checks are suspended
- Check Prod. Order Status codeunit respects the suspended check so the warning appears only once
- Changes applied to Sales Line in W1 and all localization layers
- Includes tests for the scenario
- Behaviour changes for users or extensions.
