# #12064 Support SharePoint paths containing hash and percent characters

> SharePoint connector now supports file paths containing hash and percent characters by adding separate decoded-path APIs backed by ResourcePath endpoints, with a new REST Base Folder Path Format setting to control URL decoding behavior.

[Pull request](https://github.com/microsoft/BCApps/pull/12064) · merged into `main` (BC30) on 2026-10-07 by JesperSchulz · 13 files (+700 -23), 8 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- New decoded-path SharePoint Client APIs backed by ResourcePath endpoints handle names containing # and %
- The connector uses them for file upload, download, delete, listing and existence checks, and for folder operations
- New REST Base Folder Path Format setting defaults to URL (also for existing rows); Decoded Path keeps literal names like Reports%20Archive
- Existing URL-based public client APIs are unchanged and Graph accounts are not affected
- Attachment paths and filenames are never unescaped; only the base folder and the site prefix taken from the URL are decoded
- Behaviour changes for users or extensions.
