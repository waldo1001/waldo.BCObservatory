# #11383 [SOA] Fix "The Order Promising Setup does not exist." crash when setting quote quantity

> The Sales Order Agent now handles missing Order Promising Setup gracefully by skipping capable-to-promise calculations and preventing misconfiguration through a setup confirmation dialog on the SOA Setup page.

[Pull request](https://github.com/microsoft/BCApps/pull/11383) · merged into `main` (BC30) on 2026-09-15 by VolodySyn · 3 files (+37 -7), 3 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- Agent no longer crashes with 'Order Promising Setup does not exist' error when setting quote quantities
- Capable-to-promise calculation is skipped when Order Promising Setup is absent
- Enabling 'Include capable to promise' toggle on SOA Setup page now checks for and offers to create the setup
- Graceful degradation shows availability notification instead of error for agents without order promising configuration
- No behavior change when Order Promising Setup already exists
- Behaviour changes for users or extensions.
