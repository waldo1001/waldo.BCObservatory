# #10799 Remove OnPrem scope from Table 1226 "Payment Export Data".SetSwissExport

> The SetSwissExport procedure on the Payment Export Data table is now callable from Cloud extensions by removing its OnPrem scope restriction, making it consistent with other setters and the SwissExport field itself.

[Pull request](https://github.com/microsoft/BCApps/pull/10799) · merged into `main` (BC30) on 2026-10-05 by he-d (community contribution) · 1 file (+0 -1), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Removed [Scope('OnPrem')] attribute from SetSwissExport method
- Resolves compilation error AL0296 for Cloud-targeting extensions using SetSwissExport
- Makes SetSwissExport consistent with other setters on the same table that already support Cloud
- No changes to the procedure logic, only scope restriction removed
- Maintains backward compatibility with existing OnPrem callers
