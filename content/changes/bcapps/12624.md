# #12624 Align styling in Document Report Experience themes, HF designs and bodies

> Styling of Word report themes, header/footer designs and bodies is aligned so they work consistently together, with tighter table spacing, updated font sizes, and removal of unused styles.

[Pull request](https://github.com/microsoft/BCApps/pull/12624) · merged into `main` (BC30) on 2026-11-04 by MSlenejennum · 18 files (+4 -4), 1 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- 17 binary Word files updated: 3 themes (Calm, Default, Playful), 11 header/footer designs and 3 report bodies
- Themes drop the embedded header/footer parts and unused styles; BC Data Table gets tighter spacing and all BC table styles use tabular numbers
- Normal style in header/footer designs goes from 8 pt to 12 pt, and bodies no longer hard-code a font size
- External header/footer designs no longer show a runtime date; InternalModern uses a Word DATE field
- Bodies gain new HideTableRowIfEmpty controls that hide empty table rows
- Behaviour changes for users or extensions.
