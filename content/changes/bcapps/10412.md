# #10412 Fixes in Excel reports for Aged Accounts.

> Aged Accounts Excel reports now properly handle customers and vendors with historical balances outside the selected date range and correctly assign transactions to aging buckets.

[Pull request](https://github.com/microsoft/BCApps/pull/10412) · merged into `main` (BC30) on 2026-08-24 by mynjj · 4 files (+246 -84), 3 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Added a new aging bucket from 0D to cover all historical activity before the main period
- Fixed bucket assignment logic for ending dates by using index-based retrieval instead of descending list comparison
- Removed due date filter to include all outstanding balances regardless of due date status
- Filtering for customers/vendors without due balance now considers full history, not just the selected period
- Added comprehensive tests for historical balances, bucket assignment, and not-yet-due transactions
- Behaviour changes for users or extensions.
