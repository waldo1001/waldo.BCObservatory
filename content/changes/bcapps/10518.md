# #10518 [Extensibility Request] issue 30338: expose internal put-away line event

> Report 7305 exposes a new event that allows extensions to receive and adjust the internal put-away line record after the dataitem filters are prepared.

[Pull request](https://github.com/microsoft/BCApps/pull/10518) · merged into `main` (BC30) on 2026-08-24 by AleksandricMarko · 1 file (+6 -1), 1 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- New event OnAfterWhseInternalPutAwayLineOnPreDataItem provides access to the internal put-away line record
- Event fires at the end of the dataitem's OnPreDataItem trigger
- Enables extensions to modify the actual source record during put-away line creation
- Addresses limitation where previous event used warehouse worksheet line instead
