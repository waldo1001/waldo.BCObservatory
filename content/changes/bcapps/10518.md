- New event OnAfterWhseInternalPutAwayLineOnPreDataItem provides access to the internal put-away line record
- Event fires at the end of the dataitem's OnPreDataItem trigger
- Enables extensions to modify the actual source record during put-away line creation
- Addresses limitation where previous event used warehouse worksheet line instead
