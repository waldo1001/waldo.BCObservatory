# #11998 [main] It should not be possible to post invoices with a non-existing Posting Setup combination because it creates trouble with Adjust for Payment Discount.

> The system now validates that a General Posting Setup combination exists before posting journal invoices, preventing issues that arise later when processing payment discounts.

[Pull request](https://github.com/microsoft/BCApps/pull/11998) · merged into `main` (BC30) on 2026-10-19 by Shikhverma · 13 files (+515 -22), 11 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Gen. Jnl.-Check Line now checks that a General Posting Setup row exists for the business/product posting group pair
- Combinations set up with a blank business posting group are still allowed; missing combinations are rejected
- G/L journal invoices can no longer post with a product posting group that has no matching General Posting Setup
- Prevents the failure that used to show up later when posting a payment discount
- The check is added in W1 and several country layers, with tests in W1 and CZ
- Behaviour changes for users or extensions.
