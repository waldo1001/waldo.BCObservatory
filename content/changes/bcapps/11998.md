# #11998 [main] It should not be possible to post invoices with a non-existing Posting Setup combination because it creates trouble with Adjust for Payment Discount.

> The system now validates that a General Posting Setup combination exists before posting journal invoices, preventing issues that arise later when processing payment discounts.

[Pull request](https://github.com/microsoft/BCApps/pull/11998) · merged into `main` (BC30) on 2026-10-19 by Shikhverma · 13 files (+515 -22), 11 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Added validation in Gen. Jnl.-Check Line to ensure General Posting Setup row exists for the business/product posting group pair
- Allows configurations with a blank business posting group while rejecting missing combinations
- Prevents invoices from posting with only a product posting group but no matching General Posting Setup
- Fixes issues that surface when posting payment discounts with invalid posting setup combinations
- Applied across all localization layers and added test coverage
- Behaviour changes for users or extensions.
