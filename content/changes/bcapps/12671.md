# #12671 Fix extension settings actions and repeated marketplace installation

> Extension Settings page now disables misleading New and Delete operations, exposes proper extension lifecycle actions like Uninstall, and prevents repeated marketplace installation prompts after app refresh.

[Pull request](https://github.com/microsoft/BCApps/pull/12671) · merged into `main` (BC30) on 2026-10-15 by SBalslev · 7 files (+318 -8), 4 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- New and Delete actions disabled while keeping HTTP client settings editable
- New promoted actions added for Install, Uninstall, Unpublish, Set up, Download Source, and Learn More
- Marketplace wizard skips already-installed apps to prevent re-installation requests
- Card refreshes when returning from lifecycle operations
- Regression tests added and module documentation updated
- Behaviour changes for users or extensions.
