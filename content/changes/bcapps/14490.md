# #14490 [Master]-Repeated partial return posting reuses first credit memo and corrupts original order quantities

> Fixed repeated partial return postings that were incorrectly reusing the first credit memo and corrupting original order quantities. The fix ensures each posting uses the current credit memo to update order quantities correctly.

[Pull request](https://github.com/microsoft/BCApps/pull/14490) · merged into `main` (BC30) on 2026-11-26 by neeleshsinghal · 14 files (+252 -60), 12 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Repeated partial returns reused the first credit memo instead of the latest posted one
- This corrupted the quantities on the original sales order
- Sales-Post now updates order quantities from the current posting's credit memo held in a global variable
- Change applied to Sales-Post in the W1, APAC, BE, CH, ES, FI, FR, GB, IT, NA, NO and RU layers
- Regression tests added in ERM Copy Purch Sales Doc (W1 and APAC)
- Behaviour changes for users or extensions.
