# #14490 [Master]-Repeated partial return posting reuses first credit memo and corrupts original order quantities

> Fixed repeated partial return postings that were incorrectly reusing the first credit memo and corrupting original order quantities. The fix ensures each posting uses the current credit memo to update order quantities correctly.

[Pull request](https://github.com/microsoft/BCApps/pull/14490) · merged into `main` (BC30) on 2026-11-26 by neeleshsinghal · 14 files (+252 -60), 12 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Repeated partial returns were reusing the first credit memo instead of the latest one
- This caused original sales order quantities to be corrupted incorrectly
- Solution uses the current posting's credit memo from a global variable to update quantities
- Fix applied across Sales-Post codeunit in all localization layers
- New test cases added to validate the correction
- Behaviour changes for users or extensions.
