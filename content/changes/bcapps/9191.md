# #9191 Bug 641232: [Subcontracting] Offer to install missing apps instead of hard error when disabling Legacy Subcontracting

> In the IT localization, disabling Legacy Subcontracting on Manufacturing Setup no longer stops with a hard error when the Subcontracting or IT Subcontracting Migration app is missing. It now offers to install the missing app; the user then runs the disable action again.

[Pull request](https://github.com/microsoft/BCApps/pull/9191) · merged into `main` (BC30) on 2026-07-08 by alexei-dobriansky · 1 file (+23 -6), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Replaced hard error with inline app installation offer for missing Subcontracting or IT Subcontracting Migration apps
- Uses ExtensionManagement.InstallMarketplaceExtension pattern, triggering session reload to re-run the disable process
- Pre-Check action also provides install option instead of dead-ending
- Method signature unchanged to maintain compatibility with existing cross-app calls
- Removed unused error labels for app-not-installed scenarios
- Behaviour changes for users or extensions.
