# #10630 Extend OnBeforeCheckBankAcc to skip specific bank reversal checks

> The OnBeforeCheckBankAcc event in the Reversal Entry table gains two Boolean parameters that let extensions skip the Open and Statement No. validations independently when reversing bank account ledger entries.

[Pull request](https://github.com/microsoft/BCApps/pull/10630) · merged into `main` (BC30) on 2026-08-28 by Explorer986 · 11 files (+539 -32), 8 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- Two new Boolean parameters added to OnBeforeCheckBankAcc event to control Open and Statement No. validation checks
- Extensions can now skip specific bank reversal checks without handling the entire validation
- Event signature extended with trailing parameters while maintaining compatibility with existing subscribers
- Changes applied across all regional layers (W1, APAC, BE, CH, ES, FR, IT, RU, SE)
- New tests added to verify skipping individual checks during bank entry reversal
- Behaviour changes for users or extensions.
