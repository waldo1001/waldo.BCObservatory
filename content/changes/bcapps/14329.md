# #14329 Optimizing check for PA eligibility

> The Payables Agent eligibility check now uses a more efficient query strategy to avoid unnecessary slowdowns when opening the Purchase Invoice page by leveraging an existing database index on Posting Date instead of relying on systemCreatedAt.

[Pull request](https://github.com/microsoft/BCApps/pull/14329) · merged into `main` (BC30) on 2026-11-21 by mynjj · 2 files (+39 -5), 2 AL · performance · tier official · reviewed (checked by Opus)

## What changed

- A new query checks Payables Agent eligibility using Posting Date instead of systemCreatedAt
- Uses the existing BaseApp key on Posting Date, then iterates the results to match the user ID
- Limits how many records are loaded from SQL so the check stays time-bounded
- Speeds up opening the Purchase Invoice page and the agent runtime eligibility check
- The heuristic is less accurate, so the set of eligible users may differ slightly
- Behaviour changes for users or extensions.
