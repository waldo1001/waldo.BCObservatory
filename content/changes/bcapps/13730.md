# #13730 [Expense Agent] Initialize missing vendor numbering after upgrade

> A per-company upgrade initializes missing vendor number series for the Expense Agent, ensuring merchant-driven expense creation works after upgrades when defaults were applied but vendor numbering remained blank.

[Pull request](https://github.com/microsoft/BCApps/pull/13730) · merged into `main` (BC30) on 2026-11-09 by Alexander-Ya · 7 files (+423 -30), 5 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Adds a tagged per-company upgrade step to the existing upgrade codeunit that fills only blank Expense Vendor Nos. values
- Vendor-only initializer preserves configured number series and existing counters
- Repairs the same missing value through default settings and the setup wizard
- Enables the default-settings action when the vendor numbering field is empty
- Adds tests for upgrade, number series preservation and merchant expense creation (not yet run per the description)
- Behaviour changes for users or extensions.
