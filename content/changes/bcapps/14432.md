# #14432 [Main]- Item Journal approval link fails after approver switches batches

> Fixed item journal approval links failing when approvers had previously accessed a different batch. The IsOpenedFromBatch method now correctly uses the record's template and batch instead of falling back to the user's saved batch.

[Pull request](https://github.com/microsoft/BCApps/pull/14432) · merged into `main` (BC30) on 2026-11-27 by DhavalMore88 (community contribution) · 9 files (+235 -40), 8 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Item Journal's IsOpenedFromBatch now matches General Journal's implementation
- When no batch filter is set, the method uses the record's own batch name
- Special filter characters in batch names are properly quoted
- Approval email links now navigate to the correct batch for the approver
- Applied to W1 and all localized versions (APAC, CH, ES, FR, GB, IT, RU)
- Behaviour changes for users or extensions.
