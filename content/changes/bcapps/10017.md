# #10017 [Master] - Bug 644751 Moving an expense report line to another report wrongly reports a duplicate

> Moving an expense report line to another open expense report no longer raises a false duplicate expense violation. The duplicate check no longer compares the moved line against its own source line.

[Pull request](https://github.com/microsoft/BCApps/pull/10017) · merged into `main` (BC30) on 2026-08-24 by v-rohangarg20 · 1 file (+2 -2), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- The duplicate check no longer treats a moved line as a duplicate of its originating line
- Removes false duplicate warnings when a line is moved between open expense reports
- Real duplicates within or across reports, including posted ones, should still be detected
- Small change (+2 -2) in the Expense Report Line table of the Expense Agent app
- Behaviour changes for users or extensions.
