# #10290 [Main] -Drop shipment undo receipt fails for service and non-inventory items.

> Undo receipt and undo shipment operations now work correctly for drop shipments involving service and non-inventory items by removing unnecessary cost application filters and adding a fallback lookup method through drop shipment links.

[Pull request](https://github.com/microsoft/BCApps/pull/10290) · merged into `main` (BC30) on 2026-08-18 by DhavalMore88 (community contribution) · 4 files (+168 -10), 3 AL · fix · tier official · **unreviewed** (machine-generated)

## What changed

- Removed 'Cost Application' filter from drop shipment application entry lookup to include cost-less entries for non-inventoriable items
- Added null check when finding item application entries to skip missing records instead of erroring
- Implemented fallback method to locate sales shipment lines through drop shipment document links when item ledger entry path fails
- Enables both undo shipment and undo receipt operations to complete successfully for service and non-inventory drop shipments
- Behaviour changes for users or extensions.
