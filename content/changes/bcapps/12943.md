# #12943 DK VAT Return Periods regression fix for frequency-aware parsing

> The Danish VAT Return Periods parser now correctly handles the official SKAT API XML structure, enabling proper parsing of VAT reporting periods instead of failing with zero records inserted.

[Pull request](https://github.com/microsoft/BCApps/pull/12943) · merged into `main` (BC30) on 2026-10-20 by mynjj · 12 files (+620 -108), 2 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Fixed the Get VAT Periods parser, which expected the wrong XML shape and inserted 0 records even when SKAT returned valid periods
- XML shape now follows SKAT's official documentation and sample client schema
- Filing deadline now comes from AngivelseFristKalenderFristDato instead of the optional BetalingDato
- Added test XML resources for quarterly periods, frequency changes, differing filing and payment dates, missing data and unsupported frequencies
- Expanded the tests to check the parser against these expected shapes
- Behaviour changes for users or extensions.
