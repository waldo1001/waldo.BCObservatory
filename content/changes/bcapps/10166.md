# #10166 [Extensibility Request] issue 29643: enable split transfer demand profiles

> Transfer demand profile handling now supports an event that allows extensions to create multiple profiles for different planning contexts, such as preserving distinct cable and cut-length requirements instead of aggregating quantities.

[Pull request](https://github.com/microsoft/BCApps/pull/10166) · merged into `main` (BC30) on 2026-08-20 by AleksandricMarko · 1 file (+30 -21), 1 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- New pre-creation event added to MaintainPlanningLine for transfer demand profiles
- Event provides requisition, supply profile, tracking reservation, line-number, and handled context
- Enables downstream purchase suggestions to maintain separate length requirements
- Standard behavior preserved when no subscriber handles the event
- Extensions can now safely override default transfer planning flow
