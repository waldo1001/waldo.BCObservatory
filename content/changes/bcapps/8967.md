# #8967 Ability to archive agents

> Agents can now be archived by admins from the Agent List and Card, which disables them and hides them from views while preserving their data and tasks in the database for auditing purposes.

[Pull request](https://github.com/microsoft/BCApps/pull/8967) · merged into `main` (BC30) on 2026-07-28 by krupybalu · 12 files (+1285 -1), 8 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- Adds soft-delete archiving capability for agents via new Archive and IsArchived methods
- Archived agents are disabled, hidden from role center and agent views, but remain in the database as read-only
- Requires confirmation dialog where admin types the agent's display name
- Archiving is one-way with no restore functionality in this iteration
- Adds telemetry logging for archive usage events
- Behaviour changes for users or extensions.
