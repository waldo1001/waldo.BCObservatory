# #14203 [Dataverse] Use commercial endpoints in Business Central online

> Business Central online now always uses commercial Dataverse endpoints regardless of the selected cloud, while on-premises continues to respect the selected Dataverse Cloud setting for sovereign cloud scenarios.

[Pull request](https://github.com/microsoft/BCApps/pull/14203) · merged into `main` (BC30) on 2026-11-17 by onbuyuka · 3 files (+51 -5), 2 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- GetDataverseCloudEndpoints() returns Commercial endpoints when running in SaaS infrastructure
- On-premises installations still respect the selected Dataverse Cloud value for GCC High and other sovereign clouds
- All callers already use the GetDataverseCloudEndpoints() method so the change is centralized
- Updated documentation to clarify the cloud selection only applies on-premises
- New test validates that SaaS ignores Dataverse Cloud overrides and resolves to commercial endpoints
- Behaviour changes for users or extensions.
