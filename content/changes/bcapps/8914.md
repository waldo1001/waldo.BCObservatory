# #8914 [Master]- Changing Sales Order Line Description on a Sales Order unexpectedly changes the invoice total amounts.Changes

> Fixed an issue where editing a sales order line's description would unexpectedly change invoice totals by ensuring calculations only run when the item number changes.

- The Description field validation was recalculating totals on every edit
- Totals are now recalculated only when Rec."No." differs from xRec."No."
- Stops the line amount being added to the invoice totals a second time
- Adds a test in the Document Totals Pages test codeunit
- The Sales Order Subform page is updated in the W1, CH, ES, IT, NA, NO and RU layers
