# #11657 Fix VIES integrity check: tolerate country-code prefix on echoed VAT number (uptake fix)

> The VIES integrity check for VAT numbers now tolerates country-code prefixes in echoed responses, normalizing both sides before comparison to prevent false rejection of valid VAT numbers during registration.

[Pull request](https://github.com/microsoft/BCApps/pull/11657) · merged into `main` (BC30) on 2026-09-21 by dcenic · 1 file (+18 -1), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Fixed regression where VIES responses echoing VAT numbers with country-code prefix were wrongly rejected as mismatches
- Normalizes both request and response values to prefix-stripped form before integrity check comparison
- Prevents hard block on saving VAT numbers when security checks fail due to cosmetic prefix differences
- Preserves security intent by still rejecting genuinely different numbers or country codes
- Resolves 10 failing mocks in NAV repository uptake tests that require live VIES mock service
- Behaviour changes for users or extensions.
