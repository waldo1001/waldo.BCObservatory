# #12324 Obsolete Http Web Request Mgt. usage in public API (webhooks, OData)

> Http Web Request Mgt usage is removed from webhook and OData public APIs by replacing DotNet-based code with native HttpClient and HttpRequestMessage, while obsoleting old event signatures.

[Pull request](https://github.com/microsoft/BCApps/pull/12324) · merged into `main` (BC30) on 2026-10-09 by darjoo · 4 files (+253 -61), 2 AL · refactor · tier official · **unreviewed** (model text not yet checked)

## What changed

- SendRequest in API Webhook Notification Send uses native HttpClient instead of DotNet Http Web Request Mgt
- New event OnSendRequestOnBeforeSendHttpRequest replaces obsolete OnSendRequestOnBeforeSendRequestAndReadTextResponse
- Behavior preserved: POST with JSON headers, UTF-8 body, timeouts, telemetry tags, and retry rules unchanged
- ODataUtility CreateMetadataWebRequest method obsoleted; callers should use native HttpClient/HttpRequestMessage
- Breaking: existing extensions can stop compiling or working.

## AL objects touched

- [Codeunit 6154 "API Webhook Notification Send"](../../objects/codeunit/6154.md), Base Application: modified
- [Codeunit 6710 "ODataUtility"](../../objects/codeunit/6710.md), Base Application: modified

## Obsoletions

- API Webhook Notification Send: OnSendRequestOnBeforeSendRequestAndReadTextResponse, replaced by OnSendRequestOnBeforeSendHttpRequest
- API Webhook Notification Send: OnAfterSendNotification (with DotNet HttpStatusCode parameter), replaced by OnAfterSendNotificationWithStatusNumber
- ODataUtility: CreateMetadataWebRequest
