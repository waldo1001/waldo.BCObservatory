# #11736 [29.x][VIES Integration] Per-environment daily request rate-limit

> A per-environment daily request rate-limit was added to VAT Registration Number lookups against the EU VIES service to prevent single tenants from flooding the shared outbound IP and causing service unavailability for co-located tenants in Business Central online.

[Pull request](https://github.com/microsoft/BCApps/pull/11736) · merged into `releases/29.x` (BC29) on 2026-09-24 by dcenic · 5 files (+311 -0), 3 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- New quota mechanism enforces a 2000-lookups-per-day limit on VIES validation calls per tenant
- Quota counter resets daily and blocks further requests when the cap is reached; blocked calls emit security audit and telemetry
- Online (SaaS) only; on-premises installations are unaffected since they own their own outbound IP
- Quota is checked before the SOAP request in codeunit 248 and covers all code paths including interactive, background, API, and field validation
- Counter lives in a new internal Base Application table that stores per-environment quota state
- Behaviour changes for users or extensions.
