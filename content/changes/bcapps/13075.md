# #13075 [MAIN] [IN] Add extensibility events to support deferred TDS calculation on purchase documents

> Three integration events with IsHandled parameters are added to support deferred TDS calculation on purchase documents, allowing extensions to control tax recalculation when quantity, unit cost, or document-level fields change.

## What changed

- New events for TDS certificate usage updates
- New events for recalculation on Applies-to Doc. No. or Posting Date changes
- New events for recalculation on Include GST in TDS Base changes
- IsHandled parameter enables extensions to defer or customize processing
- Standard behavior unchanged unless a subscriber explicitly handles an event
