# #13075 [MAIN] [IN] Add extensibility events to support deferred TDS calculation on purchase documents

> Adds three integration events with an IsHandled parameter to the IN TDS app. Extensions can use them to take over TDS certificate usage updates, TDS recalculation after Applies-to Doc. No. or Posting Date changes, and tax recalculation after Include GST in TDS Base changes, so they can defer TDS calculation on purchase documents.

[Pull request](https://github.com/microsoft/BCApps/pull/13075) · merged into `main` (BC30) on 2026-10-21 by v-ajaztabrez · 2 files (+35 -0), 2 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- New event for TDS certificate usage updates
- New event for TDS recalculation when Applies-to Doc. No. or Posting Date changes
- New event for tax recalculation when Include GST in TDS Base changes
- IsHandled lets a customer extension defer the processing, for example to speed up multi-line purchase orders
- Standard behavior is unchanged unless a subscriber handles an event; publishers only
