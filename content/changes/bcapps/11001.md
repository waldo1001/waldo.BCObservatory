# #11001 Bug 648577: [IT] Subcontracting migration does not precheck bin-mandatory locations

> The IT subcontracting migration now prechecks legacy vendor and purchase-header locations for unsupported warehouse settings, such as bin mandatory. If any are found it stops with a single error listing every incompatible location and its enabled settings, and leaves migration data untouched.

[Pull request](https://github.com/microsoft/BCApps/pull/11001) · merged into `main` (BC30) on 2026-09-18 by ChethanT · 2 files (+351 -0), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- Blocks migration when legacy vendor or purchase-header locations use unsupported warehouse settings
- Reports every incompatible location and lists each enabled setting
- Migration data stays untouched when the precheck fails
- Errors collected during the precheck are handled explicitly and raised as one blocking error
- Tests cover multiple locations, all unsupported settings, and migration stopping before vendor data is copied
- Behaviour changes for users or extensions.
