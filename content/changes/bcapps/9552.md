# #9552 [Main]-Issue in TDS calculation during payment application against invoices

> Fixed TDS calculation during payment application against invoices by scaling the applied amount to match the payment's TDS base, ensuring correct tax base computation when GST and payment amounts differ.

[Pull request](https://github.com/microsoft/BCApps/pull/9552) · merged into `main` (BC30) on 2026-07-17 by v-ajaztabrez (community contribution) · 2 files (+166 -100), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- TDS advance payments now use scaled applied amount based on payment TDS base ratio instead of gross amount
- Applied amount calculation: (Amount to Apply) × (Payment TDS Base ÷ Payment Amount)
- Fixed issue where partial payments and multiple invoice applications caused incorrect TDS base and tax amounts
- Scoped consumed original invoice amount to prevent cross-payment interference in multi-invoice scenarios
- Updated use case configuration version to 36 for schema changes
- Behaviour changes for users or extensions.
