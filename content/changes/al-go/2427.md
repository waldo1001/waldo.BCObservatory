# #2427 Add opt-in setting to skip draft PR builds

> AL-Go now offers an opt-in setting to skip draft pull request builds, reducing unnecessary compute consumption before changes are ready for review. The feature adds draft guards to built-in jobs and enables the ready_for_review trigger while keeping custom jobs untouched.

[Pull request](https://github.com/microsoft/AL-Go/pull/2427) · merged into `main` on 2026-11-06 by aholstrup1 · 8 files (+152 -4), 3 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- New skipDraftPullRequests setting (default false) allows repositories to opt out of building draft PRs
- When enabled, draft guards are applied to AL-Go built-in jobs and ready_for_review trigger is added to PR build workflows
- Supports both pull_request and pull_request_target triggers while leaving merge-queue builds unchanged
- Custom jobs remain unmodified, allowing repository owners to manage their own draft conditions
- Feature applies after dependency build generation and before custom jobs are appended
