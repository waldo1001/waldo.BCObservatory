# #2323 Fix enableCodeAnalyzersOnTestApps not disabling customCodeCops in workspace compilation

> Workspace compilation now correctly disables custom code analyzers when enableCodeAnalyzersOnTestApps is false, preventing custom analyzer diagnostics from running against test apps.

## What changed

- Custom analyzers are now cleared in test and BCPT-test folders when enableCodeAnalyzersOnTestApps is false
- Previously only built-in analyzers were disabled while custom analyzers continued running
- Fix aligns workspace compilation behavior with the documented setting and classic container flow
- Mutable buildParams hashtable ensures test folder changes don't affect normal app compilation
- Regression tests added to verify correct --customanalyzers argument emission
