# #2407 Enable AL-Go for GitHub on GitHub Enterprise Cloud with data residency

> AL-Go for GitHub now supports GitHub Enterprise Cloud with dynamic host resolution, automatically using the correct GitHub server and API URLs instead of hardcoded references to github.com.

[Pull request](https://github.com/microsoft/AL-Go/pull/2407) · merged into `main` on 2026-10-22 by freddydk · 27 files (+375 -110), 17 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- Scripts and workflows now use GITHUB_SERVER_URL and GITHUB_API_URL environment variables for all GitHub API calls
- GH_HOST environment variable is set for gh CLI commands to target the correct host on GitHub Enterprise
- New scenario guide documents how to use AL-Go for GitHub on GitHub Enterprise, including setup and best practices
- Template repository download logic improved to construct API URLs correctly for both public GitHub and GitHub Enterprise
- AL-Go for GitHub workflow explicitly verified to only run on github.com, preventing unsupported usage on GitHub Enterprise for the main repository
- Behaviour changes for users or extensions.
