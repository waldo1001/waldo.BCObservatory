# #2380 Fix device login initialization with a shared authentication action

> A shared authentication action now handles device login initialization for AL-Go workflows, ensuring credentials are validated and helpers are available before sign-in instructions are displayed.

## What changed

- New Authenticate action centralizes credential checks and device-login setup across workflows
- Credentials passed through environment variables instead of PowerShell source interpolation
- Existing credential precedence and admin secret name configuration preserved
- Missing credentials and invalid responses now fail explicitly with detailed messages
- Applied to CreateOnlineDevelopmentEnvironment and PublishToEnvironment workflows in both app templates
- Behaviour changes for users or extensions.
