# #2444 Implement retry logic for GitHub App token requests to handle transient errors

## What changed

- GET and POST requests in GetGitHubAppAuthToken are wrapped with retry logic
- Retries use same settings as other GitHub API calls: 3 attempts with 5 and 10 second delays
- JWT token validity and short-lived token creation make retrying safe
- Pester unit tests cover 404 on installation lookup, 502 on token request, and repeated failures
- All actions using GitHub App authentication benefit, not just CheckForUpdates
- Behaviour changes for users or extensions.
