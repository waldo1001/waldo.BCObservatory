# #2313 Fix dependency resolution when branch name contains ']' character

> Fixed dependency resolution in GitHub Helper to correctly handle branch names containing the ] character by using literal path interpretation instead of wildcard matching.

[Pull request](https://github.com/microsoft/AL-Go/pull/2313) · merged into `main` on 2026-07-21 by aholstrup1 · 3 files (+35 -1), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Branch names can legally contain ] characters, which are treated as wildcards in PowerShell -Path parameter
- GetDependencies was returning the folder itself instead of enumerating .app files when ] appeared in the folder name
- Changed from -Path to -LiteralPath to treat the folder path literally without wildcard interpretation
- No behavior change for existing branch names without brackets
- Includes regression test to prevent future breakage
