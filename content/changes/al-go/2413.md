# #2413 Only enable automatic Copilot review triggers when opted in

> Automatic Copilot review workflow triggers now activate only when explicitly opted in through settings, preventing unintended workflow runs from templates that bypass the updater's inclusion logic.

[Pull request](https://github.com/microsoft/AL-Go/pull/2413) · merged into `main` on 2026-10-20 by aholstrup1 · 9 files (+164 -19), 6 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- Copilot review workflows ship with only manual dispatch triggers by default
- The updater adds pull_request and workflow_run triggers only when CodeReviewAgent.enabled is true
- Templates prevent automatic reviews from activating in repositories using outdated updaters
- Settings schema and Copilot scenario documentation updated to reflect the opt-in requirement
- Comprehensive tests added to validate trigger configuration and workflow file handling
- Behaviour changes for users or extensions.
