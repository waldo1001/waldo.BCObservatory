# #2314 Retry current-build dependency artifact download up to 3 times

> The Download Project Dependencies action now retries failed artifact downloads up to 3 times with 30-second delays between attempts to handle transient network errors from GitHub's Actions Results service.

## What changed

- Failed downloads trigger automatic retries instead of immediate failure
- 3 sequential attempts with 30-second waits between failures
- Only the final attempt can fail the job; earlier attempts continue on error
- Addresses intermittent ETIMEDOUT errors in the dependency download step
- Happy path adds no time overhead since successful downloads skip remaining attempts
