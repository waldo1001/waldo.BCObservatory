# #2342 Fix incremental builds poisoning buildMode-specific artifacts (#2337)

> Fixed incremental builds in AL-Go that were corrupting buildMode-specific artifacts by re-publishing default build mode apps under incorrect artifact names, causing dependent projects to fail with runtime version mismatches.

[Pull request](https://github.com/microsoft/AL-Go/pull/2342) · merged into `main` on 2026-08-07 by aholstrup1 · 7 files (+152 -6), 5 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- DetermineBuildProject now receives buildMode parameter to download artifacts matching the current build mode dimension
- Build-mode-prefixed artifact masks are used instead of build-mode-agnostic masks to select correct artifacts
- Downloaded artifacts are extracted into build-mode-agnostic folders for later build steps, maintaining compatibility
- Fixes propagating corruption in incremental builds where each run becomes the baseline for the next
- Prevents AL1153 compiler errors from runtime version mismatches in multi-project repositories
- Behaviour changes for users or extensions.
