# #2343 RunTests action

> AL-Go introduces a new RunTests action that separates test execution from the build pipeline using AlTool, enabling better container lifecycle management and focused test operations.

[Pull request](https://github.com/microsoft/AL-Go/pull/2343) · merged into `main` on 2026-10-27 by spetersenms · 24 files (+5397 -3), 13 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- Preview feature with useSeparateTestAction setting (defaults to false) to move tests from RunPipeline to new RunTests action
- RunPipeline builds and publishes apps, then RunTests executes them using al runtests command
- Supports test type filtering for UnitTest, IntegrationTest, and Uncategorized categories
- Only normal tests are moved; BCPT, page scripting, and multi-country tests remain in pipeline
- Maintains BCH for container management and metadata operations while AlTool handles actual test execution
