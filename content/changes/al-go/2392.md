# #2392 AL-Go Telemetry Enhancements: repository fork and hosting information

> AL-Go telemetry now captures whether a repository is a fork and its GitHub hosting type (GitHub.com, GHEC, or GHES), helping distinguish workflows across different environments without sending server details to telemetry.

## What changed

- New `Get-RepositoryIsFork` function determines fork status from workflow event metadata
- New `Get-GitHubHostingType` function classifies GitHub hosting as GitHub.com, GHEC, or GHES
- Telemetry dimensions include repository and hosting context for Microsoft and partner systems
- Invalid or missing metadata produces warnings and returns 'Unknown' without blocking telemetry
- Added 27 unit tests covering both PowerShell 7 and Windows PowerShell 5 compatibility
