# #2403 Fix dependency filenames containing commas

> Fixed handling of dependency filenames with commas by casting install app parameters to arrays before passing them to the pipeline, preventing incorrect path splitting by BCContainerHelper.

## What changed

- Filenames containing commas were split into multiple paths when processed as strings
- Added explicit array casting for installApps and installTestApps parameters
- Download Project Dependencies now validates resolved files with Test-Path before output
- Missing files generate warnings with full paths but do not break the process
- Added comprehensive unit tests covering literal filenames, test-app markers, and error cases
