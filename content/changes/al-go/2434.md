- Artifact listing requests in DetermineArtifactsForRelease and GetArtifacts now retry up to 3 times
- Workflow metadata, artifact listings, and CI/CD baseline discovery requests include retry logic
- Retries apply to individual failed requests with 5-second and 10-second waits between attempts
- Exhausted request failures still propagate; persistent endpoint issues remain unresolved
- Existing tests updated to expect three requests and two waits
