# #2433 Fix workspace compilation with versioning strategy 3

> The versioning strategy 3 workspace compilation was failing because an appBuild sentinel value of -1 was passed to the .NET version constructor. The fix preserves each app's existing build component when the build number is -1 or omitted, while treating an explicit 0 as a valid build number.

[Pull request](https://github.com/microsoft/AL-Go/pull/2433) · merged into `main` on 2026-11-06 by aholstrup1 · 3 files (+42 -5), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Update-AppJsonProperties now correctly handles the -1 sentinel value from versioning strategy 3
- Existing build components are preserved when build number is -1 or omitted
- Explicitly supplied 0 is now treated as a valid build number instead of being ignored
- Regression tests added to cover app and test-app version scenarios
- Fix documented in release notes
- Behaviour changes for users or extensions.
