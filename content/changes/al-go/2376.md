# #2376 fix: modified files with umlauts

> Incremental build detection now finds project and app paths that contain umlauts or other special characters such as ß. It does this by turning off git path escaping and switching to UTF-8 output encoding while git diff runs.

[Pull request](https://github.com/microsoft/AL-Go/pull/2376) · merged into `main` on 2026-09-21 by OleWunschmann · 3 files (+97 -3), 1 AL · fix · tier official · reviewed (checked by Opus)

## What changed

- git diff now runs with -c core.quotepath=false, so special characters are no longer escaped as byte sequences
- The console encoding is set to UTF-8 before the git command and restored afterwards
- Fixes incremental builds that missed modified projects or apps whose paths contain characters like ä, ö, ü or ß
- Unit tests added for DetermineProjectsToBuild, and release notes updated
- Behaviour changes for users or extensions.
