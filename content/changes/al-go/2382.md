# #2382 Fix dependency artifact pattern for branch names with glob-special characters

> Fixed a bug where dependency artifact downloads failed silently when branch names contained special characters that minimatch interprets, such as commas, braces, or parentheses.

[Pull request](https://github.com/microsoft/AL-Go/pull/2382) · merged into `main` on 2026-09-30 by AlexanderMarcher · 3 files (+48 -1), 1 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Branch names with special characters (comma, braces, parentheses, exclamation, plus, at, hash, bracket) were incorrectly interpreted by minimatch glob patterns
- These characters caused artifact download to match zero artifacts and silently fall back to main branch artifacts
- Special characters in branch names are now backslash-escaped in the minimatch pattern to be treated literally
- Artifact upload, baseline lookup, and release lookup are unaffected by this change
- Tests added to prevent regression
- Behaviour changes for users or extensions.
