# #2402 Move Copilot review engine into AL-Go

> The Copilot code review engine moves from external hosting into AL-Go with a two-workflow architecture. BCQuality provides AL expertise and review skills while AL-Go handles GitHub orchestration, execution, and artifact publication.

[Pull request](https://github.com/microsoft/AL-Go/pull/2402) · merged into `main` on 2026-10-20 by WaelAbuSeada · 57 files (+14057 -30), 30 AL · feature · tier official · **unreviewed** (model text not yet checked)

## What changed

- New ReviewAgent action performs code review in read-only mode with separate publish job for write permissions
- New SetupBCQuality action installs and configures BCQuality plugin as the sole installation boundary
- Generated Per Tenant Extension and AppSource App templates receive integrated CopilotPRReview workflows
- Review generation binds to validated pull-request head SHA to prevent untrusted PR code execution
- 414+ tests validate review engine, metrics, action wrapper, and workflow orchestration across PowerShell versions
- Behaviour changes for users or extensions.
