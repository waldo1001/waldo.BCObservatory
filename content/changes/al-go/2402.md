# #2402 Move Copilot review engine into AL-Go

> AL-Go gains a built-in Copilot pull request review. A new SetupBCQuality action installs and filters the BCQuality plugin, and a new ReviewAgent action runs the review and posts comments. Generated Per Tenant Extension and AppSource App templates get a two-workflow integration, configured through new BCQuality and CodeReviewAgent settings.

[Pull request](https://github.com/microsoft/AL-Go/pull/2402) · merged into `main` on 2026-10-20 by WaelAbuSeada · 57 files (+14057 -30), 30 AL · feature · tier official · reviewed (checked by Opus)

## What changed

- New ReviewAgent action runs in four phases (context, prepare, generate, post). Review generation is read-only, and a separate job with write permissions publishes the results.
- New SetupBCQuality action is the only place BCQuality is installed. It filters the plugin by layers, skills and knowledge rules.
- Per Tenant Extension and AppSource App templates get CopilotPRReview and CopilotPRReviewRunner workflows. The runner starts through workflow_run and reads trusted settings from the base repository.
- New BCQuality and CodeReviewAgent settings split AL knowledge selection from review orchestration policy.
- Review is bound to the validated PR head SHA, and untrusted PR code is never used as workflow configuration or review infrastructure.
- Behaviour changes for users or extensions.
