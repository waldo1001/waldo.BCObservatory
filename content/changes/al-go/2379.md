# #2379 Avoid CI/CD runs for template SHA-only system updates

> The system no longer commits template SHA changes when only an empty commit occurs in the template repository, preventing unnecessary CI/CD triggers with no actual file modifications.

[Pull request](https://github.com/microsoft/AL-Go/pull/2379) · merged into `main` on 2026-09-30 by aholstrup1 · 5 files (+123 -0), 2 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- Checks if files were actually updated or removed before persisting a new template SHA
- Retains the original SHA when template URL matches and SHA already exists, skipping early return
- Allows real updates, removals, template switches, and metadata initialization to follow normal path
- SHA remains pinned to last applied revision instead of latest checked revision
- Includes comprehensive test coverage for SHA-only updates, file changes, removals, and template switches
- Behaviour changes for users or extensions.
