# #2300 Make failOn: newWarning work with workspace compilation

> The failOn: newWarning setting now detects newly introduced AL compiler warnings when workspace compilation is enabled, by running the check during the compile phase instead of the pipeline phase and handling workspace-format compiler output.

[Pull request](https://github.com/microsoft/AL-Go/pull/2300) · merged into `main` on 2026-07-31 by aholstrup1 · 5 files (+283 -20), 3 AL · fix · tier official · **unreviewed** (model text not yet checked)

## What changed

- failOn: newWarning check now runs in CompileApps action for workspace compilation mode instead of RunPipeline
- Parser handles both GitHub Actions annotation format and raw AL compiler output formats
- Build version differences in warning messages are normalized before comparison to prevent false positives
- Compiler output is preserved for baseline artifacts by passing empty buildOutputFile to RunPipeline
- Added Pester tests covering both warning formats, new vs removed warnings, and version normalization
- Behaviour changes for users or extensions.
