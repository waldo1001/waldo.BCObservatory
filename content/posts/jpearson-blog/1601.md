# Integration with Azure Static Web Apps from Business Central

> This post explains how to integrate an Azure Static Web App with Business Central by using the WebPageViewer control add-in and the window.postMessage API to enable bidirectional communication between AL code and a hosted web application.

[Read the post](https://jpearson.blog/2026/03/20/integration-with-azure-static-web-apps-from-business-central/) · James Pearson (James Pearson) · 2026-03-20 · 879 words · tier community · **unreviewed** (machine-generated)

## Key points

- WebPageViewer control add-in loads web content in an iframe within a Business Central page
- Use window.postMessage API for two-way communication between AL code and the web app
- AL code subscribes to message events and posts messages using SubscribeToEvent and PostMessage methods
- Web app listens for messages with addEventListener and responds using window.parent.postMessage
- Azure Static Web App must be served over proper SSL certificate for WebPageViewer to load it
