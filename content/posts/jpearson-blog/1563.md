# Using Azure DevOps Wiki as a WYSIWYG Editor for Your Static Site

[Read the post](https://jpearson.blog/2025/08/13/using-azure-devops-wiki-as-a-wysiwyg-editor-for-your-static-site/) · James Pearson (James Pearson) · 2025-08-13 · 998 words · tier community · **unreviewed** (machine-generated)

> Azure DevOps Wiki provides a WYSIWYG editor for maintaining static site documentation while keeping content in Git, allowing non-technical contributors to write and edit docs without learning Git workflows or Markdown syntax.

## Key points

- Azure DevOps Wiki combines a user-friendly WYSIWYG editor with automatic Git commits behind the scenes
- Consultants can write content without learning Git, branches, or Markdown syntax details
- The wiki supports drag-and-drop page reordering, image pasting, and Mermaid diagrams
- A build pipeline can automatically convert wiki content to static site format using docfx, triggered by commits
- Use batch commits in the pipeline to avoid triggering builds for every small edit
