# Calling Business Central Directly from a Managed Identity

[Read the post](https://jpearson.blog/2025/07/18/calling-business-central-directly-from-a-managed-identity/) · James Pearson (James Pearson) · 2025-07-18 · 636 words · tier community · reviewed (checked by Opus)

> Managed identities can be granted Business Central API permissions directly via PowerShell without requiring federated credentials or app registrations. This enables Azure resources to call Business Central APIs securely without creating or storing client secrets.

## Key points

- Assign API permissions directly to managed identities using Microsoft Graph PowerShell module
- Bypass the need for separate app registrations and federated credentials
- Create an Entra Application record in Business Central using the managed identity's client ID
- View assigned permissions through Azure Portal's Enterprise applications section or PowerShell
- Eliminates the need to create, store, and rotate client secrets for API access

- "You can assign Business Central (and other) API permissions to managed identities." (Establishes the core capability that managed identities can directly receive BC API permissions without intermediate app registrations)
