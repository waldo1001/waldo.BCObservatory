# Tip – Access the Clipboard with Business Central

[Read the post](https://jpearson.blog/2025/04/24/tip-access-the-clipboard-with-business-central/) · James Pearson (James Pearson) · 2025-04-24 · 489 words · tier community · reviewed (checked by Opus)

> This post explains how to use the WebPageViewer control add-in to implement a copy-to-clipboard feature for URLs and text in Business Central pages, including handling browser security restrictions on HTTP connections.

## Key points

- WebPageViewer control add-in can display HTML and JavaScript for lightweight UI enhancements without building custom add-ins
- Use JavaScript's navigator.clipboard.writeText() to copy text to clipboard and add event listeners for user feedback
- HTTP connections block clipboard access by default; enable 'Insecure origins treated as secure' browser flag for local testing
- HTTPS connections work without additional configuration for clipboard operations

## Quotes

- "That is because by default the clipboard is not available to sites which are served over http." (Explains the root cause of clipboard failures in local testing environments and why configuration is needed)
