# Streamline AL Development Using Copilot Code Review

[Read the post](https://aardvarklabs.blog/2026/03/27/streamline-al-development-using-copilot-code-review/) · Aardvark Labs (Marcel Chabot) · 2026-03-27 · 1556 words · tier community · reviewed (checked by Opus)

> GitHub's Copilot Code Review feature can assist with AL code reviews by checking code against detailed standards beyond what CI pipelines catch. Set up the feature in GitHub settings and create a codereview.instructions.md file with AL-specific guidelines to guide Copilot's review process and ensure AppSource-ready, high-quality extensions.

## Key points

- Enable Copilot Code Review in GitHub settings under Settings > Copilot > Code review to get AI-assisted code reviews on pull requests
- Create a codereview.instructions.md file with detailed AL development standards to guide Copilot's review process beyond what CI pipelines validate
- Include comprehensive guidelines covering best practices, code quality, performance, security, extensibility, UI standards, and common AL mistakes
- Keep instruction files under 1000 lines to avoid overloading Copilot and prevent false positives when reviewing complex AL code
- Use Copilot to catch issues that are technically correct but don't meet project standards or best practices
