# Business Central’s New API Overview: A Modern Replacement for Web Services

[Read the post](https://aardvarklabs.blog/2026/10/23/business-centrals-new-api-overview-a-modern-replacement-for-web-services/) · Aardvark Labs (Marcel Chabot) · 2026-10-23 · 453 words · tier community · **unreviewed** (model text not yet checked)

> Business Central's new API Overview page provides a modern, unified interface to discover all API pages in your environment, replacing the legacy Web Services page. It displays versioned APIs with publisher/group/version hierarchy and represents Microsoft's shift away from SOAP and legacy OData toward AL-defined APIs.

## Key points

- API Overview is a system page that lists all API pages regardless of source with metadata including entity name, publisher, version, page ID, and OData URL
- The page supports full API versioning and publisher/group/version hierarchy, unlike the Web Services page which had no versioning or grouping
- SOAP endpoints are deprecated and OData is legacy; AL-defined APIs are the future direction Microsoft is moving toward
- Provides better discoverability and onboarding for developers without requiring manual publishing or external documentation

## Quotes

- "With the introduction of the API Overview, Business Central finally provides a modern, unified way to see all API pages exposed in your environment." (This explains the core benefit of the new feature as a centralized discovery mechanism for all APIs in an environment.)
- "SOAP is deprecated. OData is legacy. AL‑defined APIs are the future." (This clarifies Microsoft's strategic direction and why the shift away from Web Services to API Overview matters for developers.)
- "The API Overview gives you a structured, modern look at your API surface." (This highlights the modernization aspect and how the page provides organized, authoritative information about available APIs.)
