# Business Central v29: ModuleInfo Gets Four New Runtime 18 Values

[Read the post](https://aardvarklabs.blog/2026/11/13/business-central-v29-moduleinfo-gets-four-new-runtime-18-values/) · Aardvark Labs (Marcel Chabot) · 2026-11-13 · 257 words · tier community · reviewed (checked by Opus)

> Business Central v29 introduces four new Runtime 18 fields on ModuleInfo (ContextSensitiveHelpUrl, EULA, Help, PrivacyStatement) that expose compliance and documentation metadata through AL code, eliminating the need to parse app.json or manifests.

## Key points

- Runtime 18 adds ContextSensitiveHelpUrl, EULA, Help and PrivacyStatement to the ModuleInfo data type
- Values are read in AL after calling NavApp.GetCurrentModuleInfo, alongside existing Runtime 17 values such as Name, Id and AppVersion
- Removes the need to look in app.json or manifests or duplicate this information in code
- Useful for ISVs and AppSource apps to validate metadata at runtime, surface compliance info, and include documentation links in diagnostics or telemetry
