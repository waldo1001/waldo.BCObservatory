> Business Central v29 introduces four new Runtime 18 fields on ModuleInfo (ContextSensitiveHelpUrl, EULA, Help, PrivacyStatement) that expose compliance and documentation metadata through AL code, eliminating the need to parse app.json or manifests.

- ModuleInfo now includes four new Runtime 18 fields for compliance metadata
- Developers can retrieve context-sensitive help URLs, EULA, help content, and privacy statements programmatically via NavApp.GetCurrentModuleInfo
- Useful for ISVs, AppSource apps, and extensions that need to validate or surface compliance information at runtime
- Enables runtime validation of AppSource metadata and building diagnostic pages with module documentation links
