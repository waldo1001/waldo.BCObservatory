# Understanding Business Central’s Format Address Codeunit

> Codeunit 365 (Format Address) handles address formatting across Business Central for customers, vendors, and contacts, applying global postal rules based on country configuration. The post explains its architecture, extensibility through integration events, and demonstrates how to extend it with custom logic for compliance or data correction.

[Read the post](https://aardvarklabs.blog/2026/09/04/understanding-business-centrals-format-address-codeunit/) · Aardvark Labs (Marcel Chabot) · 2026-09-04 · 984 words · tier community · **unreviewed** (machine-generated)

## Key points

- Format Address reads country-specific formatting rules from the Country Region table, making behavior configurable and safe for localization
- The codeunit is highly extensible with OnBefore integration events on each record-specific procedure, allowing custom logic without modifying core behavior
- Each formatted address returns an array of 8 text elements, with the 8th element intentionally left empty for extension use
- Custom extensions can hook into the formatting process to clean data, add location details, or apply region-specific rules without editing reports
