# Mastering Business Central API for App Management

> This post provides practical PowerShell examples for automating extension management in Business Central using the Administration API, including deploying .app files, monitoring installation progress, handling failures, and uninstalling extensions.

[Read the post](https://aardvarklabs.blog/2026/09/18/mastering-business-central-api-for-app-management/) · Aardvark Labs (Marcel Chabot) · 2026-09-18 · 1200 words · tier community · **unreviewed** (machine-generated)

## Key points

- Authenticate with the Business Central Administration API using client credentials to obtain an access token for multipart requests
- Deploy extensions using the pteInstall endpoint with specific parameters like deploymentSchedule, syncMode, languageId, and EULA acceptance
- Poll the operations endpoint after deployment to monitor installation status and detect succeeded, failed, or canceled operations
- Uninstall extensions by checking dependencies first, then calling the uninstall endpoint with parameters for update window, dependents, and data deletion
