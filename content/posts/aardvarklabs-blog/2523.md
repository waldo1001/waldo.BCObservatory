> Page customizations in Business Central allow developers to tailor page layouts to specific user profiles without modifying core functionality. The post demonstrates how to create page customization objects and profiles in AL code to hide fields and actions, hide financial data from data entry users, and deploy customizations as part of an extension.

## Key points

- Page customizations are profile-specific layout changes that work similarly to page extensions but do not require object IDs
- Customizations can only modify visibility and move fields; they cannot add triggers, procedures, or actions to maintain functional parity across all users
- A profile definition links customizations to a role center and applies them when users switch to that profile
- Multiple profiles can reuse the same customizations, allowing layered access control without code duplication
