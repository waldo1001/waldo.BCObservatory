# Guide to Handling Header and Detail Imports into Business Central with AL

> This guide demonstrates how to parse and import delimited files containing header and detail records (like sales orders) into Business Central using AL. It covers two formats: normalized (separate header/detail lines identified by markers) and denormalized (merged header/detail data on single lines), with code examples for parsing both formats into staging tables and creating sales orders.

## Key points

- Normalized format uses marker characters (H/D) to distinguish header and detail lines, while denormalized format repeats header fields on each detail line
- Data is parsed into separate staging tables (ARD_SalesHeader and ARD_SalesDetail) before creating actual sales orders
- Denormalized parsing relies on detecting changes in an anchor field (external document number) to create new headers
- The parsing logic handles line-by-line text processing, field extraction via delimiters, and linking details to headers via ID tracking
