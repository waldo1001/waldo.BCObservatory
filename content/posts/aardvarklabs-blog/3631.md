# Using Power Automate for Business Central SFTP

[Read the post](https://aardvarklabs.blog/2026/06/19/using-power-automate-for-business-central-sftp/) · Aardvark Labs (Marcel Chabot) · 2026-06-19 · 1040 words · tier community · reviewed (checked by Opus)

> Shows an alternative to native SFTP in Business Central: a custom table with a BLOB field, list and card pages, and an API page keyed on SystemId. A Power Automate flow reads a file from an SFTP server, creates a record through the API, then uploads the file content to the BLOB so it can be parsed in Business Central. The reverse direction, pushing files to SFTP, can be triggered with Business Events.

## Key points

- Create a table with BLOB field to store file content and supporting pages for UI management
- Build an API page with System ID and ODataKeyFields to enable Power Automate to interact with the table
- Use Power Automate to retrieve SFTP files and post them to Business Central via the API in two steps: create record then upload file content
- The approach also works in reverse to push Business Central documents to SFTP servers using Business Events
- Downloaded files can be processed by existing delimited data parsers within Business Central
