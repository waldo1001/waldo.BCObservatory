# Using Power Automate for Business Central SFTP

> Using Power Automate for Business Central SFTP handles file uploads by creating a table with BLOB storage, an API page for integration, and a Power Automate flow that retrieves files from SFTP servers and stores them in Business Central for processing.

[Read the post](https://aardvarklabs.blog/2026/06/19/using-power-automate-for-business-central-sftp/) · Aardvark Labs (Marcel Chabot) · 2026-06-19 · 1040 words · tier community · **unreviewed** (machine-generated)

## Key points

- Create a table with BLOB field to store file content and supporting pages for UI management
- Build an API page with System ID and ODataKeyFields to enable Power Automate to interact with the table
- Use Power Automate to retrieve SFTP files and post them to Business Central via the API in two steps: create record then upload file content
- The approach also works in reverse to push Business Central documents to SFTP servers using Business Events
- Downloaded files can be processed by existing delimited data parsers within Business Central
