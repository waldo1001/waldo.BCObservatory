# Integrating Analysis Views in Business Central Extensions

[Read the post](https://aardvarklabs.blog/2026/02/13/integrating-analysis-views-in-business-central-extensions/) · Aardvark Labs (Marcel Chabot) · 2026-02-13 · 900 words · tier community · reviewed (checked by Opus)

> Business Central AL 17.0 Runtime adds the ability to package and deploy Analysis Views in extensions. You can export Analysis View definitions as JSON files, include them in page or page extension AL code, and deploy them to automatically add pre-built analysis views to list pages in any Business Central environment.

## Key points

- Analysis views built in the UI can be exported as JSON definition files with Export Definition
- AL runtime 17.0 adds an analysisviews section to pages and page extensions, with DefinitionFile pointing to the JSON
- Page extensions need an addfirst or addlast anchor; your own pages do not
- Views shipped in an extension are locked against editing, but users can duplicate them and edit the copy; locked views can be hidden, but the author found no way to unhide them
- The feature was pending release in Wave 1 2026 at the time of writing
