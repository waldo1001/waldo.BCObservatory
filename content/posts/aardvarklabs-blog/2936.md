# Integrating Analysis Views in Business Central Extensions

[Read the post](https://aardvarklabs.blog/2026/02/13/integrating-analysis-views-in-business-central-extensions/) · Aardvark Labs (Marcel Chabot) · 2026-02-13 · 900 words · tier community · **unreviewed** (machine-generated)

> Business Central AL 17.0 Runtime adds the ability to package and deploy Analysis Views in extensions. You can export Analysis View definitions as JSON files, include them in page or page extension AL code, and deploy them to automatically add pre-built analysis views to list pages in any Business Central environment.

## Key points

- Export analysis views from the UI as JSON definition files using the Export Definition option
- Include JSON files in your AL extension project and reference them in page or page extension code using the analysisviews section
- For page extensions, use addlast or addfirst anchors to position views; for new pages, no anchor is needed
- Packaged analysis views are read-only with a lock indicator, but users can duplicate and edit copies
- This feature ships in Wave 1 2026 and works with standard pages and custom pages alike
