# Creating Data Driven Text with AI in Business Central

[Read the post](https://aardvarklabs.blog/2025/05/30/creating-data-driven-text-with-ai-in-business-central/) · Aardvark Labs (Marcel Chabot) · 2025-05-30 · 1344 words · tier community · **unreviewed** (machine-generated)

> This post shows how to build a Copilot in Business Central that generates personalized reminder text for overdue customer balances by combining user input with customer data from the database. It demonstrates passing customer name, balance due, last invoice date, and tone to an AI model to create natural-sounding collection letters.

## Key points

- Create a new Copilot codeunit that accepts customer data as parameters alongside user input to build dynamic prompts
- Use TextBuilder to combine customer information (name, balance due, invoice date, tone) into a structured user prompt sent to Azure OpenAI
- Configure AI temperature setting (0.7 in this example) to control how creative the model's output should be
- Retrieve customer and ledger entry data from Business Central tables to feed into the AI prompt
- Add a button to the Customer Card to trigger the reminder generation process with a modal page for user input
