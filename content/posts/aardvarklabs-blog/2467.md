# Enhancing Business Central with Address Validation AI

[Read the post](https://aardvarklabs.blog/2025/08/29/enhancing-business-central-with-address-validation-ai/) · Aardvark Labs (Marcel Chabot) · 2025-08-29 · 1214 words · tier community · reviewed (checked by Opus)

> Address validation using Azure OpenAI compares user-entered addresses against existing Business Central address records to identify matches and preserve associated metadata. The solution uses a system prompt to guide AI in matching addresses semantically rather than character-by-character, returning match confidence scores.

## Key points

- Free-text ship-to addresses lose extra data tied to stored Business Central addresses, such as salesperson or regional details, so matching to an existing address code helps keep it
- The user address and the customer's known addresses are sent as JSON to Azure OpenAI, which returns a match score between 0 and 1 for each address
- The system prompt carries the logic: ignore abbreviation and line-order differences, and treat a state mismatch as strongly non-matching
- In a test, a near-identical address scored 1, while the same street in Atlanta GA versus Atlanta TX scored 0.6, low enough to reject but high enough to flag for review
- The author's earlier rule-based approach using USPS CASS, Levenshtein distance and hard-coded rules only reached about 70% accuracy
