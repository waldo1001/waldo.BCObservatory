# Enhancing Business Central with Address Validation AI

[Read the post](https://aardvarklabs.blog/2025/08/29/enhancing-business-central-with-address-validation-ai/) · Aardvark Labs (Marcel Chabot) · 2025-08-29 · 1214 words · tier community · **unreviewed** (machine-generated)

> Address validation using Azure OpenAI compares user-entered addresses against existing Business Central address records to identify matches and preserve associated metadata. The solution uses a system prompt to guide AI in matching addresses semantically rather than character-by-character, returning match confidence scores.

## Key points

- User-entered addresses can be matched to existing Business Central addresses using AI to preserve related data like salesperson details
- System prompt design is critical for instructing the AI to ignore abbreviations, street designation variations, and line order while penalizing postal code mismatches
- Match confidence scores (0 to 1) help distinguish between high-confidence matches, flagged candidates needing review, and non-matches
- AI matching outperforms traditional algorithms like Levenshtein Distance combined with USPS CASS and hard-coded rules
