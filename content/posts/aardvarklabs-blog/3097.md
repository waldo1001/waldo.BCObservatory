# Step-by-Step Guide: Create Agents in AL Code

> Building agents in Business Central AL involves creating setup tables, pages, codeunits, and enums to enable autonomous multi-step operations. The guide walks through creating a Cash Flow Review Agent that can accept tasks, interact with the user during execution, and display KPI results.

[Read the post](https://aardvarklabs.blog/2026/04/03/step-by-step-guide-create-agents-in-al-code/) · Aardvark Labs (Marcel Chabot) · 2026-04-03 · 2696 words · tier community · **unreviewed** (machine-generated)

## Key points

- Agents chain multiple tasks together for complex operations, unlike single-task copilots that require review and acceptance
- Required components include setup tables with User Security ID, metadata codeunits implementing IAgentFactory and IAgentMetadata interfaces, and KPI tracking tables
- Custom Agent capability must be enabled in Business Central with appropriate permissions (Agent Admin and Agent Diagnostics) configured in a sandbox environment
- Agent instructions are embedded as resources and delivered via the Agent.SetInstructions method using user security identifiers
- Tasks are created using AgentTaskBuilder to initialize agents with titles and messages, triggering autonomous execution that may pause for user interaction
