> A developer shares how they built a VS Code extension for exploring AL codebases visually, using GitHub Copilot to overcome the barrier to entry. The tool provides dependency diagrams, relationship maps, where-used analysis, and documentation generation to help developers understand complex Business Central solutions faster.

- Visual dependency diagrams and object relationship maps help developers understand AL codebase structure at a glance
- Where-used analysis identifies references and impacts throughout a project for refactoring and troubleshooting
- GitHub Copilot reduced the time needed to learn the VS Code extension framework and made building the tool practical
- The extension is released free to the community following the tradition of sharing knowledge in the Business Central developer community
