# Managing Optional Extensions in Business Central AL Code

[Read the post](https://aardvarklabs.blog/2025/12/19/managing-optional-extensions-in-business-central-al-code/) · Aardvark Labs (Marcel Chabot) · 2025-12-19 · 478 words · tier community · **unreviewed** (machine-generated)

> This post explains how to create a single Business Central extension that optionally interacts with a third-party extension without creating a hard dependency. The technique uses NavApp.GetModuleInfo to detect if an optional extension is installed, then uses RecordRef and FieldRef to conditionally set extension-specific fields.

## Key points

- Use NavApp.GetModuleInfo with an extension GUID to detect if an optional extension is installed at runtime
- Create separate logical steps for core functionality and optional extension-specific field updates
- Use RecordRef and FieldRef with field IDs to access and modify extension fields without adding a dependency
- Check if a FieldRef is active before setting its value to ensure the field exists
- This approach allows a single extension to work in systems with or without the optional third-party extension
