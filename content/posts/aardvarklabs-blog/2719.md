# Top Improvements in Business Central Page Scripting in Release 2025 Wave 2

[Read the post](https://aardvarklabs.blog/2025/10/17/top-improvements-in-business-central-page-scripting-in-release-2025-wave-2/) · Aardvark Labs (Marcel Chabot) · 2025-10-17 · 368 words · tier community · reviewed (checked by Opus)

> Page Scripting tool in Business Central 2025 Wave 2 adds features to manage and edit recorded scripts more flexibly, including step deletion, insertion, reordering, parameter management, and script composition - addressing pain points from manual YAML editing and full re-recording requirements.

## Key points

- Users can now delete individual steps from scripts without re-recording the entire process
- Scripts support parameter management directly in the UI instead of requiring manual YAML file editing
- Multiple scripts can be combined and imported through the UI with parameter passing between them
- Steps can be reordered via drag-and-drop and new steps can be inserted at any point in the workflow
- These improvements reduce the need for manual script editing and full re-recording when changes are needed
