> Business Central Designer Mode enables drag-and-drop field editing through Visual Studio Code by pressing F6 instead of F5, automatically generating AL code from the visual changes made to pages without requiring manual coding.

## Key points

- Press F6 in VS Code to start Business Central in Designer Mode instead of Debugger Mode
- Drag and drop fields onto pages, adjust properties, and show/hide actions through a visual interface
- Designer Mode updates AL code automatically after you save changes by pressing Alt+F6
- Designer Mode works for layouts and visual properties but not for triggers or advanced page logic
- Enables collaborative work with end users to visualize layout changes in real time
