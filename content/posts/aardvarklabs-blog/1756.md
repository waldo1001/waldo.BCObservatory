# Effortless Layout Editing in Business Central

[Read the post](https://aardvarklabs.blog/2025/05/02/effortless-layout-editing-in-business-central/) · Aardvark Labs (Marcel Chabot) · 2025-05-02 · 433 words · tier community · reviewed (checked by Opus)

> Business Central Designer Mode enables drag-and-drop field editing through Visual Studio Code by pressing F6 instead of F5, automatically generating AL code from the visual changes made to pages without requiring manual coding.

## Key points

- Pressing F6 in VS Code starts Business Central in Designer Mode; F5 starts the debugger
- In Designer Mode you can add fields with drag and drop, change field properties, show or hide actions and set importance
- Stop designing, save with Download Code checked, then press Alt+F6 in VS Code to pull the generated AL into the page extension
- Triggers and other advanced page logic cannot be handled in Designer Mode
- Lets developers adjust layouts together with end users and see the results right away

## Quotes

- "With F6 the system starts in Designer Mode." (This is the key command to activate the visual layout editing feature in Business Central)
- "This also lets you work more collaboratively with an end user, allowing you to move and visualize the results in real time." (Shows the practical benefit of Designer Mode for non-technical stakeholders to participate in layout design)
