# Native SFTP Support in Business Central 28

[Read the post](https://aardvarklabs.blog/2026/05/15/native-sftp-support-in-business-central-28/) · Aardvark Labs (Marcel Chabot) · 2026-05-15 · 1571 words · tier community · **unreviewed** (machine-generated)

> Native SFTP support was briefly introduced in Business Central 28 via a new SFTP Client codeunit, enabling asynchronous file operations with external servers. However, Microsoft removed this feature due to security hardening concerns, requiring users to use Azure Functions as an alternative for SFTP connectivity.

## Key points

- SFTP Client codeunit (ID 9762) provided native SFTP operations: list files, upload, download, and delete
- Feature was removed after initial release due to platform hardening requirements and scope concerns
- Sensitive FTP credentials should be stored using Isolated Storage with SecretText for passwords
- SFTP connections require server fingerprint validation using SHA256 before initializing the client

## Quotes

- "The FTP system only supports 4 commands. List Files, Upload File, Download File, and Delete File." (Defines the complete scope of SFTP operations available before removal, helping developers understand feature limitations)
