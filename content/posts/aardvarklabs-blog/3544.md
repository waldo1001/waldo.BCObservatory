> Business Central 28.1 introduces report layout lifecycle management with status tracking. The Report Layouts page now supports Draft, Pending Approval, Approved, and Retired statuses, allowing developers to manage report layout versions without exposing incomplete versions to end users.

## Key points

- Report layouts now have status states: Draft, Pending Approval, Approved, and Retired
- Only Approved layouts are visible to end users; others remain hidden
- Draft and Pending Approval statuses allow developers to test layouts from the Report Layouts screen
- Layout status can be changed via the Actions menu without creating new sandboxes
- Retired status hides old layouts while keeping new versions available
