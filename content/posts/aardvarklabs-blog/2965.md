# Step-by-Step Guide to AI Campaigns in Business Central

[Read the post](https://aardvarklabs.blog/2026/01/23/step-by-step-guide-to-ai-campaigns-in-business-central/) · Aardvark Labs (Marcel Chabot) · 2026-01-23 · 1229 words · tier community · **unreviewed** (machine-generated)

> A practical guide to building AI-powered marketing campaigns in Business Central using two coordinated AI agents. The system generates regional postal codes based on natural language prompts and automatically adds free samples to sales orders shipping to targeted regions, minimizing AI costs by preprocessing data rather than running AI logic on every transaction.

## Key points

- Uses two sequential AI agents: one for grounded search to find postal codes from natural language scenarios, another to extract postal codes into JSON format
- Leverages Business Central's managed AI resource with Bing Grounded Search for accessing current event data that public OpenAI cannot reach
- Saves AI costs and improves performance by running AI only during campaign creation, then using native AL code for order processing
- Implements campaign logic via OnBeforeReleaseSalesDoc event to check shipping addresses against stored postal codes and add promotional items

- "The core to any AI system is prompt management. In this case we have to manage the interaction between two prompts." (Emphasizes that coordinating multiple AI agents requires careful prompt tuning for each to work effectively together)
