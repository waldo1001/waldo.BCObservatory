# Creating a Low-Cost RFID System with Business Central and Power Automate

[Read the post](https://aardvarklabs.blog/2026/06/12/creating-a-low-cost-rfid-system-with-business-central-and-power-automate/) · Aardvark Labs (Marcel Chabot) · 2026-06-12 · 2551 words · tier community · reviewed (checked by Opus)

> Building a low-cost RFID scan-in and scan-out system using an ESP32 microcontroller, PN532 RFID reader, Power Automate, and Business Central tables. The system captures location-based scans for resource tracking, automatically handles edge cases like forgotten scan-outs, and stores results in two related tables for monitoring.

## Key points

- The hardware is an ESP32 DEVKIT V1 with a PN532 RFID reader on the I2C bus, configured through a web portal with Wi-Fi, location and the Power Automate endpoint
- Power Automate sits in the middle so the device avoids OAuth; its HTTP trigger parses the JSON array and sends each scan to a Business Central API page
- The ARD_Scans table stores raw scans, and its OnInsert trigger creates or closes records in the ARD_ScanTracker table
- If a tag scans in at a new location while still open somewhere else, the earlier record gets a scan-out time and is flagged as assumed for review
- The device buffers up to 50 timestamped scans locally in case Wi-Fi is down
