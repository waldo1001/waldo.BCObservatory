# Creating a Low-Cost RFID System with Business Central and Power Automate

> Building a low-cost RFID scan-in and scan-out system using an ESP32 microcontroller, PN532 RFID reader, Power Automate, and Business Central tables. The system captures location-based scans for resource tracking, automatically handles edge cases like forgotten scan-outs, and stores results in two related tables for monitoring.

[Read the post](https://aardvarklabs.blog/2026/06/12/creating-a-low-cost-rfid-system-with-business-central-and-power-automate/) · Aardvark Labs (Marcel Chabot) · 2026-06-12 · 2551 words · tier community · **unreviewed** (machine-generated)

## Key points

- Hardware uses ESP32 DEVKIT V1 and PN532 RFID scanner with I2C wiring on a breadboard, configured via web portal to connect to Power Automate
- Power Automate acts as middleware between the ESP32 and Business Central, receiving JSON scan data and forwarding it via API
- Business Central processes scans through two tables: ARD_Scans stores raw data, ARD_ScanTracker handles scan-in/out logic with automatic edge-case handling
- When a tag scans at a new location without scanning out from the previous location, the system auto-completes the previous scan-out and flags it for review
- Scan data flows from hardware to Power Automate HTTP trigger, then to Business Central API page, with an OnInsert trigger automating the scan logic
