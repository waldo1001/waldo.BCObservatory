# Step-by-Step Guide to Word Reports in Business Central

[Read the post](https://aardvarklabs.blog/2025/08/01/step-by-step-guide-to-word-reports-in-business-central/) · Aardvark Labs (Marcel Chabot) · 2025-08-01 · 975 words · tier community · **unreviewed** (machine-generated)

> Word reports in Business Central allow developers to create report objects while power users design the layout in Microsoft Word, enabling document-style reports like invoices or activity summaries. This approach separates data definition from presentation design using Word's XML mapping features.

## Key points

- Word reports use DefaultLayout = Word and WordLayout property to reference a DOCX file for formatting
- Developers create the report object with dataset and columns; Word users export and edit the layout through Report Layouts page
- XML Mapping in Word's Developer pane connects report data elements to the document structure
- Repeating controls in Word tables display multiple rows from nested dataitems
- Custom layouts can be created, edited, and marked as default to override the report's built-in layout
