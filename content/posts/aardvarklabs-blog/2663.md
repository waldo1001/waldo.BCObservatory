# Azure OpenAI in Business Central AL: Managed vs Unmanaged

[Read the post](https://aardvarklabs.blog/2025/09/19/azure-openai-in-business-central-al-managed-vs-unmanaged/) · Aardvark Labs (Marcel Chabot) · 2025-09-19 · 763 words · tier community · **unreviewed** (machine-generated)

> The post compares two authentication methods for Azure OpenAI in Business Central: unmanaged (user-controlled) and managed (Microsoft-maintained). Unmanaged offers control and customization but requires maintenance, while managed is simpler, includes grounded Bing search integration when Copilot web search is enabled, and includes costs in the Business Central subscription.

## Key points

- Unmanaged OpenAI lets you control deployment, location, model updates, and tuning through SetAuthorization, but requires ongoing maintenance
- Managed resource uses SetManagedResourceAuthorization and is included in Business Central allotment without separate Azure billing
- Managed resource with Copilot web search enabled provides grounded Bing search, allowing AI responses supplemented by real-time web data
- Model upgrades in managed resource can change behavior; unmanaged gives control over update timing but requires retuning
- Managed resource simplifies implementation but is not suitable if data containment is a concern

## Quotes

- "The Managed Resource is part of your Business Central allotment and is not billed to your Azure Subscription." (Explains the key cost advantage of using managed resources over unmanaged Azure OpenAI)
- "What Grounded Bing Search does is provide the ability for the OpenAI Agent to utilize a search engine to supplement its response." (Clarifies the primary benefit that makes managed resource attractive for real-time information needs)
- "What works for prompting in one model may not work correctly in a newer model." (Highlights a critical consideration for managed resources when Microsoft upgrades the underlying model)
