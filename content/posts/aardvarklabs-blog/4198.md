> A developer created a visualization tool called the Middle Management Simulator to track and manage multiple AI agents working simultaneously in GitHub Copilot and VS Code. The dashboard displays agent status in real time with animated avatars, helping developers identify blocked agents, monitor progress, and find conversations requiring human input.

## Key points

- Multiple AI agents working simultaneously create visibility challenges without proper management tools
- The Middle Management Simulator uses local Copilot workspace data to animate agent avatars and show real-time status
- Visual indicators like raised hands signal when agents have questions needing human attention
- The dashboard provides insights into blocked agents, token consumption, and task progress
- The tool balances practical functionality with engaging interface design inspired by screensaver concepts
