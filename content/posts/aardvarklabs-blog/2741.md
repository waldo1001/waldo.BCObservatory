# Understanding AL Development: String Conversion Management Code Unit

[Read the post](https://aardvarklabs.blog/2025/10/24/understanding-al-development-string-conversion-management-code-unit/) · Aardvark Labs (Marcel Chabot) · 2025-10-24 · 251 words · tier community · reviewed (checked by Opus)

> The String Conversion Management Code Unit provides four procedures for handling text transformations in AL development, including encoding conversion, padding, decimal removal, and alphanumeric filtering. It wraps .NET System.Text objects functionality that would be difficult to implement in AL alone.

## Key points

- Contains four helper procedures: WindowsToASCII, GetPaddedString, RemoveDecimalFromString, and RemoveNonAlphaNumericCharacters
- WindowsToASCII converts Windows encoding to ASCII with closest character equivalents
- GetPaddedString adds padding to specified length with customizable character and justification
- RemoveDecimalFromString filters non-numeric characters while preserving decimal points, then pads result
- RemoveNonAlphaNumericCharacters uses regular expressions to strip special characters and underscores
