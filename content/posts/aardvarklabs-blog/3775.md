# Connect Claude to Business Central MCP: A Step-by-Step Guide

> This guide explains how to connect Claude AI desktop to a Business Central MCP server using a locally hosted Python proxy, eliminating authentication complexity. It covers setting up Azure AD app registration, configuring Business Central, installing the proxy tool, and updating Claude's configuration file.

[Read the post](https://aardvarklabs.blog/2026/07/24/connect-claude-to-business-central-mcp-a-step-by-step-guide/) · Aardvark Labs (Marcel Chabot) · 2026-07-24 · 886 words · tier community · **unreviewed** (machine-generated)

## Key points

- Use a local Python proxy to simplify Claude-to-MCP authentication and configuration
- Create an Azure AD app registration with specific redirect URIs and API permissions
- Register the Azure AD app in Business Central via Microsoft Entra Applications
- Install bc-mcp-proxy Python package and run setup to generate configuration files
- Add the proxy configuration to Claude Desktop's claude_desktop_config.json file under mcpServers
