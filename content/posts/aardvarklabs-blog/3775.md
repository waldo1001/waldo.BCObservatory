# Connect Claude to Business Central MCP: A Step-by-Step Guide

[Read the post](https://aardvarklabs.blog/2026/07/24/connect-claude-to-business-central-mcp-a-step-by-step-guide/) · Aardvark Labs (Marcel Chabot) · 2026-07-24 · 886 words · tier community · reviewed (checked by Opus)

> Step-by-step guide to connecting Claude Desktop to a Business Central MCP server through a locally hosted Python proxy (bc-mcp-proxy), which reduces authentication and configuration complexity. It covers the Entra ID app registration with redirect URIs and API permissions, registering the app in Business Central, running the proxy setup, and adding the generated config to claude_desktop_config.json.

## Key points

- Use a local Python proxy to simplify Claude-to-MCP authentication and configuration
- Create an Azure AD app registration with specific redirect URIs and API permissions
- Register the Azure AD app in Business Central via Microsoft Entra Applications
- Install bc-mcp-proxy Python package and run setup to generate configuration files
- Add the proxy configuration to Claude Desktop's claude_desktop_config.json file under mcpServers
