# Troubleshooting AL Extension in VS Code: Phantom Errors

> Resolving phantom AL extension errors in VS Code where tables appear marked as missing permission sets despite successful compilation. The issue occurs because file updates are only processed when the AL extension starts, and can be fixed by restarting the extension host.

[Read the post](https://aardvarklabs.blog/2026/07/03/troubleshooting-al-extension-in-vs-code-phantom-errors/) · Aardvark Labs (Marcel Chabot) · 2026-07-03 · 138 words · tier community · **unreviewed** (machine-generated)

## Key points

- Red error markers on tables claiming missing permission sets despite successful compilation indicate phantom errors
- Dependency updates or permission set changes may not be recognized until the AL extension restarts
- Restarting the AL extension via Developer: Restart Extension Host or closing and reopening VS Code resolves the issue

## Quotes

- "The issue is that some of the files and associated errors are only handled when the AL Extension starts." (Explains the root cause of phantom errors appearing after dependency or permission updates)
