# Automate Business Central Extension Deployment with PowerShell and the Admin API

> PowerShell automation script that deploys Business Central extensions to production by sorting them by dependencies, checking installed versions, and monitoring installation status through the Admin API. Useful when deploying multiple extensions from UAT environments or performing large-scale updates.

[Read the post](https://aardvarklabs.blog/2026/09/25/automate-business-central-extension-deployment-with-powershell-and-the-admin-api/) · Aardvark Labs (Marcel Chabot) · 2026-09-25 · 1925 words · tier community · **unreviewed** (machine-generated)

## Key points

- Script handles dependency resolution by extracting metadata from .app files and performing topological sorting to determine correct install order
- Version comparison prevents downgrading extensions by checking installed versions against incoming packages
- Automated monitoring polls the Admin API until installation succeeds or fails, eliminating manual oversight
- Multi-step process includes authentication via OAuth2, metadata extraction using 7-Zip, and multipart form-data uploads
- Circular dependency detection throws errors to prevent infinite loops during dependency graph traversal
