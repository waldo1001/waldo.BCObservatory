# Step-by-Step Guide to Business Central API Queries

[Read the post](https://aardvarklabs.blog/2025/07/11/step-by-step-guide-to-business-central-api-queries/) · Aardvark Labs (Marcel Chabot) · 2025-07-11 · 674 words · tier community · **unreviewed** (machine-generated)

> This post explains how to create Query objects configured as APIs in Business Central to expose data for external systems like Power BI and Power Automate. It demonstrates building a Vendor Ledger API and connecting it to Power BI for reporting, highlighting advantages like handling related records and enforcing read-only access.

## Key points

- Query objects configured with API settings (APIGroup, APIPublisher, APIVersion, QueryType = API) automatically expose data to external systems
- Query-based APIs handle related records easily and can nest several layers deep without requiring separate list parts
- Query APIs are read-only by nature, preventing accidental write operations and protecting data integrity when shared with reporting teams
- Query APIs can be directly connected to Power BI using the Dynamics 365 Business Central connector to build reports
