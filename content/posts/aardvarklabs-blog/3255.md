# Navigating Namespace Changes in Business Central 28

[Read the post](https://aardvarklabs.blog/2026/05/01/navigating-namespace-changes-in-business-central-28/) · Aardvark Labs (Marcel Chabot) · 2026-05-01 · 462 words · tier community · reviewed (checked by Opus)

> Business Central 28 introduces fully qualified names for pages, codeunits, reports, and record references, allowing developers to reference objects directly without requiring using statements at the top of files. This improves code clarity by making object origins explicit at the point of use.

## Key points

- Fully qualified names enable direct object reference without using statements
- Reduces namespace declarations at the top of files, preserving code space
- Applies to pages, codeunits, reports, and RecordRef objects
- Makes code more readable by showing object origin at the line level
