- Agents perform work in discrete steps, and you can view each step's description, reasoning, and details in the Agent Tasks page
- The View Log Entries shows how an agent navigated pages and invoked actions; View Details reveals what data and tools the agent accessed
- Adjusting agent permissions, creating tuned profiles with limited role options, and controlling data visibility improves agent performance and reduces token usage
- Monitor Copilot credit consumption to understand agent costs; each credit costs $0.01
