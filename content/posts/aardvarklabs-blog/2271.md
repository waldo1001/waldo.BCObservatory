# Understanding RDLC Reports in Business Central

[Read the post](https://aardvarklabs.blog/2025/08/08/understanding-rdlc-reports-in-business-central/) · Aardvark Labs (Marcel Chabot) · 2025-08-08 · 1189 words · tier community · **unreviewed** (machine-generated)

> RDLC reports use Report Definition Language Client to create self-hosted pixel-perfect printed reports in Business Central. This post explains RDLC fundamentals, how to edit existing report layouts with Microsoft Report Builder, and when to use RDLC versus Excel and Word reporting formats.

## Key points

- RDLC reports are self-hosted and can contain data, unlike RDL which requires separate hosting
- Microsoft Report Builder (from Power BI team) is required; files must have .RDL extension to open
- Report elements use exact positioning and can grow/shrink, enabling pixel-perfect layouts
- Tablix is the powerful data element that functions as table or matrix with row/column grouping
- Expressions can control almost any property including visibility, color, and calculated values

## Quotes

- "RDLC is capable of self-hosting the report and can contain the data, where the RDL simply defines the report and must be hosted." (Explains the key architectural difference between RDLC and RDL technologies)
