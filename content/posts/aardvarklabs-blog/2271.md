# Understanding RDLC Reports in Business Central

[Read the post](https://aardvarklabs.blog/2025/08/08/understanding-rdlc-reports-in-business-central/) · Aardvark Labs (Marcel Chabot) · 2025-08-08 · 1189 words · tier community · reviewed (checked by Opus)

> RDLC reports use Report Definition Language Client to create self-hosted pixel-perfect printed reports in Business Central. This post explains RDLC fundamentals, how to edit existing report layouts with Microsoft Report Builder, and when to use RDLC versus Excel and Word reporting formats.

## Key points

- RDLC can self-host a report and hold its data, while RDL only defines the report and needs separate hosting
- Editing needs Microsoft Report Builder; it only opens RDL files, so rename the exported .rdlc or type the full path in the open dialog
- Elements sit at exact positions and can grow or shrink, which gives pixel-precise printed output
- A Tablix connects to a dataset and supports row and column groups, so it can act as a table or a matrix
- Almost any property can be driven by an expression; new layouts are uploaded through Report Layouts with RDLC chosen as the format

## Quotes

- "RDLC is capable of self-hosting the report and can contain the data, where the RDL simply defines the report and must be hosted." (Explains the key architectural difference between RDLC and RDL technologies)
