# Streamline Your AL Development with Global NuGet Symbols

[Read the post](https://aardvarklabs.blog/2026/01/16/streamline-your-al-development-with-global-nuget-symbols/) · Aardvark Labs (Marcel Chabot) · 2026-01-16 · 162 words · tier community · reviewed (checked by Opus)

> Business Central AL 17.0 allows developers to download Business Central symbols from Global NuGet feeds instead of needing a live client environment or copying symbols from other projects. This streamlines AL extension development by adding al.symbolsCountryRegion configuration and using a new download symbols command in Visual Studio Code.

## Key points

- AL 17.0 introduces the ability to download symbols from Global NuGet feeds
- Configure al.symbolsCountryRegion in .VSCode/Settings.json with your country region code (e.g., 'us')
- New 'AL: Download symbols from global sources' command available in Visual Studio Code
- Eliminates the need to log into a Business Central environment or copy symbols from other projects

- "No need to log into a Business Central environment, no accidentally copying old resources from an old project." (Highlights the practical benefits and workflow improvements of using the new Global NuGet approach)
