# Advanced JSON Management for Business Central Developers

> Codeunit 5459 JSON Management provides a comprehensive toolset for reading, writing, and converting JSON in Business Central AL code. It simplifies complex data handling by grouping procedures into Read, Write, and Convert categories, with special attention to SaaS-safe operations for cloud deployments.

## Key points

- JSON Management holds JSON data within the codeunit variable, eliminating the need to manage separate JSONObject variables
- Read operations extract values using property names, dot-separated paths, or array indices with flexible return types
- Write operations build JSON structures by initializing objects/collections and using SetValue, AddArrayValue, or AddJson methods
- Convert operations transform between JSON and XML formats or format decimals as JSON properties
- On-Prem-only procedures exist but should be avoided in SaaS environments for cloud compatibility
