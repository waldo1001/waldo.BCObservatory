# Easy Steps to Edit Word Reports in Business Central

[Read the post](https://aardvarklabs.blog/2025/07/25/easy-steps-to-edit-word-reports-in-business-central/) · Aardvark Labs (Marcel Chabot) · 2025-07-25 · 915 words · tier community · **unreviewed** (machine-generated)

> This post explains how to edit Word report layouts in Business Central by exporting an existing report, modifying it in Microsoft Word using Developer tools, and understanding the XML mapping structure that connects report fields to data. It covers the process from exporting a layout to uploading the modified version back to Business Central.

## Key points

- Export an existing report layout from Business Central using the Report Layouts page, then open it in Microsoft Word to modify.
- Enable Word's Developer tab and use Design Mode to view and edit the report structure with access to XML mapping panes.
- Understand the XML mapping hierarchy where each data item in the AL code becomes an XML node, and each column becomes an XML value in the mapping pane.
- Use tables and grids in Word to manage repeating elements and maintain alignment; add fields by right-clicking in the XML Mapping pane and selecting Insert Content Control.
- Upload the modified Word document as a new report layout in Business Central; create multiple versions to avoid overwriting working reports.
