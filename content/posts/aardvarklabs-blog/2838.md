## Key points

- Use Excel's sheet-specific tab reading to separate header and line data while maintaining relationships
- Store mapping keys in a Dictionary to connect header records with their corresponding line items without excessive lookups
- Read each sheet independently using TempExcelBuffer.OpenBookStream() with the sheet name parameter
- Process headers first, then lines, using the stored keys to establish parent-child relationships
