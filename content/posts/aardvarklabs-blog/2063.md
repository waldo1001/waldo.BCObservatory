# Understanding User Control Host in Business Central

[Read the post](https://aardvarklabs.blog/2025/11/21/understanding-user-control-host-in-business-central/) · Aardvark Labs (Marcel Chabot) · 2025-11-21 · 571 words · tier community · **unreviewed** (machine-generated)

> User Control Host is a new Business Central page type that hosts web pages and custom controls with minimal overhead, designed originally to support Power BI reports and enabling embedded HTML resources without standard page infrastructure.

## Key points

- User Control Host is a simplified page type that requires no source table and supports only a layout, area, and single usercontrol object
- It enables embedding web pages and Power BI reports directly into Business Central with reduced page overhead
- Custom controls require JavaScript and HTML5, building on the foundation of embedded web pages
- The page type is highly restrictive by design, with no actions or editing capabilities, making it the most basic page definition possible
- Dynamic URLs can be constructed to pass parameters like customer numbers or filtered report data to the hosted content
