## Key points

- ToText() is a new method in BC 2025 Wave 1 that quickly converts variable values to text strings with default formatting
- Date and time types accept a boolean parameter that switches between locale and invariant formatting
- ToText() maintains full decimal precision for decimals, unlike the default Decimal field display which restricts to two decimals
- Special formatting behaviors include byte values showing ASCII integer values, GUID values omitting braces, and two-digit month/day/year expressions for dates
