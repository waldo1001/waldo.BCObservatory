# Understanding ToText() in Business Central 2025

[Read the post](https://aardvarklabs.blog/2025/04/25/understanding-totext-in-business-central-2025/) · Aardvark Labs (Marcel Chabot) · 2025-04-25 · 1095 words · tier community · reviewed (checked by Opus)

> ToText(), new in Business Central 2025 Wave 1, turns values of many AL data types into text using a fixed default format with no formatting options, though date and time types take an optional boolean for invariant output. The post shows the results for decimal, big integer, integer, byte, boolean, date, time, datetime, duration, GUID and version, noting output mostly matches Format(value, 0, 0) and that it does not replace Format.

## Key points

- ToText() is a quick display helper added in BC 2025 Wave 1 and is not a replacement for the Format method
- Date, time, datetime and duration ToText() accept a boolean; the default is false, and true gives invariant output like Format(value, 0, 9)
- Decimal ToText() keeps the full precision of the value, while a default Decimal field shows two decimals
- Byte ToText() returns the integer value rather than the ASCII character, GUIDs lose their braces, and dates use two-digit month, day and year
- A sample card page ARD_ToTextExample shows each type next to its ToText() result

## Quotes

- "This is not a replacement for the Format method but provides a quick way to format a value for display." (Establishes the purpose and scope of ToText() as a convenience method rather than a full replacement for existing formatting approaches)
- "The ToText() will function across the full precision of the value." (Highlights a key difference from default field display, showing ToText() preserves decimal precision rather than truncating it)
