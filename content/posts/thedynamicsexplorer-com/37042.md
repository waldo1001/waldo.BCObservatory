# Dynamics 365 Business Central – Why when I create new users do they get full access by default

[Read the post](https://thedynamicsexplorer.com/2026/02/09/dynamics-365-business-central-why-when-i-create-new-users-do-they-get-full-access-by-default/) · The Dynamics Explorer (Gavin Whittaker) · 2026-02-09 · 381 words · tier community · **unreviewed** (machine-generated)

> New users in Business Central automatically receive full access to their first company based on their assigned license. Administrators can prevent this by modifying permission sets in the License Configuration page.

## Key points

- New users inherit default permissions based on their license type and security group assignments
- The License Configuration page controls which permission sets are automatically granted with each license
- Administrators can remove permission sets like D365 BUS FULL ACCESS to restrict default access
- Changes to license configuration apply only to newly created users, not existing ones
