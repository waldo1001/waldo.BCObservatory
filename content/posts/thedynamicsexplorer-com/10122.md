# Dynamics 365 Business Central – Month End Accruals for GRNI Purchase Orders and Unposted Purchase Invoices

[Read the post](https://thedynamicsexplorer.com/2025/09/15/dynamics-365-business-central-month-end-accruals-for-grni-purchase-orders-and-unposted-purchase-invoices/) · The Dynamics Explorer (Gavin Whittaker) · 2025-09-15 · 689 words · tier community · reviewed (checked by Opus)

> This post explains how to identify and accrue for unposted purchase invoices and goods received not invoiced (GRNI) purchase orders at month end using the Purchase Lines page in Analysis Mode, then post accruals through a Recurring General Journal.

## Key points

- Use Purchase Lines page with Analysis Mode to filter unposted invoices (Document Type = Invoice, Type = G/L Account) and GRNI orders (Document Type = Order, Type = G/L Account, Amt. Rcd. Not Inv. Ex. VAT <>0)
- Apply date filters to exclude invoices from later periods and use the Pivot Function to summarize by GL code if needed
- Export filtered data to Excel and populate a Recurring General Journal to post month-end accruals and reversals
- This approach applies only to G/L Account line items; items can use Expected Costing in Inventory Setup for automatic accrual posting
