# Dynamics GP to Business Central – How to Recreate the GL Summary Enquiry using G/L Account Balance, Analysis Mode or an Analysis View

[Read the post](https://thedynamicsexplorer.com/2025/04/11/dynamics-gp-to-business-central-how-to-recreate-the-gl-summary-enquiry-using-g-l-account-balance-analysis-mode-or-an-analysis-view/) · The Dynamics Explorer (Gavin Whittaker) · 2025-04-11 · 1039 words · tier community · reviewed (checked by Opus)

> When migrating from Dynamics GP to Business Central, GL account structures change from segmented codes to single codes with dimensions. The post explains three methods to recreate Dynamics GP's GL Summary Enquiry view in Business Central: filtering the Chart of Accounts page, using Analysis Mode with natural language in Copilot, or creating an Analysis View.

## Key points

- Dynamics GP uses segmented GL codes (e.g., 200-5170-00) while Business Central uses single GL codes with dimensions for department and division
- Microsoft's migration tools consolidate segmented GL codes into single codes and create dimensions, so 50 variants of a Payroll Taxes code become one GL code
- Chart of Accounts in Business Central shows only total balances at GL code level, unlike Dynamics GP's Summary Enquiry which shows balances for specific code combinations
- Three methods to view GL balances like Dynamics GP: pre-filter Chart of Accounts before opening G/L Account Balance, use Analysis Mode on General Ledger Entries with Copilot natural language support, or create an Analysis View with compression by month and dimensions
