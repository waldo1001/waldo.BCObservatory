# Dynamics 365 Business Central – Error Message “You have one or more documents that must be posted before you post document no….” when posting a Journal

[Read the post](https://thedynamicsexplorer.com/2025/11/10/dynamics-365-business-central-error-message-you-have-one-or-more-documents-that-must-be-posted-before-you-post-document-no-when-posting-a-journal/) · The Dynamics Explorer (Gavin Whittaker) · 2025-11-10 · 540 words · tier community · **unreviewed** (machine-generated)

> When posting a journal in Business Central, an error occurs if the journal's number series has manual numbers disabled but the user tries to enter a custom document number. The post explains three solutions: enable manual numbers on the number series, remove the number series from the batch, or use the renumber function to auto-generate the next sequential number.

## Key points

- The error happens when a journal batch is assigned a number series with manual numbers disabled, preventing users from entering custom document numbers
- Manual numbers setting on the number series controls whether users can enter their own document numbers in journal batches using that series
- Three solutions exist: enable manual numbers, remove the number series from the batch, or use the renumber document numbers function
- The renumber function automatically fetches the next sequential number from the series, ensuring proper journal numbering

- "You have one or more documents that must be posted before you post document no.." (This is the exact error message users encounter, helping them identify the posting validation issue)
