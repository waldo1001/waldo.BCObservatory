# Dynamics GP to Business Central – How to Control your General Ledger Code and Dimension Combinations using Allowed Values Filter

[Read the post](https://thedynamicsexplorer.com/2025/06/16/dynamics-gp-to-business-central-how-to-control-your-general-ledger-code-and-dimension-combinations-using-allowed-values-filter/) · The Dynamics Explorer (Gavin Whittaker) · 2025-06-16 · 525 words · tier community · reviewed (checked by Opus)

> When migrating from Dynamics GP to Business Central, General Ledger segments become dimensions that are available to any account by default. The post explains how to control which dimension values can be used with specific GL accounts using the Allowed Values Filter feature to replicate Dynamics GP's segment-code restrictions.

## Key points

- Dynamics GP combines GL codes with segment codes, while Business Central separates GL accounts from dimensions
- Business Central's consolidated chart of accounts is more efficient than creating separate GL codes for each cost centre combination
- Allowed Values Filter on the GL Account card restricts which dimension values can be posted to that account
- This feature requires Code Mandatory posting to work effectively

## Quotes

- "The solution to this issue is the Allowed Values Filter to limit the Dimension Values allowed on your General Ledger Account Card." (Provides the direct answer to achieving Dynamics GP-like control in Business Central)
