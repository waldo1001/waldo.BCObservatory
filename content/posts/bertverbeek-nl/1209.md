# Migrate bc2adls from PTE to appsource extension

[Read the post](https://www.bertverbeek.nl/blog/2026/01/07/migrate-bc2adls-from-pte-to-appsource-extension/) · Discover MS BC - Bert Verbeek (Bert Verbeek) · 2026-01-07 · 363 words · tier community · **unreviewed** (machine-generated)

> The bc2adls extension for exporting Business Central data to Azure Data Lake Storage is now available on AppSource. Users with the existing PTE extension can migrate to the AppSource version using a migration app while preserving their exported data and configuration.

## Key points

- bc2adls moved from PTE to AppSource in 2026, providing easier updates and maintenance
- A dedicated migration app copies data from PTE tables to AppSource tables automatically
- Manual reconfiguration of Azure credentials (Tenant ID, Client ID, Client Secret) is required after migration
- Users should verify migration success and test exports before uninstalling the old PTE extension

- "This migration app will automatically copy all the data from the PTE tables to the appsource tables." (Explains the key benefit: data preservation during the migration process without manual intervention)
