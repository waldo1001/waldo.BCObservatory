# [Preview] bc2adls and Fabric Open Mirroring

[Read the post](https://www.bertverbeek.nl/blog/2025/05/12/preview-bc2adls-and-fabric-open-mirroring/) · Discover MS BC - Bert Verbeek (Bert Verbeek) · 2025-05-12 · 630 words · tier community · reviewed (checked by Opus)

> bc2adls release 26.32 adds preview support for Microsoft Fabric Open Mirroring. Business Central data files go to a Fabric Landing Zone, and Fabric does the CDC processing itself, so no notebook is needed. Setup requires a Landing Zone string, a _metadata.json file created through Schema Export, and a __rowMarker__ column in the exported files.

## Key points

- Open Mirroring now accepts CSV as well as Parquet, which lets bc2adls feed Fabric without a notebook
- Configure the Landing Zone string in bc2adls; authentication is the same as the regular Fabric integration
- Schema Export creates the _metadata.json file, which defines the key columns and column data types
- __rowMarker__ values: 0 means insert, 1 update, 2 delete; bc2adls does not use 4 (upsert)
- File names must be 20-digit continuous numbers, and resetting a table restarts the numbering; the feature is in preview in both bc2adls and Fabric

## Quotes

- "So no need for running a notebook anymore. Fabric will do the CDC processing for you." (Explains the key benefit of Open Mirroring - automatic data processing without manual intervention)
- "The benefit is then that you can use the data faster!" (Clarifies the performance advantage of using Open Mirroring over manual notebook processing)
- "Please mention that this feature is still in preview in bc2adls but also in Microsoft Fabric!" (Important caveat about the maturity level of both the feature and the tool)
