# [Preview] bc2adls and Fabric Open Mirroring

[Read the post](https://www.bertverbeek.nl/blog/2025/05/12/preview-bc2adls-and-fabric-open-mirroring/) · Discover MS BC - Bert Verbeek (Bert Verbeek) · 2025-05-12 · 630 words · tier community · **unreviewed** (machine-generated)

> BC2ADLS now supports Microsoft Fabric's Open Mirroring feature, allowing Business Central data to be exported to a Fabric Landing Zone in CSV or Parquet format without requiring manual notebook processing. Fabric automatically handles change data capture and replication, enabling faster data access from Business Central to Fabric.

## Key points

- Open Mirroring requires a _metadata.json file describing the table schema with key columns and column data types
- CSV files are now supported alongside Parquet format in Open Mirroring
- The __rowMarker__ column indicates operation type: 0 for inserts, 1 for updates, 2 for deletes
- File names must be in 20-digit continuous number format; resetting a table resets the number sequence
- BC2ADLS v26.32 adds Open Mirroring support, currently in preview

- "So no need for running a notebook anymore. Fabric will do the CDC processing for you." (Explains the key benefit of Open Mirroring - automatic data processing without manual intervention)
