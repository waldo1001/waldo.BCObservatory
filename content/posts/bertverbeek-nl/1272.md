# Agents in Business Central – part 5 – Creating agent from code

[Read the post](https://www.bertverbeek.nl/blog/2026/02/23/agents-in-business-central-part-5-creating-agent-from-code/) · Discover MS BC - Bert Verbeek (Bert Verbeek) · 2026-02-23 · 640 words · tier community · reviewed (checked by Opus)

> This post explains how to create, configure, and register agents programmatically in Business Central using AL code instead of relying solely on configuration. It covers agent interfaces, capability registration, setup pages, and KPI tracking needed for production-ready, ALM-compatible agent solutions.

## Key points

- Register the agent as a Copilot capability by extending the Copilot Capability enum and registering it on install
- Implement IAgentFactory to control agent creation, setup experience, and access; implement IAgentMetadata to control runtime display and UI
- Use IAgentTaskExecution to annotate agent messages, offer user intervention suggestions, and set page context such as currency and language
- Create setup pages using PageType ConfigurationDialog with a temporary source table that has a User Security ID field
- Build KPI pages as CardPart pages with cuegroups and a User Security ID field, assigned via the IAgentMetadata implementation
