> This post explains how to create, configure, and register agents programmatically in Business Central using AL code instead of relying solely on configuration. It covers agent interfaces, capability registration, setup pages, and KPI tracking needed for production-ready, ALM-compatible agent solutions.

## Key points

- Register agents by extending the Copilot Capability enum and using the Agent codeunit during installation
- Implement IAgentFactory to control agent creation, setup experience, and access; implement IAgentMetadata to control runtime display and UI
- Use IAgentTaskExecution to analyze agent messages and provide user intervention suggestions with pre-built buttons
- Create setup pages using PageType ConfigurationDialog with SourceTableTemporary set to true and a User Security ID field
- Build KPI pages as CardPart pages with cuegroups and User Security ID field, assigned via IAgentMetadata methods
