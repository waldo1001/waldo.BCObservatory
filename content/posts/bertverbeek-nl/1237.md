> Building effective agents in Business Central requires well-structured prompts with clear responsibilities, guidelines, and task instructions. The post explains how to use memory, page-specific instructions, and conditional logic to guide agent behavior reliably and keep humans in control.

## Key points

- Agent instructions need three core components: responsibilities (scope and boundaries), guidelines (rulebook for behavior), and task instructions (concrete procedural steps)
- Agents should ask for help when data is missing or unclear, and request user review for important steps to maintain human oversight
- Agents can memorize specific actions, search results, and explicitly instructed values, but not the full state of every page
- Use page-specific instructions with conditional logic to provide detailed guidance only when needed and improve performance
- Business Central agents have context-aware tools like searching pages, selecting rows, executing actions, and setting field values

- "The way you guide and structure your agent's behavior determines whether it becomes a reliable assistant or a confused chatbot." (Highlights that prompt quality directly impacts agent reliability and usefulness)
