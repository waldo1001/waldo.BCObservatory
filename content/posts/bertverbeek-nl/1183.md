# Microsoft Agent Framework and Business Central MCP server

> The Business Central MCP server enables AI agents to connect to Business Central through the Microsoft Agent Framework. Pro-code developers can use the open-source Agent Framework combining Semantic Kernel and AutoGen to build .NET and Python agents that authenticate, connect to the MCP endpoint, and expose Business Central tools.

## Key points

- Business Central MCP server launched at Directions EMEA 2025 for connecting AI agents
- Microsoft Agent Framework combines Semantic Kernel and AutoGen for building AI agents in .NET and Python
- Integration requires three steps: setting up authentication, connecting to MCP endpoint, and creating the MCP plugin
- Agents can access Business Central tools through the MCP server plugin initialized in the kernel
