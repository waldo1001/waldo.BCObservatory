# Native connection with Fabric in Business Central

> Business Central introduces native integration with Microsoft Fabric for data synchronization, replacing the need for APIs or bc2adls tools. The sync operates directly from the SQL database using change logs, supporting all tables with minute-level latency and no impact on Business Central performance.

[Read the post](https://www.bertverbeek.nl/blog/2026/09/30/native-connection-with-fabric-in-business-central/) · Discover MS BC - Bert Verbeek (Bert Verbeek) · 2026-09-30 · 511 words · tier community · **unreviewed** (machine-generated)

## Key points

- Native Fabric integration uses Open Mirroring technology and syncs from SQL change logs, not APIs or external tools
- Sync has no NST impact, supports deletions, and delivers data within minutes with automatic retries
- Setup and management available through Business Central UI and fully via APIs for selecting companies, tables, and triggering exports
- Both environments must be in the same tenant; Fabric SKU license (F2 or higher) required; up to 500 tables can be selected
- bc2adls transitions to maintenance mode; Fabric integration becomes the recommended export method for Business Central data
