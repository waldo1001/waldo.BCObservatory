# Business Central to Microsoft Fabric is a mirror. But what if you want to know what actually changed?

[Read the post](https://www.bertverbeek.nl/blog/2026/11/03/business-central-%e2%86%92-microsoft-fabric-is-a-mirror-but-what-if-you-want-to-know-what-actually-changed/) · Discover MS BC - Bert Verbeek (Bert Verbeek) · 2026-11-03 · 195 words · tier community · reviewed (checked by Opus)

> Business Central data mirrored to Microsoft Fabric appears as static copies by default, but partners can enable delta change data feeds to track table modifications and version history in the mirroring database using Fabric notebooks and SQL queries.

## Key points

- By default, Business Central tables are only mirrored into the Fabric mirroring database, and the connector does not expose changes
- Enable the delta change data feed setting to capture changes to the mirrored tables
- Create a shortcut to the mirroring database inside a lakehouse, then query it from a notebook
- DESCRIBE HISTORY lists the table versions, and table_changes shows the change type, commit version and timestamp for each row
- The example shows one customer's name being updated and another customer being newly inserted

## Quotes

- "the table in Business Central is replicated inside the mirroring database in Fabric" (Clarifies that Fabric mirroring creates copies of BC tables for analytics)
- "with this you can track all the data changes inside a table" (Summarizes the end goal of using delta change data feeds for audit and analytics)
