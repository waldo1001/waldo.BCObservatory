# Business Central to Microsoft Fabric is a mirror. But what if you want to know what actually changed?

[Read the post](https://www.bertverbeek.nl/blog/2026/11/03/business-central-%e2%86%92-microsoft-fabric-is-a-mirror-but-what-if-you-want-to-know-what-actually-changed/) · Discover MS BC - Bert Verbeek (Bert Verbeek) · 2026-11-03 · 195 words · tier community · **unreviewed** (model text not yet checked)

> Business Central data mirrored to Microsoft Fabric appears as static copies by default, but partners can enable delta change data feeds to track table modifications and version history in the mirroring database using Fabric notebooks and SQL queries.

## Key points

- Business Central tables are replicated as mirrors in Fabric's mirroring database without change tracking by default
- The delta change data feed feature must be explicitly enabled to capture data modifications
- Shortcuts within Fabric lakehouses allow querying change history and tracking specific versions of tables
- SQL commands reveal what changed, including insert, update, and delete operations with timestamps and versions

## Quotes

- "the table in Business Central is replicated inside the mirroring database in Fabric" (Clarifies that Fabric mirroring creates copies of BC tables for analytics)
- "with this you can track all the data changes inside a table" (Summarizes the end goal of using delta change data feeds for audit and analytics)
