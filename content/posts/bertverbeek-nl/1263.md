# Agents in Business Central – part 4 – troubleshooting

[Read the post](https://www.bertverbeek.nl/blog/2026/02/20/agents-in-business-central-part-4-troubleshooting/) · Discover MS BC - Bert Verbeek (Bert Verbeek) · 2026-02-20 · 464 words · tier community · reviewed (checked by Opus)

> This post explains how to troubleshoot Business Central agents when they don't behave as expected. It covers diagnostic tools like the Agent Consumption page and Agent Task Log, and identifies common pitfalls including unclear error messages, poorly written tooltips, excessive fields, and duplicate captions that confuse agents.

## Key points

- Use the Agent Consumption page to monitor credit usage and communicate costs to users
- Review Agent Task Log details to see what the agent observed, remembered, and accessed
- Write clear, actionable error messages that explain both the problem and how to solve it
- Keep tooltips precise since agents read them to understand fields
- Minimize fields and actions, and avoid duplicate captions that confuse the agent

## Quotes

- "Because no matter how well you design an agent, there will be moments where it doesn't behave as expected." (Establishes that troubleshooting is an essential skill for agent builders, not an edge case)
- "Agent then will try to solve the error. So actionable error messages will be perfect." (Shows that error messages serve the agent as instructions, not just users, requiring a different design approach)
