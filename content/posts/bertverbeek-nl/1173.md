> Building a late payment prediction model in Microsoft Fabric using AutoML instead of the native Business Central feature. The post demonstrates how to export BC customer ledger data, engineer features from payment history, train an automated machine learning model, and score open invoices to forecast payment dates for cash flow planning.

## Key points

- AutoML automates machine learning workflow steps like model selection and feature engineering, making AI accessible beyond data scientists
- Feature engineering extracts payment patterns including customer history, payment terms, and posting dates to train the prediction model
- Only closed invoices are used for training to ensure reliable historical data, while open invoices receive predictions for expected close dates
- The trained model and predictions are registered in MLflow and stored in Fabric lakehouse for use in Power BI and other analytics tools
- Data export from Business Central occurs through APIs or bc2adls integration into Fabric for the unified analytics workflow

## Quotes

- "Only closed invoices (where you know exactly how long it took to pay) are used to train the model." (Critical principle for ensuring model accuracy by using only reliable historical data without future information leakage)
