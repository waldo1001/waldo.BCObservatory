# Business Central data in Fabric: the way it should be

[Read the post](https://waldo.be/2026/10/01/business-central-data-in-fabric-the-way-it-should-be/) · waldo's blog (waldo (Eric Wauters), MVP) · 2026-10-01 · 947 words · tier community · reviewed (checked by Opus)

> Business Central now supports native data mirroring to Microsoft Fabric, allowing users to replicate their tables as Delta Parquet files in OneLake with SQL query access. The feature enters public preview in release wave 2 (likely version 29.1) and requires only workspace setup and table selection with no impact on BC performance or API limits.

## Key points

- Native mirroring to Fabric via a new Fabric integration app removes the need for custom data extraction solutions
- Mirror runs a few minutes behind BC, deletes are replicated, and whole tables are copied rather than selected fields
- New BC monitoring pages show sync runs and per-table details, with logs also pushed to Fabric
- No extra BC license cost; Fabric needs a running capacity, replication compute is free, 1 TB storage per capacity unit is free, and querying consumes capacity
- All nine Power BI apps get Fabric-based and multi-company versions

## Quotes

- "getting the data in is free, using it costs capacity" (Explains the cost structure, showing BC incurs no licensing expense while Fabric consumption applies separately)
