# Troubleshooting Series – Ep4 – Event Recorder

[Read the post](https://waldo.be/2025/09/30/troubleshooting-series-ep4-event-recorder/) · waldo's blog (waldo (Eric Wauters), MVP) · 2025-09-30 · 622 words · tier community · **unreviewed** (machine-generated)

> The Event Recorder is a Business Central troubleshooting tool that captures all events during a specific process by starting and stopping recording. It helps developers and troubleshooters identify performance issues, validate functional behavior, debug customizations, understand extension behavior, and document system processes.

## Key points

- Event Recorder captures events in order of execution with event type classification and can generate AL code snippets to subscribe to events
- Useful for identifying performance problems by revealing excessive event calls, duplicate triggers, or heavy subscribers
- Helps verify functional behavior by showing which validations or functions actually execute during business processes
- Displays events from all extensions including third-party apps, making it valuable for understanding extension interactions and conflicts
- Can support documentation and knowledge sharing by creating reproducible traces of system behavior
