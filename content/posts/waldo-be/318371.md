# Analyzing BC Telemetry with AI with the “BC Telemetry Buddy”

[Read the post](https://waldo.be/2025/10/22/i-did-a-thing-again-bc-telemetry-buddy/) · waldo's blog (waldo (Eric Wauters), MVP) · 2025-10-22 · 1803 words · tier community · **unreviewed** (machine-generated)

> BC Telemetry Buddy is a VSCode extension and Model Context Protocol tool that lets users query Business Central telemetry data through natural conversation using GitHub Copilot, without needing to write KQL or have separate subscriptions. It includes features for event discovery, stack trace analysis, report generation, and custom chat modes for focused analysis workflows.

## Key points

- Users can ask questions about BC telemetry in natural language through VSCode without writing KQL queries
- The tool uses a Model Context Protocol bundled in the extension to provide AI agents with BC-specific tools and context
- Multiple authentication methods are supported, with per-workspace configuration enabling organization by customer or environment
- Users can create custom chat modes to define focused analysis types with specific tools and output formats
- The tool integrates with online resources, local KQL files, and discovers both standard and custom telemetry events

## Context

- Features: MCP integration, Natural language telemetry queries, Event discovery, Stack trace analysis, SQL statement analysis, PDF/PNG graph generation, Custom chat modes, Multi-authentication support
