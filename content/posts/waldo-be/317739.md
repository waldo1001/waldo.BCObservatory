> The Sessions window in the Business Central Admin Center allows partners and delegated admins to view active sessions across all server instances and cancel problematic ones to improve system performance and resolve resource issues.

## Key points

- Sessions persist after closing tabs or windows, requiring manual management through the Admin Center
- The Sessions window displays all active sessions including background tasks and allows cancellation of individual sessions or environment restart
- Administrators can cross-reference Database Locks with Sessions to identify which user or process is causing performance issues
- Cancelling sessions should be done carefully to avoid incomplete transactions; restart is a last resort for critical situations
- Access requires delegated admin role or appropriate Admin Center permissions

## Quotes

- "Restart is a last resort. It stops all processes so reserve this for critical situations where cancelling individual sessions didn't resolve the issue." (Establishes the escalation hierarchy for session management, distinguishing between targeted cancellation and environment-wide restart)
