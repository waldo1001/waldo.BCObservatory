# Troubleshooting Series – Ep3 – Missing Indexes

[Read the post](https://waldo.be/2025/08/29/troubleshooting-series-ep3-missing-indexes/) · waldo's blog (waldo (Eric Wauters), MVP) · 2025-08-29 · 962 words · tier community · **unreviewed** (machine-generated)

> Troubleshooting missing indexes in Business Central SaaS environments requires understanding the Missing Indexes page, which reflects SQL DMV data that resets after server restart. Since developers can only add indexes through apps, careful analysis using telemetry to track missing indexes over time helps identify which indexes are truly necessary before implementation.

## Key points

- Indexes can only be added through development via AppSource apps or PTE apps, not through configuration.
- The Missing Indexes page shows SQL DMV data that is lost after database restart or server migration, making it a temporary snapshot.
- Estimated Benefit field calculates usefulness based on seeks, scans, and cost impact to prioritize which indexes to create.
- Tracking missing indexes with telemetry over time across customers and tables provides better analysis than a single snapshot.
- You can remove and modify your own keys without breaking changes, but lack of index usage statistics makes it risky to remove existing indexes.

## Quotes

- "The only way to add indexes, is through development." (Clarifies that index management requires code changes through apps, not UI configuration, which impacts implementation strategy.)
