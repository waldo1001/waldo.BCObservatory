# Handling Business Central Telemetry like a boss: iFacto Telemetry – Pt. 3

> The iFacto Telemetry app extends Business Central's built-in telemetry capabilities by adding custom events to track missing indexes, function performance, media orphans, installed apps, delegated user actions, feature management status, and retention policies. It helps administrators monitor system health and performance across multiple customers and environments.

## Key points

- The app sends custom telemetry events daily to track database issues like missing indexes, media orphans, and retention policy status
- Performance tracking via start/stop markers on custom methods enables comparison of execution duration and SQL statements across customers
- Security monitoring includes delegated user changes to critical data such as vendor bank accounts
- Dashboard visualization consolidates custom telemetry and daily telemetry data into tabs for easier analysis
- Job queue codeunit 1350 must run daily to ensure telemetry events are triggered
