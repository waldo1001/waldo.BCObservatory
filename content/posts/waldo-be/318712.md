# The Business Central 2026 release wave 2 docs nobody asked for ..

> Waldo created an interactive navigation tool for the Business Central 2026 Wave 2 release event videos, mapping 319 features across 38 videos with direct timestamps to help users find specific announcements without watching all 7+ hours. The site uses AI to extract features and quotes from auto-captions and cross-references them with official documentation to highlight gaps or conflicts.

[Read the post](https://waldo.be/2026/10/02/the-business-central-2026-release-wave-2-docs-nobody-asked-for/) · waldo's blog (waldo (Eric Wauters), MVP) · 2026-10-02 · 1356 words · tier community · **unreviewed** (machine-generated)

## Key points

- 319 features identified from 38 videos (7 hours 9 minutes) with developer tools receiving 89 minutes of airtime
- Interactive zoomable wheel organizes features by 10 functional areas, with clickable timestamps linking to exact seconds in YouTube videos
- Discovered 22 documented features not shown in videos and 178 shown but not documented, plus 46 status conflicts between video announcements and official docs
- Site built using AI to process 68,000 words of YouTube captions, extract features and quotes, and create a searchable index across all videos

- "Every single thing on the site exists to get you to the right video, at the right second, as fast as possible." (Explains the core design philosophy of optimizing user navigation to specific content rather than consuming full-length videos.)
