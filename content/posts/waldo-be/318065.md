# BCTalent – Escape Rooms

> The BCTalent program created Business Central escape rooms where trainees complete consultant or developer tasks within BC to unlock progression. The framework-based app tracks progress via events and telemetry, with potential for future use by ISVs and at industry events.

[Read the post](https://waldo.be/2025/07/25/bctalent-escape-rooms/) · waldo's blog (waldo (Eric Wauters), MVP) · 2025-07-25 · 1154 words · tier community · **unreviewed** (machine-generated)

## Key points

- Escape rooms are BC apps organized as venues (consultant and developer themed) with sequential rooms unlocked by completing tasks
- System auto-evaluates task completion using event subscriptions and test codeunits to detect user actions like record creation or code changes
- Framework app uses interfaces for each entity type with HTML resource files for instructions and solutions
- Telemetry and Azure Data Explorer dashboards track completion times, hints used, and participant progress
- Future plans include releasing the framework for ISVs to create custom rooms for products, interviews, and training

## Quotes

- "90 minutes in Business Central, where you need to gain access to different rooms by discovering and executing Business Central related tasks." (This describes the core mechanic of using BC itself as both platform and training mechanism.)
- "I even see opportunities for you, ISVs, to be able to download the framework app and create your own rooms for your own products." (Indicates the framework's extensibility and future commercial potential beyond Microsoft training.)
