# BC Telemetry Buddy – 84 commits later..

[Read the post](https://waldo.be/2025/11/30/bc-telemetry-buddy-84-commits-later/) · waldo's blog (waldo (Eric Wauters), MVP) · 2025-11-30 · 1631 words · tier community · reviewed (checked by Opus)

> BC Telemetry Buddy evolved from a proof of concept to a production-ready tool for analyzing Business Central telemetry. The v1.0.0 release transformed it from a bundled extension into modular components, added AI-powered chat features for data discovery and analysis, and implemented comprehensive testing and CI/CD pipelines.

## Key points

- Architecture refactored to separate the VS Code extension from an optional MCP server NPM package, allowing flexible deployment and usage scenarios
- Discovery-first approach with event catalog browsing, schema discovery tools, and ready-made KQL patterns to simplify telemetry exploration
- AI-powered chat participant and specialized chat modes that handle both simple data queries and complex performance analysis automatically
- Multi-profile support added to handle multiple telemetry endpoints, with a setup wizard to guide configuration
- Matured to production quality with 737 tests covering critical paths, 84.87% code coverage, automated CI/CD pipelines, and anonymous usage telemetry

## Quotes

- "In the last 4 weeks, my BC Telemetry Buddy went from "nice demo" to "this might actually be getting somewhere"." (Demonstrates the rapid maturation of the tool from concept to production readiness)
- "The extension now runs completely standalone: commands & KQL go straight to Azure/Kusto. No MCP, no extra process, just VS Code and your telemetry." (Key architectural change that simplifies deployment and usage options for users)
