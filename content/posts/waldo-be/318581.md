# BC Telemetry Buddy .. now with (community) knowledge

[Read the post](https://waldo.be/2026/04/07/bc-telemetry-buddy-now-with-community-knowledge/) · waldo's blog (waldo (Eric Wauters), MVP) · 2026-04-07 · 1069 words · tier community · reviewed (checked by Opus)

> BC Telemetry Buddy now includes a two-layer knowledge base that shares telemetry troubleshooting patterns and investigation playbooks across the community. The tool stores both shared community knowledge and local customer-specific insights as markdown files, allowing the AI to start problem-solving with context rather than from scratch.

## Key points

- The knowledge base has two layers: community articles shipped with the tool and local articles kept in your own workspace, all plain markdown loaded into cache at startup
- After an investigation you can ask the AI to draft an article; it only saves after you confirm, either locally or to the community via a GitHub issue
- A Manage Knowledge Base command in VS Code lists loaded articles and lets you exclude community articles you disagree with, recorded in the config file
- The knowledge base loads at server level, so it works across AI clients such as Claude Desktop, Cursor and Copilot Chat
- Community articles live in the project GitHub repo, and contributions of proven KQL patterns and playbooks are invited

- Features: community knowledge base, local knowledge base, telemetry investigation playbooks, KQL pattern sharing, article exclusion, knowledge base management UI, GitHub integration, markdown-based storage
