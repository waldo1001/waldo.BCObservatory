# BC Telemetry Buddy .. now with (community) knowledge

[Read the post](https://waldo.be/2026/04/07/bc-telemetry-buddy-now-with-community-knowledge/) · waldo's blog (waldo (Eric Wauters), MVP) · 2026-04-07 · 1069 words · tier community · **unreviewed** (machine-generated)

> BC Telemetry Buddy now includes a two-layer knowledge base that shares telemetry troubleshooting patterns and investigation playbooks across the community. The tool stores both shared community knowledge and local customer-specific insights as markdown files, allowing the AI to start problem-solving with context rather than from scratch.

## Key points

- Knowledge base has two layers: community articles that ship with the tool and local articles stored in your workspace
- Users can ask the AI to save new telemetry patterns and solutions back to the knowledge base after investigations
- Community articles can be individually excluded if you disagree with their advice
- Knowledge base works across all AI clients (VS Code, Claude Desktop, Cursor, Copilot Chat) at the server level
- Articles are plain markdown files stored in GitHub, encouraging community contributions of proven KQL patterns and playbooks

- Features: community knowledge base, local knowledge base, telemetry investigation playbooks, KQL pattern sharing, article exclusion, knowledge base management UI, GitHub integration, markdown-based storage
