> BC Observatory is an unofficial knowledge map linking Business Central resources - Learn pages, code, videos, blogs, and roadmap items - to help AI agents find accurate information without guessing. It indexes 25,702 AL objects, 622 videos, 623 community posts, and other sources, accessible as an MCP server, website, and markdown files.

## Key points

- AI agents need connected knowledge to avoid confidently providing wrong answers; BC Observatory links documentation, code, videos, and blogs with source attribution.
- The system uses deterministic parsing for code and selective AI models for summaries and prose, with Opus as reviewer and trust tiers to show review state.
- Users can install the BC Observatory MCP with npx on any agent platform, or use the website at waldo1001.github.io/waldo.BCObservatory with galaxy visualization and neighborhood views.
- Learn MCP and BC Observatory serve different purposes: Learn for documented APIs, BC Observatory for code changes, hotfixes, community insights, and connecting disparate sources.
