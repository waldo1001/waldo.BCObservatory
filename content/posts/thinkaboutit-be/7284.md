# Quick Tip: Business Central Updates 27.1 & 27.2: A Quick Look at What’s New

> Updates 27.1 and 27.2 introduce intelligent agents for automation, improved e-document processing with Peppol support, regional tax enhancements for Czechia and the US, SEPA compliance features, and admin improvements including the ability to cancel running environment updates.

## Key points

- Payables Agent and Sales Order Agent are now generally available, with preview support for MCP agent integration
- E-document workflows enhanced with two-step processing and Power Automate integration, plus extended support for shipment and transfer documents
- New Account Payable Role Center and concealed text field type added for reporting and data security
- Regional improvements include VAT drill-downs for Czechia, 1099 enhancements for the US, and SEPA CAMT0530008 support
- Admin enhancement allows cancellation of running environment updates in 27.2
