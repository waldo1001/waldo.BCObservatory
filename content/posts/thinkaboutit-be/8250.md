# Business Central 29: Introducing Composite Document Layouts

[Read the post](https://thinkaboutit.be/2026/10/business-central-29-introducing-composite-document-layouts/) · think about IT - Steven Renders (Steven Renders) · 2026-10-05 · 1251 words · tier community · **unreviewed** (machine-generated)

> Business Central 2026 release wave 2 introduces Composite Document Layouts, a modular approach to Word document layouts that separates body content, visual theming, and headers/footers into reusable components combined at runtime rather than maintaining separate complete layouts for each combination.

## Key points

- Composite layouts separate concerns: Body Layout (report structure), Theme (fonts and colors), and Header/Footer Layout (branding and company info) are composed at runtime into the final document
- Reduces layout maintenance across multiple reports and companies by reusing components instead of creating separate layouts for each combination
- Existing standalone layouts continue to work; composite layouts add a new optional model without forcing migration or changing default invoice designs after upgrade
- Defaults can be configured at multiple levels (global, company, report, body layout) allowing flexible overrides and gradual introduction through layout status controls

## Quotes

- "Business Central doesn't create another permanent Word layout for every combination. The selected components are combined when the report runs." (This runtime composition model is the core innovation that eliminates the need to maintain separate layouts for each combination of report and branding)
