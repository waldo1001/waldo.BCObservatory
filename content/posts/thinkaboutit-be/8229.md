# Business Central Data Mirroring to Microsoft Fabric Is Coming

> Business Central 2026 release wave 2 introduces data mirroring to Microsoft Fabric, a new analytical data path that synchronizes selected tables and companies to Fabric's OneLake for analytics consumption. This simplifies analytics architecture by eliminating the need to repeatedly extract transactional data through APIs, making it easier to build enterprise data platforms combining Business Central with other sources.

[Read the post](https://thinkaboutit.be/2026/10/business-central-data-mirroring-to-microsoft-fabric-is-coming/) · think about IT - Steven Renders (Steven Renders) · 2026-10-02 · 1301 words · tier community · **unreviewed** (machine-generated)

## Key points

- Simple three-step setup: create mirrored database in Fabric, connect Business Central, select tables and companies to synchronize
- Configuration packages allow Power BI apps and ISV solutions to define required tables, enabling repeatable implementations
- Fabric abstracts the underlying Delta-Parquet storage through SQL endpoints, allowing SQL queries against mirrored tables without direct file access
- Shifts analytics architecture focus from 'how to extract data' to 'what data we need and how to model it' for multi-company analysis and enterprise data platforms
- Monitoring available through Business Central pages, dedicated APIs, and Fabric SQL endpoints with permission sets controlling access

## Quotes

- "Business Central is getting a new data path specifically for analytics." (Clarifies that Fabric mirroring is not just another connector but a fundamental architectural change for analytics workloads)
- "Your analytical consumers no longer need to retrieve Business Central data directly through APIs. The selected data is already available in the analytical platform." (Explains the key advantage: pre-synchronized data eliminates repeated API extraction for analytics)
