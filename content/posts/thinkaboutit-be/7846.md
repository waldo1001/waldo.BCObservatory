# Quick Tip: CalcFields vs SetAutoCalcFields in AL

> FlowFields in Business Central are not stored in the database and must be calculated explicitly. The post explains two methods for calculating them: CalcFields for one-time calculations on single records, and SetAutoCalcFields for automatic calculation during record retrieval, with guidance on which to use to avoid performance issues.

[Read the post](https://thinkaboutit.be/2026/04/quick-tip-calcfields-vs-setautocalcfields-in-al/) · think about IT - Steven Renders (Steven Renders) · 2026-04-23 · 502 words · tier community · **unreviewed** (machine-generated)

## Key points

- CalcFields explicitly calculates FlowFields on the current record when called and is suitable for single-record calculations outside loops
- SetAutoCalcFields automatically calculates specified FlowFields for every record retrieved during FindSet or loop iterations, improving performance over repeated CalcFields calls
- Calling SetAutoCalcFields without parameters clears the auto-calculation list for the record variable
- SetAutoCalcFields is scoped to the record variable, not the table, so different variables do not inherit the setting
- As of BC26 (AL runtime 15.0), SetAutoCalcFields is available on RecordRef, enabling generic code to use the same pattern
