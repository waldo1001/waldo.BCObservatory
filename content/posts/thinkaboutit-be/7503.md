# How Do I: Analyze List Pages and Data Using Analysis Mode in Business Central

> Analysis Mode is a built-in Business Central feature that lets users interactively explore list data through grouping, aggregation, pivoting, and filtering without exporting data or creating reports. It bridges the gap between operational lists and formal reporting, replacing many traditional ad-hoc reports by keeping analysis inside the application.

## Key points

- Analysis Mode allows users to group, aggregate (Sum, Count, Average, Min, Max), pivot, and filter list data interactively while saving multiple analysis views
- Requires DATA ANALYSIS - EXEC permission and is generally available in 2023 release wave 2 and later
- Supports analysis on Query objects and related table fields, with automatic optimization for datasets over 100,000 rows
- Most effective for replacing reports that answer ad-hoc questions; classic reports remain better for fixed layouts and formal distribution
- Positioned between operational filtering and formal Power BI reporting as part of Business Central's analytics ecosystem
