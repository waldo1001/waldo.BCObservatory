# Business Central 2026 Release Wave 1: A Mix of Platform Evolution and Practical Improvements

> Business Central version 28 (April 2026) delivers distributed improvements across supply chain, reporting, governance, and developer tooling rather than single headline features. The release addresses daily friction points in inventory, purchasing, manufacturing, and introduces agent-driven administration infrastructure and semantic search capabilities.

## Key points

- Supply chain gets dozens of practical improvements: variant-level images and attributes, independent drop shipment invoice posting, multi-line invoice matching, and quality management preview
- Reporting evolves with layout governance, financial enhancements, modernized inventory reports using Excel/Word, and language defaults at company level
- Administration receives unified permissions overview, database index management, read-only permission and workflow APIs, plus preview support for cloud migration from non-standard SQL sources
- Developer tools add semantic data search, BC-Bench benchmarking framework, AL test execution from VS Code preview, and MCP server for real-time debugging with agent introspection
- Copilot and agents gain inbox category discovery, dedicated task pane, inline review of suggestions, advanced item KPIs, and ability to stop all active agent tasks
