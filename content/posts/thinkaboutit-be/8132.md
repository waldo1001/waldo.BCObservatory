# BCQuality: A Shared Quality Bar for AL Code, Built for Agents

[Read the post](https://thinkaboutit.be/2026/09/quick-tip-bcquality-a-shared-quality-bar-for-al-code-built-for-agents/) · think about IT - Steven Renders (Steven Renders) · 2026-09-09 · 744 words · tier community · **unreviewed** (machine-generated)

> BCQuality is Microsoft's open repository of quality knowledge for AL code designed to guide both human developers and AI agents toward shared coding standards. It organizes domain-specific rules in markdown files filtered by BC version and functional area, with a three-layer architecture where partners can add custom knowledge that applies automatically during code review.

## Key points

- BCQuality catches subtle AL mistakes that pass compilation but violate best practices, like incorrect SetLoadFields usage or obsolete FindSet patterns that standard linters miss.
- Knowledge files are small markdown articles capped at 100 lines, each covering one concern and filtered by BC version, technology, country, and functional area so agents pull only relevant guidance.
- The three-layer system lets Microsoft maintain endorsed rules, the community contribute patterns that can graduate upward, and partners fork the repository to add custom firm-specific knowledge.
- Installation as a VS Code plugin takes two steps: run 'Chat: Install Plugin from Source' and paste the GitHub URL, then reference it in prompts by name.

## Quotes

- "a knowledge file only earns its place if a capable agent would genuinely get something wrong without it" (Defines the admission criteria for BCQuality rules, ensuring guidance addresses real gaps that automated tools and developer knowledge cannot cover.)
- "BCQuality is built to be pulled in by the agent itself, at the moment the code gets written or reviewed" (Shows how BCQuality solves the adoption problem of traditional guidelines by delivering advice at the point of need rather than requiring manual lookup.)
