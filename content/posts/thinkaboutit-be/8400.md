# Business Central 29: What’s New in the MCP Server?

[Read the post](https://thinkaboutit.be/2026/11/business-central-29-whats-new-in-the-mcp-server/) · think about IT - Steven Renders (Steven Renders) · 2026-11-14 · 520 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2026 release wave 2 introduces new MCP server Data Query Tools that let AI agents dynamically construct and execute AL queries to analyze data across multiple tables without requiring predefined APIs. The tools are read-only, respect user permissions, and include table discovery, schema inspection, and relationship identification capabilities.

## Key points

- Four new system tools enable agents to discover tables, inspect schemas, identify relationships, and execute AL queries dynamically
- Agents no longer need developers to create dedicated APIs for ad hoc analysis across multiple Business Central tables
- Data Query Tools are in preview and will become billable when generally available
- Responsibility shifts from API design to permissions management, agent behavior, and query governance

## Quotes

- "With predefined APIs, developers control the data structures exposed to agents. With dynamic queries, that responsibility shifts more toward permissions, agent behavior, and governance." (Highlights the governance and permission considerations that become critical with dynamic query capabilities.)
