# Business Central 29: What’s New in the MCP Server?

[Read the post](https://thinkaboutit.be/2026/11/business-central-29-whats-new-in-the-mcp-server/) · think about IT - Steven Renders (Steven Renders) · 2026-11-14 · 520 words · tier community · reviewed (checked by Opus)

> Business Central 2026 release wave 2 introduces new MCP server Data Query Tools that let AI agents dynamically construct and execute AL queries to analyze data across multiple tables without requiring predefined APIs. The tools are read-only, respect user permissions, and include table discovery, schema inspection, and relationship identification capabilities.

## Key points

- Four new read-only MCP system tools let agents find tables, inspect schemas, identify table relations, and compile, validate and run AL queries
- Agents can do ad hoc analysis across several tables without a developer building a dedicated API; compiler errors are returned so the agent can fix its query
- AL query object limits on supported queries, execution time and returned data still apply
- MCP Server Configuration now has a Server Features section and a System Tools section, and admins can toggle the server from the Copilot and Agent Capabilities page
- The data query tools are in preview and will become billable at general availability; governance, permissions and query performance matter more

## Quotes

- "With predefined APIs, developers control the data structures exposed to agents. With dynamic queries, that responsibility shifts more toward permissions, agent behavior, and governance." (Highlights the governance and permission considerations that become critical with dynamic query capabilities.)
- "the new MCP data query capability is currently in preview and Microsoft has announced that it will become billable when generally available." (Important for cost planning and production deployment decisions when evaluating this feature.)
