# How Do I: Use the Word Add-in for Business Central Report Layouts

[Read the post](https://thinkaboutit.be/2026/04/how-do-i-use-the-word-add-in-for-business-central-report-layouts/) · think about IT - Steven Renders (Steven Renders) · 2026-04-01 · 1835 words · tier community · reviewed (checked by Opus)

> The Dynamics 365 Business Central Word add-in is a free Microsoft Word extension that simplifies designing Word layouts for document reports by enabling easy field insertion, layout comments, and conditional content hiding based on data values. The add-in requires Business Central version 25 or later, with full data picker functionality in version 27 and later.

## Key points

- The Word add-in provides a task pane for inserting data fields, labels, and report information into layouts without manual workarounds
- Multiple hide controls automatically remove content when empty: Hide Field if Zero, Hide Empty Table, Hide Empty Table Row, and Hide Empty Table Column
- Layout comments can be embedded directly in Word files to document design decisions without affecting printed output
- The add-in works only with data already in the report; adding new fields or complex conditional logic requires developer involvement
- Word layouts still lack advanced features found in RDLC layouts such as conditional formatting, calculated aggregations, and complex page controls
