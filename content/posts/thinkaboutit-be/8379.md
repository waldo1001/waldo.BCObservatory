# Business Central 29: Match Production Database Configuration in Sandbox Environments

[Read the post](https://thinkaboutit.be/2026/11/business-central-29-match-production-database-configuration-in-sandbox-environments/) · think about IT - Steven Renders (Steven Renders) · 2026-11-03 · 280 words · tier community · reviewed (checked by Opus)

> Business Central 2026 release wave 2 introduces Match Production Configuration, an Admin Center action that temporarily adjusts a sandbox database to resemble production configuration for 72 hours. This helps partners and developers test extension performance and behavior more accurately by reducing the gap between sandbox and production environments.

## Key points

- Sandbox databases can be configured to match production database settings in the Admin Center for 72-hour periods
- Feature enables more accurate performance testing, extension development, and cloud migration validation
- Limited to 3 activations per tenant per calendar month with automatic reversion after 72 hours
- Requires environment restart and disconnects active users during activation
- Automation available through Admin Center API for integrated testing workflows
