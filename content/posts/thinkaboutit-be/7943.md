# Quick Tip: How Can You Download the Standard Business Central Power BI Reports?

> Business Central standard Power BI reports are now distributed through official Power BI template apps rather than the old GitHub repository. Users can install apps for Finance, Sales, Purchasing, Inventory, Manufacturing, Projects, Sustainability and others, then download PBIX files from Power BI workspaces, subject to permissions and licensing requirements.

[Read the post](https://thinkaboutit.be/2026/06/quick-tip-how-can-you-download-the-standard-business-central-power-bi-reports/) · think about IT - Steven Renders (Steven Renders) · 2026-06-02 · 285 words · tier community · **unreviewed** (machine-generated)

## Key points

- Standard Power BI reports for Business Central are available through official Microsoft Power BI template apps, not the old GitHub location
- After installing an app in Power BI, users can download the report as a PBIX file from the workspace
- A Power BI Pro license is required to install and use the template apps
- The apps work per company, so separate installation and configuration is needed for multiple companies

- "Microsoft provides standard Power BI reports for Business Central, but the download location is not as obvious as it used to be." (Clarifies that the distribution method has changed from the familiar GitHub location to a new approach)
