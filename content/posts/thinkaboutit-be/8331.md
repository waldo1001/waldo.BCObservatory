# Business Central 29: What’s New in BC-Bench?

[Read the post](https://thinkaboutit.be/2026/10/business-central-29-whats-new-in-bc-bench/) · think about IT - Steven Renders (Steven Renders) · 2026-10-28 · 883 words · tier community · reviewed (checked by Opus)

> BC-Bench is Microsoft's open-source framework for evaluating AI coding agents on Business Central AL development tasks like bug fixing, test generation, and code review. It helps measure whether AI models and tools actually improve AL development performance compared to general coding benchmarks.

## Key points

- AL MCP (Model Context Protocol) improves bug-fixing performance by nearly 10% when integrated with AI agents like GitHub Copilot CLI with Claude Opus 4.6.
- Agent harness choice (GitHub Copilot CLI vs Claude Code) shows no significant performance difference when the underlying model is the same; model selection and tool access matter more.
- BC-Bench is publicly available on GitHub for partners to evaluate AI agents against their own AL development tasks and compare configurations.
- Code review evaluation is now part of BC-Bench, measuring AI-assisted review quality using semantic equivalence rather than exact comment matching.

## Quotes

- "AL MCP gives AI coding agents access to development capabilities such as compiling, publishing, and searching." (Demonstrates that providing tools access is as important as model capability for improving AL development performance.)
- "As AI agents become better at generating code and pull requests, code review could become the next bottleneck." (Identifies code review as an emerging critical capability for AI-assisted development quality assurance.)
