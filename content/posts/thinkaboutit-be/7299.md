# Introduction to GitHub Copilot in VSCode for AL Development

[Read the post](https://thinkaboutit.be/2025/12/introduction-to-github-copilot-in-vscode-for-al-development/) · think about IT - Steven Renders (Steven Renders) · 2025-12-16 · 892 words · tier community · **unreviewed** (machine-generated)

> GitHub Copilot in VSCode offers multiple AI-powered modes - Inline Suggestions, Chat, Ask, Edit, Agent, and Plan - to assist AL developers with code generation, refactoring, and understanding existing code. This guide explains how to set up Copilot and when to use each mode for different development tasks.

## Key points

- Copilot provides six distinct modes tailored to different AL development workflows, from quick autocomplete to workspace-wide refactoring
- Chat mode allows developers to generate full AL objects, explain code, troubleshoot errors, and propose refactors through conversation
- Agent mode performs multi-step changes across multiple files, such as applying ApplicationArea properties or adding telemetry hooks
- Plan mode previews changes before applying them, which is important for AL projects with dependencies and object IDs
- Ask mode provides lightweight code explanations by selecting and highlighting code snippets
