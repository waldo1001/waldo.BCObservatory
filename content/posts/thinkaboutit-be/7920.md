# Quick Tip: What’s in Business Central Update 28.1

[Read the post](https://thinkaboutit.be/2026/05/quick-tip-whats-in-business-central-update-28-1/) · think about IT - Steven Renders (Steven Renders) · 2026-05-13 · 1003 words · tier community · **unreviewed** (machine-generated)

> Business Central Update 28.1 introduces the Expense Agent in public preview, a new Expense Management module for submitting and processing receipts, and expands Agent Designer to production environments. Additional features reaching general availability include excise tax calculation, report layout lifecycle control, and various fixes for deferrals, inventory posting, and localization.

## Key points

- Expense Agent automates receipt extraction, categorization, per diem calculation, mileage routing, and approval workflows at 50 Copilot Credits per receipt and requires explicit Anthropic enablement
- Agent Designer now available on production environments with evaluation tools, previously limited to sandbox
- Report layout administrators can assign statuses (Draft, Pending Approval, Approved, Retired) to control which layouts users see
- Multiple features reaching general availability including excise tax, investment boost for fixed assets, deferrals reports, and approval workflow APIs
- Over 100 application fixes and 13 platform fixes address issues like deferral calculations, VAT on credit memos, inventory posting loops, and browser compatibility

## Quotes

- "Processing is billed on a consumption basis: 50 Copilot Credits per receipt, covering the full cycle from extraction through posting." (Cost structure that must be factored into customer conversations before implementing Expense Agent)
- "The public preview is English only and limited to the US. Australia, New Zealand, and the UK are added in July 2026." (Geographic and language constraints important for deployment planning outside the US market)
