# Quick Tip: What’s in Business Central Update 28.3

> Business Central 28.3 introduces Sales Order Agent to General Availability with multi-agent support and improved item matching, enables free Payables Agent trials with 50 invoice processing, enhances Expense Agent with language support and project assignment, and allows PTE management from the Admin Center.

[Read the post](https://thinkaboutit.be/2026/07/quick-tip-whats-in-business-central-update-28-3/) · think about IT - Steven Renders (Steven Renders) · 2026-07-13 · 413 words · tier community · **unreviewed** (machine-generated)

## Key points

- Sales Order Agent reaches General Availability with multiple agent support per company and smarter item matching capabilities
- Payables Agent now allows free trials processing up to 50 invoices without initial email inbox setup
- Expense Agent adds support for Danish, French, Spanish languages with German coming soon, plus direct project assignment from the web application
- Per-Tenant Extensions can now be uploaded, installed, and managed directly from the Business Central Admin Center
