# Quick Tip: It’s Time to Move to the Word Add-in Data Picker

> The classic XML Mapping pane for Word report layouts in Business Central has started rejecting newly inserted fields as of August 2026, though existing mapped fields remain functional. Microsoft recommends switching to the newer Word add-in data picker, available since Business Central 2025 wave 2, which offers a more modern interface and avoids legacy XML mapping issues.

[Read the post](https://thinkaboutit.be/2026/09/quick-tip-its-time-to-move-to-the-word-add-in-data-picker/) · think about IT - Steven Renders (Steven Renders) · 2026-09-01 · 650 words · tier community · **unreviewed** (machine-generated)

## Key points

- New fields inserted via the XML Mapping pane stopped mapping correctly in August 2026, showing placeholder text instead of actual values
- The issue appears to be in Word's XML mapping layer rather than Business Central itself
- The Word add-in data picker provides a cleaner alternative by inserting mapped fields directly without using the legacy XML Mapping pane
- The add-in approach represents Microsoft's strategic direction for report layout development and avoids exposure to legacy mapping layer problems
- Developers should default to the Word add-in data picker for all new report layout work rather than waiting for the XML Mapping pane to cause more issues
