# Quick Tip: What’s in Business Central Update 28.2

> Business Central Update 28.2 (June 2026) introduces meaningful feature enhancements alongside hotfixes, including improvements to the Sales Order Agent for multilingual support, Quality Management reports with Word layouts as default, financial features like withholding tax and self-billed invoices, new Reporting and Data Analysis APIs, country-specific capabilities for payments and electronic invoicing, and sustainability APIs for data exchange.

[Read the post](https://thinkaboutit.be/2026/06/quick-tip-whats-in-business-central-update-28-2/) · think about IT - Steven Renders (Steven Renders) · 2026-06-11 · 825 words · tier community · **unreviewed** (machine-generated)

## Key points

- Sales Order Agent now supports Belgium and Switzerland with optimized text search language settings for accurate multilingual item lookups, and filters out inline email attachments to reduce Copilot Credits consumption
- Quality Management features reach general availability with Word layouts as the default for printable reports, ability to print directly from Quality Inspection cards, easier Report Selection page access, and integrated demo data installer
- Financial management enhancements include withholding tax calculation for vendors as standard and self-billed invoices for buyer-issued supplier invoices, with accelerated depreciation methods in public preview
- Three new API endpoints for auditing and reporting enable analysis of approval workflows and permissions, plus PDF document retrieval via API for integration scenarios
- Cross-geography data movement for Copilot and agent requests may occur from 1 July 2026; customers should review and configure preferences on the Copilot & agent capabilities page before that date
