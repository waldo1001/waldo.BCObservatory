# Quick Tip: GitHub Copilot Chat Modes Are Now Agents, and Edit Mode Is Gone

[Read the post](https://thinkaboutit.be/2026/09/quick-tip-github-copilot-chat-modes-are-now-agents-and-edit-mode-is-gone/) · think about IT - Steven Renders (Steven Renders) · 2026-09-10 · 277 words · tier community · **unreviewed** (machine-generated)

> GitHub Copilot Chat modes have been reorganized into agent roles in VS Code. The Edit mode has been replaced by diff-based editing within Agent, Plan is now a built-in role, and custom chat modes are now custom agents with a new file extension and configuration interface.

## Key points

- Chat modes are now called agent roles: Agent, Ask, and Plan are the built-in set
- Edit mode was discontinued; its diff-based editing capabilities moved into Agent
- Plan is now a proper built-in role that creates implementation plans and hands off to Agent for coding
- Custom chat modes became custom agents with .agent.md file extension instead of .chatmode.md
- VS Code split the dropdown into Session Target (harness selection) and Agent picker (role selection)

## Quotes

- "Edit did not survive, its diff based editing now sits inside Agent." (Critical change for users relying on Edit mode; they need to know the functionality moved into Agent)
