> Release Wave 27.0 of Dynamics 365 Business Central introduces mandatory features focused on performance, usability, and security. Organizations should enable and test these features in sandbox environments now to ensure extension compatibility before they become mandatory.

## Key points

- Multiple new features will become mandatory in Wave 27.0, including optimized text search, server certificate validation, and auto-save capabilities
- Features are available in Feature Management and should be tested in sandbox environments before they become compulsory
- Extensions and apps may require updates to maintain compatibility with the mandatory features
- The changes span multiple areas including warehouse operations, currency revaluation, tax forms, and navigation search
