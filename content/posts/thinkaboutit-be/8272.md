# Business Central 29: More Control Over Report Layouts and New Report Inbox APIs

[Read the post](https://thinkaboutit.be/2026/10/business-central-29-more-control-over-report-layouts-and-new-report-inbox-apis/) · think about IT - Steven Renders (Steven Renders) · 2026-10-12 · 721 words · tier community · reviewed (checked by Opus)

> Business Central 2026 release wave 2 extends report layout lifecycle management to layouts delivered by Microsoft and extensions, allowing administrators to control which layouts users can select. Additionally, new Report Inbox APIs enable external applications and automation tools to interact with scheduled reports without requiring manual intervention in Business Central.

## Key points

- Layout statuses (Draft, Pending Approval, Approved, Retired) now apply to Microsoft and extension-provided layouts, not just uploaded layouts
- Only approved layouts appear in the layout selector; administrators can still run retired layouts directly from the Report Layouts page
- Administrators can override layout descriptions for layouts from Microsoft, AppSource, and partner extensions
- Report Inbox APIs enable Power Automate, Copilot Studio agents, and external applications to programmatically interact with scheduled report output

- Features: report layout lifecycle management, layout status control, layout description overrides, Report Inbox APIs, API Overview page
