# Quick Tip: BC28: What Is New in Document Reporting

[Read the post](https://thinkaboutit.be/2026/04/quick-tip-bc28-what-is-new-in-document-reporting/) · think about IT - Steven Renders (Steven Renders) · 2026-04-13 · 953 words · tier community · reviewed (checked by Opus)

> BC28 introduces enhanced document reporting features including an improved Word add-in with a redesigned data picker, a new table builder for layouts, lifecycle status management for user-defined layouts, company-level default document language, tooltips on reports, modernized report selection pages, and 36 new document APIs covering sales, purchasing, inventory, and assembly document types.

## Key points

- The Word add-in data picker is redesigned: fields insert on double-click, the cursor moves to the next cell in tables, one search covers all data items, a new action shows metadata, and dark mode is supported.
- Table Builder, still in preview, adds an Insert Table action that builds the header, repeater, mapped columns and an optional footer from a single dialog.
- User-defined layouts can be Draft, Pending Approval, Approved or Retired. Only Approved ones appear on report request pages, and layouts shipped by extensions are not covered yet.
- A new Default Language Code on Company Information is used after the customer card language and before the user's UI language.
- 36 new API endpoints cover sales, purchasing, inventory and assembly documents. The modernized report selection pages come in a later 28.x minor update.

## Quotes

- "The table builder compresses all of that into a single dialog." (Demonstrates how the new feature significantly reduces the manual work required to build Word document layouts with complex table structures.)
