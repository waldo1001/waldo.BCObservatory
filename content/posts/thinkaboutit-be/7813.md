# Quick Tip: BC28: What Is New in Document Reporting

> BC28 introduces enhanced document reporting features including an improved Word add-in with a redesigned data picker, a new table builder for layouts, lifecycle status management for user-defined layouts, company-level default document language, tooltips on reports, modernized report selection pages, and 36 new document APIs covering sales, purchasing, inventory, and assembly document types.

[Read the post](https://thinkaboutit.be/2026/04/quick-tip-bc28-what-is-new-in-document-reporting/) · think about IT - Steven Renders (Steven Renders) · 2026-04-13 · 953 words · tier community · **unreviewed** (machine-generated)

## Key points

- The Word add-in's data picker redesign makes field insertion easier with double-click capability, auto-advancing cursors in tables, cross-item search, and dark mode support.
- Table Builder preview feature lets users configure and insert full table structures in one dialog, eliminating manual column-by-column field insertion.
- Layouts can now have lifecycle states (Draft, Pending Approval, Approved, Retired) visible only to admins, controlling which layouts appear to users on report request pages.
- Company-level default language code setting resolves document language based on customer card, then company default, then user UI language.
- 36 new APIs provide integration access to previously unavailable document types across sales, purchasing, inventory, and assembly without custom AL code.
