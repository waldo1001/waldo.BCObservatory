# Business Central 29: Exploring the New Microsoft Copilot Chat

[Read the post](https://thinkaboutit.be/2026/11/business-central-29-exploring-the-new-microsoft-copilot-chat/) · think about IT - Steven Renders (Steven Renders) · 2026-11-02 · 1171 words · tier community · reviewed (checked by Opus)

> Business Central 29 introduces a new unified Microsoft Copilot Chat that combines Business Central data, web information, and Microsoft 365 work context through an agentic loop architecture. It enables users to ask contextual questions about business records, analyze data, and receive verifiable answers with citations, while administrators control access and users can verify responses.

## Key points

- Copilot now integrates Business Central data with web information and Microsoft 365 context in single conversations, moving beyond isolated question-answer interactions.
- Behind the scenes, Copilot uses an agentic loop that iteratively selects tools and processes conversation context, page context, user context, and external information to construct grounded responses.
- Business Central MCP server enables Copilot to access standard data, extension data, and custom tables without requiring developers to build dedicated APIs for every custom object.
- Permissions are enforced within the signed-in user's access level, and administrators can manage AI capabilities through the Copilot & Agent Capabilities page.
- Users can verify Copilot answers through record citations, progress messages, a Sources view, and feedback controls, but human judgment remains essential for business decisions.
