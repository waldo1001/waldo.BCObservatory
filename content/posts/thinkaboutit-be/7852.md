# How Do I: Choose the Right AI Assistant for AL Development?

> When choosing an AI assistant for AL development, GitHub Copilot in VS Code excels for code generation with codebase context, while Claude.ai or Claude desktop offer better value for reasoning-heavy tasks like architecture and error analysis due to frontier model access without Copilot cost multipliers. The decision depends on the task type and the new usage-based billing model effective June 2026.

[Read the post](https://thinkaboutit.be/2026/05/how-do-i-choose-the-right-ai-assistant-for-al-development/) · think about IT - Steven Renders (Steven Renders) · 2026-05-04 · 980 words · tier community · **unreviewed** (machine-generated)

## Key points

- GitHub Copilot has structural advantage in VS Code due to editor integration and access to workspace symbols and AL objects
- Claude.ai and Claude desktop app provide frontier reasoning models without Copilot multipliers, making them cheaper for complex analysis and architecture work
- Pricing multipliers vary significantly by model: Haiku at 0.33x, Sonnet at 1x, and Opus at 27x under Copilot's usage-based billing
- Different AI tools suit different workflows: Copilot for inline completions, Claude for reasoning, and Copilot Agent for multi-file refactoring
- The June 1 pricing change makes the cost of frontier models inside Copilot visible and may justify moving reasoning work to separate tools

## Quotes
