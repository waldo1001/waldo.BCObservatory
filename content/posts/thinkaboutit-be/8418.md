# Business Central 29: What’s New in Page Scripting?

[Read the post](https://thinkaboutit.be/2026/11/business-central-29-whats-new-in-page-scripting/) · think about IT - Steven Renders (Steven Renders) · 2026-11-24 · 437 words · tier community · **unreviewed** (model text not yet checked)

> Page Scripting, a tool for recording and replaying user actions in Business Central without writing AL code, is now generally available in 2026 release wave 2. It adds support for multiple row selection in lists and validation of message and error dialogs, enabling functional consultants to test business rules and complete processes from a user perspective.

## Key points

- Page Scripting moves from preview to general availability with improvements to localization, accessibility, and usability
- Multiple row selection now allows recording and replaying bulk actions on selected records in lists
- New ability to validate text displayed in message and error dialogs, treating expected errors as successful test outcomes
- Page Scripting integrates with CI/CD pipelines and complements AL automated tests for comprehensive testing coverage

## Quotes

- "Page Scripting is now generally available" (Marks the transition from preview status to production-ready tool, indicating stability and Microsoft commitment)
- "An expected error can now be the successful outcome of a test." (Demonstrates how Page Scripting now handles validation of business rules that intentionally prevent operations)
- "It allows functional consultants to take greater ownership of automated functional testing, including scenarios where Business Central is expected to prevent an operation." (Shows how Page Scripting empowers non-developers to perform comprehensive functional testing beyond simple process recording)
