# Business Central 29: What’s New in the Word Add-in?

[Read the post](https://thinkaboutit.be/2026/10/business-central-29-whats-new-in-the-word-add-in/) · think about IT - Steven Renders (Steven Renders) · 2026-10-26 · 804 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2026 release wave 2 introduces improvements to the Word Add-in for document reporting, including a new Company Information dataset, an improved Table Builder for editing existing tables, reusable design components, and conditional content controls. These changes reduce repetitive work when building Word layouts and provide a more structured approach to report development.

## Key points

- Company Information dataset is now automatically available in all Word layouts, eliminating the need to duplicate company fields across multiple report datasets
- The Table Builder can now edit existing tables by reopening them to add or change columns and modify table structure without full recreation
- Reusable design components provide predefined formatting for addresses, field groups, amounts, signatures, and notes to create consistent document structures
- Hide If conditional control allows content to be shown or hidden based on Boolean values from the report dataset
- Theme and Header/Footer Layout samples help developers design consistent branding across documents
