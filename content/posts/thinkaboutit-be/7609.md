# Introducing AL Table Visualizer: An Interactive ER Diagram for Your Business Central Tables

[Read the post](https://thinkaboutit.be/2026/03/introducing-al-table-visualizer-an-interactive-er-diagram-for-your-business-central-tables/) · think about IT - Steven Renders (Steven Renders) · 2026-03-02 · 843 words · tier community · reviewed (checked by Opus)

> AL Table Visualizer is a Visual Studio Code extension that generates interactive ER diagrams from Business Central table definitions and compiled symbol packages, helping developers understand data model relationships through visualization rather than manual code tracing.

## Key points

- Reads local .al files and compiled .app symbol packages to extract TableRelation definitions and render them as interactive crow's foot notation diagrams
- Includes interactive exploration features like double-click focus, depth slider control (up to 10 levels), namespace filtering, and relation direction toggling
- Provides a Related Tables panel showing reachable tables with hop distance and relation count, sortable and filterable by table or relation view
- Offers export options for PNG, SVG, Mermaid format, and CSV to support documentation and sharing
- Currently visualizes only formally declared TableRelation properties, not implicit business logic relations in code

## Quotes

- "The diagram is built entirely on TableRelation properties. That is the formal way Business Central defines table relations, and the extension reads them accurately."
