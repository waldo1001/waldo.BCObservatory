# Quick Tip: GitHub Copilot Billing: Setting the Record Straight

> GitHub Copilot billing changes from request-based to usage-based pricing on June 1, 2026, affecting how sub-agent costs are calculated. Under the new model, each sub-agent's token consumption is billed individually rather than at the highest multiplier rate, making model selection for individual agents financially significant.

[Read the post](https://thinkaboutit.be/2026/05/quick-tip-github-copilot-billing-setting-the-record-straight/) · think about IT - Steven Renders (Steven Renders) · 2026-05-06 · 478 words · tier community · **unreviewed** (machine-generated)

## Key points

- Starting June 1, 2026, most Copilot subscribers switch to usage-based billing with per-token pricing and a monthly AI credits allowance
- Request-based billing only continues for Copilot Pro and Pro+ subscribers on existing annual plans
- Code completions remain unlimited and unaffected by billing changes
- Under usage-based billing, each sub-agent's tokens are billed individually, unlike request-based billing where the highest-multiplier model determines the entire session price
- Claude API rates in Copilot are comparable to direct API usage but differ from Claude.ai Pro flat subscription pricing

## Quotes

- "The price of an agentic session is determined by the highest-multiplier model used anywhere in the agent chain." (Clarifies how request-based billing works as contrast to usage-based billing, showing why the June 1 change matters for complex workflows)
