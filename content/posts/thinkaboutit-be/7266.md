# How Do I Fix: The EnableHyperlinks property has not been set for this report.

[Read the post](https://thinkaboutit.be/2025/12/how-do-i-fix-the-enablehyperlinks-property-has-not-been-set-for-this-report/) · think about IT - Steven Renders (Steven Renders) · 2025-12-09 · 480 words · tier community · reviewed (checked by Opus)

> When RDLC report layouts contain hyperlinks, the EnableHyperlinks property must be set in the AL report definition. This property cannot be set in Report Extension objects, creating a problem for extended standard reports. A workaround is to place URLs directly in textbox values instead of using the Action, Go to URL feature.

## Key points

- The EnableHyperlinks property is required for RDLC layouts with hyperlinks and must be set on the main report object, not in Report Extension objects
- Version 27 upgrade triggered this error for some standard reports that previously worked without the property set
- Workaround: use textbox values for URLs instead of the Action, Go to URL feature in RDLC layouts to enable clickable links without the property
- Custom RDLC layouts created via Report Extension objects can implement this workaround through the Report Layouts page

## Quotes

- "The EnableHyperlinks property needs to be set in the AL part of the report if you want to use HyperLinks in the RDLC layout." (Clarifies the technical requirement that EnableHyperlinks must be set on the report itself, not in extensions)
- "This property can not be set in a Report Extension object." (Explains the core constraint that forces users to find workarounds when extending standard reports)
