# Quick Tip: What’s in Business Central Update 28.5?

> Business Central 2026 release wave 1, update 28.5 introduces two main features: Microsoft-managed Azure OpenAI resources for Copilot extensions (now generally available) and embedded Verifactu mode for Spanish tax reporting. This smaller monthly update simplifies Copilot deployment by removing the need for customers to manage their own Azure OpenAI infrastructure.

[Read the post](https://thinkaboutit.be/2026/09/quick-tip-whats-in-business-central-update-28-5/) · think about IT - Steven Renders (Steven Renders) · 2026-09-28 · 329 words · tier community · **unreviewed** (machine-generated)

## Key points

- Developers can now build Copilot extensions using Microsoft-managed Azure OpenAI resources instead of requiring customers to set up their own subscriptions
- Microsoft handles infrastructure management including scaling, monitoring, load balancing, security, and AI consumption tracking
- Embedded Verifactu functionality for Spain is now generally available, supporting automatic invoice submission to AEAT with digital signatures and QR codes
- This is a smaller update with only two feature changes, as focus shifts toward the upcoming Business Central 29.0 major release
