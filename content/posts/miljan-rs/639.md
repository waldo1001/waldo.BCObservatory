# Understanding the Contoso Demo Data Tool in Business Central

[Read the post](https://miljan.rs/2025/07/06/understanding-the-contoso-demo-data-tool-in-business-central/) · miljan.rs (Miljan Milosavljević, MVP) · 2025-07-06 · 647 words · tier community · reviewed (checked by Opus)

> The Contoso Demo Data Tool is a new, extensible coded approach that replaced RapidStart Configuration Packages for creating demo-ready companies in Business Central, starting with 2024 Wave 2 Update 3. It supports multiple modules across finance, manufacturing, warehouse, and other business functions, and can be triggered manually or during company creation.

## Key points

- Microsoft transitioned from RapidStart Configuration Packages to the Contoso Demo Data Tool, beginning with 2024 Wave 2 Update 3
- The tool supports modular initialization covering Common, Foundation, Finance, Manufacturing, Warehouse, Inventory, Sales, Purchasing, Service, Human Resources, Fixed Assets, Jobs, CRM, E-Documents, Sustainability, Subscription Billing, and Statistical Accounts
- Users can run the tool manually in an empty company or automatically during new company creation, with options for Setup Data or Complete Demo Data
- The tool is still under active development with known issues around data dependencies and re-running scenarios between different initialization modes

## Quotes

- "The tool is not fully data-agnostic. Errors can occur if you initialize some modules and then try others later without the prerequisites." (Critical limitation users must understand to avoid initialization failures)
- "It's clear that Microsoft is investing heavily in this tool. I believe ISVs should consider adopting the same approach in their own solutions." (Strategic recommendation for partners to adopt coded demo data practices)

## Heads up

- warning: "The tool is not fully data-agnostic. Errors can occur if you initialize some modules and then try others later without the prerequisites." (about version 2024 Wave 2 Update 3, version BC 2025 Wave 1)
