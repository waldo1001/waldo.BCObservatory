# Search code on GitHub in the browser

[Read the post](https://nataliekarolak.wordpress.com/2025/07/01/search-code-on-github-in-the-browser/) · The BC Docs Librarian (Natalie Karolak, MVP) · 2025-07-01 · 610 words · tier community · reviewed (checked by Opus)

> This post explains two browser-based methods for searching Business Central code on GitHub: using GitHub's native code search for quick keyword queries across repositories, and using github.dev editor to perform VS Code-style searches on any branch including historical code repositories.

## Key points

- GitHub code search is fast and requires no local setup, but only searches the default branch of repositories
- github.dev editor provides VS Code search capabilities in the browser for any branch, useful for accessing historical code repositories like Stefan Maron's Code History repos
- Browser-based searching avoids cluttering your machine and eliminates the need to pull and refresh local repositories
- Code search is limited to keyword matching; symbol-based analysis like 'Find references' still requires local VS Code with downloaded symbols

## Quotes

- "The browser search is much faster than to open and load a large repository before you can even enter your search criteria." (Explains the key advantage of browser-based searching for development efficiency)
