# Help, I don’t get any AL warnings in the Output tab!

[Read the post](https://nataliekarolak.wordpress.com/2025/08/26/help-i-dont-get-any-al-warnings-in-the-output-tab/) · The BC Docs Librarian (Natalie Karolak, MVP) · 2025-08-26 · 203 words · tier community · reviewed (checked by Opus)

> AL warnings may appear missing from the Output tab in VS Code due to an active filter in the filter box. Clearing the filter reveals previously hidden warnings without requiring recompilation.

## Key points

- The VS Code Output tab is where AL reports build infos, warnings and errors; the Problems tab is not reliable for this
- Typing anything into the Output filter box limits the view to matching lines
- Recompiling while a filter is still set makes all warnings seem to vanish
- Removing the filter value shows every entry again, no recompile needed
- If expected warnings are missing, check the Output filter box first

## Quotes

- "The moment we (unintentionally) enter something into the Filter box, we will see only output lines matching the current filter." (Explains the primary cause of missing warnings: active filters hide non-matching output)
- "If we compile again while the filter value is still set … the warning (or more precisely: all warnings) will be gone!" (Shows that recompiling with an active filter permanently removes warnings from view until cleared)
- "So watch out for the output filter box!" (Provides the key takeaway for developers to check this often-overlooked setting)
