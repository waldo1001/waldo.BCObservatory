[Read the post](https://nataliekarolak.wordpress.com/2026/10/02/docs-whats-new-in-bc-29-for-developers-and-admins/) · The BC Docs Librarian (Natalie Karolak, MVP) · 2026-10-02 · 2614 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 29 (2026 release wave 2) released October 1, 2026 includes new AL methods, testability enhancements, reporting improvements with composite layouts and Word add-in support, interface default implementations, and agentic developer tools with MCP servers for AI-assisted development.

## Key points

- New AL methods for IsolatedStorage read isolation, ModuleInfo access, Record.IsDirty(), and shared resources via publicResourceFolders
- Table extension keys now mix base table and extension fields; four new system flow fields for user names/full names added
- Default interface methods allow adding functionality to published interfaces without breaking existing implementors
- TestHandlers property enables lifecycle callbacks for cross-cutting tasks; data-driven tests via TestDataSource attribute
- Composite Word layouts with header/footer and theme parts; Word Add-in always included in runtime 18.0+ without feature flag

## Quotes

- "Default interface methods let you add new functionality to a published interface without breaking existing implementors." (Enables safer evolution of interfaces in production extensions without requiring implementors to update code)
