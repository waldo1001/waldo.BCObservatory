# Get the new BCQuality plugin for VS Code!

[Read the post](https://nataliekarolak.wordpress.com/2026/08/19/get-the-new-bcquality-plugin-for-vs-code/) · The BC Docs Librarian (Natalie Karolak, MVP) · 2026-08-19 · 367 words · tier community · **unreviewed** (model text not yet checked)

> BCQuality is an open-source Microsoft repository that helps AI agents and AL developers generate better code for Business Central by encoding known AI mistakes. A new VS Code plugin now makes it easier to use by automatically downloading repository files and requiring only the mention of 'BCQuality' in prompts instead of URLs.

## Key points

- BCQuality focuses on fixing common AI errors rather than general best practices
- The new VS Code plugin automatically installs and updates repository files locally
- Users can install the plugin through VS Code's Command Palette without manual setup
- The repository includes knowledge and skills subfolders in community and microsoft folders
- Automatic updates check roughly every 24 hours or can be triggered manually

## Quotes

- "It only encodes the things AI gets wrong." (Clarifies that BCQuality's unique value is correcting AI mistakes, not general coding standards)

- Features: BCQuality plugin for VS Code, automatic code review and fixes, community-driven repository, self-improving AI code patterns, plugin auto-update capability
