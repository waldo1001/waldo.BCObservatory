# DataTransfer type causing runtime errors

[Read the post](https://nataliekarolak.wordpress.com/2026/01/09/datatransfer-type-causing-runtime-errors/) · The BC Docs Librarian (Natalie Karolak, MVP) · 2026-01-09 · 237 words · tier community · **unreviewed** (model text not yet checked)

> The DataTransfer data type improves AL upgrade code performance but has two undocumented runtime failure scenarios that the compiler does not catch: assigning constant values to Code fields and filtering on FlowFields or Media fields. The post documents these issues and provides workarounds for each.

## Key points

- DataTransfer.AddConstantValue fails when assigning constants directly to Code fields; use a Code variable instead as a workaround
- DataTransfer.AddSourceFilter does not support FlowFields, FlowFilters, or Media type fields; fall back to traditional SetRange and ModifyAll methods
- These issues may be fixed in future platform builds; the first issue was resolved in platform 27.0.44405 and 26.0.44406
- AL compiler does not warn about these problems before runtime execution
