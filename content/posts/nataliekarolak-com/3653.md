# Docs: What’s new in BC 27 for developers

[Read the post](https://nataliekarolak.wordpress.com/2025/10/02/docs-whats-new-in-bc-27-for-developers/) · The BC Docs Librarian (Natalie Karolak, MVP) · 2025-10-02 · 2059 words · tier community · reviewed (checked by Opus)

> Business Central 27 (released October 1, 2025) introduces new AL methods, properties, and features for developers, including automation APIs for feature management, enhanced text/record operations, smarter pipelines with directory configuration, improved Copilot integration, and updated compiler rules with stricter error handling.

## Key points

- New AL methods for GUID creation, truncate operations, text manipulation, and record field access by name
- Enhanced properties including MaskType for sensitive data masking, TestType for test organization, and new AllowInCustomizations values for field editability
- Smarter pipelines feature with directory.app.props.json for reusable configuration and ALTool compile command support
- Changed Date method behavior on blank query columns and stricter AL compiler rules with new error codes
- Summary system part customization for Copilot and support for Document ExtendedDataType on media fields

## Quotes

- "The directory.app.props.json file defines reusable variables and app.json properties for one or more AL apps in a folder." (This feature enables developers to manage consistent configuration across multiple AL applications efficiently.)
