# Docs: What’s new in BC 28 for developers

[Read the post](https://nataliekarolak.wordpress.com/2026/04/02/docs-whats-new-in-bc-28-for-developers/) · The BC Docs Librarian (Natalie Karolak, MVP) · 2026-04-02 · 2361 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 28 introduces major developer features including semantic search on data and metadata, support for fully qualified names and namespaces in AL, data analysis definitions in apps, MCP Server enhancements, AL coding agents with BC-Bench, improved database index management, and new tooling like the Word Add-in for report layouts and GitHub Codespaces support.

## Key points

- Developers can use semantic search on data and metadata, and define data analysis definitions in AL apps
- Support for namespaces and fully qualified names enables running codeunits, pages, and reports by name with new method overloads
- Model Context Protocol (MCP) Server is enhanced with admin capabilities and integrable with Visual Studio Code for automated tasks
- New tools include database index usage management, BC Word Add-in for report layout editing, GitHub Codespaces for cloud-based development, and SFTP Client codeunit
- Multiple new AL compiler rules and warnings address analysis views, native methods, BigInteger conversions, and FlowField usage in queries
