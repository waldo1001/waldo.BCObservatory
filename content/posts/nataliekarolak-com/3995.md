# Docs: What’s new in BC 28 for developers

[Read the post](https://nataliekarolak.wordpress.com/2026/04/02/docs-whats-new-in-bc-28-for-developers/) · The BC Docs Librarian (Natalie Karolak, MVP) · 2026-04-02 · 2361 words · tier community · reviewed (checked by Opus)

> Business Central 28 introduces major developer features including semantic search on data and metadata, support for fully qualified names and namespaces in AL, data analysis definitions in apps, MCP Server enhancements, AL coding agents with BC-Bench, improved database index management, and new tooling like the Word Add-in for report layouts and GitHub Codespaces support.

## Key points

- Developers get semantic search over data and metadata, and analysis views can now be packaged and shipped in AL extensions
- New overloads run codeunits, pages and reports and open RecordRefs by fully qualified name; Record and RecordRef also expose FullyQualifiedName
- MCP tooling grows, including an Admin Center API MCP server usable from VS Code and a standalone MCP server in ALTool
- New tooling covers index usage management, a Word Add-in (preview) for report layouts, GitHub Codespaces and a faster Base64 codeunit; the new SFTP Client module is being withdrawn by Microsoft
- Many new compiler, CodeCop and AppSourceCop rules cover analysis views, native procedures, BigInteger conversions and FlowFields in query links

## Quotes

- "AL developers can use semantic search on data and metadata. Allow developers to define data analysis definitions in their apps." (Highlights core developer capabilities for intelligent data access and custom analysis tools in BC 28)
- "New method overloads are introduced to support running codeunits, pages, and reports using their fully-qualified names." (Demonstrates namespace support enabling more explicit and maintainable code organization patterns)
- "BC 28 provides tools to view index usage statistics and selectively disable low-use indexes to improve write performance and reduce storage costs." (Shows new performance optimization capabilities for production environments)
