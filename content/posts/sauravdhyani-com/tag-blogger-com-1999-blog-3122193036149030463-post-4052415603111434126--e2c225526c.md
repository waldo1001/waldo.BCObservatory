# Manage Database Index Usage in Business Central.

> Business Central 2026 Wave 1 enables administrators to manage database indexes directly from the client without SQL access. The feature allows viewing index metrics, disabling unused secondary indexes per company, and optimizing database storage and write performance.

[Read the post](https://www.sauravdhyani.com/2026/08/manage-database-index-usage-in-business.html) · Saurav Dhyani (Saurav Dhyani, MVP) · 2026-08-24 · 730 words · tier community · **unreviewed** (machine-generated)

## Key points

- Administrators can view index details (name, size, usage statistics, enabled status) through the Table Data Management page
- Company-specific index control allows different companies to have the same index enabled or disabled independently
- Only secondary indexes can be disabled; primary keys, unique indexes, SIFT indexes, and SystemId indexes remain protected
- Disabling indexes reduces storage usage and improves insert/update/delete performance; enabling is queued for the next midnight maintenance
- Index management requires reviewing usage statistics and testing in sandbox before production changes, as low usage during short periods may not indicate permanent irrelevance

## Quotes

- "Administrators can now make informed optimization decisions directly from the Business Central client." (This eliminates the need for direct SQL tool access for database index management, making the capability more accessible to business administrators.)
- "Company A can have an index enabled. Company B can have the same index disabled." (This multi-company flexibility allows tailored optimization for different organizational units with different workloads, reducing unnecessary overhead.)
