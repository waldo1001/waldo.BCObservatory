# Automating Posting Periods in Business Central with Date Formulas

[Read the post](https://www.sauravdhyani.com/2026/06/automating-posting-periods-in-business.html) · Saurav Dhyani (Saurav Dhyani, MVP) · 2026-06-03 · 279 words · tier community · reviewed (checked by Opus)

> Date formulas enable automatic posting period adjustments in Business Central based on today's date instead of fixed dates. This feature applies to General Ledger Setup, User Setup, and General Journal Templates, reducing manual updates and posting errors.

## Key points

- Date formulas define allowed posting ranges relative to the current date, so posting windows move automatically instead of needing manual updates.
- They can be set in General Ledger Setup, User Setup and General Journal Templates.
- Restrictions are checked in order: User Setup, then General Ledger Setup, then General Journal Template when its mandatory toggle is on.
- Examples include current month only, rolling 30 days, previous month close and today only.
- A formula can be used for one boundary while the other boundary stays a fixed date.

## Quotes

- "Date formulas are dynamic expressions that calculate allowed posting ranges relative to today's date." (This explains the core concept of how date formulas work as smart boundaries that move with time rather than being static.)
- "You can combine formulas with fixed dates - one boundary can be dynamic, the other fixed." (This flexibility allows organizations to implement hybrid approaches that mix static and dynamic posting period controls.)
