# AI-Part1: what-is-GitHub-copilot-in-vscode-business-central.

> GitHub Copilot in VS Code evolved from simple autocomplete to a spectrum of capabilities including inline suggestions, chat, agent mode, and cloud agents. For Business Central AL developers, understanding these distinct modes and their constraints is essential because generic tutorials for other languages don't account for BC-specific patterns like event subscribers, table extensions, and object ID ranges.

## Key points

- GitHub Copilot spans multiple modes: inline completions, Copilot Chat, Agent mode, Cloud agent, and subagents, each with different levels of autonomy.
- Business Central development differs from generic software development because extensions extend base objects rather than modifying them, requiring explicit constraints in prompts.
- BC-specific patterns like event subscribers, table/page extensions, and the Business Central Test Toolkit rarely appear in generic Copilot tutorials and must be taught explicitly.
- Object ID ranges and naming conventions are team-specific and cannot be inferred automatically by Copilot.
