# Preview Images Directly in the Business Central Web Client

[Read the post](https://www.sauravdhyani.com/2026/09/preview-images-directly-in-business.html) · Saurav Dhyani (Saurav Dhyani, MVP) · 2026-10-05 · 1072 words · tier community · reviewed (checked by Opus)

> Business Central now supports previewing image attachments directly in the web client without downloading. The feature works with multiple image formats across attachments, agents, email, and FactBox thumbnails, with developers using File.ViewFromStream (online) or File.View (on-premises) to integrate the functionality into extensions.

## Key points

- Users can view supported image files in a dedicated previewer similar to PDF and print preview experiences
- Supported formats include JPEG, JPG, PNG, BMP, SVG, WEBP, ICO, GIF, AVIF, and TIFF/TIF in Safari
- Animated GIFs are supported as FactBox thumbnails with animation for up to 48 frames
- Extension developers can use File.ViewFromStream (online) or File.View (on-premises) to enable preview functionality
- Image and PDF thumbnails can be clickable entry points to open the previewer
