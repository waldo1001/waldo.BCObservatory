# Restrict Global Symbol Downloads to a Minor Version in Business Central 2026 Release Wave 2

[Read the post](https://www.sauravdhyani.com/2026/10/restrict-global-symbol-downloads-to.html) · Saurav Dhyani (Saurav Dhyani, MVP) · 2026-10-14 · 1167 words · tier community · reviewed (checked by Opus)

> Business Central 2026 release wave 2 adds Global Sources Enforce Minor Version, a setting that restricts global symbol downloads to the major and minor version specified in app.json while allowing the newest patch within that minor version. This feature helps AL developers maintain reproducible development boundaries and control symbol resolution from Microsoft's global NuGet sources.

## Key points

- Global Sources Enforce Minor Version constrains symbol downloads to the specified major.minor version while selecting the latest available patch
- Minor-version enforcement is disabled by default; when enabled, it prevents symbol resolution from crossing minor version boundaries
- Configuration uses the application property in app.json combined with the AL/Visual Studio Code setting to control version targeting
- This feature improves CI/CD reproducibility and keeps development teams aligned on specific Business Central minor releases

## Quotes

- "When this setting is enabled, global symbol downloads are constrained to the major and minor version specified in the application property of app.json." (Explains the core function of the feature and how it prevents unintended version resolution drift)
