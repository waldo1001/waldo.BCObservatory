# Business Central ToolTip and ToolTipML Properties Are Now Available on Pages

[Read the post](https://www.sauravdhyani.com/2026/09/business-central-tooltip-and-tooltipml.html) · Saurav Dhyani (Saurav Dhyani, MVP) · 2026-10-06 · 1014 words · tier community · **unreviewed** (machine-generated)

> Business Central now supports ToolTip and ToolTipML properties directly on page objects, allowing navigation actions to inherit tooltips from their target pages rather than requiring duplicate tooltip definitions on each action.

## Key points

- ToolTip and ToolTipML can now be defined at the page object level in AL code
- Navigation actions using RunObject automatically inherit the tooltip from the target page if they don't specify their own
- This reduces duplicated tooltip text and improves consistency across multiple navigation paths to the same page
- Action-level tooltips can still override page-level tooltips when specific descriptions are needed
- This behavior mirrors the existing tooltip inheritance pattern already available for reports
