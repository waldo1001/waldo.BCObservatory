> Business Central version 29.0 (2026 release wave 2) is now generally available, marking the start of the next upgrade cycle for cloud customers. New customers will be provisioned with version 29.0, and existing Business Central 28 customers should prepare for upgrades through testing, notification configuration, extension validation, and scheduled maintenance planning.

## Key points

- New Business Central cloud environments now start with version 29.0; version 28 will eventually be removed from creation options
- Administrators must configure notification recipients to receive Microsoft upgrade and compatibility alerts
- Production upgrades should be scheduled after sandbox testing completes, with update windows aligned to customer time zones and maintenance periods
- Per-Tenant Extensions must be validated against version 29.0 before production upgrades
- Customers planning version 28 go-live should create required environments immediately while that version remains available
