# How to Use Date Formulas for Allowed Posting Periods in Business Central BC28.

[Read the post](https://www.sauravdhyani.com/2026/06/how-to-use-date-formulas-for-allowed.html) · Saurav Dhyani (Saurav Dhyani, MVP) · 2026-07-22 · 536 words · tier community · reviewed (checked by Opus)

> Business Central BC28 introduces dynamic date formulas for allowed posting periods that automatically calculate posting windows based on the current date instead of requiring manual updates. Administrators can configure these formulas in General Ledger Setup, User Setup, and Journal Templates to automate posting restrictions and reduce monthly maintenance.

## Key points

- Date formulas dynamically calculate posting ranges using expressions like <-CM>, <0D>, and <-30D> that adjust automatically over time
- Formulas can be configured at three levels: Global (General Ledger Setup), User-specific (User Setup), and Journal-specific (General Journal Templates)
- User Setup restrictions take priority over other posting controls when multiple levels are configured
- Administrators can mix formulas and fixed dates together, though entering one clears the other for the same boundary
- Feature reduces monthly administrative effort while improving posting governance and preventing outdated posting windows

## Quotes

- "Posting date formulas allow Business Central to dynamically calculate allowed posting ranges based on today's date." (Explains the core capability that replaces manual posting date maintenance with automatic calculations)
- "Entering a formula clears the fixed date; entering a fixed date clears the formula." (Important behavior that administrators need to understand when mixing formulas and fixed dates)
