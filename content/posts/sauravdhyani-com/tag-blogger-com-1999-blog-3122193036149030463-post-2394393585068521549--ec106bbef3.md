# How to Use the Copy Location Feature in Business Central 2026 Wave 1 (BC28)

> The Copy Location feature in Business Central BC28 allows users to duplicate existing warehouse and location configurations instead of setting them up manually, reducing implementation time and standardizing setups across multiple locations.

[Read the post](https://www.sauravdhyani.com/2026/06/how-to-use-copy-location-feature-in.html) · Saurav Dhyani (Saurav Dhyani, MVP) · 2026-07-15 · 523 words · tier community · **unreviewed** (machine-generated)

## Key points

- Copy Location duplicates warehouse configuration, settings, and operational setup from an existing location to a new one
- The feature does not copy inventory quantities, ledger entries, or transaction data
- It is available directly from the Locations page and Location Card page via the Actions menu
- Useful for multi-warehouse rollouts, franchise deployments, testing environments, and rapid implementations
