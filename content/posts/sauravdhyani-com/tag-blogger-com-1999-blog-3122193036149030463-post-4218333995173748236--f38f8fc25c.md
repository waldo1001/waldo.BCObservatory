# How to Export CSV Files from Business Central Using CSV Buffer (Developer Guide)

> This guide explains how to export data from Business Central to CSV format using the CSV Buffer table, covering its structure, recommended architecture, common export issues, and performance best practices for developers building integration and data exchange solutions.

## Key points

- CSV Buffer is a built-in table with Line No., Field No., and Value fields that enables controlled CSV export with headers and formatting
- Recommended export pattern uses a codeunit to add headers, insert data row-by-row into temporary CSV Buffer, write to Blob, and download to client
- Common issues include commas in text breaking columns (requires sanitization), missing headers reducing clarity, and FlowFields exporting as zero (needs CalcFields or SetAutoCalcFields)
- CSV separators can be commas, semicolons, colons, or pipes; Excel and most tools handle custom separators via Text to Columns
- Performance optimization requires SetLoadFields to fetch only needed fields, avoiding unnecessary FlowField calculations, and keeping CSV Buffer temporary
