> Setting up Visual Studio Code, the AL Language extension, and GitHub Copilot for Business Central AL development requires installation of three components and verification of connections. This post guides developers through each setup step and highlights common gotchas like extension version mismatches and separate subscription management.

## Key points

- Install VS Code as the only Microsoft-supported IDE for AL development, then add the AL Language extension from either the Marketplace or your BC container version
- Run the AL: Go! command to create project structure, connect to your BC tenant, and download necessary symbols for standard BC objects
- GitHub Copilot requires a separate subscription from both BC licenses and VS Code, so verify the subscription is active during extension installation
- Test the full setup by publishing the sample AL file to your sandbox and running /explain commands in Copilot Chat to confirm all components communicate
- Disable telemetry in VS Code settings if data privacy is a concern
