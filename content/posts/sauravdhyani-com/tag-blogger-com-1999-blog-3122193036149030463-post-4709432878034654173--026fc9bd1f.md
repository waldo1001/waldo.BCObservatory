# How to Install Microsoft Dynamics 365 Business Central 29 On-Premises

[Read the post](https://www.sauravdhyani.com/2026/10/how-to-install-microsoft-dynamics-365.html) · Saurav Dhyani (Saurav Dhyani, MVP) · 2026-10-15 · 1004 words · tier community · reviewed (checked by Opus)

> This guide covers the prerequisites and installation steps for deploying Microsoft Dynamics 365 Business Central 29 (2026 release wave 2) on-premises in a test or demonstration environment, including supported hardware, software, and network configuration requirements.

## Key points

- Business Central 29.0 requires Windows Server 2022 or 2025, .NET 10.0, .NET Framework 4.8, and SQL Server with compatibility levels 160 or 170
- Minimum deployment needs 16 GB RAM for the application and 100 GB disk space; 32-64 GB RAM is recommended for publishing large extensions
- Installation involves preparing the environment, installing components via setup.exe, configuring SQL Server and server instance, setting service ports (Management 7045, Client 7085, SOAP 7047, OData 7048, Developer 7049), and validating the Web Client after completion
- All Business Central components must come from the same version and build to avoid deployment problems
- Post-installation verification should confirm the server service is running, the database is accessible, the Web Client opens successfully, and authentication works
