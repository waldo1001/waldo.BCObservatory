# New ModuleInfo Properties in Business Central 29

[Read the post](https://www.sauravdhyani.com/2026/09/new-moduleinfo-properties-in-business.html) · Saurav Dhyani (Saurav Dhyani, MVP) · 2026-10-02 · 954 words · tier community · **unreviewed** (machine-generated)

> Business Central 29 adds four new ModuleInfo properties (Help, EULA, PrivacyStatement, ContextSensitiveHelpUrl) that let AL developers retrieve application manifest metadata programmatically. These properties require runtime 18.0 or later and help extensions avoid duplicating configuration URLs in code.

## Key points

- Four new ModuleInfo properties retrieve Help links, EULA, privacy statements, and localized context-sensitive Help URLs directly from application metadata
- Use NavApp.GetCurrentModuleInfo() to populate a ModuleInfo variable and access the new properties
- ContextSensitiveHelpUrl automatically resolves the user's locale from supported application locales
- Runtime version 18.0 or later is required to use these new properties
