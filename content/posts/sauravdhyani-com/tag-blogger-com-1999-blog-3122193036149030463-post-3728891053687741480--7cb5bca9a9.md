# Business Central 2026 Release Wave 2: Turn SIFT Indexes On or Off

[Read the post](https://www.sauravdhyani.com/2026/09/business-central-2026-release-wave-2_01917375766.html) · Saurav Dhyani (Saurav Dhyani, MVP) · 2026-10-07 · 1605 words · tier community · **unreviewed** (machine-generated)

> Starting with Business Central 2026 Release Wave 2, administrators can now turn SIFT (SumIndexField Technology) indexes on or off directly in the application through Table Information. This feature provides operational control over database performance by allowing targeted index management based on actual usage patterns without requiring developer changes or application modifications.

## Key points

- SIFT indexes maintain pre-calculated aggregate information using SQL indexed views to speed up sum and count calculations on large tables
- Enabling SIFT improves read performance for aggregations but creates maintenance overhead during insert, update, and delete operations
- Administrators can now manage SIFT indexes per company in multi-company environments through the Table Information page and data-management view
- Disabling SIFT should be based on evidence-driven analysis of workload and usage patterns, not automatic decisions based on low usage statistics
- This feature creates better separation between developer data-model design, consultant workload analysis, and operational index management

## Quotes

- "Business Central administrators can now turn SIFT indexes on or off directly from the application." (This is the core new capability introduced in 2026 Wave 2, enabling operational control without developer involvement)
- "The goal is not to have fewer indexes. The goal is to have the right indexes for the workload." (Clarifies that index management should be evidence-based and workload-specific, not about blanket disabling)
