# How to Group and Consolidate General Journal Lines Using Query Object in Business Central.

> This post explains how to consolidate General Journal Lines in Business Central using Query Objects to group records by Posting Date, Account No., and Dimension Set ID, then aggregate amounts and insert consolidated results into a target journal batch. It addresses a common developer scenario where multiple journal lines with identical keys need to be combined.

## Key points

- Query Objects are the correct tool for consolidation because they handle grouping and SUM aggregation efficiently, unlike manual record looping
- Consolidation keys typically include Posting Date, Account No., and Dimension Set ID, with Amount field aggregated using SUM
- Query Objects are read-only; the pattern requires executing the query, looping results, creating new journal lines in target batch, then deleting source lines
- Manual record looping approaches are complex, error-prone, and perform poorly compared to Query Objects for grouping scenarios
- Safe consolidation requires keeping source batch untouched until target insertion completes successfully to prevent data loss
