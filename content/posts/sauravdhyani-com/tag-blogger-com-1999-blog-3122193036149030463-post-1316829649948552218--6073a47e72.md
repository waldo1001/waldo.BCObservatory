# Business Central v29: Use System Audit Fields in Analysis Mode and Profiles

[Read the post](https://www.sauravdhyani.com/2026/09/business-central-v29-use-system-audit.html) · Saurav Dhyani (Saurav Dhyani, MVP) · 2026-10-12 · 687 words · tier community · **unreviewed** (model text not yet checked)

> Business Central v29 enables administrators to use system audit fields (such as who created a record and when it was modified) directly in Analysis Mode and Profile customizations without building custom extensions. This configuration-driven approach reduces development effort and maintenance costs while improving audit visibility.

## Key points

- System audit fields like System Created At, System Created By, System Modified At, and System Modified By are now accessible in Analysis Mode and Profiles
- Previously, these fields required custom page extensions to display, introducing development and maintenance overhead
- Administrators can now configure audit information visibility for specific user roles through Profiles without code
- Analysis Mode users can explore and analyze records by creator, review modifications, track ownership trends, and improve troubleshooting
- This enhancement reduces customization footprint, accelerates deployments, and improves supportability for audit investigations
