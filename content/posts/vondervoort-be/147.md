# ALCops: The Story So Far

[Read the post](https://www.vondervoort.be/index.php/2026/09/06/alcops-the-story-so-far/) · Vondervoort.be (Arthur van de Vondervoort) · 2026-09-06 · 621 words · tier community · **unreviewed** (machine-generated)

> ALCops is a community-driven collection of code analyzers for AL that reached v1.0 after six months of development with over 480 merged pull requests. It provides focused specialized analyzers for language correctness, code smells, formatting, documentation, and testing, now integrated with AI assistants through an MCP server and replacing the earlier LinterCop project by October 2026.

## Key points

- ALCops evolved from v0.5 to v1.0 through community contributions and refinements of false positives and edge cases
- The project is organized into six specialized analyzers: PlatformCop, ApplicationCop, LinterCop, FormattingCop, DocumentationCop, and TestAutomationCop, each addressing specific domains
- ALCops now integrates with AI assistants like Claude, Codex, and Cursor via an MCP server to provide code analysis in agent-driven workflows
- BusinessCentral.LinterCop is being deprecated with an October 2026 deadline, with users expected to migrate to ALCops
