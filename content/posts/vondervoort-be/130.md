> ALCops is a new community-driven code analyzer collection for AL that succeeds LinterCop, with about 95% of the original rules migrated. It provides VS Code extension and AL-Go support for daily AL development, with future work on Azure DevOps integration and AI tool compatibility.

## Key points

- ALCops is a fresh start community project built on the foundation of BusinessCentral.LinterCop, allowing breaking changes without damaging existing setups
- The original LinterCop repository will transition to read-only as development resources concentrate on ALCops
- Current v0.5.0 covers 95% of LinterCop rules with VS Code and AL-Go support, ready for daily AL development use
- Future roadmap includes Azure DevOps extension, AI agent integration (Claude Code, GitHub Copilot), and potential MCP integration
