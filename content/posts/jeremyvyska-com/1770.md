## Key points

- GitHub Copilot refresh covers agent mode, custom agents, agent skills, instructions files, MCP servers, and plugin packaging for AL development
- Claude Code class teaches setup for BC repos, plan-build-verify loop with AL compiler, skills and subagents, and artifacts for shareable pages
- BCQuality class explains the three-layer structure, integration with Copilot and Claude Code, custom knowledge files, and process integration
- All classes run twice weekly in two time zones with 60-minute live sessions plus 30-minute unrecorded Q&A, with DRM-free recordings included
