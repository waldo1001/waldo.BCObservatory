# Fall 2026 Agentic Development Classes: Copilot Refresh, Claude Code, and BCQuality

[Read the post](https://jeremyvyska.com/2026/10/25/fall-2026-agentic-development-classes/) · Jeremy Vyska (Jeremy Vyska, MVP) · 2026-10-25 · 907 words · tier community · reviewed (checked by Opus)

> Three standalone agentic development classes for Business Central teams cover GitHub Copilot updates for AL development, Claude Code setup and workflow, and BCQuality integration for consistent code quality. Scheduled for November-December 2026 with live and recording options.

## Key points

- The GitHub Copilot refresh covers what changed in agent mode, custom agents and agent skills, where instructions files, prompt files and AGENTS.md belong, which MCP servers are worth connecting, and packaging all of it as plugins for AL teams
- The Claude Code class covers setting up a BC repo (CLAUDE.md, permissions), plan mode with a plan, build, verify loop that uses the AL compiler and tests, skills, subagents and hooks, plus Artifacts and Remote Control
- The BCQuality class covers its Microsoft, community and custom layers, using it from Copilot and Claude Code to review AL changes, writing custom knowledge files, and fitting it into local review, pull requests and pipelines
- Each class runs twice in its week (Tuesday 17:00 or Friday 10:00 CET, 17 Nov to 4 Dec) as 60 recorded minutes on Teams plus 30 minutes of unrecorded Q&A, with DRM-free recordings
- Prices are 200 EUR per live class or 150 EUR for a recording only, with bundles and team licences also offered

## Quotes

- "AGENTS.md: what goes where in a BC repo" (Clarifies where to document agent configuration in Business Central repositories)
- "Plan mode and the plan → build → verify loop, with the AL compiler and tests in the loop" (Describes the core Claude Code workflow for BC development with integrated validation)
- "BCQuality is the successor to alguidelines.dev, built for both human and agentic developers." (Establishes BCQuality as the evolution of guidance standards for both agent and human code review)
