Classes are designed for developers already working with AI tools or exploring them for AL development.

- VS Code and GitHub Copilot class covers agent mode, custom agents, skills, and MCP servers for AL work
- Claude Code class teaches setup and usage patterns specific to Business Central, including plan mode and artifacts
- BCQuality class shows how to integrate quality standards into development workflows for both human and agentic developers
- Three standalone classes run twice per week to accommodate different time zones, with live Q&A sessions
