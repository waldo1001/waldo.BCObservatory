# Building at Scale: Long-Running AI Agents for Real Development

[Read the post](https://jeremyvyska.com/2026/02/10/building-at-scale-long-running-ai-agents-for-real-development/) · Jeremy Vyska (Jeremy Vyska, MVP) · 2026-02-10 · 1997 words · tier community · **unreviewed** (model text not yet checked)

> A three-phase agentic orchestration system (Building, Reviewing, Improving) for developing large-scale Business Central ecosystems using AI agents. The author demonstrates the pattern by creating 38 applications across 700+ AL files while managing dependencies, quality standards, and model drift through comprehensive instructions, JSON progress tracking, pattern-based reviews, and strategic model selection.

## Key points

- Use different Claude models strategically: Opus for planning and instruction creation, Sonnet or Haiku for mechanical implementation execution
- Implement three-phase workflow with stateful JSON progress tracking and dependency-aware task identification to enable AI agents to self-direct and avoid rework
- Pattern-based review across nine architectural dimensions (naming, data model, business logic, performance, security, error handling, extensibility, UX, sustainability) scales better than line-by-line code review
- Combat model gravity through comprehensive explicit instructions, validation checkpoints, and multiple correction passes since models have behavioral tendencies that persist despite clear guidance
- Leverage parallel task execution once dependencies map and instructions stabilize, achieving initial implementation in approximately two hours for 19 applications
