# AL Object ID Ninja MCP Server Is Here

[Read the post](https://vjeko.com/2026/02/02/al-object-id-ninja-mcp-server-is-here/) · Vjeko.com (Vjekoslav Babić, MVP) · 2026-02-02 · 352 words · tier community · reviewed (checked by Opus)

> AL Object ID Ninja now has an official MCP Server, published on npm, for agentic tools such as Cursor, Claude Code and Windsurf. It lets AI assistants request, commit and unassign object IDs so that IDs do not collide. It is built from scratch for platform 3.0 after a community server stopped working when platform 2.0 was shut down. VS Code users with the Ninja extension do not need it.

## Key points

- MCP Server provides AI coding assistants with programmatic access to AL Object ID Ninja for requesting, committing, and unassigning object IDs
- Addresses the need for automated object ID management in agentic coding environments where AI generates AL code
- Official platform 3.0 version built from scratch and maintained alongside the Ninja platform
- VS Code users with the Ninja extension already have this functionality and need no changes
- Available on npm for installation in MCP-compatible tools like Cursor, Claude Code, and Windsurf

## Quotes

- "Hook it up to your MCP-compatible tool of choice, and your AI coding buddy gets full access to Ninja's object ID management." (Explains the core capability of the MCP Server to enable AI assistants to manage object IDs automatically)
- "This new server is the official one for platform 3.0. Built from scratch, maintained alongside the rest of the Ninja platform." (Clarifies this is the authoritative version replacing the unsupported platform 2.0 implementation)
- "If you're using VS Code with the Ninja extension, nope. You're all set." (Important for users to know when they already have equivalent functionality and don't need the MCP Server)
