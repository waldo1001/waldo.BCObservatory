# Object IDs, now assignable by VS Code agents (LM tool integration)

[Read the post](https://vjeko.com/2026/01/07/object-ids-now-assignable-by-vs-code-agents-lm-tool-integration/) · Vjeko.com (Vjekoslav Babić, MVP) · 2026-01-07 · 330 words · tier community · reviewed (checked by Opus)

> AL Object ID Ninja 3.1.0 enables language-model agents in VS Code to assign object IDs directly via tool integration, eliminating manual ID allocation when agents write AL code. This feature ensures conflict-free ID assignment across multiple apps in real time.

## Key points

- Agents writing AL code can now request object IDs from Ninja without human intervention
- The tool integration prevents conflicts by assigning IDs in a globally coordinated way
- Within the first hour of release, agents assigned 64 object IDs across 12 different apps
- An official MCP server for AL Object ID Ninja is in development for broader agent support

## Quotes

- "They're assigned correctly, globally, and in real time, exactly the same way Ninja already does it for human developers." (Clarifies that agent-assigned IDs maintain the same safety and uniqueness standards as human-assigned IDs)

- Versions: Ninja 3.1.0
