# Copilot Inventory Queries

[Read the post](https://www.olofsimren.com/copilot-inventory-queries/) · Olof Simren (Olof Simren) · 2025-10-08 · 1001 words · tier community · **unreviewed** (machine-generated)

> A partner-built Copilot extension for Business Central helps manufacturing companies manage inventory by answering natural language questions about reorder points, replenishment timing, and demand trends. It uses Azure OpenAI as a backend AI model with structured prompts and JSON data from inventory tables to provide suggestions with explanations.

## Key points

- The extension uses Microsoft's Copilot interface tools in AL to build custom AI features for inventory management
- It connects to an Azure OpenAI deployment configured in Azure AI Foundry with credentials stored securely in isolated storage
- Prompts include system instructions that teach the AI model to analyze Business Central inventory data (item ledger entries, open orders) and answer user questions
- The solution optimizes costs by compressing data before sending to the AI model and only including relevant fields
- It demonstrates practical AI use cases like suggesting reorder points, reorder quantities, sales trends, and reordering policies
