# Allow Posting Date Formula

[Read the post](https://www.olofsimren.com/allow-posting-date-formula/) · Olof Simren (Olof Simren) · 2026-09-01 · 272 words · tier community · reviewed (checked by Opus)

> Business Central now supports date formulas for allowed posting dates in General Ledger Setup and User Setup, eliminating the common first-of-month panic when users cannot post transactions outside their allowed date range. This feature allows flexible, formula-based date restrictions that adjust automatically based on the current date.

## Key points

- Date formulas can be set for Allowed Posting From and Allowed Posting To dates
- Feature is available in both General Ledger Setup and User Setup
- Replaces previous workarounds like custom job queue entries or sign-in processes
- Enables scenarios like opening only the current month based on today's date or allowing specific users to post in prior months

## Quotes

- "Business Central now has a feature to define Date Formulas for the Allowed Posting From and Allowed Posting To." (This is the core feature announcement, explaining that dynamic date formulas replace static date ranges)
- "With this you can set date formulas to open the current month only based on todays date (as an example)." (Demonstrates a practical use case showing how the feature solves the first-of-month posting problem)
