# Reopen Finished Production Orders

[Read the post](https://www.olofsimren.com/reopen-finished-production-orders/) · Olof Simren (Olof Simren) · 2025-07-29 · 529 words · tier community · **unreviewed** (machine-generated)

> Business Central now allows users to reopen finished production orders, converting them back to released status so adjustments can be made. The feature also includes reverse production entry functions on both item and capacity ledger entries, plus an option to finish orders without posted output.

## Key points

- Reopen Finished Production Orders function changes finished orders back to released status with the same production order number
- Reverse Production Entry feature reverses selected item ledger and capacity ledger entries, allowing bulk reversals
- Orders can be finished without output posted when activated in Manufacturing Setup, writing off WIP costs to the Inventory Adjustment Account
- Reopening a finished production order a second time generates an error, and orders without posted output cannot be reopened
