# Business Central Configuration Audit using Vibe Coding

[Read the post](https://www.olofsimren.com/business-central-configuration-audit-using-vibe-coding/) · Olof Simren (Olof Simren) · 2026-02-13 · 1193 words · tier community · reviewed (checked by Opus)

> A consultant created a Business Central configuration audit extension using AI-assisted vibe coding to check for 200+ data issues like circular BOMs, missing posting groups, and incomplete setups. The AI agent generated over 5400 lines of code in basic structures, requiring minimal manual adjustments and making the project feasible where writing it manually would have been impractical.

## Key points

- Vibe coding with an AI agent produced about 5400 lines of code for more than 200 data checks, far more than the author would have written by hand
- Checks include circular production BOM references, work centers without calendars, missing posting groups, incomplete posting setups and defaulted blocked dimensions
- The agent did well on tables and individual check functions, but the results report was poorly structured and it failed at Excel export, so that idea was dropped
- Asking the agent to suggest more checks and to generate documentation of all checks as a CSV worked well
- The extension is free on AppSource. Some checks are subjective, such as flagging missing sales accounts in posting setups

- "It writes the code fast and 90% is good, the rest you need to adjust." (Sets realistic expectations about AI-generated code quality and the need for human review)
