## Key points

- Six performance features organized into three categories: application-level sorting improvements, developer tools like LockTimeoutDuration and CreateSequentialGuid, and SQL optimization with enhanced flow fields

- New AL functions enable developers to control lock timeouts and generate sequential GUIDs more efficiently
- SQL statements can now be included in AL Profiles for performance monitoring and analysis
