# Optimized Base64 file handling in Dynamics 365 Business Central 2026 Wave 1

[Read the post](https://duiliotacconi.com/2026/07/29/optimized-base64-file-handling-in-dynamics-365-business-central-2026-wave-1/) · Duilio Tacconi (Duilio Tacconi, MVP) · 2026-07-29 · 897 words · tier community · reviewed (checked by Opus)

> Dynamics 365 Business Central 2026 Wave 1 introduces a new platform codeunit for Base64 encoding and decoding that automatically improves performance and reduces memory usage without requiring code changes. Existing applications gain 30-45% better encoding and 15-25% better decoding performance, while developers can optionally refactor to use stream-based methods for further optimization.

## Key points

- New System.Runtime.Base64Convert codeunit (2000000024) provides optimized native Base64 methods with multiple overloads for streams and text
- Automatic performance gains of 30-45% for encoding and 15-25% for decoding happen without refactoring existing code
- Stream-based encoding/decoding methods offer optional optimization path for applications handling Base64 intensively
- Platform includes telemetry warnings for strings exceeding 10MB to help identify refactoring opportunities
