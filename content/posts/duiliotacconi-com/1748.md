# Cloud Customer Management System (CCMS): to avoid reinventing the wheel

[Read the post](https://duiliotacconi.com/2025/12/12/cloud-customer-management-system-ccms-to-avoid-reinventing-the-wheel/) · Duilio Tacconi (Duilio Tacconi, MVP) · 2025-12-12 · 705 words · tier community · reviewed (checked by Opus)

> CCMS is a free, open-source Business Central app written in AL for managing partners' cloud customer tenants and environments. It covers environment lists, rescheduling updates, installed apps and available updates, telemetry, capacity and feature management. It grew out of a prototype admin app by Duilio Tacconi and Stefano Demiliani, which was merged with a similar Directions for Partners project after Directions EMEA 2025.

## Key points

- The repo has been open for contributions since 11 December 2025; users can download the app or fork it
- Screens shown include the environment list, rescheduling updates from the Environment Card, installed apps and available updates, telemetry, capacity and feature management
- The app was built because partners keep getting requests like automating environment copies or finding which customers run a given AppSource app version
- The prototype was mostly vibe coded with Claude Sonnet 4.5 and presented next to the YAMPI MCP server in Poznan
- It joined forces with Freddy Kristensen's Directions for Partners project and is promised to stay free
