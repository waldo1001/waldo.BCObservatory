# FlowFields with same filters and table in a single OUTER APPLY

[Read the post](https://duiliotacconi.com/2026/02/13/flowfields-with-same-filters-and-table-in-a-single-outer-apply/) · Duilio Tacconi (Duilio Tacconi, MVP) · 2026-02-13 · 1114 words · tier community · **unreviewed** (machine-generated)

> Dynamics 365 Business Central 2025 Wave 2 optimizes SmartSQL by combining multiple FlowFields with identical table filters into a single OUTER APPLY statement, reducing SQL queries and improving query performance. This enhancement matters for applications with many FlowFields querying the same data pool.

## Key points

- FlowFields sharing the same table and filters now consolidate into one OUTER APPLY instead of separate ones, eliminating redundant data retrieval
- SmartSQL automatically groups SUM, AVERAGE, COUNT, MIN, MAX, EXISTS, and LOOKUP aggregations when they target the same data
- This optimization is enabled by default in version 27.0 and has no configuration needed
- Indexed views (V-SIFTs) are excluded from grouping to maintain their specialized behavior
- The feature reduces network chatter and improves execution plans, with measurable impact on telemetry signals like page views and long-running query traces
