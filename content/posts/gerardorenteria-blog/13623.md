> BC Launch Profile is a VS Code extension that centralizes and streamlines management of Business Central environment configurations across multiple clients and sandboxes. It eliminates manual editing of launch.json files by enabling instant environment switching, team collaboration through shared JSON profiles, and quick configuration duplication.

## Key points

- Allows developers to instantly switch between multiple Business Central environments stored in a centralized bclaunchprofiles.json file
- Supports team collaboration by making environment configurations shareable via Git, Teams, or SharePoint
- Provides two modes: updating existing launch.json configurations or duplicating and applying profiles for rapid setup
- Includes search functionality to find configurations by client name, environment type, or tenant ID

- Features: Instant environment switching, Centralized configuration management, Shareable team profiles, Search by client/environment/tenant, Configuration duplication, Git version control integration
