# 🤖 AboutText: Teaching AI to Understand Your APIs ✨

> The AboutText property, added to APIV2 pages in Business Central 27.1, allows APIs to describe themselves to AI assistants. When APIs are exposed through the Model Context Protocol (MCP), this property tells AI systems what the API manages, what data it includes, what operations it supports, and what use cases it enables, helping AI assistants decide when to use the correct API.

## Key points

- AboutText is a new property in BC 27.1 for APIV2 pages that describes API functionality to AI systems
- The property appears as a tool description in Copilot Studio when reading MCP configuration
- AI assistants read AboutText to determine which API to use when responding to user requests
- Best practice structure includes what the API manages, what data it includes, operations supported, use cases, and integrations
