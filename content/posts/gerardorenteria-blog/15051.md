# 🔎 Change Log Blame View: View change history in a different way

> The Change Log Blame View extension reorganizes standard change log data into a matrix-style view where rows represent fields and columns represent events, making it easier to track when specific record values changed, by whom, and why.

[Read the post](https://gerardorenteria.blog/2026/07/17/%f0%9f%94%8e-change-log-blame-view-view-change-history-in-a-different-way/) · Gerardo Renteria (Gerardo Renteria) · 2026-07-17 · 1237 words · tier community · **unreviewed** (machine-generated)

## Key points

- Matrix layout displays change history with fields as rows and events as columns for easier timeline visualization
- Filters and groups change log entries by table and primary key, excluding audit fields to reduce clutter
- Reusable pattern via page extensions allows adding a 'Change Log (Blame View)' action to any record page
- Helps quickly identify which field changed, when it changed, and which user made the change

## Quotes

- "This way, instead of reviewing isolated entries, you can read the history almost like a visual timeline." (Explains the core benefit of the matrix layout for understanding record evolution visually)
- "This is not a closed solution. The idea can be reused on any page where you can identify the current record." (Shows the extension's reusability across different pages and record types through a standardized pattern)
