# 🧠 Global memory for your VS Code agent: preferences that follow you

> VS Code agents can use a built-in memory system with three scope levels (user, repository, and session) to store preferences and context that persist across conversations. This feature helps agents remember user preferences, project conventions, and temporary task context automatically in future sessions.

[Read the post](https://gerardorenteria.blog/2026/05/19/%f0%9f%a7%a0-global-memory-for-your-vs-code-agent-preferences-that-follow-you/) · Gerardo Renteria (Gerardo Renteria) · 2026-05-18 · 885 words · tier community · **unreviewed** (machine-generated)

## Key points

- Memory has three scopes: User (persistent across all workspaces, first 200 lines auto-loaded), Repository (scoped to workspace, persists between conversations), and Session (temporary, cleared when chat closes)
- Users tell the agent in natural language what to remember, and it automatically chooses the appropriate scope and creates files to apply in future sessions
- Memory is stored locally on the machine and managed through two chat commands
- The feature must be enabled via 'github.copilot.chat.tools.memory.enabled: true' configuration
