## Key points

- AL Language versions range from early 2017 updates (0.2 to 0.13) through Business Central 2027 release wave 1 (version 30.0)
- Recent versions add support for markdown page fields, multi-pair ModifyAll operations, snapshot debugging for tests, document media types, and ternary operators
- The extension handles compiler optimizations like parallel workspace compilation, AppSourceCop rule updates, and improved error diagnostics
- Agent and copilot features integrated including GPT-5.3-chat model upgrades and searchable downloaded symbols
- Bug fixes address issues with publishing, packaging, formatting, debugging, and language server functionality
