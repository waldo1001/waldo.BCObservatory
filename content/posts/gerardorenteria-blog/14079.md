# AL Language extension for Microsoft Dynamics 365 Business Central – versions

[Read the post](https://gerardorenteria.blog/2026/10/19/al-language-extension-for-microsoft-dynamics-365-business-central-versions/) · Gerardo Renteria (Gerardo Renteria) · 2026-10-19 · 9991 words · tier community · reviewed (checked by Opus)

> Bilingual summary page of the AL Language extension changelog. It lists entries from the early 2017 monthly updates (0.2.x) up to version 30.0 for Business Central 2027 release wave 1, and points to the official VS Code Marketplace changelog for the full text. Each version entry covers new language and compiler features, AppSourceCop rule changes and bug fixes.

## Key points

- Version 30.0 adds Markdown page fields, ModifyAll with up to five field and value pairs on Record and RecordRef, and the AL0720 check for multi-root workspaces.
- Versions 18.x add snapshot debugging of AL tests through the MCP proxy, sharing public packaged resources between apps, ReadCommitted for queries and environment-wide symbol search.
- Earlier versions add the HttpClientHandler for mocking HTTP in tests, YAML in JsonObject, packaged resources via NavApp, the ternary operator and the Document and Task extended data types.
- Many entries list AppSourceCop rule updates and fixes for publishing, the formatter, the debugger and the language server.
- The 17.0 and 18.0 entries note that agents in Business Central move to GPT-5.3-chat as their default model.

## Quotes

- "Apps can now expose selected packaged resources to other apps." (Enables better code organization and reusability by allowing extensions to share resources across app boundaries)
- "We have introduced a new handler type HttpClientHandler to allow mocking the response of HTTP requests in test codeunits." (Facilitates better testing practices by enabling developers to mock external HTTP dependencies in AL tests)
