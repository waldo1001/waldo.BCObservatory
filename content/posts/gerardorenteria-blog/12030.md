# 📖 Improving the error experience in BC with contextual links 📢

[Read the post](https://gerardorenteria.blog/2025/09/05/%f0%9f%93%96-improving-the-error-experience-in-bc-with-contextual-links-%f0%9f%93%a2/) · Gerardo Renteria (Gerardo Renteria) · 2025-09-05 · 1063 words · tier community · **unreviewed** (machine-generated)

> Business Central's Forward Links feature provides contextual help URLs for common errors. Custom ForwardLinks can be added via Event Subscribers to complement Microsoft's standard links, helping users solve problems faster by displaying support URLs directly in error messages.

## Key points

- Forward Links are predefined error-to-documentation mappings (Name, Description, Link) that appear automatically in Error Messages pages
- Custom ForwardLinks can coexist with standard ones by using Event Subscribers on the Named Forward Link table
- Event Subscriber code executes on load to register custom links like CUSTOM_GENERAL_VALIDATION, CUSTOM_INTEGRATION_PBI, and CUSTOM_WORKFLOW_HELP
- A test page can simulate multiple errors simultaneously to verify ForwardLink behavior in realistic scenarios

## Quotes

- "When an error occurs that has an associated ForwardLink, Business Central automatically displays the Support URL field on the Error Messages page." (Explains how ForwardLinks integrate into the standard error handling workflow to provide immediate help)
