# 🧭 Page Explorer for Business Central: everything a page hides, in plain sight

[Read the post](https://gerardorenteria.blog/2026/07/10/%f0%9f%a7%ad-page-explorer-for-business-central-everything-a-page-hides-in-plain-sight/) · Gerardo Renteria (Gerardo Renteria) · 2026-07-10 · 1154 words · tier community · reviewed (checked by Opus)

> Page Explorer is an AL extension that displays all fields and actions available on a Business Central page in a single window, showing their current values, descriptions, and tooltips. It uses the native Page Summary Provider codeunit to parse page metadata and helps users understand page structure and available options.

## Key points

- Displays fields with current values and descriptions, plus available actions with tooltips in a side-by-side interface
- Built on Page Summary Provider codeunit and Page Action table 2000000143 included in Business Central
- Provides a 'With Value Only' filter to show only populated fields and a debug view showing raw JSON
- Extended via pageextensions that add a Page Explorer button to any page by passing the page ID and record SystemId
- Includes pre-built extensions for Customer Card, Vendor Card, Item Card, and Sales Order pages

## Quotes

- "The pattern is always the same: a pageextension that adds the action in processing and passes the corresponding Page:: together with the record's SystemId." (Shows the reusable pattern that makes the extension easily extensible to any page without duplicating core logic.)
