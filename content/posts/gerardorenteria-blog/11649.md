> This post describes a custom personal tagging system for Business Central that uses colors and emojis to visually categorize and identify records across different entity types. The system enables user-scoped tags that help users organize and quickly recognize records without affecting other users.

## Key points

- Tags work universally across any Business Central table including customers, vendors, orders, and items
- Visual design uses emoji and color combinations for immediate recognition and priority identification
- User-scoped implementation stores tags in two linked tables without impacting other users
- Integration occurs through FactBox UI elements added to entity card pages for easy tag management
- Eight codeunit functions handle core operations: creating, assigning, removing, searching, and retrieving tags
