# 🪶 How to slim down the prompt and spend fewer credits in Github Copilot

[Read the post](https://gerardorenteria.blog/2026/06/04/%f0%9f%aa%b6-how-to-slim-down-the-prompt-and-spend-fewer-credits-in-github-copilot/) · Gerardo Renteria (Gerardo Renteria) · 2026-06-04 · 2140 words · tier community · **unreviewed** (machine-generated)

> GitHub Copilot switched to token-based billing on June 1, 2026. The post explains how to reduce credit spending through context optimization (cleaning tools and extensions), developing efficient chat habits (shorter threads, avoiding redundant file pasting), selecting appropriate models and reasoning effort levels, and matching task complexity to the right mode (Ask, Plan, or Agent).

## Key points

- Token costs vary significantly: cached reads are cheapest, outputs are most expensive; each factor in the cost formula (context size, iterations, model price, reasoning effort) is controllable
- Environment cleanup reduces context bloat by disabling unused tools, extensions, and MCP servers that silently inject artifacts into every message
- Chat habits matter: keep threads short (12-15 turns or 80-120K tokens), close chats when changing topics, reference files with # instead of pasting full content, and paste text rather than requesting URLs to be read
- Match models and modes to task complexity: lightweight models for factual questions in Ask mode are cheapest; save powerful models and high reasoning effort for deep bugs and architecture decisions
- Diagnosis before iteration: if results are weak, improve the prompt first (cheap), then increase reasoning effort, then upgrade the model; blind repetition wastes credits and rarely converges
