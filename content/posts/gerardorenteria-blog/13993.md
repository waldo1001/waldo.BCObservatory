# 🧠 Agent Skills + MCPs: check your BC extension health in VS Code 🔍

> Agent Skills are reusable instruction packages in VS Code that orchestrate external tools like YAMPI and BC Telemetry Buddy to analyze Business Central extension health across environments. A three-level loading model activates only relevant skills without penalizing context, enabling developers to check extension status, versions, deployments, and lifecycle events in production through a single chat message.

[Read the post](https://gerardorenteria.blog/2026/03/07/%f0%9f%a7%a0-agent-skills-mcps-check-your-bc-extension-health-in-vs-code-%f0%9f%94%8d/) · Gerardo Renteria (Gerardo Renteria) · 2026-03-07 · 1410 words · tier community · **unreviewed** (machine-generated)

## Key points

- Agent Skills are folders in .github/skills/ containing SKILL.md instructions and tool references that Copilot conditionally loads based on context relevance
- The SKILL.md frontmatter description is critical for skill activation at Level 1, requiring clear use case documentation to ensure Copilot recognizes when the skill applies
- Skills orchestrate external MCPs without executing their own code: YAMPI provides environment and installed app data while BC Telemetry Buddy analyzes 6 extension lifecycle events (installations, updates, failures) via KQL queries
- A unified health report consolidates environment versions, available updates, and telemetry events from multiple parallel tool calls into two Markdown tables for extension diagnostics across all tenants

## Quotes

- "The description is critical because it's what Copilot reads at Level 1 to decide if the skill is relevant." (Explains why proper skill documentation is essential for activation and why poorly described use cases will prevent skill loading)
