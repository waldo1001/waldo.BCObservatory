# 📋 Effortless Copy Actions: From Business Central to Clipboard 📎

[Read the post](https://gerardorenteria.blog/2025/11/19/%f0%9f%93%8b-effortless-copy-actions-from-business-central-to-clipboard-%f0%9f%93%8e/) · Gerardo Renteria (Gerardo Renteria) · 2025-11-19 · 961 words · tier community · reviewed (checked by Opus)

> This extension enables users to copy formatted customer, vendor, and transaction data from Business Central directly to the clipboard with a single action, ready to share via email, Teams, or other applications. It demonstrates a modular AL architecture using page extensions, codeunits, and WebPageViewer to handle data formatting and clipboard operations.

## Key points

- Modular architecture separates formatting logic by entity type into dedicated codeunits for customers, vendors, and ledger entries
- WebPageViewer add-in renders HTML with two-column layout and JavaScript clipboard API for seamless data copying
- Page extensions add copy actions to Customer List, Vendor List, and Customer Ledger Entries, integrating the feature into existing workflows
- Formatted data preserves layout when pasted into external applications like email, Teams, or text editors
