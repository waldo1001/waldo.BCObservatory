# Visual Studio Code – versions

> Visual Studio Code released numerous updates from April 2024 through September 2026, with emphasis on agent-based development, integrated browser tools, AI model flexibility, and enhanced developer productivity features. This helps teams stay current on available coding editor capabilities and AI-assisted development workflows.

## Key points

- Agent-first development became central with autonomous task completion, background agents, and multi-agent orchestration across local and cloud resources
- Integrated browser tools allow agents to validate their own work by taking screenshots, clicking through pages, and testing web apps without leaving the editor
- Support for multiple AI models and providers, including Claude, Copilot, ChatGPT, and custom API keys with configurable thinking effort and token optimization
- MCP (Model Context Protocol) servers enable extensible tool ecosystems for agents to access specialized capabilities and APIs
- Developer experience improvements include quick chats, chat checkpoints, session memory, and streamlined multi-file editing across workspaces
