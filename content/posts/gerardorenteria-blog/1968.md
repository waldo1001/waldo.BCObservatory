> Visual Studio Code release notes covering versions 1.95 through 1.142 (August 2024 to October 2026), highlighting agent-focused features including autonomous task execution, model management, integrated browser capabilities, debugging tools, and enterprise controls for managing AI development workflows.

## Key points

- VS Code increasingly emphasizes agentic capabilities with autonomous task execution, subagents, and background session management across multiple versions
- Model flexibility expanded through model provider switching, BYOK (bring-your-own-key) options, and Anthropic/OpenAI model support with configurable context windows up to 1M tokens
- Enterprise and security features strengthened with agent sandboxing, permission policies, MCP server sandboxing, and command risk assessment for safe AI autonomy
- Integrated browser tools evolved from preview to general availability, enabling agents to navigate, take screenshots, and validate their own work without leaving VS Code
- Developer productivity enhanced through features like multi-folder sessions, session memory, chat history sync across machines, and ability to fork/continue conversations
