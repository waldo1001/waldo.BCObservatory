> This post demonstrates a custom marking feature that restores legacy NAV functionality, allowing users to mark specific records across multiple filters and analyze them together in Business Central lists. The solution uses table extensions, an enum for visual markers, and page extensions with keyboard shortcuts to enable cross-filter record selection.

## Key points

- Marks individual records with Ctrl+F3 to create a subset for focused analysis across different filter criteria
- Uses a boolean enum field with a Unicode bullet symbol (●) visible in the list for quick visual identification
- Combines marking with Business Central's analysis mode to group, total, and display only marked records
- Provides a reusable architectural pattern through table extensions and page extensions that works with any list page
- Enables workflow where users apply filters, mark results, apply different filters, mark those results, then analyze all marked records together
