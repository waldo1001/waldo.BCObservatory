# 🪝 VS Code Agent Hooks: Give Copilot Context Before the First Message

[Read the post](https://gerardorenteria.blog/2026/05/03/%f0%9f%aa%9d-vs-code-agent-hooks-give-copilot-context-before-the-first-message/) · Gerardo Renteria (Gerardo Renteria) · 2026-05-03 · 1951 words · tier community · **unreviewed** (machine-generated)

> VS Code Agent Hooks allow developers to automatically run scripts at specific lifecycle events to provide dynamic context to AI agents before and during sessions. The post demonstrates how to use SessionStart and PreCompact hooks to ask onboarding questions, store answers, and reinject context when conversations are compacted, enabling agents to adapt their behavior based on project type, technology stack, and experience level.

## Key points

- Agent hooks execute at 8 defined lifecycle points and receive/respond with JSON to influence agent behavior
- SessionStart hook fires once when a session begins and can ask questions to establish context before any user input
- PreCompact hook fires before conversation compaction to re-inject onboarded context so the agent doesn't lose session information
- Hooks use JSONL files to persistently store session answers and profiles (junior, mid, senior) to tailor agent responses
- Hooks provide dynamic runtime context complementary to instructions and custom prompts, not replacing them

## Quotes

- "Agent Hooks allow you to automatically run code at specific points in the agent lifecycle, before the user types anything." (This is the core capability that enables automation of context setup without manual intervention on every session.)
- "Hooks don't replace instructions or custom prompts; instead, they provide dynamic runtime context." (Clarifies the complementary role of hooks within the broader system of agent customization.)
