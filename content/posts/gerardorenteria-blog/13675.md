# 📝 Adding Notes to Financial Report Lines 📊

[Read the post](https://gerardorenteria.blog/2026/02/14/%f0%9f%93%9d-adding-notes-to-financial-report-lines-%f0%9f%93%8a/) · Gerardo Renteria (Gerardo Renteria) · 2026-02-14 · 1057 words · tier community · **unreviewed** (machine-generated)

> An AL extension adds line-level notes to financial reports (Account Schedules) in Business Central, allowing users to document explanations directly within reports instead of maintaining separate documentation. Notes appear in the definition page, matrix overview, printed reports with synchronized numbering, and Excel exports.

## Key points

- Two new fields added to Account Schedule lines: Has Notes (calculated) and Note Text with edit dialog
- FactBox in Account Schedule Overview shows notes for selected lines with direct edit actions
- Reports include superscript indices in descriptions and a synchronized NOTES TO FINANCIAL STATEMENTS section
- Excel export includes a bold Notes column with all line notes and preserved formatting
- Solution supports CFO/controller presentations, auditor documentation, and analyst variance comments

## Quotes

- "Some users in monthly closing meetings always had to keep additional separate documentation to explain things." (Identifies the core problem this extension solves: keeping explanations separate from financial reports.)
