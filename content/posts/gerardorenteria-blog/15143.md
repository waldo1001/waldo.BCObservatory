# 🧩 Deriving dimensions in Business Central beyond Default Dimensions

> The OnAfterGetRecDefaultDimIDProcedure integration event in the DimensionManagement codeunit fires after Business Central calculates default dimensions, allowing you to extend or modify dimension sets with custom logic. This approach demonstrates five scenarios: deriving dimensions from document fields, other dimensions, related tables, historical data, and overriding with higher-priority rules.

## Key points

- Hook into OnAfterGetRecDefaultDimIDProcedure to extend default dimensions without modifying standard code
- Use two helper procedures: StageDim to prepare dimensions in a temporary buffer and CommitStagedDims to merge them into the document's dimension set
- Derive dimensions from multiple sources: document fields, already-calculated dimensions, related table lookups, and historical customer data
- Force dimension recalculation by subscribing to field OnAfterValidateEvent when Business Central doesn't automatically recalculate
- Override previously derived dimensions with higher-priority rules in the same event to implement conditional logic
