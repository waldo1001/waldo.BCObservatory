# BcContainerHelper – versions

> BcContainerHelper is a PowerShell module for managing Business Central containers. This post documents release notes for versions 6.1.18 through 5.0.4, covering fixes for PS7 remote session issues, Docker service readiness, test app dependencies, backup operations, NuGet package handling, compiler folder functionality, and numerous other improvements.

[Read the post](https://gerardorenteria.blog/2026/09/09/bccontainerhelper-version/) · Gerardo Renteria (Gerardo Renteria) · 2026-09-09 · 11416 words · tier community · **unreviewed** (machine-generated)

## Key points

- Disables PSSessions for BC v27-v28 by default due to PS7 remote session issues, with escape hatches available
- Adds Docker service readiness polling (up to 120 seconds) before creating containers to prevent immediate failures
- Fixes multiple Run-AlPipeline issues including test app dependency installation and publishing with useCompilerFolder
- Adds NuGet caching improvements and performance optimizations for package downloading and resolution
- Introduces support for online sandboxes and pre-installed Business Central instances in CI/CD pipelines

## Quotes

- "New-BcContainer: Wait for the Docker service to become ready (poll up to 120 seconds) instead of failing immediately." (Describes improved resilience when Docker daemon is still starting, particularly important for CI runners)
- "Use Artifact Index by default when using Get-BcArtifactUrl" (Indicates a major performance improvement by using indexed artifact resolution as the default method)
