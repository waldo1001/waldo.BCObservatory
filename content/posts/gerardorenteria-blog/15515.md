# 🌍 Amount Conversion to Favorite Currencies in Business Central

[Read the post](https://gerardorenteria.blog/2026/11/15/%f0%9f%8c%8d-amount-conversion-to-favorite-currencies-in-business-central/) · Gerardo Renteria (Gerardo Renteria) · 2026-11-15 · 1491 words · tier community · **unreviewed** (model text not yet checked)

> An extension that displays amount conversions to user-selected favorite currencies directly within Business Central pages using existing exchange rates. It works on any amount field via drill-down or assist-edit triggers and in factboxes, showing converted amounts with the applicable exchange rate date and factor.

## Key points

- Users select favorite currencies (e.g. USD, GBP, CHF) and see amounts converted in those currencies without leaving the current page
- The extension uses the standard Currency Exchange Rate table and ApplnExchangeAmtFCYToFCY function, ensuring consistency with BC's posting logic
- Conversions apply the latest exchange rate dated on or before the document date, handle multi-currency triangulation, and round to target currency precision
- The solution provides two UI patterns: OnDrillDown for non-editable fields (like sales orders) and OnAssistEdit for editable fields (like general journals), plus a compact factbox view
- Missing exchange rates display as 0 in red without raising errors, and configuration uses a simple page listing currency codes with order and active status
