> A custom bookmark organizer system that lets users create hierarchical folder structures to organize Business Central pages by workflow, with export and import capabilities via JSON. Complements native roles and bookmarks for personalized daily navigation, onboarding workflows, and process-specific page organization.

## Key points

- Users organize pages into hierarchical folders per role or process, not managed by IT, complementing native roles
- Supports import/export of bookmark structures as JSON templates for sharing between users or backup
- Includes a Role Center widget showing an expandable tree for quick page access alongside dedicated navigation pages
- Enables scenarios like daily workflow shortcuts, structured new user onboarding paths, and month-end process routing
