# 🚫 Never Publish an AL Extension with Missing Translations Again

> A VS Code extension that validates translation files are present before publishing AL extensions, manages regional language variants, and visually highlights incomplete translations. It helps developers prevent missing translations for required markets.

[Read the post](https://gerardorenteria.blog/2026/04/16/%f0%9f%9a%ab-never-publish-an-al-extension-with-missing-translations-again/) · Gerardo Renteria (Gerardo Renteria) · 2026-04-16 · 1399 words · tier community · **unreviewed** (machine-generated)

## Key points

- Enforces required languages through VS Code configuration and validation commands
- Automatically handles regional language variants like es-ES_tradnl and fr-CH as equivalents of base languages
- Creates or syncs regional variant translation files from base language files
- Highlights incomplete translations in g.xlf and language-specific files with configurable visual indicators
- Displays language status tooltips when hovering over highlighted entries
