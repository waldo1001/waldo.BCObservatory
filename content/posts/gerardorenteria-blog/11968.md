> The post presents an enhancement to Business Central's standard user task functionality that links tasks directly to specific records like customers or vendors. Instead of standalone tasks, users can now create contextualized tasks from record cards or through a record selector, with a Related Record section for navigation.

## Key points

- User tasks can be linked to specific records (customers, vendors, items, sales orders, or any table) through a new Select Related Record button
- A Related Record FactBox on any card displays only tasks related to that specific record and allows creating new linked tasks automatically
- Tasks created from record cards are automatically contextualized to the current record, and a Go to Related Record button enables quick navigation
- The implementation includes a table extension for contextual fields, a codeunit for linking operations, and page extensions for task cards and record selectors
