> AL Object Visualizer is a VS Code extension that displays AL objects in a filterable tree view with customizable badges and colors, helping developers navigate and manage multiple files across projects efficiently.

## Key points

- Automatically decorates AL files with Unicode badges and colors in the Explorer based on object type
- Groups all workspace objects by type in a statistics panel with configurable folder nesting levels
- Supports real-time text and regex filtering to quickly locate specific AL objects
- Allows direct file opening from filtered results and provides quick picker selection by object type
