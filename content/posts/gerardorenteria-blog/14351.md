# 🔍 Field Magnifier for BC: Enhanced Accessibility 👓

> A contextual field magnifier extension for Business Central improves readability by displaying magnified field content in a floating popup on hover, with three adjustable zoom levels (3x, 4x, 5x), without affecting the rest of the interface.

## Key points

- Detects hover events on BC fields and extracts caption and value to display magnified in a floating popup
- Offers three adjustable zoom levels (3x, 4x, 5x) that grow caption and value proportionally
- Implemented using a Control AddIn (JavaScript + CSS) with Page Extensions and Actions for toggle and zoom control
- Benefits users with visual needs or anyone wanting better readability without permanent interface changes
- Uses a reusable pattern that can be applied to any BC page
