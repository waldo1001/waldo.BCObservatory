# ⚙️ GitHub Copilot: Workspace-Level Control Over AI Context 🔄

> GitHub Copilot allows developers to organize and control AI context at the workspace level by enabling or disabling instructions, prompts, agents, and skills per project or client through settings.json configuration. This prevents style guidelines and rules from one client or project from interfering with work on another.

[Read the post](https://gerardorenteria.blog/2026/03/02/%e2%9a%99%ef%b8%8f-github-copilot-workspace-level-control-over-ai-context-%f0%9f%94%84/) · Gerardo Renteria (Gerardo Renteria) · 2026-03-02 · 718 words · tier community · **unreviewed** (machine-generated)

## Key points

- Organize AI context (instructions, prompts, agents, skills) into separate folders by client, project, or purpose
- Toggle context on or off per workspace using true/false switches in settings.json
- Use diagnostics in the Chat Configure menu to verify which context Copilot is actually using
- Prevents mixing of personal preferences, client rules, and company guidelines that could create conflicts
- Example folder structure separates AL development, TypeScript, security reviews, and client-specific instructions
