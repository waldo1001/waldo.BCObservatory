# 💸The answer is the expensive part: controlling output tokens

> Output tokens cost 6× more than input tokens in large language models, making it essential to control what Copilot writes rather than just what you send. The post explains hidden reasoning tokens and provides practical habits and prompt instructions to reduce output costs when using Copilot for AL development and code changes.

## Key points

- Output tokens are 6 times more expensive than input tokens because the model generates responses word-by-word, requiring multiple neural network passes
- Reasoning tokens (used for planning and self-correction in advanced models) are billed as output even when invisible on screen
- Surgical prompts requesting specific changes (e.g., modifying only a procedure instead of rewriting entire codeunits) can reduce costs by 19×
- Agent mode costs scale nonlinearly with iterations; use Ask mode for understanding, Plan for decisions, and Agent only for execution
- Permanent conciseness instructions and clear output format constraints (diff only, no prose, no alternatives) provide recurring high savings across all prompts
