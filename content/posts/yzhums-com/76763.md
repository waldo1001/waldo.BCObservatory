# Dynamics 365 Business Central: How to quickly copy a report layout (Create a copy of the selected layout)

[Read the post](https://yzhums.com/76763/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-10-22 · 360 words · tier community · reviewed (checked by Opus)

> Report layouts control report content and formatting in Business Central. Users can quickly copy an existing layout by selecting it, toggling 'Save Changes to Copy', entering a new name, and confirming on the Report Layouts page.

## Key points

- Report layouts determine which fields, arrangement, and styling appear in reports
- Four layout types are available: Word, RDLC, Excel, and External
- The 'Save Changes to Copy' toggle enables quick duplication without exporting and importing
- Copied layouts can be customized after creation
