# Business Central 2025 wave 2 (BC27): Go To Symbol In Workspace (Ctrl+T) has been extended to search for a broader range of AL symbols (includes Procedures, events, global variables, and many more)

[Read the post](https://yzhums.com/66056/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-07-24 · 436 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2025 wave 2 extends the Go To Symbol In Workspace feature (Ctrl+T) in Visual Studio Code to search for a broader range of AL symbols beyond application objects, including procedures, events, global variables, page controls, page actions, and table fields, making navigation and source code discovery easier for developers.

## Key points

- Go To Symbol In Workspace (Ctrl+T) now searches procedures, events, global variables, page controls, page actions, table fields, and more beyond just application objects
- The extended search can be disabled or configured via settings like al.extendGoToSymbolInWorkspace.enabled, ResultLimit, and IncludeSymbolFiles
- Developers can jump directly to target code from search results, improving workflow efficiency
- The feature was introduced in BC26 with searchable downloaded symbols and has been significantly expanded in BC27

## Quotes

- "The Visual Studio Code feature "Go To Symbol In Workspace" (Ctrl + T) has been extended to search for a broader range of AL symbols." (This core capability enables developers to find and navigate to more types of AL code elements efficiently, beyond just application objects.)
- "After clicking, you can jump directly to the target code, and the same is true for the following." (Direct navigation to code improves developer productivity by eliminating manual searching through source files.)
- "This new way of searching can be disabled under the setting "al.extendGoToSymbolInWorkspace.enabled"" (Configuration options allow developers to customize the feature behavior based on their preferences and performance needs.)
