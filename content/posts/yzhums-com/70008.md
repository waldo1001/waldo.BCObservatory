# Dynamics 365 Business Central: Add a Scan Barcode action and scan multiple/Continious scanning (Invoke barcode scanning programmatically from AL)

[Read the post](https://yzhums.com/70008/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-01-15 · 1312 words · tier community · **unreviewed** (model text not yet checked)

> Business Central version 24 introduced barcode scanning APIs using control add-ins to replace .NET-based APIs, enabling developers to add scan actions and continuous scanning to custom pages via the CameraBarcodeScannerProviderAddIn control add-in.

## Key points

- Version 24 provides control add-in based APIs for barcode scanning, replacing deprecated .NET APIs
- Use CameraBarcodeScannerProviderAddIn control add-in to add barcode scanning buttons and actions to custom pages
- Implement BarcodeAvailable and BarcodeFailure event triggers to handle scan results and error cases
- Call RequestBarcodeAsync() method to initiate single or continuous scanning; re-call in BarcodeAvailable trigger for continuous mode

## Quotes

- "Version 24 introduced barcode scanning APIs based on control add-ins to replace the .NET-based APIs." (Marks the shift to the recommended approach for implementing barcode scanning in custom extensions)
- "This means we can add scan barcode actions and multiple scanning functions to our own extensions." (Enables developers to create custom barcode scanning capabilities beyond standard Business Central functionality)
- "Enabling multiple scans is also very simple; just remove the comments from step 5 in the sample." (Shows that continuous scanning requires minimal code changes, making it practical for real-world scenarios)
