# Business Central 2026 release wave 2 (BC29): Administrators can turn SIFT (SumIndexField Technology) indexes on/off

[Read the post](https://yzhums.com/75894/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-09-09 · 458 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2026 release wave 2 (BC29) enables administrators to turn SIFT (SumIndexField Technology) indexes on and off directly within the application. SIFT indexes optimize performance of FlowFields and query results by quickly calculating sums of numeric columns, and administrators can now manage them through Index Management or Table Information pages.

## Key points

- Administrators can toggle SIFT indexes on/off directly in the Business Central client without database tools
- A new Index Type field distinguishes between regular database indexes and SIFT structures
- Index changes are queued and applied during the next overnight maintenance window
- The feature works with both standard and custom SIFT fields, including table extensions

## Quotes

- "The index has been enqueued to be turned on. It will be attempted during the subsequent maintenance window (overnight local time)." (Clarifies the asynchronous process for index changes)
