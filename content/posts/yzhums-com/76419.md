# Business Central 2026 release wave 2 (BC29): Run data queries with MCP Server (no APIs required)

[Read the post](https://yzhums.com/76419/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-10-02 · 509 words · tier community · reviewed (checked by Opus)

> Business Central 2026 release wave 2 introduces Data Query Tools for the MCP Server, enabling AI agents to define, validate, and run custom data queries without requiring pre-existing APIs. This capability allows agents to perform ad-hoc joins and aggregates on Business Central data through four new system tools.

## Key points

- Data Query Tools is a new preview feature that adds system tools for compiling and running AL data queries submitted by MCP clients
- Four new system tools are available: bc_data_find_tables, bc_data_get_table_relations, bc_data_get_table_schema, and bc_data_query
- Data query tools are read-only and prevent agents from creating, modifying, or deleting data
- The feature is managed through a new Server Features tab on the MCP Server Configuration page

## Quotes

- "Your MCP application can then query data for which no existing APIs exist." (Explains the core benefit of data query tools - accessing data that lacks pre-built APIs)
- "Data query tools are read-only and don't allow agents to create, modify, or delete data." (Critical for understanding security constraints and safe data access patterns)
- "agents who use your MCP server configuration have access to data query tools they can use in their workflows." (Shows how agents gain capability to compose custom queries through the MCP server)
