# Business Central 2025 wave 2 (BC27): Cancel build and publish from Visual Studio Code

[Read the post](https://yzhums.com/67446/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-09-08 · 335 words · tier community · reviewed (checked by Opus)

> Business Central 2025 wave 2 introduces the ability to cancel build and publish operations directly from Visual Studio Code, allowing developers to stop long-running processes and iterate faster without waiting for completion.

## Key points

- Developers can now manually cancel the build and publish processes in VS Code by pressing a Cancel button or closing the application
- Cancellation is especially valuable for large extensions where build and publish times are lengthy, improving developer productivity
- If connection to the development environment is lost, publishing automatically cancels to prevent blocking subsequent publish attempts
- The feature is available in pre-release versions of the AL Language extension (v16.0.1743592 and v17.0.1750311)
