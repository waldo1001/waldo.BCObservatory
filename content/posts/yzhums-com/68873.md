# Business Central 2025 wave 2 (BC27.1): Connect AI agents to Business Central through MCP server (Dynamics 365 Business Central MCP)

[Read the post](https://yzhums.com/68873/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-11-10 · 729 words · tier community · reviewed (checked by Opus)

> BC27.1 brings a public preview of the Business Central MCP server, which lets AI agents such as those built in Copilot Studio discover and call Business Central APIs. A new page in Business Central configures which standard or custom APIs are exposed as tools, along with their permissions and options such as dynamic tool mode. At the time of writing, the author saw the Copilot Studio MCP connector only in one Japan-region paid tenant.

## Key points

- MCP is an open standard that lets AI agents discover and invoke Business Central operations such as customers, items and sales orders
- A new Business Central page configures MCP tools: all standard APIs or custom APIs, per-line read/create/modify/delete/bound action permissions, plus header settings such as Active, Dynamic Tool Mode, Discover Additional Objects and Allow Create/Update/Delete Tools
- Only page object types appear in the setup, so the author questions whether query APIs are supported
- Copilot Studio offers a standard Business Central MCP tool where you set environment, company and MCP configuration, then test it, for example by listing customers
- Running a local MCP server in tools like Claude for Desktop still works but the author finds it complicated; on-premises availability is unconfirmed

## Quotes

- "MCP standardizes how applications provide context to language models. This standardization helps applications integrate seamlessly with different data sources and tools." (Clarifies why MCP matters for achieving true AI-driven automation across business systems)

## Heads up

- gotcha: "The Object Type only shows Page, not Query. Does this mean it doesn't support the Query API?" (about version 27.1, version 2025 release wave 2)
