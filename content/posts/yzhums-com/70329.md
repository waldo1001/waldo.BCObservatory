# Dynamics 365 Business Central: View the last known error

[Read the post](https://yzhums.com/70329/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-08-28 · 531 words · tier community · reviewed (checked by Opus)

> Business Central's Help & Support page provides access to the last known error message displayed in the application, including error text, code snippet, callstack, and runtime object details. This feature helps diagnose issues even after error dialogs are closed.

## Key points

- Access the last error via the Help & Support page from the question mark icon in the top-right corner
- Error details include text, code snippet, callstack, and runtime object information
- Collectable errors may prevent accurate error retrieval since error handling is postponed until the end of the procedure
- Use GetLastErrorCode and GetLastErrorText methods to programmatically access error details
- Platform-generated errors cannot be viewed through this link; reproduce in sandbox to troubleshoot platform issues

## Quotes

- "Did you know that even after closing an error dialog, you can inspect the last error via the Help & Support page?" (This shows the practical value of accessing errors after they have been dismissed, helping users diagnose problems retroactively.)
- "Using collectable errors essentially postpones error handling to the end of the procedure call." (This explains a critical limitation of the error retrieval feature, important for developers to understand when implementing error handling strategies.)

## Heads up

- gotcha: "Please note that if collectable errors are used, it is not possible to retrieve accurate error messages."
- gotcha: "And the link can't open errors that were generated by the platform."
- warning: "The result of the GetLastErrorCode method is not translated into the local language."
