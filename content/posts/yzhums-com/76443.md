# General Availability: Dynamics 365 Business Central 2026 release wave 2 (BC29)

[Read the post](https://yzhums.com/76443/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-10-02 · 235 words · tier community · **unreviewed** (model text not yet checked)

> Dynamics 365 Business Central 2026 wave 2 (BC29) is now generally available for cloud customers with version 29.0. New customers get the latest builds automatically, while existing customers receive email notifications when updates become available. On-premises release is pending.

## Key points

- BC29 cloud version is production-ready with platform 29.0.55365.0 and application 29.0.54011.55407
- New SaaS customers automatically receive the latest builds; existing customers get notification emails
- Support period for BC29 runs from September 30, 2026 to April 5, 2028
- On-premises version has not yet been released
- BC25 update introduces flexible environment management with extended update windows (5 months instead of 30-60 days) and optional minor updates
