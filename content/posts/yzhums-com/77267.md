# Dynamics 365 Business Central: New 28+ License Key for On-Premises (license key version update)

[Read the post](https://yzhums.com/77267/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-11-10 · 442 words · tier community · reviewed (checked by Opus)

> Business Central On-Premises licensing changed effective October 1, 2026. Starting with version 28, all releases use a single forward-compatible license key version (28+) instead of version-specific keys, though customers must download a refreshed key before upgrading to each new version.

## Key points

- BC28 and later use a single 28+ license key version instead of keys for each version
- A refreshed 28+ key must still be downloaded before each version upgrade; the download date decides which objects are unlocked
- Using an older 28+ key with a newer version such as BC30 triggers a version compatibility warning
- License keys for BC27 and earlier stay version-specific and unchanged
- DUR keys come from the Microsoft 365 Admin Center and at first show version 28 until Microsoft fixes the format; the release cycle is not affected

## Quotes

- "28+ is a unified license key version, not a license file that automatically supports all future versions." (Critical distinction that prevents misunderstanding about automatic forward compatibility of downloaded keys)

## Heads up

- breaking: "Using the license key downloaded on October 1, 2026, with BC30 will result in a version compatibility warning." (about version 28, version BC28)

- Features: License key version 28+, Forward-compatible licensing, Dual Use Rights download, License key refresh mechanism
- Versions: 28, 27, 26, 25, 30
