# Business Central 2025 wave 2 (BC27): Record and edit easier with enhanced page scripting tool

[Read the post](https://yzhums.com/67705/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-09-17 · 622 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2025 wave 2 introduces enhancements to the page scripting tool, including improved script recording and editing capabilities. These features make user acceptance testing easier by allowing consultants and stakeholders to insert steps at specific points, rearrange step order, delete arbitrary steps, define parameters in the UI, and create suites of scripts directly in the UI without manual file editing.

## Key points

- Define insertion points for next recorded steps by dragging a red line or selecting 'Record from here' option
- Rearrange script steps by dragging them to new positions within the script
- Delete any step in the middle of a script, not just from the end, with warning on first deletion
- Define script parameters directly in the UI properties section instead of editing YAML files
- Create script suites in the UI by including other scripts via relative paths

## Quotes

- "Now, you can drag the red insertion line to control where the next recorded steps are inserted." (Demonstrates a key improvement that eliminates tedious manual editing previously required to insert steps in the middle of scripts)
- "Now, you can add parameters directly in the UI in the properties section for the script." (Shows how the UI enhancements make parameter management more accessible without requiring YAML file editing)
