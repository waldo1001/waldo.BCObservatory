# Business Central 2026 release wave 1 (BC28): Run AL tests from Visual Studio Code (Test codeunits and test methods)

[Read the post](https://yzhums.com/72045/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-04-09 · 675 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2026 wave 1 adds the ability to discover and run AL tests directly inside Visual Studio Code without switching to external tools. Developers can now use Test Explorer to automatically detect test codeunits and test methods, run tests with different profiles, and view coverage results, reducing context-switching and supporting test-driven development.

## Key points

- Test Explorer in Visual Studio Code automatically discovers test codeunits and test methods in the active workspace
- Multiple run profiles available: Publish & Run (default), Run, Run & Debug, and Coverage (Procedure)
- Running tests from VS Code is supported in sandbox and on-premises environments but not production
- AI tests and test runner-dependent events are not supported when running from VS Code; isolation level defaults to Codeunit level unless specified
