# Dynamics 365 Business Central: Version Data Type (Major.Minor.Build.Revision)

[Read the post](https://yzhums.com/40193/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-01-09 · 450 words · tier community · reviewed (checked by Opus)

> The Version data type in Business Central stores version numbers in Major.Minor.Build.Revision format and provides methods to create and retrieve version components. Administrators use version information for troubleshooting and environment management, while developers use the Version data type to handle version numbers programmatically in AL code.

## Key points

- Version data type stores version numbers matching Major.Minor.Build.Revision format with optional Build and Revision components
- Static methods Create() allow building version objects from text strings or individual integer parameters
- Instance methods Major(), Minor(), Build(), Revision() and ToText() retrieve specific version components
- Version data type cannot be used directly as a table field or page variable
- Version information helps administrators troubleshoot issues and manage environment updates
