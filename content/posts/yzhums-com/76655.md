# Business Central 2026 release wave 2 (BC29): Use conditional visibility in the updated Word add-in (Hide If Empty/False in Word Layout)

[Read the post](https://yzhums.com/76655/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-10-14 · 736 words · tier community · reviewed (checked by Opus)

> Business Central 2026 wave 2 introduces conditional visibility controls in the Word add-in, allowing developers to design reports with hidden or shown content based on boolean fields using HideIf logic - a capability previously only available in RDLC layouts.

## Key points

- BC29's updated Word add-in adds a HideIf logic control so Word layouts can show or hide content conditionally, something earlier achieved in RDLC with decision functions like IIF.
- Under the Visibility tab, the Hide If Empty actions are Hide Field if Zero, Hide Empty Table, Hide Empty Table Row and Hide Empty Table Column, each needing a specific selection.
- Hide If False opens a dialog whose options depend on the current selection and lets you pick a boolean field from the report dataset, including ones added by report extensions.
- Install the latest add-in version (3.0.0.0) from the Word Add-ins menu to get these controls.
