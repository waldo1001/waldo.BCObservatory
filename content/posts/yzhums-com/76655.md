# Business Central 2026 release wave 2 (BC29): Use conditional visibility in the updated Word add-in (Hide If Empty/False in Word Layout)

[Read the post](https://yzhums.com/76655/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-10-14 · 736 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2026 wave 2 introduces conditional visibility controls in the Word add-in, allowing developers to design reports with hidden or shown content based on boolean fields using HideIf logic - a capability previously only available in RDLC layouts.

## Key points

- The Word add-in now supports HideIf logic control for conditional visibility, bringing feature parity with RDLC layouts
- Developers can apply Hide If Empty and Hide If False controls to fields, tables, rows, and columns based on boolean fields in the dataset
- Conditional visibility can be applied to stand-alone fields, table rows, table columns, and entire tables
- Boolean fields from the report dataset and Report Extensions can be used to control when content appears

- "Awesome! That gives us one more reason to skip RDLC." (Highlights the significance: developers now have less reason to use the more complex RDLC layout type for conditional visibility scenarios.)
