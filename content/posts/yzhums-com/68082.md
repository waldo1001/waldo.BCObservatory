# Business Central 2025 wave 2 (BC27): TextConst Data Type now have manipulation methods (Contains, ToUpper, Replace, etc.)

[Read the post](https://yzhums.com/68082/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-10-03 · 546 words · tier community · reviewed (checked by Opus)

> Business Central 2025 wave 2 (BC27) introduces manipulation methods for the TextConst data type, enabling string operations like Contains, Replace, ToUpper, Split, and Trim. These methods are available in runtime version 15.1 or greater.

## Key points

- TextConst data type now supports 20+ string manipulation methods for operations on text constants
- Common methods include Contains, StartsWith, EndsWith, Replace, Split, and case conversion functions
- Methods for string searching include IndexOf, LastIndexOf, and IndexOfAny with optional position parameters
- Text formatting methods available: PadLeft, PadRight, Remove, Trim, TrimStart, and TrimEnd
- Runtime version 15.1 or greater required; Contains is not available in version 15.0

- "With this wave (BC27), Microsoft added manipulation methods for this data type." (Establishes that this is a new feature in BC27 specifically for TextConst data type)
- "These methods are supported in runtime version '15.1' (Business Central 2025 release wave 1 Update 26.1) or greater." (Clarifies the minimum runtime version requirement for developers implementing these methods)

## Heads up

- warning: "'Contains' is not available in runtime version '15.0'. The supported runtime versions are: '15.1' or greater." (about version 15.1, version BC27)
