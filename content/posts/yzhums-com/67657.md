# Business Central 2025 wave 2 (BC27): Configure the default calculation for the Calculate Consumption report (Default Consumption Calculation Based on)

[Read the post](https://yzhums.com/67657/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-09-12 · 375 words · tier community · reviewed (checked by Opus)

> Business Central 2025 wave 2 introduces a new Default Consumption Calculation Based on field in Manufacturing Setup that lets users specify whether the Calculate Consumption report should default to expected or actual output, saving time by eliminating manual changes for each consumption calculation.

## Key points

- Manufacturing Setup now has a Default Consumption Calculation Based on field to configure default consumption calculation behavior
- Users can choose between Expected Output or Actual Output as the default calculation basis
- The default selection applies to the Calculate Consumption report and production journal consumption line calculations
- The field defaults the report but users can override the selection when needed

## Quotes

- "set the default consumption calculation in Manufacturing Setup so the Calculate Consumption report matches your preferred process automatically" (Explains the primary business value of automating report defaults to save time and reduce manual effort)
- "Whether the calculation of the quantity to consume is based on the actual output or on the expected output" (Clarifies the two calculation options available for users to configure based on their operational needs)
