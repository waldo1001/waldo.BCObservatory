# Dynamics 365 Business Central Blog Series: Integrate with Microsoft Dataverse

[Read the post](https://yzhums.com/63916/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-06-30 · 962 words · tier community · **unreviewed** (model text not yet checked)

> The post outlines three methods to integrate Business Central with Microsoft Dataverse: using the standard Dataverse connector with job queue-based synchronization, using integration tables (CDS TableType), or calling Dataverse APIs directly. It covers setup procedures, OAuth authentication, custom table integration, and recent enhancements across multiple releases.

## Key points

- Three integration approaches exist: standard connector (scheduled sync), integration tables (CDS TableType), and direct Dataverse API calls
- Standard Dataverse connector uses scheduled job queue entries and does not guarantee real-time data consistency
- OAuth 2.0 with Client Credentials grant type can authenticate Dataverse API calls via tools like Postman
- Recent features enable mapping new Dataverse fields, using synthetic relationships, safe company copying with integration, and multi-currency support
- Integration table mappings can be customized and extended for both standard and custom Dataverse tables

## Quotes

- "Using OAuth 2.0 to connect Dataverse tables (APIs) in Postman (Using Grant type: Client Credentials, not Implicit)" (Specifies the correct OAuth grant type for API-based Dataverse integration, guiding developers on proper authentication setup)
