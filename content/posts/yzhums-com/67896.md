# Business Central 2025 wave 2 (BC27): Tenant administrators can set Feature Management switches with an API (page 30092 “APIV2 – Feature Management”)

[Read the post](https://yzhums.com/67896/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-09-29 · 949 words · tier community · reviewed (checked by Opus)

> Business Central 2025 wave 2 introduces an automation API that allows tenant administrators to manage Feature Management switches programmatically. This capability enables automating feature switch settings across multiple companies and environments through API endpoints, reducing manual effort and ensuring consistent configurations.

## Key points

- Tenant admins can list feature switches, read a single switch's state, and activate or deactivate a switch through the new automation API
- The endpoint is under the automation v2.0 API, needs the company parameter, and single features are addressed by their ID in quotes; batch requests are not possible
- Activate and Deactivate are bound actions, and Activate needs the updateInBackground and startDateTime parameters
- Running an action on a feature already in that state returns an error
- If a permission error appears, add the FEATURE MGT. - ADMIN permission set to the app in the Microsoft Entra Application Card

## Quotes

- "Tenant admins can now control entries on the Feature Management page using an API." (Establishes the core capability enabling programmatic feature management instead of manual configuration)
- "This allows them to automate setting feature switches across multiple companies and/or environments." (Highlights the scalability benefit for organizations managing multiple Business Central instances)
- "Batch processing is not possible." (Important limitation to understand when planning API integration for feature management at scale)
