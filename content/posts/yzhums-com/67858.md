# Business Central 2025 wave 2 (BC27): Add LockTimeoutDuration allow increasing/lowering lock timeout instead of only disabling/enabling it (New Database.LockTimeoutDuration Method)

[Read the post](https://yzhums.com/67858/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-09-26 · 294 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2025 wave 2 (BC27) introduces a new Database.LockTimeoutDuration method that allows developers to adjust lock timeout duration in seconds rather than simply enabling or disabling it, useful for long-running processes that need flexible timeout control.

## Key points

- New Database.LockTimeoutDuration method gets or sets lock timeout duration in seconds instead of just toggling on/off
- Setting a lock timeout of 0 or less disables the lock timeout
- Designed for long-running processes like overnight batch jobs that need timeout flexibility
- Requires runtime version 16.0 or greater, not available in version 15.0
- Method can be invoked without specifying the data type name
