# Dynamics 365 Business Central: Copy Comments from Vendor to Purchase Document – Customization

[Read the post](https://yzhums.com/70840/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-02-26 · 630 words · tier community · **unreviewed** (model text not yet checked)

> This post explains how to customize Business Central to automatically copy comments from vendor cards to purchase orders. The standard system transfers comments within document types but lacks a feature to pull vendor comments into new purchase documents, requiring a table extension and trigger logic to implement this capability.

## Key points

- Standard Business Central transfers comments between related documents of the same type (e.g., purchase order to purchase receipt) but does not automatically copy comments from vendor cards to purchase orders.
- Comments are stored in different tables: table 97 for vendor cards and table 43 for purchase documents, requiring custom code to bridge them.
- A table extension adds a toggle setting to Purchases & Payables Setup, and a Purchase Header extension uses OnAfterValidate and OnAfterInsert triggers to copy vendor comments when a vendor is selected.
- The customization checks both triggers because vendor number is not a primary key and documents can be created without it.
- The solution queries the Comment Line table for vendor records and inserts matching entries into the Purch. Comment Line table.

## Quotes

- "Comments on ongoing documents are transferred to the related posted document." (Explains the standard behavior that automatically passes comments between document types, which the customization builds upon.)
- "As of now, this function is not included in the standard features... So we can only customize it." (Clarifies that copying vendor comments to purchase orders requires custom development rather than relying on built-in functionality.)
