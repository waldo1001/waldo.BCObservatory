# Dynamics 365 Business Central: How to set Company Badge (System Indicator) via AL Code – Automatically set Company Badge

[Read the post](https://yzhums.com/72250/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-04-16 · 471 words · tier community · reviewed (checked by Opus)

> This post explains how to set company badges (system indicators) automatically via AL code using the UI Helper Triggers codeunit event subscriber, without modifying the Company Information table. Company badges help users identify which company and environment they are working in.

## Key points

- Use codeunit 2000000004 'UI Helper Triggers' and subscribe to the GetSystemIndicator business event to set company badges programmatically
- Set badge text and style using the Style Option, which includes 10 predefined color options from Standard to Bright Purple
- Apply different badges based on company name or other logic using case statements in the event handler
- Round badges indicate production environments while square badges indicate sandbox environments
- Browser refresh (Ctrl+F5) updates the badge display in the client
