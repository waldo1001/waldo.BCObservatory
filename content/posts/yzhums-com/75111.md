# Dynamics 365 Business Central: How to navigate directly from the BC admin center to the Power Platform admin center

[Read the post](https://yzhums.com/75111/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-08-05 · 224 words · tier community · reviewed (checked by Opus)

> Administrators can navigate directly from the Business Central admin center to the Power Platform admin center by selecting an environment, then choosing Support and New Support Request. This access is useful for managing Copilot credits, viewing known issues, and administering Power Platform resources linked to Business Central.

## Key points

- Direct navigation path: BC admin center > select environment > Support > New Support Request opens Power Platform admin center
- Power Platform admin center manages environments and settings for Power Apps, Power Automate, Power Pages, Microsoft Copilot Studio, and Dynamics 365 apps
- Useful for checking BC known issues and managing Copilot Credits and usage when using BC Agent features
- Alternative access methods include direct URL, Microsoft 365 admin center, or via individual Power apps

## Quotes

- "if customers use the BC Agent features, they need to manage Copilot Credits/Usage." (Identifies a key use case for accessing Power Platform admin center from BC when using agent capabilities)
