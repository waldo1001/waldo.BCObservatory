# Business Central 2026 release wave 1 (BC28): Audit user and group permissions across apps (new Permissions Overview page)

[Read the post](https://yzhums.com/71200/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-03-06 · 352 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2026 release wave 1 introduces a new Permissions Overview page that provides centralized visibility into permission sets across all installed apps and extensions. This feature helps administrators audit user and group permissions, analyze permission dependencies, and manage access control more efficiently.

## Key points

- The Permissions Overview page displays permission sets from Microsoft, ISV applications, and user-defined sets in a single unified view
- Administrators can filter permissions by object, scope, extension, or permission set to quickly locate specific access rules
- The page shows which permission sets grant access to specific objects and which security groups and users are assigned to each set
- This centralized approach simplifies security audits, permission dependency analysis, and troubleshooting access issues
