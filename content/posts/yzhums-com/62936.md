# Dynamics 365 Business Central: How to show more than 999+ in Cue on Role Centers (Show actual numbers instead of 999+)

[Read the post](https://yzhums.com/62936/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-07-09 · 527 words · tier community · **unreviewed** (model text not yet checked)

> Cues on Business Central Role Centers display 999+ when values exceed 999 instead of showing actual numbers. This post explains a workaround by using a Decimal data type field instead of Integer, which displays the full value without the limit.

## Key points

- Integer data type fields in Cues cap display at 999 and show 999+ for larger values
- Decimal data type fields display actual amounts without this limitation
- Implementation requires adding a Decimal variable to the page and assigning the FlowField value to it
- The OnDrillDown trigger must be set to make the Cue interactive and clickable
- DecimalPlaces property with 0:0 format prevents decimal point display while using Decimal type
