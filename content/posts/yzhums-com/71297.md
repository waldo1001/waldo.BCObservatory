# Business Central 2026 release wave 1 (BC28): Set default language for documents on the company level (Default Language Code)

[Read the post](https://yzhums.com/71297/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-03-11 · 401 words · tier community · reviewed (checked by Opus)

> Business Central 2026 wave 1 introduces a company-level default language code for customer-facing documents. This feature allows organizations to define a default language for documents like invoices and sales orders, ensuring multilingual teams send documents consistently in the customer's expected language regardless of the user's UI language settings.

## Key points

- New Default Language Code field in Company Information sets a company-wide language for documents
- Documents use the company default language instead of the user's language setting
- Improves clarity and reduces confusion for customers in multilingual scenarios
- Complements existing Language Code in master data and Region property from BC22

## Quotes

- "Local customers will consistently receive invoices and other sales documents in the expected language, regardless of the user's UI language." (This explains the core benefit: ensures consistent document language for multilingual organizations without relying on user settings)
- "This improves clarity, reduces confusion, and ensures a better customer experience, especially in multilingual teams." (Highlights the business value and the scenario where this feature is most useful)
