# Dynamics 365 Business Central: Automatically create Lot/Serial No. Information card on posting (No customization)

[Read the post](https://yzhums.com/67269/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-11-05 · 383 words · tier community · reviewed (checked by Opus)

> Dynamics 365 Business Central can automatically create Lot and Serial Number Information cards during purchase order posting without customization. This feature uses Item Tracking Code options to generate missing cards when inbound transactions are posted, simplifying item tracking workflows for companies that need to track items from entry.

## Key points

- Item Tracking Code has two standard options: Create SN Info. on posting and Create Lot No. Info. on posting
- Serial or lot numbers can be assigned automatically using predefined number series or custom number series, or manually by entering vendor numbers
- Information cards are automatically created during document posting if they don't already exist
- No customization required; this functionality is available as a standard feature
