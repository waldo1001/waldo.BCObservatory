# Dynamics 365 Business Central: Automatically enable Allow HttpClient Requests after custom extension/app installation

[Read the post](https://yzhums.com/65533/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-06-26 · 425 words · tier community · **unreviewed** (model text not yet checked)

> This post explains how to automatically enable the Allow HttpClient Requests setting for custom extensions during installation using an install codeunit, avoiding the need for manual configuration in each environment.

## Key points

- HttpClient requests to external services require explicit Allow HttpClient Requests permission in extension settings
- Without this setting enabled, outbound HTTP calls fail and users see blocking dialogs during initial requests
- An install codeunit can automatically enable this setting by modifying the NAV App Setting table during extension installation
- Using an install trigger eliminates manual configuration steps in each Business Central environment
