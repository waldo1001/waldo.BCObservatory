# Dynamics 365 Business Central: Automatically enable Allow HttpClient Requests after custom extension/app installation

[Read the post](https://yzhums.com/65533/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-06-26 · 425 words · tier community · reviewed (checked by Opus)

> This post explains how to automatically enable the Allow HttpClient Requests setting for custom extensions during installation using an install codeunit, avoiding the need for manual configuration in each environment.

## Key points

- Apps calling external services through HttpClient need Allow HttpClient Requests enabled in Extension Settings, per app including library apps
- If the setting is off, calls can fail in the platform and users get a prompt asking whether to allow the request
- Choosing Allow Always enables the option, but that has to happen manually in every environment
- The setting lives in system table NAV App Setting, so an install codeunit can read the current module info and set the flag on install
