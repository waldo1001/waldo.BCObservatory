# Dynamics 365 Business Central: How to clear all Customized Pages for a Profile (Role)

[Read the post](https://yzhums.com/75960/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-11-25 · 494 words · tier community · **unreviewed** (model text not yet checked)

> Administrators can clear all customized pages for a Business Central profile to return it to its original state, or selectively manage individual page customizations through the Customized Pages interface. This differs from user personalization, which individual users apply to their own workspaces.

## Key points

- The 'Clear customized pages' action removes all page customizations for a selected profile at once
- The 'Manage customized pages' option lets administrators review and delete customizations for specific pages individually
- Profile customizations apply to all users assigned to that profile and can include hidden, moved, or added fields and actions
- Profile customizations are distinct from user personalization; clearing profile customizations won't affect individual user settings

## Quotes

- "Profile customization is configured by an administrator for a profile (role), while personalization is made by individual users for their own workspace." (Clarifies the fundamental distinction between administrator-managed profile customizations and user-driven personalization, essential for understanding customization scope.)
