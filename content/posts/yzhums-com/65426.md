# Dynamics 365 Business Central: How to bulk import big/large text (length exceeds 250 and 2048) from external files via AL

[Read the post](https://yzhums.com/65426/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-06-24 · 920 words · tier community · reviewed (checked by Opus)

> This post explains how to bulk import text longer than 250 or 2048 characters from external files into Business Central using XMLPort objects instead of Excel Buffer or CSV Buffer, which have length limitations. It demonstrates the solution with a practical example of importing rich text into a customer table.

## Key points

- Excel Buffer and CSV Buffer imports cut field values at 250 characters, while Text fields allow 2048 and Blob fields can hold longer text
- An XMLport with a temporary Integer tableelement and textelements can import long values; the long textelement needs TextType set to BigText to go beyond 2048
- In OnBeforeInsertRecord the code writes the value into the target Blob via OutStream, then calls currXMLport.Skip since nothing is inserted into Integer
- From BC24, Configuration Packages can also import Blob fields, but only for tables that are not system tables
