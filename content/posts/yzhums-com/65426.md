# Dynamics 365 Business Central: How to bulk import big/large text (length exceeds 250 and 2048) from external files via AL

[Read the post](https://yzhums.com/65426/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-06-24 · 920 words · tier community · **unreviewed** (model text not yet checked)

> This post explains how to bulk import text longer than 250 or 2048 characters from external files into Business Central using XMLPort objects instead of Excel Buffer or CSV Buffer, which have length limitations. It demonstrates the solution with a practical example of importing rich text into a customer table.

## Key points

- Excel Buffer and CSV Buffer cannot import text fields exceeding 250 characters, even though the system supports up to 2048 characters for Text fields and unlimited for Blob fields
- XMLPort with TextType property set to BigText allows importing large text and Blob fields that exceed standard length limits
- The solution involves creating a temporary table element in the XMLPort and handling the Blob field conversion using OutStream in the OnBeforeInsertRecord trigger
- Configuration Packages in Business Central 2024 wave 1 also support Blob type field imports, though direct system table modification is not recommended
