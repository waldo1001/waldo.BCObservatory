# Dynamics 365 Business Central: How to use Custom Translator (D365 Translation Service support ends)

[Read the post](https://yzhums.com/64982/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-07-25 · 1414 words · tier community · **unreviewed** (model text not yet checked)

> Microsoft is deprecating Dynamics 365 Translation Service as of October 15, 2025, and recommends migrating to Azure AI Custom Translator. This post provides a step-by-step guide to set up Custom Translator for translating Business Central solutions, including resource creation, workspace setup, model training, and API usage examples.

## Key points

- Dynamics 365 Translation Service reaches end-of-support on October 15, 2025 and will no longer be available
- Custom Translator is an Azure AI service that builds customized neural machine translation systems for enterprises and ISVs
- Setup requires an Azure subscription, Translator resource creation, workspace and project configuration in the Custom Translator portal
- Training models requires uploading dictionary, translation memory, or training documents in supported formats like XLF files
- Text translation can be done via the Translator Text API v3 with a category ID, or using the free DocumentTranslator Windows app
