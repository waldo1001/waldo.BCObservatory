# Dynamics 365 Business Central: How to change Zero (0) of Flowfield field to Dash (-) on the page

[Read the post](https://yzhums.com/65156/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-06-12 · 310 words · tier community · reviewed (checked by Opus)

> FlowField values can display a dash instead of zero using the BlankZero property on page fields, which works for both standard and custom fields but not editable fields.

## Key points

- FlowFields calculate and display results based on CalcFormula, such as inventory sums from ledger entries
- The BlankZero property set to true hides zero values and displays them as blank or dash on pages
- This formatting approach applies to custom fields and methods returning numbers, but does not work for editable fields
- AutoFormatExpression and AutoFormatType properties control the underlying zero format behavior

## Quotes

- "FlowFields display the result of the calculation described in the CalcFormula Property." (Explains the core purpose of FlowFields in calculating and displaying derived values from base tables)
- "Just use the BlankZero Property." (Provides the simple solution for replacing zero display with dash or blank on pages)
- "This does not work for editable fields." (Important limitation that prevents users from applying this approach to all field types)
