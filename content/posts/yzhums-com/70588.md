## Key points

- Namespaces organize code into logical groups and prevent naming conflicts
- The AllObjWithCaption virtual table (2000000058) displays AL Namespace information for all objects
- Create a list page based on AllObjWithCaption to access analysis mode features
- Use analysis mode to group namespaces and export data to Excel
