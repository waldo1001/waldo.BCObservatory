> Business Central 2026 wave 1 (BC28) introduces visual avatars in list pages to display which user or agent created or modified records, eliminating the need for customization to show creator and modifier identity information.

## Key points

- Avatars appear in list view layouts without requiring page customization, indicating record creators and modifiers
- Feature supports named users, system users, and AI agents following BC's existing identity model
- Hovering over avatars shows tooltip with full display name and record timestamp
- Users can toggle the Created/Updated by column on or off via view layout options
- Benefits teams working with shared data by reducing verification time for ownership and responsibility
