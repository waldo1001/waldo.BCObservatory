# Dynamics 365 Business Central: How to flow/pass custom field values from Sales Order to Production Order

[Read the post](https://yzhums.com/74172/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-06-25 · 723 words · tier community · **unreviewed** (model text not yet checked)

> This post explains how to pass custom field values from Sales Orders to Production Orders using event subscribers in Codeunit 99000792. It demonstrates two events for header-to-header and line-to-line field mapping with complete AL code examples including table and page extensions.

## Key points

- Use event OnAfterCreateProdOrderFromSalesLine to pass values from Sales Header to Production Order header
- Use event OnCreateProductionOrderOnBeforeProdOrderLineModify to pass values from Sales Line to Production Order Line
- Extend both source (Sales Header/Line) and target (Production Order/Line) tables to add custom fields
- Subscribe to standard events without modifying core codeunit logic
