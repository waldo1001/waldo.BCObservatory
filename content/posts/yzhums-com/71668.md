# Business Central 2026 release wave 1 (BC28): Copy Existing Locations to Create New Locations (Copy Location)

[Read the post](https://yzhums.com/71668/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-03-25 · 332 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2026 release wave 1 introduces a Copy Location feature that allows users to quickly duplicate existing location records to create new warehouse locations, eliminating the need for manual entry or Configuration Packages.

## Key points

- Copy Location is a new action available on the Locations list and Location Card pages in BC28
- Users can select an existing location and copy it to create a new location with customizable fields
- This feature simplifies location setup compared to traditional manual data entry or Configuration Package methods
- The capability mirrors the existing Copy Item feature and could expand to other master data types

## Quotes

- "Traditionally, creating multiple locations required manual entry or Configuration Packages. But with this wave (BC28), it's as simple as clicking a button." (Demonstrates the efficiency improvement the Copy Location feature provides over previous setup methods)
- "Hopefully, Microsoft expands this 'Copy' capability across all master data - it would save so much setup time!" (Indicates the broader value and future potential of this copying pattern for other Business Central setup tasks)
