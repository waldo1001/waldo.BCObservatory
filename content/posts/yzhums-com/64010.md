[Read the post](https://yzhums.com/64010/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-05-12 · 242 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2025 wave 2 introduces two new Visual Studio Code themes (Business Central Light and Business Central Dark) featuring the teal brand color. These themes are included in the AL extension package and can be installed from the pre-release version.

## Key points

- Two new VS Code themes introduced: Business Central Light and Business Central Dark with teal coloring
- Themes are included in the AL .vsix package and accessible via a new Set Color Theme button
- Available through pre-release version of AL language extension starting from BC22
- Users can further customize theme colors in VS Code user interface settings
