# Business Central 2026 release wave 2 (BC29): Report layout subtype on Word layouts

[Read the post](https://yzhums.com/76205/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-09-18 · 424 words · tier community · **unreviewed** (model text not yet checked)

> Word layout report design in Business Central 2026 wave 2 introduces a new Subtype property that allows layouts to be specified as Default, HeaderFooter, Theme, or Body. This enables creation of composite layouts where body layouts reference separate header/footer and theme parts, improving flexibility in report formatting and branding.

## Key points

- Subtype property on Word layouts supports four values: Default, HeaderFooter, Theme, and Body
- Theme layouts must use dotx file extension, while Default and Body use docx files
- Body layouts enable composite designs by referencing separate HeaderFooter and Theme parts
- New Manage themes and header-footer layouts page displays layouts with HeaderFooter and Theme subtypes
