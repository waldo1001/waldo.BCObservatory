# Business Central 2026 release wave 1 (BC28.1): Create new Purchase Invoice from PDF (Out-of-the-Box)

[Read the post](https://yzhums.com/72842/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-05-13 · 426 words · tier community · reviewed (checked by Opus)

> In BC28.1 (2026 wave 1) the Payables Agent can create purchase invoices from a PDF that users upload with New from PDF on the Purchase Invoices page, so the process no longer depends only on emailed invoices. The agent identifies the vendor and builds a draft with reasoning tips for review. The invoice is created after the user confirms. It stops if the vendor cannot be identified.

## Key points

- Purchase invoices can now be created manually from PDF files via a new 'New from PDF' button on the Purchase Invoices page, complementing the existing email-based Payables Agent workflow
- The Payables Agent analyzes PDF documents, identifies the vendor, and generates a draft with suggested field values and explanations of its reasoning
- Users review the draft, confirm details section by section, and can adjust values before finalizing the purchase invoice creation
- This feature consumes Copilot credits (65 credits in the test example) and automatically enables the Payables Agent

## Quotes

- "We can now manually upload a PDF to create a Purchase Invoice." (This is the core capability addition that eliminates dependency on email-triggered workflows for vendor invoice processing)
