# Business Central 2025 wave 2 (BC27): UpdateAuditFields Method on DataTransfer is now in Cloud scope

[Read the post](https://yzhums.com/67809/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-09-24 · 430 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2025 wave 2 (BC27) now makes the UpdateAuditFields method on DataTransfer available in Cloud scope, allowing developers to control audit field updates when transferring data between tables during upgrades and installations.

## Key points

- UpdateAuditFields method on DataTransfer was previously OnPrem-only, now available in Cloud scope in BC27
- DataTransfer is a language construct for fast upgrade code that moves or copies field data between tables
- Audit fields (SystemCreatedAt, SystemCreatedBy, SystemModifiedAt, SystemModifiedBy) track record creation and modification
- UpdateAuditFields method controls whether audit fields are updated when copying data; defaults to true

## Quotes

- "UpdateAuditFields Method on DataTransfer is now in Cloud scope." (This removes a previous restriction that limited the method to on-premises development, enabling more flexible cloud-based upgrade scenarios.)
- "developers can write faster upgrade code when they want to move a field (with data) from one table to another" (DataTransfer provides a performance advantage for migration scenarios compared to traditional methods.)
