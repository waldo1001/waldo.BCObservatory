# Dynamics 365 Business Central: Analyzing performance issues using the page inspector

[Read the post](https://yzhums.com/70070/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-01-20 · 377 words · tier community · **unreviewed** (model text not yet checked)

> The page inspector in Business Central helps diagnose performance issues by displaying details about page design, elements, and data sources. It particularly shows which extensions affect a page and how long they take to execute, accessible via Help & Support or Ctrl+Alt+F1.

## Key points

- Page inspector reveals page design, elements, and data sources behind pages
- Extensions tab shows installed extensions affecting the page with execution time in milliseconds and event subscriber counts
- Four extension types are categorized: adds page, extends page, adds table, extends table
- Performance information displays execution time and number of event subscribers per extension

## Quotes

- "If a specific page takes too long to load, it might be due to extensions that are adding expensive operations to the page triggers." (Identifies the common cause of performance issues that page inspector can help diagnose)
