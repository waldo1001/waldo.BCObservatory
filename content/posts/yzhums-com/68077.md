# Business Central 2025 wave 2 (BC27): Support for new ExtendedDataType value: Document (display/preview a PDF as a portrait image in FactBox)

[Read the post](https://yzhums.com/68077/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-10-09 · 1036 words · tier community · reviewed (checked by Opus)

> Business Central 2025 wave 2 introduces a new ExtendedDataType value called Document for Media and MediaSet fields, enabling portrait-oriented content like PDFs to be displayed in FactBoxes on ListPart and CardPart pages. The feature requires image conversion and currently supports only the first page of multi-page PDFs due to a bug.

## Key points

- Document ExtendedDataType value supports Media and MediaSet fields on ListPart and CardPart page types only
- PDFs must be converted to images before storage, using codeunit 3110 PDF Document for conversion
- Current limitation restricts display to the first page of multi-page PDFs (bug under Microsoft review)
- Media data type provides better performance than BLOB for caching and rendering in the UI

## Quotes

- "Using the Media or MediaSet data type provides better performance than using a BLOB data type and is more flexible in its design" (Justifies when to use Media over BLOB for storing and displaying content)
