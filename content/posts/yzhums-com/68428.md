# Dynamics 365 Business Central: Check posting date before posting (preview posting) in the sales and purchase documents – Customization

[Read the post](https://yzhums.com/68428/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-10-17 · 502 words · tier community · **unreviewed** (model text not yet checked)

> This customization adds a validation to check if the posting date on sales and purchase documents matches the current month, displaying a confirmation dialog if it does not. It uses event subscribers on the Sales-Post and Purch.-Post codeunits to enforce this check before posting.

## Key points

- Event subscribers are used on codeunits 81 (Sales-Post) and 91 (Purch.-Post) to intercept posting operations
- The customization checks if the posting date falls within the current month using CalcDate function
- Both regular posting and preview posting scenarios are covered with appropriate events
- A confirmation dialog prompts the user to proceed if the posting date is outside the current month
- This approach can be extended to add other custom validations like required field checks

## Quotes

- "This is just a simple example, you can also use the same method to add other controls, such as required fields, etc." (Demonstrates that this event subscriber pattern is reusable for implementing additional business rule validations)
