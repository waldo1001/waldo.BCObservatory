# Business Central 2026 release wave 2 (BC29.1): Cross-environment Master Data Management

[Read the post](https://yzhums.com/77263/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-11-11 · 917 words · tier community · reviewed (checked by Opus)

> BC29.1 (2026 release wave 2) extends the existing master data management feature with a Cross-environment setup action. It lets a company sync master data such as customers, vendors and products from a company in another Business Central environment. The connection uses OAuth through a single-tenant Microsoft Entra app, so both environments must be in the same tenant, and both must approve the cross-environment privacy notice.

## Key points

- Builds on master data management from BC22 (log review, choosing tables and fields with filters, job queue pull of changes) by adding a wizard to connect to a company in a different environment.
- Setup: register a single-tenant Entra app with API.ReadWrite.All, add the OAuthLanding.htm redirect URI, create a client secret, then add the app on the source environment's Microsoft Entra Applications page with the MDM CROSS-ENV READ permission set.
- The cross-environment privacy notice must be approved in both environments. The wizard then lets you test the connection and start the initial synchronization.
- Common errors: HTTP 401 means the permission set or privacy approval is missing, a separate message flags an unapproved notice on the source, and HTTP 404 means the source is older than version 29.1.

## Quotes
