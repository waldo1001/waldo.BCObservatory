[Read the post](https://yzhums.com/76696/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-10-15 · 1127 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2026 wave 2 introduces new design components in the Word add-in for document reporting, allowing developers to create report layouts faster by inserting pre-built elements like addresses, field groups, amounts, signature lines, and notes with single clicks instead of manually building complex layouts.

## Key points

- Microsoft added design controls for common document report parts including addresses, field groups, amounts, signature lines, and notes
- Design components can be inserted with single clicks, dramatically faster than building layouts manually or with RDLC
- Word add-in version 3.0.0.0 is the latest version and should be installed from the Add-ins menu
- Pre-built components arrive with example figures and layouts that developers can customize by replacing with actual data fields
- New components include options like sender/receiver addresses, document information grids, calculation tables, and totals rows
