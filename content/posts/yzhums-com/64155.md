# Dynamics 365 Business Central: Overview of all available action (button) icons/images

[Read the post](https://yzhums.com/64155/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-05-19 · 390 words · tier community · reviewed (checked by Opus)

> The post explains how to find and use action (button) icons from the Dynamics 365 Business Central Action icon library. It covers three methods to access icons: the web-based icon library at aka.ms/bcicons, the AZ AL Dev Tools VS Code extension, and Ctrl+Space IntelliSense in Visual Studio Code.

## Key points

- Business Central includes a built-in Action icon library with images sized 16x16 pixels by default, or 32x32 pixels for promoted actions
- Icons are added to actions using the Image property in AL code
- Three main ways to find icons: web library at aka.ms/bcicons, AZ AL Dev Tools VS Code extension with filtering, or Ctrl+Space IntelliSense
- If the Image property is not set, no icon will display on the action
- Legacy methods for NAV include the Dynamics NAV Image Library tool and direct image downloads

## Quotes

- "Business Central includes images that you can use on actions in command bar menus and promoted actions on the ribbon." (Clarifies that Business Central provides built-in icons developers can leverage for UI elements)
- "If you forget to set Image property, no icon will be displayed." (Important reminder that the Image property is required to show icons on actions)
