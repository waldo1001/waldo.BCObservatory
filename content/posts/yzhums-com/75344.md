> Reference guide listing standard abbreviations for Dynamics 365 Business Central object types, word abbreviations used in naming conventions, and financial/time period abbreviations. Useful when developing or documenting AL code to follow Microsoft naming conventions.

## Key points

- Object types have abbreviations like Page, Codeunit, Table, Query, and Report for file naming
- Common words in Dynamics 365 have standardized short forms such as Cust for customer, Inv for invoice, and Whse for warehouse
- Financial metrics and time periods use abbreviations like YTD (Year to Date), PY (Previous Year), and FY (Fiscal Year)
- Following these conventions ensures consistency across development and documentation in Business Central
