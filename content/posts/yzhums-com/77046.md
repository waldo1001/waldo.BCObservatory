# Dynamics 365 Business Central: How to easily check users and their licenses (User Details)

[Read the post](https://yzhums.com/77046/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-11-20 · 238 words · tier community · **unreviewed** (model text not yet checked)

> User Details page provides a quick way to view all users and their assigned licenses in Business Central without needing to access the Users in Plans query or create customizations.

## Key points

- Access User Details by opening the Users page and selecting User Identifier Overview
- User Details page displays user name, authentication email, Entra Object ID, and assigned licenses
- Replaces the need to use Users in Plans query or build custom list pages for license tracking
- Provides centralized view of user licensing information in one convenient location
