# Business Central 2026 release wave 2 (BC29.1): Data mirroring to Microsoft Fabric (No APIs or OData Needed)

[Read the post](https://yzhums.com/77184/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-11-12 · 1810 words · tier community · reviewed (checked by Opus)

> Business Central 2026 wave 2 introduces data mirroring to Microsoft Fabric, enabling organizations to synchronize selected companies and tables to OneLake for analytics, reporting, and integration with Power BI and Data Factory. The post provides detailed setup instructions including workspace preparation, service principal configuration, and table selection, along with guidance on troubleshooting and monitoring export status.

## Key points

- Data mirroring replicates Business Central data to Microsoft Fabric's OneLake in Delta Parquet format without requiring APIs or OData
- Setup requires creating an open-mirrored database in Fabric and configuring either a custom app registration or using the Microsoft Business Central Fabric Export application
- Administrators must add companies and tables to synchronize, then start continuous exports which run asynchronously with configurable intervals
- Synchronized data becomes available for analytics experiences including Fabric IQ, Power BI, Data Factory, and other Fabric tools
- Initial exports take approximately two hours for standard databases, with subsequent exports completing in around 20 minutes
