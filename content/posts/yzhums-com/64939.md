> June 2025 cumulative updates released for Business Central across multiple versions (BC26 CU02, BC25 CU08, BC24 CU14). Includes platform and application build numbers for both cloud SaaS and on-premises deployments, plus lifecycle information showing support dates for versions from 2019 through 2025 release waves.

## Key points

- BC26 CU02 released with platform 26.0.34852.0 and application 26.2.34746.34995 for cloud; separate builds for on-premises
- BC25 introduces flexible environment management with 5-month windows for major updates instead of 30-60 days, and optional minor updates
- Multiple versions supported simultaneously: BC26, BC25, BC24 actively receiving updates; BC23 and earlier marked end-of-life or end-of-support
- On-premises follows Modern Lifecycle Policy with version 26.x supported until October 2026; Fixed Lifecycle Policy applies to older versions through October 2025
