# Dynamics 365 Business Central: How to specify the No. Series when creating a Sales Order (Make Order) from Sales Quote – Customization

[Read the post](https://yzhums.com/62368/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-05-27 · 869 words · tier community · **unreviewed** (model text not yet checked)

> This post explains how to customize the Make Order process to specify the number series when converting a sales quote to a sales order, since the standard process automatically uses default numbering without allowing manual selection.

## Key points

- Sales orders created from quotes normally use automatic numbering from the default no. series, but the Make Order action does not offer a choice of series like manual order creation does.
- The default no. series must have Default Nos. enabled or an error prevents automatic order creation from quotes.
- Customization uses the OnCreateSalesHeaderOnBeforeSalesOrderLineLockTable event in codeunit 86 Sales-Quote to Order to manipulate the order number.
- The standard No. Series codeunit offers LookupRelatedNoSeries function to open a selection dialog and GetNextNo to retrieve the next number, enabling manual series selection during conversion.
- Using OnBeforeInsertSalesOrderHeader event causes transaction lock errors due to Form.RunModal restrictions, so OnCreateSalesHeaderOnBeforeSalesOrderLineLockTable is the correct approach.
