# Dynamics 365 Business Central: How to calculate the total (sum) of a column in a table (Four ways)

[Read the post](https://yzhums.com/61561/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-05-30 · 1561 words · tier community · **unreviewed** (model text not yet checked)

> The post explains four methods to calculate column totals in Business Central: using AL loops (for, foreach, while, repeat-until), the Record.CalcSums method, Query objects with aggregation, and FlowFields. Each approach has different use cases and performance characteristics for developers calculating sums of data.

## Key points

- AL loops are the most universal approach but least efficient; repeat-until is simple for basic summation
- CalcSums method works with SumIndexFields in keys for efficiency but does not support FlowFields
- Query objects with Sum method property are recommended for frequent calculations and can group data by date components
- FlowFields automatically calculate totals on pages without additional code logic using CalcFormula properties

## Quotes

- "The CalcSums function is used to calculate a total for a specific field, based on the filters of the dataset." (Explains the core purpose and mechanism of the CalcSums method, the most efficient approach for total calculations)
- "This is very useful for displaying totals on a page, as there is no need to add additional logic, just the properties." (Highlights the key advantage of FlowFields: automatic calculation without code, reducing development effort)
- "If frequent calculations are required, this method is recommended." (Identifies when Query objects should be used, guiding developers to choose the right approach for their scenario)
