# Dynamics 365 Business Central Blog Series: Work with dimensions

[Read the post](https://yzhums.com/69639/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-12-23 · 930 words · tier community · **unreviewed** (model text not yet checked)

> This blog series covers dimensions in Dynamics 365 Business Central, including how to add shortcut dimensions and custom dimensions to pages, set up default dimensions at various levels, manage dimension priorities, use dimensions in financial reporting, and leverage dimension features across inventory, journals, and locations.

## Key points

- Shortcut dimensions (3-8) can be added to pages for easier access alongside global dimensions
- Default dimensions can be assigned to multiple records at once and set at account type or location level
- Dimension corrections for general ledger entries and allowed values filtering provide better control and conflict avoidance
- Dimensions are supported in standard APIs and Power Automate workflows
- Dimension combinations can be imported and dimension metadata retrieved via AL code
