# Dynamics 365 Business Central: GitHub Copilot Agent Tools now available in the AL Extension (New AL Tools Available for Agents)

[Read the post](https://yzhums.com/67990/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-09-30 · 273 words · tier community · reviewed (checked by Opus)

> The pre-release AL Language extension now includes GitHub Copilot agent tools, such as al_build, al_download_symbols and al_publish, which let Copilot agent mode automate AL workflows. They appear in the extension's version 17.0 changelog but also work with runtime 16.0. They need VS Code 1.99 or later with agent mode enabled, and they are experimental.

## Key points

- GitHub Copilot agent tools were added to the AL VSIX so agent mode can automate AL development tasks
- Tools shown include al_build, al_download_symbols and al_publish, and each call shows its input and output details
- Listed in the AL extension version 17.0 changelog and tested with pre-release v17.0.1825603; they also work on runtime 16.0
- Agent mode needs VS Code 1.99+, the chat.agent.enabled setting, and Agent selected in the Chat view
- The tools are experimental and may change
