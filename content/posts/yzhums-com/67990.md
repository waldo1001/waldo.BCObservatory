# Dynamics 365 Business Central: GitHub Copilot Agent Tools now available in the AL Extension (New AL Tools Available for Agents)

[Read the post](https://yzhums.com/67990/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-09-30 · 273 words · tier community · **unreviewed** (model text not yet checked)

> Microsoft released GitHub Copilot agent tools for the AL VSIX extension that enable agents to automate and orchestrate AL workflows. These experimental tools including al_build, al_download_symbols, and al_publish are available in Business Central 2026 release wave 1 (version 17.0) and require VS Code 1.99 with agent mode enabled.

## Key points

- New GitHub Copilot agent tools added to AL VSIX for automating AL development workflows
- Tools include al_build, al_download_symbols, and al_publish commands accessible to agents
- Available in Business Central 2026 release wave 1 (version 17.0) and works with runtime 16.0
- Requires VS Code 1.99 or later with agent mode enabled via chat.agent.enabled setting
- Tools are experimental and subject to change in future updates
