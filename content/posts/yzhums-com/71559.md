# Business Central 2026 release wave 1 (BC28): New Early Access Preview Features page (1965, List)

[Read the post](https://yzhums.com/71559/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-03-17 · 348 words · tier community · reviewed (checked by Opus)

> BC28 (2026 release wave 1) adds a new list page, Early Access Preview: New Features (page 1965), which shows some of the new features in the wave with detailed descriptions. From this page users can send feedback on a selected feature, and screenshots, screen recordings and file attachments can now be added. The page also has View Help and Watch Video actions. Optional features are still enabled on the Feature Management page.

## Key points

- New optional features are initially disabled and can be individually enabled by administrators on the Feature Management page
- The Early Access Preview Features page (1965) lists new features for BC28 with detailed descriptions accessible via the Description field
- Users can provide feedback directly from the page with compliments, problem reports, or suggestions, now supporting screenshots, screen recordings, and file attachments
- The page includes View Help and Watch Video actions to assist users until official documentation becomes available
