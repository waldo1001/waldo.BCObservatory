# Dynamics 365 Business Central: Set the Document No. with dynamic dates in Recurring General Journals

[Read the post](https://yzhums.com/66210/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-08-13 · 528 words · tier community · reviewed (checked by Opus)

> Recurring General Journals allow you to set document numbers with dynamic dates using Document Number Formulas with placeholder codes like %1 for day, %3 for month, and %4 for month name. This feature helps manage recurring transactions for expenses such as rent and subscriptions with automatically formatted document identifiers.

## Key points

- Recurring journals use the Posting No. Series field to generate document numbers, not the Document No. field like regular General Journals
- Document Number Formulas support placeholder codes (%1-%5) that automatically insert date components, period information, and accounting period names
- Allocation keys can divide recurring entries among various accounts, and automatic reversal entries can be specified for the day after posting
- This feature works without customization by entering placeholders in the period description, such as 'PAYMENT FOR %4 %1' to display 'PAYMENT FOR JULY 1'

## Quotes

- "A recurring journal is a general journal with specific fields for managing transactions that you often post with few, if any, changes." (Defines the purpose and use case of recurring journals for handling repetitive transactions)
- "You can enter the following placeholder codes for typical values. The values are added automatically when the period description displays." (Explains the core mechanism for implementing dynamic dates in document numbers without customization)
- "Only the Posting No. Series field can be filled in on recurring journals." (Key difference from standard General Journals that clarifies how document numbering works in recurring journals)

## Heads up

- warning: "This is not available in other journals, such as General Journals."
