# Business Central 2025 wave 2 (BC27): RecordRef – Get/Search field by name (New overloads)

[Read the post](https://yzhums.com/67623/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-09-11 · 457 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2025 wave 2 (BC27) adds new overloads to RecordRef Field and FieldExist methods that enable searching for fields by their name instead of field number, simplifying AL code when working with dynamic field references.

## Key points

- New overloads accept Text parameter for field name in RecordRef.Field() and RecordRef.FieldExist() methods
- Replaces previous workaround approach for getting field information by field name
- Requires runtime version 16.0 or greater; not available in version 15.0
- Makes AL code cleaner when you need to access fields dynamically by name rather than field ID

## Quotes

- "New overloads are added to the Field and FieldExist methods, which allows searching for a field by its name." (This is the core feature announcement that directly describes what BC27 adds to simplify field access in AL code.)
- "Microsoft has brought us an easier way. New overloads are added to the Field and FieldExist methods." (Explains this is a quality-of-life improvement that reduces coding complexity when working with dynamic fields.)
- "'Field' is not available in runtime version '15.0'. The supported runtime versions are: '16.0' or greater." (Critical compatibility detail that developers must know to avoid deployment issues when using the new overloads.)
