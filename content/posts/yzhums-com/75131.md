# Dynamics 365 Business Central: Displaying Sales/Purchase Order No. in Item Ledger Entries (Source Order No. and Source Description)

[Read the post](https://yzhums.com/75131/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-08-26 · 358 words · tier community · **unreviewed** (model text not yet checked)

> Business Central now provides Source Order No. and Source Description fields that allow users to display the original sales or purchase order numbers in Item Ledger Entries without custom development. These calculated fields can be added to the Item Ledger Entries page through personalization.

## Key points

- Source Order No. and Source Description are new calculated fields (not physical table fields) that show the original order numbers and customer/vendor names in Item Ledger Entries
- These fields are added via the Personalization feature without requiring custom development
- The page must be reopened after adding the fields to display the populated data
- The fields automatically fetch order numbers from Posted Sales Shipments or Posted Purchase Receipts, and remain blank if no source order exists

## Quotes

- "Microsoft recently introduced two new fields to address this exact issue, Source Order No. and Source Description" (Explains the solution for displaying order numbers in Item Ledger Entries without custom development)
- "These two fields are not actual physical fields stored in the table; rather, they are calculated via standard methods." (Clarifies how the fields work and why the page needs to be reopened to display data)
