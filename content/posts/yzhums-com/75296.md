# Dynamics 365 Business Central: AL Copilot Skills Collection (VS Code extension)

[Read the post](https://yzhums.com/75296/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-08-19 · 280 words · tier community · **unreviewed** (model text not yet checked)

> The AL Copilot Skills Collection is a VS Code extension that installs AI coding assistant skills for Business Central AL development, supporting both GitHub Copilot and Claude. It includes purpose-built skills like a setup table generator that helps developers create tables and pages through conversational AI interactions.

## Key points

- Install multiple AI coding skills for AL development with a single command from the VS Code Marketplace
- Skills deploy to your selected assistant target in the workspace and work with both GitHub Copilot and Claude
- The setup table generator skill allows developers to create new setup tables and pages through conversational interaction
- Works alongside AL Agent Tools to enhance the AL development experience
