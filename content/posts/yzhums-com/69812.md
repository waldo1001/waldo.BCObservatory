# Dynamics 365 Business Central: How to view excel reports (Excel Layout) directly from the web without downloading files (Excel Online)

[Read the post](https://yzhums.com/69812/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-04-27 · 730 words · tier community · reviewed (checked by Opus)

> Reports with Excel layouts can open in Excel for the web instead of downloading, once Use OneDrive for system features is turned on in the OneDrive Setup assisted setup. The file is copied to OneDrive and shown in the browser. The same setting also controls the Open in Excel and Edit in Excel actions on list pages.

## Key points

- Excel layouts are .xlsx based and support formulas, PivotTables and PivotCharts.
- Turning on Use OneDrive for system features copies Excel and Word report output to OneDrive and opens it online.
- Open in Excel on list pages keeps the page filters and works on Windows and macOS.
- Edit in Excel output is capped at 100 columns when OneDrive is used for system features.
- The add-in runs in Excel for the web from a supported browser and in the Windows desktop app, but not on macOS.

## Quotes

- "If your organization has configured OneDrive for system features, the Excel workbook is opened in your browser by using Excel for the web." (Describes the key requirement and outcome for viewing reports directly in the browser without downloads)
- "Business Central automatically limits the exported workbook to 100 columns when OneDrive is configured for system features." (Important constraint to be aware of when working with tables containing many columns in Excel Online)

## Heads up

- warning: "Business Central automatically limits the exported workbook to 100 columns when OneDrive is configured."
