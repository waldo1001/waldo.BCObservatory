# Dynamics 365 Business Central: How to view excel reports (Excel Layout) directly from the web without downloading files (Excel Online)

[Read the post](https://yzhums.com/69812/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-04-27 · 730 words · tier community · **unreviewed** (model text not yet checked)

> Excel layouts in Business Central can be viewed directly in a web browser using Excel Online instead of downloading files, provided OneDrive integration is configured for system features. This approach respects Business Central filters and works across Windows and macOS devices.

## Key points

- Excel layouts are based on Microsoft Excel workbooks and support familiar Excel features like formulas, PivotTables, and PivotCharts
- Enabling 'Use OneDrive for system features' automatically opens Excel and Word reports in online versions instead of downloading them
- Excel for web respects filters from Business Central pages, showing the same filtered rows and columns
- Business Central limits exported workbooks to 100 columns when OneDrive is configured for system features
- Excel Online works on any device with a supported browser, though Excel desktop add-in only works on Windows

## Quotes

- "If your organization has configured OneDrive for system features, the Excel workbook is opened in your browser by using Excel for the web." (Describes the key requirement and outcome for viewing reports directly in the browser without downloads)
- "Business Central automatically limits the exported workbook to 100 columns when OneDrive is configured for system features." (Important constraint to be aware of when working with tables containing many columns in Excel Online)
