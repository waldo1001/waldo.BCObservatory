# Business Central 2026 release wave 1 (BC28.2): Power BI Report Deployments (Centralized Management of Power BI Apps)

[Read the post](https://yzhums.com/72067/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-06-23 · 507 words · tier community · reviewed (checked by Opus)

> Business Central 2026 wave 1 introduces the Power BI Report Deployments page, enabling centralized management and batch deployment of Power BI apps to workspaces without manual installation of each app. This capability streamlines analytics setup for finance, inventory, manufacturing, projects, and other functional areas.

## Key points

- New Power BI Report Deployments page (6347) manages the standard Power BI apps centrally instead of installing each app by hand
- Several reports can be selected and deployed together to a Power BI workspace
- Deployment status starts as Queued, can be refreshed with Reload, and can be opened to see detailed steps
- Failed deployments can be retried from scratch, and the PBIX file can be downloaded for a selected report
- For now the page works only in evaluation companies; deployed apps then show as installed on the Power BI Reports Setup page

## Quotes

- "Deploy Power BI reports to your workspace, update them when new versions are available, and retry deployments that have failed." (This explains the three core capabilities of the new Power BI Report Deployments feature, showing how it simplifies multi-app management.)
- "You can select multiple reports and then choose the Deploy action to deploy them to your Power BI Workspace." (Highlights the batch deployment capability that eliminates the previous need to install each Power BI app manually.)
