# Business Central 2026 release wave 2 (BC29): Access application links (Help, EULA, PrivacyStatement, and ContextSensitiveHelpUrl) through ModuleInfo – New properties on ModuleInfo

[Read the post](https://yzhums.com/75853/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-09-08 · 255 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2026 release wave 2 (BC29) extends ModuleInfo to expose app manifest metadata including Help, EULA, PrivacyStatement, and ContextSensitiveHelpUrl properties. These new properties enable developers to access application links and locale-aware help URLs at runtime.

## Key points

- ModuleInfo now exposes four new properties for accessing app manifest metadata at runtime
- New properties include Help link, EULA link, PrivacyStatement link, and context-sensitive help URL with locale resolution
- Runtime version 18.0 or later is required to use these ModuleInfo properties
- ContextSensitiveHelpUrl automatically resolves the user's locale from the application's supported locales
