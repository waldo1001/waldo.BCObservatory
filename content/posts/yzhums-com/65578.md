# Dynamics 365 Business Central: How to quickly remove white-space characters from the current Text/String (leading, trailing and all) in AL

[Read the post](https://yzhums.com/65578/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-07-04 · 515 words · tier community · **unreviewed** (model text not yet checked)

> This post explains four methods to remove whitespace characters from text strings in AL: TrimStart for leading spaces, TrimEnd for trailing spaces, Trim for both leading and trailing, and DelChr for all whitespace. It includes working code examples showing each method in a test page.

## Key points

- TrimStart() removes only leading whitespace characters
- TrimEnd() removes only trailing whitespace characters
- Trim() removes both leading and trailing whitespace in one call
- DelChr() can remove all whitespace characters from anywhere in the string
- Each method has specific use cases depending on which whitespace needs to be removed
