# Dynamics 365 Business Central: How to substitute a page for another page via AL

[Read the post](https://yzhums.com/61818/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-08-27 · 638 words · tier community · **unreviewed** (model text not yet checked)

> Page substitution in Dynamics 365 Business Central allows developers to redirect users to a different page when opening a standard page using AL code. The post explains techniques such as using the Error method in OnOpenPage trigger and, starting with BC26, extending the CardPageId property for list pages.

## Key points

- Unlike reports, pages lack standard substitution events, requiring custom solutions in OnOpenPage trigger
- Using Error('') after Page.Run() prevents the original page from opening, allowing seamless redirection
- CurrPage.Close() in OnOpenPage does not work reliably and may display blank pages
- Business Central 2025 wave 1 (BC26) introduced CardPageId property extension for easier card page substitution
- For card and document pages in earlier versions, SetRecord and Run methods with Error() provide a workaround

## Quotes

- "Microsoft has not prepared any standard events in advance. So we have to solve this problem in other ways." (Explains why custom solutions are needed instead of relying on built-in page substitution events like those available for reports)
- "Using this method, we can allow users to jump to our customized page when they open the standard page." (Summarizes the practical benefit of the Error method approach for seamless page redirection)
- "Starting with Business Central 2025 wave 1 (BC26), this is no longer a problem, as we can extend the CardPageId Property." (Highlights that BC26 introduced native support for card page substitution, simplifying the solution)
