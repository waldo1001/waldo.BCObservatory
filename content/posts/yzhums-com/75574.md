# Dynamics 365 Business Central: GetLastErrorCode, GetLastErrorText and GetLastErrorCallStack Methods

[Read the post](https://yzhums.com/75574/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-09-03 · 334 words · tier community · reviewed (checked by Opus)

> The post explains three system methods for retrieving error information in Business Central AL code: GetLastErrorCode identifies error classification, GetLastErrorText provides error details, and GetLastErrorCallStack returns the call stack where the error occurred. It helps developers implement error handling and conditional logic based on error details.

## Key points

- GetLastErrorCode retrieves the error classification and is not translated to local language
- GetLastErrorText gets detailed error message and is translated to local language
- GetLastErrorCallStack returns the call stack from where the error occurred, though some error types don't return complete stacks
- These methods work with try functions to add conditional checks for error handling

## Quotes

- "For some errors, such as divide by zero errors and overflow errors, GetLastErrorCallStack does not return every call in the stack." (Developers need to know the limitations of call stack retrieval for certain error types and when to use the debugger instead.)
