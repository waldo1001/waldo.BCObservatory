# Business Central 2025 wave 2 (BC27): Install UK localization as an extension to the base app (UK Delocalization)

[Read the post](https://yzhums.com/69120/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-01-28 · 533 words · tier community · **unreviewed** (model text not yet checked)

> UK localization for Business Central 2025 wave 2 (BC27) is now available as extensions on the W1 base app instead of being built into the core product. This delocalization approach reduces implementation costs, simplifies multi-region operations, and allows ISVs broader market access.

## Key points

- UK localization features are delivered as a set of extensions on the W1 base app starting in BC27
- Delocalization reduces implementation time and costs, particularly for organizations operating in multiple regions
- Includes a data upgrade feature to simplify transition from the previous localized version
- Users can choose to adopt new features during a three-release period before old features are deprecated
- Extensions cover VAT and tax, banking and payments, fixed assets, and general UK-specific functionality

## Quotes

- "Removing country-based customizations from the base app helps organizations save time and reduce costs during implementation." (Explains the core business value of delocalization for cost and time efficiency)
- "After this period, the previous features will be deprecated, and the new localization will automatically be enabled." (Indicates the transition timeline and mandatory adoption plan for the new extension-based model)
