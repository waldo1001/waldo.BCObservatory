# Business Central 2026 release wave 1 (BC28): AL developers can use semantic search on data and metadata

[Read the post](https://yzhums.com/71365/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-03-11 · 330 words · tier community · reviewed (checked by Opus)

> BC28 lets AL developers run semantic similarity searches, such as top n records by similarity to a search term, over data and virtual metadata records. Microsoft's docs call the codeunit Semantic Data Search, but the author found it as codeunit 2000000025 Semantic Search, with the methods SetMaxResults, SetSearchTarget and FindSimilarByField. It is scoped OnPrem, so extensions get error AL0296 and cannot use it in the cloud.

## Key points

- New codeunit 2000000025 enables semantic search on metadata objects and data records with similarity ranking
- Developers can query records using similarity-based syntax like TOP n by similarity to search terms
- Methods include SetMaxResults, SetSearchTarget, and FindSimilarByField for controlling searches
- Currently scoped to OnPrem only, unavailable for cloud extensions due to scope restrictions

## Quotes
