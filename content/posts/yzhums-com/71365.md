# Business Central 2026 release wave 1 (BC28): AL developers can use semantic search on data and metadata

[Read the post](https://yzhums.com/71365/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-03-11 · 330 words · tier community · **unreviewed** (model text not yet checked)

> AL developers in Business Central 2026 release wave 1 can use semantic ranking to search both data and metadata with similarity-based queries through the new Semantic Data Search codeunit. The feature is currently restricted to on-premises environments only.

## Key points

- New codeunit 2000000025 enables semantic search on metadata objects and data records with similarity ranking
- Developers can query records using similarity-based syntax like TOP n by similarity to search terms
- Methods include SetMaxResults, SetSearchTarget, and FindSimilarByField for controlling searches
- Currently scoped to OnPrem only, unavailable for cloud extensions due to scope restrictions

## Quotes

- "The Scope attribute is currently set to OnPrem. This means it cannot be used in the cloud version." (Critical limitation explaining why the feature is unavailable for cloud extension development)
