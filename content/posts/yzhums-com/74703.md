# Business Central 2026 release wave 1 (BC28): Copilot and agent data movement across geographies

[Read the post](https://yzhums.com/74703/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-07-14 · 1167 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2026 wave 1 (BC28) introduces controls for managing Copilot and agent data movement across Azure geographies. Starting July 1, 2026, environments may process AI requests outside their primary data residency region, with consent managed via the Copilot & agent capabilities page.

## Key points

- Copilot requires Azure OpenAI Service which only exists in specific regions, potentially requiring cross-geography data movement
- Admins can control data movement consent on the Copilot & agent capabilities page; disabled consent blocks Copilot availability
- Data stays within primary regions only for US-hosted environments; EU and other regions require cross-geography processing
- Three independent geographic concepts exist: Business Central country/region (localization), Azure data residency (business data location), and Azure OpenAI geography (AI processing location)
- Prompts and outputs may move outside geography to Azure OpenAI endpoints; Microsoft stores data up to 24 hours for abuse monitoring but doesn't use it for model training
