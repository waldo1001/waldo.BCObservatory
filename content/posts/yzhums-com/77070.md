# Business Central 2026 release wave 2 (BC29): Match Production Database Configuration

[Read the post](https://yzhums.com/77070/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-11-04 · 471 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2026 wave 2 (BC29) introduces Match Production Database Configuration, a feature that temporarily aligns a sandbox environment's database settings with production for 72 hours to enable accurate performance testing and support cloud migration processes.

## Key points

- Temporarily matches sandbox database configuration to production for 72 hours, then automatically reverts after the next update window
- Enables more accurate performance testing using the Performance Toolkit by providing the same Azure performance tier as production
- Requires environment restart and should be performed when no users are active
- Feature is available in Admin Center but may still have some readiness issues

## Quotes

- "This action temporarily matches your sandbox environment's database configuration to that of a typical production environment database for 72 hours." (Explains the core functionality that addresses the performance tier difference between sandbox and production environments)
- "Production environments are deployed on dedicated performance tiers in Azure, ensuring a high level of availability and prioritized support." (Clarifies why this feature is needed and the fundamental difference that necessitates matching database configurations for accurate testing)
- "After 72 hours, the environment will automatically be moved back to a sandbox environment database configuration during its next update window." (Important operational detail showing the automatic rollback mechanism that prevents permanent sandbox-to-production conversion)
