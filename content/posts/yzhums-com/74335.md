# Dynamics 365 Business Central: Make the same column editable or non-editable based on different conditions on the list page (Dynamic Editable Control for the Same Column)

[Read the post](https://yzhums.com/74335/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-06-26 · 359 words · tier community · **unreviewed** (model text not yet checked)

> Make a column editable or non-editable on a list page based on row-specific conditions using a Boolean field and the Editable property. This is useful when different rows need different edit permissions without showing error messages.

## Key points

- Use a variable bound to the Editable property to conditionally control field editability
- Update the variable in OnAfterGetRecord to reflect the condition for each row
- Update the variable in OnValidate when the condition field changes
- Fields remain non-editable from the start, no error messages required

## Quotes

- "they want a specific column to be editable only for rows that meet certain conditions, and non-editable for all other rows." (Defines the core requirement for conditional field editability based on row-level conditions)
- "the field should simply be non-editable from the start." (Explains that the solution must prevent editing without triggering validation errors)
- "you just need to control the Editable property using a variable." (Provides the key implementation technique for achieving dynamic editability)
