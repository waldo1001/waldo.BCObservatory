# Dynamics 365 Business Central: Control over adjustment of one item (Adjust Inventory)

[Read the post](https://yzhums.com/70273/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-01-29 · 288 words · tier community · **unreviewed** (model text not yet checked)

> The Adjust Inventory function in Business Central allows quick inventory level changes for individual items. Organizations can control access through the Allow Inventory Adjustment setting on the Inventory Setup page or by restricting permissions via permission sets.

## Key points

- Adjust Inventory is a quick way to increase or decrease stock for one item from the item list or card
- The feature can be disabled globally via the Allow Inventory Adjustment toggle on Inventory Setup
- Permission sets can restrict access to the Adjust Inventory dialog for security control
- When disabled, users cannot see the Adjust Inventory action on pages

## Quotes

- "you can enable or disable the Allow Inventory Adjustment feature directly on the Inventory Setup page" (Shows how to control access to the adjustment feature at the system level)
- "When disabled, users will not be able to see the Adjust Inventory action on the page" (Clarifies the practical impact of disabling the feature on user interface)
