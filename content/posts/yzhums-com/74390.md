# Business Central 2026 release wave 1 (BC28.2): Use new APIs for analyzing approval workflows for auditors and IT staff

[Read the post](https://yzhums.com/74390/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-06-30 · 731 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2026 wave 1 introduces seven new read-only APIs for analyzing approval workflows, enabling auditors and IT staff to build advanced compliance reports in Power BI and intelligent automation with Copilot Studio while maintaining security through isolated API permissions.

## Key points

- Seven new API V2.0 endpoints provide read-only access to workflow approval data including workflows, steps, approvers, and approval entries
- APIs enable secure external auditing and compliance reporting without modifying approval system data
- Organizations can integrate with Power BI, Copilot Studio, and MCP Server for analytics and intelligent automation
- Permission isolation ensures robust security while empowering authorized teams to access and analyze approval workflows
