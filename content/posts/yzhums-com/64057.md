# Business Central 2025 wave 1 (BC26.1): New method to add SecretText values to JSON objects – WriteWithSecretsTo

[Read the post](https://yzhums.com/64057/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-05-13 · 450 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2025 wave 1 (BC26.1) introduces WriteWithSecretsTo, a new method for adding SecretText values to JSON objects. This feature helps developers securely handle credentials and sensitive data by replacing placeholder values in JSON with encrypted secrets before serialization.

## Key points

- WriteWithSecretsTo is a new method on the JsonObject type that adds SecretText values to JSON objects
- Developers create a JSON object with placeholders, define paths in JSONPath format, and use the method to produce a SecretText with credentials replaced
- The feature integrates with the SecretText type introduced in BC23 to protect sensitive values from exposure
- Method requires runtime version 15.1 or greater; not available in 15.0

## Quotes

- "A new method was added to the JsonObject type, which allows developers to add SecretText values." (Introduces the core capability for securely embedding secrets in JSON structures)
