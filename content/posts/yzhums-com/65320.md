# Dynamics 365 Business Central: About the size of the value displayed on the card/document page (textbox too small to read?)

[Read the post](https://yzhums.com/65320/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-07-22 · 962 words · tier community · reviewed (checked by Opus)

> When text fields exceed the display capacity of page textboxes in Business Central, developers can use the MultiLine property, Rich Text feature, FactBox components, or action-triggered dialogs to present the content readably. This matters for fields like Customer Name that can store long values but appear truncated on the web client.

## Key points

- Text fields in Business Central support up to 2048 characters but may appear truncated on small textbox areas in the web client
- The MultiLine property combined with a wrapper group and ShowCaption set to false expands the display area for long text
- Rich Text feature with ExtendedDatatype set to RichContent handles multimedia content and large text blocks effectively
- FactBox components positioned on the right side of pages can display related long-form content without cluttering the main layout
- Developers can trigger full text display through user actions like OnAssistEdit to show content in a dialog without taking up page space

## Quotes

- "The maximum length for a field of type 'Text' is 2048 AL." (Establishes the technical limit for standard text fields, informing the choice of solution (Blob for longer content).)
