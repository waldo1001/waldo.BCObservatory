# Dynamics 365 Business Central: How to easily prevent users from adding or modifying Links and Notes (Making Links and Notes Read-Only)

[Read the post](https://yzhums.com/72087/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-04-14 · 396 words · tier community · **unreviewed** (model text not yet checked)

> Making Links and Notes read-only in Business Central by excluding Insert, Modify, and Delete permissions on the RecordLinks system table prevents users from creating or editing these record annotations while keeping the UI elements visible.

## Key points

- Links and Notes use the RecordLinks system table (2000000068) for data storage
- Excluding Insert, Modify, and Delete permissions on RecordLinks makes Links and Notes read-only
- UI actions remain visible but trigger insufficient permissions errors when users attempt to save changes
- Excluding Read permission entirely hides Links and displays Notes as an empty box

## Quotes

- "If you only allow read-only permissions for users, you just need to exclude the Insert, Modify, and Delete permissions for RecordLinks (2000000068)." (This is the core technique for making Links and Notes read-only without hiding the UI elements)
