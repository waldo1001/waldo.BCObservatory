# Business Central 2026 release wave 1 (BC28): New Method for DataTransfer data type (AddDestinationFilter Method)

[Read the post](https://yzhums.com/71894/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-04-02 · 444 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2026 wave 1 introduces the AddDestinationFilter method for the DataTransfer data type, enabling developers to filter destination tables during bulk data transfers. This enhancement makes DataTransfer more practical for complex upgrade and installation code by allowing filtering on target tables, which was not previously possible.

## Key points

- AddDestinationFilter method allows filtering the destination table during bulk data transfers, complementing the existing AddSourceFilter method
- DataTransfer uses set-based SQL operations instead of row-by-row processing, improving performance during upgrades and installs
- The new method accepts a destination field, filter expression with operators and replacement fields, making complex data migration scenarios more efficient
- Available with runtime version 17.0 in Business Central 2026 wave 1 (BC28)

## Quotes

- "With the latest update, that has finally changed with the introduction of AddDestinationFilter." (Highlights that filtering the destination table, which was impossible up to BC27, is now available in BC28.)
