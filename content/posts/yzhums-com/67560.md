# Business Central 2025 wave 2 (BC27): New values (AsReadOnly & AsReadWrite) for the AllowInCustomizations property

[Read the post](https://yzhums.com/67560/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-09-10 · 615 words · tier community · **unreviewed** (model text not yet checked)

> BC27 introduces new values (AsReadOnly, AsReadWrite) for the AllowInCustomizations property to give AL developers finer control over how table fields can be used in page customizations. This property can now be set at table, table extension, and field levels, with corresponding analyzer rules to support field classification.

## Key points

- AllowInCustomizations property now accepts AsReadOnly (read-only in customizations) and AsReadWrite (editable in customizations) values in addition to Never
- The property can be set at table, table extension, and field levels for more efficient field management
- Default value ToBeClassified and deprecated value Always behave like AsReadOnly
- New analyzer rules AS0138, AS0139, and PTE0026 support field classification but are currently optional

## Quotes

- "AsReadOnly - allows use in page customizations, but only as read-only. AsReadWrite - allows fields to be made editable in page customizations." (These new values provide explicit control over field editability in customizations, replacing the ambiguous Always value)
- "For efficiency, AllowInCustomizations can now also be set at the table and table extension level." (Setting the property at higher levels simplifies field management when the same rule applies to multiple fields)
