# Dynamics 365 Business Central: How to get the Month Name/Text from a date (Two ways)

[Read the post](https://yzhums.com/69978/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-01-16 · 533 words · tier community · reviewed (checked by Opus)

> Shows two ways to get a month name from a date in AL: Format with the Month Text date format (full or three-letter), and reading Period Name from the Date virtual table (ID 2000000007) for the month period. As an extra, the BC25 Date methods return the month number, not the name.

## Key points

- Format(date, 0, '<Month Text>') returns the full month name; adding a length of 3 gives the short name.
- The Date virtual table has the primary key Period Type plus Period Start; getting the Month row at the start of the month returns its Period Name.
- The Date table can be opened in the browser by adding the table=2000000007 URL parameter.
- The BC25 Date methods (for example .Month) give the month number only, which is simplest when the number is enough.

## Quotes

- "The Date virtual table (ID 2000000007) in Business Central gives you easy access to days, weeks, months, quarters, and years." (Explains the core capability of the Date virtual table for date period operations)
- "we can just use Format(Rec."Posting Date", 0, '<Month Text>')." (Shows the simplest Format() syntax for extracting month names from dates)
