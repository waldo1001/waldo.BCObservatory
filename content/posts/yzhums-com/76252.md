# Business Central 2026 release wave 2 (BC29): Check records for uncommitted changes (Added the IsDirty property to the Record API)

[Read the post](https://yzhums.com/76252/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-09-22 · 264 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2026 wave 2 introduces the IsDirty property to the Record API, allowing developers to check whether a record instance has uncommitted changes before performing validation or saving operations. This feature is available in runtime version 18.0 and later.

## Key points

- The IsDirty property returns a boolean indicating whether an in-memory record has different values than its database state
- Developers can use IsDirty to determine if a record has been modified since retrieval or last persistence
- The feature requires runtime version 18.0 or greater and is not available in version 17.0
- This enables conditional logic for validation, saving, and processing based on actual changes

## Quotes

- "Use the Record API IsDirty property to determine whether a record instance contains unsaved changes before deciding to validate, save, or otherwise process it." (This explains the primary purpose and use case for the new feature)
- "Gets a boolean value that indicates whether the current in-memory record instance has different values than when it was loaded from the database." (This clarifies the exact behavior and return value of the IsDirty method)
