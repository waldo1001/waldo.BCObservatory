# Dynamics 365 Business Central: Scheduling Financial Reports via Email (Send Regular Financial Reports to Your Inbox) – No Customization

[Read the post](https://yzhums.com/72470/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-04-24 · 546 words · tier community · reviewed (checked by Opus)

> Business Central 2026 Wave 1 (BC28) introduces scheduled distribution of financial reports via email. Users can set up recurring financial report schedules with multiple recipients, custom filters, and automatic email delivery, eliminating the need for customization.

## Key points

- BC28 adds a Schedules action on the Financial Reports and Financial Report Card pages, opening a Financial Report Schedules page
- A single financial report can have several schedules, each with a code, description, export option such as PDF, and an email send option
- Recipients can be multiple users, but each needs an email address in User Setup or an error appears
- Schedules use a next run date/time and a recurrence formula, with optional custom filters and start/end date filter formulas
- Runs are handled by the Financial Report Export Job in the job queue and output reaches recipients by email and report inbox

## Quotes

- "Historically, Financial Reports in BC has lacked support for scheduling when generating or printing reports. But that has finally changed." (Highlights the significance of this release as addressing a long-standing gap in the product.)
