# Dynamics 365 Business Central: How to quickly jump/navigate to the First or Last row in the list

[Read the post](https://yzhums.com/75322/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-08-18 · 253 words · tier community · reviewed (checked by Opus)

> The post explains how to use keyboard shortcuts to quickly navigate to the first or last row in Business Central lists without customization. Ctrl+Home jumps to the first row and Ctrl+End jumps to the last row, saving time when working with large datasets.

## Key points

- Ctrl+Home and Ctrl+End shortcuts navigate to first and last rows respectively
- On macOS, use Fn+Ctrl+Left arrow for first row and Fn+Ctrl+Right arrow for last row
- These shortcuts work in list views, tile views, and subforms like Sales Order Subform
- No page customization is needed to use these built-in keyboard shortcuts
