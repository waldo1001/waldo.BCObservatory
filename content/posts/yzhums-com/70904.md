# Deprecated features in Business Central 2026 release wave 1 (BC28)

[Read the post](https://yzhums.com/70904/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-03-02 · 972 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2026 release wave 1 (BC28) removes several deprecated features including Excel reports on role centers, API v1.0, legacy Power BI marketplace apps, Intelligent Cloud Insights, and numerous legacy reports across finance, fixed assets, manufacturing, sales, and purchasing. Replacements include enhanced Power BI reports, Excel layouts on ledger tables, and data analysis capabilities.

## Key points

- Excel reports (Balance Sheet, Income Statement, Cash Flow, etc.) are removed from Business Manager and Accountant Role Centers due to difficulty in modifying them requiring AL and VBA skills
- API v1.0 is deprecated in favor of API v2.0 which uses GUID keys, eliminates complex properties, and improves performance
- Legacy Power BI marketplace apps for CRM, Finance, and Sales are replaced by seven new Power BI apps released in version 25.1
- Intelligent Cloud Insights feature is removed and replaced by the new Power BI apps
- Multiple legacy reports (20+ across finance, assets, manufacturing, sales, and purchasing) are removed; users should test new Excel layout and Power BI replacements before upgrading

## Quotes

- "Changing them requires technical skills in AL and VBA (Visual Basic for Applications) programming." (Explains why Microsoft is removing Excel reports - they are difficult for users to modify without developer skills)
- "In API v2.0, all multipart keys and non-GUID keys are replaced with unique GUID keys." (Key technical improvement in v2.0 that improves auditing and API reading performance over v1.0)
- "If you are still using these reports, please test the new version of the report as soon as possible." (Urgent guidance for customers to validate replacement features before the BC28 release)
