# Dynamics 365 Business Central: How to display/add “Sent To” on the Sent Emails (8883, List) page?

[Read the post](https://yzhums.com/72539/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-04-28 · 543 words · tier community · **unreviewed** (model text not yet checked)

> The Sent Emails page in Business Central does not display recipient information by default. This post explains how to add a 'Sent To' field using a page extension that retrieves recipients from the Email Message codeunit by accessing the temporary Sent Email table.

## Key points

- The Sent Emails page (8883) uses a temporary table and does not include the 'Sent To' field
- Table 8889 'Sent Email' has internal access restrictions, but codeunit 8904 'Email Message' provides public methods to retrieve recipients
- A page extension can add a new field that populates recipient data via the GetRecipients method on OnAfterGetRecord trigger
- The solution uses RecordRef and FieldRef to access the MessageId from the temporary table and match it with the email message
