# Business Central 2026 release wave 1 (BC28): Storing Document Attachments outside the database (No customization) – See benefits of external storage support for document attachments

[Read the post](https://yzhums.com/69818/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-04-15 · 2221 words · tier community · reviewed (checked by Opus)

> BC28 introduces external storage support for document attachments, allowing organizations to store attachments in SharePoint, Azure, or SFTP instead of the database. This reduces database capacity usage, improves performance, and provides better cost control and scalability for document-heavy processes without requiring customization.

## Key points

- Attachments can be stored externally in SharePoint, Azure Blob Storage, Azure File Share, or SFTP to reduce database capacity consumption
- Setup requires configuring external file accounts with appropriate authentication credentials and permissions
- The feature includes storage synchronization capabilities to migrate existing attachments and manage external files
- Organizations remain responsible for managing, backing up, and securing externally stored files; Microsoft does not manage them

## Quotes

- "By default, Business Central customers can use up to 80 GB of database storage capacity across all their environments (production and sandbox)." (Establishes the storage constraint that makes external storage necessary for many organizations)
