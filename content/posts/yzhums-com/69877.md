> Page inspection is a diagnostic tool in Dynamics 365 Business Central that enables users and developers to analyze page composition, performance issues, and access control. The post series covers multiple aspects including field highlighting, performance analysis, and controlling visibility of inspection details.

## Key points

- Page inspection allows checking whether a page or report is standard or customized and viewing table field information
- Performance issues can be analyzed using the page inspector to examine page composition and behavior
- Access to page inspection details can be controlled and hidden selectively, including table fields, extensions, and filters
- Field highlighting in page inspection helps quickly locate specific fields on a page
- Page inspection pane is collapsible and shows filter information and text/code field sizes
