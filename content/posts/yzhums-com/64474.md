# Dynamics 365 Business Central: How to check whether the current user has only the Microsoft 365 Plan in AL

[Read the post](https://yzhums.com/64474/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-05-28 · 710 words · tier community · reviewed (checked by Opus)

> Detect whether a Business Central user has only a Microsoft 365 license by querying the Users In Plans table and checking the Plan ID. This helps apply custom logic or UI changes based on license type, useful since Microsoft 365 plan users can access BC in Teams but encounter errors when accessing directly.

## Key points

- Users with only Microsoft 365 licenses can access Business Central through Microsoft Teams but not directly
- Use the Users In Plans query filtered by User Security ID to determine license type
- Check if the user's Plan ID matches the Microsoft 365 Plan ID from the Plan Ids codeunit
- The example page extension demonstrates how to show different messages based on license type
- Licensing is important for cost optimization and data governance in multi-license scenarios
