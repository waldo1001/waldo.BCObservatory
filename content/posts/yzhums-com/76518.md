# Business Central 2026 release wave 2 (BC29): AL developers can turn indexes on/off in AL code

[Read the post](https://yzhums.com/76518/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-10-09 · 513 words · tier community · **unreviewed** (model text not yet checked)

> AL developers can now programmatically enable and disable database indexes in Business Central 2026 wave 2 (BC29), allowing app publishers to manage index performance tuning as part of their feature deployment.

## Key points

- AL developers can now turn database indexes on or off directly from AL code using methods in codeunit 2000000029 'Index Management'.
- Database indexes improve query performance by allowing the system to locate data efficiently instead of scanning all records.
- This capability extends previous index management features introduced in BC20 (Database Wait Statistics) and BC28 (manual index on/off and per-company cost viewing).
- Developers can query field information from table 2000000041 'Field' to target specific indexes for management.
- App publishers can now ship index management as part of their features rather than relying on administrators.
