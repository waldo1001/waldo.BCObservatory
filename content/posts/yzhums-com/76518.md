# Business Central 2026 release wave 2 (BC29): AL developers can turn indexes on/off in AL code

[Read the post](https://yzhums.com/76518/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-10-09 · 513 words · tier community · reviewed (checked by Opus)

> AL developers can now programmatically enable and disable database indexes in Business Central 2026 wave 2 (BC29), allowing app publishers to manage index performance tuning as part of their feature deployment.

## Key points

- In BC29, AL code can turn database indexes on or off, so app publishers can ship index management alongside their features.
- Microsoft updated methods in codeunit 2000000029 Index Management; these match the actions on the Index Management page.
- This builds on BC20 insights into missing indexes and on BC28 per-company index usage, cost viewing and turning indexes off.
- The example turns off an index on table 21 Cust. Ledger Entry, using table 2000000041 Field to identify it.
