# Dynamics 365 Business Central: Convert Word (.docx) To HTML (.html) within BC (No control add-in and APIs)

[Read the post](https://yzhums.com/64042/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-05-14 · 496 words · tier community · reviewed (checked by Opus)

> Converting Word (.docx) files to HTML (.html) format within Business Central using the built-in ConvertWordToHtml procedure from codeunit 9651 without requiring control add-ins or external APIs. The post demonstrates two practical approaches: converting attachments in Document Attachment Details and uploading Word documents for conversion.

## Key points

- Business Central provides a standard method via codeunit 9651 'Document Report Mgt.' with the ConvertWordToHtml procedure
- The conversion can be performed on Word files stored as document attachments or uploaded directly
- Implementation uses TempBlob codeunit to handle file streaming and conversion
- Some Word documents with unsupported package content may fail conversion with a specific error message

## Quotes

- "If you encounter a file that cannot be converted, the following error message will be displayed" (Alerts developers to potential conversion failures with unsupported Word document structures and helps with error handling)
