# Information sharing: SQL Server 2025 is now GA – Business Central to Support it in 2026 Release Wave 1 (BC28)

[Read the post](https://yzhums.com/69079/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-11-20 · 481 words · tier community · reviewed (checked by Opus)

> SQL Server 2025 has reached general availability with expanded resource limits, and Business Central 2026 release wave 1 (BC28) will support it. On-premises Business Central customers can benefit from increased memory capacity in SQL Server Standard Edition for improved query performance.

## Key points

- SQL Server 2025 Standard edition now supports up to 32 cores and 256 GB of memory, compared to previous limits
- Express edition database size limit increased to 50 GB, with Express Advanced consolidated into unified SQL Express
- SQL Server Web edition is being discontinued; SQL Server 2022 is the final Web edition version
- Business Central 2026 release wave 1 (BC28) will support SQL Server 2025 for on-premises deployments

## Quotes

- "Business Central 2026 release wave 1 will of course support running on SQL Server 2025." (Confirms official support timeline for on-premises customers planning infrastructure upgrades)

## Context

- Features: SQL Server 2025 support, increased memory capacity, Standard Edition enhancements, Express Edition improvements
- Versions: 2025 release wave 2, 2026 release wave 1, BC28
