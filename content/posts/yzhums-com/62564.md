# Business Central 2025 wave 1 (BC26.2): Add fields/columns from related tables in analysis mode (No customization)

[Read the post](https://yzhums.com/62564/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-06-09 · 744 words · tier community · reviewed (checked by Opus)

> Business Central 2025 wave 1 (BC26.2) introduces the ability to add fields from related tables directly in analysis mode without customization, enabling more advanced data analysis and grouping capabilities across table relationships.

## Key points

- Users can add fields from related tables to analysis mode tabs via context menu options
- Available fields must already exist on pages; the dialog shows the source table and fields
- Multiple fields can be selected at once; added related fields can be removed using the Remove related columns action
- Filtering, sorting, and pivoting on calculated fields is limited for performance; Excel exports show only visible data
- This feature builds on analysis mode capabilities introduced in BC22 and enhanced through subsequent releases

## Quotes

- "Analysis mode is a powerful experience that lets you create and analyze data views easily." (Explains the core value of the feature for end users creating custom data views)

## Heads up

- gotcha: "For the best performance, we need to limit filtering, sorting, and pivoting on calculated fields." (about version 26, version 2025 release wave 1)
- gotcha: "exporting data to Excel will include just what is on screen." (about version 26, version 2025 release wave 1)
