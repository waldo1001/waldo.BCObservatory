# Dynamics 365 Business Central Blog Series: REST API web services (APIs)

[Read the post](https://yzhums.com/63801/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-05-02 · 1907 words · tier community · reviewed (checked by Opus)

> This blog series covers REST API web services in Dynamics 365 Business Central, including standard and automation APIs, OAuth authentication, custom API development, error handling, and integration with Microsoft 365 services like SharePoint and OneDrive.

## Key points

- Business Central supports multiple API types: standard APIs, automation APIs, and custom APIs built with query or codeunit objects
- OAuth 2.0 authentication is required for API access as Basic Auth was removed for Business Central Online
- APIs can be extended, filtered, and used with bound/unbound actions for data manipulation and system integration
- Business Central APIs integrate with Microsoft 365 services including Graph API for SharePoint, OneDrive, and email logging
- Database access intent controls write permissions and database access modes when calling APIs from client applications

## Quotes

- "Web Service Access Keys (Basic Auth) for Business Central Online has been removed" (OAuth 2.0 is now the mandatory authentication method for API access, requiring developers to update integration patterns)
- "Business Central supports three types of web services: (REST) API, SOAP, and OData" (Understanding the different web service types helps developers choose the right approach for their integration needs)
