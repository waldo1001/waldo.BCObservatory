# Dynamics 365 Business Central: Generate barcode through external services/APIs (Telepen, Swiss QR Code, QR codes with colors, images or text……)

[Read the post](https://yzhums.com/56046/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-05-20 · 1516 words · tier community · reviewed (checked by Opus)

> Business Central includes built-in barcode functionality via the System Application, supporting 1D and 2D barcodes in reports. When custom formatting like colors, sizes, or embedded images is needed, external APIs like QuickChart can generate QR codes and other barcode types through HTTP requests in AL code.

## Key points

- The standard Barcode module in the System Application adds barcodes to reports: one-dimensional barcodes from BC18 and 2D barcode fonts such as QR, Aztec and Data Matrix from BC19.1.
- The standard module cannot change size, colors, center images or captions, so the post calls the QuickChart API instead.
- QuickChart QR parameters cover format, margin, size, dark and light colors, error correction level, a center image and caption text.
- A page extension on Item Card uses HttpClient to request the image and import it into the item Picture field.
- A second example lets the user choose QR Code, Data Matrix, Aztec, Telepen or Swiss QR Code. Some external services are paid.

## Quotes

- "The barcode functionality lets you convert an alphanumeric value in a report dataset into a barcode on a generated report." (Establishes the standard barcode capability baseline in Business Central before discussing external API enhancements)
- "If the customer requires a QR code in a special format, such as a special size, background color, etc., the standard cannot do it." (Explains the limitation of built-in functionality and the use case for external APIs)
