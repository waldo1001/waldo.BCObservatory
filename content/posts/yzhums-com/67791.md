# Business Central 2025 wave 2 (BC27): Allow copying nodes in the profile editor and support for hovering

[Read the post](https://yzhums.com/67791/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-09-22 · 599 words · tier community · reviewed (checked by Opus)

> Business Central 2025 wave 2 (BC27) adds the ability to copy nodes in the VS Code profile editor and support for hovering to display full node text. These enhancements make it easier for developers to edit long nodes like SQL queries in the AL performance profiler.

## Key points

- Profile editor nodes can now be copied using Ctrl+C and pasted anywhere with Ctrl+V
- Hovering over nodes displays their full text, helping with long SQL queries and other extended content
- Feature is available in BC27 and documented in AL Language extension Version 16.0
- Builds on existing AL performance profiling capabilities introduced progressively since BC19

## Quotes

- "In the profile editor, individual nodes can be copied and hovered to show the full text of the node." (Describes the core functionality that improves the developer experience when working with complex performance data.)
