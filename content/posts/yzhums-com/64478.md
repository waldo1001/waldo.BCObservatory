# Dynamics 365 Business Central: How to quickly check if a field is a primary key field

[Read the post](https://yzhums.com/64478/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-11-28 · 498 words · tier community · **unreviewed** (model text not yet checked)

> This post explains how to programmatically check if a field is part of a table's primary key in AL code. It provides standard AL methods using RecordRef and KeyRef to determine primary key membership and the field's position within the key sequence.

## Key points

- Every table has exactly one primary key that uniquely identifies records; only table objects can define primary keys, while table extensions inherit them
- Secondary keys create SQL indexes and can be defined multiple times in both table objects and extensions
- AL provides standard methods in codeunit 9800 that use RecordRef and KeyRef objects to check primary key membership without querying the Key table
- The IsPrimaryKeyField method returns a boolean and can also determine the field's sequence number within the primary key

## Quotes

- "Every table has a primary key, and there can only be one primary key per table. Primary keys are defined on table objects only." (Establishes the fundamental constraint that guides how developers structure table definitions and extensions)
