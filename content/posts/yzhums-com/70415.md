# Dynamics 365 Business Central: How to run a Report in Preview Mode without the Request Page (Hide Request Page)

[Read the post](https://yzhums.com/70415/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-02-05 · 742 words · tier community · **unreviewed** (model text not yet checked)

> This post explains how to preview a Business Central report without showing the request page. It describes bypassing the request page using UseRequestPage or Report.Run methods, then demonstrates a preferred approach for BC26 that saves reports as PDF and displays them directly in the web client.

## Key points

- UseRequestPage(false) and Report.Run with RequestWindow=false bypass the request page but disable preview/print options and download the file instead
- Business Central 2025 Wave 1 (BC26) enables direct PDF preview in the web client, providing a better user experience
- Two practical approaches are provided: using Report Selections for standard reports and direct SaveAs method for fixed reports
- Reports can be saved as PDF using SaveReportAsPDFInTempBlob or SaveAs methods, then displayed with File.ViewFromStream

## Quotes

- "However, doing so disables the preview and print options, causing the file to be downloaded directly." (Explains the limitation of traditional methods for bypassing the request page, motivating the need for an alternative approach)
- "With this feature, you can open PDF attachments directly in the Business Central web client without downloading them first." (Describes the BC26 capability that enables the improved solution for previewing reports without request pages)
