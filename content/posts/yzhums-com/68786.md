# Dynamics 365 Business Central: How to record extra serial or lot number information (Item Tracking Comments)

[Read the post](https://yzhums.com/68786/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-11-21 · 326 words · tier community · **unreviewed** (model text not yet checked)

> Recording extra information for serial or lot numbers using the Item Tracking Comments feature allows companies to track quality assurance details and other metadata without customization. The feature uses a dedicated table to store comments linked to each tracking number.

## Key points

- Create a Lot/Serial No. Information card manually or automatically from inbound documents
- Add comments to tracking numbers via the Item Tracking Comments page for quality assurance and other details
- No customization required, supports unlimited comments, and uses dedicated table for easy access during development
- Alternative: use Notes from the system part to write notes on records

## Quotes

- "The advantage of this method is that it requires no customization and supports an unlimited number of comments." (Highlights that this is a native capability that is easy to implement without development resources)
- "It uses a dedicated table, Item Tracking Comment (6506), to manage these comments, making them relatively easy to access during custom development." (Important for developers who need to access or extend this functionality programmatically)
