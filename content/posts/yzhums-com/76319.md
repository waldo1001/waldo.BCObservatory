# Business Central 2026 release wave 2 (BC29): Use cross-platform report layout paths (forward slashes or backslashes)

[Read the post](https://yzhums.com/76319/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-09-25 · 328 words · tier community · reviewed (checked by Opus)

> Business Central 2026 wave 2 (BC29) allows report layout and analysis view paths to use either forward or backward slashes consistently across Windows and Linux systems. This enables the same AL source code to compile identically on different operating systems without requiring path changes.

## Key points

- Report layout properties (RDLCLayout, WordLayout, ExcelLayout, LayoutFile, DefinitionFile) now accept both / and \ separators on all operating systems
- Same AL source code compiles identically on Windows and Linux without path modifications
- AL0363 diagnostic is no longer reported for mismatched directory separators
- Particularly useful for cross-platform development and CI/CD pipelines using different build environments

## Context

- Features: cross-platform report layout paths, forward slash support in paths, backslash support in paths, analysis view definition paths
- Versions: BC29, 2026 release wave 2
