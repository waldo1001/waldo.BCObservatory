# Dynamics 365 Business Central: How to distinguish Positive and Negative Adjustments from Item Journals vs. Physical Inventory Journals in Item Ledger Entries

[Read the post](https://yzhums.com/75164/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-08-12 · 586 words · tier community · **unreviewed** (model text not yet checked)

> The post explains how to distinguish between positive and negative adjustments created from Item Journals versus Physical Inventory Journals in Item Ledger Entries. It describes the workflows for both journals and shows that Physical Inventory Journals create corresponding Physical Inventory Ledger Entries while Item Journals do not, plus provides customization code using FlowFields to display source codes for differentiation.

## Key points

- Item Journals post inventory adjustments directly without documents, while Physical Inventory Journals reconcile system inventory with actual warehouse stock
- Item Ledger Entries from both sources look identical without examining related data like Document No. or Source Code
- Physical Inventory Journals automatically generate Physical Inventory Ledger Entries; Item Journals do not
- Source Code field in Item Registers can distinguish the origin, viewable via Analysis Mode or by adding a FlowField customization to Item Ledger Entries

## Quotes

- "Posting Physical Inventory Journals doesn't just generate Item Ledger Entries - it also creates Physical Inventory Ledger Entries." (This is the key distinguishing characteristic between the two journal types that allows users to identify their source.)
- "Even if you open the table directly, you still can't tell the difference." (Explains why a workaround or customization is necessary to distinguish between the two adjustment sources.)
