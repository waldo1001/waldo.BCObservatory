# Dynamics 365 Business Central: How to check if a string contains particular strings (if a string is a substring of another)

[Read the post](https://yzhums.com/51041/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-11-26 · 327 words · tier community · **unreviewed** (model text not yet checked)

> This post explains two methods to check if a string contains a substring in Business Central using AL code: the Text.StrPos method returns the position of the first occurrence, while Text.Contains returns a boolean value. Both approaches are demonstrated with table extension examples.

## Key points

- Text.StrPos(Text, Text) searches for the first occurrence of a substring and returns its position, or zero if not found
- Text.Contains(Text) is a simpler alternative that directly returns whether a substring occurs in the string
- For case-insensitive searches, use Text.LowerCase or Text.UpperCase to convert strings before comparing
- Both methods return zero or false if the string or substring is empty

## Quotes

- "Text.StrPos(Text, Text) Method: Searches for the first occurrence of substring inside a string." (This is one of two main approaches for finding substrings, showing the foundational method available in AL)
- "Text.Contains(Text) Method: Returns a value indicating whether a specified substring occurs within this string." (This is the simpler, more modern alternative method that directly answers the question of substring existence)
