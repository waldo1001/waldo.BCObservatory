Users can leverage AI-powered chat to find business data using natural language, get task guidance, and understand field purposes without leaving the application.

## Key points

- Copilot chat now supports 20 more languages than the previous release
- Users can find and analyze business data by asking natural language questions about customers, vendors, sales orders, and items
- Copilot provides step-by-step guidance on business tasks and explains field purposes via chat
- BC27 includes improved prompt understanding for multi-sentence inputs and faster performance
- Field tooltips now include an Ask Copilot option that opens chat with contextual explanations
