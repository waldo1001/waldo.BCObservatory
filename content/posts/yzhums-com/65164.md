# Dynamics 365 Business Central: Using Ask Learn (AI assistant) on Microsoft Learn (Technical documentation)

[Read the post](https://yzhums.com/65164/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-06-13 · 534 words · tier community · reviewed (checked by Opus)

> Ask Learn is an AI assistant in preview on Microsoft Learn that answers questions, clarifies concepts, and defines terms related to Business Central and other Microsoft products. It helps users quickly search documentation and summarize content directly on technical pages.

## Key points

- Ask Learn uses AI grounded in Microsoft Learn documentation to answer Business Central questions and define concepts
- Currently available only in English and requires Microsoft account sign-in
- Works best with clear, specific questions and accepts up to 500 characters per prompt
- Available in preview on Microsoft Learn training pages; users should verify responses for accuracy
- Similar to existing Chat with Copilot feature already in Business Central

- "Ask Learn is an AI assistant that can answer questions, clarify concepts, and define terms throughout your training experience." (Describes the core capability of Ask Learn for improving the learning experience)
