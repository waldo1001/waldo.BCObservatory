# Business Central 2026 release wave 2 (BC29): Developers can define indexes that span fields from a base table and its table extensions (Table extension keys can now mix both base table fields and extension fields)

[Read the post](https://yzhums.com/75873/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-09-07 · 508 words · tier community · reviewed (checked by Opus)

> Business Central 2026 release wave 2 (BC29) enables developers to define database indexes that span fields from both base tables and their table extensions. Previously, keys could only contain fields from either the base table or the extension, not both, which required workarounds like data duplication or complex joins.

## Key points

- Table extension keys now support mixing base table fields and extension fields in key definitions (KeyFields, SumIndexFields, SqlIndex, IncludedFields)
- This eliminates previous AL compiler error AL(AL0423) that prevented unified keys across table and extension boundaries
- Developers can create more efficient database indexes without performance compromises or awkward workarounds
- Mixed-field indexes improve data modeling efficiency and reduce the need for unnecessary data duplication

## Quotes

- "This often forced unnecessary data duplication or heavy SQL joins." (Explains the practical pain point that developers faced before this feature was available)
