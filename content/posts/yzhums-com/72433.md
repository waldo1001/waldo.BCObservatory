# How to create a new Demo & Trial Business Central tenant via Microsoft Demo eXperiences (MDX) – formerly CDX

[Read the post](https://yzhums.com/72433/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-05-08 · 473 words · tier community · **unreviewed** (model text not yet checked)

> Creating a trial Business Central tenant via Microsoft Demo eXperiences (MDX), the successor to Customer Digital Experiences (CDX), requires navigating through Experiences and claiming a new tenant since the direct Create Tenant page has been deprecated.

## Key points

- MDX replaces CDX for creating trial Business Central environments with an updated process
- Trial tenants are claimed through the Experiences section by selecting an experience and choosing 'Claim new tenant'
- Only one trial tenant can be created at a time, with a 90-day duration, and only 3 environments can be created per month
- Partners can access and manage created tenants through the MDX Dashboard

## Quotes

- "Customer Digital Experiences (CDX) has recently been officially updated to Microsoft Demo eXperiences (MDX). The method for creating a trial version has changed." (Indicates a platform transition that partners need to be aware of for creating test environments)
- "You can only create one trial tenant (90 day)." (Sets clear expectations about trial environment limitations)
- "Only 3 environments can be created per month." (Establishes rate limits that partners must plan around)
