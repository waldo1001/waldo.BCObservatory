# Regarding the recent problem I encountered when opening Power Apps with Zscaler

[Read the post](https://yzhums.com/67024/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-08-28 · 2771 words · tier community · **unreviewed** (model text not yet checked)

> Power Apps customizations may fail to run on end-user machines when Zscaler security software is deployed, causing ProxyError and script loading errors during Go-Live despite working in UAT environments.

## Key points

- Zscaler Client Connector can block Power Apps from running on end-user PCs
- Issue does not affect all custom Power Apps, only some
- Works in development and UAT but fails during Go-Live on user machines with Zscaler
- ProxyError and script loading errors indicate Zscaler intervention blocking access to required resources
- Zscaler provides internet security through traffic inspection and policy enforcement
