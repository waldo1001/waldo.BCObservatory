# Dynamics 365 Business Central: Quickly check the current filters used on the current page via Page Inspection

[Read the post](https://yzhums.com/69722/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-01-06 · 537 words · tier community · **unreviewed** (model text not yet checked)

> Page Inspection in Business Central allows you to quickly view all current filters applied to a page, including filters from the filter pane, list views, code, and subpage links. This feature helps identify hidden filters and understand their sources, accessible via Ctrl+Alt+F1 or the Help & Support menu.

## Key points

- Access page inspection using Ctrl+Alt+F1 keyboard shortcut or through Help & Support menu
- Page Filters tab shows all filter types: user filters, table view filters, subform link filters, and form view filters
- Identify filters that may not be visually displayed on the page and their sources
- View mandatory filters created with Record.FilterGroup() method that users cannot remove
- Security filters cannot be viewed using page inspection

## Quotes

- "This also allows you to identify filters that are not displayed on the page." (Highlights a key benefit for troubleshooting and understanding actual page filtering behavior)
