# Business Central 2026 release wave 1 (BC28): Map new Dataverse fields (New and custom Dataverse tables are readily available for mapping from the lookup on Integration Table column)

[Read the post](https://yzhums.com/71914/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-04-21 · 530 words · tier community · reviewed (checked by Opus)

> Business Central 2026 wave 1 enables administrators to map new Dataverse fields directly without writing code or creating table extensions, simplifying synchronization between Business Central and Dataverse as schemas evolve.

## Key points

- New fields added to Dataverse can now be mapped through the Integration Table Mappings page in Business Central without code changes
- Administrators can map fields from the Field Name and Integration Field Name lookup without creating or updating table extensions
- Newly mapped fields default to Disabled status and must be manually enabled
- New custom Dataverse tables still require the previous integration method and cannot be auto-discovered
- This reduces configuration effort and accelerates adoption of custom fields in integrated environments

## Quotes

- "As an administrator, you can map newly added Dataverse fields without recreating table extensions or writing code, reducing configuration effort." (Shows the core benefit of eliminating code requirements for field mapping, lowering operational complexity)
- "With this wave (BC28), no code is required, the newly added field in Dataverse is already visible and can be mapped." (Demonstrates the practical implementation where Dataverse fields are auto-discovered and immediately available for mapping)
- "For new tables, we still need to use the previous method." (Clarifies the feature's scope limitation - only new fields in existing tables are auto-discovered, not new Dataverse tables)
