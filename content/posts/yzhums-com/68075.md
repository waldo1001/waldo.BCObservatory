# Business Central 2025 wave 2 (BC27): Date methods behavior on blank Date and DataTime fields when retrieving date data in queries

[Read the post](https://yzhums.com/68075/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-10-27 · 438 words · tier community · reviewed (checked by Opus)

> Business Central 2025 wave 2 (BC27) changes how date methods return values for blank Date and DateTime fields in queries. Starting with BC27, blank dates return 0 for day, month, and year instead of 1, 1, and 1753 as in earlier versions.

## Key points

- Setting the Method property on a query column to Day, Month or Year returns only that part of a date
- BC stores a blank date internally as 0D, while SQL Server stores it as 01-01-1753
- In BC26 and earlier, a blank date returns 1, 1 and 1753 for day, month and year
- From BC27 onward, a blank date returns 0 for day, month and year
- The example query over Purchase Header, Purchase Line and Item uses these methods on the Order Date field

## Quotes

- "In Business Central, a blank date is represented internally as 0D. In SQL Server, a blank date is 01-01-1753." (Understanding the internal representation of blank dates is essential for predicting how date methods behave across versions.)
- "The values that date methods return for blank fields differ by product version." (This warning signals a breaking change that requires developers to test and potentially update query logic when upgrading to BC27.)
