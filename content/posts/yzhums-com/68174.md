# Business Central 2025 wave 2 (BC27): App version in “Copy error details”/”Share details via”

[Read the post](https://yzhums.com/68174/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-10-08 · 436 words · tier community · reviewed (checked by Opus)

> Business Central 2025 wave 2 (BC27) now includes extension version numbers in error details when users copy or share error information. This enhancement helps support staff and developers identify which extension version a customer is using without manually checking Extension Management.

## Key points

- Error dialogs now display the extension version number alongside extension name and publisher in the AL call stack
- This capability builds on previous improvements: BC22 introduced Copy details, BC24 replaced it with Share feature
- Knowing the extension version helps troubleshoot issues, especially for AppSource extensions that may not be up to date
- Version information is automatically included when users share error details via the UI

## Quotes

- "With this wave (BC27), Microsoft has enhanced this feature again, and we can see the version number of the extension in the error details." (Explains the core new capability that extension versions are now visible in error details.)
- "The AL call stack contains the object name, function name, line number, extension name, and extension publisher." (Describes what troubleshooting information is available in the call stack for diagnostics.)
