> Business Central 2025 wave 2 introduces Guid.CreateSequentialGuid method which generates sequential unique GUIDs that perform better as table keys than random GUIDs. This method is useful when you need improved performance for GUID-based indexing.

## Key points

- Guid.CreateSequentialGuid creates sequential unique GUIDs instead of random ones
- Sequential GUIDs perform better when used as table keys due to partial sequencing
- The method is available in AL Language extension version 16.0
- Each execution starts from a new GUID rather than continuing the sequence

## Quotes

- "Sequential GUIDs perform better when used as a field in a key, because they are partially sequential instead of fully random." (Explains the key benefit of the new method - improved performance for table key operations compared to random GUIDs)
