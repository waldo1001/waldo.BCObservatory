# Business Central 2025 wave 2 (BC27): New layout information fields in the aggregated metadata sheet for the Excel layout template (Object caption, Local date, and UTC timezone offset)

[Read the post](https://yzhums.com/67838/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-09-25 · 340 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2025 wave 2 introduces three new layout information fields in the Excel layout template's aggregated metadata sheet: object caption, local date, and UTC timezone offset. This enhancement helps developers better configure Excel report layouts by providing additional contextual information.

## Key points

- Three new fields added to the Aggregated Metadata sheet in Excel layouts: object caption, local date, and UTC timezone offset
- These fields support Excel report layout creation and design alongside existing dataset definition tasks
- The feature is available in BC27 public preview but not yet documented in the official release plan
- Word layouts do not yet include these new metadata fields despite having report metadata access capability

- Features: Excel layout template metadata, Object caption field, Local date field, UTC timezone offset field
