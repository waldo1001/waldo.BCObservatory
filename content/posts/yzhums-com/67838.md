# Business Central 2025 wave 2 (BC27): New layout information fields in the aggregated metadata sheet for the Excel layout template (Object caption, Local date, and UTC timezone offset)

[Read the post](https://yzhums.com/67838/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-09-25 · 340 words · tier community · reviewed (checked by Opus)

> BC27 (2025 wave 2) adds three layout information fields to the hidden Aggregated Metadata sheet of Excel layout templates: object caption, local date and UTC timezone offset. The change is listed in the AL Language extension 16.0 changelog, not in the release plan, and Word layouts do not have these fields yet.

## Key points

- Excel layouts contain a hidden Aggregated Metadata sheet holding ReportMetadata and ReportRequest
- BC27 adds object caption, local date and UTC timezone offset fields to that sheet
- The change comes from the AL Language extension 16.0 changelog and is not yet in the release plan
- Word layouts gained report and request metadata access in BC26 but do not have these three new fields

## Context

- Features: Excel layout template metadata, Object caption field, Local date field, UTC timezone offset field
- Versions: BC27, 2025 wave 2, BC26, 2025 wave 1
