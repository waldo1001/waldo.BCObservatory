# Business Central 2026 release wave 1 (BC28): Define item attributes for item variants

[Read the post](https://yzhums.com/70986/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-03-03 · 464 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2026 wave 1 (BC28) adds the ability to assign attribute values to individual item variants. Variants now inherit attributes from the parent item but can have their own adjusted or removed values, and a new Update Variant Attributes action syncs attributes across variants.

## Key points

- Item variants can now have attribute values assigned at the variant level, separate from the parent item's attributes
- Variants inherit attributes from the item automatically but allow for adjustment or removal of inherited values
- A new Update Variant Attributes action on the Item Card forces synchronization of attributes from the item to all its variants
- Variant-specific attributes are managed through the Item Variant Attribute Values page, accessible from Item Variants List or Item Variant Card

## Quotes

- "You can assign attribute values that reflect the specific variant at the item variant level." (Explains the core capability that variants can now have unique attribute values independent of the parent item)
- "Item variants inherit attributes from the item, and you can adjust or remove those inherited values when the variant requires different information." (Shows that while inheritance exists, variants have flexibility to customize attributes without affecting the parent item)
