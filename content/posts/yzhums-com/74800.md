# Does Dynamics 365 Business Central support browser-based translation (e.g., Microsoft Translator in Edge browser)?

[Read the post](https://yzhums.com/74800/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-07-22 · 580 words · tier community · reviewed (checked by Opus)

> Browser-based translation tools like Microsoft Translator in Edge can technically display Business Central content in different languages, but this approach is not recommended because it causes contextual inaccuracy for ERP terminology, disrupts UI layout and performance, and creates inconsistent experiences across users. The post explains how Business Central's proper language support works through language packs from Marketplace instead.

## Key points

- Business Central supports multiple languages through installed language packs available on Marketplace, with platform captions translated by Microsoft and application captions by Microsoft or partners
- Browser-based translation mistranslates domain-specific ERP terms like 'Posting' and 'Item Ledger Entries' and translates values that should remain unchanged
- Real-time translation by browser extensions can break UI elements, freeze responsive grids, and cause performance problems during data entry
- Client-side browser translation creates inconsistent experiences across users and complicates troubleshooting and technical support

## Quotes

- "Language support requires translation of platform captions and application captions (UI)." (Establishes that proper language implementation in Business Central involves structured UI translation, not browser translation)

- Features: multi-language support, language packs, XLIFF translation files, browser-based translation
