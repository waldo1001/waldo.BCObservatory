# Dynamics 365 Business Central: How to import Change Log Setup (Table/Field) using Configuration Packages

[Read the post](https://yzhums.com/76760/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-11-05 · 352 words · tier community · reviewed (checked by Opus)

> The post explains how to import Change Log Setup configuration (tables and fields) efficiently using Configuration Packages. Instead of setting up each table and field individually, you can use three specific tables (Change Log Setup, Change Log Setup (Table), and Change Log Setup (Field)) to bulk import the configuration via packages.

## Key points

- The change log records direct user changes to data in the tables and fields you choose to track
- Setting up each tracked table and field by hand takes a long time
- The setup list pages (593 and 594) are based on the system tables AllObjWithCaption and Field, so importing through those pages is not the route
- Instead, put tables 402 Change Log Setup, 403 Change Log Setup (Table) and 404 Change Log Setup (Field) in a configuration package
- Export a few sample settings first, then use the export as a template for the import

## Quotes

- "The change log in Business Central lets you track all direct modifications a user makes to data in the database." (Establishes the core purpose and value of the change log feature for audit and compliance needs)
- "However, configuring this setup individually for each table and field is extremely time-consuming." (Identifies the problem that the bulk import solution solves)
