# Business Central 2025 wave 2 (BC27): New field “AL Namespace” has been added to object metadata record (AllObj, AllObjWithCaption, Page Metadata, Report Metadata, and Codeunit Metadata)

[Read the post](https://yzhums.com/68087/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-10-02 · 768 words · tier community · reviewed (checked by Opus)

> Business Central 2025 wave 2 introduces a new AL Namespace field in object metadata tables (AllObj, AllObjWithCaption, Page Metadata, Report Metadata, and Codeunit Metadata), enabling developers to discover and filter namespace information that was previously unavailable in system tables.

## Key points

- BC27 adds an AL Namespace field to AllObj, AllObjWithCaption, Page Metadata, Report Metadata and CodeUnit Metadata
- AL namespaces, introduced in Business Central 2023 wave 2 (runtime 12.0), help segment code and avoid naming conflicts
- Before BC27, namespaces could not be exported because no table stored them
- The new field can be read directly in the tables or filtered and processed from AL code
- Microsoft also added descriptive summaries for these metadata tables and fields

## Quotes

- "As of now, we cannot export all namespaces because the namespace is not stored in any table." (Explains the problem this feature solves - namespaces were previously inaccessible from system tables)
- "A namespace ensures that all of a given set of objects have unique names so that they can be easily identified." (Clarifies the purpose of namespaces in managing object identification and reducing conflicts)
