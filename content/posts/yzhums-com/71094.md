# Business Central 2026 release wave 1 (BC28): Support for packaging analysis views in extensions (Create analysis views via AL)

[Read the post](https://yzhums.com/71094/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-03-05 · 630 words · tier community · reviewed (checked by Opus)

> Analysis views can now be packaged in AL extensions as .analysis.json files and added to list pages via analysisview components. Developers can create views in the web client's Analysis Mode, export them, include them in extension projects, and reference them in page definitions to distribute standardized data analysis capabilities across Business Central environments.

## Key points

- Analysis views are created and exported as .analysis.json files from Analysis Mode in the web client
- The .analysis.json file is included in the AL extension project and referenced via an analysisview component in the analysisviews section
- Keywords like addfirst, addlast, addbefore, and addafter control the placement of analysis views relative to other views
- Analysis views can extend standard pages or be added directly to new custom pages
- The targetObjectId in the definition file must match the object containing the analysis view, and missing dependencies must be resolved

## Quotes

- "Analysis views can now be packaged and delivered as part of AL extensions for list pages, including extensions and customizations." (Shows the core capability that allows developers to distribute reusable analysis views across environments)
- "Prior to this release, sharing Analysis views required the 'Copy Link' function, which was incredibly cumbersome for large teams." (Demonstrates the problem this feature solves by eliminating manual sharing workarounds)
