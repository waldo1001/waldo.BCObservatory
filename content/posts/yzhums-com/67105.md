# Dynamics 365 Business Central: How to get database usage through API

[Read the post](https://yzhums.com/67105/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-09-03 · 551 words · tier community · reviewed (checked by Opus)

> This post explains how to retrieve Business Central environment database usage through the Admin Center API instead of the admin portal. It covers authentication setup with Microsoft Entra apps and two available API endpoints that return database storage metrics.

## Key points

- Business Central has a 80 GB base storage limit plus per-user allowance, shared across all tenant environments
- Admin Center API supports Microsoft Entra app authentication from version 20.0 onwards
- Two endpoints available: GET environments (v2.3) returns databaseSize, and GET usedstorage (v2.26) returns detailed storage breakdown
- API v2.26 or newer required for accurate large database storage reporting using 64-bit integers

## Quotes

- "By default, Business Central customers can use up to 80 GB plus an allowance per licensed Essentials or Premium user of database storage capacity." (Establishes the storage quota context that users need to monitor through the API)
- "Consume version 2.26 or newer to correctly retrieve database storage usage for large databases and make sure your client supports 64-bit integers." (Critical technical requirement for accurate data retrieval in production environments)

- Features: Admin Center API, Microsoft Entra authentication, database size retrieval, storage monitoring, environment management, capacity tracking
- Versions: 20.0, 2.3, 2.26
