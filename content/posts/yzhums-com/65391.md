# Dynamics 365 Business Central: How to set Allow HttpClient Requests for multiple extensions (selected extensions) at the same time

[Read the post](https://yzhums.com/65391/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-06-19 · 783 words · tier community · reviewed (checked by Opus)

> Enabling Allow HttpClient Requests for multiple extensions at once requires creating a custom page that reads from the NAV App Installed App table and modifies the NAV App Setting table in bulk. This solves the problem of having to enable the setting manually in each environment for every extension.

## Key points

- Allow HttpClient Requests must be enabled per extension to allow outbound HTTP calls from AL code
- The Extension Management page cannot be extended, so a custom page using NAV App Installed App table is needed
- The setting is stored in system table 2000000201 NAV App Setting which is cloud-scoped and extensible
- A custom page with a bulk action can update Allow HttpClient Requests for selected extensions at once

## Quotes

- "This setting is saved in table 2000000201 NAV App Setting. The scope of this table is Cloud and it is extensible." (Identifies the underlying system table where the setting can be modified programmatically)
- "This setting must be enabled for each app/extension, including library apps." (Clarifies why bulk operations are needed for managing multiple extensions)
