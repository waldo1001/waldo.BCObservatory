# Business Central 2026 release wave 1 (BC28): Show Currency Symbol/Code and Currency Symbol Position

[Read the post](https://yzhums.com/74649/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-07-10 · 476 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2026 wave 1 introduces Show Currency Symbol/Code and Currency Symbol Position settings on the General Ledger Setup and Currencies pages. These new features allow organizations to display currency symbols or codes in amount fields throughout the system with flexible placement options before or after amounts.

## Key points

- Two new settings added to General Ledger Setup: Show Currency (controls whether symbols/codes appear for LCY or FCY) and Currency Symbol Position (placement relative to amount)
- Currency Symbol Position setting also added to Currencies page for foreign currency configuration
- LCY formatting is controlled globally from General Ledger Setup, while FCY formatting is configured individually for each currency record
- Currency symbol position settings automatically apply to all amount fields throughout the system once configured

## Quotes

- "We can now show the currency code or symbol in amount fields, including flexible placement options." (This is the core capability introduced - allowing organizations to customize how currency information appears in their system across all amount fields.)
- "For any foreign currencies (FCY), the symbol position must be configured specifically within each record on the Currencies page." (This explains the key difference in configuration approach: LCY is global while FCY requires individual currency record setup.)
