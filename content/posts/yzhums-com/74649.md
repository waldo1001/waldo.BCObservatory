# Business Central 2026 release wave 1 (BC28): Show Currency Symbol/Code and Currency Symbol Position

[Read the post](https://yzhums.com/74649/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-07-10 · 476 words · tier community · reviewed (checked by Opus)

> BC28 (2026 release wave 1) adds a Show Currency setting and a Currency Symbol Position setting to General Ledger Setup, plus a Currency Symbol Position field on the Currencies page. Together they let amount fields show a currency symbol or code before or after the amount.

## Key points

- General Ledger Setup gains Show Currency, which controls when a symbol or code is shown for LCY and FCY, and Currency Symbol Position
- Show Currency applies globally to both local and foreign currencies
- Symbol position on General Ledger Setup covers only LCY; each foreign currency sets its own position on the Currencies page
- Once set, the formatting is applied to amount fields across the system
- The feature was rolled back earlier and is available again in BC28.3

## Quotes

- "We can now show the currency code or symbol in amount fields, including flexible placement options." (This is the core capability introduced - allowing organizations to customize how currency information appears in their system across all amount fields.)
- "For any foreign currencies (FCY), the symbol position must be configured specifically within each record on the Currencies page." (This explains the key difference in configuration approach: LCY is global while FCY requires individual currency record setup.)
