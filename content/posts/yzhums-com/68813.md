# Dynamics 365 Business Central: How to determine whether the current environment is Sandbox or Production

[Read the post](https://yzhums.com/68813/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-11-17 · 637 words · tier community · **unreviewed** (model text not yet checked)

> Determining whether a Business Central environment is Sandbox or Production can be done through multiple methods: checking the Help & Support page, using company badges that differ by shape (round for production, square for sandbox), accessing the App Launcher, or using the Environment Information codeunit.

## Key points

- Production environments are for running daily business operations on performance tiers with high availability, while Sandbox environments are for testing and development
- Environment names may not reliably indicate the actual environment type, requiring verification methods
- The Help & Support page's Report a Problem tab shows the environment type in the Microsoft Extra Tenant ID
- Company badges automatically reflect environment type and appear round for production or square for sandbox
- Alternative technical methods include using the App Launcher or codeunit 457 Environment Information

## Quotes

- "A round company badge signifies a production environment, and a square badge signifies a sandbox environment." (Provides a quick visual way to identify environment type without admin access)
