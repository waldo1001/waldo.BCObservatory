# Dynamics 365 Business Central: Merge duplicate records (customers, vendors, or contacts)

[Read the post](https://yzhums.com/67058/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-08-29 · 822 words · tier community · reviewed (checked by Opus)

> The Merge Duplicate feature in Business Central allows users to consolidate duplicate customer, vendor, or contact records by selecting which field values to keep and resolving any conflicts before completing the merge. This standard feature helps maintain data quality when records are created during data entry or migration.

## Key points

- Open the Merge With action from the card of the record you want to keep (customer, vendor or contact)
- The Fields FastTab lists differing values; only a few differences suggest a true duplicate
- The Related Tables FastTab is informational and shows counts of related records for each customer
- Select Override to take the alternate value for a field, then choose Merge
- Conflicts on primary-key fields are resolved on the Merge Duplicate Conflicts page by removing or renaming the duplicate; the merge cannot be undone and requires the MERGE DUPLICATES permission set

## Quotes

- "Only users with the MERGE DUPLICATES permission set can use this functionality." (Important security and access control requirement)
