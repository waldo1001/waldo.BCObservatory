# Dynamics 365 Business Central: Merge duplicate records (customers, vendors, or contacts)

[Read the post](https://yzhums.com/67058/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-08-29 · 822 words · tier community · **unreviewed** (model text not yet checked)

> The Merge Duplicate feature in Business Central allows users to consolidate duplicate customer, vendor, or contact records by selecting which field values to keep and resolving any conflicts before completing the merge. This standard feature helps maintain data quality when records are created during data entry or migration.

## Key points

- Access the Merge Duplicate feature from the card of the record you want to keep using the Merge With action
- The Fields FastTab displays differences between two records; few differences indicate a likely duplicate
- The Related Tables FastTab shows connections to other tables and helps identify merge conflicts with primary key fields
- Users can override field values by checking the Override checkbox to select which alternate values to keep
- Merge conflicts can be resolved on the Merge Duplicate Conflicts page before finalizing the merge, with options to remove or rename the duplicate record

## Quotes

- "Only users with the MERGE DUPLICATES permission set can use this functionality." (Important security and access control requirement)
