# Dynamics 365 Business Central: How to quickly clear/remove all breakpoints in VS Code

[Read the post](https://yzhums.com/66721/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-08-18 · 304 words · tier community · reviewed (checked by Opus)

> VS Code debugging for Business Central allows developers to set breakpoints to pause code execution. This post explains two methods to clear all breakpoints at once: using the Remove All Breakpoints button in the Breakpoints tab, or adding a custom keyboard shortcut since the feature lacks a default shortcut like Visual Studio's Ctrl+Shift+F9.

## Key points

- Breakpoints pause code execution when the debugger reaches them, helping developers inspect application behavior
- The Breakpoints tab has a Remove All Breakpoints button for bulk clearing without removing breakpoints individually
- VS Code doesn't have a default shortcut for removing all breakpoints, but you can add a custom one through File > Preferences > Keyboard Shortcuts
- Custom shortcuts like Alt+B can replicate Visual Studio's Ctrl+Shift+F9 functionality in VS Code
