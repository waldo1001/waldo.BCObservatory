# Dynamics 365 Business Central: How to show or hide subform fields based on a value in the main page

[Read the post](https://yzhums.com/71582/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-04-01 · 351 words · tier community · **unreviewed** (model text not yet checked)

> This post explains how to dynamically show or hide subform fields based on a value in the main page of a Sales Order, using a custom field and page extension logic in AL code to create a responsive user interface.

## Key points

- Add a custom Boolean field to the main page (Sales Header) to control visibility state
- Use page extensions to modify subform fields and implement a SetShowItemInfo procedure
- Implement OnValidate and OnOpenPage triggers to update field visibility in real time when the main page field changes
- The example demonstrates hiding or showing Item No., Item Reference No., and Description fields in the Sales Order Subform
