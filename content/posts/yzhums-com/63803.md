# Dynamics 365 Business Central: How to disable/hide OneDrive action group for all users

[Read the post](https://yzhums.com/63803/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-05-15 · 617 words · tier community · **unreviewed** (model text not yet checked)

> The post explains how to disable or hide OneDrive action groups in Dynamics 365 Business Central for all users. It covers three methods: using personalization on individual pages, using page customization and extensions, and using the OneDrive Setup guide or Privacy Notices Status page to manage OneDrive features globally.

## Key points

- OneDrive actions (Open in OneDrive, Share, Edit in OneDrive) are available on pages with files like Report Inbox and document attachments
- Page-level customization hides OneDrive actions only on specific pages, requiring modifications to multiple pages to hide them everywhere
- Administrators can disable OneDrive features for all users through the OneDrive Setup assisted setup guide or by marking Disagree for Everyone on the Privacy Notices Status page
- OneDrive integration is automatically configured and enabled in Business Central online, with two option categories: Use for app features and Use for system features

## Quotes

- "Unlike Power Automate action groups, we can move or hide OneDrive actions using personalization." (Explains the primary UI-based method available for managing OneDrive actions without code changes)
- "In the Microsoft OneDrive row, select the Disagree for Everyone check box." (Provides the exact step to globally disable OneDrive for all users through privacy settings)
