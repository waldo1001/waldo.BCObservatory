# Business Central 2026 release wave 1 (BC28.2): Use new APIs for analyzing permissions for auditors and IT staff

[Read the post](https://yzhums.com/74366/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-06-29 · 540 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2026 wave 1 introduces five read-only APIs for querying permission sets, access controls, user permissions, and mappings. These APIs enable auditors and IT staff to build security reports and analytics in Power BI or Copilot Studio without compromising system integrity.

## Key points

- Five new read-only APIs expose permission data: Expanded Permission Sets, Access Control, Users Permissions, User Permission Sets, and Permission Sets
- APIs belong to the Automation API v2.0 and support querying permission sets, scope, extensions, security groups, and user mappings
- Organizations can integrate APIs with Power BI and Copilot Studio to create advanced auditing reports and intelligent agents
- Read-only access maintains security and compliance while providing real-time visibility into permission assignments and access controls

- "The new read-only permission APIs empower businesses to strengthen security and compliance by enabling external auditing and analytics without compromising system integrity." (Explains the core value proposition that auditing can occur externally while maintaining system security)
