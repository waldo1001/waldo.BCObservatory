# Dynamics 365 Business Central: Search for duplicate contacts (automatic and manual)

[Read the post](https://yzhums.com/67162/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-09-02 · 438 words · tier community · **unreviewed** (model text not yet checked)

> Dynamics 365 Business Central provides automatic and manual methods to search for duplicate contacts before merging them. Users can configure a Search Hit percentage threshold (default 60%) on the Marketing Setup page to define when contacts are considered duplicates, and Business Central can automatically notify users when creating or modifying contacts if duplicates are detected.

## Key points

- Configure Search Hit percentage on Marketing Setup page to set duplicate matching threshold
- Enable automatic duplicate search when creating or modifying contacts
- Manually search for duplicates using Generate Duplicate Search String action with filter criteria
- Use Merge Contacts action to merge duplicate contact records

## Quotes

- "Avoiding duplicate contacts can help ensure that you interact with the right person for the right company." (Explains the business value of having clean, non-duplicate contact data for accurate customer interactions.)
- "You can specify the percentage of identical data that two contacts must have in order to consider them duplicates." (Shows how the Search Hit percentage setting controls the matching precision for identifying duplicates.)
