# Dynamics 365 Business Central: How to add a Signature Pad to the Sales Order page (Capture and Save Customer Signatures)

[Read the post](https://yzhums.com/75073/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-08-04 · 386 words · tier community · reviewed (checked by Opus)

> Adding a signature pad to the Sales Order page in Business Central using control add-in objects allows customers to sign digitally and save signatures directly within the system. The post demonstrates a real-world implementation using public JavaScript libraries from CDN.

## Key points

- Control add-in objects can load the public signature_pad JavaScript library from jsDelivr or cdnjs through the Scripts property
- A new Customer Delivery Signature group on the Sales Order lets customers sign by hand, and a Clear button or a Clear Signature header action resets the pad
- A Customer Signature Preview FactBox holds the signature saved with Save Signature and has a delete option
- The approach can be added to other pages such as Warehouse Shipment or Sales Invoice, and it works on the Web, Tablet and Phone clients

## Quotes

- "Unlike the calculator we looked at before, we can find this directly in public JS libraries, such as in CDN or cdnjs" (Shows how to leverage existing open-source JavaScript libraries for control add-in development without building from scratch)
- "This is not limited to the Web Client; it can also be used on the Tablet and Phone clients." (Indicates cross-client compatibility extends the feature's usability across multiple platforms)
