# Business Central 2026 release wave 1 (BC28.2): Change AI models for agents in the UI

[Read the post](https://yzhums.com/74431/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-07-01 · 405 words · tier community · reviewed (checked by Opus)

> Business Central 2026 wave 1 (BC28.2) lets agents use different AI models directly in the UI. Users can select a specific model for each agent or use automatic default selection, with a resolution order that prioritizes task-level, then agent-level, then system default models.

## Key points

- On the Agents page, each agent card has an Agent model section where you choose a specific model or Auto
- The model chosen affects how an agent behaves, how it performs and what results it gives
- Business Central picks the model in this order: the one set on the task, then the one set on the agent, then the default
- Custom agents arrived in 2025 wave 2 (BC27.4); managing models in the UI is new in BC28.2 and is in preview
- With Auto, the model can change over time; to get predictable behavior, pin the agent to a specific model version

- "Agents in Business Central can run on different AI models. The model an agent uses can affect its behavior, performance, and results." (Explains the core capability and why model selection matters for agent functionality)
