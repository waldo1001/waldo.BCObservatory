# Business Central 2026 release wave 1 (BC28.2): Change AI models for agents in the UI

[Read the post](https://yzhums.com/74431/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-07-01 · 405 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2026 wave 1 (BC28.2) lets agents use different AI models directly in the UI. Users can select a specific model for each agent or use automatic default selection, with a resolution order that prioritizes task-level, then agent-level, then system default models.

## Key points

- Agents can be configured to use specific AI models or automatic default selection through the Agents page
- Model selection affects agent behavior, performance, and results
- Model resolution follows a hierarchy: task-level model takes precedence, then agent-level model, then system default
- Custom agents were introduced in BC25.2 (BC27.4), and UI model management is new in BC28.2
- Using 'Auto' allows the system to change models over time; pinning to a specific version provides predictable behavior
