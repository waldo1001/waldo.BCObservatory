> Page Scripting tool in Business Central 2026 wave 2 (BC29) reaches general availability with support for selecting multiple rows in grids and validating dialog text. The tool allows recording and replaying user actions in the web client to create repeatable user acceptance tests without writing code.

## Key points

- Page Scripting moves from preview to general availability with full localization and accessibility improvements
- New capabilities include multi-row selection in grids and text validation in message and error dialogs
- Enables creation of repeatable user acceptance tests by recording and replaying user actions without AL code
- Captures bulk workflows and validates expected messages, making recordings into meaningful process checks
