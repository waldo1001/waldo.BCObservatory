# Dynamics 365 Business Central Blog Series: Report Extension Examples & Use Cases

[Read the post](https://yzhums.com/70354/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-02-02 · 1159 words · tier community · **unreviewed** (model text not yet checked)

> This blog series covers multiple articles on extending and customizing reports in Dynamics 365 Business Central, including report extension objects, adding media and comments, PDF password protection, modifying sorting and filters, and managing report layouts and exports.

## Key points

- Report extensibility via ReportExtension object allows adding columns and fields to standard reports
- Reports can be customized with media, comments, notes, signatures, and regional settings
- PDF password protection and custom filenames for exports can be configured without control add-ins
- Report layouts and request pages can be modified to change sorting, filters, and disable print/preview options
- Custom columns added via extension may not appear in exported layouts from the Report Layouts page

## Quotes

- "Custom columns/fields added via Report Extension not found in standard layouts exported from Report Layouts page" (Developers need to understand that extension-added fields behave differently in exported layouts, affecting customization strategies)
