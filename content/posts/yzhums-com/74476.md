# Dynamics 365 Business Central: How to add Item Attributes Factbox (9110, ListPart) to Item Ledger Entries page

[Read the post](https://yzhums.com/74476/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-07-02 · 374 words · tier community · reviewed (checked by Opus)

> Item attributes allow businesses to assign and search items by characteristics like height and model year. This post shows how to extend the Item Ledger Entries page with the Item Attributes Factbox using a page extension and the LoadItemAttributesData method triggered on record changes.

## Key points

- Item attributes enable storing and filtering items by customer-relevant characteristics
- The Item Attributes Factbox is a standard list part (9110) included on Item Card and Item List pages
- To add the factbox to other pages, use a page extension with the OnAfterGetCurrRecord trigger to call LoadItemAttributesData
- The factbox calculation happens dynamically in the trigger rather than through SubPageLink property

## Quotes

- "CurrPage.ItemAttributesFactBox.PAGE.LoadItemAttributesData("No.");" (Shows the key code pattern needed to dynamically load item attributes data in the OnAfterGetCurrRecord trigger)
