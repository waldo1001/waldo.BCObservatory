# Dynamics 365 Business Central Blog Series: Integrate Business Central with SharePoint

[Read the post](https://yzhums.com/63735/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-04-29 · 457 words · tier community · reviewed (checked by Opus)

> This is an index of a blog series on connecting Business Central with SharePoint. It covers BC28 external storage for document attachments with no customization, reading and uploading SharePoint files through AL and Graph API, saving reports to SharePoint manually or automatically, keeping attachments in SharePoint so they do not use BC capacity, and previewing many file types inside BC without a JavaScript control add-in.

## Key points

- Business Central 2026 wave 1 (BC28) supports storing document attachments outside the database without customization
- Files can be uploaded to and imported from SharePoint document libraries using AL code with Graph API
- Reports can be saved directly to SharePoint both manually and automatically via AL integration
- External attachment storage in SharePoint preserves Business Central database capacity
- Multiple file types (PDF, JPG, PPTX, DOCX, XLSX, TXT, CSV, MP4) can be previewed within Business Central without JavaScript control add-ins

- "How to import/read files from SharePoint (document library) to Business Central via AL (Graph API)" (Shows developers can integrate SharePoint content into Business Central using standard Graph API methods)
