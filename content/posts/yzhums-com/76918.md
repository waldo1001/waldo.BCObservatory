# Dynamics 365 Business Central: The AL Table Proxy Generator is distributed in the Microsoft.Dynamics.BusinessCentral.Development.Tools.Altpgen NuGet package (altpgen.exe missing from AL Language extension)

[Read the post](https://yzhums.com/76918/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-10-26 · 750 words · tier community · **unreviewed** (model text not yet checked)

> The AL Table Proxy Generator tool (altpgen.exe) is now distributed through the Microsoft.Dynamics.BusinessCentral.Development.Tools.Altpgen NuGet package instead of the AL Language extension, with support for .NET versions 8.0 and 10.0. The tool generates proxy tables for integrating Microsoft Dataverse tables into Business Central.

## Key points

- AL Table Proxy Generator moved from the AL Language extension to the Microsoft.Dynamics.BusinessCentral.Development.Tools.Altpgen NuGet package as the official distribution method.
- Tool supports multiple .NET versions (net8.0 and net10.0); users select the altpgen.exe matching their installed .NET version.
- Azure app registration must be configured as multi-tenant to authenticate with Dataverse; Dataverse table names are case-sensitive.
- Proxy tables act as integration connectors linking Business Central tables to Microsoft Dataverse columns, enabling cross-system data integration.

## Quotes

- "The AL Table Proxy Generator is distributed in the Microsoft.Dynamics.BusinessCentral.Development.Tools.Altpgen NuGet package now." (Indicates the official shift from bundled extension distribution to centralized NuGet package management for the tool.)
- "The app registered in the Azure Portal must support multi-tenant." (Critical configuration requirement to successfully authenticate Dataverse connections from altpgen.)
