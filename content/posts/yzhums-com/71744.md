# Business Central 2026 release wave 1 (BC28): Financial Reporting enhancements

[Read the post](https://yzhums.com/71744/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-04-07 · 434 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2026 wave 1 introduces enhancements to Financial Reporting that streamline report creation, distribution, and administration. Report authors can customize layouts and branding, users can automate report scheduling and run reports across dimensions, and administrators gain centralized control of defaults and audit logging.

## Key points

- Report authors can customize PDF outputs with company logos, override global defaults for negative number formats and logo placement
- Report users can schedule reports for distribution groups and run reports across all dimension values
- Administrators can set global defaults and monitor report usage through new audit logs
- Financial Reporting replaces the legacy Account Schedules feature with new dedicated APIs and standard financial report templates
