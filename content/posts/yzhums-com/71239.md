# Business Central 2026 release wave 1 (BC28): Add the Description 2 field to various pages to gain more insight (planning, routing, production order creation, and related processes)

> The Description 2 field is now available for personalization on multiple pages in Business Central 2026 release wave 1 (BC28), including production planning, routing, and production order creation pages. This field allows users to customize their workspace and display additional information across related manufacturing and planning processes.

## Key points

- Description 2 field added at table level and supported across planning, routing, and production order workflows
- Available for personalization on 17 pages including Production BOM Lines, Routing Lines, and Prod. Order Components
- Continues Microsoft's pattern of adding personalizable fields in major updates to improve data visibility
- Users can customize their workspace to display additional insight without page extensions
