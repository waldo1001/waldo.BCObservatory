# Dynamics 365 Business Central: Entering Quantities/Amounts by Calculation and Negative Numbers

[Read the post](https://yzhums.com/56173/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-08-06 · 334 words · tier community · **unreviewed** (model text not yet checked)

> Business Central supports entering calculations and negative numbers directly into decimal fields, functioning like a mini calculator. This feature works with basic arithmetic operations and combined formulas for quantities and amounts, but only applies to decimal data types.

## Key points

- Decimal fields accept mathematical expressions like 19+19, 41-9, 12*4, or 12/4 that calculate automatically
- Combined calculations work with parentheses like (2+3)*4 as long as there are no spaces in the formula
- Negative numbers can be entered as -20.5 or 20.5- with the final operator determining the sign
- Only decimal data type supports formulas; integer, text, and code fields do not
- Integer fields support negative numbers but text and code fields store formulas as literal text

## Quotes

- "When entering numbers into these fields, you can enter the formula instead of the sum quantity." (Explains the core capability that decimal fields accept formulas rather than just static values)
- "This can only be used for Decimal Data type." (Clarifies the important limitation that this feature is restricted to decimal fields only)
- "If the last character of the expression is a + or a - , the entire expression will be recorded with that sign." (Explains the rule for how negative numbers are determined in suffix notation)
