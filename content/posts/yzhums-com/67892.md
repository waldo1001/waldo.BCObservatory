# Business Central 2025 wave 2 (BC27): Add data fields to report layouts using Word add-in (new data picker)

[Read the post](https://yzhums.com/67892/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-10-03 · 555 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2025 wave 2 introduces a new data picker task pane in the Word add-in that simplifies adding data fields, repeaters, and items to report layouts through a tree structure interface instead of direct XML editing. This feature improves report creation productivity and reduces errors for layout authors.

## Key points

- New task pane in Word add-in enables intuitive insertion of data items, repeaters, and fields with a collapsible tree view
- Tooltips and metadata display help users navigate fields accurately and reduce errors during layout design
- Updated report Word layout XML now includes 'Obsolete State' attribute for Report Column and DataItem elements
- Data picker is available only in Word desktop version, not Word Online, due to missing features like content controls
