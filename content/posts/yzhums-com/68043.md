# Business Central 2025 wave 2 (BC27): Autofill contact details with Copilot

[Read the post](https://yzhums.com/68043/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-10-02 · 393 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2025 wave 2 introduces Copilot-powered autofill for contact details such as address, phone, email, and website. The feature searches the web using Bing to suggest field values, reducing data entry time and errors for all users.

## Key points

- Copilot autofill now searches the web for customer and vendor contact information using Bing Search
- Administrators must enable Bing Search on the Copilot & agent capabilities page to activate the feature
- The feature builds on the wave 1 autofill capability and offers better reliability and support for 20 additional languages
- Users can review and select suggested values before applying them to records

## Quotes

- "Copilot now automatically searches the web for information and provides suggestions for customer or vendor contact details such as address, phone, email, and website." (Explains the core capability that eliminates manual lookup of publicly available contact information)
- "To enable Copilot to get information from the web, administrators must first Enable Bing Search on the Copilot & agent capabilities page." (Clarifies the setup requirement for using the feature in production environments)

- Features: Autofill contact details with Copilot, Web search integration with Bing, Automatic field value suggestions, Multi-language support
