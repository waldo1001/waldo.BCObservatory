# Dynamics 365 Business Central: Generate Swiss QR Code without external services/APIs

[Read the post](https://yzhums.com/65522/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-06-27 · 394 words · tier community · reviewed (checked by Opus)

> Business Central includes a standard Swiss QR Code Helper codeunit that allows developers to generate QR codes natively without external APIs. The post demonstrates how to add a page action that generates a Swiss QR code from item data and saves it to the item picture.

## Key points

- The Barcode module in System Application provides 2D barcode support including QR codes since BC 2021 wave 2
- Codeunit 4113 'Swiss QR Code Helper' is the standard Microsoft method for generating Swiss QR codes
- QR codes can be generated directly in AL code using the Swiss QR Code Helper without external services
- Generated QR code images can be imported and stored as item pictures in the database

## Quotes

- "The barcode functionality lets you convert an alphanumeric value in a report dataset into a barcode on a generated report." (Establishes the core barcode capability available in Business Central for standard use cases)
- "If you just want to generate a Swiss QR Code, Microsoft has prepared a standard method for us." (Highlights that Swiss QR code generation is a supported feature without needing external services)
