# Business Central 2026 release wave 2 (BC29): Restrict global symbol downloads to a specific minor version

[Read the post](https://yzhums.com/76037/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-09-11 · 550 words · tier community · reviewed (checked by Opus)

> Business Central 2026 release wave 2 (BC29) introduces a new 'Global Sources Enforce Minor Version' setting that lets developers restrict global symbol downloads to a specific minor version during AL development. This complements the BC28 feature that enabled downloading symbols directly from Microsoft's global repository without requiring a running environment.

## Key points

- BC29 adds the 'Global Sources Enforce Minor Version' setting to constrain symbol downloads to a specific minor version (e.g., 26.0 matches only 26.0.x.x)
- When disabled (default), the latest version within the same major version is downloaded regardless of minor version
- Symbols can be downloaded from global sources using AL: Download symbols from global sources command with country/region code localization
- Symbol version is controlled through the application property in app.json file

## Quotes

- "When enabled, downloading symbols from global sources are constrained to the minor version specified in the app.json." (This explains the core functionality of the new BC29 feature that provides developers with precise control over which symbol versions they download.)
- "From Business Central 2026 release wave 1 (BC28), you can download them directly from Microsoft's global repository." (Context for the BC28 predecessor feature that removed the need for running environments to download symbols.)
