# Dynamics 365 Business Central: Quickly find the Tenant ID, Azure AD Instance, and Tenant Scope from the domain (tenant) name without signing in

[Read the post](https://yzhums.com/67043/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-08-26 · 295 words · tier community · reviewed (checked by Opus)

> This post explains how to find a Business Central tenant's ID, Azure AD instance, and tenant scope using Microsoft's Where's My Tenant web tool, which requires only the domain name and no sign-in credentials.

## Key points

- The Where's My Tenant tool allows querying Azure AD for tenant information without password authentication
- You can find the tenant GUID, verify if a tenant exists in Azure AD, and identify which Azure AD instance it resides in
- The tool works with various domain formats including onmicrosoft.com domains, custom domains, and supports special regions like US Government and China
- You can search either by tenant domain name or by entering the Tenant ID directly to find the Azure AD instance

## Quotes

- "Because this doesn't require a password, as long as you know the domain, you can view information such as Tenant ID." (Highlights the key advantage that the tool requires no authentication, making it accessible for quick lookups)
