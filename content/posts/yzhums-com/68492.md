# Business Central 2025 wave 2 (BC27): Use enhanced analysis assist with Copilot

[Read the post](https://yzhums.com/68492/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-10-20 · 431 words · tier community · reviewed (checked by Opus)

> Business Central 2025 wave 2 (BC27) introduces enhancements to the Copilot analysis assist feature, which helps users quickly create analysis views by describing their data needs in natural language instead of manual clicking. New capabilities include system permissions control, the ability to include fields from related tables, performance feedback, and date hierarchy pivoting.

## Key points

- Copilot analysis assist enables users to request data analysis views using natural language descriptions like 'show me vendors by location sorted by amount of purchases'
- New system permission in the Copilot System Features permission set controls access to the analysis assist feature
- Users can now ask Copilot to include fields from related tables in analysis views
- Immediate feedback is provided about performance impacts when designing analysis tabs, such as warnings about computed fields and export limitations
- Date hierarchy fields can now be pivoted in server-side data mode for better data exploration
