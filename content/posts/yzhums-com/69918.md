# Dynamics 365 Business Central: Cancelling a scheduled PTE update install (Next Major/Next Minor)

[Read the post](https://yzhums.com/69918/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-01-13 · 464 words · tier community · reviewed (checked by Opus)

> The post explains how to cancel a scheduled app update when deploying to the next version in Business Central. Since the Extension Installation Status page lacks a cancel action, the solution is to upload the same app version again to overwrite the scheduled installation details.

## Key points

- Re-uploading the same app version overwrites the original schedule, which is the workaround for cancelling a pending Next Minor or Next Major install
- The Extension Installation Status page has no cancel action for scheduled installs
- If the app contains next-version changes, the re-upload will fail to install on the current version, so extra steps are needed to prevent installation
- BC23 Apps Update Cadence lets environments auto-update apps with minor updates and schedule individual app updates
- A later update notes that BC29 adds cancelling scheduled PTE installs in the admin center

## Quotes

- "It's actually very simple, just upload same version again. This will overwrite the original schedule details." (Provides the direct solution to cancel scheduled app updates without a native cancel action)
- "Microsoft is introducing an environment-level setting that automatically updates all installed apps with every minor update, and lets you schedule individual app updates." (Explains the Apps Update Cadence feature that changed how app updates are managed starting in BC23)
