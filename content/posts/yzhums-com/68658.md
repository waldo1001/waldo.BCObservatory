# Dynamics 365 Business Central: How to set the minimum and maximum numeric values ​​for a field

[Read the post](https://yzhums.com/68658/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-10-30 · 526 words · tier community · **unreviewed** (model text not yet checked)

> Setting minimum and maximum numeric values for fields in Business Central can be done using MinValue/MaxValue properties or OnValidate triggers. The property-based approach validates only through the UI, while OnValidate triggers provide more control and validate application code changes.

## Key points

- MinValue and MaxValue properties restrict field values at the table and page control levels with built-in validation messages.
- Properties validate only UI changes; direct table updates via code bypass validation.
- OnValidate triggers on table fields run before page field triggers and allow custom range logic.
- Properties cannot enforce exclusive bounds; OnValidate triggers enable stricter constraints like greater-than-zero-only rules.
