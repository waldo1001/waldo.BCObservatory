# Dynamics 365 Business Central: How to add Marketing Text Factbox to Item List page

[Read the post](https://yzhums.com/72069/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-04-13 · 449 words · tier community · reviewed (checked by Opus)

> Adding a Marketing Text factbox to the Item List page requires a page extension that inserts the Entity Text Factbox Part and controls visibility using the Marketing Text codeunit. This customization lets users view AI-generated or custom marketing text directly from the list instead of only from the item card.

## Key points

- Marketing text differs from the Description field; it serves as rich promotional copy for web shops and customer communications
- The Entity Text Factbox Part (page 2011) can be added to any list or worksheet containing Item No. using a page extension
- Visibility is controlled via the Marketing Text codeunit's IsMarketingTextVisible method
- SetContext procedure must be called in OnAfterGetCurrRecord to populate the factbox with the correct item's marketing text
- AI-generated marketing text suggestions are available through Copilot as the easiest creation method
