# Dynamics 365 Business Central: How to add Notes (System Parts) from FactBox to a report

[Read the post](https://yzhums.com/69896/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-01-14 · 703 words · tier community · **unreviewed** (model text not yet checked)

> The post explains how to retrieve Notes stored in the Record Link system table and display them in Business Central reports. It demonstrates using the Record Link Management codeunit and AL code to read note blobs and add them to a report extension.

## Key points

- Notes, Links, and Summary are system parts defined using the systempart() keyword in pages
- Notes data is stored in system table 2000000068 Record Link as a Blob type associated through Record ID
- Use codeunit 447 Record Link Management and its ReadNote procedure to convert note blobs to text for reporting
- Report extensions can filter notes by Record ID and Type to display them in layouts

## Quotes

- "The note is stored in a Blob. Microsoft has prepared a standard conversion method for us in codeunit 447 Record Link Management." (Explains why you need special handling to retrieve notes and which codeunit provides the solution)
- "Please try to use the standard method for better performance." (Recommends best practice for reading note data instead of using InStream directly)
