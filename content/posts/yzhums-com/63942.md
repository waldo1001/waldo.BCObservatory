> The post presents two methods to preview Word (.docx) files in Business Central 2025 wave 1 without downloading: converting Word to PDF then previewing as PDF, or converting Word to HTML and displaying in a preview page. These approaches extend the native PDF preview feature to support Word documents.

## Key points

- Business Central 2025 wave 1 added native PDF preview in web client, but cannot preview other formats like Word
- First solution converts Word documents to PDF and leverages the built-in PDF preview capability
- Second solution converts Word to HTML and displays it using a custom preview page with WebPageViewer control
- Both methods avoid external APIs and control add-ins, using only native Business Central capabilities
- Example code provided for both approaches using Document Report Management codeunit
