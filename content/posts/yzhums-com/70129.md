# Dynamics 365 Business Central: How to check if the time zone supports daylight saving time (DST) via AL

[Read the post](https://yzhums.com/70129/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-01-23 · 346 words · tier community · **unreviewed** (model text not yet checked)

> This post explains how to check whether a time zone supports daylight saving time (DST) in Business Central using AL code. It demonstrates using the TimeZoneSupportsDaylightSavingTime method from codeunit 8720 to determine DST support and includes a practical page extension example.

## Key points

- Business Central stores all DateTime fields as UTC and converts them to user-specified time zones in the UI
- The standard Time Zone table does not include daylight saving time information
- Use codeunit 8720 'Time Zone' method TimeZoneSupportsDaylightSavingTime to check DST support for a time zone ID
- The example shows adding a DST support field to the Time Zones Lookup page using a page extension
