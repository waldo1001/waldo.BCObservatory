# Dynamics 365 Business Central: How to add or subtract hours from a DateTime field

[Read the post](https://yzhums.com/68755/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-01-21 · 269 words · tier community · **unreviewed** (model text not yet checked)

> Adding or subtracting hours from DateTime fields in Business Central can be done using the AddHoursToDateTime procedure from the Type Helper codeunit. This is useful for timezone conversions and date-time manipulations in AL code.

## Key points

- The Type Helper codeunit provides an AddHoursToDateTime procedure for simple hour arithmetic on DateTime fields
- Pass positive values to add hours and negative values to subtract hours
- This method is simpler than working with Duration data type when you only need to adjust hours
- Timezone conversions can be achieved by adding or subtracting hours based on the offset between UTC and the target timezone

- "DateTime - Duration = DateTime, DateTime + Duration = DateTime" (Explains the fundamental operations for working with DateTime and Duration data types in AL)
- "if you only need to add or subtract hours from a DateTime field, there's an even simpler method" (Highlights that AddHoursToDateTime is a convenient alternative to Duration calculations for hour-only adjustments)
