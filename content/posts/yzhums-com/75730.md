# Business Central 2026 release wave 2 (BC29): Show recently used in lookups

[Read the post](https://yzhums.com/75730/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-09-04 · 514 words · tier community · reviewed (checked by Opus)

> Business Central 2026 release wave 2 introduces a Recently Used feature in lookup dialogs that surfaces recently accessed records based on user activity signals, reducing clicks and accelerating workflows. The feature works at the table level across functional areas like Sales and Purchasing, reusing server intelligence that powers Autofill recommendations.

## Key points

- Lookup dialogs now display recently used records upfront, making it faster to select common values without searching
- Suggestions are personalized per user and based on usage signals collected by the platform, consistent with Autofill
- Recent records operate at the table level and cross functional areas, so items accessed in Sales Orders appear in Purchase Order lookups
- A new Recent button appears in lookup windows; clicking Search returns to standard search view
- Empty recent lists display nothing, but users can always browse and search the full record list

## Quotes

- "The suggestions are personalized to each user and are based on usage signals already collected by the platform." (Understanding that recommendations are personalized and reuse existing server intelligence helps explain consistency across Business Central.)

## Heads up

- gotcha: "If there are no recent search or usage records, this view will remain empty." (about version BC29)
