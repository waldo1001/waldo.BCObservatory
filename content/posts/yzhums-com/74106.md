# Dynamics 365 Business Central: How to create a new item from a picture/image (Out-of-the-Box)

[Read the post](https://yzhums.com/74106/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-06-09 · 559 words · tier community · reviewed (checked by Opus)

> Business Central has an out-of-the-box New from picture action, found under the arrow next to New on the Items page, that creates an item from an uploaded image. The image is analyzed to pick a fitting item category and suggest a template, the user fills in item attribute values, and on OK the item is created with the picture attached and a description based on the image file name.

## Key points

- New from picture sits in the dropdown next to New on the Items page; first use asks for confirmation
- The uploaded image is analyzed to choose a suitable item category and suggest a template; the category stays blank if nothing fits
- The user completes the item attribute values before confirming, and these are saved with the new item
- The new item gets the picture automatically, a description containing the source image name, and other fields from the chosen template

## Quotes

- "We can actually create an item directly from a picture/image." (This highlights the key feature being discussed - an alternative method to create items beyond the standard template approach.)
- "The system will automatically select the most suitable Category based on the image and suggest a Template to apply." (This explains the core automation benefit of the feature that saves time and reduces manual data entry.)
