# Business Central 2025 wave 1 (BC26): Running objects in actions defaults to UI descriptors on target object

[Read the post](https://yzhums.com/62513/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-05-02 · 383 words · tier community · reviewed (checked by Opus)

> Running objects in actions now defaults to UI descriptors (Caption, Tooltip, AboutText, AboutTitle) from the target object. This ensures consistency and allows existing actions to automatically benefit from descriptors defined on pages and reports without duplication.

## Key points

- In BC26, an action that only runs an object now defaults to the target object's Caption, Tooltip, AboutText and AboutTitle.
- Actions that use RunObject on a page or report pick up that object's AboutText and AboutTitle when the action does not set them. Role Explorer and Report Explorer show these descriptions as teaching tooltips.
- Reports now have a ToolTip property, and page actions that point to a report use the report's tooltip by default.
- Tooltip inheritance only works for reports, because pages have no Tooltip property. Tooltip also cannot be added through an extension (error AL0124), so only base objects that already define it pass it on.

## Quotes

- "On pages, actions that refer to reports will default to the Tooltip defined on the target report." (Highlights the specific addition of Tooltip support on reports to enable this consistency feature)

## Heads up

- gotcha: "Since the property 'tooltip' cannot be extended, if the standard does not add this property, it cannot be inherited." (about version BC26)

- Features: RunObject property defaults, UI descriptor inheritance, Caption defaults, Tooltip property on reports, AboutText defaults, AboutTitle defaults, Teaching tooltips in explorers
