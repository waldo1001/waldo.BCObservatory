# Business Central 2026 release wave 2 (BC29): Enable unified Copilot chat experience consistent with Microsoft Copilot (New Chat with Copilot)

[Read the post](https://yzhums.com/75811/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-09-07 · 580 words · tier community · reviewed (checked by Opus)

> Business Central 2026 release wave 2 introduces a unified Copilot chat experience that matches Microsoft 365 Copilot's interface and capabilities. Users can now interact with business data, web search results, and AI-powered assistance through a modern chat with features like temporary chat, model switching, agent mode, file uploads, and resizable windows.

## Key points

- BC29 replaces the custom-designed Chat with Copilot UI from BC24 with Microsoft 365 Copilot embedded in Business Central
- Opened from a new Copilot icon in the app bar; the chat combines Business Central data, web search and general knowledge
- Added capabilities include temporary chat, model switching, agent mode, image and file uploads, and resizing to nearly full screen
- Available to all Business Central users; Microsoft Copilot license holders and eligible Microsoft 365 business customers get extras such as Work IQ
- Its version follows Microsoft 365 Copilot since it uses it directly

## Quotes

- "Microsoft unified the experience by bringing Microsoft 365 Copilot directly into Business Central." (This explains the key improvement - eliminating the custom UI difference and providing consistency with other Microsoft 365 products.)
- "You can now upload images and files." (This highlights a new capability that extends the chat's functionality beyond text-only interactions.)
