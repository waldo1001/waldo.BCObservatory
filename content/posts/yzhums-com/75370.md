# Dynamics 365 Business Central: Database exports are now significantly faster and more reliable

[Read the post](https://yzhums.com/75370/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-08-21 · 674 words · tier community · reviewed (checked by Opus)

> Microsoft is rolling out an Admin Center update that makes Business Central database exports much faster and more reliable, with failures under 1% even for large environments. The Export History page is being removed: exports are now tracked on the Operations page, which also shows error details. Anyone reading export history through the Admin Center APIs should switch to the environment Operations endpoints.

## Key points

- Database exports are now significantly faster and more reliable with failure rates below 1%
- Export History page is being removed; export progress tracking moves to the Operations page
- Admin Center APIs for export history must migrate to environment Operations endpoints
- BACPAC files are exported to Azure storage containers via Admin Center

## Quotes

- "database exports are now significantly faster and more reliable, with a failure rate below 1%" (This shows the key improvement that directly impacts administrators managing SaaS environments)
- "export progress can now be tracked from the Operations page, alongside other environment operations" (This indicates the architectural change admins need to adopt for monitoring exports)
- "If you're using Admin Center APIs to get database export history, please migrate to the environment Operations endpoints instead" (This is an actionable requirement for API users to update their integration code)

## Heads up

- breaking: "If you're using Admin Center APIs to get database export history, please migrate to the environment Operations endpoints instead." (about version BC28.4, version 2026 wave 1)
- gotcha: "The dedicated Export History page in the Admin Center is being removed, and export progress can now be tracked from the Operations page." (about version BC28.4, version 2026 wave 1)
