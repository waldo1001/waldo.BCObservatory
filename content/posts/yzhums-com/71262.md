# Business Central 2026 release wave 1 (BC28): Run AL objects and open record references using fully qualified names (Support for namespaces and fully qualified names)

[Read the post](https://yzhums.com/71262/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-03-09 · 358 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2026 release wave 1 (BC28) adds support for namespaces and fully qualified names in AL, allowing developers to run codeunits, pages, and reports and open table references using fully qualified names instead of numeric IDs. This feature helps organize code into logical groups and prevents naming conflicts when libraries are combined.

## Key points

- New method overloads enable running codeunits, pages, and reports using fully qualified names like 'Microsoft.Sales.Posting."Sales-Post"'
- RecordRef.Open can now be invoked with the fully qualified name of a table
- Record and RecordRef instances expose a new FullyQualifiedName property
- Namespaces organize code into logical groups and hierarchies to prevent naming conflicts and enable name reuse across different contexts

## Quotes

- "Namespaces are used to organize code into logical groups and hierarchies, which can prevent naming conflicts that can occur when libraries are combined." (Explains the core benefit of namespaces for managing code complexity and library integration in Business Central development)
