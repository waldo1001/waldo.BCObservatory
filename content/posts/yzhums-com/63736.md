# Dynamics 365 Business Central Blog Series: FlowFields

[Read the post](https://yzhums.com/63736/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-04-30 · 550 words · tier community · **unreviewed** (model text not yet checked)

> This series covers FlowFields, a powerful feature in Business Central that calculates values (sum, average, count, min, max, exist, lookup) from related tables. Articles discuss how FlowFields work, extending them, using FlowFilters, handling permissions, managing drill-downs, and new features in BC26 like selective calculation and the SetAutoCalcFields method.

## Key points

- FlowFields perform calculations (sum, average, count, min, max, exist, lookup) on related table data without storing values
- FlowFilters allow filtering FlowField totals on lists, with support for default filter settings
- Users lacking read permissions on source tables see blank FlowField values
- BC26 introduces selective FlowField calculation for visible fields and SetAutoCalcFields method on RecordRef
- FlowFields cannot be nested (based on other FlowFields) in queries
