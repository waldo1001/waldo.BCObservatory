# Dynamics 365 Business Central Blog Series: FlowFields

[Read the post](https://yzhums.com/63736/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-04-30 · 550 words · tier community · reviewed (checked by Opus)

> An index of blog articles on FlowFields in Business Central. It covers the calculation types (sum, average, exist, count, min, max, lookup), whether standard FlowFields can be extended, a query error when a FlowField is based on another FlowField, disabling drill-downs, checking in AL whether a field is a FlowField, read permissions, default FlowFilters on lists, and two BC26 changes.

## Key points

- FlowFields support sum, average, exist, count, min, max and lookup calculations.
- Putting a FlowField that is based on another FlowField into a query column list causes an unsupported error.
- AL code can check a field's class to tell whether it is a FlowField, and drill-downs on FlowFields can be disabled.
- A default Filter totals by (FlowFilter) setting can be applied to lists.
- BC26 calculates values only for visible FlowFields and adds SetAutoCalcFields to RecordRef.
