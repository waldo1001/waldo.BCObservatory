# Dynamics 365 Business Central: Do users really need permissions for Temporary Tables? (Permissions and temporary tables)

[Read the post](https://yzhums.com/22035/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-08-06 · 504 words · tier community · reviewed (checked by Opus)

> Temporary tables in Dynamics 365 Business Central do not require Table Data permissions because their data exists only in memory. Users need Execute permission on the Table object and Read permission on Table Data for regular tables to open a page, but temporary tables bypass the Table Data permission requirement.

## Key points

- Temporary tables are stored only in memory and do not modify the database, so they do not require Table Data permissions
- To open a page in Business Central, users typically need three permission types: Table Data, Table object, and Page
- Table Data permissions control access to data (Read, Insert, Modify, Delete), while Table object permissions control access to the object definition (Execute only)
- Setting SourceTableTemporary property to true on a page allows users without Table Data permissions to create, read, modify, and delete records

## Quotes

- "To open a page, you need at least three types of permissions: Table Data, Table, and Page." (This establishes the foundational permission structure needed for basic page access in Business Central.)
