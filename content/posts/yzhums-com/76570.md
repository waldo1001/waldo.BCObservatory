# Business Central 2026 release wave 2 (BC29): Retained DEV extensions (DEV extensions remain installed during environment update)

[Read the post](https://yzhums.com/76570/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-10-08 · 515 words · tier community · reviewed (checked by Opus)

> According to Microsoft in the BCLE, from Business Central 2026 release wave 2 (BC29), DEV extensions published from VS Code (or created with Designer) are no longer uninstalled when an environment is updated or relocated. They will behave like PTEs. The author could not test this yet because BC29.1 was not released.

## Key points

- Before BC29, DEV-scope extensions were removed on every minor or major update or relocation, so they had to be republished. Their data was kept.
- There are three extension scopes: Global (AppSource and Microsoft apps), PTE (tenant scope, uploaded via Extension Management or the admin center) and Dev (published from VS Code or made with Designer).
- Losing DEV extensions after an update was painful during UAT or client checks. Uploading them as PTEs is a workaround, but it does not suit code that changes often.
- The change comes from BCLE and is not yet in the release plan or AL changelog. The author has not verified it.

## Quotes

- "Dev extensions will now behave like PTEs and won't be uninstalled after an update." (This is the core feature change that eliminates the hassle of reinstalling DEV extensions during environment updates.)
- "Extensions that have been published from Visual Studio Code are removed when the environment is updated or relocated within our service." (This explains the previous behavior that BC29 now addresses, showing why the change is a significant improvement.)
- "It can be a hassle, especially during UAT or client verification when the feature suddenly disappears the next day." (Illustrates the practical pain point that this feature eliminates for developers and consultants during testing cycles.)

## Heads up

- gotcha: "extensions published via Visual Studio Code were previously removed during environment updates or relocations" (about version BC29)
