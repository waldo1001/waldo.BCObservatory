# Dynamics 365 Business Central: Create an extensibility request on BCApps (ALAppExtensions is being retired)

[Read the post](https://yzhums.com/75294/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-08-31 · 346 words · tier community · reviewed (checked by Opus)

> The ALAppExtensions repository on GitHub is being retired effective September 1, 2026, and extensibility requests including event requests are moving to BCApps. The post explains how to submit requests in the new location and provides guidance on writing effective extensibility requests.

## Key points

- ALAppExtensions repository will stop accepting new issues on September 1, 2026 and become read-only on October 19, 2026
- All extensibility requests including event requests must now be submitted through BCApps instead
- Existing issues and links in the old repository remain accessible and will not be deleted
- When requesting events, follow best practices like passing records rather than exposing specific field lengths and avoiding variants in event signatures

## Quotes

- "From 1 September 2026 you can no longer create issues here. Extensibility requests, including event requests, move to BCApps." (This is the critical deadline for the migration that developers must follow to continue submitting extensibility requests.)
- "Nothing is deleted - all issues and links keep working." (This reassures developers that historical requests and documentation will remain accessible after the repository is archived.)
- "Pass records rather than expose a specific length of the text field, or many fields from the record." (This is a best practice guideline for writing effective extensibility requests that will be accepted.)

## Heads up

- breaking: "From 1 September 2026 you can no longer create issues here." (about other ALAppExtensions)
- breaking: "You can't change existing variables because that would cause a breaking change."

## Context

- Features: Extensibility requests, Integration events, External functions, Event signatures, Temporary tables, Argument tables
