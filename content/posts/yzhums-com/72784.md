# Dynamics 365 Business Central: Microsoft now displays the full name of the Country/Region when creating a new environment

[Read the post](https://yzhums.com/72784/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-05-11 · 299 words · tier community · reviewed (checked by Opus)

> The Business Central Admin Center now displays the full country/region name instead of abbreviations when creating new environments. This improvement simplifies environment setup by eliminating the need to reference external mapping tables to understand country codes.

## Key points

- Business Central Admin Center now shows full country/region names during environment creation instead of abbreviations
- The country selection determines both the localization and Azure region for the environment
- Administrators can create environments for any supported country/region in any available version
- Manual input is supported for country selection
