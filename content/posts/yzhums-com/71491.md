# Business Central 2026 release wave 1 (BC28): Allow Posting From/To DateFormula (A new way to specify posting periods)

[Read the post](https://yzhums.com/71491/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-03-16 · 858 words · tier community · reviewed (checked by Opus)

> Business Central 2026 wave 1 introduces Allow Posting From/To DateFormula fields that let you define posting periods using dynamic date formulas (like 'CM' for current month) instead of manually updating fixed dates. This replaces the need for constant manual updates to posting date restrictions.

## Key points

- DateFormula fields calculate posting boundaries relative to the work date, eliminating manual date maintenance each period
- Formulas support relative date expressions combining letters (C, D, W, M, Q, Y) and numbers (e.g., 'CM+1M' for current month plus one month)
- The feature applies to both General Ledger Setup and User Setup, allowing company-wide and user-specific posting period rules
- The two methods are mutually exclusive per field, but you can mix static dates and formulas across different fields for flexible control

## Quotes

- "This formula is calculated based on the 'Work Date' from My Settings, not the system's 'Today' date." (Critical implementation detail ensuring consistency with existing posting period behavior and preventing date mismatches.)
