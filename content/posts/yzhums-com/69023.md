# Dynamics 365 Business Central: How to show Experience Tier (Essential or Premium) on the Companies (list page)

[Read the post](https://yzhums.com/69023/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-11-18 · 494 words · tier community · reviewed (checked by Opus)

> This post explains how to add a visible Experience Tier column (Essential or Premium) to the Companies list page, since this setting is not directly displayed by default. The solution uses AL code with a page extension to retrieve and display the experience tier for each company.

## Key points

- The Experience tier is not a field on the Company table (2000000006) or the Company Information table (79). The Company Information page computes it as a variable when the page opens.
- The standard logic only returns the tier of the current company, so it is rewritten to work for each company row.
- A page extension on Companies adds a read-only Experience column, filled in OnAfterGetRecord.
- The code reads the Experience Tier Setup record for each company name with RecordRef and FieldRef, then fills a temporary Experience Tier Buffer and picks the selected tier.
