# Dynamics 365 Business Central: How to show Experience Tier (Essential or Premium) on the Companies (list page)

[Read the post](https://yzhums.com/69023/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-11-18 · 494 words · tier community · **unreviewed** (model text not yet checked)

> This post explains how to add a visible Experience Tier column (Essential or Premium) to the Companies list page, since this setting is not directly displayed by default. The solution uses AL code with a page extension to retrieve and display the experience tier for each company.

## Key points

- Experience Tier is stored in the Experience Tier Setup table, not in the Company table or Company Information page
- The Experience setting controls which features users can access (Essential vs Premium functionality)
- A page extension on the Companies list uses the Experience Tier Setup table to retrieve and display the tier for each company
- The code uses RecordRef and FieldRef to dynamically read experience tier values from the Experience Tier Setup record
