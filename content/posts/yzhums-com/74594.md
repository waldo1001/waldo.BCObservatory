# Dynamics 365 Business Central Cloud: Production vs. Sandbox Environments – Key Differences

[Read the post](https://yzhums.com/74594/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-07-15 · 1038 words · tier community · **unreviewed** (model text not yet checked)

> Production and sandbox environments in Business Central have distinct purposes and capabilities. Production environments run on dedicated Azure performance tiers for daily business operations, while sandboxes are for testing and development. Key differences include performance characteristics, debugging and extension deployment options, backup/restore capabilities, and feature preview availability.

## Key points

- Production environments are deployed on dedicated Azure performance tiers ensuring high availability, while sandboxes share different performance tiers and are unsuitable for performance benchmarking
- Sandbox environments support direct Visual Studio Code debugging and extension deployment, but production environments only allow limited snapshot debugging
- Production environments can be restored to either production or sandbox, while sandbox environments can only be restored to sandbox
- Sandbox environments can preview new functionality ahead of official release, and Microsoft sometimes releases sandbox-only features for testing before production availability
- Premium and Essential subscriptions include one free production environment and three free sandbox environments per customer
