# Dynamics 365 Business Central: How to check the font of a standard report

[Read the post](https://yzhums.com/75007/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-07-29 · 223 words · tier community · reviewed (checked by Opus)

> To see which fonts a standard Business Central report uses, export its layout file, either from the request page's Report Layout menu or from the Report Layouts page. The method works the same for Word, RDLC and Excel layouts. Business Central online only has fonts pre-installed on its servers, and custom fonts cannot be uploaded.

## Key points

- Export report layouts through the request page using the three-dot menu next to Report Layout
- Business Central servers have pre-installed fonts that cannot be customized with uploads for security and legal reasons
- The same export method works for Word, RDLC, and Excel layout formats
- You can also export layouts directly from the Report Layouts page if you know the Report ID or Name

## Quotes

- "For security and legal reasons, you cannot upload custom fonts to the Business Central environment." (Explains the constraint that makes exporting and checking existing fonts necessary)
- "It's very simple. This example uses a Word layout, but you can use the exact same method for RDLC and Excel layouts." (Confirms the export method is consistent across all report layout types)

## Heads up

- warning: "For security and legal reasons, you cannot upload custom fonts to the Business Central environment."
