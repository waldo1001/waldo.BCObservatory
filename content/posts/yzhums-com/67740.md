# Business Central 2025 wave 2 (BC27): Use alternative posting groups for employees

[Read the post](https://yzhums.com/67740/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-09-18 · 398 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2025 wave 2 introduces the ability to use alternative posting groups for employees, allowing users to post payable and receivable transactions to different general ledger accounts than those specified on the default employee posting group. This feature is controlled via the Allow Multiple Posting Groups toggle on the Human Resources Setup page and the Employee Card page.

## Key points

- Users can now change the default employee posting group during journal or payment document posting by enabling Allow Multiple Posting Groups
- Controllers define policies for posting transactions and accountants can select alternative posting groups when posting
- Alternative posting groups can be specified on the Employee Posting Group page using the Alternative Groups action
- The feature supports scenarios like routing employee travel expenses to different financial accounts than regular payroll

## Quotes

- "Controllers can define policies for posting these transactions, and accountants can change them during posting." (Shows the role-based workflow where controllers set policies and accountants implement alternatives at posting time)
