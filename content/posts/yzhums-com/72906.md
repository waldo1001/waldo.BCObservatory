[Read the post](https://yzhums.com/72906/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-05-14 · 381 words · tier community · reviewed (checked by Opus)

> In Business Central 2026 release wave 1, newly added standard extensions like External Storage for Document Attachments are not automatically installed in upgraded environments due to a change where uninstalled apps remain uninstalled. Partners must manually install missing extensions using direct URLs or AppSource.

## Key points

- New standard extensions are not automatically installed during environment upgrades to BC28
- Microsoft changed behavior so uninstalled apps remain uninstalled after upgrades
- Missing extensions can be installed manually via direct URL using the extension's App ID
- Standard extensions will be available on AppSource for one-click installation
