# Business Central 2026 release wave 1 (BC28): Manage database index usage and cost per company (View index and Turn off indexes)

[Read the post](https://yzhums.com/71379/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-03-12 · 585 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2026 wave 1 introduces the ability to view database index details in the UI and selectively disable non-unique indexes per company to reduce storage costs and improve write performance. This feature helps administrators and developers optimize database usage directly from the Database Index Information page.

## Key points

- The new Database Index Information page shows per-index details including storage usage, SQL Server statistics, and index type
- Non-unique indexes with low usage can be disabled per company to reduce storage costs and improve write performance
- Unique indexes, primary keys, SIFT, and systemid indexes are protected from disabling
- Disabling an index takes effect immediately while enabling is queued for the next scheduled midnight maintenance process

## Quotes

- "You can turn off non-unique indexes with low usage to reduce storage costs and improve write performance." (This is the core capability that helps organizations optimize their database resources by selectively disabling underutilized indexes.)
- "Unique indexes, primary keys, SIFT, and systemid indexes are protected from disabling." (This explains important guardrails that prevent accidental disabling of critical indexes that maintain data integrity.)
- "Disabling an index takes effect immediately. Enabling an index is queued for the next scheduled midnight process." (Understanding the timing differences between disabling and enabling indexes is crucial for operational planning.)
