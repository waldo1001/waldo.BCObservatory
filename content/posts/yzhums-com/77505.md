# Business Central 2027 wave 1 (BC30): Remove ability to expose a Microsoft page as an OData endpoint (Disable OData web services on Microsoft UI pages)

[Read the post](https://yzhums.com/77505/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-11-18 · 725 words · tier community · reviewed (checked by Opus)

> Business Central version 30 (2027 wave 1) removes the ability to expose Microsoft pages as OData endpoints because UI pages should not be treated as APIs and are subject to breaking changes. Customers using OData integrations on Microsoft pages must copy the page source code into their own extensions before upgrading, or consider alternative integration methods like API pages or Data Mirroring to Microsoft Fabric.

## Key points

- Microsoft pages can no longer be exposed as OData endpoints starting in BC v30, affecting all pages from Microsoft publisher apps including Base Application and System Application
- UI pages are not designed as APIs and may change without warning, making them unreliable for integration endpoints
- Customers must copy Microsoft page source code into their own extensions and republish as OData endpoints to maintain existing integrations
- API pages or Data Mirroring to Microsoft Fabric are recommended alternatives for data integration instead of OData on UI pages

## Quotes

- "A UI page isn't an API and therefore changes to them can happen in a release without this being considered a breaking change." (This principle justifies why Microsoft is removing OData exposure on pages - pages are UI components, not stable API contracts)
- "Starting in version 30, it's no longer possible to expose a Microsoft page as an OData endpoint." (This is the core removal that customers must prepare for before upgrading to BC v30)

## Heads up

- breaking: "Starting in version 30, it's no longer possible to expose a Microsoft page as an OData endpoint." (about version 30, version 2027 wave 1)
- warning: "A change in the UI can be felt as a breaking change for an integration built on this endpoint."
- warning: "make sure to recreate the relevant pages in your own extension and publish them as OData endpoints before upgrading to Business Central v30." (about version 30)

## Context

- Features: OData web services, UI pages, Microsoft pages exposure, API pages, Data Mirroring to Microsoft Fabric
- Versions: 30.0, 2027 wave 1
