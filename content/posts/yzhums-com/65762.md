# Dynamics 365 Business Central: How to quickly check whether the user has write (Insert, Delete, and Modify) permission for the table in AL

[Read the post](https://yzhums.com/65762/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-07-15 · 431 words · tier community · reviewed (checked by Opus)

> This post explains how to use the Record.WritePermission() method in AL to check whether a user has write permissions (Insert, Delete, Modify) for a table before executing operations, allowing developers to perform alternative actions based on permission levels instead of triggering errors.

## Key points

- WritePermission() method checks if a user can write to a table, including full and partial write permissions with security filters
- Without Insert permission, New actions are grayed out; without Modify permission, card pages open in View mode only
- Developers can use WritePermission() to perform different operations conditionally based on user permissions
- Example uses WritePermission() to open Vendor Card for users with write access, Customer Card for others

## Quotes

- "Record.WritePermission() Method: Determines whether a user can write to a table." (This is the core method that enables developers to check write permissions before executing operations)
- "A write permission consists of Insert, Delete, and Modify permissions." (Clarifies what constitutes write permission, helping developers understand the scope of the check)
