# Dynamics 365 Business Central: To automatically delete archived versions (For example, have 10 versions and want to keep a copy of the latest)

[Read the post](https://yzhums.com/69366/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-01-07 · 649 words · tier community · **unreviewed** (model text not yet checked)

> Business Central allows you to automatically delete archived versions of sales, purchase, and service documents using retention policies, while optionally keeping the most recent version. Retention policies help administrators manage data cleanup by deleting archived documents past their expiration date based on the most recent archived version's date.

## Key points

- Archive sales, purchase, service, and project documents automatically when documents are changed, deleted, printed, emailed, or posted
- Use retention policies to automatically delete old archived versions while keeping the most recent one
- Original documents must be deleted before their archived versions can expire; archived versions don't expire if the original still exists
- Specify retention periods and define which archive tables to include in cleanup policies from the setup page

## Quotes

- "If the original document isn't deleted, Business Central you can't delete the archived versions." (This is a critical constraint when setting up retention policies; original documents must be removed before archives can expire)
- "When you set up the retention policy, you can specify that you want the policy to delete all archived versions except the most recent." (This capability directly addresses the user requirement to keep only the latest version while cleaning up historical archives)
- "Retention policies let administrators define how long they want to store data." (Core feature that enables automated cleanup without manual intervention, reducing storage and maintaining compliance)
