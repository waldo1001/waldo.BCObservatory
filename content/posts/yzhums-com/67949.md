# Business Central 2025 wave 2 (BC27): Editable fields in page customizations

[Read the post](https://yzhums.com/67949/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-09-30 · 407 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2025 wave 2 (BC27) introduces the ability to make page fields defined in page customizations editable, a capability previously unavailable. This requires the AllowInCustomizations property to be set to AsReadWrite on the source table field, and it applies only to fields declared in table extensions, not base table fields.

## Key points

- Page customizations can now mark fields as editable instead of always being read-only, addressing a previous limitation
- The AllowInCustomizations property must be explicitly set to AsReadWrite on source table fields to enable editing in customizations
- This feature requires runtime version 16.0 or greater and applies only to fields in table extensions, not base table fields
- Standard fields default to ToBeClassified, which prevents making them editable in customizations unless the property is modified

## Quotes

- "You can now make page fields defined in page customizations editable. Previously, such fields were always read-only." (This addresses a key limitation in page customizations that previously restricted all customization fields to read-only status.)
