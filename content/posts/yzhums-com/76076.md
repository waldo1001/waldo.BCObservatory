# Business Central 2026 release wave 2 (BC29): Financial report changes are now always logged

[Read the post](https://yzhums.com/76076/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-09-15 · 403 words · tier community · reviewed (checked by Opus)

> Financial report changes in Business Central 2026 release wave 2 (BC29) are now automatically logged in the change log without requiring manual setup, making it easier to audit modifications to financial row, column, and report definitions.

## Key points

- BC29 automatically writes changes to financial report row, column and report definitions into the change log
- There is no need to turn on or configure the Change Log manually for this
- This helps trace accidental edits made directly to standard financial reports, for example a changed Display Title
- This logging is separate from the new audit log

## Quotes

- "Changes to financial row, column, and report definitions are automatically recorded in the change log for easier auditing." (This explains the core feature that eliminates manual setup and automatically protects against accidental changes to financial reports)
- "This doesn't even require manually turning on the Change Log." (Emphasizes the key benefit that the feature works out of the box without additional configuration steps)
