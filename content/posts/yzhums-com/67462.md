# Business Central 2025 wave 2 (BC27): Understand how each Copilot and agent capability is billed (Billing Type)

[Read the post](https://yzhums.com/67462/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-09-08 · 557 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2025 wave 2 introduces a Billing Type column on the Copilot and Agent Capabilities page to clarify which AI capabilities are billed by Microsoft, by partners, or not at all. Developers must manually set the billing type when registering capabilities, and the system validates this setting against actual Azure OpenAI resource usage.

## Key points

- A new Billing Type column shows whether each Copilot or agent capability is billed by Microsoft, billed by a partner, or not consumption-billed
- Copilot in Business Central is included with the license at no extra cost, though fair-use policies or pricing may be introduced later
- Developers must manually set the billing type using RegisterCapability() or ModifyCapability() procedures and ensure it matches actual resource usage
- The system validates billing type settings at runtime against which Azure OpenAI resources the capability actually uses

## Quotes

- "Copilot in Business Central is included with your Business Central license at no extra cost." (Clarifies that users get Copilot as part of their license, addressing a common question about additional costs)
- "The billing information is set up manually by the app developer - it's not automatically inferred at runtime." (Developers must explicitly declare billing types; this won't happen automatically, placing responsibility on them for accuracy)
- "At runtime, the billing type setting is validated against which Azure OpenAI resources the capability actually tries to use." (The system checks that declared billing types match actual behavior, preventing misalignment between configuration and real usage)
