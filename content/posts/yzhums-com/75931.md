# Business Central 2026 release wave 2 (BC29): ToolTip and ToolTipML properties are now available on pages

[Read the post](https://yzhums.com/75931/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-09-09 · 338 words · tier community · reviewed (checked by Opus)

> ToolTip and ToolTipML properties are now available at the page object level in BC29. Pages can define tooltips that navigation actions inherit automatically if no explicit tooltip is set on the action itself.

## Key points

- ToolTip and ToolTipML can now be set at the page object level
- A navigation action whose RunObject is a page inherits that page's tooltip when the action has no tooltip of its own
- The inheritance works the same way it already does for reports
- ToolTip and ToolTipML cannot both be set on one page (AL0428)
- Page ToolTip needs runtime 18.0 or later (AL0666)

## Quotes

- "This mirrors the existing behavior for reports." (Shows consistency with prior implementations, helping developers understand the feature by analogy.)
- "Cannot specify ToolTipML and ToolTip property at the same time." (Critical constraint developers must follow to avoid conflicts when implementing multilingual tooltips.)

## Heads up

- warning: "Cannot specify ToolTipML and ToolTip property at the same time. Use only the ToolTip property." (about page page, version BC29)
- warning: "'ToolTip' is not available in runtime version '17.0'. The supported runtime versions are: '18.0' or greater." (about page page, version BC29)
