# Business Central 2026 release wave 2 (BC29): ToolTip and ToolTipML properties are now available on pages

[Read the post](https://yzhums.com/75931/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-09-09 · 338 words · tier community · **unreviewed** (model text not yet checked)

> ToolTip and ToolTipML properties are now available at the page object level in BC29. Pages can define tooltips that navigation actions inherit automatically if no explicit tooltip is set on the action itself.

## Key points

- ToolTip and ToolTipML properties can be set directly on page objects
- Navigation actions inherit the page's tooltip if no tooltip is explicitly specified on the action
- This behavior mirrors existing functionality for reports and table fields
- Cannot use both ToolTipML and ToolTip simultaneously on the same page
- Requires runtime version 18.0 or greater

## Quotes

- "This mirrors the existing behavior for reports." (Shows consistency with prior implementations, helping developers understand the feature by analogy.)
- "Cannot specify ToolTipML and ToolTip property at the same time." (Critical constraint developers must follow to avoid conflicts when implementing multilingual tooltips.)
