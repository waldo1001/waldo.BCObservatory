# Dynamics 365 Business Central: Comparing Years (Year-Over-Year) in Analysis Mode: A Simple 4-Step Guide

[Read the post](https://yzhums.com/69961/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-02-17 · 500 words · tier community · **unreviewed** (model text not yet checked)

> This post explains how to create year-over-year comparison reports in Business Central using Analysis Mode, a feature that enables pivot table creation and data analysis directly on list pages without requiring separate reporting or customization. The post walks through a four-step process using General Ledger Entries as an example and covers feature evolution from BC22 through BC26.

## Key points

- Analysis Mode allows users to create pivot tables and analysis views on list pages without customization or separate report running
- Year-over-year analysis compares current year data against same periods in previous years to evaluate metrics over time
- The four-step process involves enabling Pivot Mode, setting display values, dragging the Posting Date Year to column labels, and grouping rows
- Analysis results can be shared via copy link or exported to Excel, and Copilot can assist with creating analysis tabs

## Quotes

- "Comparing Years report (Year-Over-Year or YoY Analysis) simply means comparing year-over-year or year-on-year data." (This clarifies the business purpose of the analysis technique being taught)
