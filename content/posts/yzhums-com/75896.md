# Business Central 2026 release wave 2 (BC29): New system flow fields (SystemCreatedByUserName, SystemCreatedByFullName, SystemModifiedByUserName, and SystemModifiedByFullName)

[Read the post](https://yzhums.com/75896/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-09-08 · 471 words · tier community · reviewed (checked by Opus)

> Business Central 2026 release wave 2 (BC29) introduces four new system FlowFields (SystemCreatedByUserName, SystemCreatedByFullName, SystemModifiedByUserName, SystemModifiedByFullName) that display the username and full name of users who created or modified records, complementing the existing GUID-based audit fields.

## Key points

- BC29 adds four system FlowFields to normal and temporary tables: created/modified by user name (Text[50]) and full name (Text[80])
- They complement the GUID-based SystemCreatedBy and SystemModifiedBy fields, which earlier needed extra code to show a user name
- Values do not appear in Page Inspection because FlowFields are only calculated when visible
- The fields can be shown via profile page customization, Analysis Mode, or AL code

## Quotes

- "If we simply add it to the page, this will only show the GUID (User Security Id)." (Highlights the problem the new FlowFields solve - the old system fields displayed only GUIDs without additional processing)
- "But finally, in this major release (BC29), Microsoft added these new system FlowFields: SystemCreatedByUserName, SystemCreatedByFullName, SystemModifiedByUserName, and SystemModifiedByFullName!" (Marks the significant milestone of these fields finally being available as built-in FlowFields after being needed for years)

## Heads up

- gotcha: "Due to the feature described below, the value cannot be viewed in Page Inspection." (about version BC29, version 2026 release wave 2)
