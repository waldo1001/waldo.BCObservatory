# Dynamics 365 Business Central: How to monitor User AI Consumption Data within BC  (Agent consumption overview)

[Read the post](https://yzhums.com/72431/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-04-22 · 412 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 27.5 allows users to track Copilot Credit consumption directly within the application through the Agent Consumption Overview page, eliminating the need to check the Power Platform Admin Center separately.

## Key points

- Copilot Credits are billing units measuring AI usage for agent capabilities on a consumption basis
- The Agent Consumption Overview page shows credit consumption per task step and total credits used in a period
- Users can search for 'Agent' and select an agent to view its consumption data with a dedicated View consumption data option
- The full consumption log is accessible by clicking on the Total task Copilot credits field for detailed tracking

## Quotes

- "This allows you to monitor each Agent's consumption status directly, eliminating the need to log into the Power Platform Admin Center." (Highlights the key advantage of the in-app feature for users managing their AI costs)
