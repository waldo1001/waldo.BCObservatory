# Dynamics 365 Business Central: How to check whether the current page/report is standard or customized

[Read the post](https://yzhums.com/41471/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-01-27 · 1130 words · tier community · reviewed (checked by Opus)

> This post explains how to determine whether a Business Central page or report is standard or customized using object ID ranges, page inspection, and performance profiler tools. It helps developers and partners quickly identify whether functionality has been extended or modified.

## Key points

- Object ID ranges show origin: 0-49,999 is base app, 50,000-99,999 is per-tenant customization, 100,000-999,999 is Microsoft localization, 1,000,000-69,999,999 is RSP and 70,000,000-74,999,999 is AppSource apps
- Page Inspection (Ctrl+Alt+F1) shows page and report IDs, and its Extensions tab lists extensions that add or extend the page or its source table; it does not show extensions for reports
- The AL profiler (VS Code since BC19, in-client since BC20) lists active apps and the call tree, but only detects custom code that actually runs during the recording
- Error details and the AL call stack, also available through View the last known error, show which extension objects were involved

## Quotes

- "The extension model is object-based; you create new objects, and extend existing objects depending on what you want your extension to do." (Explains the fundamental architecture behind identifying whether pages are standard or customized)
