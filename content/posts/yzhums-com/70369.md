# Dynamics 365 Business Central: Does the API support Multi-level Expand (Multi layers)

[Read the post](https://yzhums.com/70369/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-02-03 · 337 words · tier community · **unreviewed** (model text not yet checked)

> The Business Central REST API supports multi-level expand (nested data retrieval) using nested parentheses in $expand syntax, allowing you to retrieve related resources across multiple layers, and also supports combining multi-level expands with filters and field selection.

## Key points

- Multi-level expand uses nested parentheses syntax like $expand=salesOrderLines($expand=item($expand=itemCategory))
- You can expand multiple entities simultaneously and combine two-level expands with multi-level nested expands in a single query
- Filter expressions and $select clauses can be added at each expansion level to retrieve only necessary fields
- Each additional level of nesting requires an extra set of parentheses in the query structure

## Quotes

- "each additional level of expansion requires an extra set of parentheses: $expand=salesOrderLines($expand=item($expand=itemCategory))" (This clearly explains the syntax pattern for multi-level expand queries, essential for developers constructing nested API calls)
- "You can also expand multiple entities simultaneously, such as combining a two-level expand with a multi-level (three-level) nested expand." (Clarifies that developers can mix multiple expansion paths in a single query for efficient data retrieval)
- "you can also include a $select clause at each level to retrieve only the necessary fields" (Shows that optimization is possible by limiting returned fields at each nesting level, reducing payload size)
