# Dynamics 365 Business Central: How to quickly strip not supported chars in File Name via AL

[Read the post](https://yzhums.com/66461/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-08-14 · 245 words · tier community · **unreviewed** (model text not yet checked)

> Saving files from Business Central to external systems requires removing unsupported characters from file names. The post demonstrates using the StripNotsupportChrInFileName method from codeunit 419 to automatically clean file names before export.

## Key points

- Windows and other systems restrict certain characters in file names (like # % & * : < > ? / \ | } ~ etc.)
- Business Central allows entering any characters without restriction, creating a mismatch when exporting files
- Codeunit 419 'File Management' provides a built-in StripNotsupportChrInFileName method to sanitize file names
- An alternative method exists in codeunit 9458 'File Account Browser Mgt.' for the same purpose

## Quotes

- "When saving files in Windows or other systems, there are some characters that cannot be contained in file names." (Explains the root cause of the problem developers face when exporting BC data to external systems)
- "However, there is no such restriction when entering data in BC." (Highlights the gap between BC's permissive input and external systems' file naming restrictions)
