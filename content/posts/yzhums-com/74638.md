# Dynamics 365 Business Central: Don’t Forget the Layout! Essential Steps for Publishing Report Extensions

[Read the post](https://yzhums.com/74638/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-07-21 · 421 words · tier community · reviewed (checked by Opus)

> Report extensions in Business Central allow developers to add columns, data items, triggers, and layouts to existing reports. Instead of manually uploading layout files in the client, developers should include layout files in their source code and use the rendering section in the AL object to manage them alongside their code.

## Key points

- Report extensions let you extend existing reports by adding columns, data items, triggers, request pages, and new layouts
- The rendering section (available from BC20) allows specifying multiple named layouts in the AL object, with one set as default
- Layout files should be stored in a Layouts folder in source code and referenced in the rendering section, not manually uploaded after deployment
- Once published via the rendering section, layouts appear on the Report Layouts page with their extension association shown
- Layouts created directly on the Report Layouts page lack extension association and won't auto-publish when code updates

- Features: Report Extensions, Multiple Named Layouts, Rendering Section, Layout File Management, Request Page Extension, Data Item Extension
- Versions: BC20, 2022 wave 1
