# Business Central 2026 release wave 2 (BC29): Cancelling a scheduled PTE update install (Next Major/Next Minor) in admin center

[Read the post](https://yzhums.com/76546/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-10-20 · 459 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2026 wave 2 (BC29) adds the ability to cancel scheduled PTE (partner tradeable extensions) installation directly from the admin center using the new Manage updates feature, improving on the previous requirement to re-upload the same version to overwrite the schedule.

## Key points

- Starting with BC28.4, PTEs can be uploaded, installed, and managed directly in the admin center instead of through Extension Management.
- When scheduling a PTE installation from the admin center, you can now cancel it by clicking Manage updates and selecting Cancel scheduled install.
- Canceling removes the scheduled version from services and requires re-uploading the app file if you want to reschedule.
- The Operations page tracks the status of canceled installations and shows which user canceled them.

## Quotes

- "Starting from Business Central 2026 wave 1 (BC28.4), we can upload, install, and manage PTEs directly in the admin center." (Establishes the new capability introduced in BC28.4 that enables centralized PTE management without using Extension Management page.)
- "If we schedule the installation of a PTE using this new method (from admin center), it can now be canceled." (Highlights the key improvement in BC29 that solves a previous limitation where canceling scheduled installations required workarounds.)
- "Canceling the installation will remove this version of the PTE from our services. To reschedule the installation, upload this version again." (Clarifies the effect of cancellation and the required action if users want to reschedulule the same version.)
