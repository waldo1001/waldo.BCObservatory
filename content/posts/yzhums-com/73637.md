# Dynamics 365 Business Central: Hide and show list views

[Read the post](https://yzhums.com/73637/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-05-28 · 392 words · tier community · reviewed (checked by Opus)

> Users can save, hide, and show filtered views on Business Central list pages to control which views appear in the filter pane, with hidden views recoverable through Personalization mode.

## Key points

- Save filtered lists as views by entering a name in the filter pane; views persist across devices and browsers
- Hide views using the arrowhead menu to temporarily remove them from the filter pane without permanent deletion
- Preset views cannot be removed, only hidden
- Unhide hidden views through Personalization mode by selecting 'Show'
- Resetting views via 'Clear personalization' permanently deletes user-created views

## Quotes

- "The solution is actually very straightforward. We just need to make it visible again through the Personalization mode." (Explains how to recover hidden views when the Show action appears unavailable in the normal interface)

## Heads up

- gotcha: "after hiding the views, the user couldn't find the 'Show' action to bring them back"
- warning: "be aware that the views you added will be permanently deleted"
