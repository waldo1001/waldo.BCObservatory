# Dynamics 365 Business Central: AL Object Relations Visualizer (New VS Code extension)

[Read the post](https://yzhums.com/70705/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-02-19 · 247 words · tier community · reviewed (checked by Opus)

> The AL Object Relations Visualizer is a VS Code extension that creates interactive, force-directed graph visualizations of relationships between AL objects in Business Central projects. It helps developers understand code dependencies through color-coded nodes, clickable file navigation, and detailed tooltips showing field names, variable declarations, and relation types.

## Key points

- Provides force-directed graph visualization using D3.js to display AL object relationships
- Automatically scans workspace to find all AL objects and their dependencies
- Offers detailed tooltips with contextual information about field names, variables, and source tables
- Enables direct file opening by clicking nodes and color-codes objects by type for quick identification
