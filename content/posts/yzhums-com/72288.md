# Dynamics 365 Business Central: How to display a custom Application Version (e.g., from W1 28.0 to YUN ZHU 28.0)

[Read the post](https://yzhums.com/72288/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-04-17 · 253 words · tier community · reviewed (checked by Opus)

> Display a custom Application Version in Business Central by subscribing to the GetApplicationVersion event in codeunit 2000000001 Version Triggers. This technique allows you to modify the version string shown in Help & Support, useful for adding company names or custom identifiers to the default version display.

## Key points

- Subscribe to the GetApplicationVersion event in codeunit 2000000001 Version Triggers to customize the application version text
- The Help & Support page shows the standard version format like W1 28.0 with platform and application build numbers
- Use codeunit 9015 Application System Constants to retrieve the original version string programmatically
- Best practice is to append custom text to the original application version rather than replacing it entirely
