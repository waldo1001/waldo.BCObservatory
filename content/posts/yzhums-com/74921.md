# Dynamics 365 Business Central: Configure text search language for multilingual environments (Text Search Language Optimizer)

[Read the post](https://yzhums.com/74921/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-07-23 · 422 words · tier community · reviewed (checked by Opus)

> Text search language optimization in Business Central allows you to configure the search index for multilingual environments by selecting a primary data language. This improves search relevance and AI agent accuracy, though it requires reindexing all searchable data which should be done outside business hours.

## Key points

- Text search language optimization improves search result relevance when data is primarily in one language
- The setting applies environment-wide and affects all users and AI agents like Sales Order Agent
- Changing the language triggers a complete reindex of searchable data, which can take significant time depending on database size
- New and updated data uses the new language setting immediately, but existing data reindexing happens as a background process
