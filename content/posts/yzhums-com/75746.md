# Business Central 2026 release wave 2 (BC29): Preview images directly in web client

[Read the post](https://yzhums.com/75746/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-09-04 · 612 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2026 release wave 2 adds native support for previewing image attachments directly in the web client without downloading them first. This feature works across all Business Central areas and supports multiple image formats including JPEG, PNG, BMP, SVG, WEBP, and GIF.

## Key points

- Image attachments can be previewed in the web client using a specialized viewer similar to print preview
- Supported image formats include JPEG, JPG, PNG, BMP, SVG, WEBP, ICO, GIF, and AVIF, plus TIFF and TIF on Safari
- Images can be downloaded from the viewer or printed directly from the client
- Extension developers can add support using File.ViewFromStream or File.View methods
- GIF files can display as animated thumbnails in FactBox with support up to 48 frames

## Quotes

- "You can open image attachments in the Business Central web client without downloading the images first." (This is the core capability that improves user experience by eliminating the download step for viewing images.)
- "Extension developers must add support for this feature using File.ViewFromStream for Business Central online, or File.View for Business Central on-premises." (It explains the technical implementation path developers need to follow to enable image preview functionality.)
