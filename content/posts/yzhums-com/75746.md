# Business Central 2026 release wave 2 (BC29): Preview images directly in web client

[Read the post](https://yzhums.com/75746/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-09-04 · 612 words · tier community · reviewed (checked by Opus)

> BC29 (2026 release wave 2) lets users open image attachments in a web client viewer like the BC26 PDF preview, where they can also download or print them. Supported formats include JPEG, PNG, BMP, SVG, WEBP, ICO, GIF and AVIF, plus TIFF on Safari. In the preview, Incoming Documents still started a download, so the author shows a page extension that calls File.ViewFromStream to add an image view action.

## Key points

- Image attachments open in a viewer similar to print or PDF preview, and the image can be downloaded or printed from there
- Supported formats: JPEG, JPG, PNG, BMP, SVG, WEBP, ICO, GIF and AVIF (including animated), plus TIFF and TIF on Safari
- Extensions must opt in by calling File.ViewFromStream (online) or File.View (on-premises), which follow the same pattern as File.Download
- FactBox thumbnails can show animated GIFs of up to 48 frames, and clicking a thumbnail of an image or the first page of a PDF opens the viewer
- Works in Attached Documents but not yet in Incoming Documents in the preview; the sample adds a View Image action on the Incoming Document Attachments page

## Quotes

- "You can open image attachments in the Business Central web client without downloading the images first." (This is the core capability that improves user experience by eliminating the download step for viewing images.)
- "Extension developers must add support for this feature using File.ViewFromStream for Business Central online, or File.View for Business Central on-premises." (It explains the technical implementation path developers need to follow to enable image preview functionality.)
