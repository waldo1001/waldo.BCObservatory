# Dynamics 365 Business Central: Require users to enter a more detailed description when posting a journal line of type G/L Account (Omit Default Descr. in Jnl.)

[Read the post](https://yzhums.com/67275/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-10-23 · 336 words · tier community · reviewed (checked by Opus)

> The Omit Default Descr. in Jnl. field on G/L Account cards forces users to enter custom descriptions for journal lines instead of auto-filling with the account's default description. When this option is enabled, posting fails if the description field is left blank, improving audit trail quality.

## Key points

- Omit Default Descr. in Jnl. checkbox on the G/L Account Card stops the account description from being auto-filled on journal lines
- With the box checked, users must type their own description on general journal lines for that account
- Posting checks that every Description is filled and raises an error if one is blank
- Journal descriptions carry over to G/L entries, so better descriptions improve the audit trail
- Originally a Netherlands localization feature, it is also available in W1
