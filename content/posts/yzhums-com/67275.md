# Dynamics 365 Business Central: Require users to enter a more detailed description when posting a journal line of type G/L Account (Omit Default Descr. in Jnl.)

[Read the post](https://yzhums.com/67275/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-10-23 · 336 words · tier community · **unreviewed** (model text not yet checked)

> The Omit Default Descr. in Jnl. field on G/L Account cards forces users to enter custom descriptions for journal lines instead of auto-filling with the account's default description. When this option is enabled, posting fails if the description field is left blank, improving audit trail quality.

## Key points

- Enable 'Omit Default Descr. in Jnl.' on the G/L Account Card to prevent automatic description insertion
- Users must manually enter a description for journal lines when this setting is active
- System validation requires all description fields to be filled before posting journal lines
- Descriptions are stored in G/L entries for audit trail purposes
- This is a Netherlands localization feature also available in W1 version
