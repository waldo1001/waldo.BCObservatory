# Dynamics 365 Business Central: Remove obsolete permissions from all permission sets

[Read the post](https://yzhums.com/65999/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-07-28 · 380 words · tier community · **unreviewed** (model text not yet checked)

> Business Central provides a built-in feature to remove obsolete permissions from user-defined permission sets when database objects are deprecated. System permission sets cannot be edited through this feature, requiring manual cleanup in extensions instead.

## Key points

- Permission sets contain permissions for specific database objects and must be assigned to users for Business Central access
- When objects are marked as ObsoleteState = Removed during version updates, associated permissions must be cleaned up
- The Remove Obsolete Permissions action on the Permission Sets page automatically removes deprecated permissions from user-defined sets
- System permission sets are read-only and cannot use this feature, requiring manual cleanup or regeneration in extensions
- This feature removes specific permissions but cannot delete entire obsolete permission sets

## Quotes

- "On the Permission Sets page, choose the Remove Obsolete Permissions action." (This is the standard feature for cleaning up deprecated permissions from user-defined permission sets automatically.)
- "This feature removes permissions from a permission set, not the permission set itself." (Clarifies the scope of the feature to prevent misunderstanding about what gets removed.)
