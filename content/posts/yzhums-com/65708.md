# Dynamics 365 Business Central: How to prevent users from adding fields/columns from related tables in analysis mode (Disable/Enable Add Related Fields)

[Read the post](https://yzhums.com/65708/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-07-16 · 391 words · tier community · reviewed (checked by Opus)

> Managing permissions for the add related fields feature in analysis mode released in BC 26.2. Administrators can disable this feature globally via Feature Management or control it per user using the Add Fields in Analysis Mode permission.

## Key points

- Analysis mode allows users to add fields from related tables for advanced data analysis without customization
- The feature is controlled by the 'Add fields from related tables in analysis mode' feature key and becomes default in version 27.0
- New system permission object 9041 'Add Fields in Analysis Mode' lets admins restrict feature access by user or permission set
- Admins can exclude this permission from permission sets to prevent specific users from adding related fields
