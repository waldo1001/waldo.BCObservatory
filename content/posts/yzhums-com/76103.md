# Business Central 2026 release wave 2 (BC29): Share packaged resources between apps (publicResourceFolders)

[Read the post](https://yzhums.com/76103/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-09-16 · 426 words · tier community · reviewed (checked by Opus)

> Business Central 2026 release wave 2 (BC29) introduces publicResourceFolders, allowing apps to expose packaged resources to other apps. Apps define private resources in resourceFolders and shareable resources in publicResourceFolders within app.json, with access controlled through new NavApp method overloads that accept app IDs.

## Key points

- Apps can now share selected packaged resources with other apps using publicResourceFolders in app.json
- New NavApp method overloads with app ID parameters enable cross-app resource access while maintaining private resource isolation
- Resource sharing does not require adding dependencies to app.json files
- Apps can discover and enumerate providers that expose matching public resources using NavApp.ListAppsWithPublicResources()

## Quotes

- "Apps can now expose selected packaged resources to other apps." (This is the core capability introduced in BC29 that solves the previous limitation where resources could only be accessed within the same app.)
- "This does not require adding a dependencies setting in the app.json file." (It clarifies that resource sharing has a lower overhead than app dependencies, making it easier to implement cross-app resource patterns.)
- "NavApp.ListResources(AppId) is always public-only, even when AppId is the current app." (This explains the security design: the app ID overload only exposes public resources, protecting private resources from external access.)
