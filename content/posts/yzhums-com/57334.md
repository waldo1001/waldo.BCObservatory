# Dynamics 365 Business Central: Why are the newly added fields in drop-down not displayed? (e.g., adding item Search Description to DropDown fieldgroup)

[Read the post](https://yzhums.com/57334/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-05-29 · 350 words · tier community · **unreviewed** (model text not yet checked)

> When adding fields to a drop-down field group in a table, newly added fields may not display if they are hidden on the underlying lookup page. To fix this, modify the page extension to set the field's Visibility property to true.

## Key points

- Field groups (DropDown) define which fields appear in drop-down controls when selecting records from a list
- Fields added to a DropDown field group won't show if they have Visibility = false on the lookup page
- The solution requires both a table extension with the DropDown field group and a page extension to make hidden fields visible
- The Item table uses the Item Lookup page as its lookup page, which hides certain fields by default

## Quotes

- "If the field you're adding to the DropDown has Visibility = false on the underlying lookup page, it won't show up in the drop-down." (This explains the root cause of missing fields in drop-down controls and is the key insight for troubleshooting)
