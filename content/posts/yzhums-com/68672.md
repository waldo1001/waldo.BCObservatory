# Dynamics 365 Business Central Blog Series: Handle CSV (comma-separated values) files

[Read the post](https://yzhums.com/68672/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-10-28 · 527 words · tier community · **unreviewed** (model text not yet checked)

> This blog series covers multiple techniques for working with comma-separated values (CSV) files in Dynamics 365 Business Central, including importing and exporting data via AL code and Power Automate, importing bulk large text fields, previewing multiple file types, and using Copilot to suggest sales lines from CSV files.

## Key points

- CSV files can be imported to and exported from Business Central tables using AL code or Power Automate without customization
- Power Automate enables JSON to CSV conversion for exporting and CSV to JSON conversion for importing data
- Large text fields exceeding 250 or 2048 characters can be bulk imported from external files via AL
- Multiple file types including CSV can be previewed within Business Central from SharePoint
- Copilot in Business Central 2024 wave 2 can suggest sales lines directly from CSV files
