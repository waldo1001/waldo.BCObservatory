# Dynamics 365 Business Central: How to copy values (Blob) ​​from one Codeunit “Temp Blob” to another Codeunit “Temp Blob”

[Read the post](https://yzhums.com/68656/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-10-29 · 296 words · tier community · **unreviewed** (model text not yet checked)

> Copying BLOB data from one Temp Blob codeunit to another requires creating an InStream from the source, an OutStream to the target, and using CopyStream to transfer the data. This technique became relevant after Microsoft deprecated Record TempBlob in BC15 and introduced the Temp Blob codeunit.

## Key points

- Temp Blob codeunit replaced deprecated Record TempBlob starting in 2019 Release Wave 2 (BC15)
- CreateInStream method reads data from the source BLOB with optional Encoding parameter
- CreateOutStream method writes data to the target BLOB with optional Encoding parameter
- Use CopyStream function to transfer data between InStream and OutStream objects

## Quotes

- "When you're writing code to manage the importing and exporting of files, you can use this codeunit." (Defines the primary use case for Temp Blob, helping developers understand when to apply this technique)
