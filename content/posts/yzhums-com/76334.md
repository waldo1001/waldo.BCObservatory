# Business Central 2026 release wave 2 (BC29): Translate objects with the same name in different namespaces (Translations with namespaces)

[Read the post](https://yzhums.com/76334/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-09-28 · 578 words · tier community · reviewed (checked by Opus)

> BC29 introduces namespace-aware translation identifiers that allow identically named AL objects in different namespaces to be translated independently. This feature uses the TranslationsWithNamespaces flag in app.json to generate translation IDs prefixed with namespace, preventing collisions while keeping non-namespaced translations valid.

## Key points

- New TranslationsWithNamespaces compiler feature flag includes object namespace in translation IDs to avoid collisions
- Translation ID format becomes readable (Namespace - Object - Property) unless non-ASCII characters require hashing
- Enable XLIFF file generation by adding TranslationFile feature in app.json, then translate labels in the generated XML files
- Namespaces organize code logically and allow name reuse across different contexts, improving code structure

## Quotes

- "Generate namespace-aware translation identifiers so identically named AL objects can be translated independently while existing non-namespaced translations remain valid." (Core definition of the feature's purpose and backward compatibility approach)
- "When enabled, the translation ID format also changes so the object and property names are visible." (Explains the practical benefit of readable IDs that make translation files easier to understand)
- "Namespaces ensure uniqueness in code names and allow reuse of names in different contexts, and provide structure for the code base." (Shows why namespaces are fundamental for preventing naming conflicts in extensions)
