# Dynamics 365 Business Central Blog Series: Preview files directly in the web client

[Read the post](https://yzhums.com/63730/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-04-28 · 427 words · tier community · **unreviewed** (model text not yet checked)

> This blog series covers methods to preview various file types (PDF, images, Word, Excel, PowerPoint, video, and more) directly in the Business Central web client without downloading or using custom control add-ins, with native support expanding through BC26 and BC27 releases.

## Key points

- PDF attachments can be previewed natively in BC26 web client without control add-ins or APIs
- Images and Base64-encoded images can be previewed directly in the web client with enlargement capability
- SharePoint-hosted files (PDF, DOCX, XLSX, PPTX, TXT, CSV, MP4) are supported for preview within Business Central
- BC27 introduces a new Document ExtendedDataType that displays PDFs as portrait images in FactBox controls
- Word documents can be previewed in the web client without downloading files

- "Preview PDF attachments directly in web client (No control add-in and APIs)" (Highlights the native capability in BC26 that eliminates custom development overhead for PDF previewing)
