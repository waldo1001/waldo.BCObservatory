# Dynamics 365 Business Central: How to quickly create Production Orders from Sales Orders

[Read the post](https://yzhums.com/74091/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-06-24 · 426 words · tier community · **unreviewed** (model text not yet checked)

> Production orders can be created directly from sales orders in Business Central by using the Sales Order Planning page and selecting the Create Prod. Order action. The feature requires the Replenishment System field on the item card to be set to Prod. Order, and supports two order creation modes: Item Order (one per item) or Project Order (multiline for all items).

## Key points

- Access production order creation through the Planning action on a sales order, then use Create Prod. Order
- Item Order mode creates one production order per item line; Project Order mode creates a single multiline order for all items
- The Replenishment System field on the item card must be set to Prod. Order; other values cause an error
- Order-to-order links are automatically applied, preventing the planning system from including linked supply or inventory in balancing

## Quotes

- "You can create production orders for produced items directly from sales orders." (States the core capability that enables manufacturing planning directly from customer demand)
- "The Replenishment System on the Item Card must be set to Prod. Order." (Critical prerequisite for the feature to work; missing this causes the process to fail)
- "When order-to-order links exist, the planning system doesn't include linked supply or inventory in the balancing procedure." (Explains how the system prevents double-counting of supply when production orders are linked to sales orders)
