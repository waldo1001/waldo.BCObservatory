# Business Central 2026 release wave 1 (BC28.1): Control the lifecycle of report layouts (Layout Status)

[Read the post](https://yzhums.com/72933/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-05-15 · 349 words · tier community · reviewed (checked by Opus)

> Report layout administrators can now control the lifecycle of report layouts by assigning statuses (Draft, Pending Approval, Approved, or Retired) to ensure only approved layouts are available to users. This feature, introduced in Business Central 2026 wave 1 (BC28.1), improves governance, compliance, and reporting consistency.

## Key points

- Layout statuses control approval stages: Draft, Pending Approval, Approved, and Retired
- Only Approved layouts appear on report request pages for user selection
- Status is changed via Actions menu, not directly editable in the layout
- Multiple layouts can have their status changed simultaneously
- Status cannot be changed for layouts provided by extensions

## Quotes

- "Only Approved layouts are available for selection on report request pages." (Defines the practical enforcement of the layout status feature to prevent unapproved reports from being used)
- "Report layout administrators can set the status of report layouts to control their lifecycle stages." (Explains the core capability and who benefits from this new feature)
