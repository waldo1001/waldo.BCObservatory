# Dynamics 365 Business Central: How to add Filter by item attributes to the Item Ledger Entries page

[Read the post](https://yzhums.com/74458/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-07-03 · 656 words · tier community · **unreviewed** (model text not yet checked)

> This post explains how to extend the Item Ledger Entries page to include filtering by item attributes, a feature already available on the Item List page. The customization adds an Item Attributes FactBox and actions to filter and clear attribute-based filters.

## Key points

- Item attributes allow items to be characterized by properties like height and model year for searching and customer service
- The standard Item List page includes a Filter by Attributes action that uses item attribute values to build a filter for matching item numbers
- The same logic can be ported to Item Ledger Entries via a page extension that adds the FilterByAttributes and ClearAttributes actions
- The customization uses temporary buffers and the Item Attribute Management codeunit to find matching items and apply filters
