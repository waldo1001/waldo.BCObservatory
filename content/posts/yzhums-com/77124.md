# Business Central 2026 release wave 2 (BC29): New notification bar

[Read the post](https://yzhums.com/77124/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-11-06 · 424 words · tier community · reviewed (checked by Opus)

> BC29 (2026 release wave 2) has an undocumented New notification bar feature in Feature Management. It is off by default and available only in sandboxes. When it is turned on, the only visible change is the bar's background color. Microsoft docs say that from version 30.0, page notifications are hidden while the Agent Data Review Bar is shown, and a Show other notifications toggle lets users see them during the review.

## Key points

- New notification bar feature is disabled by default and currently sandbox-only in BC29.
- Notifications differ from modal messages by providing information without requiring immediate user action.
- In BC 30.0, page notifications hide when the Agent Data Review Bar appears but users can show them with a toggle.
- The feature changes notification bar background color while keeping other content and layout unchanged.

## Quotes

- "Notifications provide a programmatic way to send nonintrusive information to the User Interface (UI) in the Web client." (Defines the core purpose of the new notification feature as a non-blocking communication method.)
- "This feature is currently available only in Sandbox environments and is not yet available in Production." (Important limitation that affects where users can test this notification bar feature.)
