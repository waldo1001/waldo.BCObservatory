# Dynamics 365 Business Central: How to bulk import marketing text to items – Customization

[Read the post](https://yzhums.com/65326/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-06-25 · 777 words · tier community · reviewed (checked by Opus)

> The post explains how to bulk import marketing text for items in Business Central using a custom XMLPORT and CSV file. It covers the difference between marketing text and item descriptions, the underlying Entity Text system table, and provides complete AL code for importing large text values that exceed typical field size limits.

## Key points

- Marketing text is richer, descriptive copy for items used in storefronts and customer communications, distinct from the concise Description field
- Marketing text data is stored in system table 2000000132 (Entity Text), which cannot be imported via Configuration Packages
- Custom AL code using XMLPORT with CSV format allows bulk import while handling large text values stored as Blob fields
- The solution updates existing marketing text or inserts new records based on item number and company context

## Quotes

- "Table 2000000132 is a system table, so it cannot be imported through the Configuration Package." (Explains why a custom XMLPORT solution is necessary instead of standard import tools)
- "If it already exists, edit the existing data, if not, insert the new data." (Describes the import logic that handles both creating new marketing text and updating existing records)
