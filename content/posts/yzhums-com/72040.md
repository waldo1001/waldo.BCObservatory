# Dynamics 365 Business Central: How to quickly identify the first transaction date and the number of days since the last sale with a customer

[Read the post](https://yzhums.com/72040/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-07-17 · 369 words · tier community · **unreviewed** (model text not yet checked)

> Business Central provides built-in fields to track a customer's first transaction date and calculate days since their last sale without custom code. Use the Customer Statistics page or extend the Customer List with standard fields like First Transaction Date and DaysSinceLastSale.

## Key points

- First Transaction Date is a standard field in the Customer table (table 18) that shows when a customer made their first purchase
- Days Since Last Sale automatically calculates the interval between the current work date and the customer's most recent sale posting date
- Access this information via Customer > Statistics on the Customer List or Customer Card without writing code
- You can add these fields to other pages like the Customer List using page extensions for easier visibility
