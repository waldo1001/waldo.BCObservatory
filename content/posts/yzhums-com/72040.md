# Dynamics 365 Business Central: How to quickly identify the first transaction date and the number of days since the last sale with a customer

[Read the post](https://yzhums.com/72040/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-07-17 · 369 words · tier community · reviewed (checked by Opus)

> The Customer Statistics page (Customer > Statistics, then Show more) shows a customer's first transaction date and the days since the last sale without any code. First Transaction Date is a standard field on table 18 Customer, while Days Since Last Sale is only a variable on page 151, so the post gives a page extension that adds both to the Customer List.

## Key points

- Open Customer > Statistics from the Customer List or Card and choose Show more; Customer Since and Lifetime (since) show the first transaction date
- The Days Since Last Sale value on the statistics page counts days since the customer's last purchase
- First Transaction Date is a standard field on the Customer table; DaysSinceLastSale is a page variable, not a table field
- A sample page extension adds both to the Customer List, computing days as work date minus the posting date of the latest non-reversed customer ledger entry with positive sales, with drill-down to that entry
