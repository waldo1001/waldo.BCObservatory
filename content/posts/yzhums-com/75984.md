# Business Central 2026 release wave 2 (BC29): Run multiple financial reports and get a single PDF output (Combines multiple Financial Reports into a single PDF)

[Read the post](https://yzhums.com/75984/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-09-10 · 749 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2026 wave 2 introduces Financial Report Packages, a feature that combines multiple financial reports into a single PDF that can be printed immediately or scheduled for email delivery. This replaces the previous workflow of running and configuring multiple reports separately.

## Key points

- Financial Report Packages consolidate multiple financial reports into one PDF document
- You can apply distinct filters and date formulas to each report within a package
- Reports can be printed immediately or scheduled for regular email delivery to multiple recipients
- The feature eliminates the need to set up and run separate reports individually

## Quotes

- "Financial Report Packages combines multiple Financial Reports into a single PDF, which can be exported or emailed on a regular basis." (This is the core capability introduced in this wave, showing the main benefit of the new feature.)
- "You can apply distinct filtering criteria to each combined report." (This explains the flexibility of the feature, allowing different filters for different reports in the same package.)
- "For a single Financial Report Package, you can set multiple schedules." (This shows that packages support complex scheduling scenarios with multiple recurring email deliveries.)
