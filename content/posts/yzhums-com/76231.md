# Business Central 2026 release wave 2 (BC29): Reuse header/footer layouts across document reports

[Read the post](https://yzhums.com/76231/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-09-24 · 745 words · tier community · reviewed (checked by Opus)

> Business Central 2026 release wave 2 introduces composable layouts that let administrators reuse and apply consistent header/footer layouts across document reports at global, company, report, or layout levels. Headers and footers can only be applied to Word layouts with Body subtype and must be approved before assignment.

## Key points

- Composable layouts enable headers and footers to be reused across multiple document reports for consistent branding
- Administrators can set defaults at global level, per company, per report, or per layout for flexible theming control
- New Subtype field on Word layouts distinguishes between Default, HeaderFooter, Theme, and Body subtypes with different capabilities
- Headers/footers can only be applied to Word layouts with Body subtype, not RDLC layouts or Default subtype layouts
- Themes and header/footer parts must be approved in Report themes and header-footer setup before they can be assigned

## Quotes

- "With the new composable layouts feature, you can apply a header/footer on layouts to get consistent look and feel on the PDF output." (Explains the core capability of applying headers/footers consistently across reports, which is the main feature being introduced)
- "It is possible to set defaults on a global level, per company, per report, or per layout, giving the administrator full flexibility of theming." (Describes the flexibility administrators have in controlling where themes and headers/footers apply, which is a key advantage)
- "Only a body layout carries them: a theme and header/footer are merged onto it when the report renders." (Clarifies the technical constraint that only Body subtype layouts support composite layout merging, which is important for implementation)
