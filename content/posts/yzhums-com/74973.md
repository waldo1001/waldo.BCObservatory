# Dynamics 365 Business Central: How to add a setup to the Manual Setup (1875, List) page

[Read the post](https://yzhums.com/74973/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-07-31 · 372 words · tier community · **unreviewed** (model text not yet checked)

> This post explains how to add a custom setup page to the Manual Setup page in Business Central using the Guided Experience codeunit and the OnRegisterManualSetup event. It helps developers extend the setup experience when creating custom extensions.

## Key points

- Use the Codeunit 'Guided Experience' to manage guided experience items that users can access
- Subscribe to the OnRegisterManualSetup event to add new manual setups to the Manual Setup page
- Use the InsertManualSetup method to register a custom setup with title, description, and target page
- Check if a setup already exists before inserting to avoid duplicates

## Quotes

- "The Manual Setup section provides access to setup pages where you can fill in setup fields for all areas manually." (Clarifies the purpose of the Manual Setup page as a central location for configuration in Business Central)
- "OnRegisterManualSetup: The event that is raised so that subscribers can add the new manual setups that can be displayed in the Manual Setup page." (Points to the specific event developers must subscribe to for adding custom setups)
