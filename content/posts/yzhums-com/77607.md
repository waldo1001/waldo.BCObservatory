# Business Central 2026 release wave 2 (BC29): New API Overview page to view all available APIs (Discover APIs with the API Overview page)

[Read the post](https://yzhums.com/77607/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-11-24 · 567 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2026 release wave 2 introduces a new API Overview page that provides a standard way to explore all available APIs in the environment, including Microsoft APIs and custom APIs from extensions. This replaces the previous method of manually filtering the Page Metadata virtual table.

## Key points

- New API Overview page available in BC29 for discovering and viewing all available APIs
- Page displays APIs as pages, queries, or codeunits with detailed information like API URL, publisher, group, and version
- Predefined views simplify filtering (All, API Pages, API Queries, API Codeunits, API v2.0, Microsoft APIs, Custom APIs)
- Users can directly access API endpoints from the page or filter by publisher, group, and version
