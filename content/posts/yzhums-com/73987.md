# Business Central 2026 release wave 1 (BC28): New Resize button (action)

[Read the post](https://yzhums.com/73987/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-06-03 · 304 words · tier community · reviewed (checked by Opus)

> BC28 (2026 release wave 1) adds a Resize action to the column drop-down or right-click menu on list views. It highlights the column edge so the user can drag it or double-click it to auto-fit. The author confirmed the action in BC28.0 and BC28.1 sandboxes, but not in production at the time of writing.

## Key points

- A new Resize action is in the column header drop-down menu and also appears when you right-click a column name
- After you choose Resize, the column edge is highlighted so you can drag it or double-click it to auto-fit
- The action works in all list views, not only on List pages
- It builds on the drag and double-click column resizing that came in BC15
- The author confirmed it in BC28.0 and BC28.1 sandboxes, not in production; hovering over a column edge already shows a blue line

## Quotes

- "Microsoft has added a new Resize button to the drop-down arrow menu (context menu)" (Explains the core feature improvement for easier column resizing without personalizing)
- "this button is not limited to List pages, Microsoft has added this option to all list views across the BC" (Shows the broad applicability of the feature across the entire system)
- "A vertical blue line will automatically highlight whenever you hover your mouse over the edge of a column" (Describes the visual enhancement that makes the feature more discoverable and intuitive)

- Features: Resize button, column width adjustment, auto-fit, context menu, list views
