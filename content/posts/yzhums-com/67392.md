# Business Central 2025 wave 2 (BC27): View SQL call information in performance profiles

[Read the post](https://yzhums.com/67392/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-09-05 · 652 words · tier community · reviewed (checked by Opus)

> Business Central 2025 wave 2 (BC27) adds SQL call visibility to performance profiles in both the in-client profiler and Visual Studio Code, enabling developers and consultants to diagnose whether performance issues stem from AL code or database queries without direct SQL access.

## Key points

- Performance profiles now show the SQL calls made during profiling, and you can hover over a query and copy it
- This helps tell whether slow performance comes from AL code or from the SQL calls it generates
- For scheduled profiles, the Performance Profiles overview shows the duration of captured SQL calls in partner code, the number of SQL calls, and the duration of platform calls
- Works in the web client's in-client profiler and in snapshots captured from Visual Studio Code
- Builds on the VS Code profiler (BC19), the in-client profiler (BC20) and rule-based profiler schedules (BC25)

## Quotes

- "Understanding SQL performance when troubleshooting in the cloud without direct SQL access can be hard." (Establishes the business need that this feature addresses for cloud-based deployments)
