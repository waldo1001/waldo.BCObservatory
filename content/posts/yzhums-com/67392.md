# Business Central 2025 wave 2 (BC27): View SQL call information in performance profiles

[Read the post](https://yzhums.com/67392/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-09-05 · 652 words · tier community · **unreviewed** (model text not yet checked)

> Business Central 2025 wave 2 (BC27) adds SQL call visibility to performance profiles in both the in-client profiler and Visual Studio Code, enabling developers and consultants to diagnose whether performance issues stem from AL code or database queries without direct SQL access.

## Key points

- Performance profiles now display actual SQL calls made during profiling with query details visible on hover and copyable text
- This enhancement helps identify if performance problems are due to inefficient AL code or problematic SQL queries
- Scheduled profiles in the performance overview show total SQL call duration, number of calls, and platform call duration
- Feature builds on earlier profiling capabilities added in BC19 (Visual Studio Code profiler), BC20 (in-client profiler), and BC24 (rule-based scheduling)

## Quotes

- "Understanding SQL performance when troubleshooting in the cloud without direct SQL access can be hard." (Establishes the business need that this feature addresses for cloud-based deployments)
