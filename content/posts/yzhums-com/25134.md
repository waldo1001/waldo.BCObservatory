# Dynamics 365 Business Central: How to note the records that the user has selected on the Subpage/Lines (Page.SetSelectionFilter in part)

[Read the post](https://yzhums.com/25134/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-06-23 · 363 words · tier community · reviewed (checked by Opus)

> Page.SetSelectionFilter is a method that captures records selected by users on pages or subpages, marks them in the table, and applies a filter. The post explains how to use it both on main pages by accessing subpages via CurrPage and directly on subpage extensions.

## Key points

- Page.SetSelectionFilter(var Record) gets user-selected records and applies a 'marked only' filter
- On main pages, access subpage selections using CurrPage.{SubpageName}.Page.SetSelectionFilter()
- On subpage extensions, use CurrPage.SetSelectionFilter() directly like normal page usage
- The method marks selected records in the specified table for processing
