# Business Central 2026 release wave 2 (BC29): Brand document reports with report themes

[Read the post](https://yzhums.com/76147/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-09-17 · 789 words · tier community · reviewed (checked by Opus)

> Business Central 2026 release wave 2 introduces branded document reports with composable layout themes. Administrators can apply consistent styling to PDF outputs at global, company, report, or layout levels using Word themes saved as .dotx templates.

## Key points

- New composable layouts feature allows applying report themes to Word layouts for consistent visual styling
- Themes can be configured at multiple levels: globally, per company, per report, or per layout
- Themes must be created as .dotx Word template files and approved before assignment to reports
- Layout Subtype property distinguishes between Default, Body, HeaderFooter, and Theme layouts for composite layout support
- Themes and headers/footers can only be applied to Word layouts with Body subtype, not RDLC layouts

## Quotes

- "With the new composable layouts feature, you can apply a report theme on layouts to get consistent look and feel on the PDF output." (Explains the core capability of applying themes to achieve visual consistency across business documents)
- "It is possible to set defaults on a global level, per company, per report, or per layout, giving the administrator full flexibility of theming." (Highlights the flexibility administrators have in controlling theme application across the organization)
- "Only approved themes and header/footer parts can be assigned." (Shows that themes must go through an approval process before they can be used in reports)
