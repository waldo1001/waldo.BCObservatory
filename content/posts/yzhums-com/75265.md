> Business Central query objects retrieve and combine data from one or more tables into rows and columns, supporting calculations like sums and averages. This series covers practical use cases for queries including data analysis, report creation, API development, and filtering.

## Key points

- Query objects combine data from multiple tables into unified datasets and perform calculations
- Queries can be used as data sources for pages, reports, and custom APIs
- Query features include searching through Tell Me, duplicate detection, data grouping and pivoting, and JSON export
- Built-in queries provide ad hoc analysis for fixed assets, projects, and services
- Queries support tooltips and analysis modes for better data exploration
