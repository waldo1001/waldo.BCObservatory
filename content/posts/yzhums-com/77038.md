# Business Central 2026 release wave 2 (BC29): Custom Report Layouts are now deprecated and have been removed

[Read the post](https://yzhums.com/77038/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2026-10-30 · 381 words · tier community · reviewed (checked by Opus)

> Custom Report Layouts have been removed in Business Central 2026 wave 2 (BC29). Organizations must migrate all custom layouts to the new Report Layouts feature before upgrading, as the legacy Custom Report Layouts page is no longer accessible.

## Key points

- Custom Report Layouts page has been completely removed in BC29 and is no longer accessible
- This legacy feature from Dynamics NAV was already obsolete but retained through BC28.5
- Users should migrate existing custom layouts (Word and RDLC types) to the new user-defined Report Layouts feature
- Migration to Report Layouts must be completed before upgrading to BC29

## Quotes

- "Microsoft has completely removed this page in Business Central 2026 release wave 2 (BC29), and it is no longer accessible." (Signals a breaking change requiring immediate action from users still using the legacy Custom Report Layouts feature)
- "Please ensure that all Custom Report Layouts are fully migrated to Report Layouts before upgrading to Business Central 2026 release wave 2 (BC29)." (Direct guidance on the upgrade prerequisite to avoid broken functionality)
