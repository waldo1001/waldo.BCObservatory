# Business Central 2025 wave 2 (BC27): ‘Concealed’ text field type for sensitive data (New field-level property: MaskType)

[Read the post](https://yzhums.com/67761/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-09-18 · 499 words · tier community · reviewed (checked by Opus)

> Business Central 2025 wave 2 introduces the MaskType field-level property that allows developers to conceal sensitive text field values by default with a toggle to reveal them. This feature works for Code, Text, Decimal, and Integer fields on card and document pages, and supports both desktop and mobile clients.

## Key points

- MaskType is a new enum property with values None (default) and Concealed that hides field values by default
- Users can reveal hidden values through an eye button toggle until the page is refreshed
- Only applicable to Code, Text, Decimal, and Integer field types on card or document pages, not repeaters or list pages
- MaskType differs from ExtendedDataType Masked property which permanently displays dots and cannot be removed
- Cannot be used together with ExtendedDataType Masked, and modifications to MaskType on standard fields may cause publishing errors

## Quotes

- "Concealed: The client handles this as a concealed field." (Defines the Concealed enum value that activates the masking behavior)
- "List pages or grids do not support this, only document/card pages (not supported in repeaters)" (Clarifies important scope limitations developers must understand when implementing MaskType)
