# Dynamics 365 Business Central Blog Series: Performance Profiler

[Read the post](https://yzhums.com/68765/) · Dynamics 365 Lab - Yun Zhu (Yun Zhu, MVP) · 2025-11-04 · 377 words · tier community · **unreviewed** (model text not yet checked)

> This blog series documents the evolution of performance profiling tools in Dynamics 365 Business Central across multiple releases, from the snapshot debugger in BC19 through in-client profiling enhancements in BC25-BC27, including features like sampling intervals, profiler schedules, SQL call visibility, and callstack retrieval.

## Key points

- Multiple profiling capabilities introduced progressively: snapshot debugger (BC19), in-client performance profiler (BC20), sampling intervals (BC23), profiler schedules (BC25), SQL call information (BC27)
- Profiler Schedules in BC25 enable easier setup of in-client performance profiling through rules
- BC27 adds SQL call information viewing in performance profiles and node copying support in the profile editor
- SessionInformation data type in BC26 allows developers to retrieve the current callstack programmatically
