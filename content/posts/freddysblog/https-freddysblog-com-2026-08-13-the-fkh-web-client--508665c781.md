# The Fkh Web Client

> Fkh Web Client is a web-based interface that allows developers to manage Kubernetes containers and clusters from a phone without requiring VS Code or CLI installation. It uses GitHub authentication and centralized backend logic, making it simple and secure for performing quick operational tasks.

[Read the post](https://freddysblog.com/2026/08/13/the-fkh-web-client/) · Freddys blog (Freddy Kristiansen) · 2026-08-13 · 657 words · tier community · **unreviewed** (machine-generated)

## Key points

- Web client provides a lightweight interface for starting, stopping containers, and managing the entire Fkh cluster from mobile devices
- Uses the same GitHub authentication and group membership as other Fkh interfaces, eliminating separate account management
- All business logic resides in the backend; the web client only handles display and API calls for a simple, maintainable architecture
- Designed for consultants and code reviewers who need to perform tasks in test environments without installing development tools
