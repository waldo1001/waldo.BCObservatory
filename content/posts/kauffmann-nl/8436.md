# Designing Agents for Business Central

> The Agent Design Experience in Business Central v27.4 is a sandbox tool for designing, testing, and refining agent instructions, not a low-code deployment platform. Production agents require manual conversion to AL code by exporting the agent XML configuration, creating an AL project with the Agent template, and either following the README instructions or using a coding agent to accelerate the customization process.

[Read the post](https://www.kauffmann.nl/2026/03/13/designing-agents-for-business-central/) · Kauffmann @ Dynamics 365 Business Central (Arend-Jan Kauffmann, MVP) · 2026-03-13 · 960 words · tier community · **unreviewed** (machine-generated)

## Key points

- The Agent Design Experience is a design and testing tool, not a production-ready deployment platform for low-code agents
- The tool allows writing, testing, refining instructions, simulating triggers, monitoring steps, testing permissions, and reviewing AI credit consumption in a sandbox
- Converting a designed agent to production requires exporting the agent XML, creating a new AL project from the Agent template, and customizing the code
- Coding agents can accelerate the conversion process by analyzing the exported XML and generating production-ready AL code, reducing manual conversion time to minutes
- The Agent Designer Experience app adds edit and export actions that become disabled once published to production; production apps need custom edit instructions pages for uniform user experience

## Quotes

- "This new agent designer should be used as a toolbox to simulate an agent. You can write, test, and refine the instructions" (Clarifies the core purpose of the tool is simulation and refinement, not production deployment)
