# Designing Agents for Business Central

[Read the post](https://www.kauffmann.nl/2026/03/13/designing-agents-for-business-central/) · Kauffmann @ Dynamics 365 Business Central (Arend-Jan Kauffmann, MVP) · 2026-03-13 · 960 words · tier community · reviewed (checked by Opus)

> The Agent Design Experience in Business Central v27.4 is a sandbox tool for designing, testing, and refining agent instructions, not a low-code deployment platform. Production agents require manual conversion to AL code by exporting the agent XML configuration, creating an AL project with the Agent template, and either following the README instructions or using a coding agent to accelerate the customization process.

## Key points

- The Agent Design Experience, previewed in v27.4, is a sandbox toolbox to simulate and refine agents, not a low-code or production deployment tool
- It lets you write and refine instructions, trigger tasks manually, review steps, test profiles and permissions, debug, and check AI credit use
- Moving to production means exporting the agent XML, creating an AL project from the Agent template, applying the README instructions and coding the triggers
- A coding agent prompt can apply the exported XML to the template, which may take around 15 minutes and yields a compilable agent app
- After publishing, Edit instructions and Export actions on the Agent Card are disabled since they come from the designer app; include your own edit page and extend the ConfigurationDialog setup page as needed

## Quotes

- "This new agent designer should be used as a toolbox to simulate an agent. You can write, test, and refine the instructions" (Clarifies the core purpose of the tool is simulation and refinement, not production deployment)
