# Install Agent Designer if it is missing

[Read the post](https://www.kauffmann.nl/2026/04/03/install-agent-designer-if-it-is-missing/) · Kauffmann @ Dynamics 365 Business Central (Arend-Jan Kauffmann, MVP) · 2026-04-03 · 223 words · tier community · **unreviewed** (machine-generated)

> The Agent Designer is included in the 27.4 monthly update and automatically installs in upgraded sandboxes but not production environments. When copying a post-v27.4 production environment to a sandbox, you can manually install the Agent Designer using a specific AppSource URL with its app ID.

## Key points

- Agent Designer is part of the v27.4 monthly update and auto-installs in upgraded sandboxes
- Production environments do not automatically receive the Agent Designer
- Sandboxes copied from pre-v27.4 production environments need to be upgraded to v27.4 to get the Agent Designer
- Sandboxes copied from post-v27.4 production environments do not auto-receive the Agent Designer but can be manually installed via AppSource URL
- The Agent Designer app ID is 00155c68-8cdd-4d60-a451-2034ad094223
