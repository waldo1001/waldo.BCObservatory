# One-Click Performance Analysis Inside Business Central

[Read the post](https://sshadows.dk/blog/one-click-performance-analysis-bc/) · SShadowS (Torben Leth) · 2026-03-03 · 1059 words · tier community · **unreviewed** (model text not yet checked)

> An extension adds AI-powered performance analysis directly into Business Central's Performance Profiler, detecting anti-patterns and explaining results without switching tools. It helps developers understand slow transactions quickly by identifying root causes like N+1 queries, unfiltered record operations, and event subscriber hotspots.

## Key points

- One-click analysis button on the Performance Profiler page runs pattern detection and AI-powered explanation of performance bottlenecks
- Detects anti-patterns including N+1 queries, unfiltered FindSet, method dominance, deep call stacks, and event subscriber hotspots
- Optional source code upload enables syntactic analysis to prove nesting and catch performance issues not yet visible in profiles
- Available as BC extension for quick profile-only analysis or web app for full analysis with source correlation

- Features: Performance Profiler integration, AI-powered performance explanation, Anti-pattern detection, Call tree analysis, Source code correlation, N+1 query detection, Event subscriber hotspot detection, Unfiltered query detection
