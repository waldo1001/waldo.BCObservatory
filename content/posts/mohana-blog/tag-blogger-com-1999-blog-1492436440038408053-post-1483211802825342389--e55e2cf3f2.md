# Business Central 2026 Wave 2: Preview Images Directly in the Web Client

> Business Central 2026 Wave 2 introduces native image preview functionality in the web client, allowing users to view supported image formats (JPEG, PNG, BMP, SVG, WEBP, GIF, AVIF, etc.) directly without downloading. This capability parallels existing PDF preview features and includes support for animated GIFs, clickable thumbnails, and developer access via File.ViewFromStream().

[Read the post](http://mohana-dynamicsnav.blogspot.com/2026/09/business-central-2026-wave-2-preview.html) · Mohana's Dynamics NAV & BC blog (Mohana Yadav) · 2026-09-08 · 699 words · tier community · **unreviewed** (machine-generated)

## Key points

- Users can preview images directly in Business Central's web client without local downloads, similar to PDF preview experience
- Supported formats include JPEG, PNG, BMP, SVG, WEBP, GIF, AVIF, and additional formats for Safari (TIFF)
- Animated GIF support up to 48 frames appears in FactBoxes, and thumbnails are clickable to open preview windows
- Developers can implement custom image previews using File.ViewFromStream() method for Business Central Online
- Use cases include product images, quality inspections, purchase documentation, and service attachments
