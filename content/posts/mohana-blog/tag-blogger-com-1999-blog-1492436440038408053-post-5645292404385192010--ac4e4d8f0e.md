# Pinned Comment Lines for Microsoft Dynamics 365 Business Central

> An extension that displays pinned comments as on-screen notifications when customers, vendors, or items are accessed, ensuring important notes reach users where decisions are made instead of remaining hidden in the comment sheet.

[Read the post](http://mohana-dynamicsnav.blogspot.com/2026/09/pinned-comment-lines-for-microsoft.html) · Mohana's Dynamics NAV & BC blog (Mohana Yadav) · 2026-09-12 · 840 words · tier community · **unreviewed** (machine-generated)

## Key points

- Pinned comments show notifications when customer, vendor, or item cards open and when documents referencing them are accessed
- Comments are marked as pinned with a single checkbox; existing comment functionality remains unchanged with no data migration required
- Three new fields added to comments: Pinned checkbox, optional Pin Until date for expiration, and Pin Severity for Information or Warning levels
- Notifications combine multiple pinned comments into one banner and respect standard Business Central notification settings allowing users to disable them
- Automated processes like batch posting and API calls are unaffected as notifications show only to users in the client

## Quotes

- "A pinned comment raises an on-screen notification whenever that customer, vendor, or item comes into play when the card is opened." (Explains the core functionality of making important notes visible at the point of work rather than hidden behind multiple clicks)
- "This is not a replacement notes system: there is no new table, no separate editor, and no data to migrate." (Shows the extension integrates seamlessly with existing comment functionality without requiring data changes or new infrastructure)
- "Notifications are shown only to users working in the client. Batch posting, job queue entries, API calls, and web service integrations are unaffected." (Demonstrates the extension is safe for automated processes and won't interfere with system automation)
