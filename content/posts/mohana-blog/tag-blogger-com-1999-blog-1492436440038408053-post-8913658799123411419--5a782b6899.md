# Allow Posting From/To DateFormula: No More Monthly Date Updates from Business Central v28

[Read the post](http://mohana-dynamicsnav.blogspot.com/2026/03/allow-posting-fromto-dateformula-no.html) · Mohana's Dynamics NAV & BC blog (Mohana Yadav) · 2026-03-13 · 668 words · tier community · reviewed (checked by Opus)

> Business Central 28 adds DateFormula fields to automatically calculate allowed posting ranges, eliminating manual monthly updates to posting period dates. Set the formula once and the posting window moves forward automatically based on the work date.

## Key points

- New DateFormula fields (Allow Posting From DateFormula and Allow Posting To DateFormula) on General Ledger Setup and User Setup tables calculate posting windows dynamically
- DateFormula and static Date fields are mutually exclusive; setting one automatically clears the other to prevent conflicts
- Use standard DateFormula syntax like <-CM> for month start and <CM> for month end, same as payment terms
- Posting window recalculates automatically each period without manual intervention required
- Error messages for out-of-range posting dates work the same whether dates come from static fields or formulas

## Quotes

- "No more monthly manual updates. Set the formula once, and the posting window moves forward on its own." (This summarizes the core benefit of eliminating repetitive administrative tasks that were easy to forget.)
