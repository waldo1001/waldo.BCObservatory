# Data query tools in the Business Central MCP server: a hands-on test guide

[Read the post](http://mohana-dynamicsnav.blogspot.com/2026/10/data-query-tools-in-business-central.html) · Mohana's Dynamics NAV & BC blog (Mohana Yadav) · 2026-10-07 · 1066 words · tier community · reviewed (checked by Opus)

> The Data Query Tools feature on the Business Central MCP server enables agents to query tables, read schemas, and run AL queries without requiring pre-published API pages, expanding ad hoc analysis capabilities while maintaining read-only access based on user permissions.

## Key points

- Agents can discover tables, inspect their fields and relations, write AL queries, compile them, and execute them through four system tools
- Eliminates the need for development requests and deployments for one-off queries by operating within user permissions and AL query constraints
- Read-only access prevents data creation, modification, or deletion through the query interface
- Available as a preview feature in 2026 release wave 2 for Business Central online
- Setup requires creating an MCP server configuration with the Data Query Tools feature enabled and connecting it through VS Code or other MCP clients

## Quotes

- "With the data query tools, an agent can answer a question nobody built an object for, which describes most ad hoc analysis." (Highlights the practical value of eliminating the need for pre-built API pages for every possible query scenario)
- "The boundaries become the permissions the signed-in user already has and what an AL query can express." (Clarifies that security and functionality constraints are determined by existing user permissions rather than new limitations)
- "It is read-only, so nothing can be created, changed or deleted through it." (Establishes a fundamental safety characteristic that makes the feature suitable for analysis without data modification risks)
