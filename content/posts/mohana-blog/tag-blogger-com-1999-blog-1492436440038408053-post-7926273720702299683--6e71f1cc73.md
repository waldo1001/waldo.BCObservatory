# Define Item Attributes for Item Variants

[Read the post](http://mohana-dynamicsnav.blogspot.com/2026/03/define-item-attributes-for-item-variants.html) · Mohana's Dynamics NAV & BC blog (Mohana Yadav) · 2026-03-08 · 584 words · tier community · reviewed (checked by Opus)

> Business Central 2026 release wave 1 (BC28) introduces item attributes at the variant level, allowing each variant to have distinct attribute values instead of inheriting the same values from the parent item. This solves the problem of keeping variant data accurate without creating separate items for each variation.

## Key points

- Variants can now have their own attribute values while inheriting from the parent item
- Inherited attribute values can be adjusted or removed per variant from the new Item Variant Attribute Values page
- The Update Variant Attributes action on the Item Card syncs attributes from the item to all its variants
- If the parent item has no attributes defined, variants inherit nothing

## Quotes

- "You can now define item attributes at the item variant level." (This is the core new capability that solves the problem of inaccurate variant attribute data in Business Central.)
- "Variants still inherit attributes from the parent item, but you can now adjust or remove those inherited values when a variant needs different information." (This explains how the feature maintains efficiency while providing the flexibility needed for real-world variant scenarios.)
