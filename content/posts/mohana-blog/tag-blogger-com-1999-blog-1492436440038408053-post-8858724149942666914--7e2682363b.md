# Business Central is transitioning to .NET 10

[Read the post](http://mohana-dynamicsnav.blogspot.com/2026/11/business-central-is-transitioning-to.html) · Mohana's Dynamics NAV & BC blog (Mohana Yadav) · 2026-11-11 · 332 words · tier community · reviewed (checked by Opus)

> Business Central is transitioning from .NET 8 to .NET 10 across online and on-premises deployments. For online, Microsoft handles the migration automatically during maintenance windows. For on-premises, .NET 10 arrives through cumulative updates (BC 27 at CU 27.12, BC 28 at CU 28.6, BC 29 from release), with corresponding AL Language extension version requirements.

## Key points

- Online environments migrate to .NET 10 automatically during configured maintenance windows with no manual action needed
- On-premises .NET 10 availability depends on cumulative update level, not major version, requiring verification before applying specific CUs
- AL Language extension requires .NET 10 and now uses .NET Install Tool for VS Code to automatically download and install the runtime
- Cloud-only extensions with pure AL code have no exposure to compatibility issues; on-premises solutions with DotNet interop need assembly compatibility verification

## Quotes

- "For on-prem, .NET 10 arrives through cumulative updates to supported releases." (Clarifies that on-premises upgrade timing depends on CU level, not major version, which is critical for deployment planning)
- "If you are cloud only and your extensions are pure AL, you have no exposure." (Identifies that most AppSource and cloud solutions are unaffected, reducing scope of migration concerns)

## Context

- Features: AL Language extension, .NET 10 runtime, .NET Install Tool for Visual Studio Code, cumulative updates
- Versions: BC 27, BC 28, BC 29, 2026 release wave 2
