# How I Recreated the Extension Upload Experience in Business Central

> A custom app recreates the deprecated in-product extension upload functionality by calling the Business Central admin center API from AL. It provides a familiar interface for managing extensions with deployment scheduling, schema sync options, and comprehensive logging of all installation operations.

[Read the post](http://mohana-dynamicsnav.blogspot.com/2026/09/how-i-recreated-extension-upload.html) · Mohana's Dynamics NAV & BC blog (Mohana Yadav) · 2026-09-14 · 583 words · tier community · **unreviewed** (machine-generated)

## Key points

- In-product extension upload and the extensionUpload API are deprecated and will be removed in 2027 release wave 1 (version 30)
- The PTE Extension Management app provides an upload page with deployment scheduling, schema sync control, and uninstall capabilities
- Setup requires creating an Azure app registration, configuring API permissions, and registering the app in Business Central with the Exten. Mgt. - Admin permission set
- The app includes an Installation Status tracker, Scheduled Installs view, and a Deployment Log showing all attempts with user, status, operation ID, and response details

## Quotes

- "Microsoft has deprecated the in-product upload on the Extension Management page and the Automation API extensionUpload endpoint." (Critical change notification that the current extension upload method will no longer be available after 2027 release wave 1)

- "Deployment Log - every attempt, with user, environment, HTTP status, operation ID, and the raw response body." (Highlights the comprehensive auditing and troubleshooting capability built into the custom solution)
