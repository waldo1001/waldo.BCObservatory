# Recently Used Lookup Values Improve Everyday Productivity (BC29)

[Read the post](http://mohana-dynamicsnav.blogspot.com/2026/09/recently-used-lookup-values-improve.html) · Mohana's Dynamics NAV & BC blog (Mohana Yadav) · 2026-09-07 · 498 words · tier community · reviewed (checked by Opus)

> BC29 (2026 release wave 2) adds Recently Used in Lookups: lookup dialogs can show records a user recently searched for or selected, personalized per user, so common values like vendors or customers are picked by switching to the Recent view instead of searching again. The author found Global Search activity also influences the list and wishes manually entered values were included and Recent could open by default.

## Key points

- Recently used records appear personalized in lookup dialogs based on individual user activity patterns
- Feature covers lookups for customers, vendors, items, locations, dimensions, country codes, and payment terms
- Reduces clicks and search time by eliminating need to repeat the same searches throughout the day
- Recommendations are influenced by both lookup selections and records accessed through Global Search
- Users can access frequently used records by switching to Recent view in lookup dialogs

## Quotes

- "Business Central now surfaces recently used records directly within lookup dialogs." (Explains the core functionality that enables faster record access without repeated searching)
- "The suggestions are personalized to each user based on their usage patterns." (Demonstrates that the feature adapts to individual work habits, making recommendations more relevant)
