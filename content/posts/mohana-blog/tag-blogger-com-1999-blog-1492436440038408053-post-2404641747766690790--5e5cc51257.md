# Analysis Mode killed half the Excel exports on your client's shared drive

[Read the post](http://mohana-dynamicsnav.blogspot.com/2026/08/analysis-mode-killed-half-excel-exports.html) · Mohana's Dynamics NAV & BC blog (Mohana Yadav) · 2026-08-16 · 1046 words · tier community · **unreviewed** (machine-generated)

> Analysis Mode is a feature that lets users group, filter, and pivot data on Business Central list pages without exporting to Excel. It creates personal analysis views with their own columns, filters, and arrangements that persist between sessions and can be packaged into extensions.

## Key points

- Analysis views let users organize data by grouping, filtering, and pivoting without changing underlying data or affecting other users
- Date hierarchies automatically generate Year, Quarter, and Month fields for grouping, but use calendar years not fiscal years
- Requires execute permission on system object 9640; check the DATA ANALYSIS - EXEC permission set if the button is missing
- Analysis mode can be disabled per page with the AnalysisModeEnabled property and is not supported on indented lists like Chart of Accounts
- Analysis definitions can be exported as JSON and packaged into extensions for distribution to clients

## Quotes

- "Nothing you do here touches the underlying data, and nothing you do changes the page for anyone else." (Explains the safety and isolation of analysis mode operations for nervous users)
- "Date hierarchies use the calendar year. Not your client's fiscal year." (Critical limitation when fiscal year differs from calendar year; causes reporting discrepancies)
