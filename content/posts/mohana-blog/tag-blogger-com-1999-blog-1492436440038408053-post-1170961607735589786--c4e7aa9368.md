# Managing Apps in the Business Central Admin Center

[Read the post](http://mohana-dynamicsnav.blogspot.com/2026/09/managing-apps-in-business-central-admin.html) · Mohana's Dynamics NAV & BC blog (Mohana Yadav) · 2026-09-10 · 444 words · tier community · reviewed (checked by Opus)

> The Manage Apps page in the Business Central admin center controls the stack of apps running on an environment, including the Base Application, Microsoft first-party apps, ISV apps, and per-tenant extensions. You can view, upload, install, update, or uninstall apps depending on their type, though new global apps must be sourced from the marketplace rather than installed directly.

## Key points

- An environment is a stack of apps: Base Application, Microsoft first-party apps, ISV apps and per-tenant extensions, all reviewed on the admin center Manage Apps page
- Global apps can be viewed, updated and uninstalled but not installed here, because new ones come from the marketplace. PTEs support the full lifecycle. Dev extensions can only be viewed and uninstalled
- Installing a PTE means choosing a deployment schedule and a sync mode (Add or Force Sync), then tracking progress on the Operations page. New PTEs can only use the immediate or next update window schedules
- Client-side upload through Extension Management is expected to be removed in 2027 release wave 1, so move PTE deployment to the admin center or the Admin Center API
- Rehearse uninstalls in a sandbox first. Deleting app data can only be undone with a point-in-time restore within 28 days, so export the database beforehand. Dependent apps are uninstalled too

## Quotes

- "A BC environment is really a stack of apps: Base Application, Microsoft first-party apps, ISV apps, and your own per-tenant extensions." (Establishes the architectural layers that the admin center must manage, foundational to understanding app governance)
- "Extension Management is being phased out as an upload surface. Move PTE deployment to the admin center or the Admin Center API now." (Critical actionable warning about deprecated functionality that admins must address before 2027 to avoid disruption)
