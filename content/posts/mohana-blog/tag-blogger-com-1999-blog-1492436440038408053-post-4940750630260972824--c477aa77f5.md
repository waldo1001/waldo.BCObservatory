# How to See When Your SQL Server Backup or Restore Will Finish

> A SQL Server query shows the estimated completion time for active backup or restore operations by converting the estimated_completion_time value to a readable clock time. This helps database administrators know when long-running operations will finish instead of guessing.

[Read the post](http://mohana-dynamicsnav.blogspot.com/2026/07/how-to-see-when-your-sql-server-backup.html) · Mohana's Dynamics NAV & BC blog (Mohana Yadav) · 2026-07-23 · 501 words · tier community · **unreviewed** (machine-generated)

## Key points

- SQL Server's sys.dm_exec_requests system view contains estimated_completion_time in milliseconds for active backup and restore operations
- The query converts milliseconds to seconds and adds them to the current time using DATEADD to show an actual finish time
- The estimated_completion_time value recalculates continuously as the operation progresses, giving a fresh estimate each query execution
- The percent_complete column shows progress percentage, while estimated_completion_time answers when the operation will finish
- VIEW SERVER STATE permission is required to access the underlying system views
