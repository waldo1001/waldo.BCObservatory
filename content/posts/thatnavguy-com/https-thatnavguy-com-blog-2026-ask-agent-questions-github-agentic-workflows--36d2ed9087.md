# How to ask questions about your repo with GitHub Agentic Workflows

[Read the post](https://thatnavguy.com/blog/2026/ask-agent-questions-github-agentic-workflows/) · That NAV Guy (Teddy Herryanto, MVP) · 2026-10-09 · 912 words · tier community · reviewed (checked by Opus)

> GitHub Agentic Workflows enable teams to ask questions about a Business Central extension repository without cloning code or setting up a development environment. An AI agent reads GitHub issues and replies with code insights, citations, and relevant file paths.

## Key points

- Ask Agent uses GitHub Copilot to read issues and search repository code for answers without changing source code or opening pull requests
- Setup requires installing GitHub CLI with gh-aw extension, compiling a Markdown workflow file, and configuring Copilot inference access
- Non-developers with repository read access can ask questions via /ask comments in GitHub issues without needing Visual Studio Code or local setup
- The agent cites relevant file paths and line numbers but only has access to repository code, not live environments or customer data
- Follow-up questions are supported by adding additional /ask comments with specific clarifications

- Features: GitHub Agentic Workflows, Ask Agent workflow, GitHub Copilot integration, issue-based question answering, repository code search, file citation
