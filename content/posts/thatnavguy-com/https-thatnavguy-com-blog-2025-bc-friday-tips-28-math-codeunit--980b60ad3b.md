- It includes constants like Pi and methods for trigonometric functions (Cos, Sin, Tan)
- It provides utility functions including Log, Max, Min, Floor, Ceiling, Pow, and Sqrt
- Using the built-in codeunit eliminates the need to create custom math implementations
