> The Dimension Value table contains a hidden Global Dimension No. field that reveals which shortcut dimension a dimension code belongs to, avoiding the need to check General Ledger Setup and improving lookup performance.

## Key points

- Business Central supports 8 shortcut dimensions configured in General Ledger Setup
- Dimension Value table has a hidden Global Dimension No. field
- Using this field avoids checking General Ledger Setup separately
- Improves performance for dimension lookups
