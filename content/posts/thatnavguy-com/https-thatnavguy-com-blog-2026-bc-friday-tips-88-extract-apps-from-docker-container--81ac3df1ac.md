> A Docker tip for Business Central developers showing how to extract the Applications folder from a Docker container to a local PC using the docker cp command for quick access to standard Microsoft apps and extensions.

## Key points

- Docker cp command copies the entire Applications folder from a Business Central container to local storage
- Command syntax: docker cp "Containername:C:\Applications" "C:\TargetFolder"
- Provides quick local access to standard Microsoft apps and extensions for development purposes
- Simplifies developer workflow and everyday Business Central development tasks
