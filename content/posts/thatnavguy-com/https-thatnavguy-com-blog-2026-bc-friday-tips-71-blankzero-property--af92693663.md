# BC Friday Tips #71 BlankZero Property

> The BlankZero property on numeric fields can be set to true to display empty values instead of zero, reducing visual clutter and helping users focus on meaningful data in optional fields.

## Key points

- BlankZero property controls whether numeric fields display 0 or remain empty by default
- Setting BlankZero to true improves UI cleanliness for optional numeric fields
- Users can better distinguish between meaningful data and default zero values
- This is a simple property change that enhances overall usability
