> The Keep Description field in General Journals prevents the Description from being cleared when users change the Account Type, which is useful for preserving descriptions in imported or auto-generated journals.

## Key points

- By default, BC clears the Description field when Account Type is changed on a journal line
- The Keep Description field preserves the description text when switching between account types
- Particularly beneficial for journals that are imported or generated automatically
- Allows users to maintain description integrity without manual re-entry
