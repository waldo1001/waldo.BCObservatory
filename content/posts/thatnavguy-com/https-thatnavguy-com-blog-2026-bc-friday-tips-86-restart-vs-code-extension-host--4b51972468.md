# BC Friday Tips #86 Restart the VS Code Extension Host

[Read the post](https://thatnavguy.com/blog/2026/bc-friday-tips-86-restart-vs-code-extension-host/) · That NAV Guy (Teddy Herryanto, MVP) · 2026-10-30 · 119 words · tier community · **unreviewed** (model text not yet checked)

> Restarting the VS Code AL extension host via Command Palette can resolve build failures without reloading the entire window, reducing developer interruptions when the AL extension appears stuck.

## Key points

- Run 'Developer: Restart Extension Host' from Command Palette (Ctrl+Shift+P) when AL builds fail
- Restarts only the extension process, not the whole VS Code window
- Resolves errors like 'The package could not be created' without full window reload
- Reduces development workflow interruptions

## Quotes

- "Try running Developer: Restart Extension Host from the Command Palette (Ctrl+Shift+P)." (Provides the exact command to resolve extension issues without window reload)
- "This restarts the process that runs VS Code extensions, including the AL extension, while keeping the window open." (Explains why this approach is faster than reloading the entire VS Code window)
