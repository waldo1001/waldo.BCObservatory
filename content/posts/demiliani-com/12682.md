# Introducing YAMPI: the MCP server for Dynamics 365 Business Central administration.

[Read the post](https://demiliani.com/2025/11/11/introducing-yampi-the-mcp-server-for-dynamics-365-business-central-administration/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2025-11-11 · 1554 words · tier community · reviewed (checked by Opus)

> YAMPI is an open-source Model Context Protocol (MCP) server that enables AI assistants like GitHub Copilot and Claude Desktop to manage Dynamics 365 Business Central environments through natural language commands. It simplifies BC administration by exposing 28 administrative tools across seven categories, eliminating the need to navigate multiple portals and APIs.

## Key points

- YAMPI provides 28 specialized tools organized in seven categories: authentication, environment management, application management, environment updates, session management, notification management, and feature management
- Uses Microsoft Entra ID for enterprise-grade security with intelligent token caching and automatic refresh, avoiding repeated login prompts
- Supports multi-tenant architecture for managing multiple BC tenants with seamless switching and independent secure authentication states
- Can be installed via VS Code extension for GitHub Copilot or via npm for use with other MCP clients like Cursor and Claude Desktop
- Abstracts away complexity of BC administration, enabling junior administrators to perform tasks through guided conversations and reducing the learning curve

## Quotes

- "The MCP server uses Microsoft Entra ID (formerly Azure AD) for authentication, ensuring enterprise-grade security without compromising convenience." (Addresses security concerns while maintaining ease of use, a critical consideration for administrators)
- "The project is open-source and welcomes contributions from the Business Central community." (Signals community-driven development and long-term sustainability of the tool)

## Context

- Features: Environment Management (create, copy, monitor environments), Application Management (view, update, uninstall apps), Session Management (monitor active sessions, terminate sessions), Environment Updates (check and schedule version updates), Notification Management (manage alert recipients), Feature Management (discover, activate, deactivate features), Seamless Authentication via Microsoft Entra ID, Multi-Tenant Support
