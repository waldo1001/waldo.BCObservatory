# Dynamics 365 Business Central on-premises: accessing embedded in-app resources from runtime packages.

[Read the post](https://demiliani.com/2025/08/27/dynamics-365-business-central-on-premises-accessing-embedded-in-app-resources-from-runtime-packages/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2025-08-27 · 367 words · tier community · **unreviewed** (machine-generated)

> Business Central 2024 Wave 2 introduced embedded resources in extensions, but runtime packages lacked support until version 26.3. Use the resourceFolders property in app.json and NavApp.GetResource to access images and files in your AL extensions.

## Key points

- Extensions can declare resource folders using the resourceFolders property in app.json
- AL code accesses embedded resources via the NavApp.GetResource method
- Runtime packages did not support embedded resources until version 26.3 on-premises
- Partners often use runtime packages to protect intellectual property by excluding AL code
- Full extension packages were required as a workaround on versions 26.2 and earlier

## Quotes

- "Embedded resources on runtime packages are not supported in Dynamics 365 Business Central with version <= 26.2." (Clarifies the limitation that existed and caused troubleshooting issues)
