# Dynamics 365 Business Central: finally we’ll have TRUNCATE table in SaaS.

[Read the post](https://demiliani.com/2025/08/04/dynamics-365-business-central-finally-well-have-truncate-table-in-saas/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2025-08-04 · 328 words · tier community · **unreviewed** (machine-generated)

> Business Central version 27 introduces the Rec.Truncate AL method to enable efficient bulk deletion of table rows in SaaS environments. This method supports filters and AutoIncrement field management but has limitations including no support for OnDelete triggers, media fields, or use within try functions.

## Key points

- New Rec.Truncate method in version 27 allows efficient bulk deletion matching filters with fewer operations than DeleteAll
- Method requires delete permission and no security filters on the table to execute
- When used with filters, the platform copies data to temporary table for overhead; recommended only for significant row deletions
- Does not support tables with OnDelete triggers, media/mediaset fields, try functions, or filters on FlowFields
- AutoIncrement fields can be reset to 0 or set to their pre-truncation value through method parameters

## Quotes

- "This method lets developers delete table rows, matching filters in the most efficient way." (Describes the core capability of Truncate for efficient bulk operations that are significantly faster than DeleteAll)
- "Only use filters when you're deleting significant numbers of rows (using filters for smaller deletions creates unnecessary overhead)." (Important performance guidance for developers to avoid overhead when using the feature)
