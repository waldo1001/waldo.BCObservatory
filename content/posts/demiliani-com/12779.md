# Evaluating LLMs performances for your AI task: presenting my LLMEvaluator.

[Read the post](https://demiliani.com/2025/11/17/evaluating-llms-performances-for-your-ai-task-presenting-my-llmevaluator/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2025-11-17 · 1164 words · tier community · **unreviewed** (machine-generated)

> LLMEvaluator is a Windows application for systematically comparing Azure OpenAI models across custom tasks by measuring response time, token consumption, costs, and ROI indicators. It helps organizations select the best AI model for their specific needs by running concurrent evaluations and providing comprehensive performance metrics.

## Key points

- Evaluation requires defining metrics aligned with your specific use case (accuracy, speed, relevance, etc.), not relying solely on public benchmarks
- LLMEvaluator runs concurrent Azure OpenAI model evaluations using semaphore-based throttling to compare performance in parallel
- The application measures eight key metrics including response time, token consumption, throughput, cost estimation, and compression ratio
- ROI indicator (1-10 scale) combines response time (45%), cost (45%), and output tokens (10%) to recommend the best model for your task
- Models are configured in appsettings.json with endpoints, API keys, deployment names, and per-million-token pricing for cost comparisons

## Quotes

- "Remember that there's rarely one best model, but the best model depends heavily on your specific priorities and constraints." (Explains that model selection is contextual and depends on individual business tradeoffs between speed, cost, and performance)
