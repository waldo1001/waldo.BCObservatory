# GitHub Copilot sessions: obtaining tips for better usage.

> GitHub Copilot's Chronicle feature saves and indexes your coding sessions in a local SQLite database, letting you search past work with natural language queries and receive tips to optimize usage and reduce costs.

[Read the post](https://demiliani.com/2026/06/23/github-copilot-sessions-obtaining-tips-for-better-usage/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2026-06-23 · 698 words · tier community · **unreviewed** (machine-generated)

## Key points

- Chronicle tracks session metadata, conversation turns, files touched, and external references in a searchable local database
- Secrets like tokens and API keys are automatically filtered before cloud sync
- Commands like /chronicle:tips and /chronicle:cost-tips analyze your recent sessions to suggest improvements
- VS Code stores chat sessions per-workspace in workspace storage, while Copilot CLI stores sessions globally in ~/.copilot/session-state/
- You can export, import, or manually copy session files when migrating between machines
