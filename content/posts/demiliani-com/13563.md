# Dynamics 365 Business Central: how many Copilot Credits my Agent consumes?

[Read the post](https://demiliani.com/2026/03/24/dynamics-365-business-central-how-many-copilot-credits-my-agent-consumes/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2026-03-24 · 404 words · tier community · **unreviewed** (machine-generated)

> Dynamics 365 Business Central Agents consume Copilot credits during execution. Users can monitor credit consumption directly in Business Central through the Agent page's View consumption data option, which shows monthly usage by task and the specific Copilot features used.

## Key points

- Copilot credits for Business Central Agents can be purchased through Power Platform Admin Center via prepaid packs or pay-as-you-go subscriptions
- Linking Business Central environments to Power Platform environments is required for pay-as-you-go billing and to track consumption per environment
- Agent consumption data is accessible via the Agent page's View consumption data action, showing monthly execution details and credit usage by task
- Only users with SUPER or AGENT - DIAGNOSTICS permission sets can view Copilot credits billing details; AGENT - ADMIN permission is insufficient

- "you can now monitor the consume of Copilot credits for your Agents directly in Business Central" (Highlights the built-in monitoring capability that most Business Central users and partners are not aware of)
- "The consumption overview of Business Central agents can be visible only to users with SUPER or AGENT - DIAGNOSTICS permission set assigned" (Clarifies the specific security requirements for accessing billing data, correcting a common misunderstanding about AGENT - ADMIN permissions)
