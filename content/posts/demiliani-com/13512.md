# Dynamics 365 Business Central: using the standalone MCP Server provided as part of the AL Development Tools.

[Read the post](https://demiliani.com/2026/03/09/dynamics-365-business-central-using-the-standalone-mcp-server-provided-as-part-of-the-al-development-tools/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2026-03-09 · 477 words · tier community · reviewed (checked by Opus)

> Version 17.X of the AL Development Tools .NET package adds a launchmcpserver command. It starts an MCP server, HTTP on port 5000 by default, that lets AI coding agents run AL tasks on a project: build, publish, debug, set breakpoints, snapshot debugging, download symbols and symbol search. The tools are experimental. The package itself compiles and packages extensions outside VS Code for CI/CD.

## Key points

- AL Development Tools is a cross-platform NuGet-based package for compiling and packaging Business Central extensions outside Visual Studio Code
- The launchmcpserver command launches an HTTP-based MCP server that AI agents can use to invoke AL development tools
- Available tools include building, debugging, downloading symbols, publishing, setting breakpoints, snapshot debugging, and symbol searching
- The server supports configurable options like port, transport mode, telemetry, ruleset, and output folder
- These tools are experimental and designed to streamline AL development workflows with AI assistance
