# Dynamics 365 Business Central: using SFTP from AL (the native way)

[Read the post](https://demiliani.com/2026/04/13/dynamics-365-business-central-using-sftp-from-al-the-native-way/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2026-04-13 · 682 words · tier community · reviewed (checked by Opus)

> Business Central 2026 Wave 1 introduced a native SFTP Client codeunit for connecting to SFTP servers from AL code with multiple authentication methods, though Microsoft announced in April 2026 that this module would be removed due to platform hardening requirements.

## Key points

- The SFTP Client codeunit in the System Application wraps the SSH.NET library so AL code can talk directly to SFTP servers
- Supported sign-in methods are username with password, or username with a private key, with or without a passphrase
- You must register the server's fingerprint, a short hash of its public key, before connecting; this guards against man-in-the-middle attacks
- GetFileAsStream downloads a file, ListFiles lists a path, and DeleteFile removes a remote file; the connection is stateful and needs Disconnect when done
- An April 27, 2026 update says Microsoft will remove or deprecate the module, so Azure Functions and similar alternatives are needed again

## Quotes

- "With Dynamics 365 Business Central 2026 Wave 1 release (v28) Microsoft introduced a new SFTP Client module in System Application" (Establishes that this is a new native capability added in the 2026 Wave 1 release)
- "You must always add the fingerprint of the server you want to connect to, before connecting." (Critical security requirement for establishing trusted SFTP connections)
