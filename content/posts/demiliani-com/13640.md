# Dynamics 365 Business Central: using SFTP from AL (the native way)

> Business Central 2026 Wave 1 introduced a native SFTP Client codeunit for connecting to SFTP servers from AL code with multiple authentication methods, though Microsoft announced in April 2026 that this module would be removed due to platform hardening requirements.

[Read the post](https://demiliani.com/2026/04/13/dynamics-365-business-central-using-sftp-from-al-the-native-way/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2026-04-13 · 682 words · tier community · **unreviewed** (machine-generated)

## Key points

- SFTP Client codeunit in System Application uses SSH.NET library for both synchronous and asynchronous SFTP operations
- Supported authentication methods include username/password, username/private key with or without passphrase
- Server fingerprint (SHA256 hash of public key) must be verified before connecting to prevent man-in-the-middle attacks
- Available methods include GetFileAsStream for downloads, ListFiles for directory listing, and DeleteFile for remote file deletion
- Connection is stateful and must be explicitly closed with SFTPClient.Disconnect()

## Quotes

- "You must always add the fingerprint of the server you want to connect to, before connecting." (Critical security requirement for establishing trusted SFTP connections)
