# Securely accessing an Azure OpenAI model from an Azure Logic Apps Standard AI agent using a Private Endpoint.

> Azure Logic Apps Standard can securely connect to Azure OpenAI through a private endpoint without public internet exposure. The post explains how to configure a virtual network with subnets, create a private endpoint for Azure OpenAI, disable public access, enable VNet integration on Logic Apps, and use managed identity authentication instead of API keys.

[Read the post](https://demiliani.com/2026/06/16/securely-accessing-an-azure-openai-model-from-an-azure-logic-apps-standard-ai-agent-using-a-private-endpoint/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2026-06-16 · 1897 words · tier community · **unreviewed** (machine-generated)

## Key points

- Private endpoint creates a private network interface for Azure OpenAI accessible via a private IP within the VNet
- Logic Apps Standard requires VNet integration with subnet delegation to route outbound traffic privately
- System-assigned managed identity replaces API key authentication, following least privilege with Cognitive Services OpenAI User role
- DNS resolution within VNet returns the private IP, while external traffic sees public IP which is disabled after setup
- All traffic flows through Microsoft backbone network infrastructure, never reaching the public internet
