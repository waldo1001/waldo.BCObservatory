# YAMPI (the Dynamics 365 Business Central Administration MCP Server): installing apps from Microsoft’s Marketplace.

[Read the post](https://demiliani.com/2026/03/17/yampi-the-dynamics-365-business-central-administration-mcp-server-installing-apps-from-microsofts-marketplace/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2026-03-17 · 149 words · tier community · reviewed (checked by Opus)

> YAMPI version 1.2.1 adds the ability to install Marketplace apps (AppSource) in Dynamics 365 Business Central tenants through AI tools. The tool can resolve app details, check installation status, and manage dependencies automatically.

## Key points

- YAMPI is the author's Business Central administration MCP server, now at version 1.2.1
- The update adds installing Marketplace (AppSource) apps into a tenant environment
- YAMPI resolves the app by ID or name, checks whether it is already installed, and installs it along with required dependencies
- Users can now manage Marketplace apps and PTEs on a tenant through AI tools
- Install or upgrade with npm install -g @demiliani/d365bc-admin-mcp@1.2.1, then restart VS Code or the AI tool

## Quotes

- "Now you can fully manage Marketplace apps and PTE on a given tenant easily with AI." (Highlights the practical benefit of the tool: AI-assisted management of applications without manual intervention, improving administrative efficiency)
