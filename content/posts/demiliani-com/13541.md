# YAMPI (the Dynamics 365 Business Central Administration MCP Server): installing apps from Microsoft’s Marketplace.

> YAMPI version 1.2.1 adds the ability to install Marketplace apps (AppSource) in Dynamics 365 Business Central tenants through AI tools. The tool can resolve app details, check installation status, and manage dependencies automatically.

[Read the post](https://demiliani.com/2026/03/17/yampi-the-dynamics-365-business-central-administration-mcp-server-installing-apps-from-microsofts-marketplace/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2026-03-17 · 149 words · tier community · **unreviewed** (machine-generated)

## Key points

- YAMPI is an Administration MCP server for managing Dynamics 365 Business Central through AI tools
- Version 1.2.1 introduces Marketplace app installation capability from AppSource
- The tool automatically checks if apps are installed and resolves required dependencies
- Users can manage Marketplace apps and PTE (Private Tab Extension) through natural language AI requests
- Installation is done via npm with the command npm install -g @demiliani/d365bc-admin-mcp@1.2.1
