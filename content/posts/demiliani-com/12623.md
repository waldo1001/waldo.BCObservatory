# Dynamics 365 Business Central: previewing PDF files in web client using the new ExtendedDataType = Document.

[Read the post](https://demiliani.com/2025/10/14/dynamics-365-business-central-previewing-pdf-files-in-web-client-using-the-new-extendeddatatype-document/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2025-10-14 · 418 words · tier community · **unreviewed** (machine-generated)

> Dynamics 365 Business Central 2025 Wave 2 introduces a new ExtendedDataType called Document that enables PDF file previews in web client FactBoxes. Developers can use Media fields with this data type to display PDF files as images in CardPart and ListPart pages by converting them using the PDF Document codeunit.

## Key points

- New Document ExtendedDataType available in v27 with AL Language 16.x for Media and MediaSet fields
- Allows rendering PDF files and images in FactBox elements (CardPart and ListPart pages)
- PDF files must be converted to images using the ConvertToImage method before preview
- Implementation requires loading PDF content into InStream, converting to image format, and importing into Media field
