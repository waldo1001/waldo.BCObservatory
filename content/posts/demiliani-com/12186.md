# Using Azure AI Foundry Model Router in your AI projects.

[Read the post](https://demiliani.com/2025/07/29/using-azure-ai-foundry-model-router-in-your-ai-projects/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2025-07-29 · 1219 words · tier community · **unreviewed** (machine-generated)

> Azure AI Foundry Model Router intelligently routes LLM requests to the most suitable model based on query complexity, cost, and performance requirements. It achieves up to 60% cost savings by automatically selecting smaller models for simple tasks and larger models for complex reasoning, packaged as a single deployment that simplifies integration with standard APIs.

## Key points

- Model Router acts as a meta-orchestrator that evaluates prompts in real-time and routes them to appropriate underlying models like gpt-4.1-nano, gpt-4.1-mini, gpt-4.1, or o4-mini
- Achieves significant cost reductions by routing simpler queries to smaller, cheaper models while maintaining accuracy
- Integrates via standard Chat Completions API with a single endpoint, decoupling application logic from specific AI models
- Context window is limited by the smallest underlying model, which may cause failures if prompts exceed that model's capacity
- AL Copilot SDK currently does not support Model Router endpoints, requiring alternative approaches like custom AI layers for Business Central integrations
