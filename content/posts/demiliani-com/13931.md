# Dynamics 365 Business Central: Using Semantic Search from AL

[Read the post](https://demiliani.com/2026/06/26/dynamics-365-business-central-using-semantic-search-from-al/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2026-06-26 · 637 words · tier community · reviewed (checked by Opus)

> Dynamics 365 Business Central now exposes embedding-based semantic search as a native AL capability that understands meaning and context instead of relying on exact keyword matches. This feature uses vector embeddings stored in Azure SQL Database and is currently available for on-premises deployments through the System.Search.Semantic Search codeunit.

## Key points

- Semantic search converts text into numerical embeddings that capture meaning, allowing searches to find results based on intent and similarity rather than exact word matches
- The implementation stores vectors in Azure SQL Database and caches embeddings in the tenant database with background processing for metadata
- Developers access semantic search via System.Search.Semantic Search codeunit with methods to set search targets, max results, and perform similarity searches on specified fields
- Currently limited to on-premises deployments with target OnPrem, with plans to extend to SaaS in version 29
