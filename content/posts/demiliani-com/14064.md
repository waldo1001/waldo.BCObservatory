# How can I move my Business Central-related Azure resources to a new Azure region?

[Read the post](https://demiliani.com/2026/08/10/how-can-i-move-my-business-central-related-azure-resources-to-a-new-azure-region/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2026-08-10 · 3849 words · tier community · reviewed (checked by Opus)

> Guide for migrating Business Central-related Azure and Power Platform resources from West Europe or North Europe to the new Italy North region. Covers strategic reasons for migration, detailed step-by-step procedures for Azure services (Application Insights, Storage, Function Apps, Logic Apps, SQL Database, Azure OpenAI) and Power Platform environments, migration strategies to minimize downtime, cost considerations, and post-migration reconfiguration tasks.

## Key points

- Moving Azure services to Italy North is optional; average latency is about 22 ms from Italy North to West Europe, so most services are barely affected.
- Most Azure resources (Application Insights, Storage, Function Apps, Logic Apps, Azure OpenAI) are recreated in the new region and their data and settings copied over; Azure SQL can also use Resource Mover.
- Power Platform geo-to-geo migration requires a Microsoft Support request at least 10 days ahead, involves downtime and cannot run in parallel with the old environment.
- Canvas apps and flows outside solutions, enterprise policies, DLP rules and environment groups do not migrate and must be recreated.
- Business Central needs updated connection strings and endpoints afterward, such as the telemetry connection string and the Power Platform environment references.
