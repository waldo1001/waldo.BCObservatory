> Azure Logic Apps Standard now supports Model Context Protocol (MCP) servers, allowing organizations to create AI-powered agent tools for Dynamics 365 Business Central and other enterprise applications through low-code workflows. This integration enables seamless AI agent execution within integration platforms without complex orchestration layers.

## Key points

- MCP servers standardize how AI agents interact with external systems, and Azure Logic Apps Standard provides built-in connectors to create them for Business Central
- Existing workflows can be converted into discoverable MCP tools that agents can call securely through low-code configuration
- Authentication options include OAuth and key-based methods, with API keys generated for MCP server access
- MCP servers can be used from AI client tools like GitHub Copilot to interact with Business Central data at scale
- Multiple MCP tools can be shared across workflows and applications, reducing integration complexity
