# YAMPI (Dynamics 365 Business Central Admin MCP Server) version 2.0.x: a ground-up refresh.

[Read the post](https://demiliani.com/2026/11/17/yampi-dynamics-365-business-central-admin-mcp-server-version-2-0-x-a-ground-up-refresh/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2026-11-17 · 1377 words · tier community · **unreviewed** (model text not yet checked)

> YAMPI is an open-source MCP Server that enables AI assistants like GitHub Copilot and Claude to perform advanced Business Central administration tasks through natural language. Version 2.0 is a comprehensive refresh that expands tools from 34 to 52, upgrades to .NET 10, adds environment lifecycle management, PTE deployment via Admin Center API, enhanced security confirmations, and cross-platform support with improved reliability and testing.

## Key points

- 18 new tools added including environment lifecycle management (rename, restore, recover), database export, security group access control, and M365 license control
- PTE deployment moved from deprecated Automation API to Admin Center API v2.29 with batch folder deployment and dependency ordering
- Production environment changes now require confirmation prompts and destructive tools are marked for safer operation
- Sign-in credentials cached in OS token storage (DPAPI/Keychain/keyring) across sessions rather than memory only
- Platform support expanded to Windows, Linux, and macOS on both x64 and ARM64 architectures with 103 automated tests and CI pipeline

## Quotes

- "The sign-in is now stored in the operating system's encrypted token cache (Windows DPAPI, macOS Keychain, Linux keyring), so it survives restarts." (Demonstrates improved usability and security compared to in-memory session-only credentials)
- "Packages are published with npm trusted publishing (OIDC): no npm token is stored anywhere, and every package carries a provenance attestation." (Highlights security best practices for open-source distribution and artifact verification)

## Context

- Features: Environment lifecycle management, PTE deployment automation, Database export to Azure Storage, Microsoft Entra security group control, M365 license access management, Interactive authentication, Scheduled operations management, MCP protocol support
- Versions: 2.0.1, 2.29 (Admin Center API)
