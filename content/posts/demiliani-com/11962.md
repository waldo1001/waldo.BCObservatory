# Dynamics 365 Business Central: compressing API responses at max.

[Read the post](https://demiliani.com/2025/06/23/dynamics-365-business-central-compressing-api-responses-at-max/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2025-06-23 · 761 words · tier community · **unreviewed** (machine-generated)

> This post explains how to use Brotli compression instead of gzip to reduce the size of OData API responses from Business Central. Brotli significantly decreases bandwidth usage and transfer times for high-volume API calls by achieving better compression ratios than the default gzip algorithm.

## Key points

- Business Central APIs use HTTP compression by default, primarily gzip, which can be negotiated through Accept-Encoding headers
- Brotli is a more efficient compression algorithm that reduces response sizes dramatically compared to gzip, often by 95% or more for large datasets
- Clients enable Brotli by sending the Accept-Encoding: br header with their API requests
- In C#, HttpClient can automatically decompress Brotli-compressed responses when configured with AutomaticDecompression and the appropriate header
