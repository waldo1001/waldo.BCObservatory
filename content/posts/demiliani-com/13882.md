# Dynamics 365 Business Central: using AL MCP Server from GitHub Copilot CLI.

> The AL MCP Server exposes AL development tools through the Model Context Protocol, allowing CLI-based AI agents to perform AL operations like building, compiling, and publishing without Visual Studio Code. Install via dotnet tool and configure in GitHub Copilot CLI to automate AL development workflows in CI/CD pipelines and agent-driven scenarios.

[Read the post](https://demiliani.com/2026/06/18/dynamics-365-business-central-using-al-mcp-server-from-github-copilot-cli/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2026-06-18 · 387 words · tier community · **unreviewed** (machine-generated)

## Key points

- AL MCP Server runs as a standalone process that exposes AL development tools over the Model Context Protocol for any MCP-compatible AI agent
- Install via dotnet tool command: dotnet tool install --global microsoft.dynamics.businesscentral.development.tools --prerelease
- Configure in GitHub Copilot CLI by adding MCP server with name, selecting STDIO type, and entering command: al launchmcpserver
- Enables automated workflows where agents call AL tools in sequence like al_downloadsymbols, al_compile, and al_getdiagnostics for CI/CD validation
- Supports AppSource validation by running code analysis with AppSourceCop and filtering diagnostics by specific areas
