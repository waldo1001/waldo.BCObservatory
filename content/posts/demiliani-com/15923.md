# Azure Functions: rolling updates are now generally available on Flex consumption.

> Azure Functions Flex Consumption plan now supports rolling updates for zero-downtime deployments. This feature gradually replaces instances instead of restarting all at once, allowing in-progress executions to complete and maintaining availability during deployment.

[Read the post](https://demiliani.com/2026/09/17/azure-functions-rolling-updates-are-now-generally-available-on-flex-consumption/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2026-09-17 · 626 words · tier community · **unreviewed** (machine-generated)

## Key points

- Rolling updates drain instances in small batches and scale out new instances with updated code to maintain capacity
- Feature is only available on Flex Consumption plan, not on Consumption or Premium plans
- Requires backward-compatible changes since old and new instances run together briefly during deployment
- Comparison shows deployment slots on other plans don't guarantee zero downtime like rolling updates do

## Quotes

- "Instead of restarting everything at once, with this feature active the platform now replaces instances gradually." (Explains the core mechanism of rolling updates that enables zero-downtime deployments)
- "Your changes need also to be backward compatible." (Critical constraint for using rolling updates since old and new versions run concurrently)
- "If you need true continuity for long-running or critical functions, rolling updates on Flex Consumption is the only option that delivers it today." (Clarifies when rolling updates are necessary versus when simpler strategies suffice)
