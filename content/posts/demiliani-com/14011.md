# Visual Studio Code Agent hook for auditing your AL coding sessions.

> Visual Studio Code Agent Hooks enable custom shell commands to execute at specific points during agent sessions to audit, enforce security policies, and log file access and tool usage. This is useful for compliance when AI coding agents modify AL projects, capturing details that Git history alone cannot track.

[Read the post](https://demiliani.com/2026/07/30/visual-studio-code-agent-hook-for-auditing-your-al-coding-sessions/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2026-07-30 · 1132 words · tier community · **unreviewed** (machine-generated)

## Key points

- Agent Hooks intercept the agent loop deterministically at lifecycle events (SessionStart, PreToolUse, PostToolUse, Stop, etc.), unlike agent skills which are probabilistically invoked by the model.
- Hooks capture an audit trail of every file read/write, terminal commands, and tool calls with timestamps and session IDs, which Git alone cannot provide.
- Eight hook events are available to run custom commands at predefined stages during agent sessions for security, compliance, code quality, and workflow automation.
- Hooks sit at the policy-enforcement layer outside agent reasoning, enabling security guardrails like preventing dangerous operations (rm -rf, DROP TABLE) and enforcing code standards.
