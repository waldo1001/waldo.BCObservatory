# Dynamics 365 Business Central: introducing the new MaskedType enum field-level property.

[Read the post](https://demiliani.com/2025/09/18/dynamics-365-business-central-introducing-the-new-maskedtype-enum-field-level-property/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2025-09-18 · 400 words · tier community · **unreviewed** (machine-generated)

> Dynamics 365 Business Central 2025 Wave 2 introduces a new MaskType enum property for table fields that allows masking sensitive information in the UI. Users can toggle visibility with an eye button to reveal concealed field values on demand, providing protection from casual observation while allowing authorized access.

## Key points

- MaskType enum property supports None (default, visible) and Concealed (hidden by default, revealed via eye button) values
- Supported on Code, Text, Decimal, and Integer fields only, and only on document and card pages, not on list page repeaters or grids
- Works on web client and mobile client; cannot be used together with ExtendedDatatype = Masked property
- Available starting from Dynamics 365 Business Central version 27.1 and requires enabling via Feature Management
- Provides UI-layer protection only; unmasked data is still transmitted to the web browser

## Quotes

- "The new property will be available starting from Dynamics 365 Business Central version 27.1 and it will not be enabled by default." (Critical implementation detail about when the feature becomes available and that it requires explicit enablement via Feature Management)
