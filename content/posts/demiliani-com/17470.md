# Dynamics 365 Business Central license keys: what changes from version 28.

[Read the post](https://demiliani.com/2026/10/05/dynamics-365-business-central-license-keys-what-changes-from-version-28/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2026-10-05 · 473 words · tier community · **unreviewed** (machine-generated)

> Starting October 1, 2026, Dynamics 365 Business Central on-premises and Dual Use Rights licenses no longer use version-specific keys. Instead, a single '28+' key family applies to all versions 28 and later, requiring administrators to download a refreshed license file before each version upgrade to unlock new objects.

## Key points

- Version-specific license keys are discontinued; '28+' is the unified key for all on-premises editions and DUR licenses
- A fresh 28+ key must be downloaded before upgrading to each new version, with the download date determining which objects unlock
- Dual Use Rights deployments have a separate six-month key renewal requirement independent of the 28+ upgrade rule
- Administrators must add license key download to upgrade checklists and track DUR key expiry dates

## Quotes

- "new releases of Dynamics 36 Business Central no longer include version-specific license keys for on-premises" (Clarifies the fundamental change in licensing strategy that affects all on-premises deployments starting October 1, 2026)
- "you must download a refreshed 28+ key if you want to upgrade to the latest version" (Establishes the new mandatory step in every upgrade process and the ongoing operational burden)
