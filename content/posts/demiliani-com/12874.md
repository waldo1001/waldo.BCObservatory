# “Hacking” Google Antigravity to develop AL extensions for Dynamics 365 Business Central.

[Read the post](https://demiliani.com/2025/11/26/hacking-google-antigravity-to-develop-al-extensions-for-dynamics-365-business-central/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2025-11-26 · 559 words · tier community · **unreviewed** (machine-generated)

> Google Antigravity is an agentic development platform that can be configured to develop AL extensions for Dynamics 365 Business Central by manually adding Visual Studio Code marketplace URLs and installing the AL Language extension via VSIX file. This enables developers to leverage AI-powered coding in an agent-first interface with full AL development capabilities.

## Key points

- Antigravity uses Open VSX marketplace by default, but accessing Visual Studio Code marketplace requires adding hidden API URLs to settings
- The Microsoft AL extension for Business Central is not available in Open VSX and must be installed manually from a VSIX package downloaded from the marketplace
- After configuration, Antigravity provides full AL coding experience with intellisense, compilation, AI assistance via Gemini 3 Pro, and direct publishing to Business Central online sandbox
- Antigravity's agent-first interface with multiple coordination modes differs from traditional AI coding assistants like Cursor or GitHub Copilot
