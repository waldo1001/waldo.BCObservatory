# Dynamics 365 Business Central 2025 Wave 1 release: the state of SOAP deprecation.

[Read the post](https://demiliani.com/2025/04/07/dynamics-365-business-central-2025-wave-1-release-the-state-of-soap-deprecation/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2025-04-07 · 360 words · tier community · **unreviewed** (machine-generated)

> Dynamics 365 Business Central 2025 Wave 1 (version 26) begins deprecating SOAP web services for Microsoft UI pages, disabling this capability by default while allowing re-enablement via Feature Management. Custom UI pages exposed as SOAP will continue working through version 28, but the feature will be completely removed in version 29, requiring migration to OData or API endpoints.

## Key points

- SOAP exposure for Microsoft UI pages is disabled by default in version 26, with permanent removal planned for version 29
- Custom UI pages using SOAP will continue working but should migrate to OData endpoints
- New RT0053 telemetry signal available in version 26 to identify tenants using deprecated SOAP endpoints
- Microsoft UI pages exposed as OData endpoints will receive warnings starting version 26 and be disabled in version 30
- Custom OData endpoints for UI pages continue working in version 26 but should migrate to API endpoints

## Quotes

- "With version 26, the possibility to expose a Microsoft page as SOAP endpoint will be disabled by default." (Clarifies that the deprecation is implemented as a default change that customers can temporarily override)
- "Please remember that in Dynamics 365 Business Central version 29 the possibility to expose a Microsoft page as SOAP endpoint will be removed forever." (Sets a hard deadline for SOAP migration, giving customers a defined window for action)

## Context

- Features: SOAP web services on Microsoft UI pages, OData endpoints for Microsoft UI pages, RT0053 telemetry signal, Feature Management control, API endpoints
- Versions: 26, 29, 30
