# Dynamics 365 Business Central: automatic .NET runtime acquisition on AL Language Extension.

[Read the post](https://demiliani.com/2026/09/07/dynamics-365-business-central-automatic-net-runtime-acquisition-on-al-language-extension/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2026-09-07 · 434 words · tier community · **unreviewed** (machine-generated)

> The AL Language extension now automatically downloads and installs .NET 10.0 runtime on startup instead of bundling platform-specific binaries. This reduces extension size from 500MB to under 25MB and simplifies maintenance, but creates a workaround issue with BCContainerHelper that requires users to manually install .NET 10 beforehand.

## Key points

- AL Language extension uses automatic .NET Install Tool for .NET 10.0 runtime acquisition
- Extension size dramatically reduced by eliminating bundled platform-specific runtime packages
- Fallback mechanism to existing ASP.NET Core runtime provides graceful degradation on download failure
- BCContainerHelper's auto-download logic is broken with new .NET 10 requirement, requiring manual .NET 10 installation
- Windows, Linux, and macOS users should pre-install .NET 10 to avoid BCContainerHelper build failures
