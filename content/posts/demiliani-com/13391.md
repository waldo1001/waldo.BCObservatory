> BCMCPProxy vNext is a cross-platform .NET proxy that bridges Model Context Protocol clients with Business Central's API, upgraded from a Windows-only proof-of-concept to support macOS and Windows with improved performance, security, and modern .NET 10 architecture.

## Key points

- BCMCPProxy vNext evolved from the original Windows-only Microsoft project to support both Windows and macOS with .NET 10 and C# 13
- Device code flow authentication provides browser-based sign-in with automatic clipboard copying and token caching across sessions
- Performance improved 40-67% through sync-over-async elimination, async I/O, and better memory management
- Cross-platform support includes Intel x64, Apple Silicon ARM64, and ARM64 processors through unified dotnet build
- Security enhanced by removing hardcoded credentials and using platform-native secure storage for token caching
