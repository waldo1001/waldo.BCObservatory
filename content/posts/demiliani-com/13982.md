# The hidden cost of asking AI to do everything…

> Smart AI usage in Business Central requires understanding hidden costs beyond token pricing, including developer idle time and skill erosion. The post advocates for using AI strategically to start work while maintaining human control, learning, and team expertise through intentional design patterns, monitoring, and skill development.

## Key points

- Token costs hide the real problem of developer idle time while AI processes requests, which should be monitored like server metrics
- Overreliance on AI for code generation leads to skill loss in design patterns, system performance, external integrations, and architectural thinking
- Sustainable AI usage means asking AI for initial solutions, then manually improving code to maintain learning and control
- Teams should leverage existing Business Central features, build reusable templates, and document patterns to reduce token dependency
- The true danger is long-term skill erosion that makes teams unable to function without AI support or fix problems independently
