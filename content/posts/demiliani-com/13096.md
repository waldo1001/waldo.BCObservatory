# Dynamics 365 Business Central UI performance: what about the browser and the local machine?

[Read the post](https://demiliani.com/2025/12/29/dynamics-365-business-central-ui-performance-what-about-the-browser-and-the-local-machine/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2025-12-29 · 1894 words · tier community · **unreviewed** (machine-generated)

> Business Central UI performance depends on network latency, browser capabilities, and local machine hardware, not just backend optimization. The post explains how to measure and monitor these client-side factors during go-live and production.

## Key points

- Network latency to Azure datacenters should be 250-300ms or less; higher latency significantly impacts perceived slowness
- Modern browsers (Edge, Chrome, Safari) with adequate storage and proper configuration are essential; multiple tabs consume resources and add ~10 seconds per tab
- Local machine hardware (CPU, RAM, GPU, storage) directly affects browser rendering and JavaScript execution; 16GB+ RAM and Apple Silicon devices perform best
- Page View telemetry provides network metrics; monitoring tools like Speedometer 3.1 benchmark and custom Node.js scripts help measure actual performance
- Client-side factors are often overlooked in infrastructure assessments but can have considerable impact on end-user experience despite backend optimizations

## Quotes

- "Business Central is designed for networks that have a latency of 250 - 300 milliseconds (ms) or less." (Establishes the key performance threshold for network latency that organizations must meet)
