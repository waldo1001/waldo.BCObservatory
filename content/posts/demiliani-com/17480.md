# End of .NET 8 support and what it means for Dynamics 365 Business Central on-prem.

[Read the post](https://demiliani.com/2026/10/12/end-of-net-8-support-and-what-it-means-for-dynamics-365-business-central-on-prem/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2026-10-12 · 805 words · tier community · reviewed (checked by Opus)

> .NET 8 and .NET 9 reach end of support on November 10, 2026, creating a mismatch with Business Central on-premises lifecycle dates. BC 29 supports .NET 10 natively, while BC 27 and 28 are getting cumulative updates to support .NET 10, requiring customers to plan upgrades or updates before the deadline.

## Key points

- .NET 8 (LTS) and .NET 9 (STS) both end support November 10, 2026; .NET 10 is the next LTS release.
- BC 28 on-premises support extends to October 13, 2027, eleven months past .NET 8 end-of-life, creating a security risk.
- BC 29 natively supports .NET 10 for both Business Central Server and web server; BC 27 and 28 are receiving cumulative updates for .NET 10 support.
- Latest BC 28.6 and 27.12 updates already target .NET 10; customers must upgrade or apply updates before November 10.
- .NET 10 does not automatically run .NET 8 applications without configuration changes, which Microsoft does not support for Business Central.

## Quotes

- "BC 29 (2026 release wave 2): this release natively supports .NET 10 for both Business Central Server and the web server components." (Identifies the primary upgrade path that resolves the .NET runtime issue completely.)
- "the latest 28.6 update (October 2026) already targets .NET 10. the latest 27.12 update (October 2026) already targets .NET 10." (Shows that recent cumulative updates provide an alternative path for customers to gain .NET 10 support without major version upgrades.)

## Heads up

- breaking: "After that date there are no more servicing updates, no security fixes and no technical support for either version."
- gotcha: "With only .NET 10 installed, a .NET 8 app fails to start."
- warning: "Forcing the server to roll forward is not a supported configuration, and the runtime is only one part of the story."
