# My MCP server for Dynamics 365 Business Central Administration now supports handling PTEs.

[Read the post](https://demiliani.com/2025/12/10/my-mcp-server-for-dynamics-365-business-central-administration-now-supports-handling-ptes/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2025-12-10 · 332 words · tier community · reviewed (checked by Opus)

> An MCP server for Dynamics 365 Business Central Administration now supports per-tenant extensions (PTEs), allowing users to upload, monitor deployment status, and uninstall PTEs from AI clients like GitHub Copilot through sequential processing that prevents concurrent deployment errors.

## Key points

- Upload single or multiple per-tenant extensions from local .app files or folders to Business Central environments
- Monitor extension deployment status in real-time with configurable polling intervals and maximum wait times
- Sequential processing prevents concurrent deployment conflicts and ensures each extension completes before the next starts
- Comprehensive reporting summarizes successes, failures, and per-file status for batch operations

## Quotes

- "With the latest 1.1.1 version, my MCP server for Dynamics 365 Business Central Administration fully supports handling PTEs in your customer tenants." (Establishes the core capability and scope of the update for administrators managing per-tenant extensions)
- "Sequential Processing: Uploads and installs extensions one at a time, preventing "another operation running" errors that can occur with concurrent deployments." (Highlights the key technical advantage that solves a real problem administrators face with simultaneous PTE deployments)
