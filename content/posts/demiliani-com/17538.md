# Dynamics 365 Business Central: introducing the new “Recent Record” virtual table

[Read the post](https://demiliani.com/2026/10/23/dynamics-365-business-central-introducing-the-new-recent-record-virtual-table/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2026-10-23 · 254 words · tier community · reviewed (checked by Opus)

> Business Central 2026 Wave 2 introduces a new Recent Record virtual table that tracks records recently accessed by the current user in the current company. The read-only table logs only UI interactions and stores references to original records with timestamps, allowing users to clear their access history.

## Key points

- New Recent Record virtual table in the System.Environment namespace, added silently in 2026 Wave 2 (v29), lists records the current user recently accessed in the current company
- Table is read-only (no insert or modify) but rows can be deleted to clear history; fields are TableId and RecordSystemId (primary key), LastUsed and Description
- Only UI interactions are logged; records touched by code, such as reports or actions, are not recorded
- Reopening a record already in the list refreshes its LastUsed value

## Quotes

- "This table (defined in the System.Environment namespace) lists the records most recently accessed by the current user in the current company." (Clarifies the scope and location of the new virtual table for developers implementing user activity tracking.)
- "Records on this table are not logged if a record is managed via code." (Important limitation to understand when using the table for user monitoring, as only UI interactions are captured.)
