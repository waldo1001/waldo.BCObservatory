# Do you have Azure Functions running on Linux Consumption plan? It’s time to migrate…

[Read the post](https://demiliani.com/2025/09/26/do-you-have-azure-functions-running-on-linux-consumption-plan-its-time-to-migrate/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2025-09-26 · 1018 words · tier community · **unreviewed** (machine-generated)

> Azure Functions is retiring the Linux Consumption hosting plan on 30 September 2028. Organizations must migrate applications to the new Flex Consumption plan, which offers customizable resources, predictable performance, advanced networking, longer execution times, and better support for stateful workloads.

## Key points

- Linux Consumption plan will be retired on 30 September 2028; Windows Consumption plan is unaffected
- Flex Consumption plan enables custom CPU, memory, and OS selection with predictable cold starts and consistent pricing
- Migration requires creating a new Flex Consumption app via Azure CLI 2.77.0 or later, then redeploying code from source control or deployment packages
- Flex Consumption supports up to 4-hour execution times, VNET integration, and continuous function running without idle timeouts

## Quotes

- "On 30 September 2028, Microsoft will retire the Azure Functions Linux Consumption hosting plan." (Establishes the hard deadline for migration planning to avoid service disruption)
- "Flex: Lets you choose specific CPU, memory, and OS (Linux/Windows) for your function apps." (Highlights the key advantage of resource customization in Flex Consumption over standard Consumption)
- "The migration process instead has you create a new Flex Consumption plan app that's equivalent to your current app." (Clarifies that migration requires creating a new app rather than upgrading an existing one)

## Context

- Features: Flex Consumption plan, customizable compute and scaling, predictable cold starts, advanced networking, extended execution time, no idle timeout, resource-based pricing
