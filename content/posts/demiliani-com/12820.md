# Dynamics 365 Business Central on-premises and SQL Server 2025.

[Read the post](https://demiliani.com/2025/11/19/dynamics-365-business-central-on-premises-and-sql-server-2025/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2025-11-19 · 418 words · tier community · reviewed (checked by Opus)

> SQL Server 2025 introduces significant improvements for Dynamics 365 Business Central on-premises environments, including higher resource limits for Standard Edition, enhanced columnstore indexes, improved locking and query optimization, persistent statistics on secondary replicas, AI capabilities, and Fabric mirroring support.

## Key points

- SQL Server 2025 Standard Edition raises limits to 32 CPU cores and 256 GB RAM, up from 24 cores and 128 GB
- Ordered columnstore indexes can be built or rebuilt online; online ordered clustered builds sort in tempdb, which can help queries but slow the build
- Optional Parameter Plan Optimization chooses plans from runtime parameters, easing parameter sniffing problems
- Statistics now persist on secondary replicas after restart or failover, avoiding rebuilds
- Adds AI endpoint calls, vector types and search, and Fabric mirroring; in-place upgrade is supported from SQL Server 2014, and 2016 support ends in 2026

## Quotes

- "With SQL Server 2025, statistics are now preserved on secondary replicas, even after a restart or failover." (Eliminates a common cause of performance degradation in high-availability BC configurations after failover events)

## Context

- Features: SQL Server 2025 Standard Edition resource limits, Ordered nonclustered columnstore indexes, Online columnstore index creation, Optional Parameter Plan Optimization (OPPO), Improved locking management, Persistent statistics on secondary replicas, Vector data type and functions, Fabric mirroring with change feed capability
- Versions: SQL Server 2025, SQL Server 2024, SQL Server 2016, SQL Server 2014
