# Dynamics 365 Business Central on-premises and SQL Server 2025.

[Read the post](https://demiliani.com/2025/11/19/dynamics-365-business-central-on-premises-and-sql-server-2025/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2025-11-19 · 418 words · tier community · **unreviewed** (machine-generated)

> SQL Server 2025 introduces significant improvements for Dynamics 365 Business Central on-premises environments, including higher resource limits for Standard Edition, enhanced columnstore indexes, improved locking and query optimization, persistent statistics on secondary replicas, AI capabilities, and Fabric mirroring support.

## Key points

- SQL Server 2025 Standard Edition now supports up to 32 CPU cores and 256GB RAM, nearly double the previous limits
- Columnstore indexes can now be created or rebuilt online using tempdb for improved query performance
- Optional Parameter Plan Optimization (OPPO) reduces parameter sniffing issues and ensures more predictable query performance
- Statistics are preserved on secondary replicas after failover, preventing performance degradation from statistics rebuild
- New AI-ready capabilities include sp_invoke_external_rest_endpoint, vector data type, and vector search functionality

## Quotes

- "With SQL Server 2025, statistics are now preserved on secondary replicas, even after a restart or failover." (Eliminates a common cause of performance degradation in high-availability BC configurations after failover events)
