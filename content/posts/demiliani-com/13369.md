# Dynamics 365 Business Central: monitoring your customer’s network speed from telemetry.

[Read the post](https://demiliani.com/2026/02/06/dynamics-365-business-central-monitoring-your-customers-network-speed-from-telemetry/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2026-02-06 · 428 words · tier community · **unreviewed** (machine-generated)

> Business Central now includes hardware and network telemetry parameters in page views, such as network bandwidth (downlink) and round-trip time. These metrics help diagnose whether slow page performance is caused by client infrastructure issues rather than application code, and can be analyzed using KQL queries to correlate network conditions with page duration.

## Key points

- New deviceHardware telemetry node contains CPU cores, memory, network downlink speed (Mb/s), and round-trip time (ms) for client connections
- Network bandwidth data helps distinguish between infrastructure-related slowness and code performance issues
- KQL queries can correlate bandwidth trends with page view duration over time to identify performance anomalies
- High bandwidth should correlate with shorter page duration; if not, the page code may need optimization
