# Dynamics 365 Business Central: matching Production database configuration for Sandboxes.

[Read the post](https://demiliani.com/2026/10/26/dynamics-365-business-central-matching-production-database-configuration-for-sandboxes/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2026-10-26 · 283 words · tier community · **unreviewed** (model text not yet checked)

> Dynamics 365 Business Central 2026 Wave 2 introduces the ability to temporarily match a sandbox environment's database configuration to production-level performance for 72 hours, enabling realistic testing and performance validation without deploying to production.

## Key points

- Sandbox environments can now temporarily match production database configuration for 72 hours through Admin Center
- Configuration automatically reverts after 72 hours during the next scheduled update
- Maximum of 3 operations allowed per month per tenant
- Feature available via Admin Center API and supports all paid license types including Partner Sandbox environments
- Useful for testing app performance, Performance Toolkit, and Cloud Migration scenarios

## Quotes

- "This action temporarily matches your sandbox environment's database configuration to that of a typical production environment for 72 hours." (Explains the core functionality: sandboxes can now simulate production performance temporarily for realistic testing.)
- "After the 72 hours time limit, the sandbox environment configuration will be restored during the next update window." (Important technical detail showing automatic restoration prevents permanent sandbox modifications.)
- "This operation will be supported also via Admin Center API and it's available on all tenants with paid license types, including Partner Sandbox environments." (Clarifies accessibility and programmatic capability for partners and customers with various license types.)
