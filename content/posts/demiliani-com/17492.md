# Securing your Azure Storage Account: a guide to enabling Business Central-only access using Network Security Perimeter (part2) – now with Service Tags.

[Read the post](https://demiliani.com/2026/10/13/securing-your-azure-storage-account-a-guide-to-enabling-business-central-only-access-using-network-security-perimeter-part2-now-with-service-tags/) · Stefano Demiliani (Stefano Demiliani, MVP) · 2026-10-13 · 390 words · tier community · **unreviewed** (model text not yet checked)

> Azure Network Security Perimeter now supports service tags for inbound access rules, allowing Business Central administrators to simplify Azure Storage Account security configuration. Instead of maintaining IP allowlists, organizations can reference the Dynamics365BusinessCentral service tag, with Microsoft automatically updating the underlying IP ranges.

## Key points

- Service tag support for NSP inbound rules eliminates the need to manually track individual IP addresses
- The Dynamics365BusinessCentral service tag can be used as the source for NSP inbound access rules
- Service tags are broad by design and cover multiple Microsoft service instances, requiring trust at the service level rather than per-instance
- Administrators should consider stricter isolation options like specific IP ranges or subscription-based rules if service-level trust is not acceptable

## Quotes

- "Microsoft automatically updates the IP address prefixes associated with a service tag." (Highlights the operational benefit of eliminating manual IP range maintenance)
