# Connect Any Agent to Business Central

> The post explains how to connect external AI agents (Claude, Cursor, GitHub Copilot, etc.) to Business Central using the Model Context Protocol (MCP), focusing on a new multiplatform Python-based MCP proxy that enables agents to read and write data in Business Central. It covers setup, usage, and troubleshooting for production agent deployments.

## Key points

- Agents differ from copilots by running tools in loops and self-deciding which data to query, versus copilots providing deterministic question-answer flows.
- Microsoft's BC MCP Server only initially worked with Copilot Studio; the new BcMCPProxy enables other agents like Claude Desktop, VS Code, and Cursor to access Business Central.
- A multiplatform Python version of BcMCPProxy simplifies installation (pip install), works cross-platform on Mac, Windows, and Linux, and integrates better with IDEs than the .NET version.
- Setup requires Azure AD App Registration with specific permissions, device-code login, and configuration file generation for different MCP clients.
- Common issues include aggressive top parameter limits on results and 401/400 errors requiring permission verification or endpoint updates; explicit requests help retrieve complete datasets.
