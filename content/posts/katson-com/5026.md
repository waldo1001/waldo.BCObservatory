## Key points

- Business Central's native MCP server launched in 2025 release wave 2, enabling third-party AI agents to access BC data
- Claude Desktop requires an Entra app registration with a public client setup using PKCE and a specific OAuth callback URI
- The mcp-remote bridge tool handles HTTP transport and Microsoft sign-in between Claude Desktop and the BC MCP server
- Configuration requires matching values across three parts: Entra registration, BC MCP server setup, and Claude Desktop config file
- Three common pitfalls: confusing Claude Code config with Desktop config, using outdated mcp-remote versions, and incorrect callback port settings
