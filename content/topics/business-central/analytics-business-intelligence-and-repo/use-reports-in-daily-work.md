# Use reports in daily work

> Using reports in Business Central day to day: finding, running, previewing, printing and scheduling reports, saving settings, choosing layouts, setting default printers, using the Report Inbox, bookmarking, and exporting datasets to Excel or XML. It answers how-to questions for end users and advanced users.

## Overview

This section covers the everyday tasks around reports in Business Central. It starts with an entry page that lists the main steps: find a report with Report Explorer, fill in the request page, run or schedule it, manage saved settings, change the layout, and analyze the data.

The other pages each cover one task. Run and Print Reports explains request pages, filters, preview, print to file, printer choice and job queue scheduling. Saved settings, layout selection and default printer pages cover how to reuse options and control output. The Report Inbox page covers scheduled output, including download, sharing and OneDrive. A separate page covers exporting datasets to Excel or XML for inspection.

Start with "Use Business Central Reports in Your Daily Work" for the overview, then "Run and Print Reports in Business Central" for the core workflow. Use the other pages as needed for printers, layouts, bookmarks or data analysis.

## Key points

- Run and Print Reports covers opening, previewing, printing, printing to file and scheduling reports through the job queue, plus language and format settings.
- Saved settings let you keep options and filters for a report or batch job, either per user or shared for all users in a company, and you can copy and edit them on the Report Settings page.
- Report layouts can be set as a default per company, chosen temporarily on the request page, or managed on the Report Layouts and Report Layout Selection pages (header/footer layouts, composite branding and theme assignment are mentioned).
- Default printers can be set for all users, a specific user or a specific report using Printer Management and Printer Selections, and overridden on the request page; Universal Print is mentioned.
- The Report Inbox holds scheduled reports; you can download, share, delete them or open them in OneDrive, and files have expiration dates.
- The bookmark icon, on the page itself or in Tell Me, adds quick links to pages and reports on your role center, and bookmarks can be removed.
- Report datasets can be exported to Excel (data only) or XML for diagnosis and ad-hoc analysis; the Excel file includes a Report Metadata worksheet and shows filters.
