# Banking & Payments

> Swiss banking and payments in Business Central: QR-bills, ESR payment slips, LSV+ direct debit collections, SEPA credit transfers, bank clearing numbers and the Vendor Payments List report. It answers how to set up, issue, export, import and post these payments in the Swiss version.

## Overview

This section covers the electronic payment methods used in Switzerland. Overview pages describe the options: QR-bills, ESR (Einzahlungsschein mit Referenznummer), LSV+ (Lastschrift Verfahren) direct debit and SEPA credit transfers, with IBAN and QR-IBAN support. Separate pages explain ESR, which handles payments in Swiss Francs and Euros, and LSV+ in more depth.

Task pages follow the payment flow. For ESR, you print payment slips on sales invoices or as ESR coupons. You then import bank files into cash receipt journals, where payments are applied to invoices automatically. For LSV+, you create a collection in the LSV Journal, close it, and export the LSV file for the bank. Later you import the bank's payment advice into a cash receipt journal and post it. Automatic ESR processing can close LSV journal lines when matching ESR payment files are imported. QR-bill management covers issuing QR-bills on invoices and scanning, importing and reconciling received ones.

Start with the Swiss Electronic Payments overview to pick the method that fits. Then use the ESR, LSV+ or QR-bill pages for setup and daily steps. The clearing numbers import and the Vendor Payments List report support these flows.

## Key points

- The Swiss Electronic Payments overview covers QR-bills, ESR, LSV+ and SEPA credit transfers, with IBAN and QR-IBAN support.
- ESR printing: print payment slips on sales invoices or as separate ESR coupons, choosing the ESR bank and the number of copies.
- ESR import: the Read ESR File action loads bank file data into cash receipt journals and applies payments to invoices automatically by matching the ESR reference number. Multiple ESR banks are supported.
- LSV+ collection: the LSV Suggest Collection batch job fills the LSV Journal. You can print the collection order and mark payment discounts. The export page adds a test mode for the LSV file.
- Closing an LSV collection combines postings and sets the status to Released, which prepares the LSV file for the bank. You can reopen the collection or change the posting date.
- Posting LSV+ payments: import the bank's payment advice into the cash receipt journal with the Get From LSV Journal action, then post. The LSV Status field tracks progress, and automatic ESR processing can close matching LSV journal lines.
- QR-bill management covers QR-bills on posted sales and service invoices, scanning and importing received QR-bills, structured and combined address types, SWICO billing information, and payment reference generation and matching.
- Bank clearing numbers are imported from a bank directory file with Import Bank Directory and can be updated automatically. The Vendor Payments List report sorts payments chronologically or by vendor and offers Standard, FCY Amounts and Posting Info layouts.
