## Overview

This section holds general pages for the Canadian version of Business Central. It has no subtopics, only two pages.

The main page is about GIFI codes, which classify financial information so it can be reported electronically to the Canada Revenue Agency. It covers setting up the codes, associating them with general ledger accounts, viewing account balances by GIFI code, and exporting those balances to Excel for use in tax preparation software.

The second page is a short pointer on how to print troubleshooting reports in the Canadian version. Start with the GIFI page if you are preparing tax filings, and use the troubleshooting page when you need diagnostic reports.

## Key points

- GIFI codes classify and report financial information to the Canada Revenue Agency electronically.
- GIFI codes are set up first, then associated with general ledger accounts.
- Account balances can be viewed by GIFI code.
- Balance information can be exported to Excel for tax preparation software.
- A separate page explains how to print troubleshooting reports in the Canadian version.
