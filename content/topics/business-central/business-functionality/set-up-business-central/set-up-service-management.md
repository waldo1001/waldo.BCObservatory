# Set up service management

> Learn section Business functionality > Set up Business Central > Set up service management: 14 Microsoft Learn pages. Index of what Learn documents here, linked to Learn.

Path: [Business functionality](../../business-functionality.md) > [Set up Business Central](../set-up-business-central.md) > Set up service management · tier official · system service · no narrative yet

## Learn pages

- [How to Create Service Items](https://learn.microsoft.com/dynamics365/business-central/service-how-to-create-service-items): Learn about the different ways you can create service items in Business Central, for example within a service order or when shipping items.
- [How to set up loaners \| Microsoft Docs](https://learn.microsoft.com/dynamics365/business-central/service-how-setup-loaner-program): Set up loaner items to lend to customers as temporary replacements while their service items are being repaired.
- [How to set up work hours and service hours](https://learn.microsoft.com/dynamics365/business-central/service-how-setup-work-service-hours): Learn how to set up the work and service hours used to calculate the response date and time for service orders and quotes.
- [Service items and service item components](https://learn.microsoft.com/dynamics365/business-central/service-how-setup-service-items): Learn about the things you must set up before you can use service items, including default values such as response time and service price group.
- [Set up codes for standard services](https://learn.microsoft.com/dynamics365/business-central/service-how-setup-service-coding): Learn how to set up codes for regularly performed service activities with a predefined set of service lines.
- [Set up fault reporting in Service Management](https://learn.microsoft.com/dynamics365/business-central/service-how-setup-fault-reporting): Set up fault reporting to standardize how you record faults, symptoms, reasons, and resolutions for service items using fault codes and related codes.
- [Set up pricing and costs for services](https://learn.microsoft.com/dynamics365/business-central/service-how-setup-service-costs-pricing): Learn how to use pricing features to set up and customize your application so that you apply and adjust pricing on service items, repairs, and orders.
- [Set up resource allocation \| Microsoft Docs](https://learn.microsoft.com/dynamics365/business-central/service-how-setup-resource-allocation): Learn how the system can help ensure that you assign someone who has the skills required to provide a service.
- [Set up service contracts](https://learn.microsoft.com/dynamics365/business-central/service-how-setup-service-contracts): Learn how to set up service contracts with required prerequisites including service contract groups, contract templates, and customer templates.
- [Set up service management processes](https://learn.microsoft.com/dynamics365/business-central/service-setup-service-processes): Learn how to set up processes that help ensure your customers are satisfied with your services.
- [Set up service offerings](https://learn.microsoft.com/dynamics365/business-central/service-how-setup-service-offerings): Learn how to define the services your organization offers and schedule them for customers as part of service management setup.
- [Set up statuses for service orders and repairs \| Microsoft Docs](https://learn.microsoft.com/dynamics365/business-central/service-order-repair-status): Set up nine distinct repair status options to track the progress of service item repairs and maintenance in service orders.
- [Set up troubleshooting processes \| Microsoft Docs](https://learn.microsoft.com/dynamics365/business-central/service-how-setup-troubleshooting): Learn how to set up processes that help service representatives identify and resolve issues with service items.
- [Setting up service management \| Microsoft Docs](https://learn.microsoft.com/dynamics365/business-central/service-setup-service): Overview of tasks to set up Service Management to suit the way that your organizations manages its services.
