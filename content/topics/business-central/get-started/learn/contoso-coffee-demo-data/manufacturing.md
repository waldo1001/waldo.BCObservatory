# Manufacturing

> Contoso Coffee manufacturing demo walkthroughs for Business Central. They cover production BOMs, routings, capacity, flushing, planning, variants and subcontracting, and answer how-to questions about setting up and running these scenarios with sample data.

Path: [Get started](../../../get-started.md) > [Learn](../../learn.md) > [Contoso Coffee demo data](../contoso-coffee-demo-data.md) > Manufacturing · tier official · system manufacturing · narrative reviewed by Opus

## Overview

This section is a set of hands-on walkthroughs that use the Contoso Coffee demo data. The data has four sample products with different BOMs and routings. They are used to show production, subcontracting, flushing methods, capacity and demand forecasting.

The pages fall into a few groups. Setup pages cover creating a production BOM and BOM version, creating a routing, and setting up a new work center and machine center. Production and planning pages cover firm planned production orders, combining automatic and manual flushing, Order Planning with reservations, and variants with MPS planning. Subcontracting pages cover processing a subcontracting operation, the three component supply methods, and subcontracting prices with item charges.

Start with "Introduction to Contoso Coffee Manufacturing" to see the sample products and scenarios. Then follow the walkthrough that matches the task you want to try.

## Key points

- The introduction page describes four sample products and covers phantom BOMs, standard and specific costing, item tracking, product variants and alternative routings.
- BOM walkthrough: create a production BOM and a BOM version, add components, copy a BOM, set a starting date and certify it.
- Routing walkthrough: create a routing manually with operation numbers, work center assignment, setup and run times, then certify it.
- Capacity walkthrough: set up a work center and machine center with shop calendar, capacity calendar and efficiency ratings.
- Production orders: create a firm planned order and use backward and forward scheduling. Combine forward flushing, manual consumption journals and backward flushing.
- Order Planning walkthrough: use Calculate Plan, Make Orders and Reserve to create subassembly production orders and reserve their output for a parent order.
- Variants walkthrough: set up SKUs, production BOMs by variant and demand forecasts by location and variant, then run MPS planning and verify components.
- Subcontracting pages cover subcontracting routing, transfer orders and purchase orders, work-in-progress items, return materials, and the supply methods transfer to vendor, consignment at vendor and vendor-supplied. They also cover subcontracting prices and item charge allocation.
