## Overview

This section is the entry point for new Business Central customers. It has two pages and no subtopics. One page explains how to start a free trial, and the other explains what to set up once you have an environment.

The trial page describes two routes. In countries with Microsoft-based localization, you sign up directly with Microsoft. In countries without built-in localization, the trial goes through a partner in the Cloud Solution Provider program. Localized demo data and sandbox environments are part of the trial options.

The "Get ready for doing business" page covers the first setup tasks: assisted setup guides, company information, creating users and assigning permissions, and role-specific home pages. It also links to quick start articles for key areas. Start with the trial page if you have no environment yet, and go to the setup page if you already do.

## Key points

- Free trial can be started through a Microsoft-based localization path.
- In countries without built-in localization, the trial is set up through a partner in the Cloud Solution Provider program.
- Trials relate to localized demo data and sandbox environments.
- Assisted setup guides help with initial configuration.
- Initial tasks include setting up company information, creating users and assigning permissions.
- Role-specific home pages are explained in the setup overview.
- The setup page links to quick start articles for key areas and mentions teaching tips.
- The setup page references 2021 release wave 2.
