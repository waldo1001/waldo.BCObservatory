# Business Central 2021 release wave 2

> Business Central 2021 release wave 2 (version 19) on-premises upgrade documentation. It covers upgrade paths from versions 14 to 18, C/AL to AL conversion, installing version 19 updates, moving tables and fields between extensions, permission set upgrades, and the India data migration toolkit.

## Overview

This section collects the Learn pages for upgrading on-premises Business Central to 2021 release wave 2 (version 19). The entry page, "Upgrade to Business Central 2021 Wave 2", describes the two main options: a technical upgrade or application refactoring. The compatibility matrix helps confirm a valid upgrade path before you start.

The remaining pages split by starting point. Versions 15 to 18 use the base application upgrade and technical upgrade pages. Version 14 with C/AL has separate pages for an unmodified application, a customized application moved to the Microsoft base application, and the full technical upgrade. Supporting pages cover Txt2Al code conversion, permission set upgrade, and moving tables and fields between extensions with migration.json, either down or up the dependency graph.

Start with the overview and the compatibility matrix, then choose the page that matches your source version and level of customization. Use the version 19 update page for cumulative updates after you are on version 19.

## Key points

- The compatibility matrix lists minimum compatible update versions for upgrades between major releases, from version 14 onward.
- Upgrade options to version 19 are technical upgrade or application refactoring, from versions 16, 17 or 18 (technical) and from version 14 or earlier (C/AL).
- Version 14 C/AL customizations are converted to AL with the Txt2Al tool, including .NET interoperability and test library conversion.
- Moving a C/AL application to the Microsoft system and base applications uses the DestinationAppsForMigration server setting and migration.json.
- Table and field ownership moves between extensions use migration.json; moving up the dependency graph needs a two-stage process with a transition extension.
- Permissions move from legacy data-based permissions to AL object-based Permission Set and Permission Set Extension objects.
- Technical upgrade steps include database conversion, extension compilation, tenant mounting, synchronization, and extension installation.
- The India Data Migration Toolkit upgrades from Dynamics NAV 2016 India in two steps, covers localization data but not customizations.
