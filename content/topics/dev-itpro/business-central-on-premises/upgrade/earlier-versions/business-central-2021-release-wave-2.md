- [Moving Tables and Fields to Extensions Up the Dependency Graph](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/devenv-migrate-table-fields-up): Explains how to move tables and fields from an extension to another extension that is up the dependency graph
- [Technical upgrade From version 14 to version 19](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/upgrade/upgrade-technical-upgrade-v14-v19): Describes how to do a technical upgrade from Business Central 14 to 19

- [Upgrade to Business Central 2021 Wave 2](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/upgrade/upgrade-overview-v19): Provides an overview of Business Central 2021 release wave 2 upgrade
- [Upgrading Customized C/AL Application to Microsoft Base Application for Version 19](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/upgrade/upgrade-to-microsoft-base-app-v19): Describes how to do an upgrade from a customized Business Central 14 to Microsoft Base Application for version 19
- [Upgrading Permission Sets and Permissions](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/upgrade/upgrade-permissions): Describes how to upgrade permissions and permission sets
- [Upgrading unmodified C/AL application to version 19](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/upgrade/upgrade-unmodified-application-v14-v19): Describes how to upgrade an unmodified Business Central 14 application to version 19
- [Upgrading Version 15, 16, 17, or 18 Base Application to Version 19](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/upgrade/upgrade-unmodified-application-to-v19): Describes how to upgrade an unmodified Business Central 15, 16, or 17 application to version 19
