# Business Central 2022 release wave 1

> Business Central 2022 release wave 1 (version 20) upgrade documentation for on-premises installations. It answers questions about upgrade paths from versions 14 to 19, C/AL to AL conversion, moving tables between extensions, permission sets, report changes, and installing version 20 updates.

## Overview

This section covers upgrading to Business Central 2022 release wave 1 (version 20). The entry page, "Upgrade to Business Central 2022 Wave 1", outlines the paths: a technical upgrade, or application refactoring to the system application. The compatibility matrix helps you check which upgrade paths and minimum update versions are allowed.

## Key points

- Start with "Upgrade to Business Central 2022 Wave 1" and the compatibility matrix to confirm the upgrade path.
- Versions 15 to 19 upgrade to version 20 through database conversion, extension publishing and recompilation, tenant synchronization and data upgrade, with PowerShell cmdlets.
- Version 14 upgrades convert C/AL to AL with the Txt2Al tool; unmodified apps replace the C/AL base application with the Microsoft System and Base Application extensions.
- Customized version 14 upgrades use the DestinationAppsForMigration server setting and migration.json for two-phase table migration.
- Moving tables and fields between extensions depends on dependency direction: down the graph uses migration.json, up the graph uses a transition extension in two stages.
- Permission sets become AL objects (Permission Set and Permission Set Extension) instead of legacy data-based permissions.
- Version 20 uses platform rendering for reports, so Word and custom layouts, report events and RDLC need review before upgrading.
- The India Data Migration Toolkit moves Dynamics NAV 2016 India data to Business Central 2021 release wave 2 in two steps, without customizations.
