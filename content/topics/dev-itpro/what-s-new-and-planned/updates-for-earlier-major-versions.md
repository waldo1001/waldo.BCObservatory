# Updates for earlier major versions

> Release notes for Business Central minor updates from 15.2 (2019 release wave 2) through 27.5 (2025 release wave 2), including 26.0 and 27.0 preview pages. They answer what changed in a given update: hotfixes, features, localization, telemetry, deprecations and upgrade notes.

## Overview

This section is a set of per-update release notes for earlier major versions of Business Central. Each page covers one update (for example 17.3 or 24.2) and names the release wave it belongs to. The pages are grouped by wave: 2019 wave 2 (15.x), 2020 waves 1 and 2 (16.x, 17.x), 2021 waves 1 and 2 (18.x, 19.x), 2022 waves 1 and 2 (20.x, 21.x), 2023 waves 1 and 2 (22.x, 23.x), 2024 waves 1 and 2 (24.x, 25.x) and 2025 waves 1 and 2 (26.x, 27.x).

Use them to find when a capability, regulatory change or deprecation arrived. Typical content includes hotfixes, new features, telemetry signals, localization updates by country, and notes on features that become mandatory. Start with the update number you are on or asking about. Pages 26.0 and 27.0 describe the larger feature sets for their waves.

Some pages carry version labels that differ from their titles. Examples are 26.1 and 26.2, which are titled as 2024 wave 1 but described as 2025 wave 1, and 23.5, which mentions update 26.0. Check the release wave named in the page body.

## Key points

- Coverage runs from update 15.2 (2019 release wave 2) to 27.5 (2025 release wave 2), plus 26.0 and the 27.0 preview.
- Deprecations are noted: Internet Explorer 11 (16.5, 17.5), OData V3 and basic authentication removal (17.4, 17.5), and Docker image production moving to artifacts (16.4).
- Telemetry additions appear across 15.3 to 17.3: sign-in attempts, company lifecycle, extension lifecycle, page views, job queues, permissions and web service key authentication.
- Cloud migration and environment features: data migration from on-premises (16.2), environment backup and restore (17.3), environment copy across types (19.1), delegated admin migration setup (19.4), Dynamics SL migration (25.2), and migration from any SQL database (27.5).
- Localization and regulatory items recur: Intrastat, SAF-T, CFDI and Carta Porte for Mexico, electronic VAT return, SII for Spain, IRS 1099, e-invoicing in Denmark, and Verifactu for Spain (27.3).
- E-documents framework and PEPPOL updates appear from 23.2 through 27.x.
- Copilot and agent features: marketing text and bank reconciliation help (23.1), Chat with Copilot (25.x), Sales Order Agent and Payables Agent (26.x, 27.x), and AI agent designer in public preview (27.4).
- Updates such as 23.5 and 24.1 flag upcoming mandatory features like G/L entry aggregations when posting invoices and the new extensible exchange rate adjustment. Later 24.x and 25.x pages repeat these items.
