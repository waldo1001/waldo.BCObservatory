# Dataverse API

> Learn section Integration > Integrating with Microsoft Dataverse > Data synchronization > Dataverse API: 11 Microsoft Learn pages. Index of what Learn documents here, linked to Learn.

Path: [Integration](../../../integration.md) > [Integrating with Microsoft Dataverse](../../integrating-with-microsoft-dataverse.md) > [Data synchronization](../data-synchronization.md) > Dataverse API · tier official · system integration · no narrative yet

## Learn pages

- [Business Central Dataverse API Overview](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/api-dataverse/dynamics-dataverse-api): Learn how the Business Central Dataverse API notifies Business Central about Dataverse entity changes and supports webhook subscriptions.
- [Company Resource for the Business Central Dataverse API](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/api-dataverse/resources/dynamics_company): Learn about the company resource in the Business Central Dataverse API, including its properties and Dataverse entity change navigation.
- [Create a Business Central Dataverse API Subscription](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/api-dataverse/api/dynamics_subscriptions_create): Create a webhook subscription for the Business Central Dataverse API and complete the validation handshake for the notification URL.
- [Create a Dataverse Entity Change in Business Central](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/api-dataverse/api/dynamics_dataverseentitychange_create): Notify Business Central that a Dataverse table changed so the applicable Dataverse synchronization job can run immediately.
- [Dataverse Entity Change Resource for Business Central](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/api-dataverse/resources/dynamics_dataverseentitychange): Learn about the Dataverse entity change resource that notifies Business Central when a synchronized table changes in Microsoft Dataverse.
- [Delete a Business Central Dataverse API Subscription](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/api-dataverse/api/dynamics_subscriptions_delete): Delete a webhook subscription from the Business Central Dataverse API when an integration no longer needs change notifications.
- [Get a Company with the Business Central Dataverse API](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/api-dataverse/api/dynamics_company_get): Retrieve a Business Central company through the Dataverse API route so you can identify the company used for entity change operations.
- [Get Dataverse Entity Change Details](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/api-dataverse/api/dynamics_dataverseentitychange_get): Retrieve a Dataverse entity change from Business Central to inspect the Dataverse table associated with a synchronization notification.
- [Retrieve Business Central Dataverse API Subscriptions](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/api-dataverse/api/dynamics_subscriptions_get): Retrieve webhook subscriptions for the Business Central Dataverse API, including their notification URLs, resources, and expiration times.
- [Subscription Resource for the Business Central Dataverse API](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/api-dataverse/resources/dynamics_subscriptions): Learn about the subscription resource used to manage webhook notifications and callback details for the Business Central Dataverse API.
- [Update a Business Central Dataverse API Subscription](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/api-dataverse/api/dynamics_subscriptions_update): Renew or update a webhook subscription for the Business Central Dataverse API and complete the required notification URL handshake.
