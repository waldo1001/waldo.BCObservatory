# Deprecated features

> Deprecated features in Business Central: what has been removed or replaced in the platform (client, server, database), the application, local versions and tables, plus how code is marked obsolete and the timeline for removal. It answers whether a feature, API, table or tool is deprecated, what replaces it, and when.

## Overview

This section lists what Microsoft has deprecated or removed in Business Central and how deprecation works. The own pages cover platform items (client, server, database) by release wave from 2022 wave 1 to 2027 wave 1, the BcContainerHelper deprecation, and the timeline for deprecating code. The subtopics cover the application (W1), local functionality, deprecated tables, and the AL mechanisms for marking code obsolete.

Start with the page that matches your question. For platform items such as endpoints, authentication, PowerShell modules or the Windows Client, use the client, server, database page. For application objects such as reports, APIs or tables, use Application and Deprecated tables. For how long you have to react, read the timeline page, which sets a minimum of 12 months between marking code obsolete and removing it. Deprecating code explains the obsolete attributes, preprocessor symbols and the 'with' statement change.

For build and container tooling, the BcContainerHelper page says support ends October 1, 2027, and points to AL-Go for GitHub as the replacement.

## Key points

- Platform deprecations are listed by release wave, from 2022 wave 1 to 2027 wave 1.
- Platform items include OData endpoints on Microsoft pages, SOAP endpoints on UI pages, PowerShell 5.0 administration modules, Web Service Access Keys (Basic Auth), data-defined permission sets and delta links with APIs.
- ADAL and Azure AD Graph are replaced by MSAL and Microsoft Graph. The Windows Client is removed in favor of the web, desktop and mobile apps. The Excel COM add-in and programmatic printing are tied to it.
- BcContainerHelper support ends October 1, 2027. AL-Go for GitHub is the replacement.
- Microsoft allows at least 12 months between marking code obsolete and removing it. The tools are the ObsoleteState and ObsoleteTag properties, the Obsolete attribute and AppSourceCop.
- The Application subtopic covers W1 removals from 2019 to 2027, including objects deleted from the Base App in 2025 release wave 1 (v26).
- Deprecated tables pages map old tables to new names for code rewrites from 2020 release wave 1 onward, and list India deprecated tables for 2021 release wave 2. Data migration may be needed.
- Deprecating code covers preprocessor symbols, obsolete attributes and the deprecation of explicit and implicit 'with' statements.
