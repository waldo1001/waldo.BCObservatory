- [AL development environment reference overview](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/devenv-reference-overview): Overview of the objects in the AL Language development environment.

- [BigInteger data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/biginteger/biginteger-data-type): Stores very large whole numbers that range from -9,223,372,036,854,775,807 to 9,223,372,036,854,775,807.
- [BigText data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/bigtext/bigtext-data-type): Handles large text documents.
- [Blob data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/blob/blob-data-type): Is a complex data type.
- [Boolean data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/boolean/boolean-data-type): Indicates true or false.
- [Byte data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/byte/byte-data-type): Stores a single, 8-bit character as a value in the range 0 to 255.
- [Char data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/char/char-data-type): Stores a single, 16-bit character as a value in the range 0 to 65535.
- [Code data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/code/code-data-type): Denotes a special type of string that is converted to uppercase and removes any trailing or leading spaces.
- [Data types and methods in AL](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/library)
- [Date data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/date/date-data-type): Denotes a date ranging from January 1, 1753 to December 31, 9999.
- [DateTime data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/datetime/datetime-data-type): Denotes a date and time ranging from January 1, 1753, 00:00:00.000 to December 31, 9999, 23:59:59.999.
- [Decimal data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/decimal/decimal-data-type): Denotes decimal numbers ranging from -999,999,999,999,999.99 to +999,999,999,999,999.99.
- [Dictionary data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/dictionary/dictionary-data-type): Represents an unordered collection of keys and values.
- [Duration data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/duration/duration-data-type): Represents the difference between two DateTimes.
- [Extensible Enums](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/devenv-extensible-enums): Overview of the enumeration type and the concept of extending them.
- [Guid data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/guid/guid-data-type): Represents a 16 byte binary data type.
- [Integer data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/integer/integer-data-type): Stores whole numbers with values that range from -2,147,483,647 to 2,147,483,647.
- [Joker Data Type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods/devenv-joker-datatype): The Joker data type is an internal type, a wildcard, not exposed to AL developers.
- [JsonArray data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/jsonarray/jsonarray-data-type): Is a container for any well-formed JSON array.
- [JsonObject data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/jsonobject/jsonobject-data-type): Is a container for any well-formed JSON object.
- [JsonToken data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/jsontoken/jsontoken-data-type): Is a container for any well-formed JSON data.
- [JsonValue data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/jsonvalue/jsonvalue-data-type): Is a container for any well-formed fundamental JSON value.
- [List data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/list/list-data-type): Represents a strongly typed list of ordered objects that can be accessed by index.
- [Media data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/media/media-data-type): Encapsulates media files, such as image .jpg and .png files, in application database tables.
- [MediaSet data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/mediaset/mediaset-data-type): Encapsulates media, such as images, in application database tables.
- [Option data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/option/option-data-type): Denotes an option value.
- [Record data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/record/record-data-type): Is a complex data type.
- [System data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/system/system-data-type): Is a complex data type.

- [TextBuilder data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/textbuilder/textbuilder-data-type): Represents a lighweight wrapper for the .Net implementation of StringBuilder.

- [Time data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/time/time-data-type): Denotes a time ranging from 00:00:00.000 to 23:59:59.999.
- [XmlAttribute data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/xmlattribute/xmlattribute-data-type): Represents an XML attribute.
- [XmlAttributeCollection data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/xmlattributecollection/xmlattributecollection-data-type): Represents a collection of XML attributes.
- [XmlCData data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/xmlcdata/xmlcdata-data-type): Represents a CData section.
- [XmlComment data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/xmlcomment/xmlcomment-data-type): Represents an XML comment.
- [XmlDeclaration data type](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/xmldeclaration/xmldeclaration-data-type): Represents an XML declaration.
