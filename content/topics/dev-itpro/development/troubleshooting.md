# Troubleshooting

> Troubleshooting for Business Central development covers tools and guides for finding and fixing problems: in-client diagnostics, AL profiling and debugging, telemetry in Application Insights, and troubleshooting guides (TSGs). It answers questions about errors, slow performance, locks, web service failures and cloud migration problems.

## Overview

This section collects resources for gathering information about an issue, identifying the cause, and applying a fix. An overview page introduces the main tools: error dialog inspection, Page Inspector, Event Recorder, database locks, the Performance Profiler and the AL Profiler.

The subtopics split by where you work. Troubleshooting in the client covers diagnostic tools inside Business Central, plus personalization, permissions and on-premises mobile app issues. Troubleshooting in AL covers the AL Profiler, VS Code debugging, snapshot debugging and printing problems. Troubleshooting with telemetry covers sending telemetry to Azure Application Insights and analyzing it with KQL, Power BI and alerts. The troubleshooting guides give step-by-step help for specific failures.

Start with the overview page to pick a tool. Use the client pages for quick checks, the AL pages for code-level problems, telemetry for patterns over time, and the TSGs when you have a known symptom such as a report error or an OData, API or SOAP failure.

## Key points

- Client tools include page inspection, error dialogs, database locks, table information, missing indexes, event discovery, report dataset export and the Performance Profiler.
- AL troubleshooting covers the AL Profiler, VS Code debugging, snapshot debugging, Page Inspection and performance articles for extensions.
- Printing troubleshooting in AL covers printer and report payload errors.
- Telemetry pages cover enabling telemetry to Azure Application Insights, the available events, KQL and Power BI analysis, and alerting.
- Telemetry can also be used to diagnose performance problems.
- TSGs cover cloud migration problems, report errors and slow reports, and web service failures (OData, API, SOAP).
- The client section also covers page customization, personalization, permissions and on-premises mobile app issues.
