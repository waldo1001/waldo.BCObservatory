Six ways to look at the cross-referenced data

desktop, dark - one thumbnail and one paragraph each - real counts 2026-10-07

A. Layered Observatory

Canvas 2D

The galaxy stays; at system level a Tilt control tips it into four planes sharing x/y: media, topic hubs, all code objects, countries. The cross-references become the lines between planes, and a focused star lights its core sample through all of them. The only direction where every kind of data shares one picture. Risk: 2,021 objects plus 728 links is a lot of ink on one plane.

B. Code city

WebGL required

The /objects/ treemap, extruded: district is namespace, building is object, height is fields plus procedures, colour is the existing lens. The BC28 to 29 to 30 stepper makes 85 buildings appear, 943 grow, 20 go obsolete and 32 vanish. The best picture of version change there is. But it is code only: docs, media and events have no place to stand, and 16k buildings means WebGL.

C. Neighbourhood explorer

SVG

Start from any object and see rings of what touches it: Table 18 "Customer" has 41 relates to, 170 referenced by, 32 pages and codeunits, 4 extensions, 11 subscribers, plus Learn pages. Relation kinds are filters, you expand one neighbour at a time, and an events mode answers "who subscribes". Precise and cheap, and every ring is already a list. No overview, no time.

D. Galaxy, honest

Canvas 2D, as today

Keep the 2D galaxy and fix what was measured: position means the Learn tree and the namespace tree, the focused star draws its cross-system edges, brightness is evidence, hubs pulse when a video or post lands this week, and a version lens lights the 899 objects changed in BC29. Every system and star gets exits to the instruments. Cheapest, most reuse; still 1,018 stars, not 16,425.

E. Instrument panel

DOM only

No hero map. The home is one panel of the instruments that already exist, each with live numbers and a way in: atlas, country heatmap, deprecation calendar, event explorer, version lens, drift report, coverage heatmap, this week's digest, 11 flight paths, search and Ctrl+K. Honest and fast, zero new pipeline. But every answer is one click away in a separate room, and the observatory stops being a place.

F. 3D star field (baseline)

WebGL + force layout

The obvious 3D: a force-directed graph of all 16,425 objects and 20,516 relations, orbit and zoom, labels on hover. It impresses for ten seconds and then answers nothing: no docs, no media, no countries, no versions, no stable positions, no keyboard path, no mobile. Included so the comparison is fair. It is the hairball every other direction is trying not to be.
